## 摘要
同策略蒸馏（OPD）在教师提供的密集令牌级监督下，基于学生自身的轨迹进行训练。奖励外推方法（如ExOPD）通过放大教师参考对数似然比来超越直接模仿，但对每个令牌应用单一的全局系数λ。这可能会驱使学生拟合隐式奖励中的极端峰值，导致奖励黑客攻击和训练不稳定，且最优λ因领域而异，需要昂贵的搜索。我们提出REOPD，一种用于OPD的可靠性自适应奖励外推框架。REOPD结合了令牌级兼容性权重与批次级自适应预算，产生令牌级系数λ_{b,t}=1+γ_b q_t，在保持教师对齐的同时，沿可靠的教师参考方向选择性外推。它无需验证器、奖励模型、价值模型，也无需标准OPD之外的额外推出。REOPD在单教师数学任务和多教师设置的两个领域上均优于G-OPD，同时在单教师代码任务上与G-OPD持平，展示了跨领域和教师配置的有效细粒度可靠性自适应。

## Abstract
On-policy distillation (OPD) trains a student on its own trajectories under dense token-level supervision from a teacher. Reward-extrapolation methods such as ExOPD amplify the teacher-reference log-likelihood ratio to move beyond direct imitation, but apply a single global coefficient $λ$ to every token. This can drive the student to fit extreme peaks in the implicit reward, causing reward hacking and unstable training, and the optimal $λ$ varies across domains, requiring costly sweeps. We propose REOPD, a reliability-adaptive reward extrapolation framework for OPD. REOPD combines a token-level compatibility weight with a batch-level adaptive budget, yielding a token-wise coefficient $λ_{b,t}=1+γ_b q_t$ that preserves teacher alignment while selectively extrapolating along reliable teacher-reference directions. It requires no verifier, reward model, value model, or extra rollout beyond standard OPD. REOPD outperforms G-OPD on single-teacher mathematics and on both domains in the multi-teacher setting, while matching G-OPD on single-teacher code, demonstrating effective fine-grained reliability adaptation across domains and teacher configurations.

### 1. 核心问题与整体含义（研究动机和背景）

- **背景**：同策略蒸馏（On-policy Distillation, OPD）是一种大语言模型后训练范式——学生模型在自己的生成轨迹上训练，教师对同一前缀提供密集的 token 级监督。G-OPD 将 OPD 形式化为稠密 KL 正则化强化学习，其中“教师-参考对数似然比”被视为隐式 token 级奖励。
- **现存问题**：奖励外推方法 ExOPD 通过设置全局系数 λ > 1 放大该残差，鼓励学生“超越”教师。然而：
  - **全局系数不加区分**：ExOPD 对所有 token 使用相同的 λ，可能放大教师-参考 log-ratio 中的极端峰值，使学生过度拟合这些峰值，导致奖励黑客（reward hacking）和训练不稳定；
  - **超参数敏感**：最优 λ 在不同任务域之间差异明显，每个新场景都需要昂贵的完整训练和评估扫描，且仍可能选不出合适的强度。
- **核心出发点**：教师对齐和“超越教师的外推”应被分开控制——一个 token 虽然存在较大的师生差异，仍可能提供有用的对齐信号，但不一定适合被放大进行外推。REOPD 正是基于这一观察而提出。

### 2. 论文提出的方法论

**核心思想**：REOPD 在保留标准 OPD 教师对齐项的前提下，只对外推残差进行细粒度的可靠性自适应控制，组合两个层面的机制：

- **Token 级兼容性权重 q_{b,i,t}**：
  - 利用已由 G-OPD 计算的师生 log-prob，构造低方差的 k3 差异代理：
    - x = log πT(y) − log πθ(y)；
    - δ̂ = exp(x) − x − 1 ≥ 0；
  - 得到兼容性权重 q = exp(−δ̂/τ)，其值域为 (0, 1]：
    - 师生差异小 → q ≈ 1，保留大部分外推残差；
    - 师生差异大 → q 变小，抑制不可靠方向的外推；
  - q 是局部兼容性度量，不是任务正确性度量。
- **Micro-batch 级自适应预算 γ_b**：
  - 在同步微批内聚合两个统计量：
    - 兼容加权残差比例 ρ_b = Σ |r|·q / Σ |r|；
    - 可靠残差 RMS 尺度 s_b = RMS(q·r)；
  - 对两者做 EMA 平滑（β = 0.95），计算目标预算：
    - γ̂_b = clip(B0·ρ̄_b / (s̄_b + ε), 0, γ_max)；
    - 再做一次平滑（β_γ = 0.9）得到最终 γ_b；
  - ρ 越大允许越强外推，s 越大则抑制强度，上限 γ_max = 1 提供显式约束。
- **有效外推系数**：λ_{b,i,t} = 1 + γ_b·q_{b,i,t}，因此 token 成本为：
  - C_{b,i,t} = a_{b,i,t} − γ_b·q_{b,i,t}·r_{b,i,t}
- **算法流程要点**：
  1. 采样学生轨迹；
  2. 计算学生、教师、参考的 log-prob；
  3. 计算对齐项 a、残差 r、差异代理 δ̂ 和脱离计算图的 q；
  4. All-Reduce 同步微批充分统计量；
  5. 更新 EMA 统计量并计算 γ_b；
  6. 构造 PPO 风格优势 A = −C，更新学生策略。
- **关键特性**：所有控制信号（q、统计量、γ）均为 stop-gradient；不引入验证器、奖励模型、价值模型或额外 rollout；特例关系——γ=0 退化为 OPD；q=1 且 γ=λ−1 退化为固定 λ 的 ExOPD。

### 6. 论文的主要结论与发现

- **主结果**：
  - 单教师数学：REOPD 池化准确率 47.66%，优于 OPD（46.28%）和 ExOPD λ=1.25（47.47%）；
  - 单教师代码：REOPD 加权准确率 63.45%，优于 OPD（62.55%）和 ExOPD λ=1.25（61.72%），与 G-OPD 持平；
  - 多教师蒸馏：REOPD 在数学（47.01%）和代码（63.32%）两个领域同时优于 OPD（46.43%/61.99%）和 ExOPD λ=1.25（46.98%/62.90%）。
- **与最优固定 λ 的比较**：REOPD 在 4 个设置中 3 个超越了对应网格内最优固定 ExOPD（+0.19、+0.03、+0.42 pp），在单教师代码上仅落后 0.15 pp——表明无需逐场景 λ 扫描也能达到可比或更好的效果。
- **消融揭示组件重要性**：
  - 去掉 q（no_q）导致性能从 47.66% 骤降至 43.39%（−4.27 pp）→ token 级兼容性是**核心组件**；
  - 去掉 γ 上界（no_bound）为 47.16%（−0.50 pp）→ 上限是**中等强度的保护**；
  - 固定 γ（no_batch）在最优 λ0=1.25 时达到 47.66%，与 Full REOPD 持平 → 在线预算的核心价值是**免除逐场景扫描**而非提升定点上限。
- **控制器动力学**：γ 和有效系数 λ 在训练早期最强地自适应（γ 从约 0.61 升至约 1.00），后期主要由 q 提供剩余变化，说明 REOPD 并非使用恒定系数。

### 7. 优点

- **方法设计简洁、工程友好**：完全复用标准 OPD 中已有的学生、教师、参考 log-prob，不引入验证器、奖励模型、价值模型或额外 rollout，易于在现有 OPD 流水线上落地。
- **细粒度可靠性控制**：将“教师对齐”与“超越教师的外推”解耦，只在可靠的教师-参考方向上选择性放大，从机制上降低奖励黑客风险。
- **逐 token + 跨 batch 双层自适应**：同时覆盖局部( token )和全局(微批)的残差信息，并通过跨秩 All-Reduce 保证各 rank 使用一致的控制器输出。
- **泛化性与鲁棒性**：同一套超参数跨数学、代码和多教师场景均有效，无需逐场景 λ 扫描，减轻了应用成本。
- **诊断清晰**：消融研究设计精准，能清楚分离各组件贡献，且提供了控制器运行轨迹作为内部行为验证。

### 8. 不足与局限

- **兼容性 ≠ 正确性**：q 只是师生差异的代理，无法识别“学生教师都错但一致”的轨迹，因此不能完全避免奖励黑客。
- **剩余控制器超参数**：τ、γ_max、β、β_γ 和 B0 的自动标定仍需人工指定；数学场景还使用了 5 次调用的 warm-up 及 γ=0.25 特殊配置，说明方法并非完全免调参。
- **统计依赖微批构成**：ρ 和 s 对批内样本组合敏感，跨数据分布漂移时可能有波动。
- **训练后期预算饱和**：γ 在后期接近上界 1.0，后期自适应主要由 q 承担，外推强度的动态调节能力在后期受限。
- **实验覆盖不足**：
  - 仅在 Qwen3-4B 上验证，缺少不同模型族、不同规模、不同教师强度的泛化证据；
  - 未报告多次运行的方差、训练中期曲线、更长训练设置下的行为；
  - 未比较“共享 vs. 按教师独立控制器”的设置差异。
- **代码评估限制**：只有 pass@1、采样数较少（4 次），且未涉及更长篇幅的程序合成任务，与数学 benchmark 相比证据强度较弱。
