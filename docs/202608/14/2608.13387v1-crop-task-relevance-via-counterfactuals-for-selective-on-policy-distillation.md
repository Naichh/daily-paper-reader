## 摘要
在线策略蒸馏（OPD）在从当前策略采样的轨迹上监督学生语言模型，但对具有不同监督价值的响应标记赋予相同的权重。选择性OPD通过根据估计的训练价值在响应标记间非均匀分配监督来解决这一局限性。然而，大多数现有标准主要关注优化需求，例如不确定性或师生分歧，而任务相关性（即监督是否与当前输入的语义内容相关）作为互补维度仍未被直接刻画。为弥补这一空白，我们引入了用于在线策略蒸馏的反事实相关性（CROP），通过释义校准的反事实敏感性边际来操作化任务相关性。对于每个源提示，CROP构建一个经过验证的原始-释义-反事实三元组，保持学生采样固定，并测量每个响应位置对任务相关条件变化的敏感性，该敏感性通过其对保留语义的改写变化的敏感性进行校准。匹配选择的对照实验表明，CROP识别出的有用监督位置优于随机或最低相关性选择，而组件比较确认了反事实敏感性和释义校准两者的价值。在两种师生设置中，CROP相比最强的非CROP选择器将整体性能提高了1.92分和2.96分。这些结果支持任务相关性作为选择性OPD的互补标准，并确立CROP作为一种模型内部、对比特定的方法用于分配token级监督。

## Abstract
On-policy distillation (OPD) supervises a student language model on trajectories sampled from its current policy, but assigns equal credit to response tokens with unequal supervision value. Selective OPD addresses this limitation by allocating supervision non-uniformly across response tokens according to their estimated training value. Most existing criteria, however, focus primarily on optimization need, such as uncertainty or teacher-student disagreement, while task relevance, namely whether the supervision is tied to the semantic content of the current input, remains less directly characterized as a complementary dimension. To address this gap, we introduce Counterfactual Relevance for On-Policy Distillation (CROP), which operationalizes task relevance through a paraphrase-calibrated counterfactual sensitivity margin. For each source prompt, CROP constructs a validated original-paraphrase-counterfactual triplet, holds the student rollout fixed, and measures each response position by its sensitivity to a task-relevant condition change calibrated by its sensitivity to a meaning-preserving rewrite. Matched selection controls show that CROP identifies more useful supervision positions than random or lowest-relevance selection, while component comparisons confirm the value of both counterfactual sensitivity and paraphrase calibration. Across two teacher-student settings, CROP improves aggregate performance by 1.92 and 2.96 points over the strongest non-CROP selector. These results support task relevance as a complementary criterion for selective OPD and establish CROP as a model-internal, contrast-specific method for allocating token-level supervision.

## 1. 核心问题与研究动机

- **背景**：在线策略蒸馏（On-policy Distillation, OPD）通过让教师模型对学生当前策略访问到的前缀进行监督，兼顾了在线策略覆盖与密集的 token 级分布监督。但标准 OPD 对所有响应 token 赋予相同的监督权重，忽视了不同 token 在训练价值上的异质性。
- **现有不足**：目前的选择性 OPD 方法（如基于熵、师生分歧、可教性、位置等）主要刻画的是 **优化需求（optimization need）**——即一个 token 是否需要修正、是否不确定、是否与教师不一致等——但较少直接刻画**任务相关性（task relevance）**，即该 token 的监督信号是否真正与当前输入的任务语义相关。
- **核心问题**：一个 token 需要优化（不确定、与教师有分歧）不代表它承载了任务特异的语义信号；反之，一个低熵、看似"确定"的 token 可能恰恰是对任务关键条件的反应。CROP 正是为了补充这一维度而提出。
- **整体含义**：论文主张将任务相关性作为选择性 OPD 中与优化需求互补的监督价值维度，并提出了一个可操作的、模型内部的、对比特定的 token 级相关性度量方法。

## 2. 方法论：CROP

### 2.1 核心思想

- 为每个源提示构造一个**原始–释义–反事实三元组** (x, x_para, x_cf)：
  - **释义 (paraphrase)**：保持任务语义不变的重写（作为表面形式变化的对照）；
  - **反事实 (counterfactual)**：仅改变一个明确的、实质性的任务条件（如数字、运算、范围等）。
- 固定学生模型在原始提示下的实际采样输出 y，将同一 y 的前缀分别放在三个提示下重新评分，测量每个响应位置对条件变化的敏感性，并用对释义变化的敏感性进行校准。

### 2.2 关键技术细节

- **匹配重评分**：对于每个响应位置 t，分别计算：
  - P_ot = π̄θ(· | x, y<t)
  - P_pt = π̄θ(· | x_para, y<t)
  - P_ct = π̄θ(· | x_cf, y<t)
- **Top-K Jensen–Shannon 散度**：对两个分布取 TopK 并集作为有限支撑，补充残余概率桶后计算 JSD（默认 K=64，自然对数单位）。
- **释义校准的相关性分数**：
  - 反事实敏感性：dsem_t = JSD_K(P_ot, P_ct)
  - 表面敏感性：dsurf_t = JSD_K(P_ot, P_pt)
  - CROP 分数：sCROP_t = dsem_t − dsurf_t
- **批量全局预算化选择**：在固定监督 token 预算内，CROP 全局选择分数最高的位置，并引入每样本最少保留一个 token 的保障机制，最终生成二值响应 token 掩码。
- **可选熵混合（CROP-ent）**：通过 Soft-OR 将学生熵与 CROP 分数结合，用于测试不确定性是否与反事实相关性互补。
- 底层 OPD 更新不变：仅掩码决定哪些采样 token 参与 KL 蒸馏损失。

## 6. 主要结论与发现

- **任务相关性是有效补充维度**：CROP 在两种师生设置中分别比最强非 CROP 选择器提升 **1.92 分**（47.98 vs TIP 的 46.06）和 **2.96 分**（57.13 vs Pure OPD 的 55.25，与 CROP-ent 57.48 相比差值为 2.96 基于最佳 CROP 变体）。
- **CROP 的排序是有用的**：CROP-10% 比 Random-10% 高 2.00 分，比 Bottom-10% 高 3.34 分。
- **反事实敏感性是主要信号，释义校准有增益**：CROP 超过 CS-OPD 1.98 分、超过 PC-OPD 4.89 分。
- **CROP 不是熵代理**：其在最低熵十分位上保留了 10% 的 token，而熵类选择器几乎为零。
- **预算效应非单调**：CROP 在稀疏到中等预算（10%–20%）区间最有效；CROP-ent 在 25% 预算时达到峰值 47.99。
- **熵与相关性互补性因设置而异**：CROP-ent 在 Qwen3-8B→4B 设置中最佳，但在 4B→1.7B 设置中不如 CROP。

## 7. 优点

- **问题定位清晰**：将"任务相关性"从"优化需求"中明确区分出来，并给出直观的二维框架。
- **方法设计精巧**：使用释义作为语义不变的对照、反事实作为条件改变的干预，在同一固定 rollout 上做差分，构造简洁且因果方向明确。
- **模型内部、无需额外训练**：仅需若干次学生模型的前向传播即可计算分数，不引入额外可学习参数。
- **兼容性好**：CROP 输出为二值掩码，可直接嵌入任何采样 token 的 OPD 目标，不改变教师 target 和损失结构。
- **消融与控制实验严谨**：随机/最低分对照、组件消融、预算扫描、污染审计等多角度验证了选择分数的有效性与排序的含义。
- **透明度好**：附录提供了完整的三元组构造提示词、验证标准、定性实例、环境版本与代码仓库 commit ID。

## 8. 不足与局限

- **领域覆盖有限**：目前仅在数学推理数据（DAPO-Math）上验证，并未涵盖代码、开放域问答、指令跟随等更广泛的场景，泛化性未知。
- **模型家族单一**：仅使用 Qwen3 系列（1.7B、4B、8B），未验证跨模型家族（如 Llama、Mistral）的有效性。
- **三元组构造依赖 LLM 与人工设计的验证规则**：
  - 生成与验证使用 GPT-5.1，存在模型自身偏差传播的风险；
  - 未独立控制属性（如问题难度）；
  - 反事实只变化一个条件，但程序化验证无法覆盖所有语义等价性；
- **分数解释的局限性**：论文明确指出 CROP 分数是"模型内部、对比特定"的排名启发式，而非因果效应或真实任务相关性的无偏估计；高分数可能反映过度反应，低分数可能反映对条件变化的真实不敏感。

- **最低保留机制可能污染预算比较**：逐样本至少保留一个 token 的约束意味着实际保留比例可能超过名义预算，各方法之间的实际预算一致性未在正文中量化。
