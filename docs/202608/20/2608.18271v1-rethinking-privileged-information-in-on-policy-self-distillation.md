## 摘要
在线策略自蒸馏（OPSD）利用同一模型在特权参考信息条件下产生的token级监督，训练学生模型基于自身响应进行学习。我们探究OPSD带来的性能提升究竟表明学生学到了参考信息，还是仅反映了对基础模型中已存在的推理行为的恢复。我们使用Qwen3模型（参数量从1.7B到8B）在科学和数学数据集上进行了OPSD实验。我们的分析框架将参考信息引入的监督与教师模型在无参考情况下提供的监督分开，并衡量每种监督与学生预测变化的对齐程度。正确的参考信息在教师生成模式、模型规模和训练数据集上并未提供一致的性能收益。学生可以在没有正确参考信息的情况下获得改进，并且在多个数学推理基准上，来自其他问题的解答可以优于正确解答。学生预测与基础模型思考行为的对齐程度强于与参考信息引入的监督的对齐程度，但由其他问题构建的对照组也能在很大程度上再现这两种对齐。此外，归因于正确参考信息的更强对齐并不稳定地与参考信息带来的更大性能收益同时出现。因此，仅凭性能提升和分布对齐无法确定特权参考信息在OPSD中对学生学习的贡献。

## Abstract
On-policy self-distillation (OPSD) trains a student on its own responses using token-level supervision from the same model conditioned on privileged reference information. We investigate whether performance gains from OPSD show that the student learned the information in the reference or instead reflect recovery of reasoning behavior already present in the base model. We perform OPSD experiments on science and mathematics datasets using Qwen3 models ranging from 1.7B to 8B. Our analysis framework separates the supervision induced by the reference from the supervision provided by the teacher without the reference and measures how each aligns with changes in the student's predictions. The correct reference does not provide a consistent performance benefit across teacher generation modes, model sizes, and training datasets. Students can improve without the correct reference, and a solution from another problem can outperform the correct solution on several mathematical reasoning benchmarks. The student's predictions align more strongly with the base model's thinking behavior than with the supervision induced by the reference, but controls constructed from other problems reproduce much of both alignments. Moreover, stronger alignment attributable to the correct reference does not reliably coincide with a greater performance benefit from the reference. Performance gains and distributional alignment alone therefore cannot determine how privileged reference information contributes to student learning in OPSD.

## 1. 论文的核心问题与整体含义

- **研究动机**：在线策略自蒸馏（OPSD）已成为 LLM 后训练的重要方法（如 DeepSeek-V4、Qwen3、GLM-5、Kimi K3 等均采用类似思路），其核心假设是，教师模型在特权参考信息（如参考解答）条件下提供的 token 级监督，能帮助学生提高推理性能。然而，性能提升的来源并不清楚：学生是真的从参考信息中学到了新知识，还是仅仅恢复了基础模型中已经存在但未在推理时充分发挥的思考行为？
- **整体含义**：本文通过系统性的解耦实验，考察了特权参考信息在 OPSD 中的实际作用，挑战了"参考信息越多越好"的直觉。研究发现，正确的参考信息并非持续有益，甚至其他问题的解也能取得更好的性能；学生预测变化与基础模型思考行为的对齐强于与参考监督的对齐。**仅凭性能增益或分布对齐不足以判断特权参考信息对学生学习的真实贡献**，后续研究需要更细粒度的归因方法。

## 2. 方法论

- **核心思想**：设计一个分析框架，将教师监督分解为两部分——由参考信息引入的监督（reference-induced supervision）与无参考时的恢复性监督（recovery supervision），并分别衡量它们与学生预测变化的对齐程度，再通过与"其他问题上下文"构造的控制组对比，识别出真正依赖正确问题上下文的部分。
- **训练目标**：学生 π_S 仅基于问题 x 生成轨迹 y，冻结的教师 π_T 在 x + 参考 r 条件下提供逐 token 的广义 Jensen-Shannon 散度监督：
  L(π_S) = E[Σ_t D_JSD(π_T(·|x, r, y_<t) ∥ π_S(·|x, y_<t))]
- **监督分解**：在每步 t，定义 log T（教师有参考）、log N（教师无参考）、log S_c（学生当前）。总教师-学生差异可分解为：
  - D_tot = log T − log S_c
  - D_ref = log T − log N（参考方向：参考信息对教师预测的影响）
  - D_rec = log N − log S_c（恢复方向：无参考教师与初始学生的差异）
- **方向测量指标**：
  - 内积与范数：在初始学生生成的所有 token 位置上计算（I_0）
  - 参考投影系数 w_ref = ⟨D_ref, D_tot⟩ / ‖D_tot‖²
  - 学生变化量 ΔS_c = log S_c − log S_0
  - 投影系数 β_D = ⟨ΔS_c, D⟩ / ‖D‖²
  - 余弦相似度 cos θ_D = ⟨ΔS_c, D⟩ / (‖ΔS_c‖ ‖D‖)
  - R²_c：ΔS_c 落在两个教师方向张成子空间中的平方长度比例
  - KL 散度：KL_I0(N ∥ S_c)
- **控制组构造**：保持学生响应和前缀固定，将教师的参考/上下文替换为其他问题的参考/上下文，生成控制方向 D*_ref、D*_rec、D*_think。通过对比原始测量与控制测量之间的差异，隔离出对正确问题上下文的依赖。每种控制构造在三种不同配对下重复，以验证结果不受特定配对影响。

## 6. 主要结论与发现

- **性能层面**：
  - 正确参考不提供一致的性能优势；无参考训练也能显著提升，错配参考（其他问题的解）甚至能在多个数学基准上优于正确参考（8B 上 AIME25 和 HMMT25、4B/1.7B 上全部三个竞赛数学基准）。
  - 参考的价值依赖教师生成模式、模型规模和训练数据集：thinking 教师下 MegaScience 科学基准去除参考反而更好；non-thinking 教师下错配参考多数更好。
- **分布对齐层面**：
  - 学生预测变化与恢复方向 D_rec 的对齐强于与参考方向 D_ref 的对齐；这更多地反映基础模型思考行为的恢复。
  - 其他问题构造的控制组能再现大部分对齐（R² 控制值 ≥ 评估值），表明高对齐并不依赖于正确问题上下文。
  - 正确参考带来的额外对齐很小，且更强的对齐不对应更大的性能收益（1.7B MegaScience 上对齐差异最大，但无参考训练性能更好）。
- **总体结论**：性能和分布对齐指标本身无法确定特权参考信息在 OPSD 中的因果贡献，需要更细粒度的归因方法。

## 7. 优点

- **分析框架具有通用性**：将教师监督分解为参考诱导与恢复两部分，并可迁移到其他 OPSD 变体；控制组设计（用其他问题上下文）能有效排除与具体问题无关的共性对齐，是方法论上的一大亮点。
- **实验设计系统全面**：覆盖 3 个模型规模、2 个训练域、2 个教师模式、多种参考类型，且学生生成模式保持固定，干净地隔离了教师侧因素。
- **结论严谨克制**：使用配对 bootstrap 估计不确定性，多控制配对验证稳定性，并明确指出相关对齐不等于因果贡献，避免过度解读。
- **对实践具有警示意义**：为 OPSD 方法的设计者提供了实证证据，表明盲目引入特权参考可能无效甚至有害，需重新审视参考信息的价值。
