## 摘要
在线策略自蒸馏（OPSD）通过从冻结教师模型中对学生模型采样的轨迹进行蒸馏来适应语言模型。然而，其有效性关键取决于这些轨迹的质量。我们表明，当学生模型的生成轨迹偏离目标轨迹时，教师模型基于偏离目标的上下文进行条件生成会显著削弱其任务相关的监督信号。受控的上下文破坏实验揭示了这一失效模式，我们称之为轨迹条件信号退化。为解决该问题，我们提出一个统一的训练框架，分离两条互补的监督路径。第一条保留轨迹条件分布匹配，在学生实际访问的状态上提供指导。第二条在规范的黄金标准上下文上应用监督交叉熵，避免将目标标记强加给错误的生成轨迹前缀时的不兼容性。利用token级轨迹-目标对齐来调整规范上下文锚定的强度，在冷启动阶段增强它，并随着轨迹质量的提高而放松。跨多个模型规模、两个任务族以及通用推理基准的实验表明，所提出方法在OPSD基础上改善了任务获取，同时保持了通用能力，从而实现了更有利的经验可塑性-稳定性权衡。这些发现将上下文质量确定为在线策略自蒸馏中的核心瓶颈，并证明了将轨迹条件指导与规范监督分离的价值。

## Abstract
On-policy self-distillation (OPSD) adapts a language model by distilling guidance from a frozen teacher on trajectories sampled from the student. Its effectiveness, however, depends critically on the quality of those trajectories. We show that when student rollouts drift from target trajectories, conditioning the teacher on off-target prefixes substantially weakens its task-relevant supervision. Controlled prefix-corruption experiments expose this failure mode, which we term rollout-conditioned signal degradation. To address this problem, we propose a unified training framework that separates two complementary supervision pathways. The first retains rollout-conditioned distribution matching, providing guidance on states the student actually visits. The second applies supervised cross-entropy on canonical ground-truth contexts, avoiding the incompatibility of imposing target tokens on erroneous rollout prefixes. Token-level rollout-target alignment is used to adapt the strength of the canonical-context anchor, emphasizing it during cold start and relaxing it as rollout quality improves. Experiments across multiple model scales, two task families, and general-reasoning benchmarks show that the proposed approach improves task acquisition over OPSD while preserving general capabilities, resulting in a more favorable empirical plasticity-stability trade-off. These findings identify context quality as a central bottleneck in on-policy self-distillation and demonstrate the value of separating rollout-conditioned guidance from canonical supervision.

# 论文总结：Adaptive Supervised Anchoring for On-Policy Self-Distillation

## 1. 核心问题与研究动机

- 在线策略自蒸馏（On-Policy Self-Distillation, OPSD）是语言模型后训练的一种重要方法：教师和学生共享同一基座模型，教师通过“特权上下文”（如已验证的解决方案）获得任务相关信息，学生则基于自身生成的轨迹（rollout）接受教师逐 token 的分布监督。
- OPSD 的有效性依赖一个隐含假设：**在学生自身生成的前缀上，教师仍能提供任务相关的有效监督**。但论文发现该假设在任务输出格式、动作空间或推理协议在预训练中未被充分表示时非常脆弱——学生可能快速进入偏离有效轨迹的上下文，导致教师虽能看到目标解，却无法在偏离轨迹上给出正确引导。
- 通过控制实验，论文定义了核心失败模式：**rollout-conditioned signal degradation（轨迹条件信号退化）**。例如，在规范的（canonical）前缀下教师对目标 token 的预测准确率可达 80.4%，但换成学生冷启动的自然 rollouts 后骤降至约 6.5%；进一步提高前缀破坏率，准确率单调降至 3.8%。
- 直接引入标准交叉熵（SFT 式）也存在问题：若在偏离的 rollout 前缀上施加目标 token 监督，会造成“目标–上下文不匹配”；若先 SFT 再 OPSD，则形成硬阶段切换，无法根据实时轨迹质量调节。
- 研究动机：揭示上下文质量是 OPSD 的核心瓶颈，并提出一种**上下文分离 + 自适应锚定**的框架，以同时提升任务获取能力和通用能力保留，实现更好的可塑性–稳定性权衡。

## 2. 方法：SDS（Supervised Distillation Steering）

### 2.1 核心思想
- 将两类监督信号放在**不同的、各自语义有效的上下文**下评估：
  - **rollout-conditioned 蒸馏分支**：在学生的实际生成前缀 `[x; ŷ]` 上，最小化学生分布与冻结教师分布的逐 token 散度，提供学生实际访问状态上的在线指导。
  - **canonical-context 锚定分支**：在标准真实轨迹前缀 `[x; y*]` 上，对学生计算教师强制的交叉熵损失（teacher forcing），保证目标 token 在其合法的上下文中被监督。
- 两条分支共享同一组可训练参数（LoRA 增量），但前向计算时上下文严格分离。
- 采用**自适应锚定权重**：`w_anchor = 1 − sim(ŷ, y*)`，其中 `sim` 是 rollouts 与目标轨迹的 token 级相似度。初始 rollout 与目标差异大时 w_anchor 高，冷启动阶段强锚定；随着轨迹质量改善，w_anchor 自动降低，蒸馏分支逐步主导。该机制形成负反馈闭环，无需人工设计 SFT→OPSD 切换点。

### 2.2 关键技术细节
- OPSD 损失：平均每个轨迹 token 位置上的广义 Jensen-Shannon 散度（JSD）：
  ```
  L_OPSD = (1/|ŷ|) Σ_t D( p_T(·|x_PI, ŷ_<t) || p_S(·|x, ŷ_<t) )
  ```
  其中教师固定为初始参数 θ₀，学生为 θ₀+Δθ。
- 锚定损失（canonical cross-entropy）：
  ```
  L_anchor = −(1/|y*|) Σ_t log p_S( y*_t | x, y*_<t )
  ```
- 最终目标：
  ```
  L_SDS = L_distillation + α · w_anchor · L_anchor
  ```
  α 控制锚定分支的最大贡献。
- 前向开销：每条训练样本需要额外一次学生前向计算（约增加 30–40% 的单个 OPSD step 成本），但省去了两阶段训练（SFT + OPSD）的额外预算和手动调参。

### 2.3 基于三个研究问题的诊断分析
- **RQ1**：教师信号是否在学生 rollouts 下仍有效？——否，自然 rollouts 下教师目标 token 准确率从规范前缀的约 80% 降至 1–6.5%，信号保留率仅 3.8%–8.1%。
- **RQ2**：上下文退化是否导致信号损失？——通过受控前缀破坏实验和真实 rollout 分箱分析，确认教师准确率随前缀退化程度单调下降；早期出错 rollouts 上教师后验准确率约 20.5%，接近正确的 rollouts 上可达 82.7%。
- **RQ3**：朴素交叉熵注入是否足够？——不足，因为会产生目标–上下文不匹配；实验显示 Naive OPSD+CE 任务准确率仅 55.20%，且 AIME 通用推理能力几乎崩溃（3.33%）。

## 6. 主要结论与发现

- **核心发现**：上下文质量是 OPSD 的训练瓶颈。教师监督信号在规范前缀下很强，但在学生偏离轨迹上急剧退化。
- **设计原则**：每个监督目标应在语义有效的上下文（context-validity principle）下评估；将 rollout-conditioned 分布匹配与 canonical 监督分离可避免目标–上下文不匹配。
- **方法有效性**：SDS 通过自适应锚定权重（基于 rollout–target token 级对齐）实现闭环节流，在冷启动时强化标准监督，在轨迹质量提升后自动放松。相比 OPSD 极大提升任务获取；相比 SFT 显著保留通用推理能力；优于朴素混合和固定权重/两阶段方案。
- **权衡可控**：α 作为可解释旋钮调节可塑性–稳定性平面上的位置；自适应权重优于任何固定权重。

## 7. 优点

- **问题发现深刻**：通过定量诊断（自然 rollout、受控破坏、分箱分析）清晰揭示了 OPSD 的隐性失败模式，并给出信号保留率等可测量指标。
