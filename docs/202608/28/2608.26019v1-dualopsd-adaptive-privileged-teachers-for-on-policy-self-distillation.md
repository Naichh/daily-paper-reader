## 摘要
在线策略自蒸馏（OPSD）使用学生模型的特权副本提供密集监督，而无需外部教师。尽管在训练过程中学生的分布和输出风格会发生变化，OPSD仍保持该特权教师固定不变。我们提出了DualOPSD，一种非对称交替框架，可自适应调整两种策略。学生首先从特权教师那里学习。随后，教师在同一学生轨迹上向更新后的学生分布移动。这种更新使后续监督对学习者具有响应性，且无需另一次展开展开（rollout）。在Qwen3-8B非思考模式下，DualOPSD在AIME 2024、AIME 2025和HMMT 2025上将avg@12相对于OPSD分别提高了23.61、13.89和10.00个点。在1.7B和4B规模上的结果表明，准确率增益取决于模型规模。在所有三种规模下，DualOPSD都减少了截断。4B诊断还显示教师与学生之间的双向KL散度均较低。

## Abstract
On-policy self-distillation (OPSD) uses a privileged copy of the student model to provide dense supervision without an external teacher. OPSD keeps this privileged teacher fixed, even though the student distribution and output style change during training. We propose DualOPSD, an asymmetric alternating framework that adapts both policies. The student first learns from the privileged teacher. The teacher then moves toward the updated student distribution on the same student trajectory. This update makes later supervision responsive to the learner and does not require another rollout. On Qwen3-8B in non-thinking mode, DualOPSD improves avg@12 over OPSD by 23.61, 13.89, and 10.00 points on AIME 2024, AIME 2025, and HMMT 2025. Results at 1.7B and 4B show that the accuracy gain depends on model scale. Across all three scales, DualOPSD reduces truncation. The 4B diagnostic also shows lower KL in both directions between the teacher and student.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：大语言模型（LLM）的后训练对提升推理能力至关重要。常见方法包括：
  - **SFT**：在固定高质量解答上做 token 级监督，但属于 off-policy，训练前缀与模型自身推理前缀不一致。
  - **RLVR**（如 GRPO）：在模型自采样上训练，但反馈稀疏（仅序列级正确性），且每个 prompt 通常需要多次 rollout，成本高。
  - **知识蒸馏**：需要外部教师模型，通常提供稠密 token 级监督。
- **现有方法 OPSD**：On-policy self-distillation 从同一基础模型构造两个条件策略：学生只看问题，教师额外看到“特权上下文”（如参考解答）。学生采样一条轨迹，教师在该轨迹的每个 token 前缀上给出稠密监督。OPSD 无需外部教师、无需 verifier 调用，同时获得 on-policy 状态覆盖和稠密反馈。
- **OPSD 的缺陷**：OPSD 将特权教师视为固定不变的“静止 oracle”。但学生分布和输出风格在训练中不断变化，固定教师无法适应这种变化。此外，OPSD 采用逐点裁剪（pointwise clipping）来抑制风格 token 的大 KL 贡献，但裁剪只是“拒绝”当前不兼容的监督，教师并未收到反馈，后续仍可能持续提供相同的不兼容信号。
- **核心问题**：特权教学策略本身是否也应该在 on-policy self-distillation 中学习？
- **整体含义**：论文提出 **DualOPSD**，一个非对称交替更新框架，同时学习“学生”和“教师”两侧。学生先以保守（裁剪）方式从特权教师学习，教师随后沿同一学生轨迹向更新后的学生分布移动，从而形成闭环，使后续监督对学习者具有响应性，且无需额外 rollout。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想
- 将 OPSD 的单向、固定教师监督改为**非对称交替闭环**：
  - 学生：使用点级裁剪的 forward KL 从当前教师学习（保留 OPSD 的保守更新）。
  - 教师：使用完整的 reverse KL（DKL(pS∥pT)）朝更新后的学生分布移动（不裁剪），从而吸收被学生训练所抑制的风格反馈。
- 学生与教师角色不对称，不优化对称共识目标；教师始终看到特权上下文（参考解答），学生只看到问题。

### 2.2 关键技术细节
- **学生更新**（沿用 OPSD 的裁剪方案）：
  \[
  L_S(\theta,\phi) = \mathbb{E}_{(x,r),\hat{y}\sim p^S_\theta}\left[\frac{1}{|\hat{y}|}\sum_n \sum_{v\in\mathcal{V}} \min\left( \mathrm{sg}[p^T_{\phi,n}(v)] \log \frac{\mathrm{sg}[p^T_{\phi,n}(v)]}{p^S_{\theta,n}(v)}, \tau \right)\right]
  \]
  其中 sg 表示 stop-gradient，τ 是上剪辑阈值（1.7B/4B 为 1e-6，8B 为 1e-7）。
- **教师更新**（在同一个学生轨迹上）：
  \[
  L_T(\phi,\theta^+) = \mathbb{E}_{(x,r),\hat{y}}\left[\frac{1}{|\hat{y}|}\sum_n D_{\mathrm{KL}}\left( \mathrm{sg}[p^{S,+}_{\theta,n}] \| p^T_{\phi,n} \right)\right]
  \]
  其中 θ+ 是更新后的学生参数。教师梯度只通过教师 logits 传递，学生分布被停止梯度作为目标。
- **交替更新顺序**（Algorithm 1）：
  1. 学生采样一条轨迹 $\hat{y} \sim p^S_\theta(\cdot|x)$；
  2. 学生按裁剪 KL 更新为 θ+；
  3. 保持同一轨迹 $\hat{y}$，重新计算更新后学生的 logits（关闭梯度）；
  4. 教师以完整 reverse KL 更新（ϕ ← ϕ − η_T ∇_ϕ L_T）；
  5. 下一轮使用更新后的教师作为学生目标。

### 2.3 其他说明
- 学生和教师作为两个独立的 LoRA adapter 挂在同一个冻结基础模型上，共享基础权重但参数和 AdamW 状态分离。
- 采样在梯度图外；教师不生成答案，只做一次额外的 forward/backward，因此无需额外 rollout。
- 该机制与交互式模仿学习（interactive imitation learning）相关——监督围绕学习者访问的状态进行自适应。

## 6. 论文的主要结论与发现

- **自适应教师显著提升较大模型的准确率**：
  - 8B：DualOPSD 相比 OPSD 在 AIME24/AIME25/HMMT25 上 avg@12 分别提升 **+23.61 / +13.89 / +10.00** 点。
  - 4B：分别提升 **+13.06 / +5.00 / +6.67** 点。
  - 1.7B：反而下降（−3.61 / −1.94 / −1.94 点），说明收益与模型规模强相关。
- **规模效应的统计支撑**：8B 相对 Base 的增益与 1.7B 相对 Base 的增益之差，其 bootstrap 95% 区间均不含零，支持“规模依赖”而非均匀收益。
- **降低截断率在所有规模上一致**：4B 截断率从 9.63% 降至 2.31%；1.7B 从 3.24% 降至 1.20%；8B 从 8.43% 降至 3.33%。但截断率降低并不必然伴随准确率提升（1.7B 上准确率反而下降），因此截断率本身无法解释准确率变化。
- **KL 耦合降低**：4B 上 DualOPSD 的 DKL(pT∥pS) 比 OPSD 低 50.2%，DKL(pS∥pT) 低 45.9%，表明教师确实朝学生移动，二者分布更一致。
- **教师自适应本身有效**：消融中，同一学生更新下，DualOPSD-C 在 100 步的均值超过冻结 OPSD 5.37 点；完整 reverse KL 又比下裁剪版本高 2.87 点（主要来自 HMMT25 的 +5.56 点）。
- **不对称设计必要**：学生用保守的裁剪 forward KL，教师用完整 reverse KL，二者角色不可互换；去掉学生裁剪会导致大幅性能退化。

## 7. 优点：方法或实验设计上的亮点

- **新颖且高价值的核心思想**：指出 OPSD 固定教师的局限性，提出让教师也参与学习，形成闭环自适应——这是对自蒸馏范式的重要扩展。
- **无需额外 rollout 或 verifier**：教师更新复用学生已采样轨迹，只增加一次 forward/backward，训练成本增加可控（4B 约 +0.4h），实用性强。
- **非对称设计合理**：学生接收来自正确参考的保守监督（裁剪掉风格噪声），教师接收完整的学生分布信号（学到学生风格变化），明确区分角色，避免盲目对齐。
- **实验覆盖多尺度**：1.7B/4B/8B 三个规模揭示了规模依赖现象，避免了小模型上的虚假结论；并通过 bootstrap 区间提供统计支持。
- **诊断维度丰富**：除准确率外，报告截断率、长度、双向 KL、训练成本、消融等多个角度，帮助理解机制。
- **实现细节充分**：附录给出精确 prompt、优化顺序、基线预算，可复现性强。

## 8. 不足与局限

- **实验规模与统计功效有限**：
  - 仅 90 道评测题（每项 30 道），题目少，准确率波动可能较大；
  - 单一训练种子（seed 42），没有报告多次种子的均值/方差；
  - 8B 的大幅提升需要跨种子验证。
- **只有一种模型家族**：所有实验在 Qwen3 上进行，结论可能不适用于其他架构或训练范式的模型。
- **KL 诊断样本量小**：仅用 8 个 4B 示例、固定前缀，难以代表完整训练分布；且低 KL 可能是教师目标本身导致，不能直接证明“推理更好”或“更有效使用参考”。
- **1.7B 上性能下降未深入解释**：论文提到收益与规模相关，但对反转原因分析不足（仅在长度、截断率层面给出关联）。
- **基线比较的公平性存疑**：
  - OPSD 与 DualOPSD 步数都为 100，但教师更新带来的计算量不同；
  - PiDistill/BRTS 是作者自实现变体，可能未充分调优，且仅 4B 上测试，对比不够全面；
  - GRPO 用 200 步，而蒸馏方法用 100 步，步数不一致让公平性讨论略显仓促。
- **没有分析风格 token 的实际变化**：论文指出 OPSD 中风格 token 是裁剪主要对象，但 DualOPSD 下教师如何具体改变风格分布、对学生答案格式有何影响，缺乏定量样例展示。
- **应用限制**：需要训练时提供参考解答（特权信息），适用于有标准答案或参考解的任务；开放式生成任务难以直接应用。
