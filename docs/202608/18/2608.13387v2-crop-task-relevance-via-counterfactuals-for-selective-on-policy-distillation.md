## 摘要
在线策略蒸馏（OPD）使用从当前策略采样的轨迹来监督学生语言模型，但对具有不同监督价值的响应标记赋予相同的权重。选择性OPD通过根据估计的训练价值不均匀地分配跨响应标记的监督来解决这一限制。然而，大多数现有标准主要关注优化需求，如不确定性或师生分歧，而任务相关性——即监督是否与当前输入的语义内容相关联——作为补充维度仍未得到直接刻画。为弥补这一空白，我们提出了用于在线策略蒸馏的反事实相关性（CROP），它通过释义校准的反事实敏感性边际来操作化任务相关性。对于每个源提示，CROP构建一个经过验证的原始-释义-反事实三元组，保持学生轨迹固定，并根据每个响应位置对任务相关条件变化的敏感性（由其对保持意义的改写敏感性进行校准）来衡量其重要性。匹配的选择对照表明，CROP识别出比随机或最低相关性选择更有用的监督位置，而组件比较则确认了反事实敏感性和释义校准两者的价值。在两种师生设置中，CROP在最强非CROP选择器上分别提高了1.92和2.96个点的聚合性能。这些结果支持任务相关性作为选择性OPD的补充标准，并确立了CROP作为一种模型内部、对比特定的方法，用于分配标记级别的监督。

## Abstract
On-policy distillation (OPD) supervises a student language model on trajectories sampled from its current policy, but assigns equal credit to response tokens with unequal supervision value. Selective OPD addresses this limitation by allocating supervision non-uniformly across response tokens according to their estimated training value. Most existing criteria, however, focus primarily on optimization need, such as uncertainty or teacher-student disagreement, while task relevance, namely whether the supervision is tied to the semantic content of the current input, remains less directly characterized as a complementary dimension. To address this gap, we introduce Counterfactual Relevance for On-Policy Distillation (CROP), which operationalizes task relevance through a paraphrase-calibrated counterfactual sensitivity margin. For each source prompt, CROP constructs a validated original-paraphrase-counterfactual triplet, holds the student rollout fixed, and measures each response position by its sensitivity to a task-relevant condition change calibrated by its sensitivity to a meaning-preserving rewrite. Matched selection controls show that CROP identifies more useful supervision positions than random or lowest-relevance selection, while component comparisons confirm the value of both counterfactual sensitivity and paraphrase calibration. Across two teacher-student settings, CROP improves aggregate performance by 1.92 and 2.96 points over the strongest non-CROP selector. These results support task relevance as a complementary criterion for selective OPD and establish CROP as a model-internal, contrast-specific method for allocating token-level supervision.

## 1. 论文的核心问题与整体含义

在线策略蒸馏（OPD）通过让教师模型对学生当前策略访问过的前缀进行打分，将稠密的 token 级分布监督与在线策略覆盖相结合。然而，标准 OPD 对响应中所有 token 一视同仁，统一分配监督权重，这会造成监督资源的浪费：模型会将大量监督花在输入无关的通用 token 上，同时低估那些承载任务特定学习信号的 token。

现有选择性 OPD 方法虽然意识到了 token 价值的不均匀性，但它们主要刻画的是**优化需求**（optimization need）这一维度——即 token 是否不确定、是否与教师分歧、是否可教、是否可靠、是否能改善训练目标。论文指出，即使一个 token 不确定、与教师存在分歧或容易被纠正，它仍可能反映的是输入无关的通用生成模式。因此，存在一个未被充分刻画的互补维度：**任务相关性**（task relevance）——即该 token 的学习信号是否真正依赖于当前输入的任务语义。

论文的核心动机是：一个 token "需要被优化"和"值得被优化"是两回事。任务相关性应当作为与优化需求互补的独立维度被引入选择性 OPD 的监督分配中。

## 2. 论文提出的方法论

### 2.1 核心思想

CROP（Counterfactual Relevance for On-Policy Distillation）通过**释义校准的反事实敏感性边际**来操作化任务相关性。其核心逻辑是：对于一个固定不变的学生响应，如果某个 token 位置的分布在"条件改变的反事实提示"下发生显著变化，而在"保持意义不变的释义提示"下保持稳定，那么该位置就承载了任务相关的语义信号。

### 2.2 技术流程

**第一步：反事实三元组构建（离线）**

对每个源提示 x，构造经过验证的三元组 (x, x_para, x_cf)：
- **x_para（释义）**：保持任务相关含义、任务目标和输出约束不变的改写。
- **x_cf（反事实）**：改变一个明确的实质性条件，同时保持任务目标和输出约束。

使用 LLM 生成候选改写，并由独立评判器基于语义保持、单条件干预、确定性和答案类型一致性等标准进行验证。只有严格验证通过的三元组才用于训练（16,594 个，占 95.38%）。

**第二步：匹配的学生重打分**

给定学生从原始提示 x 生成的固定响应 y = (y_1, ..., y_T)，在三个匹配提示下重新打分每个位置的 token 分布：

- P_ot = π̄_θ(· | x, y<t)
- P_pt = π̄_θ(· | x_para, y<t)  
- P_ct = π̄_θ(· | x_cf, y<t)

固定真实响应和所有前缀不变，防止独立采样轨迹的差异被误认为提示敏感性。

**第三步：Top-K 基于残差的 Jensen-Shannon 散度**

由于完整词表过大，使用 Top-K 词汇支持集加残差类别来近似计算 JSD：

- 取两个分布 TopK 支持的并集，为省略的 token 赋零概率，并添加一个残差类别承载所有省略的概率质量
- 在此有限支持上计算 JSD_K(P, Q)

**第四步：释义校准的得分**

对每个响应位置计算：

- 语义敏感性：d_sem_t = JSD_K(P_ot, P_ct)
- 表面敏感性：d_surf_t = JSD_K(P_ot, P_pt)
- CROP 得分：s_CROP_t = d_sem_t − d_surf_t

高边际意味着反事实诱导的分布变化大于释义，即该位置对任务相关条件变化敏感。

**第五步：批量全局预算化选择**

在固定的监督 token 预算下，CROP 在全局范围内选择得分最高的位置，并带有每样本最少保留一个 token 的保护机制。最终生成硬掩码，只改变哪些响应 token 进入采样 token OPD 损失，教师目标和 OPD 目标本身不变。

**第六步（可选变体）：CROP-ent**

将 CROP 得分与学生熵通过 Soft-OR 组合（s = eH + es_CROP − eH·es_CROP），用于检验不确定性信号与任务相关性的互补性。

## 6. 论文的主要结论与发现

1. **CROP 有效提升性能**：在 Qwen3-4B → Qwen3-1.7B 设置下，CROP 平均分达 47.98，比 Pure OPD 高 3.18 分，比最强非 CROP 选择性基线 TIP 高 1.92 分；在 Qwen3-8B (GRPO) → Qwen3-4B 设置下，CROP-ent 平均分 57.48，CROP 为 57.13，均优于所有基线。

2. **任务相关性与优化需求是互补维度**：熵排名分析显示，CROP 有 10.0% 的保留 token 落在最低熵十分位（Entropy、TIP、TA-OPD 几乎为零），说明 CROP 能捕捉到不确定性选择器遗漏的低熵但高任务相关性的位置。

3. **反事实敏感性是主要信号，释义校准有额外增益**：组件消融显示 CROP 超过 CS-OPD 1.98 分，超过 PC-OPD 4.89 分，超过 CROP-Teacher 3.25 分。

4. **CROP 的排序是有意义的**：CROP-10% 比 Random-10% 高 2.00 分，比 Bottom-10% 高 3.34 分，证明得分排序承载了有用信息。

5. **预算密度影响选择器偏好**：CROP 在稀疏到中等预算（10%–20%）下最有效；在高预算下其他选择器可能更优，说明并非简单地增加 token 覆盖就能提升性能。

## 7. 优点

1. **维度创新**：明确提出"任务相关性"作为与"优化需求"互补的监督价值维度，为选择性 OPD 提供了新的理论视角。

2. **方法设计精巧**：
   - 固定学生 rollout 并在三个匹配提示下重新打分，排除了轨迹采样差异的干扰
   - 释义作为校准基线，有效分离了语义变化与表面改写的影响
   - 使用 Top-K 加残差的 JSD 近似，在计算可行性和精度之间取得平衡

3. **对比实验严谨**：
   - 设计了匹配选择控制（随机 vs 最低 vs 最高），验证了排序的有用性
   - 熵排名分布分析直接证明了与不确定性选择器的行为差异
   - 完整的多预算扫描揭示了不同监督密度下的选择器偏好

4. **质量控制完善**：三元组验证流水线具有明确的接受标准、置信度阈值和人工可检查的诊断信息，还有详细的训练-评估污染审计。

## 8. 不足与局限

1. **领域覆盖有限**：实验仅覆盖数学训练提示和 Qwen 模型系列，向代码、开放域问答等其他领域的可迁移性尚未验证。

2. **三元组构建的依赖**：自动构建的释义-反事实三元组质量依赖生成器和评判器模型，验证流水线虽设计了严格标准，但评判器置信度是自报告的、非校准的。

3. **得分是启发式而非因果估计**：论文明确承认 CROP 得分是模型内部、对比特定的排序启发式，不是正确性度量、地面真值任务相关性或不受限的因果效应。低分可能反映稳定性，也可能反映对相关条件变化缺乏反应；高分可能包含对残余提示差异的过度反应。

4. **CROP-ent 的结果不稳定**：熵与任务相关性的互补只在部分师生设置下成立，在另一种设置中 CROP 主方法优于 CROP-ent，说明这种组合的收益是设置依赖的。

5. **反事实干预类型的碎片化**：记录中干预条件类型有 9,116 种不同字符串（如 side length、segment length、circle radius 等被保留为不同标签），表明当前流程缺乏系统化的语义分类。

6. **当前实验仅使用每个提示一个验证干预**：未来可评估多干预、难度控制的反事实以及扩展到更多模型家族和领域。
