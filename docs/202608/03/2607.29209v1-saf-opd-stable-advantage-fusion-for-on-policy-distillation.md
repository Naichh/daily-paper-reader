## 摘要
基于可验证奖励的强化学习（RLVR）将单一的响应级奖励广播给每个令牌，而同策略蒸馏（OPD）则用更强的教师模型对每个令牌进行评分以获得密集优势，但将性能上限限制在教师质量，并抑制超越教师的探索。二者的互补性使得结合RLVR和OPD前景广阔，但我们发现，用固定系数融合两种优势会因两种校准不当而引发熵坍缩：一是量级不匹配，即令牌级OPD优势可能飙升远超有界的RLVR优势，从而抹去后者的信号；二是时间不匹配，即持续全强度的OPD不断将学生拉向教师，限制了超越教师所需的探索。我们提出SAF，一种稳定优势融合框架，通过仅应用于OPD优势的轻量级四阶段流程解决这两个问题：采用“稀疏化后压缩”机制进行量级控制，配合“预热后退火”机制进行时间控制，每个阶段均可独立切换且开销可忽略。我们将RLVR与GRPO结合，在Qwen3-1.7B/4B/8B上评估SAF，涵盖七个数学推理和代码生成基准：SAF避免了熵坍缩，且在所有六个模型-领域设置中持续优于固定系数GRPO+OPD融合，聚合分数提升0.51%至2.70%，同时训练更加稳定。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) broadcasts a single response-level reward to every token, while on-policy distillation (OPD) scores each token against a stronger teacher for a dense advantage but caps performance at teacher quality and discourages exploration beyond it. Their complementarity makes combining RLVR and OPD promising, but we find that fusing the two advantages with a fixed coefficient triggers entropy collapse from two miscalibrations: a magnitude mismatch, where token-level OPD advantages can spike far beyond the bounded RLVR advantage and erase its signal, and a temporal mismatch, where sustained full-strength OPD keeps pulling the student toward the teacher and limits exploration needed to surpass it. We propose SAF, a Stable Advantage Fusion framework that resolves both issues via a lightweight, four-stage pipeline applied only to the OPD advantage: a sparsify-then-compress mechanism for magnitude control paired with a warm-up-then-anneal mechanism for temporal control, with each stage independently switchable and adding negligible overhead. Instantiating RLVR with GRPO, we evaluate SAF across seven mathematical reasoning and code generation benchmarks with Qwen3-1.7B/4B/8B: SAF avoids entropy collapse and consistently outperforms fixed-coefficient GRPO+OPD fusion, improving the aggregate score by 0.51-2.70% across all six model-domain settings while achieving more stable training.

# SAF-OPD: 面向同策略蒸馏的稳定优势融合

## 1. 核心问题与研究动机

大语言模型在复杂推理任务中的训练有两种互补但存在冲突的范式：

- **RLVR（基于可验证奖励的强化学习）**，如GRPO：将基于规则的验证器产生的响应级奖励在采样组内归一化为单一标量，然后广播给该响应中的所有令牌（token）。优点是奖励经过验证、有界、可靠；缺点是粒度粗糙——所有令牌被等同对待，无法区分完成正确推导的长响应中哪个令牌真正关键。
- **OPD（同策略蒸馏）**：将学生生成的轨迹提交给更强的教师模型，计算令牌级的优势 `A_OPD_i,t = log π_T(y_i,t | s_i,t) − log π_θ(y_i,t | s_i,t)`。优点是反馈密集、令牌级、能对模型当前无法解决的问题提供教师相对信号；缺点是性能上限受限于教师质量——学生只会被拉向教师的分布，缺乏超越教师所需的外部探索压力。

二者天然互补：RLVR提供稀疏但验证过的信号，OPD提供密集但教师相对的信号。因此一个自然的想法是以固定系数直接相加融合两者（GRPO + OPD）。**然而论文发现，这种朴素的固定系数融合会导致策略熵在训练早期崩溃**，最终限制性能。这不是简单的超参调节可以解决的，而是源于两个本质性的失配：

1. **量级失配（Magnitude Mismatch）**：GRPO优势是每次 rollout 仅归一化一次的有界实值；而 OPD 优势逐令牌独立重算，无界且呈重尾分布。论文通过实证发现，少数极端令牌的`|A_OPD|`可高达20.36，而GRPO优势幅度通常不超过2.47——在最坏情况下，单个令牌可以主导整条序列的梯度更新，将GRPO信号完全压制。
2. **时间失配（Temporal Mismatch）**：全强度OPD引导的价值随训练进程动态变化。训练早期，学生迫切需要教师指导；但一旦学生吸收了大部分可学的教师知识，继续施加全强度OPD会过度约束策略、挤占GRPO驱动的探索空间，不仅无法帮助超越教师，还会把学生的天花板压低。

## 2. 方法论：SAF 稳定优势融合框架

SAF的核心思想是**不调节单一全局系数，而是用独立机制分别处理两种失配**。完整融合规则为：

```
A_total_i,t = A_GRPO_i + opd_coef(s) · scale(s) · A_OPD_i,t_tanh
```

其中四个阶段全部只作用于 OPD 优势，GRPO 优势保持不动，分别负责量级控制与时间控制。

### 2.1 量级控制：稀疏化-压缩两级流水线

**Stage 1 — Top-k% 稀疏化**：在每个响应序列内部，仅保留`|A_OPD|`超过该序列`(1−k%)`分位数（阈值`τ_k(i)`）的令牌，其余置零：
```
M_i,t = 1[|A_OPD_i,t| ≥ τ_k(i)]
```
该阈值逐序列自适应，可适应各序列自身的量级分布；`k=100`时退化为不过滤。

**Stage 2 — 有界 tanh 压缩**：对残存信号做有界、可调尺度的变换：
```
A_OPD_i,t_tanh = c · tanh(A_OPD_i,t_top-k%)
```
`tanh`将输出限定在`(−c, c)`内，同时在原点附近近似线性，保持小/中信号的相对排序。即使压缩前有极端离群值也无法逃逸上界。

> 两阶段分工明确：Stage 1决定"哪些令牌贡献"（基于相对显著性），Stage 2决定"幸存令牌最多能贡献多少"（绝对幅值上限）。

### 2.2 时间控制：预热-退火两级调度

**Stage 3 — KL触发预热**：OPD系数从零随全局步数线性上升：`scale(s) = min(s / S_warmup, 1.0)`。预热可因KL下降提前终止——一旦学生到教师的采样反向KL相对降幅达到阈值δ（即`(KL_0 − KL_s)/KL_0 ≥ δ`），立刻冻结scale。这样避免了预设固定步数的盲目性，因为它根据学生实际收敛速度自适应调整。

**Stage 4 — 剩余步数线性退火**：设`S`为总训练预算，`s_w`为预热结束步，`R = S − s_w`为剩余预算，则退火调度为：
```
opd_coef(s) = 1,                            s < s_w
opd_coef(s) = c_min + (1 − c_min)(1 − t_a/R),  s ≥ s_w
```
退火从1线性降至小值`c_min`；预热越早结束，退火越平缓。最终GRPO逐步重获主导权，为超越教师留出探索空间。

### 2.3 实现特性

各阶段可独立开关，全部关闭即退化为固定融合；全部开启即为完整SAF。实现仅需：每序列一个分位数计算、KL_0存储、以及两个标量状态`s_w`和`t_a`。**无额外模型、无额外损失项、无额外前向传播**，可作为现有GRPO+OPD循环的即插即用替代品。

- 所有方法（含Base、基线、SAF）保持相同的解码和评分设置

## 5. 实验数量与充分性分析

### 5.1 主要实验

- **主结果矩阵**：3个学生规模 × 2个领域 = 6个模型-领域设置，每个设置下对比5种方法，覆盖7个基准
- **消融实验**：在Qwen3-4B数学推理上做5组消融（固定融合→+量级控制→+预热→+退火→完整SAF，以及δ=0.3对比δ=0.2）
- **训练动态分析**：6个诊断指标（熵、KL散度、critic score、响应长度、AIME-24/25准确率）× 4种训练范式
- **原始信号分析**（附录D）：前5个训练步中，每步3个代表性响应（最差/中性/最好），共计15个响应、180个top-magnitude令牌位置的逐令牌检查
- **参数空间分析**（附录B）：4种训练范式的逐层L2权重漂移与相对权重漂移可视化，以及GRPO vs OPD更新的SVD奇异子空间重叠分析

### 5.2 充分性评价

**做得好的方面**：
- 消融设计严谨，逐步添加组件，能清晰剥离每个机制的贡献（量级控制单独不够，时间控制单独不够，两者结合才有效）
- 训练动态从信号分布、优化轨迹到参数空间多层面交叉验证，诊断逻辑闭环
- 附录中180个原始令牌级别的实证数据有力地支撑了"量级失配"这一设计动机
- 评估设置统一（相同解码、评分），对比公平

**可以改进的方面**：
- 仅使用单一教师模型（Qwen3-30B-A3B-Instruct-2507），未测试不同教师质量/架构对SAF鲁棒性的影响
- 学生模型规模范围仅覆盖1.7B~8B，未涉及更大（如14B~70B）或更小（如0.5B以下）的模型
- 对比的OPD-only是在不同配置（更大批大小、更少步数）下训练的，虽然论文说明是"专用蒸馏配置"，但跨方法比较时的配置不一致可能引入潜在偏差
- 退火中`c_min=0`意味着最终OPD信号完全消失，其最优性未做专门验证

## 6. 主要结论与发现

1. **固定系数融合确实失败**：Qwen3-4B数学推理中，GRPO+OPD（fixed）的熵从约0.35骤降至0.30并长期低位徘徊，KL降至四种方案中最低（最贴近教师），但最终准确率最低（AIME-24约0.57 vs SAF约0.59）且最早出现平台期。KL最低并不等于性能最好——因为教师本身是有缺陷的代理。

2. **SAF在所有6个模型-领域设置中一致优于固定融合**，聚合得分提升0.51%~2.70%；六设置平均49.46%，较固定融合高1.54%，比GRPO-only高2.71%，比OPD-only高1.60%。

3. **数学推理中收益随学生规模减小而增大**（8B: 0.97% → 4B: 1.51% → 1.7B: 1.85%），表明更小的学生更依赖受控后的密集OPD信号；代码生成中收益非单调（最大在4B的2.70%），表明规模与领域有交互作用。

4. **SAF保持中间熵机制**：约0.35~0.38的中间熵水平（GRPO-only最高0.42+，固定融合最低0.30），既保留教师引导的稳定化作用，又为GRPO驱动的持续探索留出空间。SAF的critic score迅速恢复并达到约0.84（接近纯GRPO），而固定融合仅停在0.77。

5. **时间控制是性能核心**：消融显示，量级控制单独加入（不改变时间调度）与固定融合几乎持平（44.35% vs 44.38%），而完整的时间控制（预热+退火）将性能从44.35%推至45.89%。δ从0.2提高至0.3（延长全强度OPD）降低1.38%准确率，验证了"过久的全强度引导适得其反"的判断。

## 7. 方法优点

1. **轻量级与即插即用**：不新增模型、损失项、前向传播或教师查询，仅变换已采样的OPD优势，可无缝替换现有GRPO+OPD系统，工程成本极低。
2. **针对性设计**：量级失配和时间失配各自配备独立机制，各阶段可独立开关，消融清晰，避免了"一个全局系数调不到位"的根本困境。
3. **自适应性强**：top-k阈值逐序列自适应，预热用实际KL下降触发而非固定步数，退火周期由预热终点动态决定——超参在跨模型、跨任务时具有较高泛化鲁棒性。
4. **有理论支撑**：G-OPD证明OPD可视为密集KL约束RL的特例，A_OPD本身是隐式奖励，这为A_GRPO与A_OPD合法相加提供了理论基础。
5. **实证诊断扎实**：论文用18,000+令牌级别的原始信号分析坐实"量级失配"，用熵/KL/长度/准确率多曲线交叉验证时间失配，诊断不是猜的，而是量出来的。

## 8. 不足与局限

1. **教师单一性**：仅用Qwen3-30B-A3B-Instruct-2507一个教师。不同质量/校准水平的教师下SAF的表现未知，论文自身也承认"未声称对未经测试的教师鲁棒"。
2. **规模覆盖有限**：学生仅覆盖1.7B~8B区间，外推到更大规模（如70B）或MoE架构的可信度有限。
3. **OPD-only配置不一致**：OPD-only使用单独的一套训练配置（批大小1024 vs 128，步数不同），虽然这是"专用蒸馏配置"，但严格的公平对比应使用同一套rollout配置。
4. **超参选择空间开放**：`k=20`、`c=0.1`、`δ=0.2`等关键超参仅做了有限搜索（只对比了δ=0.2和δ=0.3，没有做δ更细的网格），最优性未能充分保证。
5. **KL估计基于单次采样**：附录C使用单token采样的k3估计器计算KL，虽然裁剪了极端值，但单采样估计方差较高，对预热早停判定的稳定性有一定影响。
6. **没有与更先进基线比较**：未与MiMo-V2-Flash、KDRL、RLSD、SDAR等现有OPD+RLVR融合方法直接对比，只与朴素固定系数融合做了对照。
7. **附录中参数空间分析是探索性的**：论文自己声明SVD子空间分析等"不构成SAF设计的直接证据"，仅作为补充观察，其严格因果关系有待未来研究。
