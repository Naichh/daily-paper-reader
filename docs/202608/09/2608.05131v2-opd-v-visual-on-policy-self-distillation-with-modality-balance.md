## 摘要
在策略自蒸馏已成为改善多模态大语言模型视觉推理的标准后训练方法。现有方法从多样输入源中提取特权信息以指导自蒸馏，但这些设计忽略了模态不平衡——MLLM推理固有的一种挑战。当文本信息主导生成时，模型无法充分整合其多模态输入，导致精心设计的特权信息未被充分利用，限制了OPSD的有效性。为探究这一局限，我们构建了具有放大图像的正教师和具有掩码图像的负教师，它们展现出不同程度的模态不平衡。其推理正确性和token logits的变化表明，模态平衡本身即可作为特权信息。受此发现启发，我们提出OPD-V，一种通过正教师和负教师实例化该信息的视觉OPSD范式。正模态平衡Logits边际定义了模态平衡信任区域，用于选择用于自蒸馏的在策略token。在6个基准、4个MLLM主干和5种后训练方法上的实验表明，OPD-V在降低训练成本的同时持续提升推理性能。

## Abstract
On-Policy Self-Distillation (OPSD) has become a standard post-training approach for improving visual reasoning in multimodal large language models (MLLMs). Existing methods draw privileged information from diverse input sources to guide self-distillation. Yet these designs overlook Modality Imbalance, a challenge inherent to MLLM reasoning. When textual information dominates generation, the model cannot fully integrate its multimodal input. Consequently, carefully designed privileged information remains underused, limiting the effectiveness of OPSD. To examine this limitation, we construct a Positive Teacher with the Zoom-In Image and a Negative Teacher with the Mask Image, which exhibit different degrees of Modality Imbalance. Changes in their reasoning correctness and token logits reveal that Modality Balance can itself serve as privileged information. Motivated by this finding, we introduce OPD-V, a visual OPSD paradigm that instantiates such information through the Positive Teacher and Negative Teacher. Positive Modality-Balance Logits Margins define a Modality-Balance Trust Region that selects the on-policy tokens used for self-distillation. Experiments across 6 benchmarks, 4 MLLM backbones, and 5 post-training methods show that OPD-V consistently improves reasoning performance while reducing training cost.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：多模态大语言模型（MLLMs）在视觉理解与推理任务上表现出色。On-Policy Self-Distillation（OPSD）已成为改善 MLLM 视觉推理的标准后训练方法。OPSD 从当前学生模型采样轨迹，并用同一模型的副本（教师）在学生访问过的前缀上提供稠密训练目标，教师可获取训练时才有的特权信息。
- **核心问题**：现有视觉 OPSD 方法（如 Vision-OPD、Visual-OPSD、VA-OPD、VCSD）从不同输入来源（文本答案、视觉裁剪、对比视图等）构造特权信息，但普遍忽略了 **Modality Imbalance（模态不平衡）** 这一 MLLM 固有挑战——即模型在生成时过度依赖文本上下文而非图像信息。这导致精心设计的特权信息未被充分利用，限制了 OPSD 的有效性。
- **关键发现（启发点）**：论文构造了**正教师**（输入放大图像 Zoom-In Image）和**负教师**（输入掩码图像 Mask Image），二者表现出不同程度的模态不平衡。实验表明：模态平衡程度本身可以作为一种**特权信息**——教师的模态平衡程度差异（通过注意力比与 logits 间隔体现）与学生正确率存在正相关。
- **整体含义**：论文提出 OPD-V，将模态平衡显式地转化为 token 级蒸馏信号，从而使 OPSD 在模态不平衡条件下依然有效，并实现推理精度提升与训练成本下降的双重目标。

## 2. 提出的方法论

### 2.1 核心思想
- 将模态平衡这一模型**内部状态**转化为**显式的教师输入差异**，并进一步转化为 token 级监督信号。
- 核心手段：**双教师对比机制**——利用正/负教师对学生生成 token 的评分差异（Modality-Balance Logits Margin）来筛选用于蒸馏的在线 token，只对"视觉证据支撑增强"的 token 施以蒸馏。

### 2.2 关键技术细节与公式
- **模态平衡注意力比**：
  $$\rho(c; y) = \frac{\sum_{t \in T_y} \alpha_t^V(c)}{\sum_{t \in T_y} \alpha_t^T(c) + \epsilon}$$
  衡量在模型条件 c 下、响应 y 上视觉注意力相对文本注意力的比重，用以量化模态不平衡。

- **正/负教师构造**：
  - 学生输入：原始图像 I；
  - 正教师输入：裁剪放大任务相关区域的 Zoom-In Image **I_zoom**；
  - 负教师输入：在 **I_zoom** 上随机黑化一块矩形区域得到的 Mask Image **I_mask**。
  - 三者共享相同文本查询和同一学生生成前缀 y<t，教师参数为 EMA 维护的副本 ¯θ。

- **Modality-Balance Logits Margin**：
  $$\delta_t^{MB} = \ell_t^+(y_t) - \ell_t^-(y_t)$$
  即正/负教师对同一学生 token yt 的对数概率之差。正值说明该 token 在放大视觉证据后获得了更大的支持。

- **Modality-Balance Trust Region**：
  $$\mathcal{R}_{MB}(y) = \{ t \in T_y \mid \delta_t^{MB} > 0 \}$$
  即所有 margin 为正的 token 位置构成信任区域，仅在此区域内进行蒸馏。

- **OPD-V 目标函数**：
  $$\mathcal{L}_{OPD\text{-}V}(\theta) = \mathbb{E}\left[ \frac{1}{\sum_{t \in T_y} r_t} \sum_{t \in \mathcal{R}_{MB}(y)} r_t \, \delta_t^{MB} \, D_{JS}\left(q_t^+, p_{\theta,t}\right) \right]$$
  其中 $D_{JS}$ 为 Jensen–Shannon 散度，margin 本身还作为权重调节蒸馏强度。

- **算法流程**（Algorithm 1）：学生按原始图像采样 rollout → 正/负教师对每个 token 计算分布 → 计算 δMB → 筛选正 margin token → 用 JSD 蒸馏正教师分布到学生 → 更新学生 → EMA 更新教师参数。
- **工程优化**：采用 Top-K（K=100）logits + 尾概率桶近似实现接近无损的分布蒸馏，大幅降低显存开销。

## 6. 主要结论与发现

1. **一致性能提升**：OPD-V 在全部 6 个基准上优于所有匹配后训练基线。Qwen3.5-4B 平均精度从 64.30% 提升至 80.01%（+15.71 个百分点），比最强后训练基线 Vision-OPD 高 2.91 个百分点。
2. **跨架构泛化**：Qwen3-VL-4B 从 68.00%→74.14%，Qwen3-VL-8B 从 68.93%→73.03%，Qwen3.5-9B 从 69.75%→77.63%，验证了对不同视觉融合机制均有效。
3. **小模型超越大模型**：4B 参数的 Qwen3.5-4B（OPD-V 训练后）平均 80.01%，超过表中所有闭源模型（GPT-5.2 为 71.81%、Gemini-3.5-Flash 为 79.24%）以及 397B 的 Qwen3.5（77.44%）和 1T 的 Kimi-K2.6（72.81%）。
4. **响应更简洁**：OPD-V 最终 10 步平均响应长度 141 tokens vs OPSD 的 554 tokens（减少 74.5%），训练过程中保持稳定，未出现 OPSD 的后期长度增长。
5. **策略熵稳定**：4B 与 9B 骨干的策略熵在 warm-up 后保持稳定（0.827 与 0.761），无模式坍塌。
6. **信任区域持续有效**：信任区域 token 占比在训练后期保持约 50%（4B：53.6%，9B：49.9%），说明正负教师对比在训练全程保持区分能力。
7. **训练成本降低**：训练步耗时在 4B 与 9B 上分别下降 31.8% 与 24.7%。原因是响应更短 + 教师输入构造更高效（9B 中教师批构造与预处理时间从 79.2s 降至 15.3s）。

## 7. 优点

- **问题切入点新颖**：首次将"模态不平衡"作为特权信息本身，而非仅视为障碍，为 OPSD 提供了一个新的理论视角。

- **高效的工程实现**：Top-K+尾概率的蒸馏近似、EMA 教师、无额外可训练参数；响应长度缩短进一步降低计算量，实现"又快又好"。

- **小模型强性能具有实践价值**：4B 模型超过 1T 参数模型，展示了训练策略的相对优势；信任区域机制的可解释性较好。

## 8. 不足与局限

- **基准覆盖面偏窄**：评估集中于视觉细节感知类任务（V*、ZoomBench、HR-Bench、MME-RealWorld），缺少通用 VQA（如 GQA、TextVQA）、视觉定位、视频理解等任务，对"模态平衡改善"的普遍性与任务依赖性论证不足。
- **训练设置受限**：仅用 6.2K 合成样本、训练 1 epoch；未展示不同数据规模、多轮训练、或混合真实数据下的表现，规模化证据不足。
