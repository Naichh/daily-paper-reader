## 摘要
强化学习通过评估从当前策略中采样的轨迹来改进自动驾驶的视觉-语言-动作（VLA）模型。组相对策略优化（GRPO）从每次 rollout 组内的奖励差异中学习。当所有采样的轨迹都较差时，这种相对信号可以对失败进行排序，而无法识别失败区域之外的行为。我们提出了 FIRE-VLA，一种失败知情的自进化框架，将此类未解决的失败转化为下一策略的特权监督。低奖励、低多样性的组触发从同一模型的冻结轮次起始副本进行的自蒸馏。教师和学生具有相同的参数规模，但只有教师能观察到隐藏的未来轨迹。监督遵循学生生成的 prefix，并仅限于答案 token，而 GRPO 对每个组保持活跃。更新后的策略为下一轮提供教师，使得路由的失败分布随策略变化而无需更大的外部教师。从相同的 Qwen2.5-VL-3B SFT 检查点开始，比较匹配了学生的 rollout 和策略更新次数。在来自 150 个保留 nuScenes 场景的 6,019 个示例上，FIRE-VLA 保持了可比的单样本规划，将 G=4 平均 L2 从 1.848 米降低到 1.500 米，并将评估持久失败率从 13.03% 降至 11.20%。平均误差的减少主要源于罕见的严重 rollout，而非普通轨迹的均匀改进。

## Abstract
Reinforcement learning improves autonomous-driving vision-language-action (VLA) models by evaluating trajectories sampled from the current policy. Group relative policy optimization (GRPO) learns from reward differences within each rollout group. When all sampled trajectories are poor, this relative signal can rank failures without identifying behavior outside the failed region. We introduce FIRE-VLA, a failure-informed self-evolution framework that converts such unresolved failures into privileged supervision for the next policy. Low-reward, low-diversity groups trigger self-distillation from a frozen round-start copy of the same model. Teacher and student have the same parameter scale, but only the teacher observes the hidden future trajectory. Supervision follows the student's generated prefix and is restricted to answer tokens, while GRPO remains active for every group. The updated policy supplies the teacher for the next round, allowing the routed failure distribution to change with the policy without requiring a larger external teacher. Starting from the same Qwen2.5-VL-3B SFT checkpoint, the comparison matches student rollout and policy-update counts. On 6,019 examples from 150 held-out nuScenes scenes, FIRE-VLA retains comparable single-sample planning, reduces G=4 mean L2 from 1.848 to 1.500 m, and lowers evaluation-persistent failure prevalence from 13.03% to 11.20%. The reduction in mean error arises mainly from rare severe rollouts rather than uniform improvement across ordinary trajectories.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型将视觉感知、语言推理与可执行驾驶行为（如轨迹预测）连接起来。此类模型通常先经过监督微调（SFT）获得驾驶先验，再通过强化学习（RL）提升策略。
- **核心问题**：在策略内 RL 后训练中，组相对策略优化（GRPO）依赖组内多条采样轨迹之间的奖励差异进行学习。**当某组所有轨迹都是低质量失败时**（论文称之为 "unresolved failure group" / 未解决失败组），GRPO 的相对奖励仅能对这些失败轨迹进行排序，**无法提供如何逃离失败区域的行为信号**——即"知道都很差，但不知道怎样才算好"。
- **研究缺口**：现有方案要么使用外部大模型生成纠正（如 ELF-VLA 的失败修正），要么依赖更大规模的教师模型，计算开销大且可能引入分布偏移。
- **核心问题表述**：是否能让同一个 VLA 模型利用自身产出的未解决失败来监督其下一代策略，**无需引入更大的外部教师模型**？

## 2. 方法论：FIRE-VLA

### 总体框架

FIRE-VLA 是一个失败知情的自进化框架，其核心思路是：**将未解决失败转化为下一轮策略的特权监督**。每一轮包含一个四阶段流程：失败路由 → 构造双上下文 → 特权同策略蒸馏 → 策略更新。

### 关键技术细节

- **（1）失败知情路由（Failure-Informed Routing）**：对每个 rollout 组计算三项统计量——奖励均值 r̄ᵢ、奖励标准差 σᵢ、有效响应比例 vᵢ。当满足以下条件时判为"未解决失败组"：
  - 均值 ≤ 批内第 30 百分位（低表现）
  - 标准差 ≤ 批内第 30 百分位（低多样性）
  - 有效比例 ≥ 0.5（排除格式错误主导的情况）
  - 被路由的组额外施加特权蒸馏损失（PSD），未路由的组仅用 GRPO；**GRPO 对所有组始终保持激活**。
- **（2）同策略教师–学生对（Privileged Same-Policy Teaching）**：教师和学生每轮从相同权重初始化，参数规模完全相同。唯一差异是**教师上下文额外包含隐藏的 ground-truth 未来轨迹 token**（⟨priv⟩τ*ᵢ⟨/priv⟩），而学生永远看不到该字段。两个分支均基于学生生成的前缀（on-policy prefix）进行条件化，确保监督落在策略实际访问的状态分布上。
- **（3）答案 token 蒸馏**：仅对 <answer> 跨度内的生成 token 施加监督。计算学生与教师分布之间的**截断 Jensen–Shannon 散度（JSD）**，其中：
  - 分布近似为教师 top-16 token + 1 个残差尾部桶；
  - 混合权重 β = 0.5；
  - 每个 token 的散度值被截断在 0.05 以内；
  - 按答案 token 数加权聚合，不额外做逐响应有效性过滤。
- **（4）轮次自进化（Round-Wise Self-Evolution）**：完整损失为 ℒ = ℒ_GRPO + λ·z·ℒ_PSD，其中 λ = 0.1。每轮结束后，更新后的策略成为下一轮的教师与学生对初始权重，**失败分布随策略演化而变化**。实验中实例化为 K = 2 轮，每轮 75 次策略更新。

## 3. 实验设计

### 数据集与场景

- **训练数据**：1,200 个独立 RL prompt，分为两个 600 的互斥子集（对应两轮），每 prompt 采样 4 条响应，总计 4,800 条 rollouts。
- **评估数据**：来自 150 个保留的 nuScenes 场景（与训练场景无重叠），共 **6,019 个样本**（含 5,119 张唯一图像）。
- **基准**：以同一 Qwen2.5-VL-3B SFT 检查点为共同初始化，对比方法为：
  - **Common SFT**（共同参考基线）
  - **Standard GRPO**（150 次连续更新）
  - **FIRE-VLA**（2 轮 × 75 次更新）
- **评估协议**：
  - 单样本低温规划（temperature 0.2）；
  - G=4 随机采样规划（temperature 0.8），每样本取 4 条候选；
  - 评估持久失败检测器在独立 SFT 校准分割上冻结阈值（r̄ ≤ 0.4458, σ ≤ 0.0748, v ≥ 0.5），跨模型共用；
  - 所有 GRPO–FIRE 对比按样本配对，置信区间用 10,000 次自助抽样（按场景聚类）。

## 4. 资源与算力

- **硬件**：4 张 NVIDIA RTX 3090 GPU（24GB）。
- **训练配置**：BF16 全参数训练，FSDP 分布式策略，学习率 5×10⁻⁷，权重衰减 10⁻²，warm-up 0.05，梯度裁剪 1.0，全局 actor batch size 8，响应上限 384 tokens。
- **训练时长**：论文**未明确报告训练时长**（小时数），但报告了 150 次策略更新与 4,800 条 rollouts 的总量。
- **额外开销**：FIRE-VLA 需要额外的冻结教师前向传播，且第二轮会重置优化器和调度器状态，因此**不是等计算量比较**。

## 6. 主要结论与发现

### 核心结果（6,019 个冻结样本）
- **单样本低温规划**：FIRE-VLA 平均 L2 从 0.642 → 0.602 m，但配对置信区间 [−0.1104, 0.0087] 穿越零，故判定为**名义规划能力相当**，非统计显著优势。
- **G=4 随机采样规划**：平均 L2 从 **1.848 → 1.500 m（下降 18.8%）**，配对差 −0.348 m，场景聚类 95% CI [−0.771, −0.032]，统计显著。
- **评估持久失败率**：从 **13.03% (784/6,019) → 11.20% (674/6,019)**，配对差 −1.83 个百分点，95% CI [−2.55, −1.11]。
- **严重尾部失败**：含 >10 m 候选的样本从 1.35% → 0.83%，配对差 −0.52 个百分点，CI [−0.83, −0.22]。
- **奖励–几何不一致**：GRPO 的标量奖励更高（0.637 vs 0.616），但几何尾部更差。原因是奖励使用有界倒数变换，在物理误差极大时饱和，导致标量奖励与极端 L2 之间的 Pearson 相关极弱（约 0.08）。
- **分布分析的关键发现**：FIRE-VLA 的均值改进**并非来自普通轨迹的均匀改善**，而是集中于**抑制罕见严重 rollout**。GRPO 在候选 P90、P95 上反而更好，winsorized 均值显示 FIRE-VLA 在 3–20m 截断范围内全面略差（+0.02~0.05m），仅未截断时大幅改善（−0.35m）。

## 7. 优点

- **问题识别精准**：清晰地定位了 GRPO 在"全组失败"场景下的信息不足问题，不是批判 GRPO 目标本身，而是指出其信息含量局限。
- **无需外部大教师**：教师和学生同参数规模、同轮起点，仅通过隐藏未来信息获得"特权"，避免了引入外部模型的分布偏移与开销。
- **自进化机制优雅**：轮次式教师晋升使失败分布与策略同步演化，路由自适应性强。
- **设计细致**：JSD 截断、token 级 cap、答案 token 加权聚合、有效性阈值等都体现了工程层面的周全考虑。
- **评估透明度高**：在统计严谨性上下了功夫——场景聚类 CI、配对分析、冻结检测器、区间穿越零的诚实解读（如单样本结果不声称优势）、有意展示反例。论文反复强调"不打算把普通轨迹改善当作卖点"。
- **诚实处理负面结果**：如实报告了单样本差值的统计不显著性、FIRE-VLA 在 P90/P95 上更差、恢复率差异不显著等负面发现。

## 8. 不足与局限

- **实验验证范围有限**：仅一个训练种子、两轮自进化、开环评估，无法支撑关于长周期自进化收敛性或闭环安全性的结论。
- **组件不可分离**：无消融实验，无法判断性能提升主要来自路由机制、蒸馏方式还是轮次提升。
- **非等计算比较**：额外的教师前传和优化器重启使比较存在计算不公平性。
- **横向 prompt 不可比**：两轮使用不同 prompt 子集，限制了纵向"同一失败是否被修复"的分析能力。
- **奖励设计局限**：有界倒数奖励在极端误差区域饱和，未明确优化尾部风险，尾部改善是间接收益。
- **相对于 SFT 的退化**：两种 RL 方法的 G=4 随机采样误差均显著高于 SFT（1.50 / 1.85 vs 1.00 m），FIRE-VLA 只是缓解了 GRPO 引入的退化，并未恢复 SFT 级随机鲁棒性。
- **部署限制**：仅前视单目相机、开环轨迹预测，未涉及多传感器融合、闭环执行、安全保证等实际部署关键因素。
