## 摘要
使用强化学习训练多轮LLM智能体通常依赖于轨迹级奖励，这种奖励为每一步分配统一的优势，无法识别哪些决策导致了成功或失败。自蒸馏方法可以通过向强化学习注入特权信息来提供更细粒度的监督。然而，现有方法通常以难以区分的方式将同一种特权信息应用于每一步，忽略了一个关键的不对称性：常规步骤几乎不需要额外指导，而关键错误步骤则需要环境反馈本身无法提供的纠正方向。我们提出AHEAD，一个步骤感知框架，将不同的监督来源匹配到不同的步骤类型。教师模型在所有步骤上接收环境反馈作为有依据的密集信号，并在错误步骤上额外接收LLM生成的纠正提示，以提供环境反馈所缺乏的方向。该方法对标准GRPO算法引入了极小的改动。在ALFWorld、WebShop和基于搜索的QA中，以及三种模型规模下，AHEAD提高了任务成功率（在7B规模上比GRPO在ALFWorld上高13.3个百分点，在WebShop上高11.0个百分点），以更少的训练步骤达到给定的成功率，并在比仅基于结果的强化学习和先前的自蒸馏基线更紧凑的交互预算内解决任务。

## Abstract
Training multi-turn LLM agents with reinforcement learning typically relies on trajectory-level rewards, which assign a uniform advantage to every step and cannot identify which decisions led to success or failure. Self-distillation methods can provide finer-grained supervision by augmenting RL with privileged information. However, existing approaches usually apply the same type of privileged information to every step in an indistinguishable manner, ignoring a key asymmetry: routine steps need little additional guidance, while critical error steps require corrective direction that environment feedback alone cannot provide. We propose AHEAD, a step-aware framework that matches different supervision sources to different step types. The teacher receives environment feedback on all steps as a grounded dense signal, and additionally receives LLM-generated corrective hints on error steps to supply the direction that environment feedback lacks. The method introduces minimal changes to the standard GRPO algorithm. Across ALFWorld, WebShop, and Search-based QA, and across three model scales, AHEAD raises task success (+13.3 points on ALFWorld and +11.0 on WebShop at 7B over GRPO), reaches a given success rate in fewer training steps, and solves tasks within tighter interaction budgets than outcome-only RL and prior self-distillation baselines.

## 1. 核心问题与研究动机

多轮 LLM 智能体的强化学习训练是当前热门方向，但存在一个核心矛盾：

- **轨迹级奖励的粗粒度问题**：以 GRPO 为代表的强化学习算法使用轨迹级奖励，为轨迹中每个 token 分配**相同优势**，无法辨别哪些决策真正导致了成败。但事实上轨迹中各步骤的重要性高度不对称——多数步骤是常规操作（只需环境反馈确认即可），而少数关键错误步骤（如拿错物体、执行无效动作、发出错误搜索词）决定了整个回合的成败。
- **现有自蒸馏方法的不足**：已有的自蒸馏方法（如 SDAR、RLSD、Skill-SD 等）虽能通过特权信息（Privileged Information, PI）提供更细密监督，但它们大多将**同一类型的任务级 PI**（如检索技能、参考答案）不加区分地应用于所有步骤，忽略了上述步骤类型的不对称性——常规步骤并不需要额外指导，而错误步骤需要具体纠正方向。
- **环境反馈的"必要但不充分"**：多轮环境天然提供步骤级信号——环境反馈，对常规步骤足以确认行为正确，但对错误步骤（如"Nothing happens"）只能宣告失败，无法告诉智能体"哪里错了、应该怎么做"。

## 2. 方法论

### 2.1 核心思想

AHEAD（Adaptive Hindsight with Environment-Augmented Distillation）的核心是 **步骤感知的特权信息分配**：

- **常规步骤**：仅注入环境反馈（确认行为结果，弱信号）
- **错误步骤**：环境反馈 + LLM 生成的纠正提示（提供修正方向，强信号）

两者结合产生**天然自适应的监督**——无需显式门控或逐步骤系数，错误步骤自动获得更强的 token 级监督信号。

### 2.2 技术细节与算法流程

AHEAD 在标准 GRPO 上增加三个组件（图 2 展示了完整管线），仅对失败轨迹启用 PI 管线：

**阶段 1：错误步骤识别（仅失败轨迹）**
- 完整的失败轨迹（观察、动作、环境反馈、终局结果）交给 LLM 分析器
- 识别关键错误步骤集合 Eτ，并为每个错误步骤生成纠正提示（必须是指令式命令，如"去 diningtable 1 找目标物体"，禁止描述错误本身）

**阶段 2：步骤感知 PI 构建**
- 对失败轨迹中每个步骤 t，非错误步骤注入环境反馈 Φenv_t；错误步骤同时注入环境反馈和 LLM 纠正提示 Φllm_t，构造教师上下文：

```
˜h_t = H(h_t, Φenv_t, Φllm_t)  若 t ∈ Eτ
       H(h_t, Φenv_t)          若 t ∉ Eτ
```

**阶段 3：选择性轨迹过滤**
- **仅对失败轨迹**应用 PI 重加权（成功轨迹的 GRPO 优势方向已正确，注入 PI 反而引入噪声）
- 成功轨迹保留原始 GRPO 优势

**阶段 4：优势重加权**
- 计算 token 级自蒸馏信号：δt,ℓ = log πθold(yt,ℓ|˜ht, yt,<ℓ) − log πθold(yt,ℓ|ht, yt,<ℓ)
- 转换为有界乘性权重：

```
w_t,ℓ = clip(exp(sgn(Aep)·sg(δ_t,ℓ)), 1−ε, 1+ε)
Ã_t,ℓ = Aep·[(1−λk) + λk·w_t,ℓ]
```

- 关键性质：exp(·)>0 且裁剪保持正性，**重加权永远不会改变优势的符号**，环境奖励始终控制更新方向
- λk 从 0.5 线性衰减到 0（D=50 训练步），后期回到纯 GRPO，防止对特权信息过度依赖
- 最终目标函数为将 Ãt,ℓ 替换 Aep 后的 GRPO 裁剪代理目标

**训练-推理边界**：LLM 分析器、纠正提示、PI 增强评分仅在训练阶段使用，**推理时不需要任何 PI、LLM 调用或环境反馈注入**。

## 6. 主要结论与发现

1. **步骤感知 PI 有效**：对不同步骤类型分配不同监督来源（常规步骤=环境反馈，错误步骤=环境反馈+纠正提示），能自适应产生弱确认信号和强纠正信号，大幅提升最终成功率。
2. **样本效率提升**：AHEAD 比 GRPO 以更少训练步骤达到同等成功率（7B 节省 57% 训练步，1.7B 节省 43%）；更在推理时用更少交互步数解决任务（unseen split 7B 上 15 步即达 GRPO 54 步的成功率）。
3. **增益不依赖单一分析器**：换用四种不同分析器均超越 GRPO；但**小模型的瓶颈在策略容量而非提示质量**——1.7B 上分析器间差异仅 0.8 个百分点。
4. **重加权稳定性强**：OPSD 独立使用或简单拼接到 GRPO 上会崩溃（Qwen3-1.7B 上退化到 32.0% vs GRPO 46.1%），而 AHEAD 因符号保护机制完全避免了此类不稳定。
5. **增益集中于 GRPO 最弱的类别**：Unseen-134 上 7B 的 Look +44.4、Pick2 +35.3 点（均为长动作序列任务），而 GRPO 已解决好的 Clean/Cool 不变。

## 7. 优点

- **对标准算法改动极小**：只增加一个 LLM 分析器调用、一次增强前向计算和一个有界重加权，公式简洁，无额外 KL 项、无逐步系数。
- **设计巧妙**：环境反馈是零成本的现有信号，LLM 纠正提示只需在失败轨迹上调用；两者互补——环境反馈提供"发生了什么"，纠正提示提供"应该发生什么"。
- **符号保护机制**：重加权无论多大都不会反转环境奖励的更新方向，从根本上避免了自蒸馏信号与 RL 奖励冲突导致的训练崩溃。
- **训练-推理边界清晰**：推理阶段零额外开销，所有 PI 相关计算仅存于训练阶段。
- **消融与分析扎实**：对每个核心设计决策（λ 衰减、失败过滤、多错误步识别、双 PI 源）均有对比；AUROC 分析直接验证了"错误步骤获得更大信号"的核心假设；定性轨迹对比生动展示失败模式差异。
- **分析器鲁棒性验证**：回答了"增益是否只来自昂贵分析器"这一自然质疑，且给出分析器选择随骨干规模的实用建议。

## 8. 不足与局限

- **LLM 分析器成本与依赖**：训练阶段需要外部 LLM 调用，GRPO 无此开销；所有四种分析器均为大型专有/前沿模型，小型开源模型能否胜任未测试。
- **错误步骤可识别性依赖**：适用于错误离散、可辨识的环境（拿错物体、位置错误、无效查询）；对于错误细微、累积性、源于遗漏而非错误行为的环境，分析器可能难以定位真正决策点。
- **评估范围有限**：三个基准均具有相对短轨迹、二分成功/失败结果的共性；更长视界、连续动作空间、部分可观测性、软奖励信号环境未覆盖。
- **小模型的增益瓶颈在容量**：1.7B 上换更强分析器近乎无增益，说明更高质量提示在小模型上边际收益递减，方法在小模型上可能受策略容量限制。
- **3B 规模的部分类别退化**：表 5 显示 Seen-140 上 Look 类 -23.1 点（AHEAD 53.8 vs GRPO 76.9），平均增益仅 +1.5 点，说明在强 GRPO 基线上 AHEAD 并非在所有类别都一致占优。
- **消融覆盖缺口**：搜索式 QA 未纳入消融表；未提供 GPU 总时长、训练成本等量化信息，调用了大量外部 LLM 的资源消耗难以从论文直接估算。
