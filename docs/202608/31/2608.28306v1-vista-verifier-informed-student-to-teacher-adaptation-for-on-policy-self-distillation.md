## 摘要
在线策略自蒸馏（OPSD）通过使用来自特权教师（同时参考标准解答）的密集令牌级监督，训练一个仅基于问题的学生模型在其自身的轨迹上，从而提升推理能力。然而，标准OPSD将教师分布视为学生轨迹上的固定目标，并且仅更新学生，尽管——即便特权条件并不能保证教师始终为仅基于问题的推理提供最合适的目标。因此，当教师分布与学生合理的推理不对齐时，这种单向监督可能误导学生。为此，我们引入了验证器知情的学生到教师适配（VISTA），它在保留标准OPSD学生更新的同时，利用基于结果验证的轨迹将教师适配到学生分布。在每个验证过的轨迹内，VISTA进一步将这种适配限制在教师-学生KL散度最大的前$k$个位置。值得注意的是，VISTA复用了标准OPSD中的轨迹和损失函数，不引入额外的采样或单独的奖励目标。在AIME24、AIME25和HMMT25上，使用Qwen3模型（1.7B、4B和8B），VISTA在每个规模上均取得了最高的Avg@12，相较于OPSD分别提升了$0.6$、$0.7$和$2.1$个点。这些结果证明了基于结果验证的轨迹对学生监督的价值，并突显了学生到教师适配作为OPSD一个有前景的方向。

## Abstract
On-policy self-distillation (OPSD) improves reasoning by training a problem-only student on its own rollouts using dense token-level supervision from a privileged teacher that also sees a reference solution. However, standard OPSD treats the teacher distribution as a fixed target along the student's rollout and updates only the student %, although -- even though privileged conditioning does not guarantee that the teacher always provides the most appropriate target for problem-only reasoning. This one-way supervision can therefore misdirect the student when the teacher distribution is misaligned with valid student reasoning. We therefore introduce Verifier-Informed Student-to-Teacher Adaptation (VISTA), which preserves the standard OPSD student update while using outcome-verified rollouts to adapt the teacher toward the student distribution. Within each verified rollout, VISTA further restricts this adaptation to the top-$k$ positions with the largest teacher--student KL divergence. Notably, VISTA reuses the rollout and loss function from standard OPSD, introducing no additional sampling or separate reward objective. Across AIME24, AIME25, and HMMT25 with Qwen3 models at 1.7B, 4B, and 8B, VISTA achieves the highest Avg@12 at every scale, improving over OPSD by $0.6$, $0.7$, and $2.1$ points, respectively. These results demonstrate the value of student supervision from outcome-verified rollouts and highlight student-to-teacher adaptation as a promising direction for OPSD.

## 1. 核心问题与整体含义

- **背景**：On-policy self-distillation（OPSD）是一种针对推理模型的在线自蒸馏范式：学生模型只依赖问题（problem-only）采样 rollout，而特权教师模型额外看到参考解答（reference solution），从而在学生的每个 token 位置提供密集的 token 级监督。标准 OPSD 将教师分布视为固定目标，只更新学生。
- **核心问题**：论文指出标准 OPSD 隐含一个“教师优越性假设”（teacher-superiority assumption）：教师分布必须在学生 rollout 的每个位置都比学生当前分布更接近理想的问题-only 分布。但参考条件并不能保证这一点，具体有两类失败：
  1. **过度支持参考特有 token**：教师可能生成并高概率支持“reference solution”等只有教师才见过的表述，导致学生学到推理时不存在的参考依赖。
  2. **压制有效替代推理**：当学生的有效续写与教师偏好不一致时，教师会给该 token 较低概率，前向 KL 更新会压低学生概率，抑制合理推理与自我纠正。
- **整体含义**：论文提出，与其只单方向“教师→学生”监督，不如在合适条件下允许“学生→教师”反馈，即利用结果验证过的学生轨迹来调整教师分布，从而让教师反过来为学生提供更合适的监督。这一方向在 OPSD 框架中属于首次探索。

## 2. 方法论：VISTA

- **核心思想**：在保留 OPSD 标准学生更新的基础上，增加一个选择性的“学生到教师适配”项；适配只在结果验证通过的 rollout 上进行，且只选择教师–学生 KL 散度最大的 top-k 个 token 位置。
- **关键设计**：
  - **结果门控（outcome gate）**：使用确定性验证器判断 rollout 最终答案是否正确（数学题用规则答案检查，代码用沙箱执行）。只有验证通过的 rollout 才允许教师更新，避免把未定位的错误分布强化进教师。
  - **KL 引导的位置选择（top-k position mask）**：在每条合格 rollout 中，计算每个位置教师–学生分布之间的 KL 散度，选择散度最大的最多 k 个位置进行教师更新。这样既聚焦于最不对齐的位置，又避免教师过快逼近学生而丧失互补的特权知识。
- **训练目标**：
  - 学生损失沿用 OPSD 的逐位置裁剪全词表前向 KL：
    \[
    L_S=\frac1{|y|}\sum_t D^{\mathrm{clip}}_{V,\tau}\left(\mathrm{sg}[P^T_t]\|P^S_t\right)
    \]
  - 新增教师适配损失：
    \[
    L_T=\frac1{|y|}\sum_t \gamma_t(x,y,y^*)\,D^{\mathrm{clip}}_{V,\tau}\left(P^T_t\|\mathrm{sg}[P^S_t]\right)
    \]
  - 总目标：\(L_{\text{total}}=L_S+\lambda L_T\)，其中 \(\gamma_t=\gamma_{\text{out}}(x,y)\cdot\gamma_{\text{pos}}^t(x,y,y^*)\)。
- **重要细节**：
  - 学生损失使用前向 KL（teacher 在第一项，student 在第二项），具有覆盖多种模式的特点。
  - 教师损失将学生分布放在第二项、教师参数放在第一项，等效于反向 KL，具有模式寻找（mode-seeking）特点，鼓励教师集中概率到学生的少数有效续写。
  - 两个损失均使用 stop-gradient，避免交叉梯度干扰。
  - 方法完全复用标准 OPSD 的 rollout 与损失函数形式，不需要额外采样，也不需要单独训练奖励模型。

  - GRPO

  - **结果门控消融**：全 rollout 适配、随机 60% 门控、反门控（只用验证失败 rollout）、VISTA 的验证通过门控。
  - **位置选择消融**：前 k 个位置、均匀随机 k 个位置、后 k 个位置、KL 引导 top-k 位置。
  - **top-k 数量扫描**：k ∈ {8, 16, 32, 64} 以及“全位置”设置。
- **教师侧分析**：

## 6. 主要结论与发现

- 在三个 Qwen3 规模上，VISTA 均取得最高的三基准平均 Avg@12：
  - 1.7B：44.0（比 OPSD 高 0.6）
  - 4B：64.3（比 OPSD 高 0.7）
  - 8B：66.9（比 OPSD 高 2.1）
- 8B 提升最大，说明随着学生能力增强，成功 rollout 为教师提供的适配信号质量更高，学生–教师正反馈循环更明显。
- 消融结果显示：
  - 使用验证通过 rollout 的适配（66.9）显著优于全 rollout（65.8）、随机门控（65.6）和反门控（64.5，甚至低于 OPSD 64.8）；
  - KL 引导 top-k 位置优于前 k、随机 k、后 k 等固定规则；
  - k=16 附近最优，过少（8）则适配不足，过多（64 或全位置）则可能过快抹平教师–学生差距、削弱后续监督。
- 教师侧分析表明：
  - 教师对已验证有效学生轨迹中低概率 token 数量从 24.35 降至 19.32，说明教师对学生有效推理的支持更充分；
  - 教师显式引用参考解答的频率从 63% 降至 48%，说明参考依赖有所缓解；
  - 教师自身在特权条件下的 Pass@12 保持 100%，Avg@12 上升，说明适配不损害教师能力。

## 7. 优点

- **问题诊断清晰**：明确提出“教师优越性假设”的形式化定义，并给出两类失败模式的真实训练案例，有说服力。
- **方法简洁、工程上廉价**：直接复用 OPSD 的 rollout 和 KL 损失，不引入额外采样、独立奖励模型或过程级标注；只需一个规则化结果验证器。
- **双向自适应思想新颖**：首次在 OPSD 框架内实现“教师学习学生”的选择性反馈，且不改变推理时的学生部署方式。
- **实验设计细致**：消融控制合理（如随机门控匹配激活率、位置选择保持相同 k、全位置设置与 OPSD 使用相同 token 范围），教师侧分析提供了多角度间接证据。
- **可扩展性好**：在 8B 规模上增益最大，提示方法随学生容量提升而获益更多。

## 8. 不足与局限

- **机制验证仍是间接的**：理想分布 \(P^I_t\) 不可观测，论文未能直接证明经适配后的教师确实更接近理想目标，只能依赖低概率 token 计数、参考引用频率等代理指标。
- **评测覆盖面窄**：仅覆盖三个竞赛数学 benchmark（AIME24、AIME25、HMMT25），没有在代码、科学问题、通用问答等其他推理场景验证泛化性。
- **基线可复现性存在一定局限**：OPSD、GRPO 等关键基线使用原论文数字，未在同一代码库、同一设备环境下全部重新训练，可能存在实现差异带来的比较误差。
- **调参敏感性**：\(\lambda\) 与 \(k\) 的选择虽然给出了经验区间（λ≥0.75，k∈[16,32]），但缺乏对 λ 的系统扫描，也没有说明对超参数的敏感度边界；不同模型规模使用不同 k（1.7B/4B 用 32，8B 用 16），是否必须按规模调整尚未充分解释。
- **位置选择的代价**：KL 引导 top-k 需要存储/计算每个位置的全词表分布，虽然不增加采样，但会带来额外的显存与计算开销；论文未量化这部分额外成本。
- **潜在偏差风险**：训练集本身来自 OpenThoughts 数学子集，可能与评测基准存在数据分布重叠；论文未报告去重或泄漏检测，存在一定的数据污染风险。
- **应用限制**：方法依赖“有确定性结果验证器”的场景；在开放式生成、主观判断或无法自动验证的任务中，结果门控无法直接使用，适用范围受限。
