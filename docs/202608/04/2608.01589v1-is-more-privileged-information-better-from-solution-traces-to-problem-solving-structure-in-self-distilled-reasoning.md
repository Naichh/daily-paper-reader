## 摘要
同策略自蒸馏（OPSD）通过利用模型在以参考解为条件下的特权视图来监督仅观察问题的学生视图，从而改进推理。然而，教师提供的词元级目标可能依赖于推理时不可用的参考特定信息。我们提出了问题空间引导的OPSD（PS-OPSD），用基于轨迹的引导替代完整解，该引导描述初始状态、目标条件、约束以及选定的状态转移路径。学生展开和OPSD目标保持不变。在三个数学推理基准和从1.7B到8B的模型规模上，PS-OPSD在所比较的方法中取得了最高的聚合仅问题准确率。受控实验进一步表明，引导相关性和路径连贯性对这些增益有贡献，突显了特权信息的表示作为OPSD中一个重要的设计选择。

## Abstract
On-policy self-distillation (OPSD) improves reasoning by using a privileged view of a model conditioned on reference solutions to supervise a student view that observes only the question. However, the teacher-provided token-level targets may depend on reference-specific information unavailable at inference time. We propose Problem-Space-Guided OPSD (PS-OPSD), which replaces the complete solution with trajectory-grounded guidance describing the initial state, goal conditions, constraints, and a selected state-transition path. The student rollout and OPSD objective remain unchanged. Across three mathematical reasoning benchmarks and model scales ranging from 1.7B to 8B, PS-OPSD achieves the highest aggregate question-only accuracy among the compared methods. Controlled experiments further indicate that guidance relevance and path coherence contribute to these gains, highlighting the representation of privileged information as an important design choice in OPSD.

# 论文《Is More Privileged Information Better?》中文总结

> 论文提出：在同策略自蒸馏（OPSD）中，**特权信息的“表示方式”** 比“信息量大小”更关键；用结构化的问题空间引导替代完整解题轨迹，能显著提升推理模型的question-only泛化性能。

## 1. 核心问题与研究动机

- **背景**：同策略自蒸馏（On-Policy Self-Distillation, OPSD）通过“同模型的另一个视角”作为教师，利用已验证的参考解（reference solution）对学生生成的推理前缀进行逐 token 监督。学生只看到问题（question-only），教师则额外看到完整参考解。
- **核心矛盾**：训练时教师能看到完整参考解，但推理时学生只能从问题出发。**完整参考解中包含大量推理时不可获得的信息**（如特定最终答案、特定计算顺序、特定措辞），导致“信息丰富” ≠ “可迁移”。
- **已有证据**：近期研究发现，OPSD 训练后的模型在推理时会显式引用参考解、答案键或不存在的提示（显式特权信息调用，即 PI-invocation），说明教师提供的完整参考解可能引入了对特权信息的依赖。
- **核心研究问题**：**教师应该观察什么样的特权信息？**（What privileged information should the teacher observe?）

## 2. 提出的方法：PS-OPSD

### 2.1 核心思想

基于经典问题空间理论（Newell & Simon 1972；STRIPS），将解题过程表示为一组**结构化语义要素**：

- **初始状态（Initial State）**：变量、实体、已知条件和关系；
- **目标条件（Goal Conditions）**：目标及可验证的达成条件；
- **约束（Constraints）**：定义域限制、全局不变量、有效性条件；
- **选定的状态转移路径（Selected State-Transition Path）**：有序的转移记录列表，每个转移记录包含：
  - 算子（Operator）
  - 前置条件（Preconditions）
  - 诱导变换（Transformation）
  - 结果状态（Resulting State）

该表示被称为 **Problem-Space Guidance（问题空间引导）**，由离线提取器从“问题+已验证参考解”中提取，缓存后供训练使用。

### 2.2 关键设计

- **数学形式**：问题定义为 \(P(q) = \langle S, s_0, O, G, C\rangle\)；实际序列化为 \(g_{PS}(q, r) = \langle s_0, G, C, \pi \rangle\)，其中 \(\pi = (\tau_1, \ldots, \tau_k)\) 是选定的转移路径。
- **与 OPSD 的唯一区别**：将特权教师上下文从完整参考解 \(r\) 替换为引导 \(g_{PS}(q, r)\)。学生 rollout 方式、蒸馏目标、推理流程均**完全不变**。
- **训练目标**：仍为逐 token 坐标裁剪 KL 散度，公式为：
  \[
  \mathcal{L}_{PS\text{-}OPSD} = \mathbb{E}_{(q,r)\sim D, \hat{y}\sim p_\theta(\cdot|q)} \left[ \frac{1}{|\hat{y}|} \sum_t \tilde{D}_{c,T}(p^{PS}_{T,t} \| p_{\theta,t}) \right]
  \]
  其中 \(\tilde{D}_{c,T}\) 是对每个词汇坐标贡献裁剪后再求和的近似 KL。
- **推理阶段**：学生仅从问题生成，参考解、引导、教师、提取器全部缺席。

## 3. 实验设计

### 3.1 数据集与基准

- **训练数据**：OpenThoughts 的数学推理子集。
- **评估基准**：三个竞赛级数学推理基准——**AIME24、AIME25、HMMT25**。
- **评估指标**：每个问题生成 12 条推理轨迹，报告准确率（Accuracy = 每问题正确生成数的百分比平均），并计算三个基准的未加权平均（Avg）。

### 3.2 模型与对比方法

- **模型**：Qwen3-1.7B、Qwen3-4B、Qwen3-8B（教师与学生同源初始化，学生仅更新 LoRA 参数）。
- **对比方法**：

  - SFT（监督微调）

## 6. 主要结论

- **PS-OPSD 在所有 3 个模型规模上取得最高平均准确率**：1.7B（43.12）、4B（64.32）、8B（65.40），超过最强基线 1.54–2.04 个百分点；九个规模-基准组合中六个居首。
- **显式特权信息调用率大幅降低**：训练集上 OPSD 为 3.0% → PS-OPSD 为 0.5%；验证集上 2.2% → 0.4%。
- **引导相关性与路径连贯性均重要**：
  - Mismatched PS 比 PS-OPSD 低 2.56 点（所有基准上均下降）；
  - Path-Corrupted PS 低 2.13 点（所有基准上均下降）；
  - Flattened PS 低 0.71 点（趋势非全局一致，HMMT25 上反而更高 1.39 点）。
- **问题级分析**：PS-OPSD 在 Base-hard 子集上准确率从 1.69% 提升至 4.35%，同时对 Base 已解决问题的能力保持 98.51% 的保留率，净扩容 +2。
- **熵分析**：PS-OPSD 的收益不源于正确路径上的分布更集中；在 4B/8B 上其正确路径 token 熵反而更高，说明覆盖了更多样的解题方式。

## 7. 方法的优点与亮点

- **问题定位精准**：明确指出 OPSD 中的“特权信息表示”是先于损失函数设计的关键问题，切中领域盲点。
- **方法论优雅**：只改教师上下文的表示，学生 rollout、蒸馏目标、推理流程完全不动，改动最小化、可复用性强。
- **理论支撑扎实**：将经典问题空间理论（Newell & Simon, STRIPS）与关系迁移理论中的“结构关系比表面形式更可迁移”结合，具有认知科学依据。
- **表示设计合理**：四大字段 + 四要素转移记录，既保留数学推理的语义关系，又丢弃参考特定表层信息（最终答案、公式推导的具体措辞等）。
- **评估框架严谨**：设定了“oracle envelope”一致性标准，报告了赢/输/平局计数，并补充了多维度诊断；诚实报告某些基准上其他方法更高的情况。

## 8. 不足与局限

- **领域覆盖面有限**：仅竞赛数学，未验证在代码推理、科学问答、规划等任务的适用性。
- **模型覆盖面有限**：仅 Qwen3 单一家族的 3 个规模，且 8B 以下，未验证更大模型或不同架构。
- **提取器依赖**：需要 Qwen3.6-35B-A3B 作为离线提取器，**引入了对更大/更强模型的外部依赖**，增加了预处理成本，且提取器质量与引导质量之间的因果关系未做扰动分析。
- **问题空间的简化**：只捕获单个已验证参考解对应的一条轨迹，而非完整问题空间，可能遗漏替代解题路径。
- **无错误恢复能力**：转移记录是“理想化”的，未考虑学生在中间步骤出错后的恢复路径。
- **因果识别不足**：PI-invocation 率和熵分析均是表面/行为诊断，不构成特权信息泄漏的因果证明；控制实验采用单一配置（一把种子），统计功效有限。
- **评估指标单一**：仅报告准确率，未报告推理效率、token 开销、答案多样性等辅助指标。
- **论文中未披露训练算力细节**，无法评估方法的资源门槛。
