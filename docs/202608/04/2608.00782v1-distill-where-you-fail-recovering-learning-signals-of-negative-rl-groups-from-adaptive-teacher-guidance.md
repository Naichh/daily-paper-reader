## 摘要
基于可验证奖励的强化学习（RLVR）已成为大语言模型（LLMs）后训练的标准范式。尽管群体相对策略优化（GRPO）被广泛采用，但它存在奖励信号稀疏的问题，并且当组内所有响应获得相同奖励时，梯度会完全消失。同策略蒸馏（OPD）通过提供来自教师模型的密集、词元级监督提供了一种自然的补救措施。然而，简单地将GRPO与OPD结合会导致性能下降，原因有三个：并非所有样本都能从蒸馏中受益；过快拟合教师会削弱RL的探索能力；且OPD的优势是不对称的，会抑制大多数词元。为应对这些挑战，我们提出RSTG（通过自适应教师指导恢复学习信号），在最重要之处选择性地、精准地应用蒸馏。在样本层面，OPD仅作用于负零方差提示，每个样本按教师的置信度加权。在词元层面，蒸馏仅针对学生熵高或师生差异大的词元。我们进一步利用教师模型生成的正确轨迹进行SFT训练，在RL无梯度之处注入正梯度信号。实验表明，RSTG在数学和代码任务上分别比朴素的GRPO+OPD显著提升+4.02%和+3.05%。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has become a standard paradigm for post-training large language models (LLMs). While Group Relative Policy Optimization (GRPO) is widely adopted, it suffers from sparse reward signals and loses gradients entirely when all responses within a group receive identical rewards. On-policy distillation (OPD) offers a natural remedy by providing dense, token-level supervision from a teacher model. However, naively combining GRPO with OPD leads to degraded performance, due to three underlying causes: not all samples benefit from distillation; fitting too quickly to the teacher undermines the exploratory capacity of RL; and OPD's advantages are asymmetric, suppressing most tokens. To address these challenges, we propose RSTG (Recovering Learning Signals via Adaptive Teacher Guidance), which applies distillation selectively and precisely where it matters most. At the sample level, OPD is restricted to negative zero-variance prompts with each sample weighted by the teacher's confidence score. At the token level, distillation targets only tokens with high student entropy or large teacher-student divergence. We further augment training with SFT on correct trajectories generated by the teacher model, injecting positive gradient signals where RL yields none. Experiments demonstrate that RSTG substantially outperforms naive GRPO+OPD by +4.02% on math and +3.05% on code.

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基于可验证奖励的强化学习（RLVR）已成为大语言模型（LLM）后训练的标准范式，其中 GRPO（Group Relative Policy Optimization）因简单稳定被广泛采用。
- **问题一：梯度消失**：GRPO 在组内所有响应奖励一致（全对或全错）时，优势函数归零，梯度完全消失。这类提示被称为**正/负零方差提示**（positive/negative zero-variance prompts），模型无法从中获得任何学习信号。
- **问题二：朴素组合失效**：同策略蒸馏（OPD）通过教师模型的 token 级对数概率提供稠密监督，天然可弥补 GRPO 的稀疏奖励缺陷。但简单地把 GRPO 与 OPD 损失相加会导致性能下降，作者识别出三个原因：
  - **样本级均匀性**：并非所有样本都适合蒸馏——教师在不同样本上的熟练度差异巨大，对低熟练度样本的蒸馏会产生误导。
  - **教师界限性**：OPD 收敛过快，学生性能被锁死在教师水平之下，过早收敛严重削弱 RL 的探索能力。
  - **优势不对称性**：学生生成的 token 在教师分布下通常概率很低，导致大部分 token 级优势为负值，对学习信号形成系统性抑制。
- **整体含义**：PPT目标回答如何构建一种**选择性、精准、自适应**的教师蒸馏机制，在 RL 信号缺失之处恢复可用的梯度信号，实现 GRPO 与 OPD 的有效融合。

### 2. 提出的方法论（RSTG）

**核心思想**：不是对所有样本、所有 token 均匀地蒸馏，而是**在失败之处蒸馏**——将 OPD 限定在负零方差提示上，按教师的熟练度加权，并在 token 级筛选高质量监督目标，同时用 SFT 注入正梯度信号。

**三个关键组件**：

#### ① 样本级：数据选择 + 教师置信度加权

- **数据选择依据**：实验发现，仅在"学生全错、教师全对"（Dswtr，2k 样本，仅占全量 57k 数据的 3.63%）上训练 OPD，效果优于在全量数据上训练，也优于只在学生全错（Dsw）上训练。这说明 OPD 的互补价值集中在**负零方差提示**上。
- **教师置信度加权**：设 ω_i ∈ [0,1] 为教师对第 i 个提示的 mean@8 成功率，作为教师对样本的掌握程度代理，用以缩放 OPD 优势。最终混合优势函数为：

```
AHybrid(i,t) = β · ωi · A_OPD(i,t)    （当 rj = 0, ∀j∈G，即负零方差提示）
             = A_GRPO(i,t)            （其他情况）
```

其中 β 为缩放超参数，控制 OPD 信号强度。

#### ② token 级：基于 Soft-OR 的 Token 选择

- **目标**：减缓学生向教师收敛的速度、降低梯度噪声。
- **筛选标准**：两类高价值 token——学生熵高（推理关键节点、模型不确定处）的 token，以及师生分歧大（信息量大）的 token。
- **Soft-OR 组合公式**：对 min-max 归一化后的熵 ĥ_t 与分歧 d̂_t，计算选择分数 s_t = ĥ_t + d̂_t − ĥ_t·d̂_t，保留 top-k% 的 token，其余 token 的 OPD 梯度置零：

```

           = 0           （否则）
```

#### ③ 辅助 SFT：正梯度信号注入

- **动机**：负零方差提示上 OPD 优势持续为负（比正零方差提示更负），形成抑制性优化信号；且 OPD 是局部的（依赖学生已生成的、可能错误的前缀），梯度不可靠。
- **做法**：在负零方差提示上，对教师预生成的正确答案轨迹做 SFT。从 RL 视角看，这相当于给教师轨迹的每个 token 赋常数正优势 A_SFT = 1，注入纯正梯度信号，同时提供全局视角的监督。
- **最终目标函数**：

```
J_Final(θ) = J_GRPO(θ; β·ωi·Â_OPD) + β·J_SFT(θ)   （负零方差提示）
           = J_GRPO(θ; A_GRPO)                     （其他情况）
```

SFT 与 OPD 共享同一个衰减系数 β（β_init = 5×10⁻³，δ = 5×10⁻⁵，β_min = 1×10⁻³，线性退火）。

### 6. 主要结论与发现

- RSTG 在数学上比朴素 GRPO+OPD 平均提升 **+4.02%**，在代码上提升 **+3.05%**，且超越几乎所有基线。
- 朴素 GRPO+OPD 在数学上略微劣于标准 GRPO（−0.2%、−1.57%、+0.36%），在代码上则有明显提升（+4.52%、+7.44%、+9.64%），说明 OPD 的适用性高度依赖领域和样本选择。
- **两个关键实证发现**：① 在"学生全错"的子集上做 OPD 优于全量数据；② 进一步限定在"学生全错且教师全对"的子集上效果最佳，仅用 3.63% 的数据即可反超全量训练。
- RSTG 有效缓解了 OPD 的优势不对称现象（优势值整体上移，更多 token 获得正信号）。
- RSTG 显著减慢了对教师的收敛速度（step 200 时重叠率 65.81%，低于 OPD 的 69.7% 和朴素组合的 67.6%），保留了 RL 探索空间。
- RSTG 解决了 OPD 引起的响应长度突然膨胀问题，长度与标准 GRPO 相当。
- 教师置信度加权 + token 选择这两个 OPD 设计组件**不可或缺**——移除后性能（51.74%）甚至低于 ReLIFT（52.52%），说明缺乏精细设计的 OPD 会反过来损害 RL。

### 7. 优点

- **问题诊断深入**：明确剖析了朴素 GRPO+OPD 失败的三个机理（样本均匀性、教师界限性、优势不对称），并有实证佐证（图 3、图 4）。
- **设计精准高效**：只在最需要的负零方差提示上蒸馏，且用教师置信度动态加权，计算开销极小，是"花小钱办大事"的典范。
- **理论统一性强**：将 GRPO、OPD、SFT 统一在同一个 RL 策略梯度框架下（分别对应不同的优势函数），推导清晰。
- **Token 级细粒度控制**：基于熵与分歧的 Soft-OR 选择机制灵敏且可解释，兼顾了探索保留和信息密度。
- **客观性较好**：对比基线包括 ReLIFT、RL-ZVP 等针对性方法，且朴素组合基线的配置取的是最优变体，避免了对基线的低估。

### 8. 不足与局限

- **模型规模受限**：学生模型最大为 4B（Qwen3-4B），无法确认 RSTG 在更大规模（7B 及以上）上的有效性。作者也坦言受限于算力。
- **领域覆盖有限**：仅覆盖数学和代码两个领域，未涉及 agentic 任务、通用对话、指令跟随等更广泛的 RLVR 应用场景。
- **对能力差距敏感**：实验发现当师生能力差距较小时（配对❷，4B→4B），收益相对不显著；RSTG 的适用边界对教师选择有一定要求。
- **β 系数调参敏感**：β_init 过大会导致过拟合教师、过早收敛，过小则蒸馏信号不足，需要精细调参。
- **SFT 数据依赖教师单次采样**：虽然选最短正确答案，但采样数为 8，对极高难度问题的覆盖可能不足。
- **长尾零方差提示问题**：随着训练推进，负零方差提示比例持续下降，RSTG 分支的触发频率越来越低，后期收益可能边际递减。
- **潜在的评测偏差**：APPS 只均匀抽样 500 条用于评测，可能无法充分代表完整测试分布。
