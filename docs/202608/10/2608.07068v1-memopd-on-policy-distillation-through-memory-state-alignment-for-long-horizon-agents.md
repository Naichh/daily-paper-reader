## 摘要
长时程智能体在交互过程中会积累不断增长的上下文，从而损害性能和稳定性。紧凑记忆通过压缩和重写模型调用之间保留的历史信息来缓解这一问题。学习保留什么通常依赖于带最终任务奖励的近端策略优化（PPO），但稀疏奖励对单个记忆更新的指导作用有限。这一局限促使了在线策略蒸馏（OPD）的发展，它在学生轨迹上提供密集的教师监督。为了使这种监督有效，教师必须在生成动作的同一状态下评估每个采样动作。然而，记忆压缩期间进行的上下文重写可能破坏这种对齐。当采样响应被保留并重新编码以供后续调用时，将交互展平为持久历史可能导致教师在学生轨迹中从未访问过的状态下对动作评分。因此，该动作从来源上仍属于在线策略，但从状态上却不一定如此。为此，我们提出了记忆对齐的在线策略蒸馏（MemOPD）。MemOPD记录每次模型调用的输入和采样输出，恢复其原始标记位置和因果可见性，并将重建的调用打包以进行高效的教师评分。教师在采样动作位置提供全词表监督，而PPO保持最终任务目标。实验验证了多次上下文更新中的状态对齐，并表明在匹配对照中，相较于持久历史教师评分，该方法将F1提高了7.0%。总体而言，MemOPD-3B相较于PPO将F1提高了最多416.2%，而打包在训练期间使演员计算速度提升了最多1.63倍。本工作的代码公开于：https://github.com/TPssp/MemOPD。

## Abstract
Long-horizon agents accumulate growing contexts during interaction, impairing performance and stability. Compact memory mitigates this problem by compressing and rewriting the history retained between model invocations. Learning what to retain typically relies on proximal policy optimization (PPO) with final task rewards, but sparse rewards provide little guidance for individual memory updates. This limitation motivates on-policy distillation (OPD), which supplies dense teacher supervision on student rollouts. For such supervision to be valid, the teacher must evaluate each sampled action under the same state in which it was generated. However, the context rewriting performed during memory compression can break this alignment. When sampled responses are retained and re-encoded for later invocations, flattening the interaction into a persistent history may cause the teacher to score the action under a state that the student never visited during rollout. The action therefore remains on-policy by provenance, but not necessarily by state. We therefore propose Memory-Aligned On-Policy Distillation (MemOPD). MemOPD records the inputs and sampled outputs of each model invocation, restores its original token positions and causal visibility, and packs the reconstructed invocations for efficient teacher scoring. The teacher provides full-vocabulary supervision at the sampled action positions, while PPO preserves the final task objective. Experiments verify state alignment across several context updates and show that it improves F1 by 7.0% over persistent-history teacher scoring in a matched control. Overall, MemOPD-3B improves F1 over PPO by up to 416.2%, while packing yields up to a 1.63x speedup in actor computation during training. The code for this work is publicly available at: https://github.com/TPssp/MemOPD.

# MemOPD 论文总结

## 1. 核心问题与整体含义

- **研究背景**：长时程语言智能体（如信息检索、多轮决策）在交互中会不断累积上下文，导致计算开销增大、模型注意力分散、性能下降。为控制上下文增长，现有方法引入**紧凑记忆（compact memory）**机制，对模型调用之间的历史进行压缩、筛选和重写。
- **已有训练的不足**：常见训练方式是用**PPO + 最终任务稀疏奖励**优化整个交互轨迹。但稀疏延迟的奖励难以对每次记忆更新（保留什么、丢弃什么）提供足够细粒度的监督。
- **在线策略蒸馏（OPD）的潜力与障碍**：OPD 可以通过教师在学生 rollout 上提供密集的逐 token 监督，弥补稀疏奖励的问题。但要求教师评估某个动作时，所看到的**状态（输入上下文）必须与学生采样该动作时的状态完全一致**。
- **核心问题**：紧凑记忆的“上下文重写”会破坏这种一致性——学生采样过的响应片段可能在后续被保留、重排、压缩成新的上下文；如果直接将完整交互历史“展平”成持久历史，教师就会在**学生从未访问过的状态**下评估动作。此时动作仅是“来源上在线”（确实是学生采样的），但“状态上不在线”，蒸馏目标不再对应真实的轨迹条件分布。
- **整体含义**：论文提出，必须进行**记忆状态对齐（Memory State Alignment）**，让训练时的每一个动作都在其原始调用状态下被评分，才能使得 OPD 在长时程紧凑记忆智能体中有效。论文据此提出 MemOPD 框架。

## 2. 方法论

- **核心思想**：将一次模型调用（call）视为独立的状态单元。MemOPD 在 rollout 阶段记录每次调用的精确输入 token 和采样输出 token；训练时重构这些调用，恢复原始 token 位置、因果可见性、预测位置；再通过共享稳定前缀的方式打包成高效批处理表示，使教师和 PPO 都在对齐后的状态下计算。
- **关键概念**：
  - **记忆状态定义**：σ_t = (z_t, ρ_t, V_t, γ_t)，其中 z_t 是 tokenized 输入，ρ_t 是 token 位置，V_t 是因果可见性，γ_t 标识预测目标 token 的位置。
  - **动作域（Sampled Action Domain）**：用掩码 m^act 区分真正被采样的动作 token 与作为后期上下文出现的相同 token（后者不参与策略损失、熵、GAE 等决策）。
  - **教师监督掩码**：m^T 限定在采样动作域内，主实验中 m^T = m^act，即对所有采样响应 token 提供全词表监督。
- **重建与打包**：
  - 将记录的各次调用按 `[q, x_0, a_0, x_1, a_1, ...]` 排成一个物理序列，但注意力只在同一调用内部按原因果可见性计算，不同调用之间互相屏蔽。
  - 稳定前缀 q 只存一份，但位置保持全局一致，且对所有调用可见；每个调用内的 token 位置从该原始调用的索引重新开始，而不是随物理序列递增。
  - 被保留到后续上下文的响应 token 会出现两份：一份是采样动作，一份是上下文，二者有不同的位置和可见性。
- **Rollout Context Equivalence (RCE)**：
  - 要求打包执行得到的每个动作 token 的全词表 logits 与独立执行对应调用时的 logits 在数值容差内一致，即 `||ℓ_pack - ℓ_ind||_∞ ≤ ε_num`。
  - RCE 是离线正确性审计，不是训练损失。
- **优化目标**：
  - **教师蒸馏项**：使用全词表反向 KL 散度，`L_OPD = (1/Σm^T_j) Σ_j m^T_j · RKL(p_{θ,j} || p_{T,j})`。
  - **PPO 项**：在采样动作域上计算 clipped PPO，包含参考策略 KL 惩罚（`KL_ref = [ℓ_old − ℓ_ref]_+`）和奖励整形 `r̃ = r − β·KL_ref`；GAE 只沿有序采样动作推进，跳过上下文位置。
  - **总损失**：`L_actor = L_PPO − αH + λL_OPD`，α、λ 分别为熵正则和教师引导系数。

## 3. 实验设计

- **数据集 / Benchmark**：

  - **单目标 Wiki-RAG**：标准开放域问答，模型反复检索 Wikipedia 段落再作答，测试从多目标检索到单目标设置的泛化。
- **对比方法**：
  - 外部强基线：Qwen2.5-14B-Inst、Qwen2.5-7B-Inst、A-MEM、Truncate、Search-R1、DeepResearcher、MEM1-QA (7B)。
  - 内部训练基线：Mixed-horizon SFT (3B)、PPO (3B)、MemOPD (3B)。
  - 消融控制：PPO（无教师）、Persistent-history OPD（教师使用持久历史评分）、MemOPD（教师使用重建调用状态）。
- **模型配置**：学生为 Qwen2.5 3B，教师为 gpt-oss-120b 生成轨迹、冻结 7B 模型作为蒸馏教师，参考策略为 SFT 初始化。

## 6. 主要结论与发现

- **状态错位是真实且严重的**：在 3B 模型审计中，持久历史重建导致 p99 对数概率误差 1.774、651 个采样动作位置的 top-1 预测改变、13.29% 的动作在策略未变时被 PPO 错误裁剪。
- **状态对齐带来显著增益**：在匹配 Q2 对照中，相对持久历史教师评分，MemOPD 将 F1 再提高 7.0%、EM 提高 10.0%；教师引导本身（未对齐）也比纯 PPO 提高 F1 5.6%。
- **长时程优势扩大**：MemOPD-3B 在 Q8 和 Q16 上将 F1 较 PPO 提升 283.2% 和 416.2%，说明对齐后的稠密教师监督对更长 horizon 尤其重要。
- **单任务迁移有效**：在 Wiki-RAG 上，F1 和 EM 较 PPO 提升约 7.4% 和 6.1%，同时依赖度和推理时间下降。
- **效率与正确性可兼得**：打包共享计算带来最高 1.63× 的 actor 计算加速，同时满足 RCE（数值误差在浮点容差级）。
- **方法具有通用性**：RCE 验证在多种上下文更新机制下均成立，说明 MemOPD 不依赖于特定记忆拓扑。

## 7. 优点

- **问题定义清晰**：首次在紧凑记忆智能体背景下，明确区分“动作来源在线”与“动作状态在线”，提出记忆状态对齐的必要条件。
- **方法设计严谨**：通过记录精确 token ID、恢复位置/可见性、区分采样与上下文副本，完整保留了 rollout 的条件分布；RCE 提供了严格的离线验证标准。
- **实验对照公平**：PPO 与 MemOPD 使用相同的重建调用、采样动作掩码、初始化与数据顺序，能较纯净地隔离教师引导和状态对齐的影响。
- **验证层次丰富**：既做了端到端性能比较，也做了状态重建错误审计、教师状态控制、损坏来源分解、多种上下文更新机制下的 RCE 验证。
- **代码开源**，提高了可复现性。

## 8. 不足与局限

- **模型规模单一**：学生仅测试 Qwen2.5 3B，教师为 7B；未验证在更大或更小学生模型、不同教师规模下的表现。
- **基准范围有限**：主要采用检索问答类任务（HotpotQA/NQ 变体、Wiki-RAG），未涉及更复杂的长时程 agent 环境（如 WebShop、Mind2Web、真实工具调用），记忆状态错位的影响可能在其他场景中表现不同。
- **训练细节不完整**：未报告总训练时长、GPU 峰值显存、PPO 的完整超参数扫描结果，以及对 λ、β 等系数的敏感性分析。
- **教师生成依赖外部模型**：使用 gpt-oss-120b 生成 SFT 数据且只保留正确答案轨迹，可能引入数据分布偏差；论文未讨论这种偏差对状态对齐实验的影响。
- **RCE 验证局限于 token-logit 层面**：论文未分析教师蒸馏在 embedding 空间或长尾 token 上的误差，也未讨论训练过程中学生策略漂移后状态对齐是否依然保持（只验证了 rollout 时冻结策略下的重构）。
- **效率指标偏限于 actor 计算**：打包加速仅计算了前向/反向的 actor 时间，未包含教师评分、critic、数据加载等整体训练开销，实际端到端收益可能低于 1.63×。
