## 摘要
在策略自蒸馏（OPSD）已成为提升多模态大语言模型（MLLMs）视觉推理能力的标准后训练方法。现有方法从多样输入源中提取特权信息以指导自蒸馏，但这些设计忽视了模态不平衡——MLLM推理中固有的挑战。当文本信息主导生成时，模型无法充分整合其多模态输入，导致精心设计的特权信息未被充分利用，限制了OPSD的有效性。为检验这一局限性，我们构建了使用放大图像的正面教师和使用遮罩图像的负面教师，它们表现出不同程度的模态不平衡。其推理正确性和词元对数的变化表明，模态平衡本身即可作为特权信息。受此发现启发，我们提出了OPD-V，一种通过正面教师和负面教师实例化此类信息的视觉OPSD范式。正面模态平衡对数边际定义了模态平衡信任区域，用于选择用于自蒸馏的在策略词元。在6个基准、4个MLLM骨干和5种后训练方法上的实验表明，OPD-V在降低训练成本的同时持续提升推理性能。

## Abstract
On-Policy Self-Distillation (OPSD) has become a standard post-training approach for improving visual reasoning in multimodal large language models (MLLMs). Existing methods draw privileged information from diverse input sources to guide self-distillation. Yet these designs overlook Modality Imbalance, a challenge inherent to MLLM reasoning. When textual information dominates generation, the model cannot fully integrate its multimodal input. Consequently, carefully designed privileged information remains underused, limiting the effectiveness of OPSD. To examine this limitation, we construct a Positive Teacher with the Zoom-In Image and a Negative Teacher with the Mask Image, which exhibit different degrees of Modality Imbalance. Changes in their reasoning correctness and token logits reveal that Modality Balance can itself serve as privileged information. Motivated by this finding, we introduce OPD-V, a visual OPSD paradigm that instantiates such information through the Positive Teacher and Negative Teacher. Positive Modality-Balance Logits Margins define a Modality-Balance Trust Region that selects the on-policy tokens used for self-distillation. Experiments across 6 benchmarks, 4 MLLM backbones, and 5 post-training methods show that OPD-V consistently improves reasoning performance while reducing training cost.

## 1. 核心问题与整体含义

- **研究背景**：多模态大语言模型（MLLMs）的视觉推理能力常通过后训练阶段提升。在策略自蒸馏（On-Policy Self-Distillation, OPSD）已成为一种标准后训练方法：由当前学生模型采样轨迹，再用学生自身的副本（教师）在这些轨迹上提供密集的蒸馏目标。教师可借助“特权信息”（如参考答案、额外视觉输入等）提升监督信号质量。
- **核心问题**：现有 OPSD 方法在构建特权信息时，普遍忽视了一个 MLLM 推理中固有的挑战——**模态不平衡（Modality Imbalance）**，即模型生成时过度依赖文本上下文，而不能充分整合视觉输入。即使特权信息设计得再精细，若模型自身在多模态融合上“偏科”，这些信息也会被低效利用，从而限制 OPSD 的效果。
- **关键洞察**：作者通过构造“正教师”（Zoom-In Image，放大任务相关区域）和“负教师”（Mask Image，遮罩部分视觉区域）发现：不同模态平衡程度会显著影响教师对同一学生响应的评分差异；模态平衡本身可以作为一种特权信息，用来区分哪些 token 更适合用于自蒸馏。
- **整体含义**：本文提出 **OPD-V**，将“模态平衡”显式转化为可计算的教师对比信号，并在该信号定义的“信任区域”内进行自蒸馏。该方法在多个基准和骨干模型上一致提升推理性能，同时降低训练成本，为视觉 OPSD 提供了新范式。

## 2. 方法论

### 2.1 核心思想

- 将模态平衡作为特权信息，通过双教师（正负对比）实例化。
- 学生使用原始图像；正教师使用放大图像（增强视觉证据）；负教师使用遮罩图像（削弱视觉证据）。
- 比较两个教师对同一学生 token 的归一化对数概率，得到“模态平衡对数边际”（Modality-Balance Logits Margin），并据此选择用于蒸馏的 token 子集。

### 2.2 关键定义

- **模态平衡注意力比率**：
  \[
  \rho(c;y) = \frac{\sum_{t \in T_y} \alpha^V_t(c)}{\sum_{t \in T_y} \alpha^T_t(c) + \epsilon}
  \]
  其中 \(\alpha^V_t, \alpha^T_t\) 分别是第 \(t\) 个 token 处视觉和文本注意力质量；该比率衡量对视觉信息的相对依赖程度。

- **正/负教师分布**：
  \[
  q^+_t(\cdot) = p_{\bar{\theta}}(\cdot | I_{zoom}, x, y_{<t}), \quad q^-_t(\cdot) = p_{\bar{\theta}}(\cdot | I_{mask}, x, y_{<t})
  \]

- **模态平衡对数边际**：
  \[
  \delta^{\text{MB}}_t = \log q^+_t(y_t) - \log q^-_t(y_t)
  \]

- **模态平衡信任区域**：
  \[
  R_{\text{MB}}(y) = \{ t \in T_y \mid \delta^{\text{MB}}_t > 0 \}
  \]
  仅保留正教师支持强于负教师的 token 位置。

### 2.3 训练目标

- 在信任区域内，用 Jensen–Shannon 散度从正教师分布蒸馏到学生分布：
  \[
  \mathcal{L}_{\text{OPD-V}}(\theta) = \mathbb{E}\left[ \frac{1}{\sum_{t \in T_y} r_t} \sum_{t \in R_{\text{MB}}(y)} r_t \, \delta^{\text{MB}}_t \, D_{\text{JS}}\left(q^+_t, p_{\theta,t}\right) \right]
  \]
  其中 \(r_t\) 为有效 token 指示符，\(\delta^{\text{MB}}_t\) 作为权重缩放所选 token 的蒸馏损失。

- **Top-K 蒸馏**：采用 \(K=100\) 的 top-K token 集，并加尾部概率桶，避免全词表 logit 的内存开销。

### 2.4 训练流程

1. 学生模型用原始图像采样 on-policy 轨迹 \(y\)。
2. 正教师（Zoom-In）和负教师（Mask）分别对相同前缀打分。
3. 计算每个 token 的模态平衡对数边际，选出正边际的 token 作为信任区域。
4. 在该区域内，用正教师分布对学生做 JS 散度蒸馏。
5. 教师参数通过 EMA 更新（\(\tau=0.05\)）。

## 6. 主要结论与发现

- **性能一致提升**：OPD-V 在 Qwen3.5-4B 上平均准确率从 64.30% 提升到 80.01%（绝对 +15.71 个百分点），超过所有匹配后训练基线（Vision-OPD 为 77.10%）。在 Qwen3-VL-4B/8B 和 Qwen3.5-9B 上同样一致提升。
- **训练效率提高**：Qwen3.5-4B 步时降低 31.8%，9B 降低 24.7%。主要原因是响应更短、教师输入构建更轻量。
- **训练稳定性好**：OPD-V 保持简洁的响应长度（比 OPSD 末尾平均缩短 74.5%），策略熵在预热后保持稳定，信任区域比例稳定在约 50%。
- **机制有效**：正负教师的互补性是核心；Zoom-In 与 Mask 是测试过的最优图像操作组合。

## 7. 优点

- **方法创新**：首次将“模态平衡”这一内部状态转化为显式、可计算的特权信息，避开传统特权信息构造的盲区。
- **双教师对比设计巧妙**：通过正负教师的对数边际来动态选择蒸馏 token，将模态平衡作为 token 级过滤条件，机理清晰。
- **高效实用**：虽然多了一个教师前向，但通过更短响应和更简洁的输入构造，反而降低了整体训练时间。
- **实验严谨性较好**：跨多种骨干、多种后训练方法，且包含消融、效率分析和训练动态观察，支撑力较强。

## 8. 不足与局限

- **依赖证据中心裁剪**：正教师使用“任务相关区域”的裁剪图（Zoom-In），该区域来自训练数据中预标注的 bbox（即 Vision-OPD 数据集里的 `bbox_images` 字段）。这限制了方法在无区域标注数据上的直接应用。
- **训练数据规模小且来源单一**：6.2K 样本可能不足以体现全谱系泛化性；且数据为合成或特定分布，未必反映真实世界复杂场景。
- **评测范围有限**：只覆盖视觉细节感知类基准，未广泛评测常识推理、图表、文档等通用多模态任务；中英文之外的语言未涉及。
- **模态平衡度量依赖注意力权重**：注意力质量作为模态平衡的代理指标可能不一定完全可靠，论文未深入讨论它的失效情况。
- **对比公平性风险**：与闭源、更大规模开源模型对比时，未完全控制推理设置（如解码参数、提示格式），可能引入偏差。
- **增量成本未完全透明**：虽然步时降低，但训练仍需要额外的负教师前向，且未报告整体功耗或碳排放。
