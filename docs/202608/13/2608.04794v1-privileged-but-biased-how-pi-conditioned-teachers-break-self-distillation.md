## 摘要
自蒸馏（SD）已成为一种计算高效的替代方案，用于替代基于可验证奖励的强化学习：一个以答案相关的特权信息（PI）（如参考解答）为条件的自我教师，向一个从未见过该信息的学生提供密集的逐token监督。然而，所报告的收益几乎完全来自狭窄、低难度的设置，这留下了一个基本问题：作为唯一目标，在没有奖励项的情况下，SD是否教会了任何东西？我们在SDPO的简单设置中复现了其报告的收益，然后将相同的设置应用于困难任务，发现它并不奏效。在问答、数学、编程和多轮智能体工具使用中，跨越推理模式、模型大小和PI形式，并且在SDPO和OPSD两种配方下，逐token损失稳步下降，而验证准确率并未提高，且通常会下降。我们通过一条从损失到其所产生模型的单一因果链来解释这一失败。这条链始于PI偏差：在看到了一个特定的参考解答后，教师的逐token目标被拉向该轨迹，而不是一般性的正确性，我们用一个PI偏差分数来量化这一效应。学生的目标被训练为在所有地方匹配这一目标，因此它几乎对一次生成（rollout）是否正确视而不见，并且它所分配的损失主要落在低信息token上，如停用词、标点、不确定性标记，而不是那些决定答案的token；在正确的生成内部，探索性token引发了最高的散度，因此它惩罚了推理所需的犹豫。结果是一个更平坦、更不果断的学生，推理能力并未提高：作为唯一目标，SD优化的是一个与任务成功脱节的信号。

## Abstract
Self-distillation (SD) has emerged as a compute-efficient alternative to reinforcement learning with verifiable rewards: a self-teacher, conditioned on privileged information (PI) about the answer such as a reference solution, supplies dense per-token supervision to a student that never sees it. Reported gains, however, come almost exclusively from narrow, low-difficulty settings, leaving open a basic question: as a lone objective, with no reward term, does SD teach anything? We reproduce SDPO's reported gains in its easy setting, then apply the identical setup to difficult tasks and find that it does not. Across question answering, mathematics, coding, and multi-turn agentic tool use, across reasoning modes, model sizes, and forms of PI, and under both the SDPO and OPSD recipes, the per-token loss falls steadily while validation accuracy does not improve and typically degrades. We explain this failure through a single causal chain from the loss to the model it produces. The chain begins with PI bias: having seen one particular reference solution, the teacher's per-token target is pulled toward that trajectory rather than toward correctness in general, an effect we quantify with a PI Bias Score. Trained to match this target everywhere, the student's objective becomes nearly blind to whether a rollout is correct, and the loss it assigns falls mostly on low-information tokens like stopwords, punctuation, uncertainty markers, rather than those that determine the answer; within correct rollouts the exploratory tokens incur the highest divergence, so it penalizes the hesitation that reasoning requires. The result is a flatter, less decisive student that is no better at reasoning: as a lone objective, SD optimizes a signal decoupled from task success.

# 1. 核心问题与整体含义（研究动机和背景）

- **背景**：强化学习（RLVR）虽然是大模型推理后训练的标准方案，但其监督信号粗略、稀疏且昂贵——每个 rollout 只有一个标量奖励，所有 token 被同等对待，且需要验证器和大量在线采样。自蒸馏（Self-Distillation, SD）被视为一种计算高效的替代方案：以特权信息（PI，如参考解答）为条件的自我教师，可为学生提供密集的逐 token 监督信号，不需要外部教师模型，也不需要奖励项。
- **核心问题**：此前 SD 的成功报告（如 SDPO、OPSD）几乎全部来自狭窄、低难度的任务设置。论文提出一个根本性疑问：**作为唯一训练目标（无任何奖励项），SD 在困难任务上是否真的教会了模型推理，还是只优化了一个与任务正确性仅有表面相关性的代理指标？**
- **整体含义**：论文通过大量实验证明——SD 在困难任务上**并不优化任务正确性**。逐 token 损失稳步下降，但验证准确率不升反降。作者将失败归因于一条因果链：从 PI 偏差出发，导致损失对正确性失明，进而将学习压力集中于低信息 token 和探索性 token，最终产生一个更平坦、更不果断、推理能力没有提升的学生模型。该研究将 SD 重新定义为**一个未明确规约的目标准则族**，而非"完全不工作"的方法——密度机制本身没问题，问题在于目标信号未能编码正确性。

# 2. 方法论

- **核心思想**：SD 目标函数为逐 token 散度最小化，教师由学生自身参数（或其慢速 EMA 副本）构成，额外以特权信息 r 为条件；学生仅以 prompt 为条件，在所有位置上匹配教师的分布。
- **目标函数**：
  - $L_{SD}(\theta) = E_{(x,r)} E_{\hat{y} \sim sg(p_S)} \left[ \frac{1}{|\hat{y}|} \sum_{t=1}^{|\hat{y}|} D\left[ sg(p_T(\cdot | x, r, \hat{y}_{<t})) \parallel p_S(\cdot | x, \hat{y}_{<t}) \right] \right]$
  - 其中 sg 表示 stop-gradient，梯度只流向学生。
- **两个关键性质**：
  - **密集逐 token 目标**（Property 1）：每个位置都有目标，这一设计带来密集信号优势，但也使标点、停用词、风格化话语标记与内容性 token 被置于同等地位。
  - **PI 条件化目标**（Property 2）：当 PI 为完整参考解答 y⋆ 时，目标只反映这一条特定轨迹——包括其答案、措辞和顺序；逐 token 匹配要求学生在所有位置复现该行为，相当于强迫模型采用特定风格而非一般性正确性。
- **PI 偏差分数**（PI Bias Score）：
  - $PS_t(w) = s_T^t(w) - s_S^t(w)$，即教师和学生分配给目标序列 w 的平均对数概率之差。
  - 目标包括：上下文内解答 y⋆、同一问题的另一种正确解答 y′、无关问题的正确解答 ỹ、错误解答 y⁻。若教师编码的是正确性，则 $PS_⋆ \approx PS′$；若只编码单条轨迹，则 $PS_⋆ \gg PS′$。
- **训练稳定性处理**：采用 SDPO 的 Jensen-Shannon 散度（α=0.5），结合激进逐 token 梯度裁剪（τ=0.001）和慢速 EMA 教师（α=0.001），以应对高散度风格化 token 主导梯度和后期不稳定问题。
- **方法论定位**：论文是**诊断性/观察性研究**，不提出新的训练算法，而是通过可测量的因果链（PI 偏差 → 损失对正确性失明 → 低信息 token 吸收损失 → 惩罚探索 → 学生分布扁平化）来解释 SD 失效机制。

# 6. 主要结论与发现

- **核心结论一：SD 作为唯一目标不提供与任务正确性对齐的学习信号**。在全部 4 个困难领域、两种配方下，逐 token 损失持续下降，但验证准确率不升反降。Think 变体在 agentic 领域平均损失 3.51 分（个别 benchmark 达 7.0 分），QA 领域两种模式各损失约 1.6 分。
- **核心结论二：PI 偏差是因果链的起点**。PI 偏差分数表明，教师对上下文内解答的偏向（≈0.52）远高于对同一问题其他正确解答（≈0.02），后者与无关问题的解答几乎不可区分——教师编码的是"一条轨迹"而非"正确性"。
- **核心结论三：损失对正确性失明**。正确与错误 rollout 的逐 token 损失和 KL 在训练全程几乎完全重叠；当它们分离时方向是反的——教师–学生差距在正确 rollout 上（约 0.7）高于错误 rollout（约 0.45），即学习压力集中在学生已经正确的轨迹上。
- **核心结论四：损失集中在低信息 token**。停用词、不确定性标记（"wait"、"maybe"等）、标点、空白共吸收 55.4% 的逐 token 损失；内容词、数字、数学符号等决定答案的 token 只吸收少部分。按类别平均，不确定性标记的平均逐 token 损失最高。
- **核心结论五：SD 惩罚探索**。即使在正确 rollout 内，偏离参考路径的位置（off-path）KL 高达约 0.31，而在路径上约为 0.08（约 4 倍差距）——教师无法区分富有成效的岔路与错误，从而惩罚了推理所需的搜索行为，导致响应变短。
- **核心结论六：学生"扁平化"而非"锐化"**。教师–学生平均差距从约 3.1 收敛到约 0，但 ±1 标准差带未收缩、学生熵上升——这是抵消性收敛（cancellation）而非真正的分布匹配；结果是更早下结论、更不果断、推理不提升。
- **核心结论七：PI 特异性不存在良性中间档**。完整解决方案（过具体）和提示/技能（过笼统）都会失败，只是失败原因相反：前者把目标绑死在单条轨迹，后者信号太弱无法推动学生。
- **对先前工作的统一解释**：RLSD 的理论界（条件互信息泄漏）和 Kim et al. 观察到的推理退化现象，是同一个机制的两端——在困难任务上这条因果链完整显形。

# 7. 优点

- **诊断式方法论突出**：不是简单报告"失败"，而是构建了一条完整的、每一步都有量化证据的因果链（PI 偏差 → 损失失明 → 低信息 token → 惩罚探索 → 扁平化学生），从可干预的源头（PI 的特异性）到最终的模型行为（熵、响应长度）逐一验证。
- **PI 偏差分数简洁实用**：只需前向传播，不需要训练，即可在训练前筛选 PI 是否会导致轨迹复制而非技能迁移；大 PS⋆−PS′ 差距提示教师将迁移轨迹而非能力。
- **严格的正对照设计**：在 SciKnowEval 上用 SDPO 原始代码库和超参数成功复现了原文报告的正向结果，排除了"实现错误"这一最常见的质疑。
- **鲁棒性检验系统性好**：同时操纵响应长度、任务难度、模型规模、推理模式、PI 内容、训练配方等多个维度，每个维度都出现相同的失效签名，结论具有高度一致性。
- **与理论工作形成闭环**：将 RLSD 的条件互信息理论界转化为可直接测量的量（PI 偏差分数），并复现、扩展了 Kim et al. 的观察，把先前看似零散的现象统一为一条因果链。
- **实践指导性强**：给出了可操作的监测建议——SD 损失下降不等于学习发生，必须监控验证准确率；PI 偏差分数可低成本预筛查 PI。

# 8. 不足与局限

- **观察性研究定位**：论文明确声明自己"描述目标而非提出补救方案"，未验证将 SD 与奖励项结合（如 RLSD 的修复方式）是否能消除所记录的失效，这构成了验证闭环上的空白。
- **模型架构覆盖有限**：只评估了 Qwen3 家族（8B 和 32B），未扩展至 DeepSeek、Llama 等其他架构，跨架构的可推广性未验证。
- **评估不确定性**：验证指标仅基于 4 条采样轨迹的平均值，部分 per-domain 差异（如若干个 0.1–1.0 点的差距）相对于 run-to-run 波动较小，统计显著性有限。
- **PI 偏差分数的依赖敏感性**：该指标依赖 y′（不同正确解答）、ỹ（无关解答）、y⁻（错误解答）的具体选取，且只采样部分位置的平均对数概率比，并非条件互信息的无偏估计，只是补充性度量。
- **弱 PI 实验可能受生成质量影响**：hints 和 skills 由模型生成，其失败结果可能部分反映生成质量问题（如提示不够精准）而非 PI 信息量本身不足。
- **算力资源披露不足**：虽然说明了使用的 GPU 型号和节点数，但未报告训练时长和总 GPU 时数，不利于成本估算和复现规划。
- **未覆盖组合场景**：只测试了 SD 作为"唯一目标"，未系统测试 SD 作为辅助正则项（如小权重配合奖励项）在困难任务上的表现；该问题在讨论中被列为开放问题，但从实践角度看仍是重要缺口。
