## 摘要
在线蒸馏（OPD）在教师提供的密集词元级监督下，基于学生自身轨迹进行训练。诸如ExOPD等奖励外推方法放大教师参考对数似然比，以超越直接模仿，但对每个词元应用单一全局系数λ。这可能驱使学生拟合隐式奖励中的极端峰值，导致奖励攻击和不稳定训练，且最优λ因领域而异，需要代价高昂的扫描。我们提出REOPD，一种面向OPD的可靠性自适应奖励外推框架。REOPD结合词元级兼容性权重与批次级自适应预算，生成词元级系数λ_{b,t}=1+γ_b q_t，在保持与教师对齐的同时，沿可靠教师参考方向选择性外推。它不需要验证器、奖励模型、价值模型，也不需在标准OPD之外额外展开。REOPD在单教师数学任务和双教师设置的两个领域上均优于G-OPD，同时在单教师代码任务上与G-OPD持平，展示了跨领域和教师配置的有效细粒度可靠性自适应。

## Abstract
On-policy distillation (OPD) trains a student on its own trajectories under dense token-level supervision from a teacher. Reward-extrapolation methods such as ExOPD amplify the teacher-reference log-likelihood ratio to move beyond direct imitation, but apply a single global coefficient $λ$ to every token. This can drive the student to fit extreme peaks in the implicit reward, causing reward hacking and unstable training, and the optimal $λ$ varies across domains, requiring costly sweeps. We propose REOPD, a reliability-adaptive reward extrapolation framework for OPD. REOPD combines a token-level compatibility weight with a batch-level adaptive budget, yielding a token-wise coefficient $λ_{b,t}=1+γ_b q_t$ that preserves teacher alignment while selectively extrapolating along reliable teacher-reference directions. It requires no verifier, reward model, value model, or extra rollout beyond standard OPD. REOPD outperforms G-OPD on single-teacher mathematics and on both domains in the multi-teacher setting, while matching G-OPD on single-teacher code, demonstrating effective fine-grained reliability adaptation across domains and teacher configurations.

## 论文核心问题与整体含义

**研究动机：**

- 在线蒸馏（On-Policy Distillation, OPD）是一种有效的 LLM 后训练范式：学生在自己生成的轨迹上训练，教师对相同前缀提供密集的词元级监督信号。
- 奖励外推方法（如 ExOPD）通过放大教师–参考模型的 log-likelihood 比（即隐式奖励）来超越直接模仿，但存在两个关键问题：
  1. **全局单一系数 λ 的缺陷**：ExOPD 对所有 token 应用同一个外推强度，会不加区分地放大极端奖励峰值，导致学生过度拟合少数极端残差，引发奖励黑客（reward hacking）和训练不稳定。
  2. **跨域调参成本高**：最优 λ 随任务领域与教师配置而变化，每个新设置都需要多次完整的训练和评估来找合适的系数，成本高昂。

**核心问题**：如何在不引入额外模型、不增加 rollout 的前提下，对不同 token 采用差异化的奖励外推强度，在保留教师对齐的同时避免盲目放大不可靠的残差信号。

## 方法论：REOPD

**核心思想：**

- 将"教师对齐"与"超越教师的外推"分开控制。保留标准 OPD 的对齐项 a_t，仅对教师–参考残差 r_t 施加自适应的、受控的缩放。
- 通过 **token 级兼容性权重** 与 **batch 级自适应预算** 的乘积，形成逐 token 的有效外推系数：**λ_{b,t} = 1 + γ_b · q_{b,i,t}**

**关键技术细节：**

1. **对齐项与残差项的定义**
   - 学生–教师对齐代价：a_t = log π_θ(y_t|s_t) − log π_T(y_t|s_t)
   - 教师–参考残差（隐式奖励）：r_t = log π_T(y_t|s_t) − log π_ref(y_t|s_t)
   - ExOPD 代价：C_t = a_t − (λ − 1) · r_t
   - REOPD 代价：C_{b,i,t} = a_{b,i,t} − γ_b · q_{b,i,t} · r_{b,i,t}

2. **Token 级兼容性权重 q_t**
   - 使用低方差代理 δ̂ = exp(x_t) − x_t − 1 来衡量学生–教师差异（x_t = log π_T − log π_θ）
   - 权重定义为 q_t = exp(−δ̂/τ)，τ 为温度超参数
   - 数学上 q_t ∈ (0, 1]：学生–教师差异小时 q_t ≈ 1，保留大部分外推残差；差异大时 q_t 变小，抑制外推
   - 该指标衡量的是"局部兼容性"而非"正确性"——因此只用于门控奖励残差，不影响对齐信号

3. **Micro-batch 级自适应预算 γ_b**
   - 统计量 1：兼容性加权残差比例 ρ_b = Σ|r|q / Σ|r|，衡量残差中"可靠"的比例
   - 统计量 2：可靠残差 RMS 尺度 s_b = sqrt(Σ(q·r)² / N)
   - 对两者做 EMA 平滑，得到目标预算：eγ = clip(B₀·ρ̄ / s̄, 0, γ_max)
   - 直观理解：兼容残差比例越高（ρ 大），允许越强外推；残差绝对尺度越大（s 大），则降低系数避免某批次主导更新
   - 上限 γ_max 提供显式安全约束

4. **算法流程（Algorithm 1）**
   - 对每个同步 micro-batch：采样 on-policy 响应 → 计算学生/教师/参考的 log 概率 → 计算 a、r、δ̂、q（detached）→ all-reduce 足够的统计量 → 计算 ρ、s、对齐 RMS → 更新 EMA → 计算 eγ 和 γ → 构造优势函数 A = −C → 使用标准 PPO 策略目标更新学生

5. **关键性质**
   - 有效系数满足 1 ≤ λ_{b,t} ≤ 1 + γ_max，保持 OPD 对齐项不变
   - 无需额外 verifier、reward model、value model 或额外 rollout
   - 所有控制信号均为 stop-gradient
   - 特例关系：γ=0 恢复 OPD；q=1 且 γ=λ−1 恢复固定 ExOPD

## 主要结论与发现

1. **REOPD 在多数场景下优于 G-OPD**：单教师数学（47.66% vs 46.28%）、多教师数学（47.01% vs 46.43%）、多教师代码（63.32% vs 61.99%）均取得提升；单教师代码与 G-OPD 持平（63.45% vs 62.55%）。
2. **REOPD 超过固定系数的领域最优结果**：与每个设置的最优固定 ExOPD 相比，REOPD 在 4 个设置中有 3 个更高（+0.19、+0.03、+0.42 个百分点），仅在单教师代码上稍低（−0.15 个百分点）。这表明在线自适应可以替代昂贵的逐设置调参。
3. **最优固定系数因领域而异**：数学领域最优为 λ=1.25（47.47%），代码领域最优为 λ=1.5（63.60%），多教师设置又不同——这验证了全局系数调参的必要性和成本。
4. **Token 级兼容权重是最关键组件**：移除 q_t（no_q）导致数学准确率从 47.66% 降至 43.39%（−4.27 个百分点），且在所有 4 个 benchmark 上均下降。
5. **显式预算上界提供适度安全保护**：移除 γ_max（no_bound）使准确率降低 0.50 个百分点但效果混合（HMMT Nov 提升 0.41，其他降低）。
6. **自适应 micro-batch 预算可匹配最优手调变体**：no_batch 在 λ₀=1.25 时达到 47.66%，与完整 REOPD 持平——自适应预算的价值在于免调参而非绝对性能提升。
7. **控制器动态合理**：训练前期 γ 迅速上升（0.608→接近上限），后期主要由 token 级权重 q 提供变化（0.774→0.850）。

## 优点

1. **方法设计巧妙**：将"对齐"与"外推"解耦，仅对额外残差做自适应控制，既有理论依据（G-OPD 的 dense KL-regularized RL 框架），又有清晰直觉。数学上 q_t 的构造（δ̂ = eˣ−x−1）利用了 eˣ≥x+1 的不等式，确保权重自动落在 (0,1] 区间。
2. **零额外开销**：不引入任何额外模型或 rollout，仅复用 OPD 已经计算的 log 概率，通过 all-reduce 同步统计量，实用性很强。
3. **跨域自适应**：单个共享控制器可以在多教师混合领域同时改善数学和代码，避免了为每个领域分别选择 λ。
4. **实验设计有层次**：从主实验到系数敏感性（展示问题确实存在）到消融（拆解各组件贡献）到控制器动态（验证机制运行时行为），层层递进，逻辑完整。
5. **公平性考量**：默认使用相同的 λ=1.25 作为对比基线而非逐设置选择最优，避免了对 baseline 的"不公平碾压"；同时报告了与最优固定系数的对比，展示了消融调参需求的实际效果。

## 不足与局限

1. **兼容性代理的本质缺陷**：q_t 衡量的是学生–教师差异而非正确性。当学生和教师一致但都错误时，q_t 会给出高权重，REOPD 无法识别这种情况——这是论文明确承认的理论局限。
2. **仍有超参数需要调节**：τ、γ_max、B₀ 的校准（κ、K₀）、EMA 系数 β/βγ、预热设置等依然存在。虽然这些参数在实验中跨设置共享，但论文没有做敏感性分析来验证其鲁棒性。
3. **训练后期 γ 饱和**：控制器轨迹显示 γ_b 在训练后期接近 γ_max 上界，此时自适应主要由 q_t 提供。这意味着 batch 级预算的调整空间有限，其长期贡献可能被高估。
4. **实验覆盖不足**：仅一个模型族（Qwen3-4B）、一个规模（4B）、一个检查点（step 50）、一种教师配置方式；消融只做了数学单教师。多教师设置只有一个共享控制器对比，缺少共享 vs per-teacher 控制器的直接对照。
5. **评价指标局限**：数学使用 pooled accuracy、代码使用 pass@1，均未涉及推理效率、推理长度、输出多样性等维度；没有人工评估或对失败模式的定性分析。
6. **统计严谨性**：虽然论文提到"repeated experiments"，但报告的是 pooled accuracy 而非多次独立运行的均值和方差，无法判断各方法差异是否统计显著。
7. **与更近期方法的对比缺失**：相关工作提到 TIP、Prune-OPD、SG-OPD、SCOPE 等多种自适应/可靠性感知蒸馏方法，但实验中没有与任何这些方法进行直接对比，削弱了对方法相对优势的论证力度。
