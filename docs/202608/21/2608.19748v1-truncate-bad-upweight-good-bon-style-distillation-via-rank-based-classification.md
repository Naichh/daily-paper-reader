## 摘要
推理时选择方法（如Best-of-N）通过采样一组候选并根据奖励模型选择排名最高的完成来改进生成。蒸馏试图通过用池内排名替换原始奖励，并学习一个对排名更高的完成赋予更高权重的策略，将此过程摊销到单个策略中。然而，现有的基于排名的策略通常使用平滑的全支持重加权，因此低排名的完成获得较少的质量，但仍保留在目标支持中。尽管更尖锐的重加权减少了低尾质量，但也增加了对单一奖励模型所做顶部脆弱排名的依赖。我们提出TUP：一种截断劣项、提升优项的策略，它从支持中移除低排名的完成，并仅对保留的上尾部分进行可调尖锐度的重新加权。TUP允许闭式、与提示无关的归一化，并且可以通过二元交叉熵完全离线训练，使用移位截断的胜率作为软标签，以及蒸馏到参考的对数似然比作为logits。理论上，在某些假设下，我们表明对于任何未知的预言奖励，最佳单调排名重新加权可以通过低尾截断规则匹配，为移除低尾而非仅仅降低其权重提供正式支持。实证上，我们表明TUP与强大的离线对齐基线具有竞争力。

## Abstract
Inference-time selection methods, such as Best-of-N, improve generation by sampling a pool of candidates and selecting the top-ranked completion according to a reward model. Distillation seeks to amortize this procedure into a single policy by replacing raw rewards with in-pool ranks and learning a policy that upweights higher-ranked completions. However, existing rank-based policies typically use smooth full-support reweighting, so low-ranked completions receive less mass but remain in the target support. Although a sharper reweighting reduces lower-tail mass, it also increases reliance on brittle ranking at the top made by a single reward model. We propose TUP: a Truncate-bad, Upweight-good Policy that removes low-ranked completions from the support and reweights only the retained upper tail with a tunable sharpness. TUP admits a closed-form, prompt-independent normalization and can be trained fully offline via binary cross-entropy, using shifted-truncated win-rates as soft labels and distilled-to-reference log-likelihood ratios as logits. Theoretically, under certain assumptions, we show that for any unknown oracle reward, the best monotone rank-reweighting can be matched by a lower-tail truncation rule, providing formal support for removing the lower tail rather than merely downweighting it. Empirically, we show that TUP is competitive with strong offline alignment baselines.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：
  - **推理时选择方法（Inference-time selection）**：Best-of-N（BoN）通过从基础策略中采样多个候选完成，并用奖励模型选出得分最高的一个来提升生成质量。其代价是推理时计算开销大（每个提示需多次生成与奖励评估）。
  - **蒸馏（Distillation）**：为了将 BoN 的推理时选择过程“摊销”到单个策略中，研究者提出 BoN 风格蒸馏——训练单一策略，使其内化推理时选择器的行为，部署时无需多次采样。
  - **现有方法的问题**：
    - 现有秩基方法使用**平滑全支持重加权**（如 QRPO 的 \(g(w) \propto e^{w/\beta}\)），低排名完成虽然权重低，但仍在目标支持集合中，未被真正移除。
    - 过度尖锐化重加权虽然降低低尾质量，但会过度信任奖励模型对顶部完成的“精细排名”，而奖励模型是真实oracle（人类偏好）的不完美代理，顶部排名的分歧更大。
    - 已有的跨奖励模型共识研究表明：**低排名区域（下尾）的排序在奖励模型间更稳定，而顶部精细排名分歧较大**。

- **本文核心问题**：如何设计一种 BoN 风格蒸馏策略，在保留 BoN“偏好高排名完成”原则的同时，同时（i）避免给明显不良的完成分配概率质量（截断），（ii）避免因奖励模型顶部排名不可靠而过度尖锐化（可调锐度的重加权）？

- **核心思想（TUP）**：
  - 将 BoN 蒸馏策略的设计解耦为两个独立选择：
    - **(i) 下尾截断强度**：移除多少低排名完成（由阈值 λ 控制）；
    - **(ii) 上尾重加权锐度**：在保留下来的高排名完成中，如何按其相对排名重新加权（由参数 β 控制）。
  - 通过**移位截断胜率（shifted-truncated win-rate）** 实现解耦：胜率低于阈值的完成被赋予零质量，高于阈值的完成按其相对排名被平滑重加权。
  - 该策略具有闭式、提示无关的归一化常数，可通过**二元交叉熵（BCE）** **完全离线**训练。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想：截断-重加权目标策略

- **移位截断胜率（shifted-truncated win-rate）**：
  - 定义：\(w_{\lambda,r}(x,y) = \max(w_r(x,y) - \lambda, \; 0)\)，其中 \(w_r(x,y)\) 是完成在参考策略采样分布下的胜率（win-rate），\(\lambda \in (0,1)\) 是截断阈值。
  - 胜率低于 λ 的完成被映射为 0，即在目标策略中被赋予零概率质量；高于 λ 的完成按相对排序被保留。
- **变换奖励（transformed reward）**：
  - \(R_\lambda(x,y) = \mathrm{logit}(w_{\lambda,r}(x,y)) = \log \frac{w_{\lambda,r}(x,y)}{1 - w_{\lambda,r}(x,y)}\)。
  - 阈值以下 → \(-\infty\)（移出支持集合）；阈值以上 → 平滑的相对排序分数。

### 2.2 目标策略的闭式形式（Proposition 3.1）

- **KL 约束目标下的 Gibbs 解**：

\[
\pi^*_{\lambda,\beta}(y|x) = \frac{1}{Z_{\lambda,\beta}} \pi_{\text{ref}}(y|x) \left( \frac{w_{\lambda,r}(x,y)}{1 - w_{\lambda,r}(x,y)} \right)^{1/\beta}
\]

- **归一化常数（提示无关、闭式）**：

\[
Z_{\lambda,\beta} = \int_0^{1-\lambda} t^{1/\beta}(1-t)^{-1/\beta}\, dt = \text{Beta}_{1-\lambda}\left(1 + \frac{1}{\beta},\; 1 - \frac{1}{\beta}\right)
\]

- 关键性质：当胜率在参考策略下满足 \(w_r(x,Y) \sim U[0,1]\) 时，归一化常数与提示 x 无关，这消除了对提示相关配分函数的依赖。
- **参数的角色**：
  - **λ**：决定哪些完成保留在支持集合中（支持选择）。
  - **β**：决定在保留的支持集合内，目标策略偏离参考策略的程度（尾部内重加权锐度）。

### 2.3 理论证明（Section 3.2 & Appendix A.2）

- **定理 3.2（非正式）**：在代理奖励连续等假设下，**最优单调秩重加权策略可以被硬截断规则匹配**。即：
  \[
  \sup_{f \in \mathcal{F}^\uparrow} U_x(f) = \sup_{\lambda \in [0,1)} U_x(\nu_\lambda)
  \]
  其中 \(\mathcal{F}^\uparrow\) 是非负非递减密度族，\(\nu_\lambda\) 是上尾均匀密度。这为“**截断下尾优于仅降低其权重**”提供了正式理论依据。
  - 证明关键：任意非递减密度都可表示为截断均匀密度的混合（Lemma A.2），因此最优点在极值点取到。
- **命题 3.3（非正式）**：固定阈值 λ₀ 后，若保留尾部内 oracle 胜率剖面 \(m_x(w)\) 与尾部内 log-odds 倾斜 \(\log\frac{w-\lambda_0}{1-w+\lambda_0}\) 有**正协方差**，则存在有限 \(\beta_0\) 使有限 β 的平滑重加权优于纯截断。这为“**保留尾部内上加权**”提供了理论依据。
- 附录 A.2.3 使用二次型 oracle–proxy 剖面模型进行了详细的可视化分析（Figure 3、5），进一步分离了截断增益与尾部内重加权增益。

### 2.4 训练目标：将策略学习转化为软分类问题

- **关键转换**：对支持集合内的完成，将目标策略式（8）重排可得：

\[
w_{\lambda,r}(x,y) = \sigma\left( \beta \log \frac{\pi^*_{\lambda,\beta}(y|x)}{\pi_{\text{ref}}(y|x)} + \beta \log Z_{\lambda,\beta} \right)
\]

- **训练分类器**：

\[
p_\theta(x,y) = \sigma\left( \beta \log \frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)} + \beta \log Z_{\lambda,\beta} \right)
\]

- **损失函数（BCE）**：

\[
\mathcal{L}(\theta) = \mathbb{E} \left[ -w_{\lambda,r}(x,y)\log p_\theta(x,y) - (1 - w_{\lambda,r}(x,y))\log(1 - p_\theta(x,y)) \right]
\]

- **算法流程（Algorithm 1，离线）**：
  1. 对每个提示从参考策略采样 K 个完成，用奖励模型打分，计算经验池内胜率 \(\hat{w}_r\)。
  2. 计算截断标签 \(\hat{w}_{\lambda,r} = \max(\hat{w}_r - \lambda, 0)\)。
  3. 计算已知常数截距 \(b_{\lambda,\beta} = \beta \log Z_{\lambda,\beta}\)。
  4. 训练循环中，以 \(\beta \log \frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)} + b_{\lambda,\beta}\) 为 logit，以 \(\hat{w}_{\lambda,r}\) 为软标签，最小化 BCE 损失。
- **全离线、无需配对偏好、无需在线采样、无需估算提示相关配分函数**。

## 6. 主要结论与发现

- **TUP 具有竞争力**：在 Llama 8B 和 Mistral 7B 上，TUP 在 in-dataset 和 AlpacaEval 的 LC 奖励评估中，于两个独立 Skywork 奖励模型下均取得最佳或并列最佳结果；在 ArmoRM 下与强基线（QRPO、DPO、REBEL）水平相当。
- **跨奖励模型泛化更好**：训练时仅用 ArmoRM 标签，但 TUP 在独立评估奖励模型（Skywork-Llama、Skywork-Qwen）上的表现优于基线，说明截断低尾有助于跨代理奖励泛化。
- **截断 + 尾部重加权的组合最优**（图 4 消融）：中间 λ 与中间 β 的组合获得最高 LC 奖励，验证了将支持选择与尾部内加权解耦的设计合理性。
- **理论支持**：任意单调秩重加权的最优表现可由硬截断规则匹配；在固定阈值后，当概率剖面与 log-odds 倾斜正协方差时，有限 β 的平滑再加权可以进一步提升 oracle 胜率。
- **长度不是唯一动因**：长度匹配对比中 TUP 在 ArmoRM 和 Skywork-Llama 下优于所有基线，说明奖励增益不仅来自更长输出。

## 8. 缺点与局限性

1. **统计显著性检验不足**：所有结果仅基于 3 个生成种子的标准差，未进行多次完整训练重复与配对显著性检验（如 t 检验 / bootstrap），部分对比差异幅度较小，结论稳健性有待强化。

2. **训练奖励模型单一**：训练标签仅由 ArmoRM 一个奖励模型生成，未检验使用不同奖励模型（或奖励集成）生成训练标签时 TUP 的相对优势是否保持，可能造成对特定奖励模型的过拟合未被察觉。

3. **理论基础存在理想化假设**：命题 3.1 依赖“胜率在参考策略下服从 U[0,1]”的均匀性假设；定理 3.2 依赖代理奖励连续、策略族受限等理想化条件，与实际分布的偏差可能导致理论结论在极端场景下不完全成立。

4. **未探索在线 RL 结合**：未在 PPO/GRPO 等在线强化学习框架下验证 TUP 作为奖励整形、正则项或蒸馏目标的效果，也未讨论其对奖励篡改（reward hacking）的抵抗能力。

5. **真实场景增益缺乏量化归因**：虽然附录用二次型 oracle–proxy 模型理想化地分离了截断与重加权增益，但未在真实数据上量化两部分各自的贡献比例。

6. **模型规模与基线覆盖有限**：仅验证了 8B/7B 规模的模型，未扩展到更大规模；同时未纳入 SimPO、KTO、IPO 等近期方法，与现有方法对比的完备性一般。

## 9. 整体评价与总结

- **核心贡献**：TUP 提出了一种新颖、简约且理论可解释的 BoN 蒸馏目标——通过移位截断胜率将“下尾截断（λ）”与“上尾重加权（β）”两个操作解耦，并借助闭式、提示无关的归一化常数，将策略蒸馏转化为完全离线的软分类问题。
- **理论价值**：论文不仅给出目标策略的闭式解，还从最优秩重加权策略的极值分析出发，为“截断优于软降权”和“尾部内需有限锐度重加权”提供了形式化依据，这在同类蒸馏工作中较为少见。
- **实验价值**：在两个模型家族、两个训练数据集、多个独立评估奖励模型及 GPT judge 下验证了有效性，尤其是跨奖励模型泛化性的提升，具有明确的实用意义。
- **总体定位**：这是一篇“理论推导—算法设计—实验验证”结合良好的高质量工作，设计思路清晰、复现门槛低，对推理时选择策略的蒸馏研究有重要参考价值；主要不足在于统计检验强度、训练标签多样性及在线 RL 场景的覆盖。综合来看，TUP 为 BoN 风格蒸馏提供了一个干净而有效的基线方案，值得后续工作在此基础上继续深化。
