## 摘要
在可验证奖励的强化学习中，当rollout组全部正确或全部错误时，组间相对信号缺失，在我们的实验中这类组占63.0%-68.0%。我们提出SKALD（技能锚定潜在蒸馏），一种在线策略自蒸馏框架，使用同一Qwen3-Base模型的两个上下文视图：仅基于问题的学生模型，以及以抽象、显式答案过滤技能卡为条件的教师模型。学生模型在其自身前缀上训练，将技能引发的优势转移到共享参数中，而无需在测试时使用特权输入。为稳定上下文引起的分布不匹配，SKALD采用退火指数倾斜目标，降低教师偏好但学生似然极低的token权重；随着倾斜消失，目标收敛至教师交叉熵，并恢复前向KL学生梯度。经验门控仅在验证rollout估计教师正优势时激活蒸馏。在五个保留的数学基准上，SKALD在0.6B、1.7B和4B规模下分别将整体avg@8较GRPO提升+2.46、+4.85和+12.01。在1.7B规模下，仅零方差蒸馏即可恢复完整增益的84.7%，而SKALD仍比FLOP匹配的GRPO高+4.06，比上下文技能暴露高+3.77。这些结果表明，抽象技能在组间相对奖励失去信息量的场景中提供了密集监督。

## Abstract
Reinforcement learning with verifiable rewards yields no group-relative signal when rollout groups are uniformly correct or uniformly wrong, which account for 63.0-68.0% of groups in our experiments. We propose SKALD (Skill-Anchored Latent Distillation), an on-policy self-distillation framework that uses two context views of the same Qwen3-Base model: a question-only student and a teacher conditioned on an abstract, explicit-answer-filtered skill card. The student is trained on its own prefixes, transferring the skill-induced advantage into shared parameters without privileged input at test time. To stabilize context-induced distribution mismatch, SKALD employs an annealed exponentially tilted objective that downweights teacher-preferred tokens with very low student likelihood; as the tilt vanishes, it converges to teacher cross-entropy and recovers the forward-KL student gradient. An empirical gate activates distillation only when verified rollouts estimate a positive teacher advantage. Across five held-out mathematics benchmarks, SKALD improves overall avg@8 over GRPO by +2.46, +4.85, and +12.01 at 0.6B, 1.7B, and 4B, respectively. At 1.7B, zero-variance-only distillation recovers 84.7% of the full gain, while SKALD remains +4.06 above FLOP-matched GRPO and exceeds contextual skill exposure by +3.77. These results show that abstract skills provide dense supervision where group-relative rewards become uninformative.

## 一、核心问题与研究动机

- **核心问题**：强化学习中的可验证奖励（RLVR）在组内rollout全部正确或全部错误时，会产生**零组归一化优势**，即该组对策略梯度毫无贡献。论文实验显示这类“零方差组”占所有训练组的63.0%-68.0%，构成一个严重的监督盲区。
- **研究动机**：当结果奖励无法区分时，需要更密集的token级监督信号来补充。在线策略蒸馏（On-Policy Distillation）天然适合这一需求——学生模型在自己采样的轨迹上接收教师分布的密集监督，即使结果奖励无法判别优劣。
- **核心洞察**：特权信息不一定要用完整参考答案（会泄露答案）或更大的在线教师模型（增加训练和部署成本），而是可以使用**抽象的技能卡片**——包含相关原理、适用条件、常见错误等——作为特权信号，让同一模型的教师上下文视图为学生视图提供更丰富的分布信号，最终将技能“内化”进权重而非保留在提示中。

## 二、方法论：SKALD框架

### 1. 双上下文自蒸馏结构

- 单一Qwen3-Base模型`p_θ`以两种上下文视图实例化，**共享全部参数**：
  - **学生分支** `p_S(·|x)`：仅看到问题，与部署条件完全一致；
  - **教师分支** `p_T(·|x,s)`：额外看到抽象技能卡 `s = {title, principle, usage, common mistakes}`。
- 所有轨迹从学生分支采样（on-policy），教师分支对同一前缀打分，梯度仅流过学生分支（教师使用stop-gradient）。
- 该设计同时消除外部教师的两大成本：无容量失配（参数共享）、无服务依赖（教师仅为另一种提示）。

### 2. 技能卡构建

- 使用更大的Qwen3-14B模型**离线**挖掘技能卡：从17,384个候选中保留11,382张，合并为1,926个可复用技能；
- 每个技能卡中位数关联5个问题，93.1%的训练问题获得技能分配；
- **显式答案过滤**：删除实例特有数字、实体和中间表达式，防止答案直接泄露。

### 3. 退火倾斜交叉熵目标

论文提出核心目标函数（式1）：

```
L(τ)_n = -(1/τ) log E_{v~q_n}[e^{τ log p_n(v)}]
```

其中`p_n`为学生分布，`q_n`为stop-gradient后的教师分布。该目标的关键性质：

- **τ→0极限**：收敛到教师交叉熵H(q,p) = KL(q‖p) + H(q)，其学生梯度与forward-KL完全相同；
- **有效目标靶**（Lemma 1）：`r_τ(v) ∝ q(v)p(v)^τ`，即学生依赖的 escort 分布，自动降低学生当前似然极低的教师偏好token的权重；
- **平稳解**：`p* ∝ q^{1/(1-τ)}`，在τ>0时是锐化后的模式追求（mode-seeking）分布；
- **logit梯度有界**：每个坐标位于[-1,1]区间内；
- 展开式（式3）：`L = E_q[d] - (τ/2)Var_q[d] + O(τ²)`，负方差项是乐观熵风险，而非方差惩罚。
- **调度**：τ从0.8开始，前10%训练步保持，线性退火至80%步到0，最后20%步保持τ=0（即纯教师交叉熵）。

### 4. 经验门控

- 在初始检查点用K=8次rollout估计教师-学生准确率差异 `Δ̂(0)_K(x)`；
- 仅当 `Δ̂(0)_K(x) > 0` 时激活该问题的蒸馏项；
- 门控覆盖61.2%的训练问题，固定不变（虽有14.6%的初始正门控在训练后期发生符号反转，但硬/软、固定/刷新变体表现差异很小）。

### 5. 总目标

```
L(θ) = λ_R·L_R(θ) + λ_D·E_x[g_K(x)·E_{ŷ~p_S}[(1/|ŷ|)Σ_n L(τ)_n]]
```

其中`L_R`为GRPO损失，λ_R = λ_D = 1。设置`s = y*、τ=0、g≡1、λ_R=0`时退化为OPSD目标；删除蒸馏项则退化为GRPO。

## 三、实验设计

### 1. 数据集与Benchmark

- **训练集**：DAPO-Math-17k + OpenThoughts数学子集，经三重去污（问题/解答/技能卡级）后保留23,691题；
- **评测集**：5个保留数学基准，共872题——MATH500（500题）、AMC23（40题）、AIME24（30题）、AIME25（30题）、Minerva（272题）；
- **指标**：avg@8为主要指标，pass@8为辅助指标，整体得分为按问题数的加权微平均。

### 2. 对比方法

- **基线**：Zero-shot、Few-shot(k=2)、SFT(GT-CoT)、GRPO；
- **特权蒸馏基线**：OPSD（完整参考答案）、EOPD（熵路由）、GRPO+skill in-context（训练时技能在上下文、测试时移除）；
- **SKALD变体**：SKALD-shuffled（打乱技能卡）、SKALD无技能（教师无技能条件）；
- **消融**：OPSD→+技能抽象→+倾斜目标→+门控的逐步添加。

### 3. 模型规模

- Qwen3-Base三个规模：0.6B、1.7B、4B，各自独立训练。

## 四、资源与算力

- 论文未明确报告GPU型号、数量和精确训练时长，仅提供相对计算量数据：

## 五、实验数量与充分性

论文实验相当充分，主要类别如下：

1. **主实验**：3个规模 × 5个基准 × 3个随机种子，报告avg@8/pass@8；

4. **去污与泄漏审计**：条件泄漏恢复率（6种条件）、200张卡的三评阅人审计、技能打乱对照、卡片消毒（删除实例特定信息）、同类技能卡替换；

**公平性讨论**：
- 等计算量对照中，SKALD在相同FLOP下仍比GRPO高+4.06（1.7B）和+11.19（4B）；
- OPSD消耗的计算量略高于SKALD，因此结果不能用特权评分成本解释；

## 六、主要结论与发现

1. **整体效果**：SKALD在三个规模上均优于所有基线，相对GRPO的增益为0.6B:+2.46、1.7B:+4.85、4B:+12.01，且增益随规模单调增长（但作者明确指出这不是缩放定律，仅是经验观察）。
2. **机制验证**：零方差组占63%-68%的训练组，1.7B下仅零方差组蒸馏即达49.63（+4.11 vs GRPO），恢复完整增益的84.7%；混合组-only蒸馏仅+0.79——证明SKALD增益确实来自补充了组相对奖励失效处的监督信号。
3. **权重内化优于上下文暴露**：在无技能测试协议下，SKALD（50.37）比GRPO+上下文技能暴露+训练后移除（46.60）高+3.77，支持“蒸馏进权重”而非“提示脚手架”的路线。
4. **技能必须有用**：移除教师技能条件使结果从50.37降至48.01，证明特权技能上下文是增益的关键来源。
5. **稳定性**：倾斜目标显著提升了训练稳定性——risk-neutral运行在2/3的1.7B种子和3/3的4B种子上发散，而所有倾斜运行均收敛；4B下risk-neutral达到7168 token上限而倾斜运行缩短至2.4k。

## 七、优点

1. **问题定位精准**：直击RLVR中组相对奖励失效这一真实缺陷，用数据（63-68%零方差组）量化了问题规模。
2. **设计优雅**：同一模型双上下文视图避免了外部教师模型的容量失配和部署负担；显式答案过滤技能卡在信息丰富性与泄漏风险之间取得平衡。
3. **理论支撑完整**：Lemma 1给出了有效目标、logit梯度界和平稳解的完整刻画；式(2)(3)连接了倾斜目标与交叉熵/KL的关系。
4. **实验严谨性高**：去污协议覆盖问题/解答/技能三级；条件泄漏审计量化了各条件下的答案恢复率；层级bootstrap同时重采样种子和问题；等计算量对照排除了算力混淆。
5. **自我批评坦诚**：明确承认技能门控是启发式而非保证、有序消融存在交互、三点规模趋势不构成缩放定律、单独的诊断图不构成因果证据。
6. **机制透明**：零方差组分析直接定位了增益来源，而非仅停留在端到端指标。

## 八、不足与局限

1. **外部教师依赖**：虽然“无更大在线教师”的声明在实践中成立（Qwen3-14B仅用于离线挖掘卡片），但技能卡的构建仍然依赖更大模型，并非完全自包含。
2. **门控的启发式性质**：固定门控仅基于初始采样估计，14.6%的正门控在训练中发生符号反转；论文未提供自适应门控带来的额外增益证据（仅报告变体表现相近）。
3. **技能卡覆盖率**：93.1%的训练问题获得技能分配，仍有6.9%无技能；对无技能问题的方法行为未单独分析。
4. **实验范围有限**：仅覆盖Qwen3-Base一个模型家族和数学推理任务；未验证在其他模型（如Llama、Mistral）或其他任务（代码、科学推理）上的普适性。
5. **共享参数的移动目标问题**：教师分布随训练不断变化（共享参数），论文将此视为设计特征，但未提供冻结/EMA教师轨迹的对照诊断，无法完全排除耦合动态中的潜在不稳定因素。
6. **技能-问题匹配依赖自动挖掘**：技能库质量直接影响上限，但论文未系统研究技能卡构建策略（如候选筛选阈值、合并算法）对下游性能的敏感性。
7. **泄露风险无法逻辑排除**：作者承认各类控制手段“缩小但无法从逻辑上消除”条件泄露的担忧；技能卡虽过滤了显式答案，但抽象方法提示本身在评测集中可能带来不公平优势。
8. **计算量报告不够完整**：未报告GPU型号、总卡时数、训练wall-clock时间等关键资源指标，降低了可复现性和成本评估的便利性。

## 总结

SKALD提出了一种新颖且机制清晰的自蒸馏框架，通过抽象技能卡作为特权信号补充GRPO在零方差组中的监督盲区，实验证据扎实、分析多维、自我批评坦诚。尽管在模型家族覆盖、任务泛化性和泄漏风险的绝对排除上仍有不足，但该工作为“技能内化进权重”这一路线提供了有说服力的实证支持，具有较强的理论价值和实践参考意义。
