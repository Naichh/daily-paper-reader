## 摘要
在线策略自蒸馏通过查询学生实际访问状态上的教师来改进语言模型推理。近期方法通过向教师暴露特权上下文来创建强大的信息不对称，但它们从根本上依赖外部监督——如金标准解决方案或验证器——来构建这一优势。我们引入了CoDA（共识与分歧对齐），一个完全无监督的框架，完全从模型自身未标注轨迹的潜在不确定性结构中创建可靠的特权信息。CoDA提取两个互补信号。在正分支中，答案级共识识别出稳定的推理模式，该模式条件化一个冻结的自教师以在新鲜的学生轨迹上提供密集的分布指导。然而，由于一致性并不能保证正确性，仅使用正样本的蒸馏可能将相关错误放大为虚假共识。为了打破这种有害的反馈循环，CoDA引入了一个利用分歧的负分支：少数轨迹被视为不稳定替代方案，并通过参考锚定的、类KTO的校准目标进行轻微惩罚。这种未配对的二元反馈提供了稳健的正则化，而无需强假设共识即为绝对真值。在竞赛级数学基准上的实证评估表明，CoDA显著提升了推理能力，优于自生成基线，并有效稳定了针对错误共识的训练。

## Abstract
On-policy self-distillation improves language-model reasoning by querying a teacher on states actually visited by the student. Recent methods create a powerful information asymmetry by exposing the teacher to privileged context, yet they fundamentally rely on external supervision---such as gold solutions or verifiers---to construct this advantage. We introduce CoDA (Consensus and Disagreement Alignment), a fully unsupervised framework that creates reliable privileged information entirely from the latent uncertainty structure of a model's own unlabeled rollouts. CoDA extracts two complementary signals. In the positive branch, answer-level consensus identifies a stable reasoning mode, which conditions a frozen self-teacher to provide dense distributional guidance on fresh student trajectories. However, because agreement does not guarantee correctness, positive-only distillation risks amplifying correlated errors into a false consensus. To break this harmful feedback loop, CoDA incorporates a negative branch that exploits disagreement: minority trajectories are treated as unstable alternatives and gently penalized via a reference-anchored, KTO-style calibration objective. This unpaired binary feedback provides robust regularization without requiring the strong assumption that the consensus is the absolute ground truth. Empirical evaluations on competition-level mathematical benchmarks demonstrate that CoDA significantly improves reasoning, outperforming self-generated baselines and effectively stabilizing training against erroneous consensus.

## 2. 论文提出的方法论

**核心思想：**
- CoDA 从一个关键观察出发：同一组未标注 rollouts 中既有**共识**（多数轨迹收敛于同一答案），也有**分歧**（少数轨迹偏离）。
- 共识可用于构建"特权上下文"来指导学习；分歧则可用于惩罚不稳定模式，防止错误被放大。
- 两个信号互补：共识提供正向指导，分歧提供负向校准。

**技术细节与流程：**

1. **共识构建（正分支）**
   - 对每个问题 x，从当前策略 πθ 采样 s 个候选轨迹作为证据集 Yθ(x)。
   - 通过答案提取器 a(y) 将轨迹按最终答案分组，估计每个答案 z 的经验支持度 bpθ(z|x) = (1/s)Σ I[a(y⁽ʲ⁾) = z]。
   - 仅当最大答案组包含至少两个轨迹时才保留该 prompt；模态答案集 Zmaj = arg max c(z)，c(z) ≥ 2。
   - 从模态答案池 Ymaj 中选择一个代表性轨迹 y⁺（实验比较了随机、最短、最长三种选择策略），作为特权上下文 c⁺ = ϕ(x, y⁺)。
   - 关键设计：y⁺ 只条件化教师，不直接作为学生模仿的 token 级目标。

2. **共识条件化分布对齐（正分支损失）**
   - 学生独立采样一条新鲜轨迹 r，对齐目标为：
     - p_{θ,t}(v) = πθ(v | x, r_{<t})（学生分布）
     - qₜ⁺(v) = π₀(v | ϕ(x, y⁺), r_{<t})（冻结教师分布）
   - 损失函数：L_con = (1/|M_r|) Σ_{t∈M_r} min{D_α(qₜ⁺, p_{θ,t}), τ}
   - 其中 D_α 为广义散度（α=0 时为前向 KL，实验中采用），τ 为裁剪阈值，M_r 为响应 token 掩码。

3. **参考锚定的分歧校准（负分支损失）**
   - 少数轨迹集合 Y_min 中的轨迹被赋予"不理想"标签，但**不构造偏好对**，也不断言共识答案绝对正确。
   - 对每个少数轨迹 token 计算学生与冻结参考策略 π₀ 的对数概率比：
     - ℓₜ⁻(θ) = log [πθ(yₜ⁻ | x, y_{<t}⁻) / π₀(yₜ⁻ | x, y_{<t}⁻)]
   - 损失为 KTO 风格的中心化目标：
     - L_dis(x) = E_{y⁻∼Ỹ_min, t∼M_{y⁻}} [softplus(βℓₜ⁻(θ)) − log 2]
   - 该目标只惩罚正的对数比（即学生比参考更倾向少数 token 的情况），避免无差别地最小化似然——只约束"不快于初始策略"，而非"惩罚错误"。

4. **联合目标与在线迭代**
   - L_CoDA(x) = L_con(x) + λ·L_dis(x)
   - 所有 rollouts 在每次更新时从当前学生策略重新采样，因此共识上下文和少数模式都随策略演化而动态变化。
   - 缺少重复有效答案的 prompt 直接跳过更新。

## 6. 论文的主要结论与发现

1. **完全无监督的自我蒸馏可行**：CoDA–Full 在无需任何外部标签、验证器或 oracle 过滤的情况下显著提升推理能力。Qwen3-4B 上达到 54.57%（比 base 提升 2.60 点），Qwen3-1.7B 上达到 36.12%（比 base 提升 6.38 点）。

2. **接近甚至超过监督方法**：4B 模型上 CoDA 仅比受监督的 OPSD 低 0.25 点；1.7B 模型上反超 OPSD 0.31 点，且明显优于 GRPO 和 SFT。

3. **分歧校准（负分支）有效补充共识（正分支）**：加上负分支后，1.7B 模型平均准确率从 34.37% 提升到 36.12%，4B 模型从 53.70% 提升到 54.57%。负分支能有效抑制仅用共识时的错误自我放大。

4. **假共识是真实的训练风险**：Consensus Only 在训练后期出现显著性能下降，而 oracle 过滤（删除错误共识）能保持稳定轨迹。CoDA–Full 介于两者之间——不能完全替代 oracle 过滤，但能在无标签条件下恢复大部分稳定性。

5. **最短共识轨迹作为特权上下文最优**：在 1.7B 上，选择最短模态轨迹比随机选择高 0.86 点、比最长选择高 0.84 点。但这一优势随模型输出变短而减弱，存在结构性权衡。

6. **共识样本量增大改善训练稳定性但收益递减**：s 从 5 增至 20 可降低训练损失、提高共识准确率，但最终准确率提升有限（35.05% → 35.26%），主要受限于模型本身的能力边界。s=10 为默认折中选择。

## 7. 优点

- **概念创新**：首次提出"完全无监督的在线策略自蒸馏"，将特权信息的来源从外部监督转移为模型自身的 latent uncertainty structure，这一思路具有普遍启发意义。
- **双分支设计精妙**：正分支利用共识（多数稳定的推理模式），负分支利用分歧（少数不稳定模式）作为正则化。两个信号来自同一组数据，无需额外标注。
- **KTO 式校准的弱假设优势**：没有采取偏好对（y⁺ > y⁻）这种强假设——因为共识不一定正确。参考锚定的惩罚只保证"不使少数轨迹比初始策略更可能"，逻辑上更加谨慎稳健。
- **On-policy 闭环**：证据集与对齐轨迹每一步都从当前学生策略重新采样，符合在线策略迭代的正确范式，避免了分布外偏差。
- **诊断实验设计清晰**：通过 oracle 过滤作为"仅诊断"手段，有效分离了"假共识风险"与"方法能否抑制风险"两个问题；训练动态曲线直观展示了负面分支的效果。
- **实证结果具有说服力**：以 1.7B 模型反超受监督基线，说明不需要外部金标也能达到有竞争力的推理性能。

## 8. 不足与局限

- **假设"答案为共识代理"的限制**：共识按最终答案分组，不关注推理过程。如果模型系统性偏向某种错误推理模式（即使最终答案正确），共识信号可能隐藏推理质量差异。
- **少数轨迹惩罚的固有风险**：当共识是错误的、少数轨迹中可能包含正确答案时，负分支会误伤正确推理。论文承认这一点，并用弱惩罚（小 λ、reference anchor、token 级限制）来缓解，但无法完全消除——HMMT25 上 1.7B 模型的准确率不升反降即为佐证。
- **实验覆盖有限**：仅覆盖数学推理（competition-level math），且两个模型均为 1.7B/4B 的小型模型，未验证方法在更大模型（7B/70B）或更多领域（代码、常识推理、对话）上的有效性。
- **统计可靠性不足**：未报告多次运行的标准差、置信区间或显著性检验；avg@16 的单点估计不足以支撑结论的稳定性。
- **计算效率未充分讨论**：每轮训练需生成 s=10（甚至 20）条轨迹，每一步迭代的计算开销远高于 SFT，论文未给出完整的效率对比。
- **超参数敏感性问题未深入**：λ（负分支权重）、β（KTO 温度）、τ（发散裁剪阈值）、s（样本数）等关键超参数对结果的敏感性未被系统分析。
- **与"最大能力边界"的关系不清晰**：s 越大只能使估计更接近当前策略的真实分布，但不能突破该分布的能力上限。s=20 实验未完成，削弱了这一结论的完整性。
- **缺少与更多无监督基线的比较**：如 self-consistency + majority voting 的直接端到端蒸馏、RLEF/STaR 等自我改进方法的对比。

**总体评价：**
CoDA 提出了一种新颖且有说服力的全无监督推理自我改进框架，以双信号（共识与分歧）替代外部监督，在数学推理基准上表现强劲，并通过精心的消融实验分析了假共识风险与校准机制的作用。实验覆盖尚需扩展至更大模型与更多领域，统计严谨性也可进一步提升。
