## 摘要
基于结果的目标（如GRPO）的强化学习使基于LLM的智能体能够解决复杂的、长时程的任务，然而交互轨迹中嵌入的可复用探索模式在单次策略更新后大多被丢弃。现有的经验增强方法在推理时检索历史指导，但它们在应用经验时未考虑策略不断演变的能力，并造成对外部检索的持续依赖。我们提出EDGE（用于引导探索的经验蒸馏），一个将检索到的经验视为临时训练阶段脚手架并逐步将其益处内化到参数化策略中的框架。具体而言，EDGE将每次rollout组划分为经验条件和无经验轨迹，以估计并仅接纳正的边际增益而无需额外采样，然后通过基于其自身经验支持上的反向KL目标将诱导行为蒸馏到基础策略中。一个共同进化的经验库进一步从新出现的失败模式中合成指导，并在策略演变时修剪过时的条目。在ALFWorld和WebShop上，EDGE在7B规模下相较于GRPO分别提高了8.3和12.5个成功率点，并在推理时移除外部经验后保留了其脚手架性能的96.0%。代码可在https://github.com/xvolcano02/EDGE获取。

## Abstract
Reinforcement learning with outcome-based objectives such as GRPO enables LLM-based agents to solve complex, long-horizon tasks, yet the reusable exploration patterns embedded in interaction trajectories are largely discarded after a single policy update. Existing experience-augmented approaches retrieve historical guidance at inference time, but they apply experiences without accounting for the policy's evolving capability and create persistent dependencies on external retrieval. We propose EDGE (Experience-Distillation for Guided Exploration), a framework that treats retrieved experiences as temporary training-time scaffolds and progressively internalizes their benefits into the parametric policy. Concretely, EDGE partitions each rollout group into experience-conditioned and experience-free trajectories to estimate and admit only positive marginal gains without extra sampling, then distills the induced behavior into the base policy via a reverse-KL objective on its own empirical support. A co-evolutionary experience bank further synthesizes guidance from emerging failure modes and prunes obsolete entries as the policy evolves. On ALFWorld and WebShop, EDGE improves over GRPO by 8.3 and 12.5 success-rate points at the 7B scale and retains 96.0% of its scaffolded performance when external experiences are removed at inference time. The code is available at https://github.com/xvolcano02/EDGE.

## 1. 核心问题与整体含义

- **研究背景**：基于结果目标的强化学习（如 GRPO）已经成为 LLM 智能体在长时程、稀疏奖励环境中进行多轮交互训练的标准范式。然而，轨迹中蕴含的可复用探索模式（如任务分解、恢复策略、死胡同规避等）在单次策略更新后即被丢弃，导致智能体必须不断从零开始重新发现这些模式，训练效率低下。
- **现有方法的缺陷**：已有的经验增强方法（如 Reflexion、SkillRL、EMPO² 等）通常在推理时将历史经验作为外部上下文注入，但存在两个结构性局限：
  1. 经验效用随策略演化而变化，原先有效的经验在策略内化后可能变得冗余甚至有害，但大多数方法不加区分地应用或仅用静态启发式过滤；
  2. 部署时仍依赖外部检索，使部分能力驻留在上下文窗口中而非模型参数中，带来持久 token 开销和对检索噪声的敏感性。
- **本文核心观点**：经验复用不应是静态的“检索-提示”机制，而应被建模为“脚手架→参数”的动态生命周期：经验先在训练时引导探索，再通过蒸馏内化到策略中，最后在效用消失后退役。在这一视角下，经验复用成为一种动态验证、选择性应用并最终实现参数化的学习问题。
- **整体含义**：EDGE 将外部经验作为临时训练脚手架，通过边际增益估计、增益门控蒸馏和共同进化经验库，将有益探索行为逐步固化到策略参数中，从而提升 RL 智能体的性能和训练效率，并消除推理时对外部记忆的依赖。

## 2. 方法论

EDGE 的核心思想：在 GRPO 框架中引入受控的信息不对称，通过对比“有经验”与“无经验”的 rollout 来估计经验的边际增益，并仅将正增益经验的引导行为蒸馏回策略。具体包含三个关键机制：

### 2.1 经验引导的探索脚手架
- 每个 GRPO rollout 组（大小为 G）被等分为两个子集，不额外采样：
  - **Teacher 轨迹**（G/2 条）：条件上下文为 `c_T = x ⊕ e`（任务指令拼接检索到的经验 e）；
  - **Student 轨迹**（G/2 条）：条件上下文为标准 `c_S = x`。
- 定义瞬时边际增益：
  ```math
  Δe = avg_{τ∈T_T} R(τ) − avg_{τ∈T_S} R(τ)
  ```
  其中 R(τ) 为二元结果奖励。Δe > 0 表示经验当前能提供有效引导；Δe ≤ 0 表示冗余或有害。
- 增益门控同时控制 RL 损失的构成：
  - 当 Δe > 0 时，优势在所有 G 条轨迹上计算，pooled baseline 使学生优势下移、教师优势上移，更有利于强化有经验引导的成功行为；
  - 当 Δe ≤ 0 时，teacher 轨迹从 RL loss 中排除，退化为标准 GRPO（仅在 student 子集上计算优势），避免污染策略梯度。

### 2.2 增益门控特权蒸馏
- 利用同一策略 πθ 的两种信息条件实现非对称自蒸馏：teacher 为“停止梯度”的 πθ 在特权上下文 c_T 下的输出，student 为标准上下文 c_S。
- 为规避协变量偏移，蒸馏目标建立在 student 自身生成轨迹上：对每条 student 轨迹，用 c_T 对相同 token 做无梯度前向，比较两种上下文下的分布差异。
- 采用反向 KL 散度 `D_KL(π_student ∥ π_teacher)`，具有 mode-seeking 特性，避免覆盖教师全部支持而产生冗余行为。
- 蒸馏损失：
  ```math
  L_distill(θ) = E_{τ∼T_S} [ I(Δe > 0) · Σ_t Σ_y πθ^S(y) log( πθ^S(y) / π_sg(θ)^T(y) ) ]
  ```
- 联合 actor 损失：
  ```math
  L_actor = L_RL + λ L_distill
  ```
  其中 λ 控制蒸馏权重（实验取 0.1）。

### 2.3 经验库共同进化与管理
- **扩展**：训练后识别成功率低于阈值 ξ 的任务类别，收集该类别的成功/失败轨迹，由外部反射 LLM（GPT-4o）对比合成新的经验条目，去重后插入经验库。
- **剪枝**：对每个经验 e 维护 EMA 效用分数：
  ```math
  U_e^{(t)} = (1−μ) U_e^{(t−1)} + μ Δe
  ```
  当 U_e < η（η = −0.1）时从库中移除，从而淘汰已被策略吸收或过时的经验。
- 该机制使经验库与策略能力协同演化：策略通过内化经验而改进，新失败模式又驱动经验库扩充，同时无用经验被剪枝，避免检索噪声累积。

## 6. 主要结论与发现

- **性能提升**：在 7B 规模下，EDGE 在 ALFWorld 上达到 90.4% 成功率（比 GRPO 高 8.3 个点），在 WebShop 上达到 82.6% 成功率（比 GRPO 高 12.5 个点）；在 1.5B 规模上也有一致提升。
- **探索密集型子任务受益最大**：Heat、Cool、Pick2 等长序列、稀疏反馈的子任务改进最明显，说明经验引导主要缓解了探索困难。
- **推理时无外部经验仍能保持性能**：EDGE 保留 96.0% 的脚手架性能，高于 SkillRL（82.9%）和 EMPO²（92.3%），表明蒸馏成功将经验内化为参数。
- **增益门控至关重要**：去掉增益门控后性能低于 vanilla GRPO 9.8 个点，证明无过滤的经验注入不仅无效而且有害。
- **蒸馏是关键**：去掉蒸馏后，性能仅比 GRPO 高 1.5 个点，说明仅靠探索脚手架无法持久改善策略，必须有显式的行为转移。
- **经验效用非平稳**：静态经验库的增益先正后负，而共同进化经验库能维持稳定正增益，验证了剪枝与扩展的必要性。
- **训练效率提升**：EDGE 比 GRPO 更快地降低环境步数与轨迹长度，说明政策学习到更直接的动作序列。

## 7. 优点

- **概念创新**：首次将经验复用明确建模为“训练时脚手架 → 参数内化”的动态生命周期，突破了“推理时检索增强”的静态范式。
- **无需额外采样**：通过分组对比在已有 rollout 内估计边际增益，大幅降低计算成本。
- **蒸馏设计稳健**：在 student 自身经验支持上计算反向 KL，避免分布偏移；增益门控防止负迁移。
- **经验库自适应机制**：EMA 效用跟踪结合阈值剪枝，使经验库能够随策略演化而收缩/扩展，贴近真实训练需求。
- **实验分析扎实**：包含消融、训练动态、经验增益时间演化、案例研究等多维分析，能直接支撑设计动机的有效性。

## 8. 不足与局限

- **训练开销增加**：经验库维护、teacher–student 对比计算以及外部反射 LLM（GPT-4o）调用都会带来额外成本，论文未量化这部分开销。
- **奖励质量依赖**：边际增益估计基于结果奖励

- **奖励质量依赖（续）**：边际增益估计完全依赖二元结果奖励。在奖励稀疏或噪声较大的真实场景中，Δe 的置信度会下降，可能导致门控决策失准；论文未讨论连续奖励或带噪声奖励下的鲁棒性。
- **外部反射 LLM 依赖**：经验扩展环节依赖 GPT-4o 等外部模型合成新经验，这与“摆脱外部依赖”的核心目标之间存在微妙张力——虽然推理时不依赖外部模型，但训练阶段仍需付费调用，且反射 LLM 的质量直接影响实验库的演化方向。
- **环境覆盖面有限**：仅在 ALFWorld 和 WebShop 两个文本交互套件上验证，均为相对结构化的家庭/购物任务；未在开放型对话、代码生成、具身操作等更复杂、更长时程的任务中测试，泛化性证据不足。
- **模型规模跨度有限**：模型仅限 Qwen2.5-1.5B 与 7B，缺少更大规模（如 13B/70B）或不同架构（如 Llama、Mistral）上的复现，难以判断方法是否能扩展到前沿模型。
- **蒸馏模式可能带来副作用**：反向 KL 虽能避免覆盖冗余行为，但也倾向于锁定教师的高峰模式，可能导致策略过早收敛到局部最优，削弱探索多样性；论文未分析长期训练后策略熵的变化。

## 9. 适用场景与建议

- **适用场景**：EDGE 特别适合长时程、稀疏奖励、且存在可重复利用的结构化探索模式的文本决策任务——如网页操作、工具调用、API 组合等。当策略反复在同类错误上浪费时间时，EDGE 能通过经验引导与蒸馏加速“试错→固化”的循环。同时，对推理时延迟或 token 预算敏感的生产环境也友好，因为部署时无需外部记忆检索。
- **使用建议**：
  1. 若环境奖励噪声较大，建议先对结果奖励做平滑或置信度加权，再估计 Δe；
  2. 经验库的初始构建可从少量人工标注的失败/成功对比开始，降低对反射 LLM 的依赖；
  3. 门控阈值 η 建议根据经验增益的分布做 warm-up 校准，避免过早剪除仍在起效的旧经验；
  4. 在策略快速演化阶段，可适当提高蒸馏权重 λ，在后期降低，以实现“先引导、后内化”的渐进迁移。

## 10. 总结评价

EDGE 是经验增强 LLM 智能体训练方向上的一次有价值的范式推进。其核心贡献不在于某一项算法组件的局部改进，而在于重新定义了经验在训练中的角色：从“推理时被检索的静态外部知识”转变为“训练时被动态评估、选择性使用并最终退役的临时脚手架”。增益门控、非对称蒸馏和共同进化经验库三个机制环环相扣，共同构成了一套完整的经验生命周期管理方案。实验证据表明，该方法不仅显著提升了两个基准任务上的成功率和训练效率，更重要的是证明了这些能力确实被编码进了模型参数中而非依赖上下文注入。尽管在环境覆盖面、超参数敏感性分析、外部反射 LLM 依赖等方面仍有改进空间，但 EDGE 的核心思想具有很强的可迁移性，未来可望与 RAG、工具学习、多模态智能体等领域相结合，成为智能体持续学习框架中的一个通用组件。
