## 摘要
基于视觉的人形机器人全身运动操作因部分可观测性、接触丰富的动力学以及从高维视觉输入中学习长时程行为的困难而具有挑战性。我们提出了DreamMimic，一种通过世界模型辅助蒸馏将特权教师策略提炼为基于视觉的人形控制器的框架。我们没有使用Dreamer风格的RSSM进行规划，而是重新利用它来学习预测性潜在动力学，既作为表示空间，又作为动作条件下的多步监督信号，同时向学生策略暴露紧凑的预测特征以减少长期漂移。除了针对本体感觉和视觉观察的标准重建目标外，我们还为特权状态、接触、物体状态和奖励估计添加了辅助预测头。这些预测头提供了与智能体-物体交互和任务进展相关的额外监督，鼓励潜在表示保留对接触丰富的操作有用的信号。我们进一步引入了性能条件引导（PCG），一种奖励驱动的自适应蒸馏调度，计算教师和学生的性能分数以动态平衡引导和探索。PCG在具有挑战性的视觉环境中既防止了教师过早退火，也防止了教师过度干扰。在OMOMO和BEHAVE上的实验表明，与强大的基于视觉的基线相比，跟踪式操作性能有所提升，而部署时不会向学生暴露在线的特权交互状态。定性模拟进一步检查了形态和模拟器的变化。这些结果表明，世界模型可以为在接触丰富的人形行为中稳定视觉策略蒸馏提供一种有用的机制。

## Abstract
Vision-based whole-body loco-manipulation on humanoid robots is challenging due to partial observability, contact-rich dynamics, and the difficulty of learning long-horizon behaviors from high-dimensional visual inputs. We present \href{https://github.com/DreamMimic/DreamMimic}{DreamMimic}, a framework that distills privileged teacher policies into vision-based humanoid controllers via world-model-assisted distillation. Instead of using a Dreamer-style RSSM for planning, we repurpose it to learn predictive latent dynamics that serve as both a representation space and an action-conditioned multi-step supervision signal, while exposing compact predictive features to the student policy to reduce long-term drift. Beyond standard reconstruction objectives for proprioceptive and visual observations, we add auxiliary prediction heads for privileged state, contact, object state, and reward estimation. These heads provide additional supervision related to agent--object interaction and task progress, encouraging the latent representation to retain signals that are useful for contact-rich loco-manipulation. We further introduce Performance-Conditioned Guidance (PCG), a reward-driven adaptive distillation schedule that computes performance scores for both teacher and student to dynamically balance guidance and exploration. PCG prevents both premature teacher annealing and excessive teacher interference in challenging visual settings. Experiments on OMOMO and BEHAVE show improved tracking-based loco-manipulation performance over strong vision-based baselines, without exposing online privileged interaction states to the student at deployment. Qualitative simulations further examine morphology and simulator changes. These results suggest that world models can provide a useful mechanism for stabilizing visual policy distillation in contact-rich humanoid behaviors.

## 1. 核心问题与研究动机

### 问题背景
- 人形机器人需要在视觉反馈下完成**全身移动操作（whole-body loco-manipulation）**，例如搬运桌子、拖拽物体等，这要求在移动的同时与物体进行协调交互。
- 该任务面临三大核心挑战：
  - **部分可观测性（partial observability）**：部署时无法获取物体位姿、接触状态等模拟器特权信息；
  - **接触丰富的动力学（contact-rich dynamics）**：不连续的接触事件使学习过程不稳定；
  - **长时程行为学习**：从高维视觉输入中学习长时间跨度的协调行为极易累积误差。

### 现有方法的不足
- 许多方法只关注纯运动（locomotion），无法处理复杂物体交互；
- 依赖特权信息（如真实物体位姿、接触标签）或预计算的状态估计器，无法直接部署；
- 现有视觉策略学习框架（如直接视觉编码器 + RL/DAgger）缺乏**时间结构化的预测性表示**，在长时程接触任务中容易产生复合误差。

### 研究目标
构建一个**部署时可仅依赖视觉和本体感觉输入**的视觉运动全身操作策略，同时保持对长时程接触丰富行为的跟踪能力，无需在线暴露特权交互状态。

## 2. 方法论：DreamMimic 框架

### 2.1 总体架构

DreamMimic 将问题建模为**部分可观测马尔可夫决策过程（POMDP）**，核心思想是：

> **不将世界模型用于规划，而是将其重造为预测性表示学习器**，为学生策略提供表示空间和多步监督信号。

整个框架包含四大组件：
1. 多个专家教师（specialist teachers）→ 合并为统一特权教师
2. 世界模型（RSSM）——预测性潜在动力学
3. 视觉学生策略（vision-based student）
4. 性能条件引导（PCG）调度机制

### 2.2 特权教师策略（Privileged Teacher）

- 教师可访问完整模拟器状态（真实物体位姿、交互图、接触信号）；
- 通过强化学习（RL）训练，以跟踪参考运动为目标；
- 奖励函数整合全身跟踪、末端执行器对齐、物体一致性及接触感知项；
- 遵循 InterMimic 的"专家到通才"方案，从大规模 HOI 数据集构建多个特权教师。

### 2.3 学生策略（Visuomotor Student）

- 学生策略输入为：

```
c_t = [p_t, g_t, φ^wm_t]
```

其中：
- `p_t`：非特权本体感觉观测（去除模拟器状态、交互图、接触标签）
- `g_t`：紧凑目标条件（目标物体位姿 + 短时机器人轨迹线索）
- `φ^wm_t`：世界模型特征，包含：
  - 确定性 RSSM 状态 `h_t`（从视觉—本体感觉历史和上一动作推断）
  - 预测奖励 `r̂_t`
  - 预测特权状态 `x̂^priv_t`
  - 预测接触 `ĉ^contact_t`
  - 预测物体状态 `x̂^obj_t`

- 策略网络将本体-目标特征、世界模型特征、辅助预测特征作为独立 token，通过轻量 Transformer 融合后送入 actor-critic MLP；
- 训练以**监督模仿（action distillation）**为主，**PPO 正则化**为辅。

### 2.4 世界模型（RSSM-based World Model）

采用 Dreamer 风格的 RSSM 架构，但不用于规划，而是用于表示学习：

- **编码器** `E_ξ`：将当前观测（深度 + 分割图像 + 本体感觉）和上一动作编码为嵌入；
- **RSSM 潜在动力学**：维护确定性递归状态 `h_t`（GRU）和随机状态 `s_t`（后验/先验）；
- **解码器（RecH）**：重建视觉和本体感觉观测（图像 MSE + 本体 sentim-log-MSE）；
- **辅助预测头**：
  - 奖励预测头（RPH）
  - 特权状态预测头（估计算器端交互目标：13-D 物体状态 + 全身交互图 + 目标接触标签）
  - 接触预测头（CPH）
  - 物体状态预测头（OSPH）
- 这些辅助头将潜在状态锚定到任务相关信号上，鼓励表示保留交互相关信息。

### 2.5 多步潜在蒸馏（Multi-step Latent Distillation）

核心创新之一：

- 从当前后验潜在状态 `z_t` 出发，分支两个**想象 rollout**（使用冻结的 RSSM 先验，H=3 步）：
  - 一条以学生策略均值动作 `μ^(S)_t` 为条件
  - 另一条以教师策略均值动作 `μ^(T)_t` 为条件
- 最小化两分支潜在状态的差异：

```
L_latent = Σ_{k=1}^{H} [ ||h^(S)_{t+k} − h^(T)_{t+k}||²₂ + λ_stoch ||s^(S)_{t+k} − s^(T)_{t+k}||²₂ ]
```

- 该损失**不需要教师侧视觉观测**，仅使用学习到的动力学作为动作条件下的局部一致性度量，约束师生策略在**未来状态演化**上对齐。

### 2.6 性能条件引导（PCG）

PCG 是蒸馏调度机制的创新：

- 维护教师驱动和学生驱动环境的奖励指数移动平均 `r̂_T` 和 `r̂_S`；
- 计算相对性能分数 `π = r̂_S / (r̂_T + ε)`；
- 当 π 接近目标性能比时，将教师驱动环境比例 `ρ` 从 `ρ_max` 衰减到 `ρ_min`（EMA 平滑）；
- 全程保持模仿监督系数 `c` 固定。

**效果**：防止过早减少教师引导（学生尚未成熟时），也防止教师过度干扰（学生已能在自身状态分布下工作后），减少对手动退火调度的依赖。

### 2.7 训练目标

- **世界模型损失**：
```
L_wm = L_KL + L_rec + L_rew + L_priv + L_con + L_obj
```
（KL 使用 free-bits 防坍缩）

- **学生策略总损失**：
```
L_total = c·w_action·L_action + w_wm·L_latent + w_ppo·L_ppo
```

- 优化以模仿主导，PPO 在热身期后介入作为低权重正则化器。

## 6. 主要结论与发现

1. **世界模型辅助蒸馏有效**：在 OMOMO 上 DreamMimic 达到 **92.2% 成功率**（直接视觉 RL 为 0%），显著降低机器人和物体跟踪误差（Er 5.4cm / Eo 8.8cm）；
2. **多步潜在一致性优于单步模仿**：对齐未来潜在动力学对保持长时间接触交互至关重要（消融验证 92.2% vs. 70.6%）；
3. **辅助预测头提供交互相关监督**：特权状态、接触、物体状态预测共同促进潜在表示保留任务关键信息；
4. **PCG 优于手动调度**：自适应的教师引导衰减减少了对调参的依赖，同时保持更好的长期性能；
5. **单阶段 Dreamer 不适用**：直接使用 Dreamer 风格 RL 在接触丰富的人形任务中表现远低于教师蒸馏方法（0% 成功率）；
6. **世界模型的核心价值**：作为**预测性表示空间 + 多步监督信号**，而非规划器，为接触丰富的视觉策略蒸馏提供了稳定化机制。

## 7. 优点

- **将世界模型从规划器重造为蒸馏辅助工具**：这是新颖的定位转变，避免了规划在高维人形任务中的不可行性，同时保留了预测式表示的好处；
- **多步潜在蒸馏设计精巧**：无需额外教师观测，仅使用学习到的动力学作为师生策略间的一致性度量，计算开销可控；

## 8. 不足与局限

### 已知失败模式

- 仅支持仿真到仿真的迁移，到真实系统仍需感知管道匹配和域随机化等额外工作。
