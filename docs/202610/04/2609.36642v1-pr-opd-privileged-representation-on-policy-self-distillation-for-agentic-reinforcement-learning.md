## 摘要
语言模型智能体通常通过每个回合一个奖励的强化学习进行训练，而特权自蒸馏通过让同一策略在给定技能的情况下，借助 token 概率来教导其无技能的自身，从而增强这一过程。然而，我们发现了两种现象，对这一通道提出了质疑。不可见优势：上下文中的技能将 WebShop 成功率从 42.2% 提升到 56.2%，却只改变了不到四分之一采样 token 的概率。大有可对齐：技能改变了超过 80% 的响应 token 的隐藏状态，其方式可被线性探针追溯至特定技能。为利用这一点，我们提出特权表示同策略自蒸馏（PR-OPD）。在 GRPO 热启动之后，策略为每条轨迹写下一个事后技能，以该技能作为停止梯度教师重新读取自身回复，并在每一层将其投影后的隐藏状态与教师的隐藏状态对齐，同时优化奖励目标，且无需外部技能库、独立教师或推理开销。在 ALFWorld 和 WebShop 上，使用两个骨干模型，PR-OPD 在所有设置中均取得最佳总体结果，相较 GRPO 在 ALFWorld 成功率上最高提升 4.7 个百分点，在 WebShop 准确率上最高提升 14.0 个百分点。代码见 https://github.com/balibata/PR-OPD。

## Abstract
Language-model agents are usually trained by reinforcement learning from one reward per episode, and privileged self-distillation enriches it by letting the same policy, given a skill, teach its skill-free self through token probabilities. However, we identify two phenomena that question this channel. Invisible Advantage: a skill in context lifts WebShop success from 42.2% to 56.2%, yet changes the probabilities of fewer than a quarter of the sampled tokens. Much to Align: a skill changes the hidden states of over 80% of response tokens, in a way that linear probes can trace back to the specific skill. To exploit this, we propose Privileged Representation On-policy Self-Distillation (PR-OPD). After a GRPO warm start, the policy writes a hindsight skill for each trajectory, re-reads its own responses with that skill as a stop-gradient teacher, and aligns its projected hidden states to the teacher's at every layer alongside the reward objective, with no external skill library, separate teacher, or inference overhead. On ALFWorld and WebShop with two backbones, PR-OPD achieves the best overall results in every setting, improving over GRPO by up to 4.7 points in ALFWorld success and 14.0 points in WebShop accuracy. Code is available at https://github.com/balibata/PR-OPD.

# PR-OPD 论文总结

## 1. 核心问题与整体含义

- **研究背景**：语言模型智能体通常通过强化学习从可验证奖励中训练，但多轮任务往往只有轨迹级终端奖励，信号稀疏。为增强监督，已有工作采用“特权自蒸馏”：同一策略在额外信息（如技能、事后反馈）条件下充当教师，通过 token 概率指导学生，使其在推理时无需该信息。
- **核心问题**：现有特权自蒸馏默认“教师的 token 概率足以传递特权信息”。作者发现这一假设不成立，并提出两个现象：
  - **Invisible Advantage（不可见优势）**：技能加入上下文后，WebShop 成功率从 42.2% 提升到 56.2%，但只改变不到四分之一采样 token 的概率；在动作 token 上几乎不改变。
  - **Much to Align（大有可对齐）**：同一技能改变超过 80% 响应 token 的隐藏状态，且线性探针可追溯具体技能；直接对齐教师隐藏状态的学生甚至能超过教师。
- **整体含义**：技能带给教师的行为优势真实存在，但几乎不体现在输出 token 分布中，而是主要编码在隐藏状态里。因此，学生应从教师的隐藏表示中学习特权信息，而非仅模仿其 token 概率。

## 2. 方法论：PR-OPD

- **核心思想**：提出 **Privileged Representation On-policy Self-Distillation（PR-OPD）**。学生不再蒸馏特权教师的 token 概率，而是在同策略采样轨迹上，将自身投影后的隐藏状态与“带技能重读自身回复”的停止梯度教师隐藏状态逐层对齐，同时继续优化奖励目标。
- **两阶段流程**：
  - **Stage I：GRPO 热启动**。先用 GRPO 训练策略 N 次更新，使策略具备任务能力并能分析自身经验。
  - **Stage II：联合训练**。每轮用当前策略无技能采样轨迹；同一策略为每条已完成轨迹生成一个事后技能；将技能前置到上下文形成教师上下文；学生处理原始上下文，教师处理带技能上下文，两者看到相同响应 token。
- **技能生成**：
  - 将轨迹与结果序列化为文本 \(z_i\)，提示同一策略生成事后技能 \(s_i\)。
  - 成功轨迹的技能描述可复用流程与关键观察；失败轨迹的技能指出关键错误及纠正方式。
  - 技能生成不可微，无独立 SFT 阶段，每批新 rollout 重新生成，不依赖外部技能库。
- **隐藏状态对齐**：
  - 对学生上下文 \(x\)、教师上下文 \(\tilde{x}\)，同一响应 token \(y_k\) 在第 \(\ell\) 层的学生状态和教师状态分别为：
    \[
    h^{(\ell)}_{S,k}=f^{(\ell)}_\theta(x,y_{<k}),\quad
    h^{(\ell)}_{T,k}=f^{(\ell)}_\theta(\tilde{x},y_{<k})
    \]
  - 学生与教师共享权重，因此层与层一一对应；教师提示更长，故按响应 token 配对，而非按绝对位置配对。
  - 学生状态先经过每层轻量 MLP 投影器 \(g^{(\ell)}_\psi:\mathbb{R}^d\to\mathbb{R}^d\)，含一个 512 维隐藏层，得到 \(p^{(\ell)}_{S,k}\)。教师状态停止梯度。
  - **PRA 损失**：
    \[
    \mathcal{L}_{PRA}(\theta,\psi)=\frac{1}{L|M|}\sum_{\ell=1}^{L}\sum_{k\in M}
    \left\|\hat p^{(\ell)}_{S,k}-\mathrm{sg}\left[\hat h^{(\ell)}_{T,k}\right]\right\|_2^2
    \]
    其中 \(\hat v=v/\max(\|v\|_2,\epsilon)\)。归一化后每项等价于 \(2-2\cos(p_S,h_T)\)，即只对齐方向，不对齐幅度。
  - 对齐所有 Transformer 层、所有有效响应 token；投影器训练时联合优化，推理时丢弃。
- **总体目标**：
  \[
  \mathcal{L}(\theta,\psi;t)=\underbrace{\mathcal{L}_{GRPO}(\theta)+\beta\mathcal{L}_{KL}(\theta)-\eta H(\pi_\theta)}_{\mathcal{L}_{RL}(\theta)}+\lambda_t\mathcal{L}_{PRA}(\theta,\psi)
  \]
  其中 \(\lambda_t=0\) 当 \(t\le N\)，否则为 \(\lambda\)。文中 \(\beta=0.01\)，\(\eta=0.001\)，\(\lambda=0.01\)。不使用输出空间蒸馏项。
- **算法流程**：Stage II 每轮：收集分组轨迹和奖励 → 计算 GRPO 优势 → 为每条轨迹生成技能并构造教师上下文 → 学生与教师前向 → 计算 \(\mathcal{L}_{RL}+\lambda\mathcal{L}_{PRA}\) → 更新策略和投影器 → 同步 rollout 策略。
