## 摘要
在线策略蒸馏（OPD）通过让学生在其自身生成的轨迹上训练来减少训练-测试状态不匹配，但较弱的学生可能访问与教师不一致的前缀，在这些前缀上的监督代表性较差。我们提出 SAKI（Supervision Allocation with KL-constrained Interpolation，KL 约束插值的监督分配），它将 KL 约束的教师引导 rollout 与最大耦合相结合，并复用实际发生的接受/纠正事件来路由 token 级监督。接受位置保留对采样 token 的反向 KL 监督，而纠正位置则接收对教师最高概率 token 的直接监督。在最大耦合下，纠正概率恰好为 TV(p_t, q_t)，因此同一信赖域半径既控制 rollout 偏差，又为干预和专门监督的频率提供上界。我们进一步实现了一个驻留于引擎的推测验证器，它保持精确 q 的轨迹分布与耦合语义，同时将匹配工作负载下的 rollout 吞吐量提升 4.22 倍。在七个数学推理基准上，SAKI 对 1.7B 和 0.6B 学生模型均提升了匹配的教师引导基线在 Mean@8 和 Pass@8 上的表现。放置对照和固定前缀分析进一步支持将纠正触发的路由作为一种冲突自适应的监督信号。

## Abstract
On-policy distillation (OPD) reduces train-test state mismatch by training a student on its own generated trajectories, but weak students may visit teacher-misaligned prefixes where supervision is less representative. We introduce SAKI (Supervision Allocation with KL-constrained Interpolation), which combines a KL-constrained teacher-guided rollout with maximal coupling and reuses realized accept/correction events to route token-level supervision. Accepted positions retain sampled-token reverse-KL supervision, while correction positions receive direct supervision on the teacher's highest-probability token. Under maximal coupling, the correction probability is exactly TV(p_t, q_t), so the same trust-region radius controls rollout deviation and upper-bounds intervention and specialized-supervision frequency. We further implement an engine-resident speculative verifier that preserves the exact-q trajectory distribution and coupling semantics while improving matched-workload rollout throughput by 4.22x. Across seven mathematical reasoning benchmarks, SAKI improves the matched teacher-guided baseline in Mean@8 and Pass@8 for both 1.7B and 0.6B students. Placement controls and fixed-prefix analysis further support correction-triggered routing as a conflict-adaptive supervision signal.

# SAKI 论文总结

## 1. 核心问题与整体含义

- **背景**：知识蒸馏将强教师模型能力迁移到小学生模型。在线策略蒸馏（OPD）让学生在自己的生成轨迹上接受教师监督，以缓解训练与测试时的状态分布不匹配。
- **核心矛盾**：OPD 的有效性不仅取决于“教师提供什么监督”，还取决于“在哪些状态上查询监督”。当学生显著弱于教师时，早期错误会累积，使学生进入教师自身策略下很少生成的前缀；教师在这些前缀上的条件监督代表性下降，不利于能力迁移。
- **已有尝试**：TRB 通过学生中心的 KL 信赖域构造教师引导的行为分布 \(q_t\)，改善被访问状态分布，但仍对所有前缀使用相同的逐前缀反向 KL（RKL）目标。
- **SAKI 的切入点**：在 TRB 的行为侧改进之外，补足“目标侧”问题——被引导行为保留学生提议的位置，与必须覆盖学生提议的位置，是否应接受同样的监督？
- **整体含义**：SAKI 将最大耦合中的“接受/纠正”事件复用为 token 级监督路由器，使监督分配与 rollout 构造共享同一随机过程，形成冲突自适应的在线蒸馏方案。

## 2. 方法论

- **核心思想**：在教师引导的信赖域行为分布 \(q_t\) 上，用最大耦合精确采样；耦合产生的接受/纠正事件决定 token 级监督方式。
  - **接受位置**：保留对采样 token 的 RKL 监督。
  - **纠正位置**：切换为对教师最高概率 token（Top-1）的直接监督。

- **教师引导的信赖域桥**：
  - 在每个前缀，对教师分布 \(T_t\) 和学生分布 \(p_t\) 做几何插值：
    \[
    q_{\beta,t}(v)=\frac{p_t(v)^{1-\beta_t}T_t(v)^{\beta_t}}{Z_t(\beta_t)}
    \]
  - 选择满足 \(D_{KL}(q_{\beta,t}\|p_t)\le \epsilon\) 的最大可行 \(\beta_t\)。
  - \(\epsilon=0\) 时 \(q_t=p_t\)；信赖域足够大时 \(q_t=T_t\)。

- **最大耦合与纠正事件**：
  - 学生先提议 \(z_t\sim p_t\)。
  - 以概率 \(a_t(z_t)=\min(1,q_t(z_t)/p_t(z_t))\) 接受；接受则 \(y_t=z_t\)，\(C_t=0\)。
  - 否则从正残差分布 \(r_t(v)\propto [q_t(v)-p_t(v)]_+\) 采样纠正 token；\(y_t=c_t\)，\(C_t=1\)。
  - 关键性质：最终输出边际为 \(q_t\)，且纠正概率恰好为
    \[
    \Pr(C_t=1)=\mathrm{TV}(p_t,q_t)
    \]
  - 最大耦合在所有具有相同边际的耦合中实现最小干预概率；在信赖域约束下有
    \[
    \Pr(C_t=1)\le \sqrt{\frac{1}{2}D_{KL}(q_t\|p_t)}\le \sqrt{\epsilon/2}
    \]

- **耦合路由的监督目标**：
  - 接受位置使用采样 token 的 RKL：
    \[
    L_{RKL,t}(v)=-A_t(v)\log\pi_\theta(v|h_t),\quad A_t(v)=-\mathrm{sg}[\log p_t(v)-\log T_t(v)]
    \]
  - 纠正位置使用教师 Top-1 硬标签 NLL：
    \[
    v_t^*=\arg\max_v T_t(v),\quad L_{TM,t}=-\log\pi_\theta(v_t^*|h_t)
    \]
  - 总损失按有效 response token 数归一化：
    \[
    L=\frac{1}{N_{valid}}\left[\sum_t M_t(1-C_t)L_{RKL,t}+\sum_t M_tC_tL_{TM,t}\right]
    \]
  - 纠正 token 决定下一前缀，教师 Top-1 决定参数更新，实现“轨迹构造”与“监督目标”解耦。

- **训练调度**：主训练中将 \(\epsilon\) 退火到零，使方法最终回到标准学生 rollout 的 RKL 训练；纠正监督是瞬态的。

- **引擎驻留的精确 \(q\) rollout**：
  - 使用推测块验证摊销在线教师推理：学生一次草拟最多 \(K\) 个 token，教师在单次批处理中验证。
  - 引擎内批量构造 \(q_t\)、求解信赖域系数、向量化最大耦合接受判断。
  - 只提交最长连续接受前缀；首次拒绝处采样精确残差纠正，提交该纠正并丢弃后续推测 token 与 KV 状态，从纠正后前缀继续。
  - 保持与顺序精确 \(q\) 采样相同的自回归分布和耦合语义。
