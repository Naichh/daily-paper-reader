## 摘要
同策略蒸馏（OPD）利用更强教师模型提供的稠密 token 级反馈，在学生模型自身生成的轨迹上训练学生模型。由于每次更新都以学生已经生成的推理前缀为条件，前缀也会影响教师反馈转化为学习的有效程度。我们发现，共享前缀可能导致 token 级更新变弱，并将这一现象称为前缀诱导的监督衰减（Prefix-Induced Supervision Attenuation, PISA）。这种衰减出现在两种常见情形中。(i) 即使教师持不同意见，学生的高置信度也可能削弱纠正梯度。(ii) 依赖早期推理的 token 可能获得与简单局部续写同样弱的学习信号。为解决这一问题，我们提出轨迹丢弃（Trajectory Dropout），一种简单的训练时干预，用于暴露这些被削弱的信号。学生首先执行标准的全上下文 rollout 以生成完整轨迹。训练期间，我们随机丢弃学生推理轨迹的一定比例，而教师继续观察完整轨迹以进行 token 级监督。该干预增强了对过度自信预测的纠正，并在前缀敏感位置引入额外监督。轨迹丢弃在不同规模的教师—学生模型对以及六个数学推理基准上持续提升平均性能，同时也在两个域外基准上取得增益。它还可以灵活集成到现有 OPD 变体中，计算开销可忽略不计，并进一步提升其性能。这些结果表明，轨迹丢弃提供了一种简单机制，可在不同模型规模和 OPD 目标下增强 token 级监督。

## Abstract
On-policy distillation (OPD) trains a student model on its own trajectories using dense token-level feedback from a stronger teacher model. Since each update is conditioned on the reasoning prefix already generated by the student, the prefix also shapes how effectively teacher feedback is converted into learning. We find that shared prefixes can lead to weak token-level updates, a phenomenon we call Prefix-Induced Supervision Attenuation (PISA). This attenuation arises in two common cases. (i) High student confidence can weaken corrective gradients even when the teacher disagrees. (ii) Tokens that rely on earlier reasoning can receive learning signals as weak as those for simple local continuations. To solve this problem, we propose Trajectory Dropout, a simple training-time intervention that exposes these weakened signals. The student first performs a standard full-context rollout to generate a complete trajectory. During training, we randomly drop a certain proportion of the student's reasoning trajectory, while the teacher continues to observe the complete trajectory for token-level supervision. This intervention strengthens corrections for overconfident predictions and introduces additional supervision at prefix-sensitive positions. Trajectory Dropout consistently improves average performance across teacher--student model pairs of different scales and six mathematical reasoning benchmarks, while also yielding gains on two out-of-domain benchmarks. It can also be flexibly integrated into existing OPD variants with negligible computational overhead, further improving their performance. These results demonstrate that Trajectory Dropout provides a simple mechanism for strengthening token-level supervision across model scales and OPD objectives.

## 1. 核心问题与研究动机

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）让学生在自身生成的轨迹上接受更强教师模型的稠密 token 级反馈，以缩小训练—推理分布差距，近年成为 LLM 推理能力蒸馏的主流范式。
- **核心问题**：每次更新都以学生已生成的推理前缀为条件，**共享前缀本身会塑造教师反馈被转化为学习的效率**。作者发现，稠密监督并不等于稠密学习信号——约 70% 的受监督 token 贡献不到 0.5% 的自身 logit 信号质量。
- **关键现象（PISA）**：作者将这一现象命名为**前缀诱导的监督衰减（Prefix-Induced Supervision Attenuation, PISA）**，表现为两种机制：
  - **置信度饱和**：学生在前缀支持下对某 token 极度自信（q→1），即使教师反对，纠正梯度仍趋近于零；
  - **一致性饱和**：师生优势（advantage）接近零时，**依赖早期推理的前缀敏感预测**与**简单局部续写**被混为一谈，后者是常规续写，前者却是学习跨推理步信息传递的宝贵样本。
- **整体含义**：论文追问「共享前缀隐藏了什么」，指出全上下文视角掩盖了大量被削弱但潜在有价值的学习机会，并据此提出一种轻量的训练时干预手段。

## 2. 方法论

### 核心思想
- **分离 rollout 与训练视图**：学生先用标准全上下文自回归生成完整轨迹并保存；训练时**只改变学生更新时对自身推理历史的可见性**，而 rollout 分布与教师的全前缀监督目标保持不变。
- 教师始终在完整因果前缀上对同一批目标 token 打分，学生则在带注意力掩码的视图下重新计算自身分数。

### 关键技术细节
- **训练时 Dropout**：从完整回复中随机采样若干连续片段（默认最多 8 段），其源 token 总长占回复 token 的固定比例 ρ（默认 0.2）。这些片段构成注意力掩码 M，在一次更新内固定不变。
- **掩码规则**：对选中片段 [a, b)，目标位置 t ≥ b 的 query 不能直接关注该片段的源位置；片段内部的因果可见性保留。可选**保护窗口 w** 将边界后移至 t ≥ b + w，使接下来 w 个目标仍能访问该片段，以保留邻近预测线索。掩码在所有层与注意力头上生效。
- **训练目标**（式 4）：将 OPD 代理目标中的学生分数替换为掩码视图分数 r_θ,t，权重比 r_θ,t / r̄_θ,t 的分子分母使用同一掩码，因此比值只追踪学生自身在训练视图内的参数变化：
  - L_TD(θ) = −(1/N) Σ w^M_t(θ) · a^M_t(θ)，其中 a^M_t = sg[log p_t − log r_θ,t]。
- **理论分析**（式 5–7）：
  - 掩码优势 A^M_t = A^H_t + δ_t，其中 δ_t = log q_t − log r_t 度量对掩码的敏感度；
  - 更新差分解为两项：**学生敏感度变化** A^H_t(s^M_t − s^H_t) + **新增优势** δ_t s^M_t；
  - **强化已有纠正**：对高置信 token，定义 F_p(v) = (1−v)log(v/p)，其在 v*_p 处取唯一最大值后递减，故当 v*_{p_t} ≤ r_t < q_t < 1 时必有 C^M_t > C^H_t；
  - **区分近一致预测**：当 A^H_t = 0 时，u^M_t = δ_t s^M_t，前缀敏感位置（δ_t 显著）获得额外更新信号，而 δ_t≈0 的位置仍保持弱更新。
- **局部回归解释**（附录 F.5）：在更新起点，TD 原始更新等价于将掩码学生的 log 概率向教师 log 概率做平方回归；带优势裁剪时对应 Huber 回归。
- **符号一致性保护**（附录 F.6）：掩码导致优势符号翻转的置信度饱和 token 约占 8%，信号质量占比不足 5%；若需严格一致，可用门控 g_t = 1[A^H_t A^M_t ≥ 0] 在符号翻转时回退到全上下文 OPD 更新。

### 算法流程（文字版）

## 6. 主要结论与发现

- **性能提升**：
  - OPD 的 6 数学基准平均从 28.27 → 32.78（**+4.5 pp，相对 +15.9%**）；
  - TRD 从 18.76 → 22.68（相对 +20.9%）；Fast-OPD 从 29.48 → 33.76（相对 +14.6%）；
  - 三种方法在全部 6 个数学基准上均有提升；
  - 思考推理设置下 OPD 45.40 → 47.29（+1.89 pp，相对 +4.1%）；
  - 域外 MBPP+ 与 GPQA Diamond 亦有增益；0.6B 学生上同样呈提升趋势；Pass@k 曲线全面优于 OPD。
- **机制验证**：弱信号 token（R^I ∪ R^II）占约 74%，却仅贡献约 0.48% 的全视图信号质量；掩码后同一批 token 的信号份额升至 16–23%，绝对信号质量提升数十倍；其中一致性饱和 token 贡献约 58–66% 的净增信号。
- **稳定性条件**：ρ 从 0 增至 0.2 性能上升，之后逐渐下降，最优在 **ρ = 0.2**；单 token 掩码若不保护会严重退化，加入短保护窗口即可大幅恢复，说明**保留局部前缀连续性**是稳定训练的关键。
- **依赖强教师**：用学生自身做教师的自蒸馏不带来提升，说明教师指导与轨迹丢弃是互补的——强教师提供方向，TD 改变该指导在学生更新中的表达方式。
- **方向性而非步长性**：在严格对齐更新范数后，TD 更新对留出集师生 KL 的改善仍显著更大，且随范数近乎线性增长。

## 7. 优点

- **问题洞察新颖**：首次系统刻画「共享前缀导致监督衰减」这一被忽视的现象，用梯度质量分布与受控前缀干预把诊断做实，而非停留在直觉。
- **方法极简且即插即用**：TD 不改变 rollout 分布、不改变教师监督目标、不增加额外采样或教师前向，仅改变学生更新视图，可无缝集成到 TRD、Fast-OPD 等已有 OPD 变体。
- **开销极低**：实测仅增加 2.8% 墙钟时间，工程落地成本小。
- **理论分析完整**：给出置信度饱和的闭式纠正曲线与阈值条件、近一致区域的更新分解、局部回归/Huber 解释，以及符号翻转风险的量化与保护方案。
- **实验严谨**：范数受控配对实验与通道分解有效排除了「步长效应」和「掩码即正则」两类替代解释，论证链条完整。
- **超参与稳定性刻画到位**：给出 ρ 与 w 的敏感性曲线，指出局部前缀连续性对稳定的关键作用，并报告多随机种子结果。

## 8. 不足与局限

- **模型规模有限**：仅验证 0.6B 与 1.7B 学生，配合 4B 教师；未涉及更大规模（如 7B/70B）师生对，方法在更大模型上的可扩展性未知。
- **任务域偏窄**：核心实验集中在数学推理，域外仅 MBPP+ 与 GPQA Diamond 两个 benchmark，对通用对话、长文本、多模态、多轮场景的适用性未经验证。
- **算力与训练细节披露不足**：未报告总训练时长、总步数、各消融的算力预算，复现成本不易估计。
- **超参敏感性**：ρ 超过 0.2 后性能下降，单 token 粒度掩码若无保护会严重退化，说明方法对掩码粒度与保护窗口存在一定调参依赖，鲁棒性并非无条件。
- **理论条件的充分性而非必要性**：式 (7) 只是置信度纠正增强的充分条件；掩码可能导致优势符号翻转（约 8% 的置信度饱和 token），默认方法并不启用符号一致性保护，存在小概率方向性噪声。
- **自蒸馏无效的隐含限制**：方法收益依赖存在一个显著强于学生的教师，在没有更强监督信号或师生能力接近时可能失效。
- **潜在评测偏差**：AIME 等基准每题仅 30 题、样本量小，Avg@n 的方差可能放大微小差异；评测协议中无法解析的答案一律计错，可能对长推理模型略有不利。
- **缺乏与其他前缀/上下文扰动策略的直接对照**：论文虽与 Hide to See、上下文蒸馏等做了定性区分，但未在相同实验条件下做定量比较。

## 9. 总体评价与定位

- **贡献类型**：论文属于“现象诊断—机制解释—轻量干预—受控验证”闭环较完整的方法类工作。其核心价值不在于引入复杂新架构，而在于揭示 OPD 中一个常被忽略的更新层面事实：**共享前缀会让教师稠密监督在梯度质量上高度稀疏化**。
- **方法定位**：TD 不是新的蒸馏目标，也不是新的 rollout 策略，而是对“学生更新时能看到多少自身历史”的训练时重分配。因此它更像一种**即插即用的训练正则/信号重加权机制**，可与 TRD、Fast-OPD 等已有变体叠加。
- **证据强度**：论文对“为什么有效”的机制验证强于对“普适最优”的工程验证。受控单步分析、更新范数对齐、通道分解与弱信号 token 统计共同支持 PISA 解释；但模型规模、任务域和超参敏感性仍限制外推。
- **适用边界**：更准确的定位是：TD 适用于“**强教师—弱学生—长推理链**”场景，通过重新暴露被前缀置信度掩盖的学习机会来提升蒸馏效率；若教师不够强、师生能力接近，或任务本身不依赖长程前缀传递，收益可能有限。

## 10. 对后续研究的启示

- **规模扩展**：在 7B 以上师生对、MoE、长上下文推理模型中验证 TD 是否仍保持低开销与稳定增益。
- **任务扩展**：将方法迁移到代码生成、工具调用、多轮对话、多模态推理等更依赖长前缀依赖的任务。
- **自适应丢弃**：用 δ_t、优势符号、注意力熵等在线指标决定丢弃哪些前缀片段，替代固定 ρ 与随机连续片段。
- **与课程/数据策略结合**：探索 TD 与难度课程、教师切换、拒绝采样、过程奖励模型的协同。
- **理论深化**：将局部回归解释扩展到多步更新，分析掩码引起的优势符号翻转对收敛的长期影响。
- **公平比较**：在相同算力与数据下，与上下文蒸馏、前缀扰动、token 级过滤等策略做定量对照。
