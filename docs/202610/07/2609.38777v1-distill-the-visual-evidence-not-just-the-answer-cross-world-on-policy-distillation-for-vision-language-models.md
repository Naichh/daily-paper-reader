## 摘要
视觉语言模型（VLM）蒸馏的一个核心目标，是同时迁移教师的语言能力与视觉理解能力。然而，现有方法主要监督学生的输出，使视觉理解变得隐式。我们的分析表明，学生可以在不依赖相同视觉证据的情况下匹配教师的答案，这引出了一个问题：我们如何确保学生响应真正决定答案的视觉信息？为此，我们提出 \textbf{跨世界同策略蒸馏（CW-OPD）}，它显式监督学生对视觉证据变化的响应。对于每个样本，CW-OPD 构造两个视觉世界，它们共享问题与场景上下文，但在决定答案的关键证据上不同，从而产生不同答案。我们在两个世界中执行同策略蒸馏，并蒸馏教师的跨世界信念转移，鼓励学生不仅匹配教师预测的 \emph{什么}，还要匹配其预测随证据变化的 \emph{原因}。梯度分析表明，该项对两个世界共有的误差具有不变性，并提供了仅靠端点匹配无法看到的纠正信号。通过这种方式，CW-OPD 将对相关视觉证据的依赖变为显式的蒸馏目标，而不是输出匹配的隐式结果。为了诊断模型是否真正将其答案建立在视觉证据之上，我们引入 CWBench，它通过跨世界配对准确率（CWPA）衡量跨世界一致性。在 Qwen3.5-4B 上的实验表明，CW-OPD 平均比最强基线高出 \textbf{1.2} 分，且 4B 学生在 CWBench 上以 \textbf{22.4} CWPA 分超过 DeepSeek-V4.1（552B）。代码发布于 https://github.com/baokou-fw2/CWAD。

## Abstract
A central goal of vision-language model (VLM) distillation is to transfer both the teacher's language capabilities and its visual understanding. However, existing methods primarily supervise the student's output, leaving visual understanding implicit. Our analysis reveals that a student can match the teacher's answer without relying on the same visual evidence, raising the question: how can we ensure the student responds to the visual information that actually determines the answer? To this end, we propose \textbf{Cross-World On-Policy Distillation (CW-OPD)}, which explicitly supervises the student's response to changes in visual evidence. For each example, CW-OPD constructs two visual worlds that share the question and scene context but differ in answer-critical evidence, yielding different answers. We perform on-policy distillation in both worlds and distill the teacher's cross-world belief transition, encouraging the student to match not only \emph{what} the teacher predicts but also \emph{why} its prediction changes with the evidence. A gradient analysis shows that this term is invariant to errors shared by both worlds and supplies a corrective signal invisible to endpoint matching alone. In this way, CW-OPD makes reliance on the relevant visual evidence an explicit distillation target rather than an implicit consequence of output matching. To diagnose whether a model truly grounds its answers in visual evidence, we introduce CWBench, which measures cross-world consistency via Cross-World Pair Accuracy (CWPA). Experiments on Qwen3.5-4B show that CW-OPD outperforms the strongest baseline by \textbf{1.2} points on average, and the 4B student exceeds DeepSeek-V4.1 (552B) by \textbf{22.4} CWPA points on CWBench. Code is released in https://github.com/baokou-fw2/CWAD.

## 1. 核心问题与研究动机

- **背景**：视觉语言模型（VLM）蒸馏的目标是同时迁移教师的语言能力与视觉理解能力。当前主流做法是同策略蒸馏（OPD）——让教师对学生自己生成的轨迹给出 token 级监督，从而对齐师生状态分布、降低分布不匹配带来的噪声。
- **核心痛点**：OPD 的损失定义在**边缘预测分布**上，而非预测所依赖的视觉证据上。论文用公式指出：学生分布 $p_S(y|I,q)=\sum_z p_S(y|z,q)p_S(z|I,q)$ 中，KL 散度只要求聚合后的边缘分布匹配，**并不约束证据分布 $p_S(z|I,q)$ 本身**。因此学生可以"答对"却依赖不同的视觉线索或语言先验（linguistic shortcut）。
- **实证诊断**（图 1）：
  - **输出敏感性**：遮挡答案关键区域时，教师答案 logits 的变化远大于学生，说明学生预测对关键视觉证据依赖更弱；
  - **语义编辑世界**：构造问题与场景不变、仅答案关键证据被改写的对照世界后，教师 token 概率发生一致漂移（Welch's t=47.6, p<10⁻⁴, Cohen's d=2.13），而学生几乎不跟随；
  - 师生在交叉模态注意力上也存在明显差异。
- **现有方法的局限**：一类方法引入"特权视图"（Vision-OPD 的 ROI 裁剪、RP-OPSD 的高分辨率教师），另一类改造蒸馏目标（VGS 梯度子空间引导、FP-OPD 的 Fisher 投影、VA-OPD 的视觉优势重加权、VAD 的证据方向重构）。它们都在改善"视觉监督如何传递"，但**都未约束学生的答案究竟依赖哪部分视觉证据**。
- **整体含义**：论文把"依赖相关视觉证据"从输出匹配的**隐式副产物**，重新定义为一个**显式的蒸馏目标**。

## 2. 方法论：Cross-World On-Policy Distillation (CW-OPD)

### 2.1 核心思想
构造一对**语义对称的双世界**：共享问题与整体场景，但答案关键证据被替换，从而产生不同答案；在此之上不仅做双向同策略蒸馏（匹配"是什么"），还蒸馏教师的**跨世界信念转移**（匹配"为什么答案会随证据改变"）。

### 2.2 关键技术细节

- **双世界构造（plan–edit–verify，图 2a）**
  - VLM Planner：定位答案关键证据，选一个可通过**单点局部编辑**变为正确的干扰项，写出反事实编辑指令（严格约束：只改一个物体/属性；编辑后目标选项无歧义为真、GT 无歧义为假；拒绝不可见细节或需改变视角的重构）；
  - Image Editor（Qwen-Image-3.0）：生成编辑图 $I'$，输出 1024×1024；
  - VLM Verifier：仅当"答案翻转 $A\to B$ 且问题与非关键场景上下文保持"时接受，否则退回重写指令。
  - 形成配对 $(I,q,A)\leftrightarrow(I',q,B),\ A\neq B$。

- **双向世界匹配（端点锚定）**
  - 学生在 World A 中**只 rollout 一次**，生成的 prefix $\tau_{<t}$ 在两个世界间**共享**，因此两个 next-token 分布的差异仅来自视觉证据；
  - 逐 token 计算两世界的反向 KL：
    $\mathcal{L}_{world}=\frac{1}{T}\sum_t\big[D_{KL}(p^A_S\|p^A_T)+D_{KL}(p^B_S\|p^B_T)\big]$。

- **跨世界转移蒸馏（核心创新）**
  - 定义每 token 的对数似然比 $\Delta_S=\log p^A_S-\log p^B_S$，$\Delta_T=\log p^A_T-\log p^B_T$；
  - 用 softmax 归一化后做 KL：$\mathcal{L}_{trans}=\frac{1}{T}\sum_t D_{KL}(\mathrm{softmax}(\Delta_S)\|\mathrm{softmax}(\Delta_T))$；
  - $\mathrm{softmax}(\Delta_S)\propto p^A_S/p^B_S$ 表示视觉干预诱导的**相对优势比**，同时刻画信念变化的方向与幅度。
  - 总目标：$\mathcal{L}_{CW\text{-}OPD}=\mathcal{L}_{world}+\lambda\mathcal{L}_{trans}$（主实验 $\lambda=1.0$）。

- **理论分析（第 3.3 节，Proposition 1）**
  - 将各世界 Jacobian 拆为共模部分 $\bar{J}=(J_A+J_B)/2$ 与图像相关部分 $J_\Delta=J_A-J_B$，得到
    $\nabla_\theta \ell_E=\bar{J}^\top(\varepsilon_A+\varepsilon_B)+\frac12 J_\Delta^\top(\varepsilon_A-\varepsilon_B)$，而 $\nabla_\theta \ell_T=J_\Delta^\top F(r_S)(d_S-d_T)$；
  - **共模拒绝（common-mode rejection）**：(i) 给两世界教师 logits 加同一向量 $b$ 不改变 $\ell_T$，但会改变 $\ell_E$；(ii) 任何让两个世界同向移动的参数方向，转移梯度为零；
  - 在端点驻点 $\nabla E=0$ 处，沿转移梯度走一步可使 $T$ 一阶下降，而 $E$ 仅二阶变化——说明转移监督提供了端点匹配"看不见"的纠正信号；
  - 因此**保留视觉编码器可训练**，以保证存在使两世界响应不同的参数方向。

## 3. 实验设计

- **训练数据**：CWBench 训练集，2,365 对双世界样本（源自 VLM-CapCurriculum Perception、ZwZ-RL-VQA、Visual7W、Vision-OPD 数据集），由 plan–edit–verify 流水线构造。
- **评测 Benchmark**：
  - **CWBench 评测集**（594 对），指标为 **CWPA**（跨世界配对准确率，要求两世界同时答对）与 **CWFR**（flip rate，$A_{Acc}+B_{Acc}-2\,CWPA$，衡量两世界正确性不一致的比例）；另报告 **CWPA-Q**（把问题换成与编辑区域无关的问题，检验模型是否选择性跟随问题而非盲目跟随视觉编辑）。
  - **七个标准基准**：V*Bench、HR-Bench 4K、RealWorldQA、MMVP（视觉感知与 grounding）；POPE、HallusionBench（幻觉诊断）；SEED-Bench、OK-VQA（外部知识推理）。Avg. 为七项无权重平均。
- **学生模型**：Qwen3.5-0.8B、Qwen3.5-4B。
- **教师设置**：主实验基于 OPSD（EMA 自蒸馏教师 + 基模型生成的短答案提示作为教师侧特权输入）；附录 D 另给出标准大教师设定（Qwen3.5-9B → 4B）。
- **对比方法**：Base、SFT、GRPO、OPD、OPSD，以及 Vision-OPD、RP-OPSD、VAD、VA-OPD、FP-OPD、VGS 等代表性多模态蒸馏方法，全部在 CWBench 训练集与统一训练配置下重训。
- **前沿模型对比**：在 CWBench 上与 Kimi-K3 (2.8T)、DeepSeek-V4.1 (552B)、Qwen3.8 (27B) 比较 CWPA/CWFR/CWPA-Q。
