## 摘要
同策略蒸馏（OPD）利用自身生成的轨迹训练学生模型，但在长推理轨迹上传输稠密的教师分布会造成难以承受的通信与内存瓶颈。因此，实际系统依赖稀疏教师接口，通常只传输采样词元得分或一个小型 Top-$k$ 分布。然而，这种稀疏设置面临一个根本性两难：采样词元估计器是无偏的，但会遭受严重的梯度方差；而直接优化 Top-$k$ 目标则会引入系统性偏差。为改善这一权衡，我们提出 ResOPD（带尾部残差化的同策略蒸馏），它在同策略采样下提供无偏的全词表反向 KL 梯度估计，并在所评估的设置中、在相同稀疏载荷下实现显著的方差降低。ResOPD 将未观测词表聚合为一个可观测的粗粒度尾部事件，计算其精确的聚合梯度，并仅采样细粒度的尾部内残差，且无需额外的教师查询或前向传播。大量实验表明，ResOPD 显著降低梯度方差、稳定在线训练动态，并在所评估的设置中提升下游性能。这些结果确立了 ResOPD 作为一种高效、即插即用的方差缩减原语，适用于稀疏同策略蒸馏。

## Abstract
On-policy distillation (OPD) trains a student model on self-generated trajectories, but transmitting dense teacher distributions across long reasoning traces creates prohibitive communication and memory bottlenecks. Practical systems therefore rely on sparse teacher interfaces, typically transmitting either the sampled-token score or a small Top-$k$ distribution. However, this sparse setting faces a fundamental dilemma: sampled-token estimators are unbiased but suffer from severe gradient variance, whereas directly optimizing Top-$k$ objectives introduces systematic bias. To improve this trade-off, we propose ResOPD (On-Policy Distillation with Tail Residualization), which provides unbiased full-vocabulary reverse KL gradient estimation under on-policy sampling, with substantial variance reduction under the same sparse payload in the evaluated settings. ResOPD aggregates the unobserved vocabulary into an observable coarse tail event, computes its exact aggregate gradient, and samples only the fine-grained within-tail residual, which requires no additional teacher queries or forward passes. Extensive experiments demonstrate that ResOPD substantially reduces gradient variance, stabilizes online training dynamics, and improves downstream performance across the evaluated settings. These results establish ResOPD as an efficient, plug-and-play variance reduction primitive for sparse on-policy distillation.

## 1. 核心问题与整体含义

- **研究背景**：同策略蒸馏（On-Policy Distillation, OPD）让学生在自生成轨迹上接受教师模型的 token 级监督，可缓解长序列中的 exposure bias，已成为 LLM 后训练的重要步骤。
- **核心瓶颈**：标准 OPD 需要教师模型在每个生成 token 上提供全词表分布；现代 LLM 词表可达约 250K，长推理链下通信与显存开销巨大。
- **现实折中**：实际系统采用稀疏教师接口，只传 Top-$k$ token 概率及采样 token 分数，其余尾部不可观测。
- **两难问题**：
  - 采样 token 估计器无偏，但单样本 Monte Carlo 导致梯度方差极大。
  - 直接优化 Top-$k$ 反向 KL 目标，如截断、重归一化、停止系数等，虽确定性强，但相对全词表 rKL 有系统性偏差。
- **论文定位**：提出 ResOPD（Tail Residualization for Sparse On-Policy Distillation），在相同稀疏载荷下实现全词表反向 KL 梯度的无偏估计，并显著降低方差；无需额外教师查询或前向传播，可作为即插即用组件。

## 2. 方法论

### 2.1 问题建模与全词表 rKL 梯度

- 固定轨迹前缀，设学生概率 $p_i$、教师概率 $q_i$，定义
  - $r_i=\log(p_i/q_i)$
  - $s_i=\nabla_\theta \log p_i$
  - $G_i=r_i s_i$
- 全词表反向 KL 梯度为：
  - $g=\sum_i p_i G_i=\mathbb{E}_{A\sim p}[G_A]$
- 因此，采样 token 梯度 $G_A$ 是无偏估计，但方差大。

### 2.2 稀疏 Top-$k$ 的偏差与 HETS 基线

- 设教师 Top-$k$ 支持为 $S$，$P=\sum_{i\in S}p_i$，$Q=\sum_{i\in S}q_i$，$\tau_p=1-P$，$\tau_q=1-Q$。
- 头部梯度可精确计算：
  - $h=\sum_{i\in S}p_i G_i$
- 尾部真实均值梯度不可得：
  - $\mu_{\text{tail}}=\mathbb{E}[G_A|A\notin S]$
- HETS（Head-Exact Tail-Sampled）估计器：
  - $\hat g_{\text{HETS}}=h+J G_A$，其中 $J=\mathbb{I}\{A\notin S\}$
  - 无偏，但每次尾部命中都需补偿整个被省略尾部质量，造成梯度尖峰。

### 2.3 ResOPD：尾部残差化

- 利用 Top-$k$ 同时暴露的尾部聚合质量，构造粗粒度伪 token：
  - $b=\log(\tau_p/\tau_q)$
  - $\bar s_{\text{tail}}=\nabla_\theta \log \tau_p$
  - $\mu_B=b\bar s_{\text{tail}}$
- 粗粒度完整分布的精确梯度为：
  - $g_{\text{coarse}}=h+\tau_p \mu_B$
- ResOPD 估计器：
  - $\hat g_{\text{ResOPD}}=g_{\text{coarse}}+J(G_A-\mu_B)$
- 一般化单控制形式：
  - $\hat g(B)=h+\tau_p B+J(G_A-B)$
  - 对任意前缀可测、停止梯度的 $B$ 均无偏。
- 方差分解：
  - $\mathcal V(\hat g(B))=\tau_p\mathcal V_{\text{tail}}(G_A)+P\tau_p\|\mu_{\text{tail}}-B\|_2^2$
  - 第一项与 $B$ 无关；第二项为头部/尾部事件间方差。
  - 最优 $B=\mu_{\text{tail}}$，但不可得；ResOPD 用 $\mu_B$ 替代。
  - 当 $\mu_B$ 比零向量更接近 $\mu_{\text{tail}}$ 时，ResOPD 方差严格低于 HETS。

### 2.4 两控制族与 SC-TA 关系

- 引入尾部内零均值波动：
  - $C_A=b(s_A-\bar s_{\text{tail}})$
- 统一两控制估计器：
  - $\hat g(B,\gamma)=h+\tau_p B+J(G_A-B-\gamma C_A)$
- 方差分解：
  - $\mathcal V(\hat g(B,\gamma))=\tau_p\mathcal V_{\text{tail}}(G_A-\gamma C_A)+P\tau_p\|\mu_{\text{tail}}-B\|_2^2$
- 特殊情形：
  - HETS：$B=0,\gamma=0$
  - ResOPD：$B=\mu_B,\gamma=0$
  - SC-TA：$B=\mu_B,\gamma=1$
  - 联合 oracle：$B=\mu_{\text{tail}},\gamma=\gamma^\star$
- 论文给出 SC-TA 与 ResOPD 的方差排序条件：SC-TA 在期望上可更低方差，但排序依赖前缀分布，不是全局必然。

### 2.5 采样假设与在线诊断

- 无偏性假设 $A\sim p_\theta$，即 ancestral on-policy sampling。
- 实际数学主实验使用 temperature 1.0、top-$p=0.95$、top-$k=20$，会改变采样律；但学生概率等训练量通过 fresh untruncated forward 重算，截断仅限生成阶段。
- 在线诊断使用残差二阶矩 $M_2$，衡量头部/尾部事件噪声，作为轻量机制对齐指标，而非完整协方差估计。
