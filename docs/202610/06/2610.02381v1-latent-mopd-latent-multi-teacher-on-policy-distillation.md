## 摘要
同策略蒸馏（OPD）利用学生模型自身生成的回答来训练学生。现有的 LLM 多教师 OPD 通过专家模型的输出分布来迁移其预测内容。我们提出 Latent-MOPD，据我们所知，这是首个面向 LLM 的表征级多教师 OPD 方法。它无需额外训练教师，即可通过现有专家模型的预测以及用于计算这些预测的隐藏状态来整合这些专家。为了协调来自多个专家的表征监督，我们根据教师-学生关系选择后层目标，用共享投影弥合不同的隐藏维度，并按领域对更新进行分组。每个教师的监督逐渐从隐藏状态转向 token 预测，两个通道均使用同一个被路由到的专家。在我们主要的同家族设置中，Latent-MOPD 在数学、代码和逻辑的九个基准上均优于仅 token、仅表征和均匀平均基线。在与每个教师参数量相同的情况下，学生模型在大多数这些基准上也超过了各基准上的最佳教师。在采用更大且单独开发的跨家族教师时，Latent-MOPD 在所有基准上均优于两个单通道基线。同家族的全层仅表征对照在领域纯净更新下保持稳定，但当教师领域在一次更新中交错时会发生崩溃。我们的结果表明，单个学生模型能够通过多个专家的输出分布和内部表征来整合其能力。

## Abstract
On-policy distillation (OPD) trains a student on the responses it generates. Existing LLM multi-teacher OPD transfers what specialists predict through their output distributions. We introduce Latent-MOPD, to our knowledge the first representation-level multi-teacher OPD method for LLMs. It integrates existing specialists through both their predictions and the hidden states used to compute them, without additional teacher training. To coordinate representation supervision from multiple specialists, we select late-layer targets according to the teacher-student relationship, bridge unequal hidden widths with a shared projection, and group updates by domain. Each teacher's supervision gradually shifts from hidden states to token predictions, with both channels using the same routed specialist. In our main same-family setting, Latent-MOPD outperforms the token-only, representation-only and uniform-averaging baselines on all nine benchmarks across math, code and logic. With the same parameter count as each teacher, the student also surpasses the per-benchmark best teacher on a majority of these benchmarks. With larger, separately developed cross-family teachers, Latent-MOPD outperforms both single-channel baselines on all benchmarks. A same-family all-layer representation-only control remains stable with domain-pure updates but collapses when teacher domains are interleaved within an update. Our results show that a single student can integrate capabilities from several specialists through both their output distributions and internal representations.

# Latent-MOPD 论文总结

## 1. 核心问题与研究背景

- **研究动机**：强化学习（RL）已能产出在数学、代码、逻辑等单一领域表现突出的专家模型，但如何复用这些已有专家、训练出一个具备多领域能力的**单一学生模型**仍是开放问题。
- **现有方法及其局限**：
  - 多教师同策略蒸馏（MOPD, Ma et al., 2026）将学生自生成回答按领域路由到对应教师，教师对学生 token 打分，提供**输出分布层面**的稠密监督。
  - 但输出预测只是内部计算的结果。可解释性研究（Lindsey et al., 2025; Gurnee et al., 2026）表明隐藏表征承载未被言语化的中间推理步骤并因果影响后续计算，即隐含了教师**"如何算"**的信息。
  - 表征级 OPD（LastOPD、OPRD）已验证隐藏状态监督可提升单教师迁移，但**多教师场景面临新挑战**：多个不同专家的表征目标如何选择、如何组织以共同训练同一学生骨干。
- **两个关键诊断（驱动方法设计）**：
  - **目标层选择**：同家族教师与基础学生在多数层 CKA 很高，仅在接近输出处差异变大；跨家族则在**中间层出现显著相似度低谷**（第 13 块最低约 0.116–0.124）。说明层选择需依师生关系而定。
  - **监督组织方式**：同家族全层仅表征对照中，若一个优化步内混合多个教师领域（interleaved），训练在 20 步内崩溃（MATH-500 降至 22.8）；**领域纯净批次**（domain-pure）则稳定收敛（91.7）。
- **整体含义**：论文主张单一学生可通过"输出分布 + 内部表征"双通道整合多个专家能力，且表征监督应作为**瞬态信号**（crossfade 调度）而非持续目标。

## 2. 方法论

### 核心思想
- 将 N 个冻结教师 {π_Ti} 蒸馏进一个学生 π_θ。每条 prompt 带领域标签 d ∈ {math, code, logic}，**token 通道与表征通道共用同一个被路由到的专家**。
- 教师全程冻结；投影映射仅在训练时存在，**推理只用学生**。

### 关键技术细节

- **领域路由的 token 通道（MOPD-style 扩展）**：
  - 不使用均匀平均教师分布（会稀释专家的高置信预测），而是按领域选单一教师 p_{Td,t}。
  - 在学生自采样回答的每个位置，取学生分布 top-k（k=16）候选，用**师生全词表 log 概率比**构造奖励：
    - 候选权重 w_{t,v} 在 top-k 支撑集内重归一化，而两个 log 概率保持全词表归一化；
    - r_{t,v} = −w_{t,v}[log p̄_t(v) − log p_{T,t}(v)]；
    - 按领域内 masked 标准差缩放得固定优势 A_{t,v} = r_{t,v}/σ_d（不减均值，不反向传播）。
  - 损失为策略梯度代理：L^route_OPD = −(1/|M|)Σ_t Σ_{v∈V_k,t} sg[A_{t,v}] log p_{θ,t}(v)。

- **选择性后层表征对齐**：
  - 同家族：对齐**最后 3 层**（层消融支持），映射 g_ψ 为**恒等映射**；隐藏宽度相同。
  - 跨家族：对齐**最后一层**（宽度不匹配，d_S=1536 → d_T=3584），用**共享的可训练线性映射**，由域路由的师生状态对做岭回归初始化 W = (SᵀS + λ_r I)⁻¹SᵀT；另有 MLP 变体（1536→6144→3584，GELU）。
  - 每个 token 位置的加权惩罚：ℓ^route_rep,t = (λ/d_T)‖ν(g_ψ(z^S_t)) − sg[ν(z^Td_t)]‖²₂，其中 ν 为 ℓ2 归一化，目标侧 stop-gradient。
  - **归约规则**：每个选定层在选定 token 位置上取掩码均值，再对层取等权平均——因此选 3 层**不会**把表征权重放大 3 倍。
  - 同家族在所有回答位置对齐；跨家族只取**最后 min(2000, |M_b|) 个有效位置**。
  - 存储代价：选 3/28 层使选定状态存储减少约 89.3%（16,384 位置、BF16 宽度 1536 时，2.63 GiB → 0.28 GiB；仅为解析计数，非实测峰值显存）。

- **per-teacher crossfade 调度（核心创新）**：
  - 采用 LastOPD 的 crossfade 形式：token 权重 α(u)=min(1, u/T_w) 上升，表征权重 β(u)=max(0, 1−u/T_w) 衰减。
  - 关键：**每个教师有自己的更新时钟**——u 只统计当前活跃教师已完成的更新数，领域纯净批次按 math–code–logic 轮转，只有活跃教师的计数器前进。
  - 同家族 T_w = 10 每教师步（覆盖 62 步中的 30 步）；跨家族 T_w = 7（覆盖 21 步）。
  - 系数 λ 固定：同家族 λ=1，跨家族 λ=2000；不做运行时损失份额归一化。

- **参数合并初始化（可选）**：同家族教师权重均匀平均得"model soup"，再用相同配方蒸馏 62 步。

### 算法流程（文字版）
1. 采样领域纯净的 prompt 批次（32 条，4 条回答/prompt）；
2. 学生生成回答，路由到的教师对回答打分；
3. 同时计算 token 通道损失（top-16 固定优势 PG）与表征通道损失（选定后层隐藏状态，归一化 + 投影 + stop-grad 目标）；
4. 用 (α(u), β(u)) 加权求和，反向更新学生（跨家族同时更新共享映射），教师冻结；
5. 更新后仅活跃教师的计数器 u 递增，按 math→code→logic 轮转。
