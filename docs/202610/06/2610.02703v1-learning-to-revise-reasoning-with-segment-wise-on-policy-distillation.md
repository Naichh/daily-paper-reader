## 摘要
在线策略蒸馏（OPD）通过在学生模型自身的 rollout 上利用教师模型提供的密集 token 级监督进行训练，从而提升大语言模型的推理能力。然而，token 级 OPD 并未显式提供连贯的替代推理步骤，以表明如何修正学生的步骤来改进后续推理。此外，当学生产生退化的推理前缀时，该范式可能变得不那么有效，因为后续教师监督仍以该前缀为条件，并可能强化不良推理模式。在这项工作中，我们聚焦于利用片段级 OPD 学习推理修正，以重写中间推理步骤并更好地支持后续推理。通过受控的推理干预，我们发现用教师重写稿替换学生片段可以提高后续推理准确率。因此，我们解决如何将教师重写稿转化为用于学习修正推理的显式监督这一问题。我们提出片段级在线策略蒸馏（Seg-OPD），它基于不确定性度量选择学生片段，并获取相应的教师重写稿。Seg-OPD 训练学生模型偏好教师重写稿而非其成对的学生片段，同时保留密集的 token 级 OPD 监督。在数学推理和竞赛编程任务上的大量实验表明，经 Seg-OPD 训练的学生模型比基线取得更高的修正成功率。Seg-OPD 在推理准确率上持续优于所比较的最先进基线，在不同模型和任务上平均相对提升 5.22%。代码可在 https://anonymous.4open.science/r/Seg-OPD 获取。

## Abstract
On-policy distillation (OPD) improves large language model reasoning by training students on their own rollouts with dense token-wise supervision from the teacher. However, token-wise OPD does not explicitly provide a coherent alternative reasoning step showing how the student's step could be revised to improve subsequent reasoning. Furthermore, this paradigm can become less effective when the student produces a degenerate reasoning prefix, as subsequent teacher supervision remains conditioned on that prefix and may reinforce poor reasoning patterns. In this work, we focus on learning reasoning revision with segment-wise OPD to rework intermediate reasoning steps and better support subsequent reasoning. Through controlled reasoning interventions, we find that replacing student segments with teacher redrafts improves subsequent reasoning accuracy. Therefore, we address the problem of turning teacher redrafts into explicit supervision for learning to revise reasoning. We propose Segment-wise On-Policy Distillation (Seg-OPD), which selects student segments based on an uncertainty metric and obtains corresponding teacher redrafts. Seg-OPD trains the student to prefer teacher redrafts over their paired student segments while retaining dense token-wise OPD supervision. Extensive experiments on mathematical reasoning and competitive programming tasks show that Seg-OPD-trained students achieve higher revision success rates than baselines. Seg-OPD consistently outperforms the compared state-of-the-art baselines in reasoning accuracy with an average relative improvement of 5.22% across diverse models and tasks. Code is available at https://anonymous.4open.science/r/Seg-OPD.

# 论文总结：Learning to Revise Reasoning with Segment-wise On-Policy Distillation（Seg-OPD）

## 1. 核心问题与研究动机

- **背景**：在线策略蒸馏（On-Policy Distillation, OPD）是 LLM 后训练的有效范式——学生模型基于自身 rollout 生成推理轨迹，由更强的教师模型提供密集的 token 级监督，兼具 SFT 的密集监督与 RL 的在线探索优势，可缓解 SFT 的分布偏移和结果型 RL 的稀疏奖励问题。
- **两大固有缺陷**：
  - **局部性**：token 级 OPD 只提供逐 token 的局部修正，从未显式展示一个跨多 token 的连贯替代推理步骤，学生难以理解"整个步骤应如何改写"。
  - **退化前缀强化**：由于自回归特性，后续推理以已有前缀为条件。当学生产生退化前缀（如重复循环）时，教师监督仍基于该前缀，可能反而偏好无产出的续写，进一步强化错误推理模式。
- **核心思路**：将"推理修正"（reasoning revision）——即重写中间推理步骤以更好地支持后续推理——作为显式学习目标。给定前缀 q 和学生片段 s，教师提供连贯重写稿 r，既保留暴露学生当前问题模式的 on-policy 上下文，又提供可重定向后续推理的替代路径。
- **两大挑战**：(i) 教师重写代价高，如何用有限预算选择值得修正的学生片段；(ii) 如何在利用"学生片段–教师重写"对应关系的同时，保留使 OPD 有效的密集 token 级监督。

## 2. 方法论

### 2.1 核心思想
将教师重写稿转化为显式修正监督：基于不确定性选择学生片段 → 获取教师重写稿 → 训练学生偏好重写稿而非其自身片段，同时在其余 token 上保留 token 级 OPD。

### 2.2 关键技术细节

**（1）修正单元构造（Revision Unit）**
- **片段选择**：
  - 仅在以错误结果结尾的 rollout 上构造候选片段。
  - 计算每个位置的预测熵 \(H_t = -\sum_{v} \pi_\theta(v|q_t)\log\pi_\theta(v|q_t)\)，取熵最大位置为 pivot 锚点。
  - 将锚点向两侧扩展至句号标记的句子边界，形成候选片段 \(s_i\)。
  - 用分层不确定性评分 \(U(s_i) = \frac{1}{|s_i|}\sum_t H_t - \delta_i\)（平均熵减去片段内熵的标准差），贪心按分数降序选至多 K 个不重叠片段。
- **教师重写**：将前缀 q 与学生片段 s 一并给教师，提示其从 q 之后重写 s 并继续推理；取生成的**首个句子**作为重写稿 r（仅当整篇草稿通过任务正确性校验）；r 与 q、s 构成修正单元 \(p=(q,s,r)\)。

**（2）推理修正学习目标**
- **片段级偏好损失**：借鉴 DPO 的 Bradley–Terry 形式，定义修正边际
  \[
  m_{\pi_\theta}(p)=\frac{|s|+|r|}{2}\left[\frac{1}{|r|}\log\frac{\pi_\theta(r|q)}{\pi_{ref}(r|q)}-\frac{1}{|s|}\log\frac{\pi_\theta(s|q)}{\pi_{ref}(s|q)}\right]
  \]
  即长度归一化后的对数概率差再按平均长度缩放。损失为 \(L_s(\theta)=-\frac{1}{N}\sum_i\log\sigma(\beta m_{\pi_\theta}(p_i))\)。
- **token 级蒸馏**：对落在已用片段内的 token 置掩码 \(M_t=0\)，其余位置保留 token 级 OPD 损失 \(L_t(\theta)=\mathbb{E}\sum_t M_t D_{KL}(\pi_\theta\|\pi^*)\)。
- **联合优化**：\(\theta^*=\arg\min_\theta L_t(\theta)+\lambda L_s(\theta)\)。

**（3）算法流程**（Algorithm 1）
选片段 → 构造接受的修正单元 → 计算修正边际 → 计算 \(L_s\) 与 \(L_t\) → 更新 θ → 重采样 rollout 重新选片段（教师与参考策略固定；无接受单元时 \(L_s=0\)）。

### 2.3 前期实证支撑（Sec. 3）
- 用教师重写替换学生片段，可提升初始与 OPD 训练学生的后续推理准确率（Fig. 2a）。
- 相比随机锚点，pivot（高熵）锚点在相同位置带来更高推理准确率与更高修正成功率（RSR）（Fig. 2b）。

- **训练数据集**：数学推理用 DeepMath-103K（过滤后 57,046 题）；竞赛编程用 Eurus-RL-Code（过滤后 25,276 题）。
- **评测 Benchmark**：

## 6. 主要结论与发现

- Seg-OPD 在全部模型与数据集上平均相对提升 **5.22%**；如 DeepSeek-1.5B 在 AIME24 上较 OPD 提升 8.24%，较 OmniOPD 提升 8.83%。
- 训练后的学生取得**更高 RSR**（如 Qwen3-8B 在 HumanEval+ 上 RSR 峰值 70.0% vs OPD 44.6%，教师为 75.0%）与**更低 loop rate**（如 Qwen3-4B 在 AIME25 上 15.6% vs OPD 24.0%）。
- 在平均响应长度相近时，Seg-OPD 取得更高最终准确率。
- 消融显示：pivot 锚点优于随机锚点；针对学生推理的教师重写优于仅从前缀续写；偏好学习优于直接 SFT 模仿重写稿。
- 超参数：λ 过大（=2）或 K 过大（=3）均损害稳定性，需在修正监督与 token 级蒸馏间平衡。
- 句号边界规则整体最优；训练动态上，偏好损失梯度范数普遍小于 SFT，且 Seg-OPD 后期策略熵高于 SFT 变体。

## 7. 优点

- **问题定位清晰**：准确指出 token 级 OPD 的"局部性"与"退化前缀强化"两大缺陷，并给出可验证的实证证据。
- **方法设计合理**：将教师重写作为显式修正监督，用分层不确定性（均值熵 − 熵离散度）兼顾"锚点高熵"与"整段高不确定性"，避免单点高熵误选；用句子边界保证片段与重写稿的语义完整性。
- **损失设计精细**：长度归一化 + 平均长度缩放，缓解 DPO 类目标对长度偏差的敏感性；保留 token 级 OPD 以稳定训练，并用掩码避免与片段偏好损失冲突。
- **实验覆盖较全面**：跨 4 个模型规模、数学与代码两大领域、8 个 benchmark，含消融、超参、边界规则、训练动态、行为指标与案例研究。
- **成本可控**：相比 OmniOPD（3.39–3.89× OPD），Seg-OPD 仅约 1.73–1.93× OPD 训练时间。
- **未来方向有洞见**：提出片段级偏好监督不依赖教师 logits，可扩展至多教师与黑盒教师场景。
