## 摘要
在前沿语言模型后训练中，将多个从同一基础检查点开始训练的专家模型的能力组合起来已变得越来越常见。近期趋势表明，多教师同策略蒸馏（MOPD）优于传统的异策略方法。然而，尽管 MOPD 带来了更高的推理和环境交互成本，我们发现其报告的大部分准确率提升源于某些训练设计选择和超参数优化，而非算法本身。我们在两种多教师设置、四个模型和十一个基准上进行了受控自蒸馏研究，将异策略方法，即监督微调（SFT）和软标签蒸馏，与混合教师前缀蒸馏和 MOPD 进行比较。我们发现，这四种方法达到了几乎相同的准确率。然而，MOPD 的训练 GPU 小时数是 SFT 的 14.8--23.1 倍。我们还重新审视了最近发表的四项同策略与异策略蒸馏之间的比较，并发现当 SFT 基线在拒绝采样的教师轨迹上训练并使用独立调优的超参数时，所报告的同策略增益会大幅缩小。作为一种免训练替代方案，我们还发现，简单的权重合并方法可以在几分钟的 CPU 合并时间内恢复专家能力，尽管随着模型规模减小和任务干扰增加，其准确率会下降。总体而言，我们的结果对近期因 MOPD 而报告的增益提出了质疑，并表明仔细调优更高效的异策略基线是一种可行的替代方案。

## Abstract
Combining capabilities of multiple expert models trained starting from the same base checkpoint has become increasingly common in frontier language-model post-training. Recent trends suggest that multi-teacher on-policy distillation (MOPD) outperforms conventional off-policy methods. However, despite the higher inference and environment interaction costs incurred by MOPD, we find that much of its reported accuracy gain is due to certain training design choices and hyperparameter optimization, rather than the algorithm itself. We conduct a controlled self-distillation study across two multi-teacher settings, four models, and eleven benchmarks, comparing off-policy methods, namely supervised fine-tuning (SFT) and soft-label distillation, to hybrid teacher-prefix distillation and MOPD. We found that all four methods achieve \textit{nearly identical} accuracy. However, MOPD uses $14.8$--$23.1\times$ SFT's training GPU-hours. We also revisit four recently published comparisons between on-policy and off-policy distillation and find that the reported on-policy gains shrink substantially when SFT baselines are trained on rejection-sampled teacher trajectories and use independently tuned hyperparameters. As a training-free alternative, we also find that simple weight-merging methods can recover expert capabilities with minutes of CPU merging time, although their accuracy degrades as model size decreases and task interference increases. Overall, our results question recent gains reported due to MOPD and suggest careful tuning of more efficient off-policy baselines as a viable alternative.

# 论文总结：Rethinking Self-Distillation for Multi-Teacher Capability Merging

## 1. 核心问题与研究动机

- **背景**：前沿 LLM 后训练日益将能力开发分解为领域专家训练（数学、指令跟随、Agent 任务等），各专家从同一基础检查点（base checkpoint）出发独立 RL 训练，再将能力合并回一个通用学生模型，这一过程称为**自蒸馏（self-distillation）**。
- **核心争议**：近期趋势认为**多教师同策略蒸馏（MOPD）**优于传统异策略方法，并被 GLM-5、DeepSeek-V4、Kimi K3 等采用；而 MAI-Thinking-1、Step 3.5 Flash 则采用异策略 SFT。
- **关键问题**：MOPD 需要学生反复生成与教师打分，Agent 任务还需实时环境交互，成本远高于异策略方法。但此前缺乏受控对比，无法确认其报告的准确率增益究竟来自**算法本身**，还是来自**训练设计选择与超参数优化**。
- **研究目标**：在共享初始化、统一数据、独立调参的受控条件下，回答"将多个专家能力整合进单一通用模型的最有效方式是什么"。

## 2. 方法论

### 2.1 核心思想
在**共享初始化**（学生与所有教师均从同一 base checkpoint 出发）的前提下，对四类自蒸馏目标进行公平对比，并额外考察免训练的权重合并方案。

### 2.2 四种蒸馏目标
设 $s$ 为 token 上下文（任务提示、交互历史、当前响应前缀），教师与学生 next-token 分布分别为 $\pi_d(\cdot|s)$ 与 $\pi_\theta(\cdot|s)$，损失仅作用于 assistant token：

- **SFT（异策略）**：对教师录制的 token $a$ 做负对数似然 $\ell_{\text{SFT}} = -\log \pi_\theta(a|s)$。
- **Soft-KD（异策略）**：在相同教师上下文上，最小化前向 KL $\ell_{\text{FKL}} = D_{\text{KL}}(\pi_d \| \pi_\theta)$，利用完整教师分布。
- **Offline-MOPD（混合）**：固定提示与教师交互历史，采样学生响应前缀，最小化反向 KL $\ell_{\text{RKL}} = D_{\text{KL}}(\pi_\theta \| \pi_d)$；多轮任务**不执行**学生动作、不获取新环境观测。
- **MOPD（同策略）**：对完整学生轨迹施加同一反向 KL，目标为
  $$L_{\text{MOPD}}(\theta;\bar\theta)=\sum_{d=1}^{K} w_d \mathbb{E}_{x\sim\hat P_d,\ \tau\sim p^{\bar\theta}_d}\Big[\tfrac{1}{|\tau|}\sum_{t=1}^{|\tau|}\ell_{\text{RKL}}(\theta;d,s_t)\Big]$$
  多轮任务需实时执行学生动作并接收环境反馈。

### 2.3 免训练权重合并
以任务算术为代表：$\theta_{\text{merge}} = \theta_0 + \sum_{d=1}^{K} c_d \Delta\theta_d$，其中 $\Delta\theta_d = \theta_d - \theta_0$，系数 $c_d$ 与稀疏化由合并方法决定。

### 2.4 评估指标
- **恢复率** $\text{Rec}(\pi;B)=100\cdot \frac{\sum_{b\in B}\Delta_b(\pi)}{\sum_{b\in B}\Delta_b^\star}$：ID 基准上恢复教师聚合增益的百分比。
- **保留率** $\text{Ret}(\pi;B)=\frac{1}{|B|}\sum_{b\in B}\Delta_b(\pi)$：OOD 基准上相对 base 的平均分数变化（负值表示退化）。

### 2.5 理论分析（附录 E）
命题 E.1 证明：轨迹级损失满足 $L_{\text{off}}=D_{\text{KL}}(P_T\|P_\theta)$、$L_{\text{on}}=D_{\text{KL}}(P_\theta\|P_T)$；对任意 $[0,1]$ 统计量 $F$，成功概率差被总变差上界约束，进而由三种损失的平方根界定；并给出前向/反向 KL 在教师-学生概率比有界时的双向夹逼关系，说明在自蒸馏（教师可由学生实现）下三类损失均可趋近于零。

## 6. 主要结论与发现

1. **无一致的同策略优势**：四种蒸馏方法 ID 恢复率差异极小——MIA 上最大跨度 3.5 个百分点，Agent ×3 上 4.6 个百分点；Qwen3-8B 上四者分别恢复 96.9–98.2%（MIA）与 97.6–99.3%（Agent ×3）。
2. **成本差距巨大**：MOPD 训练 GPU 小时为 SFT 的 14.8×（MIA）与 23.1×（Agent ×3）。
3. **已发表增益可被更强 SFT 基线大幅缩小**：独立调参 + 拒绝采样数据后，SFT 相对提升 1.3–6.9 个百分点；RS SFT 在 Open-MOPD 上反超 OPD 0.9 分，在 TCOD 上领先 12.1 分，在 ReOPD 上领先 3.6 分，仅在 SKD 上落后 3.0 分。
4. **更大教师不利于 MOPD**：8B 教师 + 1.7B 学生时，Agent ×3 上 SFT 恢复 99.3%、Soft-KD 93.0%，而 Offline-MOPD 仅 78.9%、MOPD 仅 73.3%；但 SFT/Soft-KD 的 OOD 退化更严重（5.4→14.8 与 4.1→11.7）。
5. **免训练合并可行但受限**：Qwen3-8B 平均恢复 99.0%，Qwen3-1.7B 仅 87.3%；MIA（能力不重叠）平均 96.6%，Agent ×3（能力重叠）仅 87.9%。
6. **行为差异不反映在分数上**：所有方法注意力权重相对变化 <0.7%；蒸馏在 MIA 上缩短响应 23–29%，在 Agent ×3 上拉长 22–67%，MOPD 变化最大；合并分别增加 3% 与 23%。
7. **拒绝采样对异策略方法收益更大**：SFT 恢复差距 6.5/7.0 个百分点，Soft-KD 3.0/3.6，而两个 MOPD 变体仅 0.5–1.6。
8. **Mix-RL 表现强劲**：在 Qwen3.5-4B 与 Qwen3-8B 上接近或超过教师水平，但单域配方变更需重新调参。

## 7. 优点

- **受控实验设计**：共享初始化、共享提示集（哈希校验）、统一评测协议与解码设置，最大限度隔离算法差异。
- **独立超参调优**：明确指出共享学习率会偏袒某些方法（off-policy 与 on-policy 最优学习率相差约 5 倍），并对每种方法、模型、设置分别扫描。
- **成本核算严谨**：不仅报告步数，还报告累计 GPU 小时，并区分一次性教师语料生成成本与训练时教师打分成本。
- **复现验证**：对 4 项已发表工作做独立复现，使用发布代码/数据，增强结论可信度。
- **理论支撑**：命题 E.1 从 KL 链式法则与 Pinsker 不等式给出离策略可匹配同策略的充分条件，解释实证结果。
- **纳入免训练替代方案**：系统评估 11 种合并方法，为实际部署提供低成本选项。
- **诚实的局限性披露**：附录 H 明确说明规模、教师兼容性等未覆盖范围。

## 8. 不足与局限

- **模型规模有限**：仅覆盖 1.7B–8B 四个模型，无法证明结论在更大规模（数十亿至千亿级）或更不兼容教师下仍成立。
- **设置覆盖有限**：仅 MIA 与 Agent ×3 两种多教师组合，未测试更多样化的教师配置。
- **大教师对比

- **大教师对比**：仅在固定 1.7B 学生下做了 1.7B vs 8B 教师的单点对比，未系统扫描教师规模、教师数量、教师间能力重叠度对结论的连续影响，"更大教师不利于 MOPD"这一发现的外推范围有限。
- **任务维度偏窄**：仅覆盖数学、指令跟随、Agent 三类能力，缺少代码生成、多语言、长上下文、安全对齐等对蒸馏敏感的能力维度；多轮任务也集中在工具/环境交互类，未涉及对话式或多模态场景。
- **指标单一**：主要依赖 ID 恢复率与 OOD 保留率两类准确率指标，未系统评估灾难性遗忘、校准性、推理效率、鲁棒性、输出多样性等维度，行为差异分析（注意力权重、响应长度）也停留在描述层面，未与性能建立因果联系。
- **拒绝采样与评测分布的潜在耦合**：RS 数据筛选可能隐式偏向与 ID 评测同分布的样本，虽论文报告了 RS 前后对比，但未做严格的数据去偏或分布偏移控制实验。
- **MOPD 实现未穷尽**：同策略蒸馏只考察了反向 KL 的单一形式（含多轮实时交互），未探索 token 级加权、教师集成方式、长度归一化变体、温度调节等可能缩小差距的设计，因此"同策略无一致优势"的结论应限定在该实现族内。
- **理论分析条件较强**：命题 E.1 依赖教师-学生概率比有界等假设，实际自蒸馏中该条件未必满足，理论仅提供充分性直觉而非紧界。
- **复现协议与主研究不完全一致**：四项复现使用报告基准调参而非留出验证集，且各复现的数据、训练预算与评测细节存在差异，削弱了与主实验结论的直接可比性。
- **免训练合并并非完全免费**：虽然合并本身为 CPU 分钟级，但合并系数与稀疏度的选择仍需 GPU 推理验证，论文在成本对比中对此的摊销方式未完全展开。

## 9. 结论与实践启示

1. **算法归因需谨慎**：在共享初始化、独立调参、统一数据的受控条件下，MOPD 相对异策略 SFT/Soft-KD 的准确率优势几乎消失。此前文献报告的同策略增益，很大程度可归因于训练设计选择与超参数优化，而非算法本质。
2. **成本—收益权衡清晰**：SFT 以约 1/15 至 1/23 的训练 GPU 小时达到与 MOPD 相当的 ID 恢复率，同时避免了多轮环境交互的工程复杂度，在给定实验范围内是更优的默认选择。
3. **数据质量优先于采样策略**：拒绝采样对异策略方法的增益（6.5–7.0 个百分点）显著大于对同策略变体的增益（0.5–1.6），提示在预算有限时应优先投入数据筛选而非同策略 rollout。
4. **免训练合并适合快速原型**：任务算术等 11 种合并方法在能力不重叠时可达 96.6% 恢复率且零训练成本，但能力重叠场景（Agent ×3）下降至 87.9%，小模型上进一步降至 87.3%，不宜作为唯一方案。
5. **Mix-RL 是值得关注的第三条路线**：联合多域 RL 在较大模型上接近或超过教师水平，但其对单域配方变更的敏感性意味着复现与调参成本可能被低估。
6. **教师规模并非越大越好**：在 1.7B 学生上，8B 教师使 MOPD 恢复率跌至 73.3%，而 SFT 仍保持 99.3%，说明异策略方法对小容量学生的容纳能力更强，但代价是更严重的 OOD 退化，需要按部署场景取舍。

## 10. 总体评价

本文是一篇**方法论严谨、结论具有颠覆性**的实证研究。其核心贡献不在于提出新算法，而在于通过受控对比、独立调参、多种子验证与四项已发表工作的复现，系统性地削弱了"多教师同策略蒸馏优于异策略方法"这一近期被广泛采纳的假设，并给出了可操作的成本核算与替代方案评估。

**最大价值**在于：将"算法优劣"与"训练设计选择"解耦，为社区提供了一个可复用的公平比较框架（共享初始化、共享提示集、独立学习率扫描），并诚实披露了成本口径与局限边界。

**主要遗憾**在于：模型规模（1.7B–8B）与任务覆盖（数学/指令/Agent）相对前沿 LLM 后训练实践仍有距离，MOPD 实现族与合并方法的探索也未穷尽，因此结论更应被理解为"在受控中等规模条件下，同策略优势缺乏证据支持"，而非"同策略蒸馏普遍无效"。

总体而言，论文对正在采用或计划采用 MOPD 的工程团队具有直接的决策参考价值，也为后续在更大规模、更多能力维度上的再验证提出了明确方向。
