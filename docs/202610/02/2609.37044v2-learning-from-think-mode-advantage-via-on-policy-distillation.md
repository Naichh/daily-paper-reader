## 摘要
显式中间推理为大型语言模型（LLMs）提供了一种更强的问题求解模式。我们研究如何通过同策略蒸馏（OPD）从这种思考模式优势中学习。OPD 保留学生生成的轨迹，并在学生访问过的前缀处提供密集的 token 级教师目标。特权推理用于蒸馏过程中，而非学生推理过程中。Uniform ThinkOPD 是一种自然的启用思考的 OPD 基线，它将固定教师条件于一条共享的思考轨迹上，并对每个同组学生回答进行均匀蒸馏。尽管其前缀是同策略的，该轨迹未必遵循与每个完整回答兼容的路径：即使回答达到相同结果，同一特权轨迹也可能导致不同的师生差异。我们用轨迹-回答散度（TRD）来刻画这种交互，并提出 ThinkOPD，它通过将组相对奖励增益与基于 TRD 的兼容性代理相结合，在回答级别进行监督路由。最终的回答权重在每个 rollout 组内进行归一化。在数学推理和代码生成任务上，ThinkOPD 在同模型设置和跨模型师生对中均优于 Uniform ThinkOPD，并在受控比较中超过具有代表性的推理链与自蒸馏基线。受控干预表明，结果收益与基于 TRD 的代理在该设置中提供了互补的路由信号。启用思考的 OPD 为研究教师优势如何沿学生回答变得可迁移提供了一个受控环境。

## Abstract
Explicit intermediate reasoning gives large language models (LLMs) a stronger problem-solving mode. We study learning from this think-mode advantage via on-policy distillation (OPD). OPD preserves student-generated trajectories and provides dense token-level teacher targets at student-visited prefixes. Privileged reasoning is used during distillation rather than student inference. Uniform ThinkOPD, a natural think-enabled OPD baseline, conditions a fixed teacher on one shared think trace and uniformly distills every sibling student response. Although its prefixes are on-policy, the trace need not follow a route compatible with every complete response: the same privileged trace can induce different teacher-student discrepancies even when responses reach the same outcome. We summarize this interaction with trace-response divergence (TRD) and introduce ThinkOPD, which routes supervision at the response level by combining group-relative reward gain with a TRD-based compatibility proxy. Final response weights are normalized within each rollout group. Across mathematical reasoning and code generation, ThinkOPD outperforms Uniform ThinkOPD in both same-model settings and both cross-model teacher-student pairs, and it exceeds representative rationale and self-distillation baselines in a controlled comparison. Controlled interventions show that outcome benefit and the TRD-based proxy provide complementary routing signals in this setting. Think-enabled OPD provides a controlled setting for studying how teacher advantage becomes transferable along student responses.

# 论文总结：Learning from Think-Mode Advantage via On-Policy Distillation

## 1. 核心问题与整体含义
- **研究动机**：显式中间推理（think mode）能让 LLM 获得更强的问题求解能力，但如何将这种“思考模式优势”通过同策略蒸馏（OPD）迁移给无思考模式（no-think）学生模型，仍缺乏系统研究。
- **核心问题**：OPD 虽然能让学生在自己的轨迹前缀上接收密集 token 级教师监督，但教师使用的特权思考轨迹（think trace）来自教师的解题路线，未必与每个学生完整回答兼容。
- **关键现象**：即使多个学生回答得到相同结果，同一共享思考轨迹也可能对不同回答产生不同的师生差异；Uniform ThinkOPD 对所有 sibling 回答等权蒸馏，忽略了这种“轨迹–回答兼容性”。
- **整体含义**：论文将 think-enabled OPD 视为一个受控环境，研究“结果收益”与“轨迹–回答兼容性”如何共同决定教师优势能否沿学生回答有效迁移。

## 2. 方法论
### 2.1 核心思想
- 提出 **ThinkOPD**：在 OPD 中保留学生生成轨迹，并让固定 think-mode 教师在学生访问过的前缀上提供密集监督。
- 与 **Uniform ThinkOPD** 不同，ThinkOPD 不再均匀加权所有 sibling 回答，而是把每个“共享思考轨迹 + 学生回答”对视为路由单元，按回答级权重分配监督。
- 路由信号有两个：
  - **奖励增益**：衡量该回答是否从教师思考模式中获得结果收益。
  - **TRD（Trace–Response Divergence，轨迹–回答散度）**：衡量共享思考轨迹沿该学生回答展开时造成的师生差异，作为兼容性代理。

### 2.2 TRD 的关键技术细节
- 对回答 \(k\) 在位置 \(t\)，先计算教师与学生稀疏前向 KL：
  - \(D_t^{(k)} = KL(q_{T,t}^{(k)} \| q_{S,t}^{(k)})\)。
- 再计算带折扣的未来延续：
  - 从 \(t\) 到 \(\min(t+H, |y^{(k)}|)\) 累加 \(D_\tau\)，并用 \(0<\gamma<1\) 折扣，掩码过滤无效生成位置。
- 最后对完整回答的有效 token 位置取平均，得到回答级 TRD：
  - 低 TRD 表示轨迹条件目标与学生较一致；高 TRD 表示持续偏离。
- TRD 不是单 token 的瞬时 KL，而是强调持续性分歧和邻近后果的响应级兼容性代理。

### 2.3 组相对响应路由
- 对每个 prompt 组内 sibling 回答：
  - 奖励增益 \(g^{(k)} = r_T^{(k)} - r_S^{(k)}\)。
  - 对奖励增益和 TRD 分别做组内 z-score 标准化。
- 回答权重：
  - 第一项随相对结果收益增大而增大：\(\sigma(\widehat{g}^{(k)})\)。
  - 第二项随相对 TRD 增大而平滑衰减：\(\exp[-\eta \sigma(\widetilde{TRD}^{(k)})]\)。
  - 二者相乘后，在组内归一化得到 \(\lambda^{(k)}\)。
- 该设计不设硬阈值，而是组内相对比较，重新分配 dense OPD 监督。

### 2.4 训练目标与算法流程
- 加权 OPD 损失：
  - 对每个有效 token 位置，用 stop-gradient 后的回答级权重 \(\lambda^{(k)}\) 加权教师–学生 KL。
  - 若所有 \(\lambda^{(k)}=1\)，退化为 Uniform ThinkOPD。
- 算法流程：
  1. 从离线 trace–response–reward bank 中取出每个 prompt 的共享思考轨迹和教师回答/奖励。
  2. 当前学生为每个 prompt 采样 \(G\) 个 sibling 回答。
  3. 对每个回答计算 token 级 KL、奖励增益和 TRD。
  4. 在 prompt 组内标准化奖励增益和 TRD，计算并 stop-gradient 权重 \(\lambda\)。
  5. 用加权全回答前向 KL 更新学生策略。
- 训练中教师仍在学生访问的前缀上重算前向分布，保持 OPD 的 on-policy 交互。
