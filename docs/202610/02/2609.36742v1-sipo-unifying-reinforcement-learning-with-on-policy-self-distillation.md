## 摘要
带可验证奖励的强化学习（RLVR）已成为提升大语言模型（LLM）在各类任务上表现的标准范式，但其稀疏的结果奖励缺乏对中间步骤的 token 级信用分配。为解决这一问题，同策略自蒸馏（OPSD）利用带有特权上下文的自教师来提供额外的稠密学习信号。然而，由于自教师往往过度自信，并对长推理轨迹施加过度惩罚，OPSD 在实践中常常表现不佳。为缓解这一问题，我们提出自指导策略优化（SIPO），采用对比式自教师来提供稠密信用。在每次迭代中，SIPO 从当前策略对每个提示采样多条轨迹，用环境奖励对其进行评分，并通过将参考答案与该组内所犯错误配对，为每条轨迹构建两个教师上下文。随后，模型在两种上下文下重新评估自身回答，将两个教师对数概率之间的差异用作 token 级反馈，从而有望使两种上下文共有的偏差在很大程度上相互抵消。由此得到的目标函数为每条轨迹赋予 token 级优势：奖励仍设定每次更新的主要方向，而自教师则在 token 之间重新分配信用。即使在所有轨迹均失败且组相对优势消失的组中，SIPO 仍能提供学习信号。通过保留对任务奖励的直接优化，同时提供稠密的 token 级反馈，该方法将强化学习与同策略自蒸馏连接起来。在多个推理与代码生成基准上的大量实验表明，SIPO 无需外部教师或额外生成，即可优于 RLVR 和 OPSD 基线。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has become a standard paradigm for improving large language models (LLMs) on various tasks, yet its sparse outcome rewards lack token-level credit assignment for intermediate steps. To address this, on-policy self-distillation (OPSD) leverages a self-teacher with privileged context to provide additional dense learning signals. However, because the self-teacher is often overconfident and imposes excessive penalties on long reasoning trajectories, OPSD frequently struggles in practice. To mitigate this, we propose self-instructing policy optimization (SIPO) with a contrastive self-teacher to provide dense credit. At each iteration, SIPO samples multiple rollouts per prompt from the current policy, scores them with environment rewards, and constructs two teacher contexts for each rollout by pairing the reference answer with mistakes made within the group. The model then re-evaluates its own responses under both contexts, using the difference between the two teacher log-probabilities as token-level feedback, so that biases shared by both contexts are expected to largely cancel. The resulting objective yields a token-level advantage for every rollout: the reward still sets the main direction of each update while the self-teacher redistributes credit across tokens. Even in groups where every rollout fails and group-relative advantages vanish, SIPO still provides a learning signal. By preserving direct optimization of the task reward while providing dense, token-level feedback, this approach bridges reinforcement learning and on-policy self-distillation. Extensive experiments across multiple reasoning and code-generation benchmarks demonstrate that SIPO outperforms both RLVR and OPSD baselines without an external teacher or additional generation.

# SIPO 论文总结

## 1. 核心问题与整体含义

- **背景**：带可验证奖励的强化学习（RLVR）已成为提升 LLM 推理能力的主流范式，GRPO 等方法通过组内多次 rollout 的奖励统计估计优势，无需 critic。
- **核心痛点**：
  - RLVR 的结果奖励是序列级稀疏标量，缺乏 token 级信用分配，难以判断哪些中间推理步骤真正贡献成功或失败。
  - 在困难问题上，若一组 rollout 全部失败，组相对优势消失，整组不提供学习信号，采样算力被浪费。论文指出 Qwen3-8B 在 DAPO-Math-17k 上早期约 20–30% 的组全失败，训练后期仍有约 10%。
  - 同策略蒸馏（OPD）可提供稠密 token 级监督，但依赖外部强教师，学生上限受教师能力约束。
  - 同策略自蒸馏（OPSD）用带特权信息的自教师提供密集信号，但自教师常过度自信，对长推理轨迹施加过重惩罚，导致长数学推理中奖励、熵、响应长度下降，甚至蒸馏崩溃。
- **整体含义**：论文提出 SIPO，将 RLVR 的奖励策略梯度与 OPSD 的稠密 token 级监督统一到单一 token 级优势中。奖励仍决定更新主方向，对比式自教师负责在 token 间重新分配信用，且无需外部教师或额外生成。

## 2. 方法论

### 核心思想

- 对同一 prompt 采样多条 rollout，用环境奖励评分。
- 为每条 rollout 构造两个自教师上下文：
  - 正上下文 \(x_i^+\)：包含参考答案 \(a^\star\)。
  - 负上下文 \(x_i^-\)：包含一个错误答案 \(a_i^-\)。
- 让同一模型在两种上下文下重新评估同一条 rollout，取两个教师对数概率之差作为 token 级对比证据。
- 两个上下文共享的偏差（如偏好简短答案、格式偏好）在相减时大部分抵消，剩余信号反映 token 更支持正确答案还是错误答案。

### 关键技术细节

- **正负上下文构造**：
  - 有参考答案时：\(x_i^+ = \text{augment}(x, a^\star)\)，\(x_i^- = \text{augment}(x, a_i^-)\)。
  - 对错误 rollout，\(a_i^-\) 是其自身最终答案；对正确 rollout，\(a_i^-\) 是组内最常见的错误答案。
  - 无参考答案时（如代码生成），使用同组中的成功 sibling 和失败 sibling 作为正负上下文。
  - 被截断、无有效判定答案、或无法构造对比对的 rollout 不获得教师项。
- **教师评估**：教师参数 \(\bar\theta\) 是策略的周期快照，每 \(K=10\) 步同步一次。教师只对已有 rollout 的 token 重新评分，不生成新文本。
- **对比证据**：
  \[
  e_{i,t}=\text{sg}\left[\log \pi_T(y_{i,t}|x_i^+,y_{i,<t})-\log \pi_T(y_{i,t}|x_i^-,y_{i,<t})\right]
  \]
  其中 \(\text{sg}[\cdot]\) 表示 stop-gradient。
- **token 级优势**：
  \[
  A_{i,t}=\hat A_i+\kappa\cdot \text{clip}(e_{i,t},-\delta,\delta)
  \]
  \(\hat A_i\) 是 GRPO 的组相对优势，\(\delta=0.2\)，\(\kappa\in\{0.1,0.2,0.5\}\)。
- **损失形式**：与 GRPO/OPD 相同的策略梯度替代目标，只是将统一序列优势替换为 token 级优势 \(A_{i,t}\)。
- **方向保持**：由于二值奖励，最小非零 \(|\hat A_i|=1/G\)。当 \(\kappa\delta<1/G\) 时，教师项不能翻转优势符号；论文还加入符号保持投影作为保险。奖励决定更新方向，教师项只重新分配 token 信用。
- **全失败组处理**：当整组失败时 \(\hat A_i=0\)，\(A_{i,t}=\kappa\cdot\text{clip}(e_{i,t})\)，这些原本被 GRPO 丢弃的 rollout 仍能通过自教师对比获得 token 级学习信号。
- **额外开销**：仅增加两次教师前向传播，不需要额外生成。
