## 摘要
多教师同策略蒸馏（MOPD）旨在将经强化学习训练的多个教师的优势整合到单个学生模型中，但教师信号如何影响参数变化仍未得到充分研究。我们研究了 Qwen3-1.7B，其四个领域教师模型与学生从相同初始化出发经强化学习训练，比较了梯度、优化器更新和任务学习曲线，并额外进行了 SmolLM3-3B 诊断。我们发现，若干因素会影响教师信号。首先，损失平均会隐式地加权响应：按 token 平均更偏好较长的响应，而均衡各领域贡献会在各领域内部保留这种加权。其次，Adam 的一阶矩会减小参数更新差异：尽管原始梯度存在差异，教师之间的余弦相似度为 0.83，而不同平均规则之间的余弦相似度为 0.96。第三，BF16 舍入会掩盖微小变化：约 97% 的 FP32 主权重与初始化不同，但仅有 7--11% 的 BF16 权重如此。最后，top-64 交集 KL 梯度与 Qwen 的全词表梯度高度接近，但其对任务性能的影响取决于平均方式：在按响应平均下，数学准确率比使用采样 token 策略梯度（PG）高 2.6 个百分点，而在全局 token 平均下低 2.1 个百分点。

## Abstract
Multi-teacher on-policy distillation (MOPD) aims to combine the strengths of RL-trained teachers in a single student, but how teacher signals affect parameter changes remains underexplored. We study Qwen3-1.7B with four domain teachers trained with RL from the same initialization as the student, comparing gradients, optimizer updates, and task learning curves, with additional SmolLM3-3B diagnostics. We find that several factors influence teacher signals. First, loss averaging implicitly weights responses: token averaging favors longer responses, and equalizing domain contributions retains this weighting within domains. Second, Adam's first moment reduces differences in parameter updates: the cosine similarity is 0.83 between teachers and 0.96 between averaging rules, despite differences in raw gradients. Third, BF16 rounding hides small changes: about 97\% of FP32 master weights differ from initialization, but only 7--11\% of BF16 weights do. Finally, the top-64 intersection KL gradient closely matches Qwen's full-vocabulary gradient, but the effect on task performance depends on averaging: mathematics accuracy is 2.6 points higher than with sampled-token policy-gradient (PG) under response averaging and 2.1 points lower under global token averaging.

## 1. 核心问题与整体含义

- **研究背景**：强化学习（RL）能训练出数学、代码、指令跟随等领域的强专家模型，但如何将这些专家的能力整合进单一学生模型仍是难题。
- **MOPD 的定义**：多教师同策略蒸馏（Multi-Teacher On-Policy Distillation）用学生自生成响应，由多个领域教师的下一 token 概率进行监督，目标是让学生同时获得所有教师的能力。
- **核心痛点**：现有 MOPD 配方在损失平均方式（响应级/领域级/token 级）、词表截断（采样 token、top-k、全词表）等选择上各不相同，但**教师信号如何经由梯度、优化器更新转化为参数变化与任务能力，缺乏机制性理解**。
- **整体含义**：论文主张不能只看最终分数，而应打通"监督信号 → 梯度 → 优化器更新 → 参数变化 → 任务表现"的完整链条，为 MOPD 的配方设计提供可解释依据。

## 2. 方法论

### 核心思想
在**固定学生参数、相同响应、相同优化器状态**的条件下，只改变监督选择（损失平均、词表监督、优化器、数值精度），对比原始梯度、Adam/SGD 更新方向、参数位移与任务学习曲线，从而分离各因素的独立影响。

### 关键技术细节

- **三种损失平均规则**（式 4）：
  - **GT（全局 token 平均）**：所有响应 token 等权，领域权重由 token 份额决定。
  - **DT（领域 token 平均）**：固定领域权重 λ_d，域内按长度加权。
  - **DR（领域响应平均）**：固定领域权重，域内响应等权。
- **协方差恒等式**（式 5）：DT 的域内梯度 = 未加权域均值 + Cov_d(T, g)/T̄_d，说明 DT 仍把梯度推向长响应；DR 消除了该长度加权项。
- **蒸馏损失**：
  - 全词表 reverse KL；
  - **PG（采样 token 策略梯度）**：理论上对全词表 KL 梯度无偏（附录 E 有证明），但单样本噪声大；
  - **Top-k 交集 KL**：仅在学生 top-k 与教师 top-k 的交集 I_k 内重归一化并计算 KL（式 3），交集为空时损失为 0。
- **优化器分析**：用 `δU_d = U(g_d; H) − U(0; H)`（式 6）剥离 Adam 历史动量（含零梯度基线），度量当前梯度对更新的真实贡献；对比保存态、重置一阶矩、重置一阶+二阶矩、无动量 SGD。
- **数值精度分析**：对比 FP32 主权重与 BF16 模型权重相对初始化的变化坐标比例，以及 90% 平方变化能量所占坐标比例。

## 6. 主要结论与发现

- **损失平均是隐式的响应/领域加权**：GT 让数学获得约 44% 损失权重（约 3 倍于 IF）；DT 固定领域权重但仍按长度加权；DR 使响应等权。无任何平均规则在所有任务上最优。
- **Adam 一阶矩掩盖教师差异**：不同平均规则的原始梯度余弦仅 0.68，但经 Adam 更新后余弦达 0.96；不同教师自身域输入下的更新余弦 >0.83，重置一阶矩后降至近 0。
- **无动量 SGD 平均分更高**：PG 损失下，SGD 在三种平均规则上四任务均分均高于 Adam（DR：39.94 vs 38.91）。
- **BF16 舍入掩盖广泛变化**：约 97% 的 FP32 主权重偏离初始化，但仅 7–11% 的 BF16 权重可见变化；能量集中度也从 FP32 的约 1/3 坐标降至 BF16 的约 4%。
- **更接近全词表梯度 ≠ 更大能力提升**：Qwen 中 top-64 交集 KL 与全词表梯度余弦 >0.999，但任务收益随平均规则反转——DR 下数学比 PG 高 2.6 分，GT 下低 2.1 分。
- **长度上限影响因平均规则而异**：8K vs 4K 的均分差为 GT +1.05、DT +0.32、DR −0.83 个百分点。
- **梯度保真度不是任务增益的充分预测因子**：PG 无偏、top-64 高度逼近，二者任务效果却不同；优化器处理（裁剪、二阶矩）与响应加权共同决定结果。

## 7. 优点

- **全链条机制分析**：不止看最终分数，而是逐层拆解"梯度 → 裁剪 → Adam 动量 → FP32/BF16 参数变化 → 任务曲线"，视角新颖。
- **严格的变量控制**：固定参数、响应、token mask 与优化器状态，仅切换监督规则，因果归因清晰。
- **理论支撑**：给出长度加权的协方差恒等式与 PG 无偏性证明，把直觉上升为可验证的数学陈述。
- **揭示被忽视的因素**：Adam 历史动量与 BF16 数值精度这两个工程细节对"教师差异是否可见"影响巨大，对实践有直接启发。
- **双模型族交叉验证**：Qwen（高概率集中）与 SmolLM（覆盖度较低）互补，避免单一模型结论外推。
- **可复现性好**：附录给出数据源、超参、种子、Adam 干预细节与接口限制说明。

## 8. 不足与局限

- **规模局限**：仅 Qwen3-1.7B 与 SmolLM3-3B，作者自认"limited model families and scales"，大模型结论可能不同。
- **领域与教师数量有限**：4 个领域、3–4 个教师，未验证更多教师冲突/协同场景。
- **实现受工程约束**：top-k 交集方案部分源于 SGLang 教师接口无法按位置查询学生 token ID（附录 D.2），可能影响与其他 top-k 变体的可比性。
- **诊断样本偏小**：部分梯度/更新对比仅 6 个批次、少量前缀；SmolLM 低覆盖组仅 85 个前缀，统计稳定性受限。
- **未报告算力成本**：训练时长、GPU 小时、能耗缺失，影响成本效益评估。
- **未解决机制**：作者提出未来探索更小 Adam β₁、梯度裁剪与二阶矩归一化为何导致"相同期望梯度却不同任务结果"，当前仍是开放问题。
- **任务指标敏感**：GPQA 用 avg@32、部分任务分数波动较大，任务间均值可能掩盖领域级反向变化（附录 G.3 已证实）。
