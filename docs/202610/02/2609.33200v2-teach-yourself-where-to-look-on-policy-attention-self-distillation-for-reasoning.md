## 摘要
在策略自蒸馏利用可访问已验证解的特权教师所提供的稠密 token 分布指导，在推理模型自身的轨迹上训练这些模型。这种监督传递了教师的预测内容，却没有直接传递教师在前文上下文中关注的位置。我们提出在策略注意力自蒸馏（OPASD），它以解条件化的注意力蒸馏补充 token 级监督。由于特权教师可以关注学生无法获得的已验证解 token，OPASD 将教师注意力投影到学生可见的位置上，并在对齐前对所得分布重新归一化。在三种模型规模和四个竞赛级数学基准上，OPASD 始终优于仅使用 token 的 OPSD，平均准确率提升 4.98 至 8.40 个百分点。OPASD 还避免了仅 token 蒸馏中观察到的回复长度膨胀和性能退化，在训练速度提升 1.53 倍的同时，将生成的 rollout token 减少 73.9%，并将估计的模型计算量减少 72.6%。这些结果表明，解条件化的注意力提供了一种互补的监督信号，使在策略自蒸馏更准确、更稳定且计算效率更高。

## Abstract
On-policy self-distillation trains reasoning models on their own trajectories using dense token distribution guidance from a privileged teacher with access to a verified solution. This supervision transfers what the teacher predicts without directly transferring where it attends within the preceding context. We introduce On-Policy Attention Self-Distillation (OPASD), which complements token-level supervision with solution-conditioned attention distillation. Because the privileged teacher can attend to verified solution tokens unavailable to the student, OPASD projects teacher attention onto student-visible positions and renormalizes the resulting distribution before alignment. Across three model sizes and four competition-level mathematics benchmarks, OPASD consistently outperforms token-only OPSD, improving average accuracy by 4.98 to 8.40 percentage points. OPASD also avoids the response-length inflation and performance degradation observed with token-only distillation, reducing generated rollout tokens by 73.9% and estimated model compute by 72.6% while training 1.53x faster. These results show that solution-conditioned attention provides a complementary supervision signal that makes on-policy self-distillation more accurate, stable, and compute-efficient.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：提升语言模型推理能力的后训练方法中，RLVR 只提供响应级奖励，对单个 token 决策指导有限；在策略蒸馏（OPD）通过教师对每个学生前缀给出完整下一 token 分布，提供更细粒度监督；在策略自蒸馏（OPSD）进一步用同一模型初始化学生与特权教师，学生仅从问题生成轨迹，教师额外看到已验证解，从而沿学生自身轨迹提供稠密的、解条件化的 token 级监督。
- **核心问题**：OPSD 只迁移"预测什么"（what to predict），没有直接迁移"关注哪里"（where to look）。在多步推理中，后步往往依赖前步建立的约束与中间结果，教师的注意力分布蕴含一种未被利用的解条件信号。
- **关键挑战**：注意力分布与 token 分布不同——token 分布定义在同一词表上可直接比较，而注意力分布定义在各自上下文位置上。特权教师能看到学生看不到的参考解 token，因此会向学生不可见位置分配注意力质量。直接对齐会强迫学生匹配不可见位置；简单丢弃这些位置又会使剩余教师注意力未归一化。这构成 **support mismatch（支持集不匹配）**。
- **整体含义**：论文提出 OPASD，在 token 级监督之外补充解条件化的注意力监督，使在策略自蒸馏不仅更准确，还更稳定、更省算力。

## 2. 方法论（OPASD）

- **核心思想**：沿同一学生生成轨迹，让同一特权教师同时提供下一 token 分布和注意力分布监督；通过"学生支持投影"把教师注意力限制到学生可见位置并重新归一化，再与 token 目标联合蒸馏。
- **基本设定**：
  - 数据集 `S = {(x_i, y*_i)}`，`x` 为问题，`y*` 为已验证解。
  - 教师固定为初始参数 `θ0`，条件为 `p^T(·|x, y*)`；学生为可训练 `p^S(·|x)`。
  - 学生采样在策略轨迹 `ŷ = (ŷ_1,...,ŷ_T) ∼ p^S(·|x)`；教师评估同一轨迹而非自行生成。
  - 每步两个策略给出 `p^S_t = p^S(·|x, ŷ_<t)`、`p^T_t = p^T(·|x, y*, ŷ_<t)`。
- **Token 级目标**：`L_tok = (1/T) Σ_t D_tok(p^T_t, p^S_t)`，梯度只经学生传播，教师目标 detached。
- **注意力表示**：取最终 Transformer 层、跨 `N_h` 个头平均，得到 `A^S`、`A^T`。对每个生成 token `ŷ_t`，`Q^S_t`/`Q^T_t` 为 query 位置，`V^S_t`/`V^T_t` 为可见支持集，`P` 为仅教师可见的参考解位置，满足 `V^T_t = V^S_t ∪ P`。
- **学生支持投影（关键技术）**：对 `i ∈ V^S_t`，
  - `Ã^T_t(i) = A^T_t(i) / Σ_{j∈V^S_t} A^T_t(j)`
  - 即剔除参考解位置的注意力质量并重新归一化。该目标仍为解条件化（因 `A^T_t` 在特权上下文下计算），且保持教师对可见位置的相对注意力比值不变。
- **注意力蒸馏损失**：使用广义 Jensen–Shannon 散度（JSD），令 `M^(β)_t = β Ã^T_t + (1-β) A^S_t`，
  - `ℓ_attn(t) = β D_KL(Ã^T_t ‖ M^(β)_t) + (1-β) D_KL(A^S_t ‖ M^(β)_t)`
  - `β→0` 与 `β→1` 分别退化为前向 KL 与反向 KL；`L_attn = (1/T) Σ_t ℓ_attn(t)`。
- **联合目标**：`L = L_tok + λ_attn · L_attn`，`λ_attn` 控制注意力监督强度。
- **算法流程**（Algorithm 1）：采样 minibatch → 对每个样本采样在策略轨迹 → 学生与教师分别评估得到 token 与注意力分布（教师 detach）→ 计算 token loss → 投影教师注意力 → 计算注意力 loss → 合并 minibatch 损失 → 更新学生。教师与参考解仅用于训练。
- **理论支撑**：Theorem O.2 证明，在所有支持于学生可见位置的注意力分布中，投影后的 `Ã^T_t` 唯一最小化到完整特权教师注意力的广义 JSD；最小散度随教师分配给不可见位置的质量 `ρ_t` 单调递增。

## 6. 主要结论与贡献

- **性能提升**：在 Qwen3-1.7B/4B/8B 三个规模上，OPASD 在 AIME 2024、AIME 2025、AIME 2026、HMMT 2025 四个基准的 Avg@12 上一致优于 Base 与 token-only 的 OPSD，且提升随模型规模增大仍保持稳定，说明注意力监督提供的额外信号具有可扩展性。
- **效率优势**：OPASD 在达到更优精度的同时，训练墙钟时间、生成 token 数与估计计算量均显著低于 OPSD（Qwen3-4B 上约 1.53× 加速、生成 token 减少约 73.9%），峰值显存也更低。这来自注意力监督对 token 级监督的补充，使模型在更少 token 上获得更有效的学习信号。
- **稳定性提升**：注意力蒸馏抑制了 token 分布的过拟合与训练后期的不稳定，多个随机种子下结果波动更小。
- **方法贡献**：
  1. 识别并形式化了在策略自蒸馏中的 **support mismatch** 问题——特权教师注意力落在学生不可见位置导致无法直接对齐；
  2. 提出 **学生支持投影** 这一简洁且理论可证的处理方式，在保留解条件信号的同时恢复归一化，并证明其为最小化广义 JSD 的唯一最优投影；
  3. 将 token 级与注意力级蒸馏统一为联合目标，给出完整算法与开源友好的实现路径（LoRA、最终层注意力）。
- **实证贡献**：提供了覆盖多规模、多基准、多消融与多动态分析的系统实验，并辅以定性案例，验证了"迁移关注哪里"对推理后训练的价值。

## 7. 局限与批判性评估

- **理论保证的边界**：Theorem O.2 的最优性建立在"注意力分布支持于学生可见位置"的假设上，而实际 Transformer 注意力经 softmax 后通常全为正，投影后仍可能引入分布偏移；理论未刻画投影带来的信息损失对最终推理性能的因果影响。
- **注意力监督的语义假设**：论文假设最终层平均注意力蕴含可迁移的"推理关注点"，但注意力是否稳定反映因果推理结构仍有争议；单层（最终层）对齐可能忽略中间层更丰富的结构信息，消融虽比较了 1/2/3 层，但未深入分析层选择与任务类型的交互。
- **泛化范围有限**：实验仅限数学竞赛题，且训练数据为 OpenThoughts 数学子集，结论能否迁移到代码生成、多跳问答、智能体规划等任务尚不明确；也未评估对安全对齐或幻觉行为的影响。
- **计算效率对比的公平性**：效率提升部分主要对比 OPSD，但未与 RLVR 等主流后训练基线在同等精度下做算力对比；同时效率数据仅给出 4B 规模、200 步的单点结果，缺乏随训练步数变化的曲线。
- **超参数敏感性**：λ_attn 在 0.25–2.0 间消融，但最优值是否随模型规模、数据规模漂移未做跨规模验证；JSD 的 β 取值也未系统扫描，实际使用中可能需额外调参成本。
- **可复现性细节**：未报告 1.7B/8B 的 GPU 数量与训练时长，随机种子仅 3 个，且未给出方差或置信区间，统计稳健性证据不足。
