## 摘要
同策略蒸馏（OPD）通过在学生生成的响应上提供密集的教师监督，来训练多轮语言智能体。然而，标准的“先思考后行动”式轨迹展开在每次简短动作前都需要冗长推理，延迟了环境转移与经验收集。直接生成动作可减少这种延迟，但可能降低轨迹质量。为此，我们提出 ActFirst-OPD，一种先行动、后推理的训练框架，将环境交互与完整响应生成解耦。学生模型利用当前交互上下文和参考下一观测，通过参考条件逆动力学推断并执行动作；当由此产生的状态转移偏离参考轨迹时，切换为自主预测下一动作。基于收集到的交互上下文，学生模型异步生成完整的“先思考后行动”响应，以供词元级教师监督。在 0.6B、1.7B 和 4B 参数的 Qwen3 学生模型上的实验表明，相较于 Vanilla OPD，ActFirst-OPD 在 ALFWorld 上实现了平均 2.3 倍的墙钟训练加速，在 WebShop 上为 1.8 倍，在 ScienceWorld 上为 4.9 倍。在九种基准-模型设置中的八种上，其平均任务成功率与所有对比的 OPD 基线持平或更高。这些结果表明，在多轮智能体蒸馏过程中，推理不必阻塞行动。

## Abstract
On-policy distillation (OPD) trains multi-turn language agents with dense teacher supervision on student-generated responses. However, standard think-then-act rollouts require lengthy reasoning before each short action, delaying environment transitions and experience collection. Generating actions directly reduces this delay but can degrade rollout quality. To address this, we propose ActFirst-OPD, an act-first, reason-later training framework that decouples environment interaction from full-response generation. The student infers and executes actions through reference-conditioned inverse dynamics using its current interaction context and a reference next observation, and switches to autonomous next-action prediction when the resulting transition deviates from the reference trajectory. From the collected interaction contexts, the student asynchronously generates full think-then-act responses for token-level teacher supervision. Experiments across 0.6B-, 1.7B-, and 4B-parameter Qwen3 students show that ActFirst-OPD achieves average wall-clock training speedups of $2.3\times$ on ALFWorld, $1.8\times$ on WebShop, and $4.9\times$ on ScienceWorld over Vanilla OPD. It matches or exceeds all compared OPD baselines in mean task success rate across eight of nine benchmark-model settings. These results demonstrate that reasoning need not block acting during multi-turn agent distillation.

- **核心痛点**：多轮 OPD 的在线经验收集极其昂贵。标准"先思考后行动"（think-then-act）轨迹中，每轮需先生成长推理再提交一个短动作，导致环境转移被推理阻塞，论文称之为 **reasoning-blocked transition bottleneck**。
  - 对 Qwen3-1.7B 在 ALFWorld 上的剖析：推理占每轮 rollout 时间的 **81–95%**；推理 token 为 37–407（0.65–6.03 s），而动作仅 10–16 token（0.15–0.28 s），环境转移 0.04–0.17 s。延迟跨轮累积，直接拉长训练时间并降低 GPU 利用率。
- **直接生成动作的替代方案存在质量风险**：受控对比显示，无推理直接产动作会带来更多无产出的重复动作（同一任务中出现 19 次重复、30 步失败），每 100 次环境转移的成功轨迹产出（successful trajectory yield）更低。
- **研究问题**：学生能否在不等待完整推理的情况下推进环境，同时保持 rollout 质量？论文的回答是：可以——**推理不必阻塞行动**。

## 2. 方法论：ActFirst-OPD

### 2.1 核心思想
将**环境交互**与**完整响应生成**解耦：交互阶段只用"动作生成"快速推进环境；完整"思考-行动"响应由同一学生**异步**从收集到的上下文中生成，供教师做词元级监督。为保持 rollout 质量，引入高质量离线参考轨迹作为局部转移目标。

### 2.2 三个关键组件

- **① 参考条件逆动力学（Reference-Conditioned Inverse Dynamics, ID）**
  - 交互上下文定义为 `c_t = q ⊕ h_t ⊕ o_t`（指令 ⊕ 实际历史 ⊕ 当前观测），历史 `h_t` 只记录真实观测与已执行动作，**不含过去推理**。
  - 在 rollout 仍与参考轨迹对齐时，把参考下一观测 `o^ref_{t+1}` 作为局部转移目标，学生以纯动作模式（无前置推理）推断动作：
    - `ã_t ∼ π^act_θ(· | c_t ⊕ o^ref_{t+1})`
  - 执行 `ã_t` 得到真实 `o_{t+1}` 并推进环境。

- **② 自主下一动作预测回退（Next-Action Prediction, NAP）**
  - 每轮用**基准特定的转移一致性检查**判断 `o_{t+1}` 是否与目标 `o^ref_{t+1}` 对齐（检查转移结果，不要求动作与参考动作相同）：动作合法性、终止标志一致、归一化观测文本相等、非终止转移的可行动作集合匹配等。
  - 一旦检查失败，**剩余 rollout 永久禁用参考引导**（不重置环境），改为仅用交互上下文自主预测：`ã_t ∼ π^act_θ(· | c_t)`。

- **③ 异步完整响应生成**
  - 对每个收集到的 `c_t`，学生用标准 think-then-act 提示（**不含**参考下一观测）生成 `y_t = (z_t, a_t) ∼ π_θ(· | c_t)`；其中 `a_t` **不提交给环境**。
  - 不同轮次的生成请求可相互重叠，并与后续环境交互重叠；环境推进不再等待推理。
  - 教师 `π_φ` 在同一批词元上下文 `c_{t,j} = c_t ⊕ x_{t,<j}` 上打分，优化 OPD 目标（学生到教师的反向 KL）。

### 2.3 优化细节与公式（文字说明）

- **OPD 目标**：`L_OPD(θ) = E[D_KL(π_θ(·|c_{t,j}) ‖ π_φ(·|c_{t,j}))]`，即期望学生到教师的反向 KL。
- **优势函数**：`A_{b,j} = sg[log π_φ(x|c) − log π_{θ_old}(x|c)]`，停梯度，无环境奖励、无优势归一化；被掩码位置优势为 0。
- **重要性比**：`ρ = exp(clip(log π_θ/π_{θ_old}, −20, 20))`，先在对数空间截断再指数化以保证数值稳定。
- **损失**：PPO 代理 + 双裁剪（δ=0.2，κ=3），按 **seq-mean-token-mean** 聚合（响应内对监督词元求均值，再对 batch 求均值）；`m_{b,j}` 对模型生成词元为 1，对人工插入词元与 padding 为 0。
- **其他设置**：AdamW，学习率 1e-6 常数，权重衰减 0.01，梯度裁剪 1.0；FIFO 缓冲，样本版本滞后 ≤ 1；三种生成模式**共享同一套学生参数 θ**；主方法**不额外加熵惩罚、不加独立参考策略 KL、不对快动作加辅助损失**。
- **思考预算解码**：两阶段生成（第一阶段上限训练 384 / 评测 1920 token；总上限训练 512 / 评测 2048 token），若超预算则插入提前停止指令；插入词元保留在师生上下文中但**不参与损失与归一化**。

### 2.4 理论分析

- **命题 1（理想化 rollout 加速）**：设快动作与完整响应生成时延分别为 `ℓ_fast ≤ ℓ_full`，标准 think-then-act 需 `T·ℓ_full`，ActFirst-OPD 需 `(T−1)ℓ_fast + ℓ_full`，故
  - `S_ideal(T) = T·ℓ_full / ((T−1)ℓ_fast + ℓ_full) ≤ min{T, ℓ_full/ℓ_fast}`，且随 T 单调不减，`T→∞` 时趋近 `ℓ_full/ℓ_fast`。
- **有限并发约束**：设并发上限 `b_max`，可得 `S_real ≤ min{S_ideal(T), b_max/(N(1+ℓ_fast/ℓ_full))}`，因此 `S_real > 1` 的必要条件为 `b_max > N(1 + ℓ_fast/ℓ_full)`——即并发不足时，额外的快动作生成开销可能抵消异步重叠收益。
