## 摘要
同策略蒸馏（OPD）利用教师模型对学生模型自身采样回答的反馈来训练学生，但提示选择如何影响教师-学生对之间的迁移仍鲜为人知。我们系统研究了在RL与SFT续训配对以及跨模型设置中的提示数量、来源和选择。我们发现OPD可以高度提示高效：少量提示即可接近大提示池的性能，四个DAPO提示即可匹配3,840个DeepMath提示所观察到的数学得分。然而，提示效用是关系性的而非内在的：仅改变教师模型就可能逆转数学与代码提示的相对有效性。为刻画这些迁移差异，我们分析了不同提示支持集和模型对上的参数与功能变化。与教师的功能对齐因支持集和目标任务而异；在续训配对中，教师对齐的预测变化可与弱参数对齐并存。在有效支持集上继续OPD可在不利迁移后恢复性能。最后，定向选择并未一致优于均匀随机采样，且过滤掉单独表现较差的来源在三次成对支持集抽样中未带来一致增益。总体而言，我们的结果区分了提示效率与提示可互换性，并表明有效的数据选择取决于教师-学生对和目标能力，而在所研究设置中随机采样提供了有竞争力的基线。

## Abstract
On-policy distillation (OPD) trains students using teacher feedback on their own sampled responses, yet how prompt choice shapes transfer across teacher-student pairs remains poorly understood. We systematically study prompt quantity, source, and selection across RL- and SFT-continuation pairs and cross-model settings. We find that OPD can be highly prompt-efficient: a few prompts can approach large-pool performance, with four DAPO prompts matching the observed mathematics score of 3,840 DeepMath prompts. However, prompt utility is relational rather than intrinsic: changing only the teacher can reverse the relative effectiveness of mathematics and code prompts. To characterize these transfer differences, we analyze parameter and functional changes across prompt supports and model pairs. Functional alignment with the teacher varies across supports and target tasks; in continuation pairs, teacher-aligned prediction changes can coexist with weak parameter alignment. Continued OPD on effective supports can restore performance after unfavorable transfer. Finally, targeted selection does not consistently outperform uniform random sampling, and filtering out a source that performs poorly alone yields no consistent gain across three paired support draws. Overall, our results distinguish prompt efficiency from prompt interchangeability and show that effective data choice depends on the teacher-student pair and target capability, with random sampling providing a competitive baseline in the studied settings.

## 1. 核心问题与研究背景

- **研究动机**：同策略蒸馏（On-Policy Distillation, OPD）已成为 LLM 后训练的重要范式——学生模型自行采样回答，教师模型在学生访问到的前缀上提供 token 级反馈，用于将能力迁移到小模型、整合领域专家教师、或恢复早期训练阶段的能力。
- **关键矛盾**：由于学生自身采样，固定提示会随学生演化而诱发不同轨迹，因此"提示选择"直接决定了教师监督施加的上下文。近期工作分别证明"单条查询即可大幅迁移"与"OPD 会跨域传播优劣"，但**提示数量、来源、选择如何随师生对与目标任务变化**仍缺乏系统理解。
- **核心问题**：提示效用究竟是内在的（intrinsic）还是关系性的（relational）？提示充足（sufficiency）是否等于提示可互换（interchangeability）？显式的提示筛选/来源过滤是否能稳定优于均匀随机采样？
- **整体含义**：作者主张把"提示效率"与"提示可互换性"区分开来——少数提示即可逼近大池性能，但哪些提示有效高度依赖教师-学生对与目标能力。

## 2. 方法论

### 2.1 OPD 训练目标

- 固定教师 π_T 与学生 π_θ，从支持集 S_M（M 条不同提示）中采样提示，用 rollout 策略 π̄_θ 生成回答，在学生访问的前缀 s_t=(x, y_<t) 上用**反向 KL** 对齐：
  L_RKL(θ; θ̄) = E_{s∼d_θ̄}[D_KL(π_θ(·|s) ‖ π_T(·|s))]。
- 实现上采用**采样 token 的策略梯度代理**（Lu & Thinking Machines Lab, 2025）：对采样 token y_t，计算 K1 log-ratio
  k̂_t = log π̄_θ(y_t|s_t) − log π_T(y_t|s_t)，反馈 Â_t = −sg[clip(k̂_t, −10, 10)]，
  对有效响应 token 取平均，**不累积未来 token 反馈**；任务奖励仅用于监控与基于奖励的选择基线，不进入 OPD 损失。

### 2.2 实验对象设计

- 支持集 S_M 从候选池 C 中抽取（M 与 |C| 分别设定），训练中持续生成新 rollout，因此**固定 M 不等于固定 token 或算力预算**。
- 三类师生对：
  - **RL 续训对**（教师由学生同一初始 checkpoint 经 RL 得到）；
  - **SFT 续训对**（经 SFT 续训得到）；
  - **跨模型对**（教师并非该 checkpoint 的续训）。

### 2.3 迁移诊断技术

- **参数对齐**：权重位移（displacement）余弦。
- **功能对齐**：在冻结的探测前缀上做**有限端点条件预测变化**——固定初始学生 top-128 token 动作支持集，对端点减初始的 log 概率变化做中心化，再用 √p_0 加权嵌入，计算功能余弦 cos_F 与教师方向投影系数 α；并定义**诊断性 KL 闭合度**（teacher-first 前向 KL 在冻结 top-128 支持上的相对下降）。
- **隐藏状态替换干预**：在每个自回归步，把接收方第 30 层（零基）当前位置隐藏向量整体替换为供体向量，供体/接收方各自维护同步 KV cache，用于检验行为是否可被表征重定向。
- **失败恢复**：在有效支持集上继续 OPD；并设计**匹配更新步数的双向支持切换**（GSM8K/DeepMath 一阶段 × GSM8K/DeepMath 二阶段，每阶段 15 步，重置 Adam、固定学习率/批大小/训练种子）。

### 2.4 提示选择方法（对比基线）

- 均匀随机、分层随机（按来源、长度四分位、初始学生难度四档分层）、语义多样性（Qwen3-Embedding-0.6B 嵌入 + 最远优先遍历）、难样本选择（初始学生 pass 率最低）、最短/最长响应、**师生分歧**（长度归一化、截断的蒙特卡洛反向 KL）、**Cost-D-opt**（基于 CountSketch 梯度素描的 D-最优设计，并以响应长度成本归一化贪心增益）。

  - 四提示对照直接检验"混合是否有互补收益"，而非只看总量提升；
  - 随机选择器报告 3 个独立支持抽样的均值 ± 样本 SD，训练种子固定。
- **局限**：多数运行只变动支持抽样种子、**训练种子基本固定为 42**，缺少训练种子层面的方差估计；续训实验 token 预算不匹配；Code 恢复用了 200 步而 native 参考仅 100 步，作者自己也承认不是最优比较。

## 6. 主要结论与发现

- **提示效率极高但不代表可互换**：Math-RL 对中 1 条提示即达 Math 44.74（3840 条为 46.77）；Code-RL 中 48 条与 22,618 条全池仅差 0.10 分；**4 个 DAPO 提示与 3,840 个 DeepMath 提示取得相同 Math 32.55（960× 提示数差异）**；Light-R1 对中 8 条 DAPO/DeepMath 达 40.83/40.63，接近原 3,533 条来源的 40.99。
- **提示效用是关系性的**：仅把教师从 Math-RL 换成 Code-RL，就在全部 4 项评测上**逆转数学与代码支持的相对优劣**（Math 上 DeepMath 46.51 vs Eurus Code 30.89；换教师后 34.06 vs 24.84）；该反转在 5 种种子配置下
