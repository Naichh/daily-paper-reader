## 摘要
区域到全局蒸馏利用以裁剪图像为条件的指导来提升全图理解。挑战在于如何有效地将教师基于裁剪的优势迁移到学生的全图推理中。我们提出渐进视角同策略蒸馏（PVD），它通过一个中间的保持宽高比的填充裁剪，将学生的视角分布从裁剪图像逐步转向全图。该填充裁剪在保留区域内容的同时，匹配全图的视觉 token 网格。在不同阶段，视角混合为全图分配递增的概率。一种轻量级的区域优势加权利用以裁剪为条件的教师-学生对数概率差，重新分配 token 级监督。在每一样本输入下进行评估时，当差距较小时施加温和的重新加权，而当差距扩大时更强调差距较大的 token。Jensen-Shannon 度量分解将这一调度解释为从匹配输入的模仿向部署目标的转变。在涵盖感知、视觉数学和通用多模态问答的基准上，PVD-full 在三个随机种子上的平均准确率达到 77.51，比无奖励蒸馏基线提升 2.01 分，比其奖励匹配变体提升 1.00 分。在无奖励设置下，PVD-distill 仍提升 1.16 分。

## Abstract
Regional-to-global distillation uses crop-conditioned guidance to improve full-image understanding. The challenge is to effectively transfer the teacher's crop-based advantage to the student's full-image inference. We propose progressive-view on-policy distillation (PVD), which shifts the student's view distribution from the crop toward the full image through an intermediate aspect-preserving padded crop. The padded crop preserves regional content while matching the full image's visual-token grid. Across stages, the view mixture assigns increasing probability to the full image. A lightweight regional-advantage weighting reallocates token-level supervision using the crop-conditioned teacher-student log-probability gap. Evaluated under each sampled input, it applies mild reweighting when the gap is small and emphasizes higher-gap tokens when the gap widens. A Jensen-Shannon metric decomposition interprets this schedule as a shift from matched-input imitation toward the deployment objective. Across benchmarks spanning perception, visual mathematics and general multimodal question answering, PVD-full reaches an average accuracy of 77.51 over three seeds, improving on the reward-free distillation baseline by 2.01 points and on its reward-matched variant by 1.00 point. In the reward-free setting, PVD-distill still gains 1.16 points.

- **瓶颈问题**：细粒度视觉细节始终是多模态大语言模型（MLLM）的短板。一个问题的关键证据往往只占据高分辨率图像的极小区域。
- **现有路线及其代价**：已有工作多在推理阶段通过引导式视觉搜索、树状缩放或智能体式的“裁剪—重问”循环来补救，虽然能恢复细节，但引入了额外的推理延迟与部署机制负担。
- **区域到全局蒸馏**：将上述收益转移到模型权重中——把同一模型条件于标注区域，使其成为“特权教师”（在更大有效尺度上看到证据，输出更锐利的下一 token 分布），再用这些分布监督学生在自身 rollout 上的全图推理。
- **具体挑战**：标准目标从一开始就用学生的全图视角、并对响应 token 均匀加权，但特权视角的优势其实只集中在少数 token 上；同时，裁剪视图与全图视图在 token 网格几何和视觉内容（区域相对尺度）上均存在差异，直接迁移困难。
- **整体含义**：本文提出 **PVD（Progressive-View On-Policy Distillation）**，把渐进式视角采样与视角相关的 token 加权整合进单一目标，实现从“匹配输入的模仿”向“部署目标”的平滑过渡，且部署时只需一次全图前向传播。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
- 将学生的观测（视角 v）视为随机变量，其分布 p(τ) 随训练进度 τ 分阶段从教师的裁剪视图向部署的全图视图迁移。
- 用“特权视角下的师生对数概率差”作为区域优势（RA），重新分配 token 级监督，不改变监督总量。
- 引入**保持宽高比的填充裁剪**作为中间视图，把“token 网格对齐”与“引入周围上下文”两件事解耦。

### 2.2 关键技术细节

- **三视图与三阶段（M=3, R=3）**
  - 视图顺序：v₁=裁剪 x_b → v₂=填充裁剪 → v₃=全图 x。
  - 阶段概率（crop, padded crop, full）：阶段1 (0.7, 0.2, 0.1)；阶段2 (0.3, 0.4, 0.3)；阶段3 (0.0, 0.2, 0.8)。
  - 阶段边界：τ₁=0.2，τ₂=0.6。
  - **单调递进约束**：对每个 j<M，累积概率 Σ_{k≤j} p_k(τ) 随 τ 非增，即质量持续向更靠后的视图移动。
  - **终端对齐约束**：最后阶段以全图为主。
  - 教师条件始终固定为裁剪，不参与调度。

- **填充裁剪构造**
  - 按 min(W/W_b, H/H_b) 缩放裁剪（保持宽高比，Lanczos 插值），居中粘贴到 (W, H) 白色画布上。
  - 结果：缩放后裁剪至少在一个维度上铺满画布，边缘为白色，不保留裁剪外像素。
  - 作用：与裁剪共享区域内容，与全图共享画布尺寸和视觉 token 网格。

- **逐 token 蒸馏损失**
  - ℓ_t(v) = JSD_K( π_T(·|x_b, q, y_<t) ‖ π_θ(·|v, q, y_<t) )，支撑集为学生 top-K 词表，教师 log-prob 在其中收集，并用尾部桶重新归一化。

- **区域优势（RA）加权**
  - 特权视角差：g_t(v) = [ log π_T(y_t|x_b, q, y_<t) − log π_θ(y_t|v, q, y_<t) ]_+。
  - 截断与去均值：ḡ_t(v) = min(g_t(v), g_max) − ⟨min(g(v), g_max)⟩_t。
  - 权重：w_t(v) = N[ clip(1 + λ·ḡ_t(v), w_min, w_max) ]，N 归一化到单位均值。
  - 超参：λ=0.5，g_max=2，[w_min, w_max]=[0.5, 2]（最重/最轻 token 比上限为 4）。
  - 梯度反向时 g_t 视为常数；复用 (1) 中已算的 log-prob，无需额外前向传播或辅助打分器。

- **总目标**
  - L_PVD = E_{v∼p(τ), y∼π_θ} [ (1/|y|) Σ_t w_t(v) ℓ_t(v) ]。
  - λ=0 时退化为均匀权重的渐进目标；再固定 v=x 即回到 Vision-OPD。

- **Jensen–Shannon 度量分解（理论解释）**
  - 设 d(·,·)=JSD(·‖·)^{1/2} 为分布度量，由三角不等式：
    d(π_T^{x_b}, π_θ^x) ≤ d(π_T^{x_b}, π_θ^v) + d(π_θ^v, π_θ^x)。
  - 定义 δ_T(v)=d(π_θ^{x_b}, π_θ^v)（代理难度，v=x_b 时为 0）与 δ_X(v)=d(π_θ^v, π_θ^x)（部署松弛，v=x 时为 0）。
  - 结论：裁剪端对齐视觉输入，全图端对齐部署输入；调度正是从前者向后者的过渡。
  - token 分配可精确分解：⟨wℓ⟩_t = ⟨ℓ⟩_t + Cov_t(w, ℓ)，当 w=1+λḡ 时修正项为 λ·Cov_t(ḡ, ℓ)。

- **与任务奖励联合训练**
  - L = L_PVD + β·L_PG，β=1；L_PG 为二值答案奖励上的组相对策略梯度损失，两项对所有 token 叠加而非分区。
