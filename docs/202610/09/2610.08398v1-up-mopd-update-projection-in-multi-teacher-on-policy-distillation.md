## 摘要
来自多个教师的同策略蒸馏将不同领域的专业知识融合到单个学生模型中，但相互冲突的梯度可能会阻碍这种融合。在普通 SGD 下，梯度修正可以直接约束参数更新。然而，在使用 AdamW 等优化器时，动量、自适应缩放和权重衰减可能会使修正后的梯度转化为一阶意义上增大某个领域损失的更新。为弥补这一缺口，我们提出用于多教师同策略蒸馏的更新投影（UP-MOPD）。UP-MOPD 让原始混合梯度更新优化器状态并生成候选位移，然后仅对违反约束的候选位移进行投影，再将它们提交到参数中。该投影给出在欧氏距离下最接近候选位移的唯一可行更新。在结合医学与通用领域的实验中，UP-MOPD 在训练后期将 IFEval-loose 准确率相比原始 M-OPD 提高 2.96 个百分点。它在八项指标上取得 60.03 的平均分，而梯度投影为 59.00，更新拒绝为 59.15。在涵盖数学、代码和指令遵循的公开基准上，它在六项任务上取得最佳平均分（32.67），在 LiveCodeBench v5 上领先，并在 IFEval 结果上并列最佳。这些结果支持通过投影优化器更新来减少领域间的干扰。

## Abstract
On-policy distillation from multiple teachers combines expertise from different domains in a single student, but conflicting gradients can hinder this integration. Gradient corrections directly constrain parameter updates under plain SGD. With optimizers such as AdamW, however, momentum, adaptive scaling, and weight decay can turn a corrected gradient into an update that increases a domain loss to first order. To address this gap, we propose Update Projection for Multi-Teacher On-Policy Distillation (UP-MOPD). UP-MOPD lets the original mixed gradient update the optimizer state and generate a candidate displacement, then projects only violating candidates before they are committed to the parameters. The projection gives the unique feasible update closest to the candidate in Euclidean distance. In experiments combining medical and general domains, UP-MOPD improves IFEval-loose accuracy late in training by 2.96 points over vanilla M-OPD. It achieves an average score of 60.03 across eight metrics, compared with 59.00 for gradient projection and 59.15 for update rejection. On a public benchmark covering mathematics, code, and instruction following, it achieves the best average across six tasks (32.67), leads on LiveCodeBench v5, and ties for the best IFEval result.These results support projecting optimizer updates to reduce interference between domains.

## 1. 论文的核心问题与整体含义

- **研究背景**：大模型后训练常产生面向不同能力/领域的专家模型。实践中两类整合需求突出：一是数学、代码、指令遵循等基础能力的合并；二是通用能力与医学、金融、法律等垂直专业能力的融合。
- **技术路线**：多教师同策略蒸馏（M-OPD）是直接的整合手段——学生自行生成轨迹，各领域教师提供稠密的 token 级监督。MiMo-V2-Flash、GLM-5、Open-MOPD 等均采用类似范式。
- **核心痛点**：当路由、监督和领域预算固定后，所有领域损失仍共享同一个参数向量和同一个优化器。多教师梯度冲突会导致领域间相互干扰。
- **关键洞察（论文的"缺口"）**：现有多任务方法（如 PCGrad、MGDA、CAGrad）都在**梯度空间**做修正，这在普通 SGD 下等价于约束参数更新。但在 **AdamW** 下，动量、自适应缩放、权重衰减会把"已修正的梯度"转化成**一阶意义上增大某领域损失**的更新。
- **形式化问题**：即使 −g₀ 对每个领域都是一阶下降方向（g_d^T(−g₀) < 0），AdamW 产生的候选位移 Δθ₀ 仍可能使某领域损失一阶上升（g_d^T Δθ₀ > 0）。因此需要回答：**如何在最小改动优化器预期更新的前提下，纠正有害的优化器输出位移？**

## 2. 方法论

### 2.1 核心思想
- 让**原始混合梯度**先更新优化器状态并生成候选位移 Δθ₀；**只对违反领域一阶约束的候选**做欧氏距离最近的可行投影，再提交参数；同时保留由原始混合梯度计算出的当前步优化器状态。

### 2.2 关键技术细节

- **M-OPD 目标**：领域损失 L_d(θ) 采用采样 token 形式的裁剪重要性加权目标（式 2），优势 a = sg[log π_teacher − log π_student]，ρ 为重要性比，ξ 为裁剪阈值。混合梯度 g₀ = Σ_d q_d g_d，Σ q_d = 1。
- **AdamW 候选位移**（式 5）：Δθ₀ = −η_t · m̂_t /(√v̂_t + ε) − η_t λ_wd θ_t，包含动量、偏差修正、自适应缩放与解耦权重衰减；实现上通过差分 FP32 主参数在优化器调用前后的值获得。
- **GP-MOPD（梯度空间对照）**：在优化器前联合投影混合梯度，g*_GP = argmin ½‖g − g₀‖² s.t. g_d^T g ≥ 0。
- **UP-MOPD（本文方法）**：在优化器输出处做最小修正：
  - 一阶损失变化 h_d(Δθ) = g_d^T Δθ，h_d > 0 视为一阶有害。
  - 设 G = [g_d]_{d∈A_t}，求解 Δθ* = argmin ½‖Δθ − Δθ₀‖² s.t. G^T Δθ ≤ 0。
  - **命题 2**：可行集 C_t 为非空闭凸锥，式 (9) 有唯一解；可行候选保持不动，否则返回最近可行位移；并满足正交分解 ‖Δθ₀‖² = ‖Δθ*‖² + ‖Δθ₀ − Δθ*‖²。
  - **引理 1**：在标量步长 SGD 下（Δθ = −η_t g），GP-MOPD 与 UP-MOPD 等价；区别仅来自优化器变换。
  - **推论 1**：可行投影满足 g₀^T Δθ* ≤ 0；若 L_d 为 β_d-光滑，则损失变化上界为 β_d/2·‖Δθ*‖²。
- **对偶与算法流程**：
  - 引入乘子 λ ≥ 0，得到 Δθ* = Δθ₀ − Gλ*，且 λ* = argmin_{λ≥0} ½λ^T Kλ − λ^T h，其中 K = G^T G，h = G^T Δθ₀（式 12–14）。
  - 对偶维度仅由**活跃领域数 D_t** 决定，与参数量无关；正乘子对应绑定约束。
  - **Algorithm 1**：单领域步走标准 M-OPD；多领域步先算混合梯度 g₀，保存更新前主参数，调用优化器得到 Δθ₀ 与状态 M_t，计算 h = G^T Δθ₀，仅当存在 h_d > 0 时求解低维对偶并重投影。
  - **有限精度提交**：投影在 FP64 中构造，提交前在 FP32 上重新校验约束；若舍入重新引入违反，做最多两轮有界修复（γ_r ∈ {2,4}）；失败则回退到零位移（永远可行）。
- **复杂度**：域梯度重放需额外 D 次梯度回传；Gram 流式构造为 O(D²P)；分布式通信仅 O(D²) 个标量；活跃集枚举最坏 O(2^D D³)，但维度由领域数而非参数量决定。
