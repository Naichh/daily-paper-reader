## 摘要
同策略自蒸馏（OPSD）无需第二个模型即可提供密集的 token 级监督：一个网络在提供参考答案时充当教师，在仅提供问题时充当学生。我们识别出这一方案的一种特定失败模式。训练期间，学生的 token 熵会超过教师并持续偏高，我们将这一模式称为熵过冲。我们将其归因于蒸馏的双方。以参考答案为条件的教师在其面向答案的推理路径上很自信，但这种自信难以迁移到学生生成的前缀上，使其监督过度依赖答案特定的线索，而非可复用的推理模式；与此同时，OPSD 使用的前向 KL 持续扩散学生的预测分布，却未将其拉回。我们提出 E$^2$-OPSD 以同时解决这两个原因。样例引导教学用检索到的已解邻近问题替换当前答案，在不揭示最终目标的同时提供可迁移的推理指导，并更好地匹配学生可达的状态。熵感知蒸馏利用学生-教师熵差来确定每个 token 修正的方向和强度。E$^2$-OPSD 在 mean@16 上将数学推理较 OPSD 提升最多 4.3 个点，而域外评估显示，相比相应的基础模型，在 mean@16 上最多提升 4.9 个点，在 pass@8 上最多提升 5.5 个点。尽管有这些提升，E$^2$-OPSD 仍然简单，不需要额外的前向传播或网络。

## Abstract
On-policy self-distillation (OPSD) provides dense token-level supervision without a second model: one network acts as teacher with the reference solution and as student with only the problem. We identify a specific failure mode of this recipe. During training, student token entropy rises past the teacher's and remains elevated, a pattern we call entropy overshoot. We trace it to both sides of distillation. The reference-conditioned teacher is confident along its answer-directed reasoning path, but this confidence transfers poorly to student-generated prefixes, making its supervision overly tied to answer-specific cues rather than reusable reasoning patterns; meanwhile, the forward KL used by OPSD continually diffuses the student's predictive distribution without pulling it back. We introduce E$^2$-OPSD to address both causes. Exemplar-guided teaching replaces the current answer with a retrieved solved neighboring problem, providing transferable reasoning guidance without revealing the destination and better matching student-reachable states. Entropy-aware distillation uses the student-teacher entropy gap to determine the direction and strength of each token's correction. E$^2$-OPSD improves math reasoning by up to 4.3 points in mean@16 over OPSD, while out-of-domain evaluations show gains over the corresponding base models of up to 4.9 points in mean@16 and 5.5 points in pass@8. Despite these gains, E$^2$-OPSD remains simple, requiring no additional forward passes or networks.

## 一、核心问题与研究动机

- **背景链条**：RLVR（可验证奖励强化学习）是当前提升 LLM 推理的主流方案，但监督过于粗糙——一整条 rollout 只坍缩为一个标量奖励。On-policy distillation（OPD）改为让教师对学生的自生成 rollout 打分，提供密集 token 级监督，但需要额外部署一个更强、且与学生共享词表的教师模型。
- **OPSD 的定位**：On-policy self-distillation（OPSD）进一步取消第二个模型——同一网络的副本在“看到参考答案”时充当教师、在“只看问题”时充当学生，师生在同一学生生成前缀上以前向 KL 匹配，从而把特权答案信息转成密集监督。
- **核心问题（熵过冲，entropy overshoot）**：作者识别出 OPSD 的特有失败模式——训练中学生 token 熵不向教师收敛，反而越过教师并持续偏高（Qwen3-1.7B 上 +23.8%）。这使有用的探索滑向持续、过度的不确定性，逐步侵蚀学生的决策果断性，并把教师侧的不确定性放大为学生的噪声行为。
- **双向归因**：
  - **教师侧**：以“当前参考答案”为条件，教师是在沿已知答案“叙述”而非从零推理，监督绑定答案特定线索而非可复用推理模式。教师在自己轨迹上熵仅 0.190 nats，在学生前缀上却升至 0.314 nats（+65%），说明其指导无法干净迁移到学生实际到达的中间状态。
  - **学生侧**：OPSD 使用的前向 KL 是 mode-covering 的，只把学生分布向外扩散，即使策略已过度弥散也持续施压，缺乏回拉机制——探索成为“单向棘轮”。
- **整体含义**：有效的自蒸馏关键不在最大化模仿，而在于让教师指导匹配学生可达状态，并调控“何时探索、何时集中”。

## 二、方法论

**总体框架**：E²-OPSD 在标准 OPSD 循环内同时修复“学什么”和“怎么学”两侧，仅使用一个冻结教师，无额外前向传播、验证器、奖励或网络。学生 π_θ 与冻结教师 π_φ（同源初始化）在同一学生前缀 ŷ_<t 上打分，但上下文不同：学生为 (x, ŷ_<t)，教师为 (x, r(x), ŷ_<t)，其中 r(x) 为教师专属特权上下文。

### 1. 样例引导教学（Exemplar-Guided Teaching, EGT）——改“学什么”
- 用**检索到的已解邻近问题**替代当前问题的参考答案作为教师条件，使教师必须自己求解 x，样例仅提供可迁移策略，不泄露终点。
- 实现：离线嵌入全部训练题并计算两两余弦相似度，每题保留 K=15 个自排除最近邻 N_K(x)；对同一问题的第 g 条 rollout，按确定性种子（问题+rollout 索引）从邻域中均匀抽一个邻居 (x′_g, y′*_g)。不同 rollout 看到不同样例，无额外检索开销。
- 教师提示词显式声明：“这是另一个相关问题的参考解，不是你要解的问题，其最终答案也不是你的答案——仅作为策略与技巧的迁移指南”，随后附学生前缀继续生成。

### 2. 熵感知蒸馏（Entropy-Aware Distillation, EAD）——改“怎么学”
- **双向熵路由（Bidirectional Entropy Routing, BER）**：以师生熵差 Δ_t = H(p_t) − H(q_t) 选择 KL 方向。
  - Δ_t ≤ 0（学生相对更集中）→ 前向 KL，扩大对教师支持选项的覆盖；
  - Δ_t > 0（学生相对更弥散）→ 反向 KL，抑制不被支持的概率质量、重新聚焦策略。
  - 计算在教师 top-K_v token 加一个尾部桶上进行，保留 OPSD 的逐元素裁剪 τ。
- **自适应间隙阻尼（Adaptive Gap Damping, AGD）**：用熵差幅度作为置信权重，抑制对扰动敏感的近零间隙路由，把学习集中到熵失配更明显的 token。批次尺度 σ² = (1/|T|)Σ Δ²_{i,t}，权重 c_t = Δ²_t / (Δ²_t + max(σ², ε²)) ∈ [0,1)，ε 为 FP32 机器精度，Δ_t = 0 时 c_t = 0。σ² 每个 mini-batch 重算，**无需可调阈值**。
- **训练目标**：L_T(θ) = (1/|T|) Σ sg(c_{i,t}) · D^BER_{i,t}，路由决策与阻尼权重均做 stop-gradient，梯度只通过学生概率回传。
- **理论支撑（附录 D）**：给出“熵差稳定性”命题——若共享候选集 S 满足 p(S), q(S) ≥ 1−η，则 |Δ − Δ_S| ≤ B_η = 2h(η) + 2η log|V|；当 |Δ| > B_η 时，熵差符号与受限分布上的符号一致，为用熵差代理“相对扩散程度”提供依据。
- **推理阶段**：所有特权上下文全部移除，不引入推理开销。
