## 摘要
许多有用的语言模型任务无法通过精确的结果验证来评估。基于评分规则的强化学习（RL）通过依据明确标准对开放式回答进行评分来解决这一问题。然而，由于奖励是在完整回答之后才分配的，训练信号无法直接识别哪些单个决策促成了最终得分。我们提出一个两阶段训练框架，首先将评分规则用作特权教师上下文，以提供密集的 token 级监督，然后将其用作进一步 RL 的奖励。在第一阶段，即评分规则特权同策略蒸馏（RP-OPD），一个无法访问评分规则的学生模型在自身生成的前缀上匹配一个感知评分规则的教师模型的下一 token 分布。在第二阶段，RL 直接优化评分规则奖励，并超越所观察到的蒸馏平台期。我们使用开放权重模型在健康与科学任务上评估该框架。在 HealthBench、ResearchQA 和 RubricHub Science 上，我们比较了后训练方法，并改变 RL 前 SFT 或 RP-OPD 的训练量，发现我们的两阶段框架在所评估的方法中取得了最高分数。RP-OPD + RL 在 RubricHub Science 上表现出有限的奖励黑客迹象，而 SFT + RL 基线则越来越多地因声称符合评分规则但未提供所需内容而获得高奖励。这些发现支持在应用基于评分规则的 RL 之前，使用评分规则来引导同策略蒸馏。

## Abstract
Many useful language-model tasks cannot be evaluated by exact outcome verification. Rubric-based reinforcement learning (RL) addresses this issue by scoring open-ended responses against explicit criteria. However, because the reward is assigned after the complete response, the training signal does not directly identify which individual decisions contributed to the final score. We propose a two-stage training framework that uses rubrics first as privileged teacher context for dense token-level supervision, then as rewards for further RL. In the first stage, rubric-privileged on-policy distillation (RP-OPD), a student without access to the rubric matches a rubric-aware teacher's next-token distributions at student-generated prefixes. In the second stage, RL directly optimizes the rubric reward and improves beyond the observed distillation plateau. We evaluate the framework on health and science tasks using open-weight models. Across HealthBench, ResearchQA, and RubricHub Science, we compare post-training methods and vary the amount of SFT or RP-OPD training before RL, finding that our two-stage framework achieves the highest scores among the methods evaluated. RP-OPD + RL shows limited signs of reward hacking on RubricHub Science, whereas the SFT + RL baseline increasingly receives high rewards for claims of rubric compliance without providing the required content. These findings support using rubrics to guide on-policy distillation before applying rubric-based RL.

- **现有范式的问题**：基于 rubric 的强化学习通常用 LLM judge 对完整回答打分，再用 GRPO 等算法更新策略。但奖励是**轨迹级标量**，反馈极其稀疏，无法直接告诉模型哪些 token 或决策促成了得分，导致探索样本消耗大、从弱基座出发时训练脆弱。
- **整体含义**：论文提出先用 rubric 作为教师特权信息进行**同策略蒸馏**，为后续 rubric-based RL 提供密集 token 级热启动；再直接用 rubric 奖励做 RL。核心主张是：**在 rubric RL 之前加入 on-policy distillation，比传统 SFT 热启动更能提升最终表现，并减轻奖励黑客。**

## 2. 方法论
- **两阶段框架：RP-OPD + Rubric-RL**
  - **阶段 1：Rubric-Privileged On-Policy Distillation（RP-OPD）**
    - 学生只看到 prompt 和学生自己生成的前缀，不访问 rubric。
    - 教师额外看到 rubric，即拥有“特权信息”，在学生生成的每个前缀上给出下一 token 分布。
    - 学生在自身 rollout 上匹配教师的 top-K 下一 token 分布，使用 **forward KL**，实验中 \(K=256\)。
    - 目标可写为：
      \[
      L_{\text{RP-OPD}}(\theta)=E_{(x,r)}\ E_{y\sim\pi_\theta}\sum_t D(\pi_{\text{teacher}}(\cdot|x,r,y_{<t})\|\pi_\theta(\cdot|x,y_{<t}))
      \]
    - 与固定教师回答的 SFT 不同，RP-OPD 在**学生自己遇到的前缀**上学习，教师分布保留多个可能续写，因此更可能维持策略熵和探索能力。
  - **阶段 2：Rubric-RL**
    - 从 RP-OPD 蒸馏 checkpoint 初始化策略。
    - 用 GRPO/DAPO-style RL 直接优化 rubric 奖励。
    - rubric 含正权重标准与负权重陷阱；LLM judge 对每条标准给二值判断 \(g_j\)。
    - 奖励归一化：
      \[
      R(x,y,r)=\frac{\sum_j w_j g_j(x,y)}{\sum_{j:w_j>0}w_j}
      \]
      全部满足正标准且不触发陷阱可得 1.0，严重陷阱可低于 0。
    - RL 目标为最大化期望 rubric 分数：
      \[
      J_{\text{RRL}}(\theta)=E_{(x,r)}E_{y\sim\pi_\theta}[R(x,y,r)]
      \]
- **关键动机**：蒸馏本身是模仿目标，会到达平台期，不能直接最大化任务奖励；但可作为 RL 的密集监督热启动。SFT 虽常见，但过度 SFT 可能降低策略可塑性、输出分布过窄、后续 RL 增益小。
