## 摘要
同策略自蒸馏（OPSD）针对从学生自身策略中采样的轨迹提供密集的 token 级反馈，这比强化学习的结果级奖励提供了更丰富的训练信号。该反馈来自一个以完整参考解为条件的教师模型，而该参考解对学生不可用。参考解指定了目标，但并未说明如何从学生当前的错误转向该目标，从而带来以解为条件的捷径风险。我们提出 AIR-OPD，一种面向同策略蒸馏的自适应迭代修复框架，提供从错误到修复的监督。给定一个失败的回答，引导生成器会针对当前错误合成修复引导。学生在该引导下采样一次同策略重试。如果重试仍然不正确，生成器会针对新观察到的错误生成新的修复引导。在每一轮中，固定的教师模型将引导作为特权上下文接收，并针对学生最新失败回答中与错误对齐的区域对学生进行监督。结果感知的阶段加权偏向早期修复阶段，并奖励那些其即时重试通过验证的阶段。我们在 DAPO-Math-17K 数据集上训练 AIR-OPD，并在 AIME24、AIME25 和 HMMT25 上进行评估，同时在 MMLU-Pro 和 GPQA 上进行分布外测试。我们考察了两种引导来源：来自当前学生策略的自引导，以及来自更大模型的外部引导。对于 Qwen3-4B 和 Qwen3-8B，AIR-OPD 均取得了最佳的数学推理平均成绩，相较最强基线最多提升 3.6 分，同时在分布外基准上保持了基础模型的性能。

## Abstract
On-policy self-distillation (OPSD) supplies dense token-level feedback on trajectories sampled from the student's own policy, a richer training signal than the outcome-level rewards of reinforcement learning. This feedback comes from a teacher conditioned on a full reference solution unavailable to the student. The reference solution specifies the target but not how to move from the student's current error toward it, creating a solution-conditioned shortcut risk. We introduce AIR-OPD, an adaptive iterative repair framework for on-policy distillation that provides error-to-repair supervision. Given a failed response, a guidance generator synthesizes repair guidance for the current error. The student samples an on-policy retry with this guidance. If the retry remains incorrect, the generator produces new repair guidance for the newly observed error. At each round, a fixed teacher receives the guidance as privileged context and supervises the student on an error-aligned region of its latest failed response. Outcome-aware stage weighting favors early repair stages and credits stages whose immediate retry passes verification. We train AIR-OPD on the DAPO-Math-17K dataset and evaluate on AIME24, AIME25, and HMMT25, alongside out-of-distribution tests on MMLU-Pro and GPQA. We examine two guidance sources, self-guidance from the current student policy and external guidance from a larger model. For both Qwen3-4B and Qwen3-8B, AIR-OPD attains the best mathematical-reasoning averages, improving over the strongest baseline by up to 3.6 points, while preserving base-model performance on the out-of-distribution benchmarks.

# 论文总结：AIR-OPD —— 从演化误差中学习的自适应迭代修复

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：强化学习可验证奖励（RLVR，如 GRPO）依赖结果级奖励，仅提供响应级标量监督，无法区分轨迹内部的 token 级贡献；同策略蒸馏（OPD）则在学生自身采样的轨迹上提供密集的 token 级监督。
- **进一步演化**：同策略自蒸馏（OPSD）让模型自身充当教师，以完整参考解作为特权上下文，从而无需单独训练教师模型。
- **核心矛盾（研究问题）**：参考解只指定了"正确目标"，但没有说明"如何从学生当前的错误走向该目标"。教师始终以完整参考解为条件，会使学生倾向于模仿特权示范，而非习得可泛化的纠错机制——作者称之为**以解为条件的捷径风险（solution-conditioned shortcut risk）**。
- **研究问题**：如何将特权监督从一次失败的同策略轨迹转化为一系列可学习的"错误→修复"转换？
- **整体含义**：AIR-OPD 借鉴教学脚手架（instructional scaffolding）思想，用随学生错误动态演化的修复引导取代静态参考解条件，把失败轨迹变成多轮可监督的修复过程。

## 2. 方法论

### 2.1 核心思想
- 用**引导生成器 G** 读取参考解，为学生的当前错误写出"修复引导"（不含答案），教师改以该引导为特权上下文；引导随学生每次失败而更新。

### 2.2 多轮自适应修复流程
- 学生按对话历史 H_t 采样响应 y_t；若未通过验证器 V，则由 G 输出 `(a_t, g_t)`：a_t 逐字引用首个出错步骤（错误锚点），g_t 给出简洁修复引导（经规则过滤，禁止泄露最终答案）。
- 将 y_t 与带修复指令的 g_t 追加到历史，学生重试 y_{t+1}；若仍错误，G 针对新错误重新定位并生成新引导。最多 K 轮，通过验证或预算耗尽即结束。

### 2.3 错误对齐的特权蒸馏
- 教师在共享历史 H_t 下额外接收 g_t（学生评分时不接收），对同一失败响应 y_t 打分。
- **监督区域起点** b_t：错误锚点 a_t 在 y_t 中的精确匹配位置。
- **监督区域终点** e_t：按 token 度量教师相对学生的正向纠错信号
  C_{t,j} = Σ_{v≠y_{t,j}} [p_T(v|…) − p_θ(v|…)]_+，
  在从 b_t 开始的空行分块端点中，选最早保留 ≥ (1−ϵ) 总纠错信号的端点；若总信号为零则保留整个后缀。
- **阶段损失** L_t：在修复区域 R_t = y_t[b_t:e_t] 上，按 OPSD 形式（前向 KL + 逐点裁剪）平均散度；梯度仅流经学生分支。

### 2.4 结果感知阶段加权
- 动机一：后续阶段上下文累积噪声，应偏向早期阶段（时间因子 γ^t，γ<1）。
- 动机二：即时重试是否通过验证反映该阶段监督质量（结果奖励 ρ^{s_{n,t}}，ρ≥1，s 为验证指示）。
- 权重 w_{n,t} = γ^t ρ^{s_{n,t}} / Σ_k γ^k ρ^{s_{n,k}}，归一化使每条轨迹总权重为 1，避免多轮样本获得更大总权重。
- 最终目标：L_AIR-OPD = (1/|B|) Σ_n Σ_t w_{n,t} L_{n,t}。

### 2.5 算法要点（Algorithm 1）
- 对每个问题采样初始响应 → 循环：生成/校验引导 → 定位锚点与端点 → 计算阶段损失 → 更新历史并重试 → 记录重试结果 → 轨迹内归一化加权求和。

## 6. 主要结论与发现

- AIR-OPD 在两种规模下均取得最佳 Math Avg.，外部引导相对最强基线 OPSD 分别提升 **3.6 分（4B）与 2.7 分（8B）**；在所有数学基准上均为最优，HMMT25 上增益尤为明显。
- **自引导已贡献大部分提升**：无需外部模型，自引导版比 OPSD 提升 2.8 / 2.1 分；外部引导增益在 8B 上小于 4B（更大的学生自身生成的引导质量更高）。
- **OOD 保持**：SFT 与 OPSD 在 OOD 上明显回退（SFT 掉 9.6/9.8 分），而 AIR-OPD 距基础模型仅 0.4 分（4B）与 0.1 分（8B），是唯一在两个规模上均保持近基础 OOD 平均的参考解类训练方法；作者推测与"只在错误对齐区域施加选择性纠正信号"有关。
- **消融结论**：
  - 仅对失败样本用 OPSD 反而下降（62.5），说明增益来自"如何监督失败"而非"选择哪些样本"。
  - 全响应监督（−1.1）或仅错误块监督（−1.6）均劣于错误对齐修复区域。
  - 时间因子与结果奖励单独使用都有增益，两者结合最佳。
  - 修复预算 K=1 即超过 OPSD，K=3 收益最佳，K≥4 出现递减（深层阶段上下文噪声累积）。
- **训练动态**：AIR-OPD 从第一个 checkpoint 起即领先，第 40 步就达到 OPSD 第 100 步的水平；监督阶段数约为 OPSD 监督样本数的三分之一，说明错误区域集中的监督"每个 token 的学习信号更强"。

## 7. 优点

- **问题定位精准**：把 OPSD 的"参考解特权监督"缺陷明确表述为捷径风险，并给出可操作的"错误→修复"监督范式。
- **方法设计优雅**：引导随错误演化、监督区域由错误锚点与教师纠错信号共同界定、端点选择有理论化的信号保留保证（丢弃尾部 ≤ ϵ）。
- **零额外开销的信号度量**：C_{t,j} 复用阶段损失已计算的分布，不增加计算成本。
- **加权机制有动机支撑**：时间衰减与结果奖励分别对应"噪声累积"与"监督质量"两个可验证假设，并用示例（Example 2 中"引导有效但重试仍失败"）说明为何不惩罚失败重试。
- **实验对照严谨**：所有基线自行复现于同一语料与骨干，并专门设置"仅失败样本的 OPSD"对照组排除样本选择混淆。
- **实用性亮点**：不牺牲 OOD 泛化、收敛更快、监督 token 更省；自引导即可生效，降低对外部大模型的依赖。

## 8. 不足与局限

- **领域覆盖窄**：训练与主评估均限于数学推理（DAPO-Math-17K → AIME/HMMT），OOD 仅 MMLU-Pro 与 GPQA 两项；方法在其他推理领域（代码、科学、智能体任务）的有效性未知。
- **依赖高质量参考解**：参考解由 GPT-5.5 生成并过滤，引导生成器也依赖参考解与私有答案作为特权证据；若参考解质量不足或领域无标准答案，框架适用性受限。
- **验证器依赖**：每轮验证使用规则化答案匹配，仅适用于可自动判定的任务；对开放式或主观任务难以直接迁移。
- **泄露检测为表层检查**：作者自承规则过滤"不能保证检测出所有语义层面的答案泄露"。
- **额外推理成本未量化**：每轮需调用引导生成器（自引导或外部模型），训练总开销、墙钟时间与 GPU 小时数未报告。
- **统计稳健性不足**：未报告多随机种子方差、置信区间或显著性检验；主表为单次配置结果。
- **超参敏感度未充分探索**：ϵ、γ、ρ 仅用默认值，未做系统敏感性分析；K 的最优值（3）可能依赖数据集与模型规模。
