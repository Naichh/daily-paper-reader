## 摘要
尽管带可验证奖励的强化学习为VideoLLM提供了可靠的结果监督，但序列级奖励所能提供的词元级指导仍然有限。同策略自蒸馏通过让自教师模型以特权信息为条件，提供密集的词元级监督，从而缓解了这一局限。然而，在单一教师上下文中聚合异质证据，会掩盖不同证据之间的一致性与冲突。另一个挑战在于判断教师指导应当用于细化基于奖励的更新，还是为失败轨迹提供纠正性监督。为解决上述问题，我们提出MeSD，一种面向VideoLLM的多证据自蒸馏框架。MeSD构建了三个共享参数的证据条件化教师，以真实答案作为共同的语义上下文，同时分别引入时间证据与空间证据。在给定相同的学生生成前缀时，MeSD相对于答案教师评估各证据特有的偏好，并将教师共同偏好与门控的教师特有残差进行融合。此外，MeSD引入验证引导优化，将轨迹划分为成功、失败或不确定三类。对于成功与不确定轨迹，MeSD在保留由奖励导出的符号的同时，细化词元级优势的幅度。对于包含所需证据且经核验的失败轨迹，MeSD采用失败条件化蒸馏，利用反向KL校正使其趋近融合分布。在多个视频基准上的实验表明，相较于强化学习与自蒸馏基线，该方法取得了稳定一致的性能提升。

## Abstract
While reinforcement learning with verifiable rewards provides reliable outcome supervision for VideoLLMs, sequence-level rewards offer limited token-level guidance. On-policy self-distillation addresses this limitation by conditioning a self-teacher on privileged information to provide dense token-level supervision. However, aggregating heterogeneous evidence within a single teacher context obscures cross-evidence agreement and conflict. A further challenge lies in determining whether teacher guidance should refine reward-based updates or provide corrective supervision for failed trajectories. To address these issues, we propose MeSD, a multi-evidence self-distillation framework for VideoLLMs. MeSD constructs three evidence-conditioned teachers with shared parameters, using the ground-truth answer as a common semantic context while separately incorporating temporal and spatial evidence. Given the same student-generated prefixes, MeSD evaluates evidence-specific preferences relative to the Answer Teacher and fuses teacher-common preferences with gated teacher-specific residuals. Furthermore, MeSD introduces Verification-Guided Optimization to classify trajectories as Success, Failure, or Indeterminate. For Success and Indeterminate trajectories, MeSD refines token-level advantage magnitudes while preserving reward-derived signs. For verified failure trajectories that contain the required evidence, MeSD applies failure-conditioned distillation, using reverse-KL correction toward the fused distribution. Experiments on multiple video benchmarks demonstrate consistent gains over reinforcement learning and self-distillation baselines.

## 1. 核心问题与研究动机

- **背景**：VideoLLM 在视频问答与时空推理上进展显著，但复杂视频推理仍困难，要求模型在时间上定位关键事件、在空间上定位相关对象，并跨帧整合信息。
- **问题一：结果监督的粒度不足**。带可验证奖励的强化学习（RLVR）能提供可靠的结果级监督，但序列级奖励无法判断中间步骤是否正确使用了时序/空间证据，词元级监督因此变得关键。
- **问题二：同策略自蒸馏（OPSD）的局限**。OPSD 用学生模型在特权信息条件下充当教师，无需更强外部教师，但直接匹配特权教师分布易导致特权信息泄漏与训练不稳定；RLSD 等做法用奖励决定优势符号、用教师信号调整幅度，却只对采样词元重新加权，未真正对齐学生分布，对失败轨迹的纠正能力有限。
- **问题三：异构证据聚合的模糊性**。时序与空间证据在同一条推理轨迹上可能产生一致或冲突的词元偏好；把它们塞进单一教师上下文，会掩盖各自贡献及跨证据的一致/冲突关系。
- **核心追问**：如何建模异构特权证据？教师指导何时应用于细化奖励更新、何时应用于纠正失败轨迹？
- **整体含义**：论文提出 MeSD，据作者所述是**首个面向 VideoLLM 的多教师同策略自蒸馏框架**，把已有答案与 grounding 标注重组为多个证据条件化教师上下文，并按轨迹验证结果分派不同监督方式。

## 2. 方法论

### 2.1 总体框架
- 两个组件：**多证据自教师（Multi-Evidence Self-Teacher）** 与 **验证引导优化（Verification-Guided Optimization）**。
- 教师与学生共享参数（教师为 EMA 副本），只对已有学生轨迹做预测，不额外生成 rollout，教师预测全部 detach 以阻断梯度。

### 2.2 证据条件化教师
- 构建三个共享参数教师：**Answer（A）**、**Answer-Temporal（T）**、**Answer-Spatial（S）**。
- 以真值答案作为公共语义上下文（仅语义答案，不含时间区间/关键帧/框坐标）；T 额外加入标注时间区间或关键帧时间戳，S 额外加入对象名与变换后的边界框。

### 2.3 教师分布融合
- 以 Answer Teacher 为**锚点**，定义证据诱导的偏好变化：`dk(z) = log q̄k(z) − log q̄A(z)`，k ∈ {T, S}。
- **教师共同偏好**用几何均值（对数空间）定义：`G(z) = (1/J)Σ dk(z)`；**教师特异残差**用算术均值与几何均值之差定义：`D(z) = log[(1/J)Σ e^{dk(z)}] − G(z)`。几何均值强调被所有非锚教师共同支持、任一分低即被压低的词元；算术均值保留个体教师的强支持与互补证据。
- **双重门控**：方向一致门 `C(z) = |G(z)| / [(1/J)Σ|dk(z)| + ε]`，在证据偏好符号相反时抑制残差；幅度门 `H(z) = |G(z)| / (|G(z)| + D(z) + ε)`，限制残差相对共同偏好的贡献。
- 融合偏好 `f(z) = G(z) + C(z)H(z)D(z)`，据此对锚教师分布重新加权归一化得到融合分布 `q̄mv`。无语义答案时改用无特权锚教师；无辅助教师时保留原分布。

### 2.4 验证引导优化
- **轨迹验证**：任务专用验证器按所需输出组件给出 Success / Failure / Indeterminate。MCQ 看选项是否正确；时序定位看 tIoU（≥0.5 为正确，=0 为错误）；时序 MCQ 需选项与区间同时正确；无法解析或任务无显式规则记为 Indeterminate。
- **词元级优势细化（非失败轨迹）**：用教师-学生对数概率差 `Δi,t = sg[log q̄mv(y) − log p̄(y)]` 计算词元权重 `wi,t = exp(sign(Ai)·Δi,t)`，再在裁剪区间内缩放轨迹优势：`Acr = Ai[(1−λs) + λs·clip(wi,t, 1−εw, 1+εw)]`，保持奖励导出的符号不变，代入 GRPO 裁剪目标。
- **失败条件化蒸馏（合格失败轨迹）**：用反向 KL 替代该轨迹的策略损失，`ℓrkl = (1/T)Σ DKL(p̄rkl ‖ sg[q̂rkl])`，教师目标 detached，梯度只经学生；该损失不依赖优势 Ai，因此在组内优势为零时仍能提供纠正信号。
- **统一目标**：`Ls(θ) = (1/|Bs|) Σ [(1−gi)ℓcr_i + gi γs ℓrkl_i]`，gi 由数据有效性、结果合格性与教师证据可用性共同决定。
- **训练调度**：教师参数 EMA 更新（衰减系数 0.99）；λs 线性退火后，令 λs = gi = 0 恢复标准 GRPO。

### 2.5 关键工程细节
- 共享候选集：credit refinement 取各分布 Top-16，failure distillation 取 Top-32；后者额外设一个尾类别 ⊥ 承载候选集外概率，并对教师目标做 10⁻⁸ 概率下限后再归一化。
- 超参：λ0 = 0.5 在 1000 步内线性退火；γ 在 100 步内升到 0.8；教师监督截止步 H = 1000；词元权重裁剪 [0.8, 1.2]；学习率 10⁻⁶，AdamW，余弦调度，1 epoch。

- **消融结论**：
  - 证据分离与互补有效：单教师聚合全部证据（w/o ES）或仅答案教师（w/o T&S）均下降，TVGBench mIoU 从 29.8 掉到 22.4 / 22.3。
  - 门控融合必要：改为算术平均（w/o GPA）后 V-STAR mLGM 从 50.2 降至 41.4。
  - 失败条件化蒸馏是关键：去除后 mLGM 降 9.2、TVGBench mIoU 降 6.8，训练奖励平台更低。
  - 验证引导优化必要：退化为多证据 OPSD（w/o VGO）时 TVGBench mIoU 仅 20.7，且训练奖励下降。
  - 验证选择优于随机选择：随机选择 mLGM 45.6 / TVGBench 26.4，均低于验证失败选择的 50.2 / 29.8。
- **鲁棒性与可扩展性**：γ 与 H 在测试范围内奖励轨迹相近；默认 (γ=0.8, H=1000) 在多数基准最优。Qwen3-VL 4B/8B/32B 上 V-STAR mLGM 分别提升 28.6 / 24.5 / 17.2 点，四基准平均提升 7.2 / 5.7 / 5.7 点。
