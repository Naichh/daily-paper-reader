## 摘要
在线策略蒸馏（OPD）在由学生模型生成的轨迹上提供密集的教师监督，但生成和评估长展开会带来可观的训练成本。现有加速方法通过开环展开调度或闭环视界自适应来降低这一成本。然而，监督兼容性在不同轨迹之间可能差异很大，使得单一展开视界难以匹配它们异质的可靠长度：视界过短可能截断有用的监督，而过长则会在可靠区域之外浪费计算。我们的关键洞见是：轨迹特定的可靠性边界无需在生成之前预测。通过将可靠性视为累积的低教师-学生兼容性事件的首次到达，该边界在采样前本质上是未知的，但它是否已经到达却可以根据已观测前缀被精确判定。基于这一洞见，我们提出 Flash-OPD，它从展开视界控制转向自适应的轨迹级边界验证。Flash-OPD 将缓存生成与教师验证交错进行，并根据每条轨迹观测到的兼容性事件独立停止该轨迹。为降低验证开销，近期事件率仅用于调度下一次验证点，而实际停止决策始终依赖精确的累积计数。这种分离可防止估计误差导致过早终止，同时支持在生成过程中高效验证。在多种数据集和师生设置上的大量实验表明，Flash-OPD 相比标准 OPD 实现了 2.2 倍至 7.5 倍的加速，同时保持或提升了准确率。

## Abstract
On-policy distillation (OPD) provides dense teacher supervision on student-generated trajectories, but generating and evaluating long rollouts incurs substantial training cost. Existing acceleration methods reduce this cost through open-loop rollout schedules or closed-loop horizon adaptation. However, supervision compatibility can vary substantially across trajectories, making a single rollout horizon difficult to match their heterogeneous reliable lengths: an overly short horizon may truncate useful supervision, while an overly long one wastes computation beyond reliable regions. Our key insight is that the trajectory-specific reliability boundary need not be predicted before generation. By viewing reliability as the first-passage of accumulated low teacher--student compatibility events, the boundary is inherently unknown before sampling, yet whether it has been reached can be determined exactly from the observed prefix. Building on this insight, we propose *Flash-OPD*, which shifts from rollout-horizon control to adaptive trajectory-level boundary verification. *Flash-OPD* interleaves cached generation with teacher verification and independently stops each trajectory according to its observed compatibility events. To reduce verification overhead, the recent event rate is used only to schedule the next verification point, while the actual stopping decision always relies on the exact cumulative count. This separation prevents estimation errors from causing premature termination while enabling efficient verification during generation. Extensive experiments across diverse datasets and teacher--student settings show that *Flash-OPD* achieves $2.2\times$--$7.5\times$ speedups over standard OPD while maintaining or improving accuracy.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：在线策略蒸馏（On-Policy Distillation, OPD）在**学生模型自生成轨迹**上获取教师的密集 token 级监督，缓解了"训练—推理状态不匹配"问题，已成为前沿 LLM 后训练（能力迁移、专门教师巩固）的重要环节。
- **核心痛点**：由于监督是沿学生自身轨迹逐 token 获得的，**长轨迹的生成与教师评估代价极高**；同时，随着学生前缀漂移到低师生兼容性区域，后段教师信号的价值会显著下降。
- **现有方法的粒度缺陷**：
  - **开环调度**（POPD、TOPD、Prefix OPD）：按训练进度预设/逐步扩展 horizon。
  - **闭环自适应**（ADWIN 基于梯度余弦、Prune-OPD 基于 top-k overlap）：依据运行时信号动态调整。
  - **PG-OPD**：样本级但只做"保留/丢弃"的二值决策。
  - 以上方法**几乎都在 batch 级别共享一个 horizon**，而实际监督可靠长度是**轨迹特异且动态演化**的：horizon 过短会截断有效监督，过长则在不可靠区域浪费算力。
- **论文核心论点**：问题的关键不是"把共享 horizon 调得更聪明"，而是**为每条轨迹分配各自的 rollout 长度**，把 rollout-horizon control 转变为**轨迹级可靠性边界验证**。

## 2. 方法论

### 2.1 核心思想：把可靠性边界视为"首次到达时间"

- 用 **teacher–student top-k 重叠**作为局部兼容性代理，定义**低兼容事件**：
  - φ_τ = 1[ |K^S_τ ∩ K^T_τ| / k < η ]，η ∈ (0,1) 为兼容阈值。
- 累积事件并定义**可靠性边界（usable length）**：
  - c_τ = Σ_{i=1..τ} φ_i
  - **E = min{ τ : c_τ ≥ B }**，B 为允许的低兼容事件预算。
- **E 的三个关键性质**：
  1. **轨迹特异**（trajectory-specific）；
  2. 是整数值过程的**精确首次到达时间**，不是需要估计的量；
  3. 是**后验的**——采样前本质未知。

### 2.2 关键洞见与转折

- 虽然 E 的位置事前未知，但**"是否已越过边界"可由已观测前缀精确判定**。
- 利用 OPD 的两条性质：
  - **Locality**：位置 τ 的奖励 r_{τ,·} 只依赖 (x, y_{≤τ})；
  - **Permanence**：前缀固定后，扩展轨迹不改变已有位置的监督信号。
- 因此可以在生成过程中**交错进行"缓存生成 + 教师验证"**，做到"边生成边判定、按需停止"，且不改变已计算前缀的监督。

### 2.3 算法流程（Flash-OPD）

对每条轨迹维护验证位置 k（初始 k₀）与累积计数 c（初始 0），循环三步：

1. **Generate to k**：从当前缓存前缀续写至验证点 k（prefix caching，避免重复解码）。
2. **Verify count**：在新生成位置上做教师评估，按上式更新 c ← c_k（精确计数）。
3. **Stop or Advance**：
   - 若 c ≥ B 或 k ≥ L_max → 设 Ê = k，停止该轨迹；
   - 否则按下式推进验证点：
     - k ← k + max( k_min , ⌈ρ(B − c)/λ̂_k⌉ )，其中 λ̂_k = (c_k − c_{k−W}) / W。
   - λ̂_k 为最近窗口 W 内的**局部事件率**，B − c 为剩余事件预算，ρ ∈ (0,1] 为步长折扣。

### 2.4 两个关键的机制性设计

- **估计与判定分离**：估计的事件率 λ̂ **只用于调度下一次验证点**；真正的停止判定始终依赖**精确累积计数 c_k ≥ B**。
- **理论保证**：
  - **命题 1（Stopping Guarantee）**：对任意 ρ、W、任意 λ̂ 实现，都有 **Ê^(b) ≥ E^(b)**，即不会过早截断。
  - **复杂度**：轮数 R ≤ 1 + ⌈(L_max − k₀)/k_min⌉；速率近似稳定时 R = O(log B)。
  - 每步只做解码与教师评估，**不引入额外开销**；由于 prefix caching，每个 token 只解码一次。
- **实现细节**：块内扫描找到首次跨越位置 s，只保留 y_{≤s}（丢弃块内越界 token），处理 EOS/长度上限三种终止情形；公式中 0 事件率时直接将下一验证点推到 L_max。
