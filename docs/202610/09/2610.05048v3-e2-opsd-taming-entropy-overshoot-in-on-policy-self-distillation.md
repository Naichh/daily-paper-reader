## 摘要
同策略自蒸馏（OPSD）无需第二个模型即可提供稠密的 token 级监督：同一个网络在给定参考答案时充当教师，在仅给定问题时充当学生。我们识别出该配方的一种特定失效模式。训练过程中，学生的 token 熵会升高并超过教师，且持续保持较高水平，我们将这一现象称为熵超调。我们将其归因于蒸馏的双方。以参考答案为条件的教师在其面向答案的推理路径上很自信，但这种自信很难迁移到学生生成的 prefix 上，使其监督过度绑定于答案特定线索，而非可复用的推理模式；与此同时，OPSD 使用的前向 KL 会持续扩散学生的预测分布，却不将其拉回。我们提出 E$^2$-OPSD 来解决这两个原因。示例引导教学用检索到的已求解邻近问题替换当前答案，在不泄露最终目标的同时提供可迁移的推理指导，并更好地匹配学生可达状态。熵感知蒸馏利用学生-教师熵差来决定每个 token 修正的方向和强度。E$^2$-OPSD 在 mean@16 上相较于 OPSD 将数学推理提升最多 4.3 分，而域外评估显示，相较于相应基座模型，在 mean@16 上最多提升 4.9 分，在 pass@8 上最多提升 5.5 分。尽管有这些提升，E$^2$-OPSD 仍然简单，不需要额外的前向传播或网络。

## Abstract
On-policy self-distillation (OPSD) provides dense token-level supervision without a second model: one network acts as teacher with the reference solution and as student with only the problem. We identify a specific failure mode of this recipe. During training, student token entropy rises past the teacher's and remains elevated, a pattern we call entropy overshoot. We trace it to both sides of distillation. The reference-conditioned teacher is confident along its answer-directed reasoning path, but this confidence transfers poorly to student-generated prefixes, making its supervision overly tied to answer-specific cues rather than reusable reasoning patterns; meanwhile, the forward KL used by OPSD continually diffuses the student's predictive distribution without pulling it back. We introduce E$^2$-OPSD to address both causes. Exemplar-guided teaching replaces the current answer with a retrieved solved neighboring problem, providing transferable reasoning guidance without revealing the destination and better matching student-reachable states. Entropy-aware distillation uses the student-teacher entropy gap to determine the direction and strength of each token's correction. E$^2$-OPSD improves math reasoning by up to 4.3 points in mean@16 over OPSD, while out-of-domain evaluations show gains over the corresponding base models of up to 4.9 points in mean@16 and 5.5 points in pass@8. Despite these gains, E$^2$-OPSD remains simple, requiring no additional forward passes or networks.

## 1. 核心问题与整体含义

- **背景**：RLVR 提供可验证奖励但监督粗糙，整个 rollout 仅压缩为一个标量；同策略蒸馏（OPD）可在学生自身 rollout 上提供 token 级稠密监督，但通常需要更强且同词表的教师模型。OPSD 进一步去掉第二模型：同一网络在教师上下文看到参考答案，在学生上下文只看到问题，并在学生生成 prefix 上用前向 KL 对齐。
- **核心问题**：论文识别出 OPSD 的典型失效模式——**熵超调**。训练中学生会变得比教师更不确定，token 熵越过教师后持续偏高，导致有用探索变成持续过度不确定，削弱学生决断性。
- **归因**：
  - **教师侧**：参考答案条件使教师沿“已知答案”路径自信推理，但这种自信难迁移到学生生成的 prefix 上，监督过度绑定当前答案线索，而非可复用推理模式。
  - **学生侧**：OPSD 固定使用前向 KL，具有 mode-covering 偏差，持续扩散学生预测分布，却缺少把分布拉回集中的反向力。
- **整体含义**：有效自蒸馏不应只最大化模仿，而应让教师指导匹配学生可达状态，并动态调节“何时探索、何时集中”。

## 2. 方法论：E²-OPSD

- **总体思路**：E²-OPSD 从“学什么”和“怎么学”两侧修复 OPSD：
  - **Exemplar-Guided Teaching, EGT**：改变教师条件上下文。
  - **Entropy-Aware Distillation, EAD**：改变学生匹配教师的方式，包含 **Bidirectional Entropy Routing, BER** 与 **Adaptive Gap Damping, AGD**。
- **EGT：示例引导教学**
  - 标准 OPSD 教师条件为当前问题及其参考答案 \(y^*\)。
  - EGT 将当前参考答案替换为检索到的**已求解邻近问题** \((x', y'^*)\)。
  - 离线用 Qwen3-Embedding-8B 嵌入训练题，计算余弦相似度，保留每题的 \(K=15\) 个最近邻。
  - 每个问题的第 \(g\) 个 rollout 均匀抽取一个邻近题，种子由训练种子、步数、问题、rollout 槽确定。
  - 教师看到：当前问题 + 相关题及其解 + 学生 prefix；学生仍只看到当前问题和自身 prefix。
  - 目的：不泄露当前答案，只传递可迁移策略，使教师指导更贴近学生可达的推理状态。
- **EAD：熵感知蒸馏**
  - 定义学生分布 \(p_t(v)\) 与教师分布 \(q_t(v;r)\)，以及 token 级熵差：
    \[
    \Delta_t = H(p_t)-H(q_t)
    \]
  - **BER：双向熵路由**
    - 当 \(\Delta_t \le 0\)，学生相对教师更集中，使用**前向 KL**，鼓励覆盖教师支持但学生未覆盖的替代项，促进探索。
    - 当 \(\Delta_t > 0\)，学生相对教师更弥散，使用**反向 KL**，抑制学生不支持的概率质量，促进集中。
    - 在教师 top-\(K_v\) token 加 tail bucket 上计算，保留 OPSD 的逐元素裁剪 \(\tau\)。
  - **AGD：自适应 gap 阻尼**
    - 用熵差幅度作为置信权重，抑制接近零的敏感路由，强化明显师生熵不匹配的 token。
    - 权重形式：
      \[
      c_t=\frac{\Delta_t^2}{\Delta_t^2+\max(\sigma^2,\epsilon^2)}
      \]
      其中 \(\sigma^2\) 为当前 mini-batch 有效 response token 上 \(\Delta^2\) 的均值。
    - 小 gap 被抑制，大 gap 保留更多更新；\(\sigma^2\) 每 mini-batch 重算，无需人工阈值。
  - **训练目标**：对每个有效 response token
