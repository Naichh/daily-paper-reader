## 摘要
角色提示通过专家身份从大型语言模型中激发专门行为，提供了一种轻量级方式来引导对高要求任务的推理。然而，当采样得到的解答仍然不正确时，评估或蒸馏完整的角色提示答案可能会遗漏有用的下一词元偏好。迁移这些偏好还需要一个目标，能够触及学生模型很少预测的备选项。我们提出 OPSRD，它使用固定的专家角色作为特权教学上下文，用于无需参考解答的同策略自蒸馏。一个无角色学生模型生成轨迹，同一基础模型的冻结实例在其精确前缀上提供角色条件分布，从而暴露出采样续写之外的备选项。教师加权的正向 KL 针对学生模型低估的备选项，并通过裁剪限制单个词表项的贡献。监督被限制在学生模型位置中熵最高的一半，将学习集中在预测不确定的位置。在三个竞赛数学基准上，使用 Qwen3-1.7B、4B 和 8B 的实验表明，相较于推理时不使用角色提示的基础模型，性能有所提升。在所有规模上，前向 KL 在三种被评估的散度中取得了最高的宏平均准确率。代码可在 https://github.com/zhansan114514/OPSRD 获取。

## Abstract
Role prompting elicits specialized behavior from large language models through an expert identity, offering a lightweight way to guide reasoning on demanding tasks. However, evaluating or distilling complete role-prompted answers can miss useful next-token preferences when the sampled solution remains incorrect. Transferring these preferences also requires an objective that reaches alternatives the student rarely predicts. We introduce OPSRD, which uses a fixed expert role as privileged teaching context for on-policy self-distillation without reference solutions. A role-free student generates a trajectory, and a frozen instance of the same base model supplies role-conditioned distributions on its exact prefixes, exposing alternatives beyond the sampled continuation. Teacher-weighted forward KL targets alternatives the student underestimates, with clipping to limit individual vocabulary contributions. Supervision is restricted to the highest-entropy half of student positions, concentrating learning where predictions are uncertain. Experiments on three competition-math benchmarks with Qwen3-1.7B, 4B, and 8B show improvements over the base models without role prompts at inference. Forward KL achieves the highest macro-averaged accuracy among the three evaluated divergences at every scale. Code is available at https://github.com/zhansan114514/OPSRD.

## 1. 核心问题与整体含义（研究动机与背景）

- **角色提示（Role Prompting）的局限**：通过专家身份（如"奥数专家"）引导大模型推理是一种轻量手段，但现有评估与蒸馏方法只看**完整生成答案**，会把角色带来的局部影响与整条解轨迹的采样效果混在一起。一条有用的"下一 token 偏好"可能根本没被采样到，或者后面被一个错误步骤覆盖。
- **一个关键负结果**：在 Qwen3-1.7B 上，给普通提示加入"奥数专家"角色后，三个竞赛数学基准的宏平均准确率从 **35.74 降到 34.54**，中性系统提示也得到同样分数——说明**角色标签本身不足以改善完整采样解**。
- **核心假设**：角色的价值不在于完整答案，而在于它能在**学生实际面临的不确定前缀**上，把概率质量移向更有帮助的续写。即使完整角色答案没有可测收益，其**前缀条件分布**仍可作为教学信号。
- **待解决问题**：能否在没有每题参考答案的前提下，让一个可复用的专家角色监督学生自己的推理轨迹？

## 2. 方法论

### 2.1 核心思想
- 使用**固定的专家角色**作为特权教学上下文，进行**无需参考答案**的同策略自蒸馏（On-Policy Self-Distillation）。
- 学生（无角色）生成轨迹；**同一基座模型的冻结副本**（关闭学生 LoRA、加专家角色）在学生的**精确前缀**上给出角色条件分布，暴露采样续写之外的备选项。
- 仅更新学生 LoRA；教师冻结；部署时用普通提示词推理。

### 2.2 关键技术细节
- **前缀对齐**：学生采样轨迹 $y_{1:T}\sim p_\theta(\cdot\mid c_S,x)$，token 已 detach；师生在同一 $y_{<t}$ 上前向，温度 $\eta=1.1$，教师用完整词表打分。
- **学生熵选择**：按学生分布计算每位置熵 $H_t=-\sum_v p^S_t(v)\log p^S_t(v)$，每条序列内保留熵最高的 $k=\max(1,\lceil\rho T\rceil)$ 个位置（默认 $\rho=0.5$）。选择用 detach 的 logits，不传梯度。
- **裁剪前向 KL 目标**：
  - 单位置未裁剪前向 KL：$D_t=\sum_v p^T_t(v)\log\frac{p^T_t(v)}{p^S_t(v)}$
  - 逐词表项裁剪：$d_{t,v}\leftarrow\min\{d_{t,v},\tau\}$，$\tau=0.05$（1.7B/4B）、$0.06$（8B）
  - 批损失：对选中位置求和词表贡献、对选中 token 取平均；未裁剪散度单独记录用于监控。
- **为何用前向 KL**：
  - 前向 KL 梯度 $\partial D_F/\partial z^S_j=(p^S(j)-p^T(j))/\eta$——当教师支持某个学生几乎不预测的续写时，直接抬高其 logit。
  - 反向 KL 梯度含 $\log(p^S/p^T)-D_R$ 因子，当 $p^S(j)\to 0$ 时更新消失，**无法触及学生低估的替代项**。
- **角色放置不对称**：教师独占角色，学生在 rollout 与评估中都无角色；消融对比"教师独占 / 共享 / 仅学生"三种放置。

## 3. 实验设计

### 3.1 数据集与基准
- **训练数据**：来自 OpenThoughts 的数学 split（`siyanzhao/Openthoughts_math_30k_opsd`），共 **29,434 例**。
- **评测基准**：AIME 2024、AIME 2025、HMMT February 2025，各 30 题；每题采样 12 次（Avg@12），temperature 1.0、top-p 0.95、生成上限 38,912 tokens。
- **模型**：Qwen3-1.7B / 4B / 8B，各模型自任教师（冻结同基座实例）。

### 3.2 对比方法
| 类别 | 方法 |
|---|---|
| 推理时提示 | Base、Base + 专家角色、Base + 中性提示 |
| 蒸馏基线 | Answer OPSD（教师带参考答案）、Role full（全位置蒸馏专家教师）、Neutral full（中性教师全位置蒸馏） |
| 本文方法 | **OPSRD**（专家教师 + 高熵 50% 位置 + 裁剪前向 KL） |

### 3.3 训练配置
- LoRA rank 64、scale 128（q/k/v/o/gate/up/down），AdamW，100 步，lr $5\times10^{-6}$，有效 batch 36，每题 1 条 rollout（上限 1,024 tokens）。
- 统计：问题级配对 bootstrap 重采样（主比较 10,000 次，散度比较 50,000 次）；1.7B 做 3 次独立训练重复，4B 对固定 checkpoint 做 4 次评测重复。

## 6. 主要结论与发现

- **角色从"提示"变为"监督"后才有效**：直接专家提示 34.54（≈Base 35.74），而教师角色全位置蒸馏 40.09，OPSRD **42.04**（+6.30 pp，95% 区间 [3.24, 9.54]），并比 Answer OPSD 高 3.33 pp（区间 [0.83, 6.02]）。
- **跨规模有效**：1.7B/4B/8B 相对 Base 分别 +6.30 / +1.67 / +3.06 pp；随基线准确率升高增益缩小，但非单调。
- **前向 KL 在各规模宏平均最高**：1.7B 上比反向 KL 高 4.81 pp（区间 [2.41, 7.31]）；4B/8B 的区间跨零，结论以 1.7B 最清晰。
- **角色应放在教师端**：仅教师条件 42.04；共享角色 −3.06 pp；仅学生角色 −3.80 pp；且评测时再加角色反而降低所有 checkpoint 的分数。
- **监督一半位置即可保留收益**：高熵 50% 相对全位置 +1.94 pp（区间跨零），三次训练重复平均差 0.77 pp；选中位置平均熵 0.874 vs 未选 0.023，说明掩码确实集中在不确定预测上。
- **收益机制**：90 题中 38 题提升、12 题下降；只有 7 题从"Base 无正确样本"变为"有正确样本"，6 题反向——**主要收益是让本已偶尔能解出的题更稳定解出**，而非获得全新解题能力。格式合规 >99%，生成长度不是主因。

## 7. 优点

- **问题设定新颖且务实**：把"角色提示收益不稳定"这一负面现象转化为"角色作为特权教学上下文"的正向方法，无需参考答案，教学信号可跨题复用。
