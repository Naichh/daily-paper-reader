## 摘要
基于可验证奖励的强化学习（RLVR）为语言模型推理提供了可靠的结果监督，但标量轨迹奖励提供的令牌级指导有限。现有的自我蒸馏方法添加了一个特权教师，但通常为其分配固定角色：直接分布匹配可能破坏成功行为，而仅幅度调制在失败后提供很少的纠正性指导。我们观察到成功和失败的轨迹需要不同形式的后见监督。成功的响应已经包含有效的学生生成推理路径，因此可以作为特权上下文，而不是被外部原理替换。然而，失败的响应需要纠正性参考信息。我们引入了混合后见自我蒸馏（$\mathrm{H}^{2}\mathrm{SD}$），该方法联合调整教师上下文和更新策略以适应轨迹正确性。对于成功轨迹，我们从验证后的响应和改写指令构建教师上下文，并仅使用教师重新评估原始响应令牌。所得概率细化了令牌信用分配，而不改变由奖励确定的方向。对于失败轨迹，经过验证的参考提示通过反向KL蒸馏提供纠正性指导。在具有挑战性的推理基准上的实验表明，H$^2$SD在代表性RLVR和自我蒸馏基线中实现了最强的整体性能，具有稳定的优化和有利的准确率-效率权衡。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) provides reliable outcome supervision for language model reasoning, but a scalar trajectory reward offers limited token-level guidance. Existing self-distillation methods add a privileged teacher but typically assign it a fixed role: direct distribution matching may destabilize successful behavior, while magnitude-only modulation offers little corrective guidance after failure. We observe that successful and failed trajectories require different forms of hindsight supervision. A successful response already contains a valid student-generated reasoning path and can therefore serve as privileged context rather than being replaced by an external rationale. A failed response, however, requires corrective reference information. We introduce Hybrid Hindsight Self-Distillation ($\mathrm{H}^{2}\mathrm{SD}$), which jointly adapts teacher context and update strategy to trajectory correctness. For successful trajectories, we construct the teacher context from the verified response and a rephrasing instruction, and use the teacher only to re-evaluate the original response tokens. The resulting probabilities refine token credit assignment without changing the direction determined by the reward. For failed trajectories, a verified reference hint provides corrective guidance through reverse-KL distillation. Experiments on challenging reasoning benchmarks show that H$^2$SD achieves the strongest overall performance among representative RLVR and self-distillation baselines, with stable optimization and a favorable accuracy-efficiency trade-off.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **问题背景**：基于可验证奖励的强化学习（RLVR，如GRPO）能提升大语言模型的推理能力，但仅提供标量轨迹奖励，缺乏令牌（token）级别的细粒度指导，导致信用分配瓶颈——模型难以知道哪些令牌导致了成功或失败。
- **现有方法局限**：
  - 在线策略蒸馏（OPD）依赖更强的外部教师模型，且需共享词表，应用受限。
  - 在线策略自蒸馏（OPSD）通过特权信息（如正确答案）构建教师，但直接分布匹配可能导致训练不稳定和信息泄露。
  - RLSD通过教师信号仅调节令牌更新幅度，避免信息泄露，但无法在失败时提供方向性纠正（仅幅度调制不足以修正错误路径）。
- **核心观察**：成功轨迹和失败轨迹需要不同形式的“后见监督”：
  - 成功轨迹已包含有效推理路径，应作为特权上下文保留，而非被外部原理替换。
  - 失败轨迹则需要纠正性参考信息（如提示）。
- **整体含义**：提出**混合后见自我蒸馏（H²SD）**，根据轨迹正确性动态调整教师上下文和更新策略，同时实现稳定的令牌级信用分配和有效的方向性修正。

## 2. 方法论：核心思想、关键技术细节、算法流程
### 核心思想
- **成功轨迹**：使用学生自身的已验证正确响应和“改写指令”构建教师上下文，教师仅重新评估原始响应令牌的概率，用于幅度调制（类似RLSD），不改变奖励确定的方向，仅细化令牌信用分配。
- **失败轨迹**：使用外部提示（hint）作为特权信息，通过**反向KL散度**（reverse KL divergence）将学生分布向教师分布对齐，提供显式的方向性修正。
- **提示生成**：使用更强的语言模型（如Kimi-K2.6）离线生成自然语言提示，包含关键中间推理步骤和最终答案（由验证器确认）。提示仅在训练时作为教师特权信息，不参与推理。
- **整体流程**：
  - 学生模型采样多个响应。
  - 根据奖励判断轨迹正确性（成功/失败）。
  - 成功轨迹：计算RLSD损失（基于教师改写指令下的概率差值），调节更新幅度。
  - 失败轨迹：计算反向KL损失（基于提示条件教师分布），进行分布修正。
  - 总损失：$\mathcal{L}_{\mathrm{H}^{2}\mathrm{SD}} = \mathbb{E}_{x,y} [ m \mathcal{L}_{\mathrm{RLSD}} + \gamma (1-m) \mathcal{L}_{\mathrm{RKL}} ]$，其中 $m$ 为正确性指示变量，$\gamma$ 控制失败轨迹修正强度。

### 关键公式与细节
- **RLSD回顾**：对于每个令牌，计算 $\Delta_t = \log P_T(y_t) - \log P_S(y_t)$，然后加权幅度 $w_t = \exp(\operatorname{sign}(A) \cdot \Delta_t)$，最终令牌优势 $\hat{A}_t = A[(1-\lambda) + \lambda \operatorname{clip}(w_t, 1-\epsilon_w, 1+\epsilon_w)]$。
- **反向KL**：$\mathcal{L}_{\mathrm{RKL}} = \frac{1}{T} \sum_{t=1}^{T} D_{\mathrm{KL}}(p_{t,\theta}^S \| \operatorname{sg}[p_{t,\theta}^{T,h}])$，阻止梯度流向教师分布。
- **改写指令**：对于成功轨迹，教师收到“重述正确响应”指令（但不生成重写文本），仅用于改变评分方式，避免答案泄露并增强对齐。

- **H²SD在所有基准上取得最佳平均性能**，特别是在Sudoku上优势显著（准确率从约25-30%跃升至76.5%和57.25%）。
