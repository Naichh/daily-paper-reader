## 摘要
基于可验证奖励的强化学习（RLVR）是提升语言模型推理能力的一种强大方法，但在每个新的强模型上重复运行成本高昂，因为目标模型在训练期间必须生成大量轨迹。随着模型规模扩大，后训练本身成为瓶颈。我们研究了一种从弱到强的替代方案：在轨迹生成成本更小的较小模型上运行强化学习，然后重用该强化学习的结果来改进更强的目标模型。直接蒸馏强化学习后的弱教师模型是不够的，因为教师的最终策略混合了有用的RL收益和小模型的局限性。我们提出了直接在线策略蒸馏（Direct-OPD），它转而传递教师模型由RL引发的策略偏移。Direct-OPD将强化学习后的教师与其自身强化学习前的参考模型进行比较，并将其对数比率作为学生模型的密集隐式奖励。简而言之，这一检查点对告诉我们RL使弱模型更可能或更不可能采取哪些动作，而Direct-OPD在更强的学生模型的自身在线状态上应用这一信号。这直接重用了弱模型的RL监督信号，无需训练显式的奖励模型或在目标模型上运行稀疏奖励的强化学习。实验表明，Direct-OPD能够持续利用较弱的教师模型来改进较强的目标模型；值得注意的是，在8块A100 GPU上仅用4小时，它就在AIME 2024上将Qwen3-1.7B从48.3%提升至62.4%。它超越了逐步骤匹配的直接强化学习，并支持多个策略偏移的顺序组合。我们的结果表明，强化学习的结果可以作为隐式奖励信号跨模型规模重用，而不仅仅是作为最终模型来模仿。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) is a powerful recipe for improving language-model reasoning, but it is expensive to repeat on every new strong model because the target model must generate many rollouts during training. As models scale, post-training itself becomes a bottleneck. We study a weak-to-strong alternative: run RL on a smaller model where rollouts are cheaper, then reuse what that RL run learned to improve a stronger target model. Directly distilling the post-RL weak teacher is not enough, because the teacher's final policy mixes useful RL gains with the limitations of the smaller model. We propose Direct On-Policy Distillation (Direct-OPD), which transfers the teacher's RL-induced policy shift instead. Direct-OPD compares the post-RL teacher with its own pre-RL reference and treats their log-ratio as a dense implicit reward for the student. In plain terms, the checkpoint pair tells us which actions RL made the weak model more or less likely to take, and Direct-OPD applies that signal on the stronger student's own on-policy states. This directly reuses the weak model's RL supervision signal without training an explicit reward model or running sparse-reward RL on the target model. Empirically, Direct-OPD consistently leverages weaker teachers to improve stronger target models; notably, it boosts Qwen3-1.7B from 48.3% to 62.4% on AIME 2024 in just 4 hours on 8 A100 GPUs. It outperforms step-matched direct RL and enables the sequential composition of multiple policy shifts. Our results show that RL outcomes can be reused across model scales as implicit reward signals, not merely as final models to imitate.

## 1. 核心问题与整体含义（研究动机和背景）

- 基于可验证奖励的强化学习（RLVR）是提升大语言模型推理能力的主流后训练方法，但在每个新的大模型上从头运行 RL 成本极高，因为每次更新都需要目标策略生成大量在线轨迹。随着模型规模扩大，后训练本身成为瓶颈。
- 为解决此问题，论文提出一种**弱到强（weak-to-strong）**的替代范式：在计算成本低的小模型上运行 RL，然后将该 RL 过程中学习到的有用信号转移到更强的目标模型，避免直接在强模型上做昂贵的 RL 训练。核心洞察是：RL 的结果不应仅被当作最终模型来模仿，而应被重用为跨模型规模的隐式奖励信号。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：不直接蒸馏弱教师的最终策略（πT），而是蒸馏其**策略偏移（policy shift）**，即 RL 训练前后的对数概率差：ΔT(y|x) = log πT(y|x) − log πTref(y|x)。该偏移等价于（在 KL 正则化 RL 框架下）教师模型的隐式奖励，因为它与 KL 正则化 RL 的最优解形式一致（π* ∝ πref exp(r/β)），因此 ΔT 提供了稠密的、逐 token 的奖励信号。
- **Direct-OPD 目标**：在强学生模型 πθ 的自身在线状态（on-policy states）上应用该偏移，同时通过 KL 项约束学生不偏离其初始化 πS：
  JDirect-OPD = E_{x} [E_{y~πθ}[ΔT(y|x)] − α D_KL(πθ || πS)]。
  这一目标等价于让学生以 πS 为参考、以教师隐式奖励 rT/αβ 为奖励的 KL 正则化 RL 优化。
- **关键技术细节**：
  - **Token 级分解**：ΔT 可分解为各 token 的偏移之和，从而在每一步都提供稠密奖励。
  - **Top-k 动作空间限制**：在每个 student 访问的前缀上，只考虑 student 的 top-k token 集合，并对该集合内的分布重归一化，以降低计算量和稳定优化。
  - **Rao-Blackwellized 梯度估计**：利用 top-k 上的期望代替单 token 采样，减少梯度方差。
  - **自适应 KL 控制**：由于 ΔT 的尺度依赖于教师训练时不可见的超参数（β），论文提出一个轻量级控制器，根据批平均隐式奖励的符号动态调整 α，使奖励信号保持在平衡范围内，避免学生过度放大或忽略局部信号。

## 6. 主要结论与发现

- Direct-OPD 能**一致地将弱教师的 RL 策略偏移转移到更强的学生**，即使学生初始精度已超过教师（例如 R1-Distill-7B 从 56.7% → 63.1%）。
- 在相同 RL 步骤下，**弱→强路线在精度和计算成本上都优于直接在大模型上做 RL**（图3）。
- 多个独立 RL 训练学到的策略偏移可以**顺序组合**，实现增益叠加（图4）。
- 成功的转移**不依赖 token 级别的重叠**；即使教师与学生思考模式不同，Direct-OPD 仍能通过隐式奖励在 student 的在线状态上起作用。
- 短 horizon（2k tokens）训练足以捕获可转移的信号，并泛化到长序列上；过长的训练 horizon 可能引入噪声。
- **自适应 KL 控制**能使隐式奖励保持在平衡区域，避免学生过度优化不可靠的偏移信号。

## 7. 优点：方法与实验设计的亮点

- **概念创新**：将 RL 结果视为**隐式奖励**而非最终策略来复用，这是弱→强泛化的新范式。
- **低成本高效益**：仅需小模型 RL 和短时间转移训练，大幅降低后训练成本。
- **强泛化能力**：跨不同教师对（JustRL、QuestA）、学生家族（DeepSeek、Qwen3）、思考模式（思考型 vs 非思考型）均有效。
- **分析深入**：不仅报告精度，还从重叠率、熵、累积 gap、KL 控制等角度揭示了方法的运作机理，提供了宝贵的可解释性。
- **实用性强**：可以顺序组合来自不同训练策略的偏移，为未来模块化提升模型能力提供了可能。

## 8. 不足与局限

- **信号的条件可靠性**：教师偏移只在学生访问的状态上才有意义，若学生偏离两个教师的分布，log-ratio 可能变得噪声大甚至误导。论文承认这是条件性的。
- **超参数依赖**：最佳响应长度和 KL 强度仍依赖具体的教师-学生对，没有完全自动化的通用选择。
- **任务单一**：所有实验仅在数学推理基准（AIME 2024/2025）上进行，未验证在编程、常识推理或开放生成任务上的表现。
- **教师 RL 过程的局限**：论文假设教师 RL 已经收敛或达到某个有意义的偏移，但若教师 RL 本身震荡或过拟合，可能影响后续转移。
- **未探讨极端弱教师**：教师与学生的能力差距如果过大（例如 1.5B → 13B+），转移效果可能下降，文中未系统测试边界。
- **依赖 checkpoint 对**：需要提前保存教师 RL 前的参考检查点，对于未保存参考的已有 RL 模型，无法直接应用。
- **实验规模**：尽管算力对比合理，但直接 RL 的基线只训练了数千步，未探索大规模、长时间 RL 场景；长期对比有待验证。
