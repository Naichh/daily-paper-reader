## 摘要
扩散大语言模型（dLLM）通过对掩码序列进行迭代去噪来生成文本，为自回归模型提供了一种并行替代方案，但通过后训练来引发强推理仍然困难：监督微调是离策略的，并且遭受曝光偏差，而强化学习仅提供稀疏的序列级奖励，且在没有可处理的序列似然的情况下难以应用。在线策略自蒸馏（OPSD）提供了一种有前景的替代方案，使用同一个模型作为学生和教师，提供密集的、令牌级别的、在线策略的监督，但其有效性依赖于给教师提供特权信息（PI）——通常是推理时不可用的实例特定真实参考——因此学生最终蒸馏出弱无PI共识策略，对dLLM推理改进甚微。我们提出dOPSD，它直接从学生自己的去噪轨迹中推导教师的特权，使用同一轨迹中更靠后、更已解码的步骤来评估掩码位置，而不是外部标签，因此教师的优势来自模型自身的解码过程；在Dream和LLaDA上，dOPSD改进了领域内数学推理和领域外代码生成，优于监督和在线策略基线。

## Abstract
Diffusion large language models (dLLMs) generate text by iteratively denoising a masked sequence, offering a parallel alternative to autoregressive models, but eliciting strong reasoning through post-training remains difficult: supervised fine-tuning is off-policy and suffers from exposure bias, while reinforcement learning gives only sparse, sequence-level rewards and is hard to apply without tractable sequence likelihoods. On-policy self-distillation (OPSD) offers a promising alternative, using one model as both student and teacher to provide dense, token-level, on-policy supervision, but its effectiveness hinges on giving the teacher privileged information (PI) - typically an instance-specific ground-truth reference unavailable at inference - so the student ends up distilling a weak PI-free consensus policy that yields little improvement on dLLM reasoning. We introduce dOPSD, which instead derives the teacher's privilege directly from the student's own denoising trajectory, evaluating masked positions using later, more-decoded steps of that same trajectory rather than an external label, so the teacher's advantage emerges from the model's own decoding process; on Dream and LLaDA, dOPSD improves both in-domain math reasoning and out-of-domain code generation, outperforming supervised and on-policy baselines.

## 一、论文的核心问题与整体含义（研究动机和背景）

扩散大语言模型（dLLM）通过迭代去噪掩码序列生成文本，是自回归模型的并行替代方案，拥有并行解码、双向上下文等优势。然而，后训练阶段激发其推理能力面临两大困难：

- **监督微调（SFT）** 是 off-policy 的，存在曝光偏差（exposure bias）；
- **强化学习（RLVR）** 仅提供稀疏的序列级奖励，且扩散模型缺乏可处理的序列似然，难以直接应用。

已有的 **OPSD（On-Policy Self-Distillation）** 方法在自回归模型上取得较好效果，它让同一模型扮演学生和教师，教师额外获得外部特权信息（PI，如真实参考解），提供密集的、token 级、on-policy 的监督。但 OPSD 转移到扩散模型时存在两个根本缺陷：

1. **PI 是外部且实例特定的**：推理时学生无法看到 PI，导致学生只能蒸馏出弱 PI 去边缘化的共识策略，性能提升有限。
2. **随机掩码偏离解码路径**：随机掩码 finished rollout 产生的中间状态是模型推理时从未访问过的，导致训练信号失配。

因此，论文的核心问题是：**如何在不依赖外部参考解的情况下，为扩散语言模型提供密集、on-policy、自生成的监督信号**。

## 二、论文提出的方法论

### 核心思想
dOPSD 的核心洞察是：扩散模型自身的去噪轨迹天然蕴含了“窥视未来”的特权。随着逐步去噪，后面步骤的上下文比前面步骤更完整。因此，**教师可以取自学生自己解码轨迹中更靠后的步骤**，而非外部参考解。这保证了：

- 教师特权是 on-policy 且自生成的；
- 学生采样的中间状态是真实解码路径上的（而非随机掩码）；
- 无需外部标签（参考解），仅在需要验证时使用最终答案。

### 关键技术细节

#### 1. 轨迹记录与步骤采样
- 学生对一个 prompt x 完整解码得到一条轨迹 \( s_0, s_1, \ldots, s_K = \hat{y} \)，其中 \( s_k \) 是在第 k 步的部分完成序列（未解码位置为 [MASK]）。
- 随机选取一个中间步骤 \( k \)，要求其掩码比例 \( |M_k|/L > \tau \)（默认 \( \tau=0.5 \)），确保有足够多的待预测位置。

#### 2. 教师目标构造
- 对于步骤 k 时仍被掩码的位置 \( i \in M_k \)，定义集合 \( T_i = \{ t: k < t \le K, i \in M_t \} \)，即后续步骤中位置 i 仍处于掩码状态的步骤。
- 教师目标 \( \bar{p}_i \) 为这些未来步骤上模型预测的平均：
  \[
  \bar{p}_i = \frac{1}{|T_i|} \sum_{t \in T_i} \pi_\theta(\cdot | x, s_t)_i
  \]
  平均范围覆盖 i 被解码之前的所有步骤，一旦位置已被解码（t ≥ 解码该位置的步数）则排除，因为那只是复制而非预测。
- 如果 \( T_i = \emptyset \)（即下一步立即解码），则退使用最终完成序列 \( \hat{y} \) 的预测。

#### 3. 目标函数
- 在每个掩码位置使用广义 Jensen-Shannon 散度（默认 β→0，即 forward KL）：
  \[
  \ell(x, \hat{y}) = \frac{1}{|M_k|} \sum_{i \in M_k} \mathrm{JSD}_\beta \Big( \mathrm{sg}[\bar{p}_i] \; \| \; \pi_\theta(\cdot | x, s_k)_i \Big)
  \]
  教师目标停止梯度，只更新学生。

#### 4. 轨迹验证
- 完成解码后，将最终答案与真实答案比较，只有正确的轨迹才贡献损失：
  \[
  \mathcal{L}_{\text{dOPSD}}(\theta) = \mathbb{E}_x \mathbb{E}_{\hat{y} \sim \pi_\theta(\cdot|x)} \big[ \mathbf{1}[\hat{y} \text{ correct}] \; \ell(x, \hat{y}) \big]
  \]
  验证仅使用短答案，不暴露参考解。

### 算法流程（文字描述）
1. 从数据集采样问题 x 和最终答案 a；
2. 模型对 x 解码生成完成序列 \(\hat{y}\) 并记录完整轨迹；
3. 如果 \(\hat{y}\) 与实际答案不符，丢弃该样本（梯度为0）；
4. 否则，从轨迹中随机选取一个步骤 k（掩码比例 > τ）；
5. 构建教师目标：对每个掩码位置，平均后续步骤中该位置仍掩码时的预测；
6. 计算 JSD 损失，通过学生部分反向传播更新模型参数。

## 三、实验设计

### 数据集与场景
- **训练数据**：MixChain-Z-PRM12K，约1.2万道竞赛级数学题，配有 CoT 解法和可验证的最终答案。
- **评估基准**（四个，包含域内和域外）：
  - **域内数学推理**：GSM8K（小学应用题，Acc@1）、MATH500（竞赛数学，Acc@1）。
  - **域外代码生成**：HumanEval（Python 函数合成，pass@1）、MBPP（入门级 Python 任务，pass@1）。

### 对比方法
所有方法均在同一训练数据上进行 LoRA 后训练（rank=32, α=32），覆盖 q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj。

- **Base**：未经过后训练的原始 Dream-7B-Instruct / LLaDA-8B-Instruct。
- **SFT**：监督微调，在参考解上直接做最大似然。
- **GRPO**：组相对策略优化，采用可验证最终答案奖赏，适配扩散解码。
- **OPSD (answer-only)**：将 OPSD 移植到扩散模型，教师仅以最终答案作为 PI。
- **OPSD (full-solution)**：教师以完整参考解作为 PI。
- **dOPSD（本文）**。

## 六、论文的主要结论与发现

1. **OPSD 直接移植到扩散模型失败**：结果支持 PI 去边缘化假说。教师使用完整参考解（更具体）时性能崩塌（GSM8K 从 81.41 降到 67.25）；仅用答案的 OPSD 也基本持平或低于基线。
2. **dOPSD 是唯一能持续提升基线的后训练方法**：
   - 在 Dream-7B 上：GSM8K +1.63, MATH500 +3.23, HumanEval +4.17, MBPP +1.06。
   - 在 LLaDA-8B 上：GSM8K +1.64, MATH500 +4.76, HumanEval +3.51, MBPP +1.09。
   - 所有基线（SFT、GRPO、OPSD）均未能在全部基准上提升，甚至倒退。
3. **域外泛化**：仅在数学上训练，但代码生成也有显著提升，表明 dOPSD 产生的推理增强具备可迁移性，且不遗忘原有能力。
4. **消融关键发现**：
   - Forward KL 优于 Reverse KL（质量覆盖更全面）。
   - 教师视野越长越好，全轨迹平均最优。
   - τ=0.5 最佳，平衡了掩码数量和预测可靠性。
   - 即使无最终答案验证（w/o verify），dOPSD 仍能提升基线，验证不是核心但能进一步提升。

## 七、优点

1. **自生成特权**：无需外部参考解或复杂提示，仅利用模型自身的去噪轨迹信息，实现“自蒸馏”的闭环。
2. **在线策略 & 密集奖励**：每个掩码位置都提供 token 级监督，比 RL 的稀疏奖励更高效；学生采样 = 训练分布，消除曝光偏差。
3. **架构无关**：不改变扩散模型的前向结构，只需记录解码步骤，训练时额外进行一次平均教师预测量。
4. **泛化性强**：域内数学提升 + 域外代码提升，且无需答案验证也能工作，拓展到无标签数据集。
5. **消融全面**：详细分析了发散方向、教师视野、阈值及验证的作用，方法解释清晰。

## 八、不足与局限

1. **额外计算开销**：每个正确轨迹需要额外前向传播（教师平均步骤数），可能比 SFT 或 OPSD 单次前向更慢。论文仅说“唯一额外代价是教师前向”，未定量对比训练时间。
2. **验证依赖**：虽然无验证也能提升，但使用答案验证带来了更大的收益；在实际无标签场景下性能可能折损。
3. **模型规模限制**：仅评估 7B/8B 参数规模，未测试更大模型（如 70B）或更大数据集上的可扩展性。
4. **仅数学训练**：尽管代码生成泛化，但仅一个训练领域（数学）可能局限了方法在不同领域（如常识推理、法律）上的普适性。
5. **超参数敏感**：τ（阈值）和教师视野长度需要调优；0.5 最佳，但其他数据集或模型可能需要重新调整。
6. **复现细节缺失**：未公开完整的训练超参数（如批次大小、学习率调度细节、GPU 型号和训练时长），可能影响复现。
