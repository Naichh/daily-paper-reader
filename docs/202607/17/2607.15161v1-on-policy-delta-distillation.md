## 摘要
策略内蒸馏是强化学习中一种替代性的后训练方法，通过从教师模型提供token级监督来缓解奖励模型施加的约束。尽管策略内蒸馏已在各种场景中得到研究和应用，但其基本设计仍未得到充分探索。在本文中，我们引入一种新的蒸馏奖励，称为Delta信号，而不是直接模仿教师模型的输出分布。Delta信号被定义为教师模型与其在推理能力指令微调之前的基模型之间的差异。因此，它捕捉了由推理微调引起的变化，并为传递推理能力提供了更直接的信号。利用大量实证证据，我们表明Delta信号显著改进了策略内蒸馏，并将这种新蒸馏方法称为策略内Delta蒸馏（OPD$^2$）。在数学、科学和代码推理基准上的实验表明，OPD$^2$始终优于传统策略内蒸馏，使推理大语言模型仅需较短的后训练周期即可实现强性能。代码将在https://github.com/naver-ai/opd2提供。

## Abstract
On-policy distillation is an alternative post-training method in reinforcement learning that alleviates the constraints imposed by reward models by providing token-level supervision from a teacher model. Although on-policy distillation has been studied and applied across various settings, its fundamental design remains underexplored. In this paper, we introduce a new distillation reward, termed the delta signal, instead of directly imitating the teacher's output distribution. The delta signal is defined as the difference between the teacher model and its base model prior to instruction tuning for reasoning capability. It therefore captures the changes induced by reasoning tuning and provides a more direct signal for transferring reasoning capabilities. Using extensive empirical evidence, we show that the delta signal substantially improves on-policy distillation and refer to the new distillation method as On-Policy Delta Distillation (OPD$^2$). Experiments across mathematics, science, and code-reasoning benchmarks demonstrate that OPD$^2$ consistently outperforms conventional on-policy distillation, enabling reasoning LLMs to achieve strong performance with only a short post-training period. Code will be available at https://github.com/naver-ai/opd2

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：大语言模型（LLM）后训练中，**策略内蒸馏（On-Policy Distillation, OPD）** 作为强化学习（RL）的替代方案，通过教师模型提供 token 级稠密监督，避免了手动设计奖励模型的成本。传统 OPD 直接让学生的输出分布逼近教师（如最小化 KL 散度）。
- **核心问题**：现有 OPD 方法直接模仿教师输出分布，但**忽视了教师模型通过推理调优（如指令微调、RL）获得的关键知识增量**。教师模型本身包含了调优前的语言偏好（如风格、表达习惯），直接蒸馏会将这些无关信息也传递给学生，导致蒸馏效率降低。
- **整体含义**：本文提出应利用 **教师模型与其基础模型（base model）之间的差异（Delta 信号）** 作为蒸馏目标，该信号捕捉了推理调优带来的“变化”，能更**直接、更纯净**地传递推理能力，从而实现更高效的后训练。

### 2. 方法论：核心思想、关键技术细节

- **核心思想**：定义蒸馏奖励为教师（$\pi^*$）与教师基础模型（$\pi^*_{base}$）的对数概率差，即 **Delta 信号** $R^\Delta_t = \log \pi^*(y_t) - \log \pi^*_{base}(y_t)$，用于替代传统 OPD 的 $R^{OPD}_t = \log \pi^*(y_t) - \log \pi_\theta(y_t)$。
- **关键分析**：通过词云、token 级信号可视化、词频统计三方面分析，发现 Delta 信号：
  - **增强**推理连接词（如 hence, however, note）；
  - **抑制**探索性/验证性词汇（如 see, try, verify）以及教师基模型中保留的自然偏好；
  - 在错误推理部分给出更明确的**负信号**，与推理正确性关联更强。
- **技术细节——OPD² 方法**：
  1. **Centering（去偏）**：将 Delta 信号减去其期望值，得到 advantage 函数 $A^\Delta_t$，消除对采样概率的偏置：
     $$A^\Delta_t = R^\Delta_t - \mathbb{E}_{\tilde{y}_t \sim \pi_\theta}[\log \pi^*(\tilde{y}_t) - \log \pi^*_{base}(\tilde{y}_t)]$$
     计算期望时取 top-1024 token 以节约显存。
  2. **Joint Conditioning（联合条件）**：为避免 Delta 信号导致收敛到 one-hot 且偏离教师的问题，引入条件：仅当 $A^\Delta_t$ 与原始 OPD advantage $A^{OPD}_t$ 同号时更新，否则置零：
     $$A^{D2}_t = \begin{cases} A^\Delta_t, & \text{if } A^\Delta_t \cdot A^{OPD}_t > 0 \\ 0, & \text{otherwise} \end{cases}$$
  3. **最终损失**：采用 RL 形式的策略梯度：
     $$\nabla_\theta J_{OPD^2}(\theta) = \mathbb{E}_{x, y \sim \pi_\theta}\left[\sum_t A^{D2}_t \nabla_\theta \log \pi_\theta(y_t)\right]$$
     只对采样 token 进行梯度更新。

### 6. 论文的主要结论与发现

1. **Delta 信号是更有效的蒸馏信号**：能专注于推理相关知识，抑制噪声偏好，在错误推理上提供更准确的负反馈。

4. **训练稳定性更好**：训练曲线显示 OPD² 在后期不退化，而 OPD/ExOPD 常出现 peak 后下降。
5. **泛化能力强**：从 Qwen3 迁移到 Gemma4 同样有效，甚至在 Gemma4 代码任务上虽未超越原始模型，但退化程度远小于 OPD 和 ExOPD。

### 8. 不足与局限

- **计算开销**：虽然不高，但仍需额外加载并推理教师基模型（参数量与教师相同），对于极大规模教师（如数百 B 参数）可能带来部署挑战。
- **实验覆盖**：仅测试了 Qwen3 和 Gemma4 两个系列，且 Gemma4 仅测试思考模式（非思考模式未测），对其他架构（如 Llama、DeepSeek）的泛化性未验证。
