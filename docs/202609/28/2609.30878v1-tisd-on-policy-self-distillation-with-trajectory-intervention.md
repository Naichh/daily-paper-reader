## 摘要
同策略自蒸馏（OPSD）提供了密集的教师目标，但仅沿学生采样的轨迹对其进行评估。当特权教师在已访问前缀处偏好某个替代动作时，OPSD 可以为分支决策提供目标，但除非学生采样到该动作，否则无法监督由该动作诱导的后继上下文。这造成了训练时的数据收集瓶颈，并表明师生分歧可以扮演一种不同的角色：提出一条轨迹分支，而不是识别充分的局部修正。我们使用受控 token 干预的诊断框架表明，在分歧峰值处教师偏好的 token 可以提高学生续写成功率，但其局部纠正价值有限。受此发现启发，我们提出一种简单的分支—重新生成—蒸馏算法，即轨迹干预自蒸馏（TISD）。TISD 强制采用教师选择的分支动作，将后缀生成交还给学生，并在以特权上下文为条件的教师下蒸馏完整轨迹。在编码模型上，TISD 相比 SDPO 将平均 Avg@4 提升了 1.2 个百分点。在科学领域，它在等步数预算下将平均 Avg@128 提升了 0.8 个百分点，在等时间预算下提升了 0.3 个百分点。这些结果支持将教师引导的分支作为为自蒸馏暴露有用后继上下文的一种方式。

## Abstract
On-policy self-distillation (OPSD) provides dense teacher targets, but evaluates them only along student-sampled rollouts. When the privileged teacher favors an alternative action at a visited prefix, OPSD can provide a target for the branch decision but cannot supervise the successor contexts induced by that action unless the student samples it. This creates a training-time data-collection bottleneck and suggests a different role for teacher-student disagreement: proposing a trajectory branch rather than identifying a sufficient local repair. Our diagnostic framework using controlled token interventions reveals that a teacher-preferred token at peak disagreement can improve student continuation success, while its local corrective value is limited. Motivated by this finding, we introduce a simple branch-regenerate-distill algorithm, Trajectory-Intervention Self-Distillation (TISD). TISD forces a teacher-selected branch action, returns suffix generation to the student, and distills the full trajectory under the privileged-context-conditioned teacher. Across the coding models, TISD improves average Avg@4 over SDPO by 1.2 percentage points. Across the science domains, it improves average Avg@128 by 0.8 points under an equal-step budget and by 0.3 points under an equal-time budget. These results support teacher-guided branching as a way to expose useful successor contexts for self-distillation.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：RLVR（带可验证奖励的强化学习）在代码、数学等可自动校验任务上训练 LLM，但验证器只提供响应级奖励，信号稀疏。同策略蒸馏（OPD）通过教师模型提供 token 级密集监督；同策略自蒸馏（OPSD）进一步取消独立教师，用同一模型在额外特权上下文（如代码执行轨迹、正确 rollout、标准答案）下充当教师。
- **核心瓶颈**：标准 OPSD 的教师目标只在**学生采样轨迹的前缀**上评估。当特权教师在某个已访问前缀偏好一个替代动作时，OPSD 能监督该分支决策本身，却**无法监督该动作诱导的后继上下文**——除非学生恰好采样到它。这形成训练时的数据收集瓶颈。
- **关键洞察**：师生分歧不应仅被视作"定位充分的局部修正"的信号，而应被视作**提出轨迹分支**的信号。作者通过受控 token 干预诊断发现：分歧峰值处的教师偏好 token 能显著提升学生续写成功率，但其局部纠正价值有限（直接替换该 token 仅修复 0.0–1.7% 的失败）。
- **另一动机**：TRD（用特权教师重写学生响应）在 SciKnowEval 上出现后期训练准确率崩溃（从 64.8% 跌至 0.0%），响应长度逼近 8192 上限，说明全教师重写会导致训练不稳定。这促使作者将后缀生成交还学生。

## 2. 方法论：核心思想与关键技术细节

### 核心思想
**分支—重新生成—蒸馏（branch–regenerate–distill）**：在分歧峰值处强制采用教师选择的动作，让**学生**重新生成后缀，再沿完整轨迹用特权上下文教师进行蒸馏。

### 算法流程（文字版伪代码）

1. **采样与验证**：对每个 prompt 采样学生响应 y，获得验证器奖励 R(y)，构建特权上下文 c_y。
2. **筛选与分支选择**（仅对失败且满足条件的 rollout）：
   - 计算每个位置的师生分歧 D_t（默认用 reverse KL）。
   - 选取峰值分歧位置 t\* = argmax_{1≤t<T} D_t(π_θ, π_φ)。
   - 取教师在该前缀下的 argmax 动作：ŷ_{t\*} = argmax_a π_φ(a | x, y_{<t\*}, c_y)。
3. **强制分支 + 学生重生成**：保留原前缀，强制插入 ŷ_{t\*}，由学生行为策略 β_θ 生成后缀：
   - ỹ = (y_{<t\*}, ŷ_{t\*}, ỹ_{>t\*})，其中 ỹ_{>t\*} ~ β_θ(· | x, y_{<t\*}, ŷ_{t\*})。
4. **蒸馏**：对保留轨迹 z（失败响应替换为 ỹ，成功响应保持原样）最小化 SDPO 式蒸馏损失：
   - ℓ_dist(z, c_y; θ) = (1/|z|) Σ_t D_t(π_θ(· | x, z_{<t}), sg[π_φ(· | x, z_{<t}, c_y)])。

### 关键设计选择及理由

- **为什么峰值分歧而非首次分歧**：实验显示，当后缀由学生生成时，峰值分歧处的续写成功率（9.9%）高于首次 argmax 分歧（6.1%）；但若由教师生成后缀，则首次分歧更优（17.1% vs 13.3%）。由于 TISD 把后缀交还学生，故选择峰值分歧。
- **为什么让学生重生成后缀**：限制训练轨迹与推理时学生生成分布之间的不匹配。教师只决定分支动作，所有后续 token 由学生采样，避免 TRD 式的分布外轨迹与训练崩溃。
- **分歧集中性**：峰值 token 单独承载 9–20% 的响应总 KL（相对均值 40–80 倍集中）；但语义分析显示峰值处多为非代码文本（4B/8B 上超 70%），说明峰值未必对应直接执行决策。
- **理论支撑（附录 C，命题 1）**：在共享参数线性模型中，即使学生完全拟合原轨迹上的教师目标，新上下文（重生成后缀）仍可能留下未约束的参数方向，从而提供互补监督。实测重生成后缀的平均 token reverse KL 是原后缀的 **2.37 倍**。

## 6. 主要结论与发现

- **代码场景**：TISD 在三个模型上平均 Avg@4 达 50.4%，Pass@4 达 51.4%，分别超过 SDPO 的 49.2% 和 50.3%（+1.2 / +1.1 个百分点）。
- **科学场景**：TISD 平均 Avg@128 在 200 步预算下达 73.5%（+0.8 点），10 小时预算下达 74.5%（+0.3 点）。
- **学习效率**：在 LCB-Large 上比最佳基线少 33% 更新达到其最高性能；在 LCB-Small 上少 56%。
- **诊断结论**：
  - 峰值分歧位置承载 9–20% 响应 KL，高度集中。
  - 教师偏好 token 的局部纠正价值有限（0.0–1.7%），但配合学生重生成后缀可显著提升续写成功率（Qwen3-8B：9.9% vs 1.7%）。
  - 重生成后缀的师生 KL 是原后缀的 2.37 倍，暴露了新的监督机会。
- **消融结论**：峰值分歧分支优于随机位置与首次分歧；教师 token 优于学生原 token；单轮重生成已足够，更多轮次无增益。
- **核心启示**：同策略自蒸馏的效果不仅取决于教师目标，还取决于**在哪些轨迹上评估这些目标**；师生分歧可作为轨迹转向信号，而非仅是局部修正信号。

## 7. 优点

- **方法简洁通用**：仅在 SDPO 基础上增加"选分支点 + 强制教师 token + 学生重生成后缀"三步，不改变蒸馏目标，易于复现与迁移。
- **诊断驱动设计**：先用受控 token 干预区分"局部修正"与"轨迹转向"两种角色，再据此设计算法，论证链条清晰。
- **规避 TRD 崩溃**：通过让学生生成后缀，限制训练-推理分布不匹配，解决了全教师重写导致的响应膨胀与准确率崩塌问题。
- **跨模型/跨领域/跨架构验证**：在 Qwen3 多个规模与 Olmo3 上复现核心诊断，在代码与科学两类场景验证方法有效性。
- **计算开销可控**：相对 SDPO 仅增加 10.3% 单步时间，与 GRPO/TRD 相当。
- **理论补充**：附录 C 用共享参数线性模型形式化说明为何重生成上下文能提供互补监督约束。

## 8. 不足与局限

- **依赖学生续写能力与教师目标质量**：TISD 的有效性取决于学生能否从教师选定动作继续生成，以及特权教师目标是否可靠；若学生续写质量差，分支收益受限。
- **额外计算开销**：分支选择与后缀重生成引入额外训练时间（+10.3%/步），论文指出需要更高效的分支选择或生成方法。
- **增益幅度有限**：科学场景等时间预算下仅 +0.3 个百分点，代码场景 +1.2 个百分点，提升幅度相对温和。
- **实验覆盖缺口**：
  - 未做严格损失消融来隔离"重生成后缀监督"相对于"分支动作监督"的独立贡献。
  - 科学场景未与 TRD 对比（因 TRD 崩溃），也未在更多科学模型上验证。
  - 语义标注依赖 GPT-5.4，且角色分层样本量小，作者自身也谨慎表示不将语义角色作为分支质量的可靠指标。
- **分支选择标准单一**：仅用 reverse KL 峰值，未探索其他分歧度量或组合标准；诊断显示峰值处多为非代码文本，说明该选择标准与"执行决策"未必对齐。
- **应用限制**：需要特权上下文（成功 sibling 或执行反馈），在无法获得此类信号的任务上适用性受限。
