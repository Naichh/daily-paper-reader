## 摘要
同策略蒸馏（OPD）通过让学生模型生成轨迹，然后将其下一词元预测与外部教师的下一词元预测相匹配来训练学生模型。这为学生提供了密集的词元级监督。同策略自蒸馏（OPSD）无需外部教师。具体而言，学生模型的第二个冻结副本在其上下文中被给予真实答案，充当教师。学生模型仅接收问题，并学习模仿拥有特权信息的教师模型，而教师在训练全程保持冻结。先前工作表明，冻结教师有助于训练稳定性，但我们认为，这可能阻止教师在训练过程中吸收学生所学到的改进。我们的主要贡献是通过一个围绕两个互补组件构建的递归框架来解决这一局限。首先，我们让拥有特权信息的教师与学生共同演化，使得一轮中学到的修正能够指导下一轮，我们将这一过程称为动态共同演化（DCE）。其次，由于更强的修正也可能使回答过于冗长和自我批评，我们额外在模型自身同策略响应的更短、经核验的改写上进行训练。我们将这一互补目标称为自精炼简洁学习（SRCL）。总体而言，我们的综合评估表明，DCE+SRCL 在多种模型规模和四个竞赛级数学基准上优于 OPSD。具体而言，在 Qwen3-8B 上，DCE+SRCL 达到 65.97% Average@12，比 OPSD 高出 35.62 个百分点，同时相对于仅 DCE 将平均输出长度减少 7.80%。

## Abstract
On-policy distillation (OPD) trains a student model by having it generate trajectories, then matching its next-token predictions with an external teacher's next-token predictions. This provides dense, token-level supervision to the student. On-policy self-distillation (OPSD) eliminates the need for the external teacher. Specifically, a second frozen copy of the student model, now given the ground truth in its context, serves as the teacher. The student model only receives the problem and learns to mimic the privileged teacher model, while the teacher remains frozen throughout training. Previous work showed that freezing the teacher is useful for training stability, but we argue that this can prevent the teacher from incorporating the improvements learned by the student during training. Our primary contribution is to address this limitation with a recursive framework built around two complementary components. First, we let the privileged teacher co-evolve with the student so that revision learned in one round can guide the next, a process we refer to as Dynamic Co-Evolution (DCE). Second, because stronger revision can also make responses too verbose and self-critical, we additionally train on shorter, verified rewrites of the model's own on-policy responses. We call this complementary objective Self-Refined Concise Learning (SRCL). Overall, our comprehensive evaluations show that DCE+SRCL outperforms OPSD across multiple model scales and four competition-level mathematics benchmarks. Specifically, on Qwen3-8B, DCE+SRCL reaches 65.97% Average@12, outperforming OPSD by 35.62 percentage points while reducing mean output length by 7.80% relative to DCE alone.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 推理后训练主要有三条路线——RLVR（结果奖励，粗粒度、序列级）、过程监督（需要步级标注或额外验证器，成本高）、以及同策略蒸馏（OPD，在被训练模型自身轨迹上提供密集的 token 级监督）。
- **OPSD 的做法与局限**：On-Policy Self-Distillation（OPSD）用同一基座 checkpoint 的两个副本——学生只看问题，教师额外看到标准答案（privileged teacher）——从而免去外部教师；为稳定训练，OPSD **冻结教师**。
- **核心问题**：冻结教师无法吸收学生在训练中学到的新能力。论文用固定错误轨迹探针发现：即使看到标准答案，冻结教师在错误回答端点仍给 EOS 高达 **94.5%** 的概率，而给 "Wait" 等反思线索仅 **22.0%**；与此同时学生在训练中反思行为显著增强，二者日益错配（Figure 1）。
- **整体含义**：作者主张让特权教师与学生**共同演化**，形成递归自我改进闭环，并用简洁化目标抑制"更强修正"带来的冗长与过度自省。

## 2. 方法论

### 核心思想
每一轮更新后的 checkpoint **同时**初始化下一轮的学生和（detached、gold-conditioned 的）特权教师，使一轮中学到的修正行为成为下一轮监督信号的一部分。

### 关键技术一：动态共同演化（DCE）
- 第 k 轮，当前参数 θ_k 采样 on-policy 响应 `y^(k) ~ p_θk(·|x)`，保留 m 个 token 作为监督位置。
- **学生分布** `p_{k,t} = p_θk(·|x, ỹ_{<t})`；**特权教师分布** `q_{k,t} = stopgrad[p_θk(·|C_prev(x,g,τ,ỹ_{<t}))]`，其中 g 为标准答案、τ 为过渡指令。
- 损失为 Forward KL：`L_G = E[ (1/m) Σ_t D_KL(q_{k,t} ‖ p_{k,t}) ]`；教师分支停止梯度。
- 优化后 θ_{k+1} 同时充当下一轮学生与教师，形成递归。
- **关键设计细节**：标准答案被放在 **assistant turn 内（assistant-side prefill）**，而非 user turn，使模型把 g 当作"自己已生成的推理"来条件化；消融显示这一放置方式大幅优于 user-side 的两种排布。

### 关键技术二：自精炼简洁学习（SRCL）
- 同一 checkpoint 在**不看标准答案 g** 的情况下，对自身 on-policy 响应做重写：`c^(k) = R_θk(x, y^(k))`。
- 只保留满足四道门的改写：① 更短且自然终止；② 无反思性措辞（Wait、Actually、Correction 等）；③ 含平衡 boxed 答案且答案正确、无更早的错误 box；④ 自包含、无重复片段。
- 对接受的改写做自回归交叉熵：`L_SRCL = -(1/N_k) Σ Σ_t log p_θk(c_t | x, c_{<t})`；若无接受样本则置 0，仅用 DCE 更新。
- g 仅用于验收判定，绝不进入改写生成，避免真值泄漏。

### 联合优化
- `L = λ_G · L_G + λ_S · L_SRCL`，λ_G、λ_S 分别控制两个目标的强度（主实验 λ_G = 5×10⁴；λ_S = 12.5/25/35/25 对应 14B/8B/4B/1.7B）。
- Algorithm 1 描述完整流程：采样 minibatch → 生成 on-policy 响应 → 打分 DCE 前缀 + 生成自改写并验收 → 联合更新 → 新 checkpoint 初始化下一轮双角色。

## 6. 主要结论与发现

- **精度大幅提升**：Qwen3-8B 上 DCE+SRCL 达 **65.97% Average@12**，OPSD 仅 30.35%、GRPO 20.28%，提升 **35.62 个百分点**；4B 为 61.88% vs 22.85%；1.7B 为 26.88% vs 10.35%。DCE 单独已贡献绝大部分精度增益。
- **SRCL 改善精度—长度权衡**：8B 上平均输出从 19,046 降至 17,561 token（-7.80%）且精度相当；4B 上精度从 60.00% 升到 61.88%、长度从 19,360 降至 17,265（-10.82%）。
- **长度本身不是原因**：OPSD-TTS 强制生成 16K token 仅得 30.76%（8B），远低于 DCE；在 8K 预算下 TTS 甚至使 OPSD 下降。
- **教师确实在共同演化**：固定轨迹上，学生/教师的端点 p(EOS) 从 92.6%/90.4% 降至 26.3%/41.3%，反思线索概率 p(r_t) 从 30.1%/32.8% 升至 77.0%/77.4%。
- **教师刷新方式**：每步动态刷新最优（65.97%），EMA 次之（最高 65.35%），周期快照最多 63.47%，冻结教师最差（41.04%）。
- **目标函数方向性**：Forward KL 最优（65.97%），Reverse KL 低 5.55 个点且多用 6,187 token，JSD 仅 17.99%。
- **放置方式**：assistant-side prefill 在 8B/4B/1.7B 上分别比 user-side instruction-last 高 9.79/6.39/14.66 个点。
- **目标互补性**：去掉 DCE 后 SRCL 单独训练崩溃到 2.36%/1,116 token（8B），说明简洁目标必须在动态指导下才有效。
- **可迁移性**：Gemma-4-12B-IT 上 DCE+SRCL 达 63.61%，优于全部非 DCE 对照；14B 早期轨迹从 21.39% 升至 step 30 的 66.39%。

## 7. 优点

- **问题定位清晰且有实证支撑**：用固定轨迹探针量化"冻结教师的错配"，而非仅凭直觉论证。
- **方法简洁、互补性强**：DCE 与 SRCL 分别解决"会不会改"和"改得冗不冗长"，二者缺一不可，消融证据充分。
- **控制实验设计严谨**：matched-budget TTS 控制、matched training step 比较、固定轨迹探针、多教师刷新策略对比，能有效排除"更长输出 = 更高精度"和"checkpoint 挑选"等替代解释。
- **递归自改进的机制可视化**：不仅报告最终精度，还展示了学生与特权分支行为同步演化（EOS 下降、反思上升），并给出位置解析的信号分析（∆NLL 随训练上升）。
- **跨规模与跨家族验证**：1.7B–14B 及 Gemma-4-12B-IT 一致有效，增强了结论的稳健性。
- **工程细节透明**：给出了完整的 prompt 模板、SRCL 四道验收门、接受率审计、复现配置表。

## 8. 不足与局限

- **推理成本显著上升**：DCE 平均输出接近 19K token，远高于 Base 的约 4K；SRCL 的省 token 效果在小模型（1.7B）上不成立，甚至从 12,600 增至 19,504。
