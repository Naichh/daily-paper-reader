## 摘要
多教师同策略蒸馏（MOPD）将多种专门能力整合到单个学生模型中，但现有做法通常将每个提示在整个 rollout 过程中硬路由到与其领域匹配的教师。这种对提示级领域标签的依赖限制了无标签训练混合数据的使用，并且未能利用其他教师提供的互补信号。我们提出 MOPD-Router，一个在每个 token 上对整个教师池进行监督路由的框架，无需领域标签，也无需训练单独的路由模型。其插件式接口支持不同的度量，用于选择和加权教师特定的 OPD 信号。在该接口中，我们提出 ExpertAlign，它根据每位教师对当前 token 处学生模型的纠正是否体现了该教师在后训练中获得的专长来为其打分，并将其与两种参考度量进行比较：基于教师置信度的 Entropy 和基于教师-学生差异的 Novelty。在强到弱和同规模蒸馏场景下，针对无标签和有领域标签训练混合数据的实验表明，ExpertAlign 在所有四种设置中均取得最强的整体性能。在无标签数据上，它相比均值聚合将总体得分提升 5.88 分（+12.3%）；在有领域标签数据上，它在不使用可用领域标签的情况下，比标准 MOPD 高出 3.95 分（+7.8%）。这些结果表明，token 级路由能够利用跨域互补监督，并减少对提示级领域分配的完全依赖。代码见：https://github.com/TURLEing/MOPD-Router。

## Abstract
Multi-teacher on-policy distillation (MOPD) integrates specialized capabilities into a single student, but existing practice typically hard-routes each prompt to a domain-matched teacher for the entire rollout. This dependence on prompt-level domain labels restricts using unlabeled training mixtures and leaves complementary signals from other teachers unused. We introduce MOPD-Router, a framework that routes supervision over the full teacher pool at each token, without domain labels or training a separate routing model. Its plug-in interface supports different metrics for selecting and weighting teacher-specific OPD signals. Within this interface, we propose ExpertAlign, which scores each teacher by whether its correction to the student at the current token expresses the specialization that teacher acquired during post-training, and compare it against two reference metrics built on teacher confidence (Entropy) and teacher-student discrepancy (Novelty). Experiments on unlabeled and domain-labeled training mixtures under strong-to-weak and same-size distillation scenarios show that ExpertAlign achieves the strongest overall performance in all four settings. On unlabeled data, it improves the overall score by 5.88 (+12.3%) points over Mean aggregation; on domain-labeled data, it outperforms standard MOPD by 3.95 (+7.8%) points without using available domain labels. These results demonstrate token-level routing can exploit cross-domain complementary supervision, and reduce exclusive reliance on prompt-level domain assignment. Code is available at: https://github.com/TURLEing/MOPD-Router.

## 1. 核心问题与整体含义

- **背景**：强化学习（RL）已成为提升 LLM 能力的重要途径，但不同任务域往往采用彼此独立的 RL 流程——数学依赖可验证奖励、代码在可执行环境中训练、指令遵循使用规则/评分反馈。这些流程从同一基座模型出发，产出各具专长的专家模型，而最终目标是一个跨域通用的单一模型，因此"多专长能力整合"成为后训练的核心问题。
- **范式**：多教师同策略蒸馏（MOPD）建立在 OPD 之上——学生按当前策略生成轨迹，多个教师在其上提供密集的 token 级监督。该范式已被多家前沿模型后训练流程采用。
- **现有做法的局限**：主流 MOPD 采用**提示级领域标签硬路由**（domain-label hard routing），即为每个 prompt 选定一个领域匹配的教师，并在整个 rollout 中固定使用该教师。这带来两个问题：
  1. 真实世界的 SFT/对话混合数据往往缺乏可靠领域标签，而一条 prompt 可能同时混合闲聊、指令遵循、数学推理与代码执行，无法给出预定义的单教师分配；
  2. 领域标签只识别"主教师"，忽略了其他教师在特定 token 上的价值。例如数学题中代码教师可助力程序化推理、指令遵循教师可帮助满足格式约束，且这种有用性随生成阶段与 token 位置变化。
- **核心研究问题**：路由度量如何在每个 token 上识别相关教师，并为其信号分配恰当权重？
- **整体含义**：论文主张从"提示级硬分配"转向"token 级、上下文相关的动态路由"，从而在无标签数据上使用 MOPD，并释放跨域互补监督的价值。

## 2. 方法论

### 2.1 框架总体思想：MOPD-Router

- 用一个**插件式接口**替代固定的 prompt→教师分配：在每个 token 上对**完整教师池**进行选择与加权，**不需要领域标签，也不需要训练独立的路由模型**。
- 路由度量统一形式为 `s_{i,t} = M(π_φi, π_θold, π_θbase; h_t)`，其中 π_θbase 是教师共享的 RL 前基座模型。得分经 Softmax（部分度量使用较小的路由温度）转为非负权重 `{w_{i,t}}`。

### 2.2 形式化基础

- 学生在旧策略下采样响应 y；教师 i 在上下文 h_t 上的**逐教师优势**为
  `A_t^(i) = sg[log π_φi(y_t|h_t) − log π_θold(y_t|h_t)]`（sg 为 stop-gradient）。
- **路由后优势**为各教师信号的加权和：`A_t = Σ_i w_{i,t} A_t^(i)`，直接占用 advantage 槽位，无需学习 critic。
- 优化目标为带重要性比 `ρ_t(θ)` 的裁剪式 PPO 型目标：`J_MOPD(θ) = E[ (1/T) Σ_t min(ρ_t A_t, clip(ρ_t, 1−ε, 1+ε) A_t) ]`，ε=0.2。
- 对照基线：领域标签硬路由 `w_{i,t} = I[i = d(x)]`（全位置 one-hot），以及均值聚合 `w_{i,t} = 1/M`。

### 2.3 三种插件式路由度量

**(a) Entropy（教师置信度）**
- 以负预测熵为得分：`s_i,t^Ent = −H(p_i^t)`，Softmax 温度 τ_R^Ent = 0.1。
- 直觉：熵越低、分布越尖锐的教师越"自信"，应获得更大权重。
- 缺陷：只看教师自身，无法判断其是否对学生有**有用**的纠正；且熵的绝对尺度差异会系统性偏向某一教师。

**(b) Novelty（教师–学生差异）**
- 取学生与教师各自 top-k（k=16）候选集 `S_S^t`、`S_i^t`，交集为共享候选集 `Ω_{i,t}`。
- **可达性**：`a_{i,t} = sqrt( p_S^t(Ω) · p_i^t(Ω) )`，衡量双方在共享候选上的概率质量。
- **新颖度**：`N_{i,t} = 1 − exp( −JS(p_S^t|Ω , p_i^t|Ω) / τ_N )`，τ_N=0.1，衡量共享支撑内的分布差异。
- 路由得分 `s_i,t^Nov = a_{i,t} · N_{i,t}`，Softmax 温度 τ_R^Nov = 0.1；Ω 为空时得分置 0。

**(c) ExpertAlign（专长对齐，本文提出）**
- 动机：教师与其基座模型的 log 策略差可刻画后训练带来的策略偏移，即教师的"专长"。
- **专长向量**（教师相对 pre-RL base 的位移，属教师内在属性）：
  `e_{i,t} = [log p_i^t(v) − log p_base^t(v)]_{v∈S_S^t}`
- **教学向量**（教师将如何重塑学生在该支撑上的 log 概率，依赖学生状态）：
  `d_{i,t} = [log p_i^t(v) − log p_S^t(v)]_{v∈S_S^t}`
- **对齐打分**：`c_{i,t} = max( cos(e_{i,t}, d_{i,t}), 0 )`，保留集 `E_t = { i : ⟨e_i,t, d_i,t⟩ > δ }`，δ=10⁻⁶，零范数向量得 0。
- 仅当教师的"教学方向"与其"后训练获得的方向"正对齐时，才认为该教师的纠正是**专长性的**而非一般性分歧。
- **两种加权规则**：
  - Uniform：保留集内等权 `1/|E_t|`；
  - Cosine：按对齐强度归一化加权 `c_{i,t} / Σ_{j∈E_t} c_{j,t}`。
- 若 `E_t` 为空，则该位置的 OPD 监督被跳过。学生 top-k 支撑取 k=16（敏感性见附录）。

### 2.4 训练流程（Algorithm 1）

1. 每个训练步 q：令 π_θold ← π_θ，从数据与旧策略采样 rollout 批次；
2. 在**学生访问过的上下文**上评估学生、所有教师及共享 base，取得度量所需量；
3. 计算各教师逐 token 优势 `A_t^(i)`；
4. 应用度量 M 得到全体教师池上的非负 token 级权重；
5. 聚合得到路由优势 `A_t`；
6. 在内层 minibatch 中重算当前学生 log 概率与重要性比，最大化裁剪 MOPD 目标以更新 θ。
