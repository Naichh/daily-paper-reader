## 摘要
在线策略自蒸馏（on-policy self-distillation, OPSD）已成为后训练LLM智能体的一种流行方案。它通过以特权信息（privileged information, PI）为条件，获得同一模型更强的教师视角，并在词元级别监督智能体模型。在这项工作中，我们表明，在多轮智能体中，这种范式教会学生自信地行动，却不具备支撑该行动的信息。训练后的智能体表现得仿佛拥有它从未观察到的特权信息，其性能远不及普通强化学习（plain RL），最坏情况下甚至低于未经训练的基座模型。因此，我们提出特权自实践（Privileged Self-Practice, PSP），它保留PI并将其从损失函数移到采样器。当学生在某任务上的rollout大多失败时，我们注入由分析器模型编写的简短任务级指令，在上下文中带有该指令的情况下重新采样该任务，并以不变的GRPO目标在结果上进行训练。特权信息始终留在提示中，从不进入损失函数。在AppWorld和SWE-bench Verified上，使用三个不同的学生模型，PSP在每个设置中都取得了最佳平均得分，并且是唯一持续优于普通GRPO的方法：在AppWorld上将任务目标完成率提升最多65%，在SWE-bench Verified上将解决率提升最多61%。

## Abstract
On-policy self-distillation (OPSD) has become a popular recipe for post-training LLM agents. It supervises the agent model at the token level with a stronger teacher view of the same model, obtained by conditioning on privileged information (PI). In this work, we show that in multi-turn agents, this paradigm teaches the student to act with confidence but without the information behind it. The trained agent behaves as if it had privileged information it never observed, and its performance falls well short of plain RL, in the worst case below the untrained base model. Therefore, we propose Privileged Self-Practice (PSP), which keeps the PI and moves it from the loss to the sampler. When the student's rollouts on a task mostly fail, we inject a short per-task instruction written by an analyzer model, sample the task again with the instruction in context, and train on the result with an unchanged GRPO objective. The privileged information stays in the prompt and never enters the loss. Across AppWorld and SWE-bench Verified, with three different student models, PSP obtains the best average score in every setting and is the only method that consistently outperforms plain GRPO, improving task-goal completion by up to 65% on AppWorld and the resolved rate by up to 61% on SWE-bench Verified.

## 1. 核心问题与研究动机

- **背景**：在线策略自蒸馏（OPSD）已成为 LLM 智能体后训练的热门方案——用同一模型在特权信息（PI，如参考解、对自身失败的反思）条件下的"更强教师视图"，对学生做词元级分布匹配。其吸引力在于信号稠密、教师免费、样本在线，对奖励稀疏的多轮智能体尤其诱人。
- **核心诊断**：在多轮智能体中，OPSD 的目标是**误设的**。教师基于学生永远看不到的 PI 推理，其词元分布含学生无法推导的内容；Yang et al. (2026a) 证明该信息差不可约，即 `I(Y_k; σ | X, Y_<k) > 0`。
- **多轮场景的致命性**：学生学到的是教师"自信、果断"的**形式脚手架**，而非支撑它的信息（如该调哪个 API、该算什么量）。更关键的是，智能体的每一步都是**对环境的动作**，会被执行并折叠进后续状态，误差跨多轮复合，最坏情况下性能**低于未训练的基座模型**。
- **核心问题**：*应当如何使用特权信息，来训练一个推理时并不拥有它的智能体？*

## 2. 方法论：Privileged Self-Practice (PSP)

### 2.1 核心思想
保留同一份特权信息，但**把它从损失函数搬到采样器**：PI 只作为 rollout 的上下文，训练目标仍是**未改动的 GRPO**，任何一项目标函数都不跨视图比较。

### 2.2 关键技术细节

- **PI 的构造（分析器 W）**
  - 固定分析器 `W`（Qwen3.6-27B）读取三样东西：任务 `x`、学生当前组的 rollout `F_x`（多为失败）、以及一条参考轨迹 `r_x`，输出 `σ_x = W(x, F_x, r_x)`。
  - 输出为 3–6 条**动作导向的祈使句规则**，包裹为 `<skills>...</skills>` 置于系统消息。
  - 两条性质：**样本级**（针对该任务与该学生，非通用提示）与**动态**（`F_x` 来自当前策略，故 `σ_x` 每次调用重新生成，随学生演化）。
  - 参考轨迹由 W 在训练前作为智能体跑 16 条/任务收集（AppWorld 90 任务中 81 个至少有一条成功；SkyRL-v0 293 任务中 258 个有）。

- **门控特权 rollout**
  - 先采 n 条非特权轨迹，计算组成功率 `p̂_x`，门控 `g(x) = 1[p̂_x < γ]` 判定"困难组"（Definition 1）。
  - 若 `g(x)=1`：生成 `σ_x`，从 `π_θ(·|σ_x ⊕ x)` **重新采样整组**并替换原组，`σ_x` 保留在该组训练上下文中；若 `g(x)=0`：按普通 GRPO 训练。
  - 更新式：`J(θ) = E_x[(1−g(x))·L_x({τ_i}) + g(x)·L_{σ_x⊕x}({τ_j⁺})]`，其中各组优势在**组内**计算，`L` 即 Eq.(3) 的裁剪 GRPO 目标（含 KL 到冻结参考模型）。
  - **Remark 2**：无任何项以特权视图作为非特权视图的目标，故 OPSD 的信息差问题不会出现。

### 2.3 为什么能迁移（理论 + 实证）

- **定义依赖度** `d_t = log π_θ(a_t|s_t,σ) − log π_θ(a_t|s_t)`，度量 σ 对第 t 轮动作概率的提升。
- **事实 1：σ 只决定少数轮次**——107 条成功特权 rollout 中，78% 恰有 1 个"决定性轮次"（承担 ≥20% 的 Σ|d_t|），无一超过 3 个。
- **事实 2：奖励强化所有轮次**——轨迹级奖励对所有轮次等权，而大多数轮次 σ 并未决定，故梯度大多可迁移。
- **命题 1（一阶迁移条件）**：一步特权视图更新后，非特权视图对数似然的一阶变化为 `ηA(τ)⟨G0, Gσ⟩ + O(η²)`，**当且仅当两视图梯度夹角为锐角时为正**。
- **实证验证**：|d_t| < 0.1 时梯度余弦中位数 0.53；决定性轮次降至 0.09（甚至略负）；71% 的 rollout 一阶转移比为正（中位数 0.24），且几乎全部增益来自 σ 未决定的轮次。
- **事实 3：门控让方法退火成普通 RL**——随 `p_x` 上升，门控触发率下降，训练自然回归 GRPO，无需人工调度。
