## 摘要
我们介绍了 Pistis 模型系列，包含分别基于 Qwen3.6 和 Qwen3.5 构建的 27B 与 9B 参数多模态大语言模型，并通过一个通用且可扩展的后训练框架开发。该框架首先通过大规模多模态监督微调（SFT）建立坚实基础。在此 SFT 基础上，我们提出交错蒸馏与强化学习（Interleaved Distillation and Reinforcement Learning, IDRL），一种新颖的后训练范式，在单一训练循环中紧密集成同策略蒸馏与强化学习。通过在两个目标之间交替，而非孤立优化任一目标或以静态联合损失将其组合，IDRL 实现了更有效的知识迁移、更高的优化稳定性，以及对长时程智能体轨迹更精确的信用分配，从而在缓解常见能力权衡的同时带来更强性能。在两种模型规模上，该框架均产生两个专用变体：Pistis-Thinking，旨在增强深度多模态推理；以及 Pistis-Agentic，额外融入智能体轨迹数据，以支持长时程规划、迭代推理和工具使用。Pistis-Agentic 在多模态搜索方面尤为强大。两种规模均优于其对应的基础模型。除模型参数优化之外，我们进一步提出 Pistis-Auto-Harnessing（PAH），一种系统级方法，通过迭代优化自动改进智能体的推理执行框架。实验表明，PAH 在不更新模型参数、也不增加交互预算的情况下提升了模型性能。

## Abstract
We introduce the Pistis model family, comprising 27B- and 9B-parameter multimodal large language models built on Qwen3.6 and Qwen3.5, respectively, and developed through a general and scalable post-training framework. The framework first establishes a strong foundation through large-scale multimodal supervised fine-tuning (SFT). Building on this SFT foundation, we propose Interleaved Distillation and Reinforcement Learning (IDRL), a novel post-training paradigm that tightly integrates on-policy distillation and reinforcement learning within a single training loop. By alternating between the two objectives, rather than optimizing either in isolation or combining them in a static joint loss, IDRL enables more effective knowledge transfer, greater optimization stability, and more precise credit assignment for long-horizon agentic trajectories, leading to stronger performance while mitigating common capability trade-offs. At both model scales, the framework produces two specialized variants: Pistis-Thinking, designed to strengthen deep multimodal reasoning, and Pistis-Agentic, which additionally incorporates agentic trajectory data to support long-horizon planning, iterative reasoning, and tool use. Pistis-Agentic is particularly strong in multimodal search. Both scales outperform their corresponding base models. Beyond model-parameter optimization, we further introduce Pistis-Auto-Harnessing (PAH), a system-level method that automatically improves the agent's inference harness through iterative optimization. Experiments demonstrate that PAH enhances the model performance without updating the model parameters or increasing the interaction budget.

## 2. 方法论

### 2.1 总体框架
三阶段：**大规模多模态 SFT → IDRL 后训练 → （可选）PAH 系统级优化**。同一框架下衍生两个变体：
- **Pistis-Thinking**：仅用推理数据 SFT，专攻深度多模态推理；
- **Pistis-Agentic**：SFT 阶段额外加入智能体轨迹数据，专攻长时程工具集成交互。

### 2.2 监督微调（SFT）
- 语料约 **3.2M QA 对**，含推理数据与智能体轨迹数据。
- **推理数据**：数学推理、图表/文档理解、科学图解、医学 VQA、代码生成、通用逻辑与真实场景 VQA。
- **输出格式**：`<think>...</think>` + 两个换行 + 最终答案（无 `<answer>` 标签），便于解析与细粒度监督。
- **质量控制流水线**：校验标签配对、逻辑完整性、最小推理长度，剔除畸形样本，对含参考答案的任务做答案一致性检查。
- **智能体轨迹数据配比**：工具集成推理（TIR）约 40%、搜索约 20%、通用智能体轨迹约 40%。
- **自生成数据筛选策略**：每个 query 采样至多 4 条轨迹，**丢弃全失败或全成功**的 query，仅保留中等难度中的一个成功轨迹（聚焦"有信息量但仍有提升空间"的样本）。
- **训练细节**：AdamW，基础学习率 1e-5，余弦衰减；Liger kernel；序列打包至最长 32,768 token；保留原生分辨率输入；3 个 epoch，全局 batch size 1,536。

### 2.3 IDRL（核心算法贡献）
- **核心思想**：在**单一训练循环内交替**执行 on-policy 蒸馏（OPD）与 RL，而非分阶段串行或静态联合损失加权。
- **调度函数**：设周期 S = S_OPD + S_RL，当 `(s mod S) < S_OPD` 且 `s < S*` 时执行 OPD，否则执行 RL；超过 S* 步后**切换为纯 RL**（依据熵平台期判断）。
  - 理由：(i) 熵平台后 OPD 对输出多样性贡献有限；(ii) 持续向教师正则化会把学生**上界锁死在教师能力**，无法取得超越教师的增益。
- **配置**：9B 变体使用 IDRL（S_OPD=5、S_RL=5；Thinking 的 S*=300，Agentic 的 S*=100）；27B 变体使用纯 RL，并作为 9B 的**冻结 OPD 教师**。α=1，β=0.5，top-k=50。

**（a）On-policy 蒸馏（OPD）**
- 采用 GKD 框架，以**广义 Jensen–Shannon 散度（JSD）**为目标：`D_JSD(β)(π_T ‖ π_θ) = β·D_KL(π_T‖M) + (1−β)·D_KL(π_θ‖M)`，其中 `M = βπ_T + (1−β)π_θ`。
- **Top-k 词表限制**：只在教师分布的 top-k token 上计算散度；对学生分布**不做重归一化**，而是用解析残差项 `log(1/(1−β))·(1 − Σ_{v∈V_t} π_θ(v))` 显式吸收 top-k 之外的教师质量，既高效又避免重归一化带来的失真。
- **散度选择的关键**：反向 KL 是 mode-seeking（加剧熵崩塌）；前向 KL 是 mass-covering（保熵）；**广义 JSD 在两者间插值**，配合足够宽的 top-k（k=50）可对抗 RL 引起的熵崩塌。
- **多模态适配问题**：直接把 OPD 用于 MLLM 增益有限（Geo3K 上 65.0→65.7）。作者发现瓶颈是**初始师生分布差距**，加入**冷启动 SFT**（先在教师生成响应上微调）后 OPD 才能稳定收敛并超过基座（Table 2、Figure 3）。

**（b）可验证奖励的 RL**
- 采用 **SAPO**（平滑自适应策略优化）：组相对优势 `A_i = (R_i − mean)/std`；用**平滑的温度控制门控** `f(r) = 4/τ·σ(τ(r−1))` 替代 PPO 式硬截断，形成平滑信任域（τ_pos=1，τ_neg=1.05，非对称）。
- **Step-level Positive-Advantage Suppression（PAS）**：识别被拒绝或无贡献的助手步骤（畸形工具调用、重复/近似调用、最终答案指令之后的调用、观测无法并入上下文等），将其**正优势置零**，但保留零/负优势——即中间动作的质量与轨迹级最终结果解耦。
- **奖励系统**（任务感知的混合奖励）：全局格式奖励（`<think>` 标签存在且严格配对）；STEM/图表数值/OCR 用**规则精确匹配**二值奖励；空间与时序 grounding 用**连续 IoU 奖励**；长文档 QA、通用 VQA、智能体搜索等开放式任务用**强裁判模型**评估。原则是"能用规则/可执行校验的绝不用模型评判"。

**（c）为何"交替"优于"求和"（理论分析）**
- 每步只有单一目标激活，因此**永不产生共享交叉项** `g_R^T g_D`。
- 求和更新的一阶改进为 `ΔJ_RL ≈ η(‖g_R‖² + α g_R^T g_D)`，`ΔJ_D ≈ η(α‖g_D‖² + g_R^T g_D)`——冲突时**两个目标都被拖累**，甚至可能降低奖励目标。
- 交替时每步为 `ΔJ_RL ≈ η‖g_R‖² ≥ 0` 或 `ΔJ_D ≈ ηα‖g_D‖² ≥ 0`，**各自一阶非负**。
- 当策略在实现 token 上比教师更自信（`π_θ(a) > π_T(a)`）时，OPD 与 RL 梯度符号相反，正是 OPD 本应纠正的"过度锐化"区间——这解释了求和方案的冲突来源。

### 2.4 Pistis-Auto-Harnessing（PAH，系统级方法）
- **优化对象**：模型冻结、工具协议与评估入口固定，仅优化**推理执行框架（harness）**——代码约束、提示词、状态表示、能力模块、路由规则、工作流。
- **五阶段外循环**：归因（机制级失败分析）→ 提案（可证伪的单点改动，含触发条件/预期状态变化/回滚条件）→ 实现 → Canary 门控（小规模定向检查）→ 全量开发集评估。**只有开发指标提升才接受，否则自动回滚**；每轮只引入一个可独立开关的改动以保证可归因。
- **得到的 Optimized Harness 组件**：
  - **Candidate Ledger**：有界的、模型可见的结构化候选记录（候选实体/答案假设、支持与反驳证据 ID、来源关系、未满足约束），证据有稳定标识符，可溯源；由确定性打分器排序并暴露证据缺口，**但所有选择与最终答案仍由同一推理模型给出**。
  - **Search Skills**：可复用操作规程（触发条件、动作步骤、成功标准、停止条件），**条件式加载**，只在会改变下一步证据动作时加载，每条轨迹最多加载少量技能。
  - **证据驱动的检查点 + 预算感知收敛**：在足够外部结果后要求记录当前最优候选；接近交互上限时停止开启新搜索分支，只允许可在预算内完成的验证，然后冻结交互强制作答。
  - **最小干预原则**：默认保持原推理路径，仅在可复现的结构状态触发时插入提示/路由/恢复动作。

### 2.5 基础设施
- **训练**：SFT 用 VeOmni（无 padding 的动态 token 预算批处理、meta-device 初始化、rank-0-only checkpoint 加载）+ FSDP2 + FlashAttention-2，相对标准 HF 流水线 **>80% 端到端加速**；RL/OPD 用 VeRL 异步 rollout 流水线（rollout 与优化分离），vLLM 作 rollout 引擎，**约 2× 端到端加速**。
- **评估**：PistisEvalKit（基于 VLMEvalKit），Model 模块（Wrapper + Modeling 后端）与 Benchmark 模块解耦；支持自动化训练-评估循环与原生智能体评测（DeepEyesV2）。
- **推理**：在 vLLM 上做异步流水线（CPU 前/后处理与 GPU 计算重叠，多流下 GPU 利用率达 99%）、多进程前后端分离（缓解 GIL，共享内存传大负载）、以及**参数对齐**（将 ViT 未对齐维度补齐到 128 的倍数以启用 Hopper TMA，适配 H20）。部分 prefill 场景推理速度提升 >100%。
