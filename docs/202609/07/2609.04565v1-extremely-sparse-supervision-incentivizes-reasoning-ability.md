## 摘要
大型语言模型通过有效的后训练展现出越来越强的推理能力。然而，主流的后训练方法在大量token上进行优化，隐含地假设有效学习必须是token密集的。我们在同策略蒸馏（OPD）设置中重新审视了这一假设，该设置自然地在每个生成的token上提供密集的教师监督。使用Qwen3模型家族，我们发现了一个反直觉的现象：仅由极小比例的生成token——每条推理轨迹少至一两个token，对应全部token的仅0.05%——就能有效激发推理能力。令人惊讶的是，这种稀疏监督在多数情况下在提升推理能力方面能匹配甚至超越全token训练，尽管将绝大多数生成token排除在训练目标之外。这一现象在数学推理任务中跨越九种教师-学生配置（涵盖不同模型规模）时一致观察到，并在代码推理、Llama模型以及基于可验证奖励的PPO强化学习（RLVR）中进一步得到验证。有趣的是，这种极端稀疏的监督可能更接近自然的学习过程：不是逐词纠正每一步，而是反思少数关键推理步骤，更新先前的理解，并继续试错，避免微观层面的修正，同时保持显著有效。总体而言，我们的结果挑战了有效后训练必须token密集的假设，并为理解和设计更高效的后训练算法指明了新方向。

## Abstract
Large language models demonstrate increasingly strong reasoning capabilities through effective post-training. Yet, prevailing post-training methods optimize over massive numbers of tokens, implicitly assuming that effective learning must be token-intensive. We revisit this assumption in the on-policy distillation (OPD) setting, which naturally admits dense teacher supervision at every generated token. Using the Qwen3 family, we discover a counter-intuitive phenomenon: reasoning can be effectively incentivized by an extremely small fraction of generated tokens--as few as one or two tokens per reasoning trajectory, corresponding to only 0.05% of all tokens. Surprisingly, this sparse supervision in most cases matches or surpasses full-token training in improving reasoning ability, despite excluding the vast majority of generated tokens from the training objective. This phenomenon is consistently observed across nine teacher--student configurations spanning different model scales on mathematical reasoning tasks, and is further validated on coding reasoning, Llama models and Proximal Policy Optimization (PPO)-based reinforcement learning with verifiable reward (RLVR). Interestingly, such extremely sparse supervision may be closer to the natural learning process: rather than correcting every step word by word, one reflects on a few critical reasoning steps, updates prior understanding, and continues the trial-and-error, avoiding micro-level corrections while remaining remarkably effective. Overall, our results challenge the assumption that effective post-training must be token-intensive and point to a new direction for understanding and designing more efficient post-training algorithms.

## 1. 论文的核心问题与整体含义（研究动机和背景）

### 研究动机

- 主流后训练方法通常以“海量 token 监督”为前提：无论是在线策略蒸馏、SFT 还是各类强化学习，都倾向于让模型在被生成的全部 token 上获得密集优化信号。
- 这背后有一个**未被充分质疑的隐含假设**：即“有效学习必须是 token 密集的”，也即教师信号越细、改得越全，学生才学得越好。
- 然而，这种“字字纠正、步步监督”的方式既昂贵，也可能偏离人类学习的真实机制——人往往只需要反思少数关键步骤，就能调整思路并继续推理。

### 核心问题

在 on-policy distillation（OPD，同策略蒸馏）中：

> “如果把训练目标从全部生成 token 缩小到极少数的几个 token，是否依然能有效诱导模型产生更强的推理能力？”

### 整体含义

- 论文的结果表明：**有效后训练未必依赖 token 密集监督**。
- 这一现象如果稳健成立，将大幅降低后训练的算力与数据成本，并为推理模型的训练目标设计提供了新的研究方向。
- 同时，它也为理解“语言模型为什么能从稀疏奖励 / 稀疏反馈中学习”提供了经验证据。

## 2. 论文提出的方法论

### 总体框架：同策略蒸馏（OPD）

- OPD 是论文考察的“默认”训练场景。
- 在该设置下，学生模型先自己采样多条完整推理轨迹（即 on-policy 生成）；
- 教师模型对这些轨迹提供 token 级的、密集的监督；
- 因此，原则上每个生成 token 都可以进入训练目标，是一种“天然密集监督”的条件——论文正是在此“最不利”条件下检验稀疏监督。

### 核心思想

作者并不追求“稀疏化训练过程”，而只做 **token 选择式的稀疏目标**：

1. 生成一条完整的推理轨迹后，不再把整条轨迹的所有 token 都当作监督；
2. 只从轨迹中保留**极少量的关键 token** 作为监督目标；
3. 用这些 token 的损失更新模型；
4. 其余绝大多数 token 被显式排除于训练目标之外。

摘要中最关键的经验数据点是：

- 每条推理轨迹只保留 **1 到 2 个 token**；
- 换算到整体 token 预算后，只使用全部生成 token 的大约 **0.05%**；
- 即便如此，在许多配置下，推理能力的提升效果仍能与“全 token 训练”相比肩，甚至更好。

- ✓ **跨模型族验证**（Qwen3、Llama）
- ✓ **跨算法验证**（蒸馏式训练、基于验证奖励的强化学习）
- ✓ **不同监督密度梯度**（由“1–2 token”对应的 0.05% 所暗示）

因此，结论并非来自单一偶然设定，具备相当的外部有效性。

### 公平性与客观性的隐患

- 在给定材料中，无法判断“稀疏 token 在 9 种配置中匹配或超越全 token”的效应幅度与显著性；
- 无法排除“全 token 训练被早停/欠调”导致的比较偏差；
- 无法判断稀疏 token 的选取是否经过“事后最优选择”——若总是选择对结果贡献最大的 token，则会引入**选择偏差/信息泄露风险**；
- 摘要中未提及“稀疏监督失败的场景”，可能存在结果选择性报告。

总体判断：**实验策略覆盖面很广，但公平性细节需等待正文与复现结果。**

## 6. 论文的主要结论与发现

1. **反直觉的“稀疏足以”现象**
   - 将训练目标压缩到每个推理轨迹仅 1–2 个 token，占比约 0.05%，即可有效激发推理能力。

2. **稀疏监督不亚于全 token 监督**
   - 在绝大多数配置中，稀疏监督提升推理能力的效果与全 token 训练相当，甚至反超。

3. **排除了大量 token 也不损害推理能力**
   - 即使把绝大多数学徒生成的 token 排除在目标之外，模型依然可以学到关键推理能力。

4. **现象具有跨任务/跨模型/跨算法的一致性**
   - 数学推理、代码推理；
   - Qwen3 与 Llama；
   - 蒸馏式 OPD 与基于可验证奖励的 PPO/RLVR；
   - 九种教师—学生配置，都能重复该现象。

5. **对“后训练必须 token 密集”的范式性挑战**
   - 当前主流后训练大规模消耗 token 的做法可能并不是最优——关键信号密度可以非常低。

6. **形成一种有启示性的“类学习观点”**
   - 这种监督更像“反思少数关键步骤、更新已有理解、继续试错”，而不是“逐词微纠正”；
   - 也就是说，对模型推理而言，**选择性反思可能比全量纠错更高效**。

---

## 7. 优点（方法/设计亮点）

- **研究问题的切中要害**
  - 直接挑战后训练领域的根本假设“token 越密学得越好”，属于“低成本实验、高概念价值”的研究。

- **反面直觉的强冲击力**
  - 在有丰富 token 监督可用的 OPD 条件下刻意扔掉绝大多数 token，反而几乎不掉点，这一结果极具传播与启发价值。

- **多维度交叉验证**
  - 九种配置 + 两类任务 + 两类模型 + 两类算法，构成比较完整的证据链，比单任务单模型的结论更可信。

- **训练效率潜力**
  - 如果把训练目标从 100% 的 token 压缩到 0.05% 的 token，训练信号计算量会有数量级下降；对规模化训练有实用启发。

- **理论想象空间**
  - 该结果使“关键步骤/批判性思维信号”成为可操作的研究对象，而非仅仅是 token 数量。

- **从“纠错”到“反思”的视角转换**
  - 为后训练算法设计和数据拼配提供新的心智模型，不只是提出一种小 trick，而是改变为什么学、学什么的叙事。

## 8. 不足与局限

### （1）缺少关键的完整技术细节

- 输入材料中未见：
  - 具体 token 选择标准（选择位置、选择策略）
  - 损失函数公式
  - 训练超参数与 token 过滤规则
  - 稀疏度连续变化曲线
- 若无上述信息，很难判断是不是“恰恰是**某些关键 token**取代了全 token”这一解释，而非“随机 token 也有效”这种更强版本。

### （2）基准覆盖与评估面不够透明

- 摘要未提及具体数据集的名称；
- 未说明是“全部成功匹配”还是“多数匹配、少数下降”；
- 数学与代码都属于推理型任务，尚未证明该现象适用于通用对话、事实性知识学习或指令跟随类场景。

### （3）可能有“事后选优”的偏差风险

- 现实中部署“只监督一两个 token”时，需要事先决定【哪些 token 值得学】；
- 论文若先看结果再选 token，或只报告最优 token 选择策略，会产生乐观偏差；
- 若真正做到事前随机/无启发式挑选，其效果还能否匹配全 token

是本文可信度的关键所在。

### （4）关于采样与效率的叙事可能存在歧义

- “只使用 0.05% token”容易被理解为“训练总成本下降 99.95%”；
- 但实际上，OPD 流程中仍需完整采样轨迹，教师也需完整前向生成，主要节省的是目标计算与反向传播的 token 开销；
- 若采样与教师推理成本占主导，则总 wall-clock 收益会远小于“99.95%”这个数字给人的直觉。

### （5）稀疏监督的有效机制未被解释

- 论文摘要并未给出“为什么少数 token 能承载足够学习信号”的理论解释；
- 是否因为“推理轨迹中大多数 token 本身就是前一个 token 的高概率延续”，导致全 token 损失梯度高度冗余？
- 是否从信息论角度看，关键 token 的负对数似然已经包含了足够的“反思信号”？
- 是否有对梯度噪声、损失景观或表征变化的分析？这些维度在当前材料中完全缺失。

### （6）长期稳定性与遗忘风险未知

- 只看后训练结束时的 benchmark 分数，无法说明稀疏监督训练的模型是否更容易遗忘或过拟合少数 token 位置；
- 若某种 token 选择策略长期重复出现，模型可能在局部区域发生表征坍缩；
- 目前没有材料讨论多次迭代、多轮训练后的稳定性。

### （7）对“稀疏度”的极端区间刻画有限

- 摘要给出 1–2 个 token（约 0.05%）的极端点；
- 但没有说明 0.1%、0.5%、1%、5% token 的效果曲线是怎样的；
- 是否存在“全 token 训练是一个病态冗余、任何少量随机 token 都够”的强结论，还是必须精确命中关键 token 才能保住效果——这个边界没有被披露。

## 9. 学术贡献与领域影响（对未来工作的启示）

### 贡献

- **实证贡献**：以较系统的多配置实验揭示了“密集 token 监督并非推理能力习得的必要条件”这一特殊现象；
- **方法贡献**：在后训练中对 token 级监督目标做极端稀疏化处理，为高效后训练开辟了新的操作维度；
- **概念贡献**：帮助研究社区把视线从“监督的频率密度”转向“监督的信息质心”，即更关注哪些 token 才是真正承载可学习信号的 token。

### 领域影响

- 对 **合成数据蒸馏与教师-学生蒸馏范式**：教师无需对所有 token 承担“逐词纠错”职责，而只需提供少数关键位置的监督；
- 对 **强化学习奖励设计**：如果“结果正确性”或“少数位点”已能提供足够学习信号，则过程奖励模型庞大的训练与标注成本需要重新论证；
- 对 **后训练数据配比**：在固定预算下，可以牺牲单条轨迹的内部监督密度，换取更多不同轨迹的覆盖，从而提升数据多样性收益；
- 对 **推理模型的可解释性研究**：哪些 token 被选中可成为分析模型“何时学会关键推理步骤”的新工具。

## 10. 论文的弱点、争议点与社区潜在质疑

1. 对“extremely sparse”的定义是否夸大？
   - 从绝对数量看确实极端；但如果选中的 token 恰好是答案 token 或关键推理转折 token，其信息价值可能并不低于整条轨迹的平均信息量。因此，用“token 个数少”来描述稀疏性是准确的，但不应将其等同于“学习信号弱”。

2. 是否真的和“人类反思”类似？
   - 摘要将稀疏监督与“反思少数关键步骤”类比，这是一种启发式叙事。现有证据并不能直接区分两种解释：
     - 解释 A：模型确实像人一样，通过修正少数错误连接实现推理跃迁；
     - 解释 B：绝大多数 token 的损失在数学上高度相关、彼此冗余，任意去掉 99.95% 对梯度方向影响不大。
   - 论文如果想要支持解释 A，需要额外进行机制分析，而不是仅凭 benchmark 提升来判断。

3. 与现有“token 级 dense reward 不必要”类工作的区分度
   - 该结论与近年来“结果奖励比过程奖励更稳健”“仅用最终答案训练也能提升推理”等发现相近；
   - 论文的独特增量在于：即便在 on-policy teacher 给出理想 dense 监督的条件下，极端裁剪仍有效。这一点具有很强的消融对照价值。

4. 学术严谨性疑问
   - 若全 token 训练本质上有大量平坦冗余结构，那么“稀疏达到全 token 效果”的结论在信息论意义上并不意外；
   - 更有价值的对标应该是：用同样计算量去生成更多轨迹，或换成不同的采样策略，而不是只裁剪单条轨迹内部的目标 token。

## 11. 对读者与后续研究者的使用建议

### 若想引用本文

- 建议引用时使用精确限定语：**在 OPD/蒸馏及 RLVR 式验证奖励条件下，针对数学与代码推理任务，极端稀疏 token 监督可与全 token 监督效果相当**。
- 不宜以标题式语言宣称“全 token 训练无用”或“后训练无需密集监督”，因为这不完全等于论文的已验证范围。

### 若想复现

- 最小复现集：在给定任务与模型中设置 full-token 条件和每轨迹 2-token 条件；尝试三种 token 选择方式（随机、教师分歧最大、末位答案）；
- 输出指标：不仅要看基准分，还应看不同 seed 的方差，否则“或反超全 token”的结论容易受噪声干扰；
- 还应报告 0%, 0.01%, 0.05%, 0.1%, 0.5%, 1%, 10%, 100% token 的完整曲线，以定位临界点。

### 若想拓展理论解释

- 可从梯度低秩性 / 损失函数信息冗余角度切入：全 token 交叉熵损失中是否绝大多数 token 的梯度在期望意义上相互抵消或对齐；如果是，则稀疏采样是天然合理的目标压缩器；
- 甚至可以设计实验估计每个 token 损失的 Fisher 信息量，验证“1–2 个 token 掌握了轨迹的大部分有效信息”。

## 12. 总体评价与结论（中肯综述）

| 维度 | 评估 |
|---|---|
| **问题重要性** | 极高。直接冲击当前基于 dense token 的后训练方法论根基。 |
| **概念创新性** | 较强。将稀疏监督从“成本节省手段”上升到“学习机制命题”。 |
| **实验策略** | 较全面。覆盖多个模型族、任务、算法、规模配置，设计思路值得肯定。 |
| **技术完整性** | 从可得材料看显著不足。token 选取、损失目标、稀疏度曲线等关键操作缺失。 |
| **证据强度** | 摘要显示出强结果，但公平性、显著性、失败案例未知。 |
| **应用潜力** | 若可复现，对后训练成本压缩有重要参考价值。 |
| **理论深度** | 较浅。主要停留在经验现象层面，尚未提升到机制性理论解释。 |
| **可复现性** | 待确认。关键细节缺失使独立复现存在较高门槛。 |

### 最终总结

本文以一种强烈而简练的操作（每轨迹仅 1–2 个 token 参与训练）展现了一个反直觉现象：在具备理想密集 token 监督的同策略蒸馏场景中，极端稀疏的监督目标非但没有破坏模型的推理学习，反而在数学与代码推理上展现出匹敌甚至超越全 token 监督的效果。

该论文的价值不仅在于节省训练成本，更在于迫使社区重新讨论：

> “当模型能从 0.05% 的 token 中学到几乎一切时，那剩下 99.95% 的 token 到底在教什么？”

然而，由于此论文章节级细节尚未在本次可获得材料中呈现，现有结论应被视作一个有潜力的学术假设，而非可直接用于生产实践的成熟算法。真正的学术贡献大小，将取决于正文中能否清楚证明：稀疏 token 不是“事后挑出来的最优 token”，其增益不是来自“全 token 训练对照组的欠拟合”，该现象不是在某个敏感的超参数窗口下才成立。

总体而言，这是一篇选题尖锐、现象醒目、仍需深入审读的推理能力与高效后训练交叉方向论文。
