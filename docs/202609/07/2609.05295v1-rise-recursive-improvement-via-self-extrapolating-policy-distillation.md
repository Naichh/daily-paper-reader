## 摘要
同策略蒸馏（OPD）为语言模型后训练提供了密集的逐词元监督，但其有效性受限于教师模型的质量：外部教师模型存在分布不匹配问题，而带有特权条件的自蒸馏则受限于上下文学习能力。我们提出RISE（基于自外推策略蒸馏的递归改进），该方法直接从模型自身的RLVR训练轨迹中构建合成教师模型。通过外推当前检查点与滞后锚点之间的位移——在参数空间或输出logits空间中——RISE将稀疏的结果驱动的参数更新转化为密集的词元级目标，无需任何外部模型或特权条件。RISE以互补循环方式结合RLVR与OPD：结果奖励将外推引导至正确推理，而外推教师模型则细化词元级决策。此外，由于教师模型随着学生模型的改进而每轮迭代更新，蒸馏成为一种递归改进机制，而非一次性压缩步骤。涵盖数学推理、多领域STEM、代码生成以及多轮智能体任务的实验表明，在所有设置中，RISE均优于仅使用RLVR训练以及同策略自蒸馏方法。

## Abstract
On-policy distillation (OPD) provides dense, per-token supervision for language model post-training, but its effectiveness is bottlenecked by teacher quality: external teachers suffer from distribution mismatch, while self-distillation with privileged conditioning is limited by in-context learning capacity. We propose \textbf{RISE} (\textbf{R}ecursive \textbf{I}mprovement via \textbf{S}elf-\textbf{E}xtrapolating Policy Distillation), which constructs a synthetic teacher directly from the model's own RLVR training trajectory. By extrapolating the displacement between the current checkpoint and a trailing anchor---in parameter space or output logit space---RISE converts a sparse outcome-induced parameter update into a dense token-level target, without any external model or privileged conditioning. RISE combines RLVR and OPD in a complementary loop: outcome rewards ground the extrapolation toward correct reasoning, while the extrapolated teacher refines token-level decisions. Moreover, since the teacher is refreshed every iteration as the student improves, distillation becomes a recursive improvement mechanism rather than a one-shot compression step. Experiments spanning mathematical reasoning, multi-domain STEM, code generation, and multi-turn agentic tasks show that RISE outperforms RLVR-only training and on-policy self-distillation across all settings.

## 1. 核心问题与研究动机

**背景**：LLM 的后训练阶段普遍依赖 RLVR 或 RLHF，利用"结果级"奖励（outcome reward）——即一个序列只有一个标量分数。这类信号存在**信用分配瓶颈**（token-level credit assignment bottleneck）：无法告知模型推理链条中哪些词元导致了成功或失败。

**同策略蒸馏（OPD）** 本可提供更密集的逐词元分布监督，但其效果被 **教师模型质量（teacher quality）** 瓶颈所制约：

- **外部教师**：存在学生轨迹的分布不匹配问题（student-teacher distribution mismatch），当学生探索到教师未见过的前缀时，教师输出的分布会失真。
- **特权条件自蒸馏（OPSD）**：模型受上下文学习能力限制，且"特权信息"（如正确答案）引入的信息可能不可迁移甚至有害。
- 已有的启发式补救措施（词元级门控、KL 融合、DAgger 式轨迹采样等）属于"标治本不治根"——它们没有追问核心问题：**教师模型到底应该是什么？**

**本文的核心洞察**：理想的教师是模型自身的 **"未来版本" π\***；虽然 π\* 未知，但训练轨迹揭示了收敛方向。通过外推当前检查点与较早锚点之间的位移（表征空间中的线性外推），即可合成一个"教师"，从而：
- 无需外部模型，也无需特权上下文。
- 训练轨迹外推在数学上有据可依——先前研究表明后训练更新通常局限于低秩子空间且呈近似线性演化。

## 2. 方法论（RISE）

### 2.1 总览

论文将 RISE 概括为一个交替迭代的训练流程：

1. **RLVR 阶段**：提供方向（grounding）。结果奖励约束外推方向指向真实的能力提升。
2. **OPD 阶段**：提供细粒度（fine-grained）的逐词元目标。外推合成的教师，蒸馏回学生。

### 2.2 核心公式（自外推教师的构建）

设当前检查点 θn 经 RLVR 更新为 θ′ₙ₊₁（图中写成 θ′ₙ₊₁），位移为 Δ = φ(θ′ₙ₊₁) − φ(θₙ)：

> φ(π_future) = φ(π_θn) + β · [φ(π_θ′ₙ₊₁) − φ(π_θn)]，β > 1

β = 1 退化为当前检查点；β > 1 沿改进方向"外推"到未来。

### 2.3 两种实例化（Representation Map φ）

| 维度 | 权重空间外推（φ = θ） | Logit 空间外推（φ = log π） |
|---|---|---|
| 公式 | θ_future = θn + β·(θ′ₙ₊₁ − θn) | log π_future ∝ log π_θn + β·(log π_θ′ₙ₊₁ − log π_θn) |
| 本质 | 任务算术（task arithmetic） | 几何混合：π_future ∝ π_θn^(1−β)·π_θ′ₙ₊₁^β |
| 关系 | f(θn + βΔθ)，即完整神经网络前向 | f(θn) + βΔf，是权重空间外推的一阶泰勒近似 |
| 实现代价 | 需要物化参数和额外的教师前向 | 不需要修改参数，但需要缓存两套模型的 logits |
| 保真度 | 跨位置一致性（一个真实的模型） | 逐位置独立外推，无全局一致性 |

### 2.4 蒸馏损失

- 全词表 KL 计算过于昂贵，采用 **top-K 近似**（K=100，代码 K=20），将后 RLVR 检查点和锚点投影到相同的 K+1 单纯形上（保留尾部桶），然后施加外推公式。
- 实际使用 **JSD** 代替反向 KL（数值更稳定，且共享相同的最优解）。

### 2.5 关键设计细节

- **外推衰减（β decay）**：β 随训练过程从 β₀ 线性衰减至 1。原因：当策略逼近最优时安全外推范围收窄（理论基础见 Proposition 3）。
- **锚点动态（EMA anchor）**：默认锚点使用 EMA（η=0.1）而非上一个 checkpoint，以平滑每步 RLVR 的噪声。但在 OLMo 模型上 η=1 更好（因为其 RLVR 梯度本身较大且稳定）。
- **预训练轨迹的数据基础**：论文通过主成分分析验证，RLVR 训练中前 3 个主成分可解释约 87% 的位移方差（1.7B 与 8B 一致），是权重空间线性外推可行的核心证据。

### 2.6 与现有方法的关键差异

- 相较于固定外部教师（如 ExOPD），RISE 的教师是**非静态**的，随着学生进步而同步刷新，不会产生静态教师的性能天花板。
- 与特权条件自蒸馏相比，RISE 不需要正确解或额外上下文，对每个 prompt 都能产生蒸馏信号（不受 batch 内有无正确样本的限制）。

## 6. 主要结论与发现

实验中，RISE 在几乎所有设置中都稳定地超过同一设置下的 GRPO 和三种特权自蒸馏变体，且在部分基准上出现了较大的性能差距（例如 OLMo-7B 的 AIME'24 +16.7 分，AIME'25 +7.7 分，MATH-500 +5.4 分）。OOD 显著提升或持平。具体结论如下：

1. RISE 显著优于 RLVR-only 和特权条件自蒸馏基线，尤其在数学奥林匹克这类竞争性基准上。
2. RISE 比现有 RLVR 具有更好的**样本效率**（早期就能达到更高准确率）。
3. RISE 保持了 OOD 能力（不损害泛化）。
4. 外推方向必须有 RLVR 结果奖励的锚定；移除 RLVR 会导致训练崩溃（输出长度炸裂到上下文极限，奖励归零）。
5. 直接采用外推参数（不蒸馏）不会带来持续改进——真正的增益来自 OPD 的"信任域投影"。
6. 安全外推范围随时间训练收窄，需要通过衰减的 β 动态控制 RISE 的强度。
7. RISE 在权威证据下同时提升 avg@N 与 pass@N，即**扩展了可解问题的覆盖面**，而非仅仅将现有解锐化。

## 7. 主要优点

1. **问题切入清晰，切入点有价值**：提出"教师模型不应是给定的，而应被构建（what should the teacher be?）"的观点，直接击中了 OPD 方法的盲点。
2. **方法论优雅且自包含**：RISE 不需要外部模型、不需要特权信息，只用自己训练轨迹上的检查点做算术操作即可得到更好的教师——这在资源密集的 LLM 后训练中具有吸引力。
3. **数学与结构上的结合支撑**：
   - 性能差分解（Theorem 2）体现教师间隙与蒸馏误差的权衡关系；

4. **提供了深刻的机制式理解**。例如通过摘除性实验验证：β 外推不可怕，方向必须对齐；外推不等于有效改进，完整蒸馏才是有价值的能力获取方式。
5. 评估范围较广（数学 / STEM / 代码 / agentic 决策）。
6. 强调效率：通过复用 rollout，在不额外采样的情况下获得增益。

## 8. 不足与局限

1. **超参数对数据/模型敏感性较强**：β₀、EMA 速率 η 在不同模型上的最优取值方向是相反的（Qwen η 较小较好；OLMo η=1 较好）——这在一定程度上削弱了"通用方法、免调节"的设定强度。
2. **外部教师的对比缺失**：作者明确排除了外部教师 OPD（ExOPD 等），理由是方法不可直接比较。但这留下了"外部教师 + RISE 式递归"能否带来额外增益的问题悬而未决。
3. **线性性假设的风险**：可用的安全外推范围在训练后期显著变窄，β 过大会造成灾难性退化。虽然在线性外推假设下给出了规范化的理论动机，但对超出训练子空间的数据（或奖励函数突然变化）鲁棒性依然有限。
4. **奖励信号偏差的放大**：如果 RLVR 的奖励信号本身可被欺骗（如存在奖励污染），那么 RISE 只会放大那个虚假方向的坏影响。
5. **实验结果对基线有潜在局限**：SDPO 特权教师设定的可能性较多，不同的系统选择可能影响该基线的效果。作者提到基线的 teacher coverage 在 85%（8B）/70%（1.7B）左右，但所报告的部分基线（GRPO+SDPO）性能甚至低于纯 GRPO，也与其他两篇基线论文报告的增益幅度不一定完全一致——需要跨库对基线效果持保留态度。
6. **学科覆盖的广度仍有局限**：对于 vision 或多模态推理、较强的代码生成（非小型模型）等领域未做验证，同时 OOD 的维度和场景有限（只测了 3 个通用理解指令任务，没有测鲁棒的分布偏移情况）。
7. **算力细节不足**：未报告 GPU 型号和绝对成本，也不利于读者核实可复现性；每个设置仅一个 epoch 的观察，也未能体现长时间（超过一个 epoch）训练下的表现趋势。
