## 摘要
具有可验证奖励的强化学习（RLVR）和同策略蒸馏（OPD）已成为推理大语言模型后训练的两种主导方法。先前工作使用OPD密集的标记级监督来补充稀疏的RL奖励，在单一步骤内融合这两种信号：要么作为RL优势的加权加性组合，要么作为受教师调节的重新缩放。在本文中，我们表明一个简单的两阶段方案，即OPD-then-RL，在逻辑和数学推理基准上始终优于纯OPD、纯RLVR以及所有此类联合基线。除了经验结果之外，我们进一步通过pass@k行为、学习动态和参数更新来提供对此的系统性理解，从而得到一个一致的解释：OPD扩展了学生对教师支持解决方案的覆盖范围，而RL在该支持范围内进行锐化，而联合优化这两种信号会导致它们相互干扰。为了提供实用的方法，我们发现OPD验证分数是决定何时切换到RL的关键信号，并且OPD比SFT更好地作为RL的冷启动。总之，我们的结果确立了OPD-then-RL作为结合这两种方法的简单而强大的方式，将两个纠缠信号转变为互补阶段。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) and on-policy distillation (OPD) have emerged as two dominant methods for post-training reasoning LLMs. Prior work uses OPD's dense token-level supervision to complement the sparse RL reward, fusing the two signals within a single step: either as a \emph{weighted-additive combination} or a \emph{teacher-modulated rescaling} of the RL advantage. In this paper, we show that a simple two-stage scheme, OPD-then-RL, consistently outperforms pure OPD, pure RLVR, and all such joint baselines across logic and math reasoning benchmarks. Beyond the empirical results, we further provide a systematic understanding of this through pass@$k$ behavior, learning dynamics, and parameter updates, yielding a consistent explanation: OPD expands the student's coverage of teacher-supported solutions and RL sharpens within that support, while jointly optimizing the two signals causes them to interfere. To provide a practical recipe, we find that the OPD validation score is the key signal for when to switch to RL, and that OPD is a better cold start for RL than SFT. Together, our results establish OPD-then-RL as a simple yet strong way to combine the two methods, turning two entangled signals into complementary stages.

## 1. 背景、研究动机与核心问题

后训练（post-training）阶段是当前改进推理大语言模型（reasoning LLM）能力的关键环节，其中两类方法占据主导地位：

- **RLVR（Reinforcement Learning with Verifiable Rewards）**：以结果奖励（sparse，序列级）驱动策略优化，典型实现为 GRPO。其优点是奖励直接反映真实任务目标，缺点是稀疏奖励对中间推理步骤缺乏监督，模型需要大量试错才能发现高奖励行为。
- **OPD（On-Policy Distillation，同策略蒸馏）**：在**学生自身采样轨迹**上，以教师模型的下一词分布 / 轨迹级 reverse-KL 提供稠密、token 级监督。优点在于学习效率高、无探索负担；缺点是仅模仿教师行为，不直接优化任务奖励。

两类方法理论上互补：OPD 提供稠密信号、负责能力扩展；RLVR 提供真实目标、负责任务性能优化。因此核心问题是：

> **如何在统一框架下把 OPD 与 RLVR 信号有效结合？** 

本文梳理了现有混合方案，发现几乎全部集中于**单步联合优化**（single-step joint optimization）——即在同一个 token 级策略梯度更新中融合两种信号。作者提出一个“过于简单但被忽视”的替代方案——**OPD-then-RL 两阶段顺序训练**，并系统论证了其相对联合优化的优势与内在机理。

总体含义：**OPD 与 RLVR 不应在同一更新中“纠缠”（entangle），而应作为互补的阶段先后进行**。OPD 先扩展学生对教师支持解空间的覆盖率，RL 再在该支持范围内锐化概率分布，实现“先扩域、后精修”的明确分工。

## 2. 方法论

### 2.1 统一 token 级视角

本文先给出一个统一记号：RL（GRPO）与 OPD 的目标都可化为 token 级策略梯度上升：

\[
\nabla_\theta J^{alg}(\theta) = \mathbb{E}\left[\sum_{i,t} A^{alg,(i)}_t \; \nabla_\theta \log \pi_\theta(y^{(i)}_t | h^{(i)}_t)\right]
\]

- RL 的 token 级优势：\(A^{GRPO,(i)}_t = \hat A^{(i)}\)（每组归一化的序列级奖励，同一序列内所有 token 相同）
- OPD 的 token 级优势：\(A^{OPD,(i)}_t = d^{(i)}_t = \log \pi_T(y_t^{(i)}|h_t^{(i)}) - \log \pi_\theta(y_t^{(i)}|h_t^{(i)})\)（逐 token 的教师-学生对数似然差）

### 2.2 既有联合优化方法的两大范式

在此统一视角下，作者将所有现有 OPD-RLVR 混合方法归类为两种范式：

**范式一：加权加性（Weighted-Additive）**

\[
A^{add,(i)}_t = w_R\, \hat A^{(i)} + w_T\, d^{(i)}_t
\]

即教师信号作为独立加项参与最终优势；当教师与验证器相悖时，优势符号可被翻转。代表方法：
- **KDRL**：恒定常数权重加性组合，是原型方法；
- **KDRL-mask**：只在错误 rollouts 上加入蒸馏项，正确时关掉；
- **SRPO、HDPO**：按正确性或者整组是否全错进行门控路由。

**范式二：教师调制（Teacher-Modulated）**

\[
A^{mod,(i)}_t = m(d^{(i)}_t) \cdot \hat A^{(i)},\quad m(\cdot)>0
\]

教师信号只调节 RL 优势的**幅度**（即 token 级信用再分配），不改变其符号，因此不会覆盖验证器给出的更新方向。代表方法：
- **TRRD**：将教师信号折入重要性比率作为 trust-region 正则；
- **RLSD**：用截断教师因子直接缩放优势大小。

### 2.3 本文提出的方法：OPD-then-RL

核心做法极其简单——两阶段硬切换：

\[
A^{alg,(i)}_t =
\begin{cases}
d^{(i)}_t, & \text{training step} \le S \quad(\text{OPD阶段})\\
\hat A^{(i)}, & \text{otherwise} \quad(\text{RL阶段})
\end{cases}
\]

- 第一阶段：用 OPD 目标（学生自身 rollout + 教师 token 级反馈的 reverse-KL）训练 \(S\) 步；
- 第二阶段：切换为纯 GRPO，以验证器结果奖励继续优化；
- 切换点 \(S\) 的选取依据：OPD 验证分数进入“收益递减”平台期时切换（默认 \(S=60\)）。

该方法不包含任何单步混合权重或门控逻辑，只是把两种信号在时间轴上**解耦为互补阶段**——这与所有联合优化方法形成本质对照。

## 6. 主要结论与发现

1. **OPD-then-RL 全面优于联合方法**：在两族任务（逻辑 + 数学）上均取得最高平均 pass@1（逻辑 80.6，数学 31.8）；在逻辑推理上比其他组合方法高出 11.7–26.7 个百分点；数学任务上对六种方法显著领先、与三种最强方法统计持平；pass@32 上没有方法显著优于它。

2. **机理一：OPD 是“扩展”，RL 是“锐化”**。pass@k 分析显示：
   - OPD 提升整体 pass@k 曲线（尤其大 k 处），即扩大可解问题集合 → **能力边界外扩**；
   - RL 缩小 pass@128 与 pass@1 的差距，即把概率质量集中到高奖励路径 → **支持集内精修**；
   - OPD-then-RL 兼备“高 pass@128（继承 OPD）+ 高 pass@1（RL 锐化）”。

3. **机理二：联合优化互相制约，顺序解耦消除干扰**。学习动态发现：
   - OPD 和所有联合方法被教师 pass@1 封顶（plateau 在教师线附近），纯 RL 与调度类方法能突破教师上限；
   - RL 阶段中，KL(p_S‖p_T) 上升的表面“漂移”，实际上源于**熵下降快于交叉熵下降**——交叉熵持续走低，说明学生是在教师支持的嵌套集合内锐化，而非真正离开教师分布。

4. **机理三：参数更新层面**。sign-conflict 分析（SCR）显示：
   - 纯 RL 与 OPD 的符号冲突率极高（top-100% 约 17–21%）；
   - OPD-then-RL 的 SCR 在 top-10% 几乎为 0、即使 top-100% 也仅 3.4–3.9%；
   - 符号冲突主要集中在低幅值参数尾部，OPD 的关键方向得以保留；
   - 干预实验证明：用 OPD 系数替换 KDRL 的冲突方向会单调改善 pass@k 但降低 pass@1——二者在该子空间内构成真实的 trade-off。

5. **实践配方一：切换判据是 OPD 验证分**。若 OPD 仍在提升，晚切换（step 100）更优；若 OPD 已验证分饱和（如 Countdown 在 step 20 饱和），早切换也无损——说明 OPD 验证分数决定了 RL 的天花板。

6. **实践配方二：OPD 是比 SFT 更好的 RL 冷启动**。SFT 冷启动的模型在后续 RL 中 pass@1 增益微弱且 pass@32 普遍下降；OPD 冷启动不仅初始 pass@1 高（30.3 vs 25.4），后续 RL 还能带来全指标增益，尤其 pass@32 平均增长 7.2 个百分点。

1. **统一理论视角（token 级政策梯度）**：首次清晰地将七种以上 OPD-RLVR 混合方法纳入单一记号框架，划分为 weighted-additive 与 teacher-modulated 两大范式——这份分类学本身就是对领域的重要贡献，便于后续研究定位和比较。

3. **多角度机制验证的严密性**：
   - 三层论证（pass@k 行为 + 学习动态 + 参数更新）相互印证，结论一致；
   - KL 分解为“交叉熵 + 熵”的做法揭示了一个反直觉现象：KL 上升不等于脱离教师分布；
   - 通过“替换冲突参数”的干预实验建立了 causal 而非仅 correlation 的证据链；
   - sign-conflict 的幅值分层暴露了“尾段冲突无害”这一关键细节。

4. **面向实用的操作性结论**：给出切换点判定标准（OPD 验证分）、默认步数建议和对比 SFT 冷启动的完整额外实验套件，读者可直接复现并迁移到自己的管线。

5. **统计效能与可复现性**：paired bootstrap、跨模型尺寸 / 跨模型族验证、附完整代码链接，提升了结论稳健性与资源可及性。

## 8. 不足与局限

1. **教师─学生配置覆盖面窄**：只研究了“外部更强教师 + 较小学生”一种常规配置；未覆盖任务特定教师、多教师、自蒸馏（self-distillation）或学生相当于教师（同构）的情形。这类设置下“OPD 扩展 + RL 锐化”的分工是否维持、两阶段是否仍优于联合都无法确定。

2. **教师始终冻结**：未考虑“教师先做 RLVR 再蒸馏给学生”的教师优先分配方式。作者虽指出 OPD-then-RL 可视为其低成本的局部代理，但两者在同预算下的受控对比空缺。

3. **OPD 目标单一**：仅使用 on-policy reverse-KL（token 级）。未对比 forward-KL、JSD、或 top-K 分布的 reverse-KL，而这些目标在 mode-covering 行为与生成多样性上显著不同，可能导致不同冷启动质量。

4. **推理类别的局限**：仅限逻辑推理（模板化问题）和数学推理。未见代码生成、通用 agent 任务或科学推理。
   - 逻辑任务模板化可能偏利于蒸馏类方法（SFT 的“背格式”风险作者也承认）；
   - 数学任务的显著优势只在部分方法上成立——对三个最强的联合基线仅为统计持平。

5. **教学在较长轨迹上的计算开销未量化**：OPD 需要逐 token 的教师对数似然，在 8K-length 数学推理上代价显著高于纯 GRPO，但论文未做同等 token 预算下的成本─收益分析。

6. **切换点 S 的选择仍带人为性**：默认 S=60 虽然合理，不同任务间的最优切换差异（如 Countdown 可提前）说明“一刀切”切换点并非最稳健解；作者也承认自动动态停止机制未被探索。

7. **算力报告缺失**：未提供 GPU 型号/数量/总训练时长的精确化信息，限制了对可复现性与实用门槛的第三方评估。

8. **EOS token 等实现技巧的通用性**：作者手动掩盖 EOS 位置以消除 tokenizer 不匹配伪影，这在其余教师-学生 tokenizer 组合（尤其同代 EOS 场景）中是否需要或如何调整没有讨论，方法论迁移时存在未言明的隐藏细节。

### 一句话总结（局限维度）

> 该论文在**经验丰富度、机制剖析、统计严谨性**上都达到高标准，但**方法适用边界仍集中于外部冻结教师的数学/逻辑推理**，对更广的模型配置、成本效益与蒸馏目标选择尚未充分外推——这既留下了未来工作的空间，也在审慎解读时应视为结论适用性的约束条件。
