## 摘要
同策略自蒸馏（On-Policy Self-Distillation, OPSD）已成为大语言模型（LLM）自我提升的一种流行范式，它使模型能够利用真值解等特权信息来充当自己的教师。然而，近期研究发现，OPSD 可能严重损害 LLM 在复杂推理任务上的性能：通过强迫学生模仿一种以特权信息为条件、人为表现得自信的推理轨迹，OPSD 无意中抑制了不确定性的表达，并惩罚了解决难题所需的探索性和自我纠错行为。为解决这一问题，我们提出负向自蒸馏（Negative Self-Distillation, NSD），这是一个新的框架，它通过偏离有缺陷的推理而非模仿特权解来优化 LLM。NSD 不依赖真实答案或外部监督，而是利用模型自身生成针对特定问题的负向条件（例如，扮演“粗心的推理者”），并将学生的分布推离这个自生成的负向教师。朴素地应用遗忘目标来实现这种偏离是有问题的，因为有缺陷的推理 token 与基础语言 token 混杂在一起；不加区分地惩罚二者可能会导致模型的基础语言能力灾难性退化。我们通过设计一种动态门控机制来解决这个问题，该机制能自动识别并隔离对推理至关重要的 token，确保梯度更新仅针对行为缺陷，同时保留模型的语言先验。实证上，NSD 始终优于 OPSD 以及其他无标签、自举式强化学习（RL）基线。

## Abstract
On-Policy Self-Distillation (OPSD) has emerged as a popular paradigm for large language model (LLM) self-improvement, allowing models to act as their own teachers by leveraging privileged information such as ground-truth solutions. However, recent findings indicate that OPSD can severely degrade the performance of LLMs on complex reasoning tasks: By forcing the student to imitate an artificially confident reasoning trace conditioned on privileged information, OPSD inadvertently suppresses expressions of uncertainty and penalizes the exploratory, self-corrective behaviors required to solve challenging problems. To address this, we introduce Negative Self-Distillation (NSD), a new framework that optimizes LLMs by diverging from flawed reasoning rather than imitating privileged solutions. Instead of relying on ground-truth answers or external supervision, NSD uses the model itself to generate a question-specific negative condition (eg, acting as a ``careless reasoner'') and pushes the student's distribution away from this self-generated negative teacher. Naively applying unlearning objectives to achieve this divergence is problematic, as flawed reasoning tokens are confounded with basic linguistic tokens; indiscriminately penalizing both risks catastrophically degrading the model's foundational language capabilities. We resolve this by designing a dynamic gating mechanism that automatically identifies and isolates reasoning-critical tokens, ensuring gradient updates target only behavioral flaws while preserving the model's linguistic priors. Empirically, NSD consistently outperforms OPSD and other label-free, self-bootstrapping reinforcement learning (RL) baselines.

# 《Negative Self-Distillation: Learning to Reason by Avoiding Flaws》论文总结

## 1. 核心问题与整体含义

- **背景**：RLVR（可验证奖励强化学习）是提升 LLM 推理能力的主流范式，但存在采样开销大、奖励稀疏、组内奖励趋同导致优势坍缩、token 级信用分配粗糙等问题。
- **现有方案**：
  - On-Policy Distillation（OPD）依赖外部强教师提供稠密 token 级监督，但难以获得既强又 tokenizer 兼容的外部教师。
  - On-Policy Self-Distillation（OPSD）让模型自身借助特权信息（如真值解）充当教师，虽可扩展，但存在严重缺陷。
- **核心痛点**：OPSD 的教师因已知答案，会产生**人为自信、高度线性**的推理轨迹。迫使学生模仿这类分布，会**抑制不确定性表达、压制探索与自我纠错行为**，从而在复杂推理任务上反而损害性能。
- **整体含义**：论文提出一种思路转换——**与其模仿"正确答案"，不如显式避开"错误推理"**。据此提出 **Negative Self-Distillation（NSD）**，一个完全自举、无需标签的框架，通过让模型偏离自生成的"负向教师"来提升推理能力。

## 2. 方法论

### 2.1 核心思想
- 用模型自身生成**针对具体问题的负向条件**（如扮演"粗心的推理者"），据此构造负向教师 π_neg；
- 优化学生使其 token 分布**远离**该负向教师，而非模仿特权解；
- 关键挑战：缺陷推理 token 与普通语言 token 混杂，朴素 unlearning 会灾难性破坏基础语言能力。

### 2.2 关键技术细节

**（1）负向条件生成**
- 默认采用在线策略：先从学生采样初始解 y_init ∼ π_θ(·|x)，再基于 (x, y_init) 生成负向条件 n ∼ π_θ(·|x, y_init)；
- 也支持离线变体：solution-aware、question-only、wiki-irr（无关维基噪声）。

**（2）双教师构造（共享初始权重）**
- **Reference model π_ref**：仅以原问题 x 为条件，给出"正常"概率 π_ref(y_t|x, y_<t)；
- **Negative teacher π_neg**：以问题 + 负向条件 n 为条件，给出"被负向偏置"的概率 π_neg(y_t|x, n, y_<t)。

**（3）动态 Token 级门控（解决 RQ1）**
- 定义门控：
  `G_t = max(0, π_neg(y_t|x,n,y_<t) − π_ref(y_t|x,y_<t))`
- 若 π_ref ≥ π_neg，说明该 token 不受负向条件影响，自动豁免惩罚；
- 若 π_neg > π_ref，说明负向提示显著抬高了该 token，标记为需抑制的推理关键 token，且惩罚权重与正差值成正比。

**（4）有界 Sigmoid 非似然惩罚（解决 RQ2）**
- 原始非似然 `−log(1−π_θ)` 在 π_θ→1 时趋于无穷，导致梯度爆炸，破坏标点、空格等高频结构 token；
- NSD 用 Sigmoid 压缩：
  `L_GU^(t) = G_t · σ(−log(1−π_θ(y_t))) = G_t · (1/2 − π_θ(y_t))`
- 梯度分析：∂GU_sig/∂z_c = G·π_c(1−π_c)/(2−π_c)²，当 π_c→1 时梯度趋于 0，实现**隐式梯度衰减**，把最强监督集中在中等置信度（π_c≈0.67）的推理关键 token 上。

**（5）KL 正则化与总目标**
- 引入参考加权的点式前向 KL 锚：
  `L_KL^(t) = π_ref(y_t|x,y_<t) · log[π_ref / π_θ]`
- 单 token 总损失：`L_NSD^(t) = L_GU^(t) + α · L_KL^(t)`（α=0.01）
- 总体目标：`J(θ) = E_{(x,n)∼D, y∼π_θ} [ Σ_t L_NSD^(t) ]`

**（6）算法流程**
1. 初始化学生 π_θ，冻结教师 π_ref = π_neg = π_θ0；
2. 对每个问题 x_i：采样推理轨迹 y 和负向提示 n_i；
3. 对每个 token t：计算 p_ref、p_neg、p_θ，求门控 G_t，累加 NSD 损失；
4. 梯度更新 θ。

## 6. 主要结论与发现

- **性能提升显著**：NSD 在 1.7B / 4B / 8B 上平均绝对提升分别为 **+2.3% / +7.5% / +6.0%**，均为各规模最优（p 值低至 <10⁻⁴）。
- **大模型收益更大**：得益于在线自生成负向条件质量随模型能力提升，4B/8B 增益明显强于 1.7B。
- **保留并激发反思能力**：反思 token 频率从 baseline 3.6、OPSD 2.2、Intuitor 0.8 提升至 **NSD 7.5/response**，表明模型更主动重新评估与纠错。
- **训练更高效**：单条 rollout + 并行前向 + 仅需 3 个标量概率，避免全词表 logit 对齐；整体比 OPSD、Intuitor 更快。
- **负向条件策略鲁棒**：question-only（+7.3%）与 wiki-irr 等轻量离线策略也能接近在线 solution-aware（+7.8%）的效果。
- **门控有效隔离风格 token**：style-task ratio 从 OPSD 的 5.4× 降至 NSD 的 2.6×–3.5×。
- **KL 约束不可或缺**：去掉 KL 后训练中期出现分布漂移、gate 激活率骤降与学习-遗忘循环。
- **思考模式同样有效**：Qwen3-4B 思考模式下 NSD 平均 +3.0%，OlympiadBench 提升尤为明显（+12.0%）；Intuitor 因过度思考截断反而严重退化。

## 7. 优点

- **范式创新**：把自蒸馏从"模仿正确答案"转为"规避错误模式"，从根本上绕开 OPSD 的特权信息偏差与过度自信问题。
- **完全无标签、无外部教师**：负向条件由模型自身生成，可扩展性强。
- **门控机制设计精巧**：用 π_neg − π_ref 的正向差自动过滤普通语言 token，无需人工规则，附有定量风格-任务比验证。
- **Sigmoid 有界惩罚有理论支撑**：附录给出完整梯度推导，证明其对高置信 token 的隐式衰减特性，避免梯度爆炸。
- **训练效率高**：单次 rollout、并行 prefill、标量级损失计算，实测 wall-clock 优于 OPSD。
- **实验规范**：报告 CI 与 p 值，消融完整，对基线做了统一化处理，案例研究展示真实纠错轨迹。
- **框架可扩展**：兼容多种负向条件策略，并可迁移到策略梯度优化形式。

## 8. 不足与局限

- **依赖模型自身能力**：NSD 需要学生能生成有意义的负向对比，对极小或极弱模型可能效果有限（作者自述）。
- **在线策略开销**：默认在线生成负向条件需额外 rollout 与前向传播，虽可换用 wiki-irr 缓解，但可能牺牲部分效果。
- **领域覆盖有限**：实验仅限数学推理（MATH 训练 + 7 个数学 benchmark），未验证代码、逻辑、通用推理等其他领域。
- **模型族单一**：仅使用 Qwen3 系列，跨模型族（Llama、DeepSeek 等）的泛化性未验证。
- **负向条件质量难以量化**：不同策略效果差异（如离线 solution-aware 反而更差）提示对条件生成时序与质量敏感，但缺乏系统分析。
- **反思 token 指标较粗糙**：仅按关键词表统计频率，可能与真实反思质量存在偏差。
- **超参敏感性未充分探讨**：α、top-k、门控阈值等超参的敏感性分析较少。
- **公平性细节**：OPSD 使用 LoRA、Intuitor 调整 batch size 等设置虽为公平起见，但也可能引入方法间不对等因素。
