## 摘要
更多的特权信息并不总能造就更好的教师。我们在同策略自蒸馏（OPSD）中研究这一张力：在该方法中，基座模型的一个冻结副本在特权上下文下对学生自身的 rollout 进行评分，而该特权上下文通常是一个完整参考解答，将最终答案与某一条特定推理路径捆绑在一起。在每个规模内保持学生视图与训练固定，我们将这一默认设置与三种离线编译的抽象（具名策略、与方法无关的框架表述以及问题类别）进行比较，并与仅答案对照进行比较，后者保留终点但移除路径。在竞赛数学的主实验中，最佳中间上下文在 4B 和 8B 规模上分别将域内峰值均值较完整解答提升 1.4 分和 1.6 分，同时存储的提示 token 少一个数量级。跨三个随机种子的比较也显示，框架上下文和类别上下文在两个规模上均带来正向平均增益。仅答案条件化在主实验中仍具竞争力，在这些规模上与完整解答相差 0.2 分以内。偏好的上下文随学生规模与任务而变化。初始教师—学生 KL 散度并不能对下游性能进行排序。因此，自我教师应看到的不是它能看到的全部信息，而是其学生仍能据以行动的抽象层级。

## Abstract
More privileged information does not always make a better teacher. We study this tension in on-policy self-distillation (OPSD), where a frozen copy of the base model scores the student's own rollouts under privileged context, conventionally a complete reference solution that bundles the final answer with one particular reasoning path. Holding the student view and training fixed within each scale, we compare that default against three abstractions compiled offline, a named strategy, a method-independent framing, and a problem category, and against an answer-only control that keeps the destination but removes the path. In the primary runs on competition mathematics, the best intermediate contexts improve the in-domain peak mean over the full solution by 1.4 points at 4B and 1.6 at 8B, while storing an order of magnitude fewer hint tokens. Comparisons across three seeds also show positive mean gains for the framing and category contexts at both scales. Answer-only conditioning remains competitive in the primary runs, within 0.2 points of the full solution at these scales. The preferred context varies with student scale and task. Initial teacher-student KL does not order downstream performance. What a self-teacher should see is therefore not everything it could, but the level of abstraction its student can still act on.

## 一、核心问题与整体含义

- **研究背景**：同策略自蒸馏（On-Policy Self-Distillation, OPSD）中，学生从问题出发采样轨迹，一个冻结的基座模型副本作为"自教师"，在**特权上下文**（privileged context）下对学生的同一前缀重新评分，从而提供稠密推理监督。教师与学生起点相同，教师的优势完全来自**信息不对称**，而非更强的模型能力。
- **核心问题**：传统做法把特权上下文设为**完整参考解答**（同时包含最终答案与一条特定推理路径）。但"更多信息"未必是"更好的监督"——完整解答提供显式过程，却可能把教师引导锚定在某条特定推导上；抽象提示或裸答案则给教师更多自由度。论文追问：**自教师应在什么抽象层级上看到参考解答？这一选择如何随学生规模与任务变化？**
- **整体含义**：特权上下文的设计本身就是监督机制的一部分，应被当作独立的设计变量，并以"训练出的学生表现"而非教师分布性质来评判。论文标题给出的答案是：自教师应看到的不是它能看到的全部，而是**其学生仍能据以行动的抽象层级**。

## 二、方法论

- **核心思想**：把教师侧上下文包（context package）作为受控干预变量，固定学生视角与训练流程，仅改变教师看到的内容层级，再以训练后学生成绩衡量上下文效用。

- **上下文策略形式化**：对每个训练问题 \(x\)，上下文策略 \(c_\ell(x)=B_\ell(x,h_\ell(x))\)，其中 \(h_\ell(x)\) 是从问题与参考解答构造的表示，\(B_\ell\) 是模板（含引导措辞"bridge"）。学生只看到 \(x\)，特权上下文只影响冻结教师的监督。

- **五个层级（L1–L5）**：
  - **L1 完整参考解答**：原始解法，约 657 token。
  - **L2 具名策略**：点名一个方法/定理/工具，但不展开步骤，禁止出现最终答案，约 39 token。
  - **L3 方法无关框架**：给出一个可迁移的认知框架转变，不含方法名与操作序列，约 25 token。
  - **L4 问题类别**：只给数学领域与对象类别，约 18 token。
  - **L5 仅答案**：只给最终答案，约 7 token，位于抽象轴之外。
  - L2–L4 由**分级语义编译**生成：L4 → L3 → L2，每个更细的调用都能看到更粗的已生成表示，并用契约强制禁止最终答案与具体数值。

- **OPSD 训练目标**：学生采样轨迹 \(y\sim p_\theta(\cdot|x)\)；冻结教师用上下文评分同一前缀，得到 \(q_{\ell,t}=p_{\theta_0}(\cdot|c_\ell(x),y_{<t})\)。损失为逐 token 分布匹配（式 4），实现上使用**全词表裁剪目标**（式 9）：对每个词表分量先做上截断 \(\min(u_{\ell,t,v},\tau)\) 再求和，因此并非精确 KL，而是裁剪后的教师—学生分布目标。教师冻结、轨迹固定，上下文改变会同时改变梯度的幅度与方向。

- **效用定义与诊断分离**：上下文效用定义为 \(U_{B,r}(c_\ell;\theta_0)=\mathbb{E}_\xi[r(\{\text{Score}_B(\theta_{\ell,\xi,k})\}_{k\in S})]\)，即按报告规则 \(r\)（峰值、固定端点等）对训练后 checkpoint 聚合。另设**分布差异诊断** \(D(c_\ell)=\mathbb{E}_{(x,y_{<t})\sim\mu_0}[D_{KL}(q_{\ell,t}\|p_{\theta_0,t})]\)，用基座模型固定 rollout 的相同前缀，避免把上下文效应与不同学生 rollout 分布混在一起。

- **三个待检验的强基线预测**：全解主导（L1 最好）、差异排序（KL 越大效用越高）、上下文不变性（存在跨规模/任务/规则的统一最优上下文）。

## 三、实验设计

- **学生模型**：Qwen3-1.7B、4B、8B 三个规模。
- **训练数据**：OPSD 原始数学题池，29,434 道题；训练 200 步，LoRA，每 25 步存 checkpoint。
- **域内 benchmark**：AIME24、AIME25、HMMT25，指标 Avg@12（每题采样 12 次）。主报告为每个 (模型, 条件, benchmark) 在 8 个 checkpoint 中**单独选取峰值**后的三 benchmark 均值（ID peak mean），同时报告无选择的 step 200 端点。
- **迁移 benchmark**：MT-AIME2024-7Lang（7 语言宏平均 Avg@12）、AutoLogi-EN（验证器准确率）、GPQA-Diamond（Avg@10）、ZebraLogic-grid（精确网格准确率）；C-Eval 作为单独解读的受限生成审计。
- **对比条件**：L1（完整解答，基线）、L2、L3、L4、L5（仅答案）、Base（未适应 checkpoint）。
- **编译器对比**：主编译器 Qwen3.5-397B-A17B；复制编译器 Qwen3-8B（thinking 模式）。
- **消融与控制**：
  - 三个训练种子（42、43、44）复制 L1/L3/L4 的域内比较，并在四种 checkpoint 聚合规则下汇总。
  - 前缀截断控制（固定 10% 参考前缀 + 答案，4B）。
  - 共享 bridge 控制（统一教师措辞，4B）。
  - rollout 预算加倍控制（1024 → 2048 token，4B）。
  - 混合与路由研究（Uniform/MidMix/ExtremeMix，4B 与 8B；学习路由器、似然优势路由、两条规则路由）。
  - 上下文语义审计（1,200 题分层抽样，直接答案泄漏与"答案等价泄漏"）、行为标注分析、item 级难度分桶分析。

## 四、资源与算力

- **GPU**：单节点 **8 × NVIDIA H200**（三个规模均使用 8 卡）。
- **训练规模**：三个学生规模各训练 **200 个优化步**，checkpoint 间隔 25 步；LoRA rank 64 / scaling 128；学习率 \(5\times10^{-6}\)，梯度范数上限 0.1。
- **批大小**：有效 batch 分别为 64（1.7B）、32（4B）、32（8B）；每卡 batch 4/4/2，梯度累积 2/1/2。
- **未明确说明**：论文**没有报告实际训练时长、总 GPU 小时数或能耗**，也没有给出编译器离线生成全量上下文的推理成本。上下文 token 长度统计（L1 约 657、L2 约 39、L3 约 25、L4 约 18、L5 约 7）只反映教师评分接口的存储开销，作者也声明这不等同于端到端墙钟成本。

## 五、实验数量与充分性

- **实验规模概览**：
  - 主实验：3 个规模 × 6 个条件（L1–L5 + Base）× 3 个域内 benchmark + 4 个迁移 benchmark。
  - 种子复制：3 个规模 × 3 个种子 × 3 个层级（L1/L3/L4），并在 4 种聚合规则下报告。
  - 编译器复制：用 Qwen3-8B 重新编译 L2–L4，在 3 个规模上重训。
  - 补充控制：前缀截断、共享 bridge、加倍 rollout 预算、多种混合/路由策略、行为与 item 级分析、语义审计。
  - 粗略估计训练 run 数量在 **60–70 个**量级（含各控制与复制）。
- **充分性**：
  - **优点**：L1/L3/L4 的域内比较有 3 个种子、3 个规模、4 种报告规则，并区分"峰值"与"无选择端点"，统计上相对扎实；控制实验覆盖了 bridge 措辞、长度、rollout 预算、编译器身份等主要替代解释。
  - **不足**：L2、L5、迁移评测、前缀/bridge/预算控制、混合与路由均为**单次运行**，只能视为期望内的一次观测而非效用估计；L2 没有多种子复制。
- **客观性与公平性**：
  - 每个规模内学生初始化、学生 prompt、冻结教师 checkpoint、训练集、rollout 过程、训练预算与损失均固定，上下文是唯一变量，控制较严格。
  - 但存在**选择性偏差**：域内峰值在 8 个相关 checkpoint 上取最大，天然偏高；item 级分析中"最佳中间条件"是在同一评测上选出的；难度分桶以 L1 自身成功率定义会引入回归均值。
  - 语义、长度、答案访问三个因素在 L1–L4 间同时变化，无法完全分离；前缀控制只匹配了截断，未匹配长度与答案访问。
  - 规模比较中，学生规模与训练配方（有效 batch 等）同时改变，因此是"训练系统"之间的比较而非单纯参数量比较。

## 六、主要结论与发现

- **简洁语义上下文可超过完整解答**：主实验中最佳中间上下文在 4B、8B 上分别比 L1 的域内峰值均值高 **1.39** 和 **1.57** 分，而存储提示 token 少一个数量级（L2–L4 平均 17.7–38.9 token vs L1 的 657.3）。
- **1.7B 例外**：最小规模上 L1 仍保持最高峰值（领先 L4 仅 0.28 分）；L3/L4 在 1.7B 的种子均值差异接近 0 或为负，无选择规则反而偏向 L1。
- **偏好随规模与任务变化**：4B 上 L3 或 L4 领先，8B 上 L2/L3/L4 各有胜负；迁移任务上不同 benchmark 的胜者不同，甚至在 1.7B 同一规模内出现反转（MT-AIME、GPQA 偏 L3，ZebraLogic 偏 L1）。没有跨全部规模与任务的统一最优上下文。
- **仅答案条件具竞争力**：L5 在 4B、8B 与 L1 的域内峰值均值差距在 0.2 分以内，但在 1.7B 落后 1.76 分
