## 摘要
强化学习（RL）能提升推理能力，但其性能取决于训练开始时所依据的策略。我们将在策略蒸馏（OPD）作为 RL 的准备阶段进行研究，并追问其收益是否超越蒸馏模型初始准确率的提升。在相同的 RL 设置下，使用 OPD 初始化的学生模型比直接进行 RL 或先监督微调再进行 RL 的模型取得更高的最终性能。即使在 OPD 几乎未带来即时准确率提升时，这种优势也可能出现。RL 前的 Pass@k 并不能完全解释这一收益：相似甚至更高的值未必导致 RL 后更好的性能。行为分析表明，除 top-1 一致之外，与教师分布的对齐可能是一种解释。这种对齐可能偏好更高质量的推理路径，同时保留 RL 可利用结果反馈进一步优化的替代路径。我们进一步考察轨迹来源和散度目标如何影响蒸馏对后续 RL 的价值。标准反向 KL OPD 在 RL 前表现更好，但前向 KL OPD 在之后反超；当使用教师生成的蒸馏轨迹时，反向 KL 在两个阶段均保持领先。这些发现表明，更优的蒸馏目标取决于轨迹来源和后续训练。我们的结果支持将 OPD 作为 RL 的准备阶段进行评估，并根据后续训练后取得的性能来选择蒸馏方案。

## Abstract
Reinforcement learning (RL) improves reasoning, but its performance depends on the policy from which training begins. We study on-policy distillation (OPD) as a preparation stage for RL and ask whether its benefits extend beyond improvements in the distilled model's initial accuracy. Under shared RL settings, students initialized with OPD reach higher final performance than those trained with direct RL or supervised fine-tuning followed by RL. This advantage can emerge even when OPD produces little immediate improvement in accuracy. Pre-RL Pass@k does not fully explain the benefit: similar or even higher values do not necessarily lead to better performance after RL. Behavioral analyses point to alignment with the teacher's distribution beyond top-1 agreement as a possible explanation. Such alignment may favor higher-quality reasoning paths while retaining alternatives that RL can further refine using outcome feedback. We further examine how trajectory sources and divergence objectives affect the value of distillation for subsequent RL. Standard reverse-KL OPD performs better before RL, but forward-KL OPD overtakes it afterward; with teacher-generated distillation trajectories, reverse KL remains ahead at both stages. These findings suggest that the preferred distillation objective depends on both the trajectory source and the training that follows. Our results support evaluating OPD as preparation for RL and selecting distillation choices by the performance achieved after subsequent training.

# 论文总结：RL Starts before RL: On Policy Distillation for Better Reinforcement Learning

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：强化学习（RL）已成为提升语言模型推理能力的重要途径，但 RL 的最终效果高度依赖"训练起始策略"。起始策略决定了模型在训练中生成什么、如何响应反馈，因此"RL 之前如何准备模型"是训练流程的关键一环。
- **问题痛点**：
  - 常见准备方式是 SFT（用强教师的解答做监督微调），但已有研究表明，中间模型在 SFT 阶段的独立准确率并不能可靠预测其 RL 后的表现（Kang et al., TailSFT 等）。
  - 在策略蒸馏（OPD）是另一条路径：学生自己生成回复，教师在这些回复的每个前缀上提供完整下一 token 分布。OPD 通常只以"蒸馏后学生的准确率"来评估。
- **核心研究问题**：**OPD 是否能作为 RL 的准备阶段，带来超出"即时准确率提升"的收益？** 即：一个蒸馏后准确率提升甚微的 checkpoint，是否仍能成为更好的 RL 起点？
- **整体含义**：论文主张应把蒸馏视为 RL 训练流程的一部分，**用"后续 RL 后的性能"而非"蒸馏后的即时性能"来评估与选择蒸馏方案**。

## 2. 方法论：核心思想与关键技术细节

### 2.1 三种准备路径的比较框架
在同一基座学生、同一 RL 配置下比较三条流水线：
- **Base → RL**：基座模型直接进入 RL。
- **SFT → RL**：先用硬 token 目标在教师生成的已验证解答上做监督微调，再进入 RL。
- **OPD → RL**：学生先生成自己的回复，教师在这些学生前缀上提供完整下一 token 分布，用 KL 匹配，再进入 RL。

### 2.2 蒸馏目标与轨迹来源的正交分解
设教师策略 $\pi_T$、学生策略 $\pi_\theta$，前缀 $s$ 上 $p_s(a)=\pi_\theta(a|s)$、$q_s(a)=\pi_T(a|s)$：

- **SFT 目标**：$L_{SFT} = -\mathbb{E}_{(x,y_T)}\frac{1}{|y_T|}\sum_t \log \pi_\theta(y_T^t \mid x, y_T^{<t})$（硬标签）。
- **反向 KL（RKL）**：$L_{RKL}(s) = D_{KL}(p_s \| q_s)$。
- **前向 KL（FKL）**：$L_{FKL}(s) = D_{KL}(q_s \| p_s)$。

两个维度可独立变化：
- **轨迹来源**：学生生成前缀（OPD）vs. 教师生成前缀（TFD，Teacher-trajectory Distillation）。注意 TFD 仍使用完整教师分布，因此区别于使用硬 token 目标的 SFT。
- **KL 目标**：RKL vs. FKL。

论文假设：RKL 惩罚学生在教师不认可的续写上分配概率，FKL 惩罚对教师支持的续写覆盖不足；两者施加损失的前缀位置不同，因此效果依赖轨迹来源。

### 2.3 下游 RL
- 使用 **GRPO 风格**的 RL，训练验证器检查最终答案正确性（boxed answer）。
- 同一设置内，Base / SFT / OPD 三条流水线**共享** RL 训练数据、验证器、优化器与采样配置，仅起始策略不同。
- 训练持续到观察到训练崩溃（奖励/熵突变、文本不连贯）为止。

### 2.4 RL 前的行为诊断（关键分析工具）
在每个设置的 1,024 个共享诊断 prompt 上（每个 prompt 采样 64 条回复）测量：
- **Pass@k**：$\text{Pass@}k(x) = 1 - \binom{n-c_x}{k}/\binom{n}{k}$，以及正确计数分布、全错组概率 $\hat p_{0,g}$、混合正确性组概率 $\hat p_{mix,g}$。
- **教师分布对齐**：在各自策略访问的前缀上记录双方 top-20 token 及其 log 概率，计算 **top-20 JS 散度**（在并集上分别归一化后计算）、**top-1 一致率**、**top-20 Jaccard 重叠**、共享教师质量。
- **保留的不确定性**：在固定"推理词表"（strategy 词表，如 let/assume/therefore/step 等）匹配位置上的 **token 熵**，并按回复正确与否分组。

## 6. 主要结论与发现

1. **OPD 是有效的 RL 准备阶段**：在文本和 VL 两个设置下，OPD 初始化的 RL 都取得最高最终平均分（文本 59.18，超直接 RL 7.28、超 SFT→RL 11.70；VL 63.02，超直接 RL 1.34、超 SFT→RL 1.69）。文本 8 项全部优于两个替代方案；VL 上优于直接 RL 16/20 项（1 平），优于 SFT→RL 17/20 项。
2. **收益可与即时准确率提升脱钩**：文本中 OPD 只把 RL 前平均分从 36.48 提到 37.02（+0.54），但 RL 后领先扩大到 7.28；AIME24 上 OPD 甚至起点低于 Base（24.17 vs 24.90），RL 后达到 57.71 vs 47.40。OPD 在 RL 期间整体提升 22.16 分。
3. **RL 前 Pass@k 不能完全解释收益**：文本 Base 与 OPD 的 Pass@k 曲线几乎重合（Pass@1 18.4% vs 19.3%，Pass@64 80.4% vs 80.0%），最终却相差 7.28 分；SFT 的 Pass@1 最高（29.33%）但最终分最低；VL 中 RKL 与 FKL 的 Pass@64 完全相同（92.68%）但 FKL 最终高 1.85 分。
4. **可能的行为解释**：OPD 相比 Base/SFT 有更低的 top-20 JS 散度（文本 0.01468 vs SFT 0.01720；VL 0.06431 vs 0.07208），同时保留了接近 Base 的 token 熵（文本 1.048 vs SFT 0.242；VL 0.629 vs SFT 0.214）。**SFT 的 top-1 一致率反而略高，但分布更集中**——说明"首选 token 一致"与"分布整体接近"是两回事。假设是：OPD 把概率推向更高质量续写，同时保留可供 RL 用结果反馈进一步调整的替代路径。
5. **蒸馏目标的最优选择取决于轨迹来源与后续训练**：
   - 学生轨迹（OPD）：RKL 在 RL 前领先（60.66 vs 60.17），但 FKL 在 RL 后反超（64.87 vs 63.02），FKL 在 20 项中 14 项更高。
   - 教师轨迹（TFD）：RKL 两个阶段都领先（57.09 → 61.90 vs 56.12 → 59.20）。
   - OPD 在任一目标下最终都优于 TFD。
6. **总体主张**：应以"后续 RL 后的性能"来评估和选择蒸馏目标与轨迹来源，而非蒸馏后的即时成绩。

## 7. 优点

- **评估视角的重新定位**：把蒸馏放在"为 RL 做准备"的框架下评估，直击"SFT 分数高不代表 RL 后好"这一实际痛点，具有很强的实践指导意义。
- **正交的实验设计**：把"轨迹来源"与"KL 目标"解耦为两个维度，并发现两者存在交互（FKL 的优势仅在学生轨迹下出现），避免了笼统地宣称某一目标更优。
- **超越单一指标的诊断体系**：不只看 Pass@k，还引入 top-20 JS 散度、top-1 一致率、Jaccard 重叠、词表条件熵、组结果概率等，从"覆盖度—分布对齐—不确定性"三个角度给出机制性解释。
- **控制变量较为严谨**：同一设置内三条流水线共享 RL 数据、验证器、优化器与采样配置；benchmark 与训练 prompt 严格分离。
- **统计报告较诚实**：对 Pass@k 差异给出 bootstrap 95% 区间，并如实标注哪些差异包含 0；对失败与退化案例（如 VL 上的 4 项落后、AIME24 上 FKL 低 4.02 分）不做隐瞒。
- **局限自觉**：作者主动指出未独立变化两个行为因素、未设计新目标函数、未估计 seed 方差。

## 8. 不足与局限

- **训练种子方差未估计**：四路轨迹来源 × 目标对比各只有一次蒸馏 + 一次 RL 运行，无法判断 1.85 分等差距是否稳健。
- **机制解释仍是假设**：教师分布对齐与保留不确定性未被独立操纵，二者的个体贡献和交互作用未解，因果关系未经受控干预验证。
- **未提出新目标函数**：只对现有 RKL/FKL 做比较，没有把观察到的规律转化为专为后续 RL 设计的蒸馏目标。
- **算力与效率信息缺失**：未报告 GPU 型号、数量、训练时长；且作者明确说明共享 RL 设置不等于等运行长度，SFT/OPD 还有额外准备成本，因此**不能据此得出效率层面的结论**。
- **checkpoint 选择准则未说明**：报告哪个 checkpoint 的规则"在可用记录中未指定"，可能影响可比性。
- **模型与领域覆盖有限**：主要基于 Qwen3-8B/32B 与 Qwen3-VL-8B/32B 一对模型，任务集中在数学与多模态推理；结论能否推广到其他规模、其他任务族（如代码、agent、长文本）尚不确定。
-

- **基准与训练数据的规模偏差**：文本设置的 RL 数据仅 17K、VL 为 16K，benchmark 数量多但每题样本量有限（如 AIME 类只有数十题），单项分数波动可能被平均分掩盖；论文虽给出逐任务差异，但未报告逐任务置信区间。
- **"训练崩溃"作为停止准则的模糊性**：以"观察到奖励/熵突变、文本不连贯"为终止信号，带有主观性，且不同流水线的崩溃时点不同，可能使"最终性能"受停止时机影响，而非纯策略质量差异。

## 9. 对实践者的启示

- **不要把蒸馏当成一次性刷分手段**：若目标是提升下游 RL，应把 OPD checkpoint 纳入 RL 流程统一评估，而不是只看蒸馏后的准确率或 Pass@k。
- **"起点分数"与"起点潜力"是两回事**：一个即时提升很小甚至略降的 OPD checkpoint，仍可能是更好的 RL 起点；反之，SFT 的高起点可能伴随 RL 阶段的收益受限。
- **选择蒸馏目标要看轨迹来源**：若采用学生轨迹（OPD），FKL 在 RL 后更优；若采用教师轨迹（TFD），RKL 更优。不应脱离轨迹来源单独讨论 RKL/FKL 的优劣。
- **保留不确定性可能是关键信号**：SFT 会把分布压得过尖（文本 token 熵 0.242 vs OPD 1.048），虽然 top-1 一致率略高，但留给 RL 的探索空间更小。诊断时除准确率外，建议同时观察分布对齐与熵。
- **优先选择学生轨迹而非教师轨迹**：在相同蒸馏目标下，OPD 的 RL 后表现均优于 TFD，说明让学生在自身分布上接受教师指导，比在教师分布上模仿更有价值。

## 10. 总体评价

本文的核心贡献不在于提出新的蒸馏算法，而在于**重新定义了蒸馏的评价坐标系**：把"蒸馏质量"从静态的即时准确率，改写为动态的"作为 RL 起点的价值"。这一视角转换配合较严谨的控制变量设计（共享 RL 配置、正交分解轨迹来源与 KL 目标）与多维行为诊断（Pass@k、分布对齐、保留熵），使结论具有说服力和可复现的操作性。

其主要弱点在于**因果链条尚未闭合**：论文观察到 OPD 在"分布对齐更好 + 熵保留更多"的同时 RL 后表现更好，但未通过受控干预（例如人为调节熵或对齐度）验证二者的因果作用，且四路变体各仅一次运行、未估计种子方差。此外，算力与效率信息缺失，使"更好"无法转化为"更划算"。

尽管如此，作为一篇面向训练流程实践的工作，它给出了清晰且可立即采用的建议：**用 RL 后的表现来挑选蒸馏方案，并优先考虑学生轨迹上的前向 KL 蒸馏**。这对当前大量依赖 SFT→RL 流水线的推理模型训练具有直接的参考价值。
