## 摘要
同策略蒸馏（On-Policy Distillation, OPD）通过学习更强的教师模型与同策略学生模型之间的词元级差异来改进推理模型。然而，这种差异并不纯粹反映教师与学生之间的能力差距：它还包含源自教师自身的偏差，这些偏差因而混入所观测到的教师-学生差异中，并在训练过程中被标准 OPD 不加区分地学习。特权 OPD 会进一步加剧这一问题：特权信息会引发更大的教师侧似然偏移，从而促使学生学习更多教师自身的偏差。我们提出校准同策略蒸馏（Calibrated On-Policy Distillation, Cal-OPD），它通过正向和负向特权干预来估计教师自身偏差区域，并通过仅保留超出该区域的部分来校准原始的教师-学生差异。在数学推理基准上的实验表明，虽然仅保留原始教师-学生差异的约 52–65% 作为优化信号，Cal-OPD 在不同模型规模上始终优于标准 OPD 及其变体。

## Abstract
On-policy distillation (OPD) improves reasoning models by learning the token-level discrepancy between a stronger teacher and an on-policy student. However, this discrepancy does not purely reflect the capability gap between the teacher and the student: it also contains deviations arising from the teacher itself, which are consequently mixed into the observed teacher--student discrepancy and indiscriminately learned by standard OPD during training. This issue is further exacerbated by privileged OPD, where privileged information induces larger teacher-side likelihood shifts, thereby encouraging the student to learn more of the teacher's own deviation. We introduce \textbf{Calibrated On-Policy Distillation (Cal-OPD)}, which estimates the teacher's self-deviation region through positive and negative privileged interventions and calibrates the original teacher--student discrepancy by retaining only the component that lies beyond this region. Experiments on mathematical reasoning benchmarks show that, while retaining only about 52--65\% of the original teacher--student discrepancy as the optimization signal, Cal-OPD consistently outperforms standard OPD and its variants across model scales.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）在学生的 on-policy 轨迹上，用教师与学生的 token 级对数似然差（教师似然 − 学生似然）作为稠密监督信号，相比仅依赖结果级稀疏奖励的 RLVR 更直接高效，已被用于 Qwen3 等推理模型的后训练。
- **核心问题**：标准 OPD 隐含假设"教师对每个学生 token 的似然都是同等可靠的参考"，但这一假设不成立。论文指出，观测到的教师-学生差异不仅包含真实能力差距，还混入了**教师自身偏差（Teacher Self-Deviation, TSD）**——即固定问题、固定学生 rollout 与 token 位置，仅改变教师侧上下文时，教师似然发生的漂移。标准 OPD 会不加区分地学习这部分噪声。
- **特权 OPD 的放大效应**：当教师被额外条件于参考解、答案、提示等训练期信息时，教师分布偏移更大，TSD 被进一步放大，学生学到更多"上下文诱导的教师变化"，甚至导致性能退化。
- **整体含义**：有效的 OPD 关键不在于"学到更多师生差异"，而在于**辨别哪些差异真正值得学习**。论文将师生差异显式分解为"TSD 可解释部分"与"校准后的残差部分"，只蒸馏后者。

## 2. 方法论：Cal-OPD

### 2.1 核心思想

- 用**正/负特权干预**作为探针，估计教师在每个 token 上的"自偏差区域"（一个似然区间）；凡是落在此区间内的师生差异都被视为可能由 TSD 解释，置零或截断；只保留超出该区域的残差作为优化信号。
- 关键区别：特权信息**不直接蒸馏给学生**，而是用于**校准教师参考**。

### 2.2 关键技术细节

- **TSD 定义**：对固定问题 $x$、学生 rollout $y$ 与位置 $t$，引入仅作用于教师的上下文干预 $c$，令
  $$\Delta^T_t(c)=\log\pi_T(y_t\mid x,c,y_{<t})-\log\pi_T(y_t\mid x,y_{<t})$$
  由于 $x$、$y_{<t}$、$y_t$ 均固定，$\Delta^T_t(c)$ 纯粹刻画上下文引起的教师似然变化。
- **TSD 区域估计**：由干预集 $\mathcal{C}$ 得到向下/向上最大偏差
  $$\hat d^\downarrow_t=\max(0,-\min_{c}\Delta^T_t(c)),\quad \hat d^\uparrow_t=\max(0,\max_{c}\Delta^T_t(c))$$
  进而估计区间 $\hat{\mathcal{R}}^T_t=[\ell^T_t-\lambda\hat d^\downarrow_t,\ \ell^T_t+\lambda\hat d^\uparrow_t]=[L^T_t,U^T_t]$，其中 $\lambda\ge1$ 为松弛因子（有限干预只是近似）。
- **校准优势**：
  $$A^{\text{Cal}}_t=[L^T_t-\ell^S_t]_+-[\ell^S_t-U^T_t]_+,\quad [z]_+=\max(z,0)$$
  当学生似然 $\ell^S_t$ 落在估计区域内时 $A^{\text{Cal}}_t=0$；否则只保留超出最近边界的残差。分解关系为
  $$A^{\text{OPD}}_t=A^{\text{Cal}}_t+A^{\text{TSD}}_t$$
- **训练目标**：沿用标准 OPD 的目标（stop-gradient 的 token 级优势 × 学生 log 似然），仅把 $A^{\text{OPD}}_t$ 替换为 $A^{\text{Cal}}_t$。
- **干预设计（Table 1）**：四组正负配对干预——任务无关指令（inst）、评估反馈（eval）、答案级特权（ans）、解级特权（sol）。例如 eval 组：正干预称"验证器判定该解正确且严谨"，负干预称"判定该解错误且有缺陷"，模板相同仅内容相反。
- **实际配置**：主实验使用 $c^{\text{pos}}_{\text{eval}}$ 与 $c^{\text{neg}}_{\text{eval}}$，松弛因子 $\lambda=5$。

### 2.3 实证分析支撑（Section 2）

- **TSD 无需任务知识即出现**：$\tau=0.01$ 时，任务无关指令的正/负变体分别在 20.2%/25.8% 的 token 上产生显著 TSD，并集 29.8%，与评估反馈（29.1%）、答案级（29.4%）相当；解级特权扩展到 39.6%。
- **位置保持的不对称性**：较弱的干预下显著 TSD 的 token，约 98% 在解级特权下仍显著；反向保留率仅约 72–74%。说明更丰富的特权上下文主要**扩展**而非**替换** TSD 位置。
- **对语义与正确性不敏感**：答案正负反转仍达 88.7% 方向一致、74.7% 共享偏差比（SDR）；说明 TSD 不能可靠解读为任务知识信号。
- **集中于表层形式 token**：高 TSD 形式为 maybe、however、therefore、consider、alternatively 等（$\rho_\tau>89\%$），低 TSD 形式为数字与数学符号（$0,\sqrt{},\theta,\text{frac}$ 等，$\rho_\tau<9.3\%$），相差近一个数量级。
