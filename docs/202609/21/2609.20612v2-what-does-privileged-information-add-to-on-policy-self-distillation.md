## 摘要
同策略自蒸馏（OPSD）让语言模型从一个冻结的自身副本中学习，该副本能看到答案或解答过程。给教师提供这些额外信息似乎能让学生有更多可学，但除蒸馏本身之外，它究竟增加了多少？为分离这一贡献，我们构建了 AMPLE-Math，一个可复用的套件，包含 5,319 道数学题，每题有六种共享同一答案的推理视角，并将每种视角与匹配的无参考蒸馏进行比较。在启用思考的教师监督直接回答轨迹时，无参考蒸馏解释了 Qwen3-1.7B 在启用思考评估下的大部分提升，无论是在领域内还是在外部基准上。在 Qwen 中，额外参考收益的证据有限，对精炼解答最为明显；而在 SmolLM3-3B 的第 50 步，完整轨迹增加了两个百分点。这些收益取决于正在训练的学生。在同一检查点，将短的直接回答轨迹替换为长的启用思考轨迹，会使两个模型家族中的收益变为损失，而题目、参考和评估保持不变。教师画像以及 Qwen 中匹配的损失干预进一步表明，改变词元级监督可以使学生行为基本不变。总之，这些发现表明，OPSD 可以通过直接回答推理和启用思考推理共享的参数，改善对现有推理能力的利用。特权参考的价值在于它为此跨模式迁移增加了什么，而不在于它揭示了多少解答内容。

## Abstract
On-policy self-distillation (OPSD) lets a language model learn from a frozen copy of itself that sees an answer or a worked solution. Giving the teacher this extra information seems to offer the student more to learn, but how much does it add beyond distillation itself? To isolate that contribution, we construct AMPLE-Math, a reusable suite of 5,319 mathematical problems with six reasoning views that share the same answer, and compare each view with matched reference-free distillation. With a thinking-enabled teacher supervising direct-response rollouts, reference-free distillation accounts for much of Qwen3-1.7B's improvement under thinking-enabled evaluation, both in domain and on external benchmarks. Evidence for an additional reference benefit is modest in Qwen, strongest for a polished solution, whereas complete traces add two percentage points in SmolLM3-3B at step 50. These benefits depend on the student being trained. At the same checkpoint, replacing short direct-response rollouts with long thinking-enabled rollouts turns gains into losses in both families while the problems, references, and evaluation stay fixed. Teacher profiles and matched loss interventions in Qwen further show that changing token-level supervision can leave student behavior largely unchanged. Together, these findings suggest that OPSD can improve access to existing reasoning capabilities through parameters shared by direct-response and thinking-enabled inference. The value of a privileged reference is what it adds to this cross-mode transfer, not how much of the solution it reveals.

# 论文总结：特权信息为同策略自蒸馏增加了什么？

## 1. 核心问题与研究动机

- **背景**：同策略自蒸馏（On-policy Self-Distillation, OPSD）中，学生模型只看到问题并生成回复，而一个冻结的教师模型（学生自身的副本）可以看到额外的“特权信息”（Privileged Information, PI），如标准答案或完整解题过程，并据此对学生的前缀打分。这一范式源自 Vapnik 的“使用特权信息学习”（LUPI），无需额外的大模型教师。
- **核心问题**：给教师看答案或解题过程，**看起来**能让学生学到更多，但学生相比基座的提升中，究竟有多少来自“蒸馏本身”，有多少来自“特权参考”的额外贡献？**仅凭“比基座有提升”无法回答该问题**，因为无参考的跨模式蒸馏本身就能带来收益。
- **关键洞察**：在 OPSD 中教师是**对学生的前缀打分**而非提供待复制的解答，因此参考的价值取决于它能否帮助教师对学生的**具体尝试**给出有用反馈，而非泄露多少解答内容。
- **研究目标**：在保持答案信息固定的前提下，分离“蒸馏本身的收益”与“特权参考的额外增益”，并考察学生训练轨迹如何影响这一增益。

## 2. 方法论

### 2.1 核心思想

- 构建 **AMPLE-Math**（Answer-Matched Privileged Levels of Explanation）：同一道题配六种共享同一验证答案、但推理表示密度不同的视角，与“无参考蒸馏”做匹配对照。
- 同时设计**教师画像（teacher profiling）**与**匹配损失干预**，区分“监督信号变化”与“学生行为变化”。

### 2.2 关键技术细节

- **OPSD 损失**：对每个受监督位置 $t$，最小化教师到学生的前向 KL，每个词表项在求和前按 0.05 上截断（clip）：
  $$\mathcal{L}_v(\theta; m_S) = \mathbb{E}_{x, y \sim \pi_\theta} \left[ \frac{1}{|I(y)|} \sum_{t \in I(y)} D_{gKL}(p^T_{v,t} \| p^S_t) \right]$$
  教师分布与采样完成在求导时固定；无参考教师初始与学生相同，故零初始损失，**PI 提供了初始差异**。
- **六种视角（平均渲染 token 数）**：Answer Only (13) → Gist (76) → Key Points (284) → Clean Solution (526) → Summary (841) → Full Trace (4916)，所有视角末尾接同一规范答案段。
- **教师画像指标**：
  - **正确性对齐 $C_v$**：对混合结果问题，比较正确答案与错误答案上的平均教师-学生对数概率偏移差；正值表示正确答案获得更大偏移。
  - **纠错压力 $F_v$**：在采样到的“再考虑标记”（wait, but, check, verify 等）上的平均偏移，负值表示教师降低这些标记概率。
  - **时间 KL 分配**：全词表 KL 在保留跨度四个四分位中的占比。
- **训练配置**：LoRA（r=64, α=128），batch size 32，lr 5e-6，AdamW，100 步；**教师始终为开启思考的冻结骨干**；主配置为“直接回答训练 + 开启思考评估”（跨模式蒸馏）。

## 3. 实验设计

- **数据集/场景**：
  - **AMPLE-Math**：从 OpenThoughts-114k 构造 5,319 题 × 6 视角 = 31,914 条监督记录；冻结划分 train/dev/test = 1,536/192/384。
  - 按基座直接回答成功率分三档（0/4、1-2/4、3-4/4），每档 512/64/128。
  - **外部基准**：AIME 2024、AIME 2025、HMMT February 2025（每题 12 个开启思考样本）。
  - **模型家族**：Qwen3-1.7B、SmolLM3-3B。
- **Benchmark 与评价**：
  - 主评价：每题 4 个开启思考样本的 Avg@4（领域内）；外部 Avg@12。
  - 次评价：关闭思考的直接回答。
  - 保存前缀评分：对前 4K/8K/16K token 评分。
  - 统计：10,000 次问题簇 bootstrap 的 95% 区间；对六视角比较做 Holm 校正。
- **对比方法/条件**：
  - 无参考对照、错答案对照（Answer Only + 别题答案）。
  - 六种视角（Answer Only、Gist、Key Points、Clean Solution、Summary、Full Trace）。
  - 训练轨迹对比：直接回答 rollout vs. 开启思考 rollout。
  - 干预实验：其他题目参考替换、截断的 trace 开头、纠错标记损失排除/降权、提示模板替换、损失窗口（Early-1K / First-4K / Distributed-1K）。

## 6. 主要结论与发现

- **无参考蒸馏已解释大部分提升**：Qwen3-1.7B 中，无参考跨模式蒸馏在领域内外都带来显著提升；额外参考收益证据有限。
- **参考贡献因模型/阶段而异**：Qwen 中 Clean Solution 有微弱优势（+1.30 分，未通过 Holm 校正）；SmolLM3 中 Full Trace 在第 50 步超过无参考 2.0 分，但第 100 步所有配置都跌破基座。
- **更完整的解答不带来一致更大收益**：Answer Only 与 Full Trace 在第 100 步仅高出无参考约 0.6 分且区间含零。
- **训练轨迹可反转迁移**：固定题目、参考与评估，把直接回答 rollout 换成开启思考 rollout，两家族收益均变为损失（Qwen 9 个 gap 全负，8 个显著）。
- **参考内容仍非无关**：用别题的长度匹配视角替换真参考，准确率下降约 2 分（通过 Holm 校正）。
- **改变词元级监督未必改变学生行为**：放宽纠错标记损失几乎不改变标记使用；损失窗口的“增益”主要由停止时机解释（匹配检查点后差异 <1 分）。
- **核心解释**：OPSD 主要通过直接回答与开启思考推理**共享的参数**，改善对已有推理能力的“访问”；增益集中在基座已能部分解决的问题上。**特权参考的价值在于它对这种跨模式迁移增加了什么，而非揭示了多少解答。**

## 7. 优点

- **问题切分清晰**：把“蒸馏收益”与“参考额外贡献”明确分离，并指出“比基座好”不能回答该问题。
- **数据集设计巧妙**：AMPLE-Math 用答案匹配的六视角控制答案信息，可复用、有审计与冻结划分。
- **诊断与控制结合**：教师画像（正确性对齐、纠错压力、KL 分配）提出假设，匹配干预再验证，避免“画像即结论”。
- **统计严谨**：问题簇 bootstrap、Holm 校正、多种子、检查点匹配、保存前缀评分等多重稳健性检查。
- **反直觉且重要的发现**：训练轨迹可反转迁移；改变监督未必改变行为；损失窗口增益主要来自停止时机。
- **可复现性**：提供代码与数据集链接，附录详述构造、过滤、统计估计量。

## 8. 不足与局限

- **算力与规模有限**：仅约 1,000 H100 小时、LoRA 短程训练、100 步、1–4 种子；部分干预仅单种子，结论强度受限。
- **领域单一**：仅数学推理，未覆盖代码、通用对话、多语言等；结论能否外推未知。
- **模型家族有限**：仅 Qwen3-1.7B 与 SmolLM3-3B 两个小模型，未验证更大模型或不同架构。
- **额外参考收益证据偏弱**：多数对比未通过多重比较校正，Clean Solution 的优势“微弱且视角特异”。
- **画像指标的局限**：正确性对齐是固定响应上的局部重加权解释，**不等于**OPSD 参数更新；论文用反例（等对齐等 KL 却迁移相反）证明聚合诊断可能伴随不同参数更新。
- **纠错标记为词法匹配**：仅识别采样到的字面标记，不能覆盖所有语义纠错续写。
- **评估重叠风险**：AMPLE-Math 与已发布 OPSD 训练数据同源，52.6% 测试题重叠；仅在原始数据实现检查中规避。
- **数据集构造依赖 LLM 生成与审查**：生成与审查使用同一模型（Qwen3.6-35B），可能共享盲点。
- **实践含义有限**：论文只给出“参考设计与学生训练是联合问题”的方向，未给出可直接部署的最优参考构造方案。
