## 摘要
高效推理的一个核心目标是改进准确率-效率前沿。然而，同时提升推理准确率和推理效率可能颇具挑战，因为这两个目标可能偏好不同的推理行为。独立进行后训练的模型已经在准确率和效率上展现出各自的优势。我们提出 Lightning Weave，一个后训练框架，通过同策略蒸馏在单个学生模型中提取并组合这些独立习得的能力。每种获得的能力由从后训练前模型到所得专家模型的策略偏移来表示。Lightning Weave 在共享的学生 token 状态上组合对齐的对数比值偏移，并使用 Tilted-Target DOPD 将缓存信号转换为稳定的学习目标。每个锚点对对缓存轨迹评分一次，使得后续学生训练无需同时服务多个实时锚点模型。在数学和代码领域的多种学生模型与基准上，Lightning Weave 显著优于基础学生模型，并达到最先进的准确率-效率前沿。在 Qwen3.5-4B 上，它将 HMMT 2025 准确率从 59.2% 提升至 64.0%，同时响应 token 数减少 10.7%；将 LiveCodeBench v5 准确率从 41.7% 提升至 54.2%，同时响应 token 数减少 9.6%。调整锚点信号的相对强度可产生强经验性的准确率-效率帕累托前沿。这些结果确立了 Lightning Weave 作为通过能力组合实现高效推理的一条新的实用路径。代码发布于 https://github.com/jet-ai-projects/Lightning-Weave。

## Abstract
A core goal of efficient reasoning is to improve the accuracy-efficiency frontier. However, jointly improving reasoning accuracy and inference efficiency can be challenging, as the two objectives can favor different reasoning behaviors. Independently post-trained models already offer distinct strengths in accuracy and efficiency. We introduce Lightning Weave, a post-training framework that extracts and composes these independently learned capabilities in a single student through on-policy distillation. Each acquired capability is represented by the policy shift from the model before post-training to the resulting specialist. Lightning Weave combines aligned log-ratio shifts at shared student token states and uses Tilted-Target DOPD to convert the cached signals into a stable learning target. Each anchor pair scores the cached trajectories once, enabling subsequent student training without serving multiple live anchor models concurrently. Across diverse student models and benchmarks in mathematics and code, Lightning Weave substantially improves upon the base students and achieves a state-of-the-art accuracy-efficiency frontier. On Qwen3.5-4B, it raises HMMT 2025 accuracy from 59.2% to 64.0% with 10.7% fewer response tokens, and LiveCodeBench v5 accuracy from 41.7% to 54.2% with 9.6% fewer response tokens. Adjusting the relative strengths of the anchor signals yields a strong empirical accuracy-efficiency Pareto frontier. These results establish Lightning Weave as a new practical route to efficient reasoning through capability composition. Code is released at https://github.com/jet-ai-projects/Lightning-Weave.

## 1. 核心问题与整体含义

- **研究背景**：大型推理模型（Large Reasoning Models）在复杂任务上表现优异，但常生成冗长的推理链，带来高昂的推理成本。高效推理的核心目标是改进**准确率–效率前沿**（accuracy-efficiency frontier），即在给定推理预算下获得更强性能。
- **核心矛盾**：准确率与效率两个目标往往偏好**不同的推理行为**，直接联合优化容易顾此失彼——激进缩短推理链会削弱有用探索，从而损害准确率。
- **关键洞察**：独立后训练（post-training）的模型已分别在准确率（如 Klear）和效率（如 DECS）上具备明显优势。因此可以换一条互补路线：**提取这些专家已经学会的能力，并通过策略蒸馏组合进单一学生模型**。
- **中心问题**：能否把独立后训练学到的能力提取并组合，从而改善学生模型的准确率–效率前沿？
- **整体含义**：论文将"能力组合"确立为高效推理的一条实用新路径，而非从头联合优化竞争性目标。

## 2. 方法论：Lightning Weave

### 核心思想
- 将每种能力表示为**锚点对**（anchor pair）诱导的**策略偏移**（policy shift）：从后训练前的检查点到后训练后的专家模型之间的行为变化，而非直接匹配专家策略本身。
- 在**共享的学生 token 状态**上对齐多个偏移，并将它们组合成一个联合学习目标，解耦了"能力组合"与"参数兼容性"。

### 关键技术细节
- **锚点对策略偏移**：第 i 个锚点对 $(π^+_i, π^-_i)$ 在 token 状态 $s$ 与动作 $a$ 上定义
  $r_i(a|s) = \log π^+_i(a|s) - \log π^-_i(a|s)$，
  该对数比值隔离了后训练引入的行为变化。
- **Tilted-Target DOPD（解决离线失配问题）**：
  - *问题*：朴素离线方法直接复用 DOPD 的采样 token 目标优化缓存轨迹，当学生偏离行为策略 $π_b$ 后，缓存动作不再给出同策略 KL 估计，正则项无法抵消固定偏移更新，**即使学生到达目标策略仍存在非零梯度**。
  - *方案*：将每个缓存偏移"倾斜"为显式目标分布
    $q(a|s) = \frac{π_b(a|s)\exp(r_∆(a|s)/α)}{Z(s)}$，
    再最小化学生到该目标的 KL：$L_{TT}(θ)=α\,\mathbb{E}_{s∼d_{π_b}}[D_{KL}(π_θ(·|s)\|q(·|s))]$。
  - *性质*：该目标与全分布、KL 正则化的 DOPD 目标在缓存状态上等价；在 $π_θ=q$ 时损失与梯度**同时消失**，具有明确的不动点，训练自校正。
- **多锚点组合（Lightning Weave）**：
  - 先加权求和对齐的 log-ratio：$r_w(a|s)=\sum_i w_i r_i(a|s)$，权重非负且 $\sum_i w_i=1$。
  - 再对共享行为策略做指数倾斜构造联合目标：
    $q_w(a|s) = \frac{π_b(a|s)}{Z_w(s)}\exp(r_w(a|s)/α)$。
  - 训练损失 $L_{joint}(θ;w)=α\,\mathbb{E}_{s∼d_{π_b}}[D_{KL}(π_θ\|q_w)]$。
  - 组合发生在**目标构造之前**，所有能力源对每个学生决策联合监督：支持同一动作的偏移相互增强，冲突的偏移通过加权比值局部协调。当 $K=1, w_1=1$ 时退化为单锚点 Tilted-Target DOPD。
- **工程实现**：每个锚点对只需对缓存轨迹评分一次；缓存后学生训练只需学生模型与缓存分数，**无需同时服务多个实时锚点模型**。跨 tokenizer 场景通过字节级字符串对齐实现（有限候选 16 个 + 一个"其他"结果，用平方对数残差代理损失）。

## 3. 实验设计

- **学生模型（5 个，跨规模与家族）**：Qwen3-1.7B、Qwen3-4B、Qwen3-4B-Thinking-2507、Qwen3.5-4B、OLMo-3-7B-Think。
- **锚点对（3 组）**：
  - 准确率导向：Qwen3-8B-Base → Klear-Reasoner-8B（Klear）；MiMo-7B-Base → MiMo-7B-RL-0530（MiMo-RL）
  - 效率导向：DeepSeek-R1-Distill-Qwen-1.5B → DECS-1.5B（DECS）
- **训练数据**：数学取 Skywork-OR1-RL-Data 的 3,200 个 prompt（转 DAPO 格式）；代码取 KlearReasoner-CodeSub-15K 的 3,200 个 prompt（长度过滤 + 去重，且与 LCB v6 无重叠）。每个学生每 prompt 生成 4 条响应，最大 2,048 token，共 12,800 条轨迹。
- **Benchmark（5 个）**：
  - 数学：AIME 2024、AIME 2025、HMMT February 2025（各 30 题，数学采样 64 次，Avg@64）
  - 代码：LiveCodeBench v5（279 题）、v6（131 题）（采样 4 次，Avg@4）
- **评价指标**：准确率（Acc.）、平均响应 token 数（#Tok.）、以及 Accuracy–Efficiency Score（AES，相对各自 base 模型按 benchmark 计算后等权平均）。
- **对比方法**：
  - 基础模型、单锚点策略（Klear-only、DECS-only、MiMo-RL）
  - 外部高效推理基线：SimpleSD、Qwen3-4B-Thinking-2507-Art、PromptCoT 2.0、模型插值（MI）
  - 消融对比：Online DOPD、Naive Offline、Data Mixture、Sequential Composition（两种顺序）

## 4. 资源与算力

- **硬件**：所有 GPU 阶段使用**单节点 8×H100**，bfloat16 精度。Qwen 系列用 Megatron-Core 训练，OLMo 用 PyTorch FSDP。

## 6. 主要结论与发现

- **一致改善准确率–效率权衡**：在全部 5 个学生模型上，Lightning Weave 均取得最高 AES，优于 base 与两种单锚点策略。
  - Qwen3-4B：平均准确率 +4.02 分，响应 token 减少 19.7%
  - Qwen3-4B-Thinking-2507：平均准确率 +4.5 分，token 减少 9.0%
  - Qwen3.5-4B：平均准确率 +9.70 分，token 减少 5.3%
  - OLMo-3-7B-Think：平均准确率 +3.74 分，token 减少 12.9%
- **具体标杆成绩**：Qwen3.5-4B 上 HMMT 2025 从 59.2% → 64.0%（token 减少 10.7%）；LiveCodeBench v5 从 41.7% → 54.2%（token 减少 9.6%）。
- **可控的 Pareto 前沿**：调整 Klear–DECS 相对权重可得到一族学生策略，非支配点经验性地勾勒出准确率–效率 Pareto 前沿，且在不同 token 预算下均优于单锚点策略（预算越紧增益越大）。
- **多锚点可扩展**：三锚点组合（Klear+DECS+MiMo-RL）取得最高 AES（0.42），加入某能力锚点会把工作点推向对应能力方向。
- **Tilted-Target 有效性**：与 Online DOPD 表现相当，但避免了同时服务 2K 个锚点模型；相比 Naive Offline 在准确率上提升 1.51–3.85 分，双锚点下 token 减少 17.6%。
- **优于组合替代方案**：相比 Data Mixture 全 benchmark 准确率更高且 token 减少 3.8–8.7%；Sequential Composition 强烈依赖顺序，而 Lightning Weave 无顺序偏置。

## 7. 优点

- **方法创新性**：
  - 用"策略偏移"而非"专家策略本身"表示能力，**解耦能力组合与参数兼容性**，可组合参数结构不同、tokenizer 不同的专家。
  - Tilted-Target DOPD 为离线缓存信号提供**显式、稳定、有不动点**的学习目标，从理论上修正了朴素离线代理的失配问题（附录给出形式化证明与反例）。
  - 在共享 token 状态上先组合偏移、再构造联合目标，使所有能力源对每个决策联合监督，优于样本混合与顺序训练。
- **工程效率**：锚点对只评分一次，训练阶段仅需学生模型，大幅降低显存与并发服务压力；多次权重配置可复用缓存，边际成本低（分摊降低 4.58×）。
- **可控性**：通过权重即可在准确率与效率之间连续调节，得到可用的 Pareto 前沿。
- **实验广度与理论深度兼具**：跨 5 个学生模型、5 个 benchmark、3 组锚点、多种基线与消融，并配有完整的理论分析（命题、推论、反例）和定性案例。

## 8. 不足与局限

- **模型规模受限**：受算力限制，实验集中在 <10B 参数模型，未验证更大规模下收益是否持续。
- **依赖配对锚点**：方法要求同时拥有具备目标能力的后训练模型及其对应前锚点，**匹配锚点对并不总是可得**（尤其对新任务）。
- **效率增益有限**：虽然改善了准确率–效率平衡，但其 token 节省幅度**仍小于专为高效推理优化的方法**（作者自述）。
- **离线近似的固有限制**：
  - 缓存状态分布为离线近似，当学生大幅偏离行为策略后，缓存状态未必覆盖新访问的状态。
  - 有限候选（top-16 + 其他）与跨 tokenizer 对齐均为对全分布设置的实用近似，理论上界仅适用于有限对齐分数、完整动作分布与固定缓存状态分布。
  - 理论保证不蕴含任务准确率或响应长度的实际改善——后者是所选锚点偏移的经验属性。
- **统计严谨性**：每个配置仅训练一次、使用固定种子，未报告多次训练种子的方差或显著性检验；重复采样仅反映解码变异性。
- **超参数敏感性未充分探索**：α 固定为 2.0，未系统研究报告对 α、权重归一化方式、候选规模等的敏感性。
- **应用限制**：数学与代码之外的领域（如
