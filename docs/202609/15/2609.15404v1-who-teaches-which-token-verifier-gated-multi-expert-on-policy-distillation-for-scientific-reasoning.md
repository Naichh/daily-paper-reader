## 摘要
多教师同策略蒸馏（OPD）正成为将专家能力整合到单个模型中的标准方法：先用强化学习（RL）训练专家，再在学生模型自身的 rollout 上将其蒸馏给学生。现有方案在序列级别分配监督——每个提示只交给一个领域教师，且每个 token 获得相同权重——这隐含地假设一个教师在整条回答中均匀有用。但我们发现，有用的教师信号在推理轨迹上是稀疏且异质的，这引出一个更细粒度的问题：谁应该教哪个 token？验证器门控多专家同策略蒸馏（VG-OPD）通过验证来回答该问题：一个专家在特定答案标准上的反事实增益赋予该专家教学资格，其与学生的分歧定位监督位置，标准重要性决定其权重；门控 KL 以加性 token 级优势的形式进入 GRPO。在科学推理任务上以经 RL 训练的能力专家进行实例化后，VG-OPD 在面向 4B 和 8B 学生的七个基准上取得最佳总体性能，在两个规模上均在其中五项基准上排名第一，且在知识密集型科学推理任务上增益最大。进一步分析表明，增益来自对已验证监督的定位，而非来自增加教师或蒸馏损失：将同样的监督预算放错位置是破坏性最大的单项改动，而不加区分的蒸馏会使 RL 低于其自身下限，门控蒸馏则将其提升。

## Abstract
Multi-teacher on-policy distillation (OPD) is becoming the standard way to integrate specialist capabilities into one model: train experts with RL, then distill them into the student on its own rollouts. Existing recipes assign supervision at the sequence level - each prompt goes to one domain teacher and every token receives the same weight - which implicitly assumes that a teacher is uniformly useful across a response. We find instead that useful teacher signal is sparse and heterogeneous along a reasoning trajectory, which raises a finer question: who should teach which token? Verifier-Gated Multi-Expert On-Policy Distillation (VG-OPD) answers it by verification: the counterfactual gain of an expert on a specific answer criterion licenses that expert to teach, its disagreement with the student localizes the supervision, and criterion importance sets its weight; the gated KL enters GRPO as an additive token-level advantage. Instantiated for scientific reasoning with RL-trained capability experts, VG-OPD attains the best overall performance on seven benchmarks for 4B and 8B students, ranking first on five at both scales, with the largest gains on knowledge-intensive scientific reasoning tasks. Further analysis shows that the gains come from localizing verified supervision rather than from adding teachers or distillation loss: misplacing the same supervision budget is the single most damaging change, and indiscriminate distillation drags RL below its own floor where gated distillation lifts it.

# 论文总结：Who Teaches Which Token? Verifier-Gated Multi-Expert On-Policy Distillation for Scientific Reasoning

## 1. 核心问题与整体含义

- **背景**：多教师同策略蒸馏（Multi-teacher OPD）已成为将多个专家能力整合进单一模型的标准范式——先用 RL 训练各领域专家，再在学生模型自身的 rollout 上将其蒸馏给学生。
- **现有做法的隐含假设**：以 MOPD 为代表的方法在**序列级**分配监督——按 prompt 的领域标签指定唯一教师，并对整条回答的所有 token 施加**均匀权重**，即默认“一个教师对整条回答同等有用”。
- **论文的核心发现**：有用的教师信号在推理轨迹上是**稀疏且异质**的。同一专家可能修正学生的计算，却同时给出错误的反应机理；同一标准下不同专家的优劣也不同。
- **由此提出的更细粒度问题**：**谁应该教哪个 token？（Who teaches which token?）** 即需要同时决定“哪位专家有资格教”与“该专家的监督应施加在哪些 token 上”。
- **整体含义**：论文主张多教师蒸馏的关键不在于“用哪个教师”，而在于“谁教哪个 token”，并通过验证器在**标准（criterion）级**建立教学资格，将监督精确定位到专家与学生分歧的 token 上。

## 2. 方法论

### 2.1 核心思想

- 以**共享的标准级评估**决定教学资格：参考解分解为若干 criterion，每个 criterion 配一个验证器；用同一验证器为专家答案与学生答案打分，识别专家在当前问题特定要求上的**反事实增益**。
- 三条原则对应三个子问题：
  - **Who（谁教）**：仅当专家在目标 criterion 上优于学生时，才获得教学许可。
  - **Where（教哪）**：仅在该专家与学生**分歧**的 token 上施加监督。
  - **How much（教多重）**：由 criterion 在 rubric 中的重要性决定权重。
- 门控 KL 以**加性 token 级优势**的形式并入 GRPO 更新。

### 2.2 关键技术细节

- **能力轴与候选集**：criterion 与专家各自携带能力轴（定量 quantitative、符号 symbolic、机理 mechanistic、证据 evidence），记为 $a(j)$、$a(E_k)$；对失败 criterion $j$，候选专家集 $K(j)=\{k: a(E_k)=a(j)\}$。
- **能力探针（probe）**：每个专家对原问题生成一次 greedy 答案 $y_k=E_k(x)$，按 prompt 缓存，组内所有 rollout 复用。
- **反事实增益与门控（Who）**：
  - $\Delta'_{j,k} = V_j(x, y_k) - V_j(x, y)$；
  - 当 $\Delta'_{j,k} > \delta$（$\delta=0$）时许可，$g_{j,k}=1$；
  - 由于失败 criterion 上 $V_j(x,y)=0$，一次缓存的 $V_j(x,y_k)$ 即可服务组内全部 rollout。
- **路由（Who，多专家池时）**：
  - $q(k\mid x,y,c_j) \propto g_{j,k}\exp(\Delta'_{j,k}/\tau)$，$\tau=0.5$；
  - 取 $k^*(j)=\arg\max_k q$；每轴仅一专家时退化为门控。
- **分歧定位（Where）**：
  - 取教师对“学生实际 token”的 log 概率 $\ell_t^{(k)}$ 的 bottom-$\eta$ 分位（$\eta=0.10$）作为初始 mask；
  - 再向左右各膨胀 1 个 token；
  - mask 是 rank-based，覆盖率约 2–17%；且与教师前向**共用同一次计算**，不增加调用。
- **验证增益权重（How much）**：
  - $s_{j,k} = q(k\mid x,y,c_j)\cdot \bar\omega_j$，其中 $\bar\omega_j=(\min(\omega_j,5)/5)^{1/2}$；
  - token 级权重取所有许可教师中的最大值，每个 token 至多分配**一个**教师，重叠 mask 不产生冲突梯度；
  - 无 mask 覆盖的 token 权重为 0。
- **目标函数**：
  - 教师项 $\hat k_t=\min(e^{\Delta_t}-\Delta_t-1,\,c)$，$c=10$，$\Delta_t=\log\pi_{E_{k_t}}-\log\pi_\theta$，期望为逐位置反向 KL；
  - $A^{KD}_{i,t}=-w_{i,t}\hat k_{i,t}$（梯度分离）；
  - 总损失 $L(\theta)=L_{PG}(A^{task};\theta)+\lambda L_{PG}(A^{KD};\theta)$，$\lambda=0.25$。
- **三项诚实性排除**：pitfall criterion（$\omega_j<0$）不参与门控；验证器弃权不参与门控；任务奖励已达阈值（≥0.75）的 rollout 不接收教师项。
- **稳定性设计**：$A^{KD}_t\le 0$ 恒成立（Proposition 1），单独使用会持续压制概率质量、加速熵坍缩，因此必须与任务奖励流联合训练，且稀疏门控把压力限制在选定 token 上。
- **算法流程（Alg. 1）**：采样 G 条 rollout → 逐 criterion 验证打分 → 计算组归一化任务优势 → 生成并缓存专家探针 → 逐失败 criterion 计算 $\Delta'$、门控、路由 → 对每位许可教师做一次前向并生成 mask → 合成 $w_t, k_t$ → 构造 $A^{KD}$ → 以 $L_{PG}(A^{task})+\lambda L_{PG}(A^{KD})$ 更新。

## 3. 实验设计

- **学生与专家底座**：Qwen3-4B 与 Qwen3-8B，非 thinking 模式。
- **专家构造**：四个能力轴各一个 LoRA 适配器（rank 64），在共享底座上以标准 GRPO 在各自轴的数据切片上训练。
- **训练数据**：来自 Dr.SCI 集合（WebInstruct-Verified、NaturalReasoning、MegaScience、RaR-Science 的混合），criteria bank 通过“derive-then-verify”与“rubric 导入”两条路径构建。
- **评估基准（7 个公开基准，3 组）**：
  - 科学推理：GPQA-Diamond（n=198）、RaR-Science（n=500）、SciBench（n=580）；
  - 领域科学：ChemBench（n=1,391）、RaR-Med（n=150）；
  - 通用推理：MMLU-Pro（固定子集 n=2,000）、MATH500（n=500）。
- **对比方法**：
  - Vanilla（起始 checkpoint）；
  - GRPO + rubric rewards（RL 下限）；
  - OPSD（以 rubric 为特权上下文的自蒸馏）；
  - MOPD（领域标签路由 + 均匀 token 权重）；
  - dGRPO-style fusion（稠密 token 级融合）；
  - CriPO（按 criterion 分解 + 自蒸馏 + token 定位）。
- **公平性协议**：所有蒸馏臂共享学生、数据混合、rollout 与步数预算、优化器设置与 $\lambda$，仅教师信号构造方式不同；教师池相同（VG-OPD 自己的四个专家）。
- **解码与评分**：统一本地 harness，greedy 解码、非 thinking、最多 4,096 新 token，rubric 类串行评判。

## 6. 主要结论与发现

- **性能结论**：VG-OPD 在 4B 与 8B 两个规模上均取得七个基准的最佳总体表现，5 项第一；MMLU-Pro 与 MATH500 上以半分之差居第二。
- **增益分布**：增益集中在知识密集型科学任务。相对 rubric-GRPO，4B 在科学推理 +2.0、领域科学 +3.3、通用推理 +0.2；8B 为 +1.7、+1.9、±0.3。
- **对比结论**：纯蒸馏（OPSD、MOPD）在组平均上最多只能与 rubric-GRPO 持平；稠密融合（dGRPO）在 4B 低于 RL 下限半分以内，在 8B 低至 1.6 分；只有 VG-OPD 在三组上
