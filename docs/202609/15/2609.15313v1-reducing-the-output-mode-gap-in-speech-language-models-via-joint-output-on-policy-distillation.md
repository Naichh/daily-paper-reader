## 摘要
自回归生成交错的文本与声学标记是语音大语言模型生成口语回复的一种常见方法。尽管这种设计能够借助显式文本引导实现流式生成，但生成的声学标记会成为后续文本预测上下文的一部分。在相同语音输入下，我们观察到，语音到文本再到语音（S2TS）模式中生成的内部文本的答案准确率显著低于语音到文本（S2T）响应。我们将这一差异称为输出模式差距（OMG）。为缩小 OMG，我们提出联合输出同策略蒸馏（JO-OPD），它利用学生模型生成的 S2TS 轨迹，将模型更强的 S2T 策略蒸馏到联合生成中。在每个文本位置，S2T 教师模型基于学生模型先前输出的纯文本投影提供软目标，而学生模型则根据对应的完整交错历史进行预测。一个保持目标进一步对原生非文本预测进行正则化。在 Step-Audio-2-mini 和 Baichuan-Audio-Instruct 上的实验揭示了两种交错生成架构中均存在 OMG。在 Step-Audio-2-mini 上，JO-OPD 将 Spoken-MQA 上的 OMG 从 42.87 个百分点降低到 16.26 个百分点，将语音渲染的 GSM8K 上的 OMG 从 29.72 个百分点降低到 13.04 个百分点，而 S2T 准确率几乎不变，且降幅显著大于匹配的 SFT 基线。基于 ASR 的评估进一步表明，在 Spoken-MQA 上，口语答案准确率提高了 7.49 个百分点。

## Abstract
Autoregressive generation of interleaved text and acoustic tokens is a common approach to spoken-response generation in speech large language models. Although this design enables streaming generation with explicit textual guidance, generated acoustic tokens become part of the context for subsequent text predictions. Given identical speech inputs, we observe markedly lower answer accuracy for the internal text generated in speech-to-text-and-speech (S2TS) mode than for speech-to-text (S2T) responses. We term this discrepancy the \emph{output-mode gap} (OMG). To reduce OMG, we propose \emph{Joint-Output On-Policy Distillation} (JO-OPD), which distills the model's stronger S2T policy into joint generation using student-generated S2TS trajectories. At each text position, the S2T teacher provides soft targets from a text-only projection of the student's preceding outputs, while the student predicts from the corresponding full interleaved history. A preservation objective further regularizes native non-text predictions. Experiments on Step-Audio-2-mini and Baichuan-Audio-Instruct reveal OMG across two interleaved generation architectures. On Step-Audio-2-mini, JO-OPD reduces OMG from 42.87 to 16.26 percentage points on Spoken-MQA and from 29.72 to 13.04 points on speech-rendered GSM8K, with little change in S2T accuracy and substantially larger reductions than matched SFT baselines. ASR-based evaluation further shows a 7.49-point improvement in spoken-answer accuracy on Spoken-MQA.

## 1. 核心问题与整体含义

- **研究背景**：语音大语言模型（SLLM）既可做语音到文本（S2T）理解，也可做语音到文本再到语音（S2TS）的联合生成。后者通常以交错方式自回归生成文本 token 与声学 token，从而支持流式语音回复并保留文本引导。
- **核心问题**：在交错生成中，已生成的声学 token 会进入后续文本预测的上下文，可能干扰文本生成。论文发现：在相同语音输入、相同模型和相同评分规则下，S2TS 模式内部文本的答案准确率显著低于 S2T 模式。
- **概念定义**：作者将这一差异称为**输出模式差距（Output-Mode Gap, OMG）**，定义为  
  \[
  \Delta_{\text{OMG}} = A_{\text{S2T}} - A_{\text{S2TS(T)}}
  \]
  其中 S2TS(T) 表示从联合轨迹中投影出的内部文本，S2TS(S) 表示重建或转写后的口语答案。
- **整体含义**：该问题属于输出侧的模态差距。与已有输入侧语音-文本能力差距研究不同，本文固定语音输入和模型，只考察“是否同时生成语音”对文本答案准确率的影响，并尝试用模型自身更强的 S2T 策略来缩小该差距。

## 2. 方法论：JO-OPD

### 2.1 核心思想

- 提出**联合输出同策略蒸馏（Joint-Output On-Policy Distillation, JO-OPD）**。
- 教师模型不是外部大模型，而是同一基座模型在 **S2T 模式**下的策略，因为 S2T 准确率通常更高。
- 学生模型在 **S2TS 模式**下生成联合轨迹，JO-OPD 在这些学生自生成轨迹的文本位置上，用教师 S2T 预测进行监督。
- 同时加入**非文本保持目标**，约束声学 token 和控制 token 的预测，避免蒸馏破坏原有语音生成能力。

### 2.2 关键技术细节

- **历史投影**：  
  - 学生上下文：  
    \[
    h_i^{\text{stu}} = (x_S, H(z_{<i}), \text{S2TS})
    \]
    即语音输入 + 完整交错历史，包括文本、声学和控制 token。  
  - 教师上下文：  
    \[
    h_i^{\text{tea}} = (x_S, P_T(z_{<i}), \text{S2T})
    \]
    即同一语音输入 + 学生前序输出的**纯文本投影**，去除声学和控制 token。  
  - 这样，教师看到的是学生“应该生成什么文本”，学生则同时受到自身声学历史影响。

- **文本蒸馏**：  
  - 在学生每个文本预测位置，比较教师分布 \(q_i\) 与学生分布 \(p_i\)。  
  - 学生分布归一化在完整文本词表上。  
  - **JO-OPD-Soft**：保留教师 top-\(k\) 文本 token 并重新归一化，作为软目标。  
  - **JO-OPD-Hard**：直接使用教师最高概率文本 token 作为 one-hot 目标。  
  - 损失：  
    \[
    \mathcal{L}_T = \mathbb{E}_{z,i}[\text{CE}(q_i, p_i)]
    \]

- **非文本保持**：  
  - 对声学输出和控制 token 的预测，用固定基座模型在 S2TS 模式下的分布作为参考。  
  - Step-Audio 2：在共享输出头的非文本位置使用 top-\(k\) 参考目标的交叉熵。  
  - Baichuan-Audio：分别对 controller 和 codec 分布使用参考到学生的 KL 散度；codec 损失梯度可经过冻结语音头回传到共享语言模型。  
  - 总损失：  
    \[
    \mathcal{L} = \mathcal{L}_T + \mathcal{L}_{\text{pres}}
    \]

- **训练流程**：  
  - 学生从基座模型初始化。  
  - 采样学生 S2TS 轨迹。  
  - 在轨迹的文本位置用教师 S2T 策略蒸馏。  
  - 在非文本位置用参考 S2TS 策略保持。  
  - 教师和参考模型在训练中保持冻结。
