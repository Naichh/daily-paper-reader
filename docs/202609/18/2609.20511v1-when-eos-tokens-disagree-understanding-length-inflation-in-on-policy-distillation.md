## 摘要
我们研究了同策略蒸馏（OPD）中的长度膨胀现象，其中学生模型的回复可能变得过长，甚至耗尽生成预算。我们将基础学生模型与后训练教师模型之间的终止词元不匹配识别为这一行为的重要来源。在Qwen3、Llama和Gemma中，即使二者声明的停止集合相同，两个模型也可能将停止概率置于不同的EOS词元上。这种不匹配会抑制学生模型偏好的终止动作，同时又无法可靠地传递教师模型偏好的替代动作。我们表明，仅对齐解码停止集合是不够的；而将功能等价的EOS词元视为共享的语义停止动作，可显著缓解所有三个模型家族中由不匹配引发的长度膨胀。为进一步理解终止行为在训练过程中如何演变，我们研究了不同K2-Horizon训练阶段中的OPD。这种分阶段分析表明，终止偏好在训练期间可能发生显著变化，同时也揭示了OPD运行后期出现的一种独特长度膨胀，且该现象在对齐终止行为之后仍然存在。总之，这些结果将终止不匹配识别为OPD长度动态的一个重要但非穷尽的原因。我们发布了包含所提出的终止处理修正的实现。

## Abstract
We study length inflation in on-policy distillation (OPD), where student responses can become excessively long and even exhaust the generation budget. We identify \emph{termination-token mismatch} between base students and post-trained teachers as an important source of this behavior. Across Qwen3, Llama, and Gemma, the two models can place their stopping probability on different EOS tokens, even when their declared stopping sets are identical. This mismatch can suppress the student's preferred termination action without reliably transferring the teacher-preferred alternative. We show that aligning the decoding stopping set alone is insufficient, while treating functionally equivalent EOS tokens as a shared semantic stopping action substantially mitigates mismatch-induced length inflation across all three model families. To further understand how termination behavior evolves over training, we study OPD across different K2-Horizon training stages. This stage-wise analysis shows that termination preferences can shift substantially during training, while also revealing a distinct length inflation late in the OPD run that persists beyond termination alignment. Together, these results identify termination mismatch as an important, but not exhaustive, source of OPD length dynamics. We release an implementation incorporating the proposed termination-handling corrections.

# 《当EOS词元不一致时：理解同策略蒸馏中的长度膨胀》论文总结

## 1. 核心问题与研究动机

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）让学生模型在自己的 rollout 上接受教师模型的密集 token 级监督，是近期将强后训练能力迁移到小模型的重要框架。
- **核心问题**：OPD 训练中学生回复会**渐进性变长**（length inflation），严重时大量 rollout 耗尽生成预算（截断），并伴随重复、自纠错死循环等生成病理。作者观察到学生往往很早就已给出正确答案，却**无法终止生成**。
- **本文切入点**：作者将**基座学生与后训练教师之间的终止词元不匹配（termination-token mismatch）**识别为这一现象的重要直接原因——两个模型可能用**不同的 EOS token 表达同一个“停止”语义决策**，即使它们声明的解码停止集合完全相同。
- **机制解释**：在采样 token 的 OPD 中，教师只对**学生已采样出的 token** 打分。若学生采样了 `<|endoftext|>` 而教师偏好 `<|im_end|>`，则学生原生 EOS 会持续收到负的蒸馏信号被压制；而教师偏好的 EOS 因学生采样概率极低（Qwen3 中约 10⁻¹¹）几乎得不到正向监督。结果是“学生想停停不下来，教师的停法又学不到”，终止概率崩塌、长度膨胀。

## 2. 方法论

### 2.1 问题形式化
- 采样 token OPD 在每步的更新系数为  
  `A_t = log π_E(y_t | s_t) − log π_θ(y_t | s_t)`，`g_t = A_t ∇_θ log π_θ(y_t | s_t)`。
- 记 `E_EOS` 为某对模型在 rollout 协议下**功能等价的终止 token 集合**，`e* ∈ E_EOS` 为基座学生原生支持的规范 EOS。
- 关键洞察：**解码器视为等价的停止事件，在目标函数中仍被当作不同动作监督**。

### 2.2 四种终止处理修正（核心贡献）
| 修正 | 作用层面 | 做法 | 效果 |
|---|---|---|---|
| **Fix 1：共享集合解码** | 仅解码接口 | rollout 时把两个 EOS 都注册为停止符 | **无效**，轨迹与 vanilla OPD 几乎一致 |
| **Fix 2：教师侧 EOS 映射** | 教师分布 | 把教师在所有 `E_EOS` 上的概率质量映射到 `e*` | 有效，但需指定规范 token |
| **Fix 3：语义 EOS 类别** | 语义动作 | 对 π_θ 与 π_E 均定义 `π̄(stop|s)=Σ_{e∈E_EOS} π(e|s)`，把 EOS 样本替换为统一 `stop` 动作后套用标准 OPD | **有效且通用**，无需指定规范 token |
| **Fix 4：规范单 EOS 动作空间** | 学生动作空间 | 将教师 EOS 质量映射到 `e*`，并从学生采样分布中移除其他 EOS 后重归一化 | 有效，但约束更强 |

### 2.3 推荐方案
- **Fix 2** 用于已知的 Qwen3 显式不匹配，最简单；
- **Fix 3（语义 EOS 聚合）** 作为跨模型家族的**默认方案**，因为它不要求两模型学习相同的表层 token，适用于 Gemma 3 这类“声明集合相同但学习偏好不同”的更一般情形。

### 2.4 理论补充（附录 C）
- 提出 Proposition 1：局部采样 token OPD 对停止 logit 施加的上行压力**弱于**轨迹一致的 reverse-KL 更新，差值 `Δ*_e − Δ^OPD_e = p_θ(s)·C_θ(s) ≥ 0`，其中 `C_θ(s)` 为续写动作的后续 KL 期望。这为修正后仍存在的**早期长度漂移**提供了可能解释。

## 6. 主要结论与发现

1. **终止词元不匹配是 OPD 长度膨胀的一个重要、可诊断的直接原因**，横跨 Qwen3、Llama、Gemma，且可在声明停止集合相同时出现（Gemma 3 的关键反例）。
2. **仅对齐解码停止集合（Fix 1）不够**；只有在**概率层面**对齐终止语义（Fix 2/3/4）才能显著缓解长度膨胀，证明问题出在训练目标而非解码配置。
3. **语义 EOS 聚合（Fix 3）是跨家族通用解**：不强制学生复现教师偏好的表层 token，而是监督其**总终止概率**，在三个家族上都恢复了终止行为（Qwen3、Gemma 3 接近教师参考长度，Llama 3.2 仍有较大残余差距）。
4. **终止偏好随训练阶段显著漂移**：K2-Horizon 中，偏好从 pretrain 的 `<|ifm|endoftext|>` 转向 final 的 `<|ifm|im_end|>`，大部分迁移发生在 midtraining 阶段；当学生已对该 token 有非可忽略采样概率时，vanilla OPD 可以完成表层 token 迁移。
5. **存在超出 EOS 不匹配的残余长度动态**：K2-Horizon Pretrain-to-Final 在修正后仍出现后期再膨胀（Phase 3），终止概率再次趋零，说明仍有其他机制（作者推测与局部 OPD 忽略未来学生-教师失配有关）在起作用。
6. **模板与评测协议影响显著**：训练模板会持久影响响应长度（DAPO 训练产生更短回复），评估格式大幅影响测得精度（TTRL 评测通常更高），而**长度与精度并不必然同向变化**——长度膨胀不必然意味着推理能力下降。

## 7. 优点

- **问题定位精准**：把一个常被归因于“算法层”现象的长度膨胀，追溯到**实现层的特殊 token 语义错配**，且给出了可操作的诊断方法（对比末位 EOS 概率）。
- **消融设计有说服力**：通过 Fix 1 的失败与 Fix 2/3/4 的成功，从正反两面证明“解码对齐 ≠ 信号对齐”，逻辑闭环清晰。
- **跨家族泛化验证**：不只停留在 Qwen3，而用 Gemma 3 的“同声明集合、异学习偏好”案例把现象推广到更一般情形。
- **分阶段分析与控制实验**：利用 K2-Horizon 的多阶段 checkpoint 揭示偏好漂移，并用后期阶段做“修正非干扰”对照，增强结论可信度。
- **理论补充**：Proposition 1 从轨迹级 reverse-KL 视角解释了局部 OPD 对停止信号的系统性偏差。
- **诚实与可复现**：明确区分哪些现象由 EOS 不匹配解释、哪些不能；公开实现、模板与 grader 细节。

## 8. 不足与局限

- **解释力不完整**：EOS 不匹配被定位为“重要但非穷尽”的原因；K2-Horizon 后期再膨胀、跨家族恢复动态差异等残余现象仍未解释，留给未来工作。
- **任务范围窄**：仅限单轮数学推理。多轮对话/agentic 场景中，特殊 token 可能区分消息结束、轮次结束、文档终止、工具交接等**功能上不等价**的事件，简单聚合语义可能破坏交互控制流。
- **模型配对限制**：base↔post-trained 配对不适用于多轮/工具场景，公平比较需改为不同规模的两个后训练模型。
- **模板分析覆盖有限**：仅限 Qwen3 的三种模板、两种 grader，跨家族模板效应未验证。
- **精度增益不稳定**：语义 EOS 修正主要改善终止与长度，下游数学精度提升为“模型相关且有限”，Llama 上两变体精度均接近零。
- **未评估全词表 OPD**：作者指出全词表 OPD 同样存在概率加权问题，但因计算成本高未做实验。
- **算力细节缺失**：未报告总训练时长与总 GPU 小时，复现成本估算不完整。
