## 摘要
在线策略蒸馏（OPD）在由学生生成的轨迹上转移教师知识，但高效的采样目标将教师分布简化为每个令牌上的标量信用。这种信用指示一个令牌应获得还是失去概率，却未指明相应的重新分配。我们将OPD重新表述为教师引导的概率传输，提出RouteOPD（路由化在线策略蒸馏），它将局部师生分歧分解为学生过剩来源与教师不足目标，并将它们耦合为显式传输对。RouteOPD优化成对对数几率，朝向从有界教师势得到的联合可实现目标，同时使传输预算适应教师需求的集中程度。该公式将更新引导至教师偏好的目标，并在单一传输算子中控制它们的量级。在四种师生设置和四个数学推理基准上的实验表明，RouteOPD始终优于采样反向KL OPD，并且改进伴随着更高的路由保真度和更低的背景泄漏。这些结果证明了在在线策略蒸馏中显式建模概率传输的有效性。

## Abstract
On-policy distillation (OPD) transfers teacher knowledge on student-generated trajectories, but efficient sampled objectives reduce the teacher distribution to scalar credit on individual tokens. Such credit indicates whether a token should gain or lose probability, yet leaves the corresponding redistribution unspecified. We recast OPD as teacher-guided probability transport and propose RouteOPD (Routed On-Policy Distillation), which decomposes local teacher--student disagreement into student-excess sources and teacher-deficit destinations and couples them into explicit transport pairs. RouteOPD optimizes pairwise log-odds toward jointly realizable targets obtained from a bounded teacher potential, while adapting the transport budget to the concentration of teacher demand. This formulation directs updates toward teacher-preferred destinations and controls their magnitude within a single transport operator. Experiments across four teacher--student settings and four mathematical-reasoning benchmarks demonstrate that RouteOPD consistently outperforms sampled reverse-KL OPD, with improvements accompanied by higher routing fidelity and lower background leakage. These results demonstrate the effectiveness of explicitly modeling probability transport in on-policy distillation.

# 论文核心问题与方法总结

## 1. 核心问题与整体含义（研究动机与背景）
- **问题根源**：在线策略蒸馏（On-policy Distillation, OPD）中，常用采样式目标会把教师对词表上完整分布的修正压缩成单个 token 上的“标量信用”（scalar credit）。该信用只能说明某个被采样 token 应被增强或抑制，却无法指定“被抑制后释放的概率质量应当流向哪些备选 token”。
- **深层缺陷**：因为标准化策略的概率不能孤立改变，抑制一个 token 会迫使学生把质量重新分配到其他 token；若不显式指定去处，实际去处完全由学生当前 softmax 的几何结构决定，导致教师信号中“目标目的地”的信息丢失。作者将此称为单次更新的“路径欠定义”（route under-specification）。
- **核心论点**：应将 OPD 重新理解为“教师引导的概率输运”（probability transport），即显式地构造从“学生多余（excess）”来源到“教师不足（deficit）”目标的概率迁移路径。这比单纯给出标量信用更完整、更准确。

## 2. 方法论：RouteOPD（Routed On-Policy Distillation）
- **核心思想**：在每个学生访问到的状态上，将师生分布分歧分解为“多余质量”和“不足质量”，再把二者配对成显式的“来源→目标”传输路线，使更新朝着教师偏好的目标方向进行，同时控制迁移幅度。
- **关键步骤（文字化算法流程）**：
  1. 在状态 \(s_t\) 上，对学生旧策略 \(\pi_{\text{old}}\) 和教师策略 \(\pi_T\) 分别取 top-k token，再取并集构成稀疏支持集 \(U_t\)。在两个分布重新在 \(U_t\) 上归一化后（仍记作 \(p_S, p_T\)），定义：
     - 来源质量：\(e_t(a)=\max(p_S(a)-p_T(a),0)\)
     - 目标质量：\(d_t(b)=\max(p_T(b)-p_S(b),0)\)
     - 总迁移质量：\(M_t=\sum e_t=\sum d_t=\frac12\|p_S-p_T\|_1\)（即总变差距离）。
  2. 若 \(M_t\) 小于阈值则跳过该状态；否则把 \(e_t, d_t\) 归一化为两个边缘分布，并用二者的**独立乘积耦合**（最大熵耦合）抽样 \(m\) 个“来源-目标”对 \((a,b)\)，从而避免显式构造稠密的 \(k^2\) 耦合表。
  3. 对每个路由对，优化“成对 log-odds”的增量：
     \[
     \Delta_t(a,b)=\left(\log\pi_\theta(b\mid s_t)-\log\pi_\theta(a\mid s_t)\right)-\left(\log\pi_{\text{old}}(b\mid s_t)-\log\pi_{\text{old}}(a\mid s_t)\right)
     \]
     该成对目标的梯度只在 `source` 和 `destination` 两个 logit 上有非零项（\(\nabla_z(\log\pi_\theta(b)-\log\pi_\theta(a))=e_b-e_a\)），因此对无关 token 没有直接 logit 梯度。
  4. **目标的可联合实现性**：为避免对每条边独立裁剪造成“环不一致”（cycle inconsistency），所有配对目标由一个共享的**有界 token 势函数** \(\phi_B(g_t(v))\) 生成，其中 \(g_t(v)=\log\max\{p_T(v),\delta_p\}-\log\max\{p_S(v),\delta_p\}\)。配对目标取两点势值之差：
     \[
     \hat D_t(a,b)=\phi_{B_t}(g_t(b))-\phi_{B_t}(g_t(a))
     \]
     这样所有边目标都是同一组“token 得分”的差，天然可联合实现。
  5. **自适应迁移预算**：教师“不足需求”越集中，给的更新幅度越大。用 Herfindahl 浓度指标 \(c_t\) 刻画教师 deficit 的集中度，预算设为 \(B_t=B_{\min}+(B_{\max}-B_{\min})c_t\)。
  6. 最终损失为以 \(M_t\) 为权重的 Huber 损失期望：对采样到的 \(m\) 个路由对，最小化 \(h_\kappa(\Delta_t-\hat D_t)\)，并乘以 \(M_t\)。
- **额外实现要点**：所有路由统计量都是 detached 的，只有当前学生项参与求导；路由开销为每状态 \(O(k+m)\)；顶 k 提取后无需额外教师前向。

## 6. 主要结论与发现
- **性能提升一致性**：相对于采样反向 KL OPD，RouteOPD 在四个设置下平均提高 Avg@16 达 2.70 个点（95% C.I.: [2.28, 3.13]）；同时超越全词表 reverse-KL 平均 1.24 点，超越固定中等预算路由 1.20 点。
- **“目的地身份”因果有效**：在冻结了 source、目标幅度、耦合权重、名义预算的对照中，用教师 deficit 作为目标（64.43）优于 rank/频率匹配随机目标（63.72）和完全随机背景目标（62.72）。
- **必须双端更新**：source-only 或 destination-only 形式均劣于同时配对成对更新，说明来源和目标需要协同修正。
- **共享势函数保证可联合实现**：独立边裁剪产生 27.6% 的“四环不一致”，共享势函数将其降为 0；目标 MAE 从 0.091 降到 0.067（自适应后 0.052），目标完成率提升至 88.1%。
- **自适应预算起效于“需求集中”时**：自适应与固定预算的差距随教师 deficit 浓度从 -0.10 单调上升到 +2.70 点，证明不是简单的“改大更新幅度”，而是集中在需求最清晰的 states 上加强传输。
- **机制与任务性能一致**：在 1,024 冻结状态上，RouteOPD 使路由保真度从 sampled-RKL 的 35.4% 提升到 90.4%，全词表背景泄漏从 68.3% 降到 13.8%；训练过程中准确率与路由质量同步上升，说明机制增益贯穿训练。
- **行为分析**：AIME24 上 RouteOPD 主要修复“推理错误”（42 个修复中有 34 个），而非格式/提前停止错误；格式有效性保持 95.21%，剪切率反而降低到 2.34%。
- **稀疏性-精度权衡**：k=32, m=2 处于帕累托拐点，以 2.5% 端到端开销达到 65.53 Avg@16；全词表路由只把精度提高到 65.61 却需要 12.5% 开销，说明稀疏路由保留了近全精度收益且代价小得多。

## 7. 优点
- **理论视角新颖**：将 OPD 中的“标量信用”缺陷解释为“缺少概率输运路线”，用总变差/边缘分解/最大熵耦合等工具给出清晰的形式化刻画。
- **面向实际操作的可实现性**：不采用稠密耦合表，而是用独立乘积耦合和蒙特卡洛抽样（\(O(k+m)\) 开销），并把所有边目标统一为一个共享有界势函数，便于训练工程落地。
- **目标设计严谨**：成对 log-odds 具有直接 logit 局部性、共享势函数保证整组边目标可联合实现；自适应预算机制与教师需求集中度直接挂钩，避免单调增大更新带来的不稳定性。
- **实验/因果证据完善**：大量“匹配对照”变量（destination identity、update form、budget、potential consistency）与固定状态诊断库，把性能差异和机制假设做了较强因果绑定；配对 bootstrap 和填充区间增加了统计可信度。
- **训练稳定性与行为分析透明**：报告了梯度范数、响应长度、剪切率、错误类别转换等细粒度指标，帮助读者分辨性能上升来自“推理修复”而非“格式改变”。

## 8. 不足与局限
- **任务覆盖偏窄**：只评估了数学推理（MATH500/AMC/AIME），没有在通用文本、代码、推理以外的任务上验证传输方案是否仍然有效；长程 Agent 或工具调用场景只作为相关工作提及，未做实验。
- **模型/环境约束**：要求教师与学生具有完全一致的有序 token ID 和序列化前缀，很多跨词表模型对无法使用；文中也明确排除了不满足兼容性的模型对，这会限制方法在大规模异构模型间蒸馏的通用性。
- **算力与透明度有限**：只提到每个 run 用 24 块 NVIDIA H20，未披露不同方法总训练步数、总 GPU 小时或更完整的能耗信息；总体计算预算无法精确复算。
- **机制指标可能被高估**：路由保真度/背脊泄漏是基于方向一致性的统计而非对单一“物理输运对”的完全识别；softmax 归一会使无关 token 概率也被动改变，所以“泄漏”不能降到零，解释时必须小心。
- **对超参比较敏感**：最优性能依赖 k、m、Bmin/Bmax 的经验选择

从第 8 点被截断处继续补全（后续内容不重复上述已有输出）:

- **超参敏感性未充分量化**：最优性能虽在 k=32、m=2 附近达到帕累托拐点，但作者仅给出了单一最优配置下的结果。对 Bmin/Bmax 的取值依赖未做更精细的敏感性网格探索，也未讨论不同任务/模型对是否需要重新调参；如果实际部署时无法快速搜索这些超参，收益可能难以稳定复现。

## 9. 改进建议与潜在解决方向
（基于作者自己的抛砖引玉和第三方视角，推测可能可落地的改进点，原文并未全部实验，但逻辑自然延伸到这些方向）
- **放宽词表兼容约束**：当前 RouteOPD 依赖师生共享完全一致的 token ID 顺序与分词器。可探索在“不一致词表但语义重叠”的模型间使用语义 token 或嵌入空间映射建立跨模型的目标集合，再做概率输运；这会显著扩大适用面。
- **将路由机制适配多 token 连续生成**：目前算法在每步状态对单 token 分布做路由，并未显式利用“状态本身”的语义嵌入。未来可将传输路线泛化为对状态上下文的条件路由（例如只在推理错误高风险状态激活），以减少对无关 token 的扰动。
- **显式多候选传输代替最大熵耦合**：独立乘积耦合虽简单高效，但没有利用来源与目标之间的语义相关性（可能导致不合理的高频 token 向罕见 token 传输）。可使用成本矩阵（如 token 嵌入余弦距离）做 Sinkhorn 耦合，在 \(O(k^2)\) 的代价下获得更能解释的路线。
- **把教师“对旧学生错误的相对评价”纳入目标**：当前教师仅给出概率分布，没有给出针对学生旧行为对错的偏好信号。若教师可产出学生轨迹的“评判”或“偏好对”，可把路由目标与该偏好对齐，降低对纯概率差异的依赖。
- **自适应预算从浓度到“状态不确定性”扩展**：目前只用教师 deficit 的 Herfindahl 浓度调节幅度，还可结合学生置信度、状态是否处于推理链的关键位置（如出现结构标记）等多模态信号，使预算分配更符合实际决策难度。

## 10. 总体评价与适用推荐
- **学术价值**：本文属于方法+机制双重贡献的扎实工作。方法侧用最优输运视角重新解释策略蒸馏的更新语义，避免只做“表面上的策略距离最小化”；机制侧设计了大量受控对照与诊断指标，把性能差异拆解到“目的地身份”“耦合一致性”“预算分配”等独立变量上，对理解蒸馏行为有很大帮助。适合作为强化学习/大模型蒸馏方向上研究生或工程师的方法学参考。
- **工程技术参考价值**：RouteOPD 的稀疏化、成对 log-odds、共享势函数等设计都追求低工程复杂度与高可复现性。若需要用“同词表教师”蒸馏数学推理学生，这可能是比采样 RKL OPD 更稳定、更高收益的候选方案。
- **不适用场景**：对跨词表/跨家族模型蒸馏（如 Llama 教师蒸馏 Qwen 学生）、动态 Agent 任务、需要防止概率泄漏被严厉惩罚的生产环节，直接套用当前方案有较大局限。

## 11. 结论（一句话版）
RouteOPD 在不增加显著 token 开销的前提下，通过在师生分布差异之间显式构造“来源→目标”概率输运路径，修复了传统采样蒸馏中教师目的地信息丢失与目标不可联合实现的问题，在 4 个数学师生对、4 个推理基准上稳定带来约 2.7 个 Avg@16 百分点的提升，并提供了从耦合保真度到错误类别转移的完整解释证据。
