## 摘要
在这项工作中，我们介绍了 Instella-MoE，一个完全开源的混合专家（MoE）语言模型，总参数量为160亿，每个 token 的活跃参数量为28亿，完全从零开始在 AMD Instinct MI300X 和 MI325X GPU 上训练。Instella-MoE 将稀疏激活的 MoE 设计与架构和系统层面的创新相结合，包括门控多头潜在注意力（Gated MLA）和 FarSkip-Collective 连接，从而实现了高效的大规模训练和推理。该模型通过多阶段流程开发，包括预训练、中期训练、长上下文扩展、基于反馈驱动的数据整理的监督微调、直接偏好优化，以及使用多教师在线策略蒸馏的强化学习。Instella-MoE 在标准预训练基准上平均得分为76.7，优于先前完全开源的模型，包括 OLMo-3-7B、SmolLM3-3B 和 OLMoE-1B-7B，同时与具有可比活跃参数规模的开源权重 MoE 和稠密基线模型（包括 Moonlight-16B-A3B 和 Qwen3.5-4B）保持竞争力。在后训练之后，我们的最终 Think 检查点在指令遵循、推理、数学、编码和聊天基准上平均得分为73.2，在评估中优于具有可比或更大活跃参数数量的完全开源和开源权重模型。为了支持透明且可重复的研究，我们发布了完整的 Instella-MoE 模型流程，包括模型权重、训练配置、数据混合和训练代码。综合来看，这些贡献使 Instella-MoE 成为高效、高性能 MoE 模型和可重复研究的强大且完全开源的基础。

## Abstract
In this work, we introduce Instella-MoE, a fully open Mixture-of-Experts (MoE) language model with 16 billion total parameters and 2.8 billion active parameters per token, trained entirely from scratch on AMD Instinct MI300X and MI325X GPUs. Instella-MoE combines a sparsely activated MoE design with architectural and system-level innovations, including Gated Multi-head Latent Attention (Gated MLA) and FarSkip-Collective connectivity, enabling efficient large-scale training and inference. The model is developed through a multi-stage pipeline comprising pre-training, mid-training, long-context extension, supervised fine-tuning with feedback-driven data curation, direct preference optimization, and reinforcement learning with Multi-Teacher On-Policy Distillation. Instella-MoE achieves an average score of 76.7 across standard pre-training benchmarks, outperforming prior fully open models including OLMo-3-7B, SmolLM3-3B, and OLMoE-1B-7B, while remaining competitive with open-weight MoE and dense baselines at comparable active-parameter scales, including Moonlight-16B-A3B and Qwen3.5-4B. After post-training, our final Think checkpoint achieves an average score of 73.2 across instruction-following, reasoning, math, coding, and chat benchmarks, outperforming both fully open and open-weight models with comparable or larger active parameter counts in our evaluation. To support transparent and reproducible research, we release the complete Instella-MoE model flow, including model weights, training configurations, data mixtures, and training code. Together, these contributions establish Instella-MoE a strong, fully open foundation for efficient, high-performing MoE models and reproducible research.

# Instella-MoE 技术报告分析

## 一、核心问题与研究动机

- **背景与问题**：大语言模型性能快速提升，但大部分顶尖模型（如 GPT-5.6、Claude、Gemini 等）为闭源发布，训练数据与方法不透明，阻碍了科学理解和复现。即便部分模型开放权重，其预训练语料、数据处理流程和完整训练配方仍不公开。与此同时，MoE 架构凭借每 token 仅激活少量参数的优势成为改善成本-性能平衡的主流方案，但“完全开源 + 高性能 + 全流程透明”的 MoE 模型仍然稀缺。
- **论文目标**：构建并发布一个完全开源的 MoE 语言模型 Instella-MoE-16B-A3B（160 亿总参数、每 token 激活 28 亿参数），在 AMD GPU 上从零训练，同时开放全阶段的权重、训练代码、数据混合和评估协议，以支撑可复现研究和社区创新。

## 二、方法论

### 1. 模型架构
- **整体结构**：仅文本的 decoder-only Transformer，共 27 层——1 层稠密 FFN + 26 层稀疏 MoE 层；每 token 激活 6/64 个路由专家加 2 个共享专家；隐藏维 2048；上下文长度从 4K 扩展到 64K。
- **Gated Multi-head Latent Attention（Gated MLA）**：保留 MLA 的低秩 KV 压缩，但在注意力输出与输出投影之间插入输入条件 sigmoid 门控：

  \[
  y_t = W_o\big(\text{Sigmoid}(W_g x_t) \odot \hat{o}_t\big)
  \]

  该门控允许每个 token 调制各注意力头内部的 value 通道，200B token 消融实验中较标准 MLA 平均分提升 0.47。

- **FarSkip-Collective 连接**：修改 Transformer 子层间连接，使 MoE 的 Dispatch/Combine all-to-all 通信能与不依赖其输出的计算（注意力、共享专家）重叠，消除通信气泡；预训练吞吐提升 12.7%，推理 TTFT 吞吐提升 39.2%，且精度与标准连接几乎持平。
- **多 Token 预测（MTP）**：预训练与中期训练阶段附加单层 MTP 头，预测每位置的下一个额外未来 token，损失权重分别为 0.3（预训练）与 0.1（中期训练），长上下文扩展后禁用。

### 2. 多阶段训练管线

| 阶段 | 数据规模 | 序列长度 | 关键设置 |
|---|---|---|---|
| 预训练 | 7.1T tokens | 4,096 | WSD 调度、峰值 LR 4×10⁻⁴、MTP |
| 中期训练 | ~100B tokens | 4,096 | 3 个变体训练后等权 model soup |
| 长上下文 Stage 1 | ~194B tokens | 65,536 | YaRN RoPE、文档掩码 |
| 长上下文 Stage 2 | ~20B tokens | 65,536 | STEM 平衡混合，恢复数学/代码能力 |
| SFT | ~290 万条记录 | 32,768 | 两轮，第二段用反馈驱动数据筛选 512K |
| DPO | 15 万偏好对 | 16,384 | 关闭负载均衡损失/路由偏差更新防止路由漂移 |
| RL | 29.8K prompts（IF-RL）；50% IF + 50% 通用（MOPD） | 16,384 | GRPO + DAPO/Dr.GRPO 改进；后接 MOPD |

### 3. 关键后训练技术
- **反馈驱动 SFT 数据筛选**：用“诊断—查询生成—检索”三步流水线——对留出集错误回答做结构化错误分析，反射模型聚合成加权检索策略，在嵌入空间中按相似度检索训练样本，相比均匀采样在同一预算下平均提高 1.5 分。
- **MoE 感知的 DPO 稳定化**：DPO 阶段关闭辅助负载均衡损失并冻结路由偏差更新，使 top-6 专家集合与 SFT 的 Jaccard 重叠从 0.42 恢复至 0.94，避免路由漂移带来的能力退化。
- **IF 专用 RL + 多教师同策略蒸馏（MOPD）**：先用带可验证奖励的 GRPO（含零梯度过滤、主动采样、token 级损失、无 KL、Clip-higher、无标准差归一化、TIS 与 R3 路由复放）得到 IF 专家；随后让学生的同策略 rollout 按域路由到 IF 专家（IF 类提示）或冻结的 DPO 模型（数学/代码/通用提示），用 token 级 teacher-student log-prob gap 构造优势做反向 KL 蒸馏，既获得指令遵循能力又避免数学推理退化。

## 六、主要结论与发现

- **基座模型（Base）**：平均分 76.7，为同类评测中全开源模型最强，明显高于 OLMo-3-7B（70.1）、SmolLM3-3B（70.5）、OLMoE-1B-7B（61.9）；在仅激活 28 亿参数的前提下超越激活参数多一倍以上的稠密全开源模型，并超过 Moonlight-16B-A3B（76.2），仅次于 Qwen3.5-4B-Base（79.5）。
- **后训练模型（Think）**：平均分 73.2，超过全开源 OLMo-3-7B-Think（72.0）与开源权重 Gemma-4-E4B（70.5）、Qwen3.5-4B（69.7），是所比较对象中最强的后训练结果。
- **系统效率**：FarSkip-Collective 带来 12.7% 预训练吞吐提升和 39.2% 推理 TTFT 吞吐提升。
- **方法有效性**：Gated MLA 与 FarSkip 在精度几乎无损前提下提升效率；关闭 MoE 负载均衡可显著降低 DPO 路由漂移；MOPD 能融合 IF-RL 的指令遵循增益而不牺牲数学/代码能力。

## 七、优点

1. **透明性极高**：发布从预训练到 RL 每个阶段的权重、训练配置、数据配比、代码与评测协议，是目前最完整的开源 MoE 发布之一。
2. **架构创新与系统优化结合**：Gated MLA 提供精度增益，FarSkip-Collective 从连接层面解决 MoE 通信瓶颈，两者组合形成模型-系统协同改进范式。
3. **针对 MoE 后训练的独特洞察**：识别出 DPO 下 MoE 路由漂移问题并提出简洁有效的解决方案；在 RL 中用 R3 + TIS 处理 MoE 训练/推理路由不一致问题，体现工程精细度。
4. **多阶段训练管线设计合理**：中期训练用 model soup，长上下文扩展拆成“适应 + STEM 恢复”两阶段，后训练按“SFT→DPO→IF-RL→蒸馏”递进，各阶段目标清晰、设计有据。
5. **AMD 硬件上的完整验证**：证明了非 NVIDIA 生态也能完成世界级开源模型训练，具有平台多元化意义。

## 八、不足与局限

1. **算力开销未明确披露**：缺少 GPU 总数、训练总时长、能耗等关键成本数据，社区难以完整评估可复现成本。
2. **单次运行、无方差报告**：主要结果与消融均为单次训练，无法判断性能差异是否在噪声范围内；尤其模型 soup、混合策略等选择可能存在偶然性。
3. **基准覆盖偏英文与通用域**：多语言能力未充分评测；数据与评测集中于数学/代码/英语知识，对安全性、偏见、事实性等维度的评估缺失。
4. **对比范围有限**：未与同规模最强的开源权重模型群（如更大活跃参数的 DeepSeek 系列、Qwen 大尺寸、Llama 系列）同一标准全面对决；对手选择可能使“state-of-the-art”表述略显局限。
5. **全开源定位的“数据”纯度仍有限**：虽然用的是公开数据集，但其中 Nemotron、Dolma、TxT360 等语料本身经过第三方清洗筛选，并非完全自建可追溯的原始数据，完全可复现性仍打折扣。
6. **潜在数据污染风险**：预训练语料与某些评估集（如 GSM8K 风格合成数据、竞赛数学）存在主题重叠，虽未发现明显泄漏，但论文未系统做污染审计。
