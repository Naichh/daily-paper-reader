## 摘要
大型语言模型的后训练通常对所有样本应用单一训练方法，尽管模型自身的轨迹揭示了不同的样本级学习状态。我们提出了Self-Routing，一种行为条件化的后训练框架，利用轨迹正确性和置信度来决定每个样本应当如何优化。根据其行为状态，样本被路由到GRPO、在策略自蒸馏、正则化或跳过，使得训练无需外部教师、额外注释或额外采样即可自适应。在Qwen3和Qwen3.5主干上的数学推理实验表明，Self-Routing一致性地优于均匀GRPO、均匀OPSD、固定混合以及更简单的路由基线。进一步分析表明，路由分布随训练而变化，并减少了对低信号或已稳定样本的不必要更新。

## Abstract
Post-training large language models usually applies a single training recipe to all samples, even though the model's own rollouts reveal different sample-level learning states. We propose Self-Routing, a behavior-conditioned post-training framework that uses rollout correctness and confidence to decide how each sample should be optimized. Depending on its behavior state, a sample is routed to GRPO, on-policy self-distillation, regularization, or skipping, allowing training to adapt without external teachers, extra annotations, or additional sampling. Experiments on mathematical reasoning across Qwen3 and Qwen3.5 backbones show that Self-Routing consistently improves over uniform GRPO, uniform OPSD, fixed mixtures, and simpler routing baselines. Further analyses show that the routing distribution changes over training and reduces unnecessary updates on low-signal or already stable samples.

### 1. 核心问题与研究动机

- **核心问题**：现有 LLM 后训练方法（如 RLVR、GRPO、自蒸馏）对所有训练样本采用**统一或者固定的全局训练配方**，但模型自身的 rollouts（采样轨迹）其实揭示了不同的样本级学习状态。**一篇论文要回答的核心是：rollout 行为是否不仅应决定样本是否被使用，更应决定样本应被如何优化？**
- **研究背景**：
  - 基于验证器的后训练（verifier-based post-training）是提升模型数学/代码等可验证推理能力的关键路径，具有奖励信号稀疏但可自动化验证的特点。
  - 已有方法只利用 rollout 信号做"选择"层面的决策：全对/全错过滤（样本取舍）、课程学习（训练顺序）、固定目标混合（各方法按固定比例混合训练）、推理时投票/重排（选最优回答）。
  - 本文指出上述方法忽略了一个结构性缺陷——样本的训练价值不是静态属性（如难度、质量），而**取决于当前模型在该样本上的 rollout 行为与所施加的优化信号的匹配度**。
- **关键视角**：将后训练视为从"rollouts（轨迹）"到"recipes（配方）"的过程——rollouts 暴露了局部学习状态，学习状态可转化为样本级训练配方。

### 2. 方法论：Self-Routing

#### 2.1 核心思想

Self-Routing 是一个**行为条件化（behavior-conditioned）的后训练框架**：根据每个样本在当前策略 πθ 下的 rollout 正确率和置信度，将样本动态路由至四种训练配方之一（GRPO / OPSD / REG / SKIP），实现从"全局统一配方"到"样本自适应配方"的转变。整个过程**自包含**：无需外部教师模型、无需人工标注、无需额外采样，仅使用训练过程中模型自身产生的 rollouts。

#### 2.2 技术细节

**（1）Rollout 采集（Rollout Collection）**
- 对每个样本 x，当前策略 πθ 生成 G 个响应：oᵢ ~ πθ(·|x)
- 结果级验证器给出二值奖励 R(oᵢ, x) ∈ {0, 1}
- 经验 rollout 准确率定义为 aₓ = (1/G)·Σ R(oᵢ, x)

**（2）行为信号（Behavior Signals）**

**① 精度分解**：将标量 aₓ 用高斯平滑映射为三个软成员分数（低/中/高精度成分）：
- lₓ = exp(−(aₓ−0)²/2σ₂ₗ)，mₓ = exp(−(aₓ−0.5)²/2σ₂ₘ)，hₓ = exp(−(aₓ−1)²/2σ₂ₕ)
- 归一化后得到 ω(aₓ) = [l, m, h]（σₗ=σₕ=0.18，σₘ=0.16）
- **设计动机**：硬阈值划分在 G 较小时使路由不稳定，软分解提高鲁棒性。

**② 置信度校准**：用 token 级预测熵估计模型的内部置信度：
- 序列级不确定性：H̄(oᵢ,x) = (1/Tᵢ)·Σ Hᵢ,ₜ（Hᵢ,ₜ 是 token 级熵）
- 批内归一化转换为置信度，并计算相对批平均值的偏差 Δcₓ，最终得 φ(cₓ) = (ẽc, êc⁺, êc⁻, fΔc)

**（3）路由评分与分配（Recipe Router）**
行为状态 bₓ = (ω(aₓ), φ(cₓ)) 经过四个路由评分函数决策：
- **s_GRPO** = m + h(1−fΔc) + l(1−êc⁻)·êc → 面向混合正确率/不确定样本，利用组内奖励对比
- **s_OPSD** = l(1−êc⁻) → 面向低精度、低置信度样本，用稠密模仿信号补充稀疏奖励
- **s_REG** = h·fΔc·êc⁺ → 面向稳定且高置信样本，保守约束防漂移
- **s_SKIP** = l·êc⁻·êc → 面向持续高置信失败样本，无有效训练信号则跳过
- 得分归一化为概率（加 ε 防止除零），样本通过**分类采样（Categorical sampling）**而非 argmax 指派到单一配方，每轮每个样本只贡献一种损失。

**（4）四种训练配方的损失**

| 配方 | 适用状态 | 损失 | 说明 |
|------|---------|------|------|
| GRPO | 混合正确率（不确定但可解） | L_GRPO = −E[min(ρᵢAᵢ, clip(ρᵢ)Aᵢ)] | 组内相对优势 Aᵢ=(rᵢ−μₓ)/(σₓ+ε)，标准 GRPO |
| OPSD | 失败但可恢复 | L_OPSD = 交叉熵在教师目标序列上 | 教师 = 同一模型 + 正确答案条件，离线预生成 |
| REG | 稳定且高置信 | L_REG = KL(πθ ‖ π_ref) | 约束策略不偏离参考策略 |
| SKIP | 低信号/持续高置信失败 | 0 | 不贡献梯度 |

**（5）策略更新**
最终损失为活跃队列的加权平均：L = (n_g·L_GRPO + n_o·L_OPSD + n_r·L_REG)/(n_g + n_o + n_r)，SKIP 不计入分母。

### 6. 主要结论与发现

1. **行为条件化路由优于全局统一配方**：在所有 6 个骨干模型上平均分全面超越 Naive-GRPO 与 Naive-OPSD。例如 Qwen3-4B 从基座 61.0 提升至 73.7，超过 Naive-GRPO 6.9 分、Naive-OPSD 3.3 分；Qwen3.5-4B 达到 86.6，比 Naive-GRPO 高 6.8 分。
2. **增益随模型容量增大而扩大**：越强的骨干模型，从自蒸馏和路由训练中获益越大；最弱模型（0.6B/0.8B）上 GRPO 与 OPSD 各有胜负，路由增益相对收敛。
3. **不同 rollout 行为状态适配不同优化机制**：诊断实验证实混合正确率样本最受益于 GRPO，低精度低置信失败样本最受益于 OPSD，稳定已解决样本对激进优化不敏感，而高置信持续失败样本应跳过。
4. **路由分布随时间自适应演化**：初期 OPSD 主导（>50% 比例），中期 GRPO 上升至峰值，后期 REG 主导，Skip 比例全程较低且后期进一步下降——说明不同训练阶段需要不同的优化信号。
5. **OOD 通用能力退化最小**：与均匀更新的基线相比，Self-Routing 在 MMLU-Pro 上的退化幅度最小，推测条件化训练减少了过特异化漂移；GPQA-diamond 在数学后训练后通常提升，Self-Routing 亦保持收益。

### 7. 优点与亮点

- **问题洞察深刻且视角新颖**：将"样本是否使用/选择哪个回答"的既有范式推进到"样本应如何被优化"的配方层面，对后训练方法论有启发意义。
- **完全自包含的训练环路**：无外部教师、无额外标注、无二次采样；信号全部从已有 rollouts 中提取；OPSD 教师也是模型自身（基于正确答案提示），消除了分布失配风险。
- **方法与实现具有正交性**：不修改 GRPO/OPSD 等个体算法内部设计，而是提供一种统一的、可插拔的路由框架，可适配未来更强的单配方算法。
- **路由设计精细**：soft 精度分解替代硬阈值 → 避免小 G 时的路由抖动；cosine 型平滑（Gaussian membership）比分段硬划分更稳定；分类采样替代 argmax → 避免边界样本早期坍缩到同一分支。
- **消融体系完整**：从策略层面的随机性（Random）→ 固定混合（Fixed-Ratio）→ 简单状态路由（Accuracy）→ 行为

### 8. 局限性与潜在问题

1. **模型规模覆盖有限**：最大仅验证到 4B 级别，且观察到的"容量越大增益越大"趋势尚未在 7B/14B/72B 上验证。若未来在更大模型上增益饱和甚至逆转（例如大模型本身rollout质量已高，OPSD/REG 分支占比变化），论文结论的普适性将受到挑战。

2. **训练集单一**：所有结果建立在 DAPO-Math-17K 单数据集上。该数据集以竞赛级数学题为主，样本的行为分布可能与通用数学语料差异较大；路由策略在混合难度、多来源数据上的鲁棒性未知。

3. **统计严谨性不足**：论文未报告多次种子运行的标准差、置信区间或显著性检验。考虑到 0.6B/0.8B 小模型上部分基准差距仅 1–3 分，这一差异可能处于噪声范围内。

4. **超参数敏感性与路由稳定性**：软精度分解的核宽 σₗ/σₘ/σₕ、批内置信归一化方式、路由采样温度等关键设计均未做敏感性分析；G=8 的 rollout 数较小，路由分类的抽样噪声对训练收敛的影响缺少量化。

5. **置信度信号的可靠性**：用 token 熵均值作为"置信度"存在已知局限（如模型对错误答案也可能高置信、长度越长熵累积越不具可比性等）。论文仅做了批内长度归一化，未与真实正确概率做校准诊断。

6. **OPSD 教师数据的"免费"程度**：虽然 OPSD 的教师目标来自模型自身加正确答案提示（离线预生成），但**正确答案本身来自数据集标注**——并非完全意义上的"自包含"，若推广到无验证标签的领域，该分支需要重新设计。

7. **计算开销表达不够直观**：FLOPs 以归一化形式给出，读者难以估计实际训练时长与绝对 GPU 成本；对比中 Self-Routing 的 FLOPs（34.7）低于 Naive-GRPO（64.0）但高于 Naive-OPSD（24.0），墙钟时间是否与 FLOPs 成正比并未说明。

8. **未与 SFT 基线对比**：论文始终对比"后训练方法"（GRPO/OPSD），但缺少与经典 SFT（监督微调，即在正确回答上直接微调）的对比基线，无法判断路由方法相对传统监督训练的增益有多大。

### 10. 我的评价与思考

#### 10.1 学术贡献定位

本文的核心贡献不在于提出某种新的策略优化算法，而在于**提出了一种新的后训练组织范式**——即"以 rollout 行为为条件、以样本为单位动态路由训练配方"。它把过去被视为"全局常数"的训练策略选择问题，转化为"逐样本、逐阶段变化的动态优化问题"。这一视角将以下此前割裂的线索统一起来：

- 课程学习（curriculum learning）关注"何时学什么"，但通常只按难度排序；
- 样本选择（sample selection）关注"学不学"，但忽略"怎么学"；
- 多任务/多目标训练关注"损失如何加权"，但权重通常是全局标量而非逐样本行为函数。

Self-Routing 巧妙地将三者融合在一个自包含框架内，具有较强的**方法论迁移潜力**——例如可扩展到代码生成、智能体任务或开放式对话等更多场景。

#### 10.2 方法有效性的理论解释

为什么"行为条件化路由"会有效？本文虽未给出严格理论证明，但可从以下角度理解：

- **优化信号与学习状态匹配**：处于不同局部最优区域的样本，需要不同种类的梯度信息。GRPO 的相对奖励对比适合"已部分掌握但回答不一致"的样本；OPSD 的稠密行为克隆适合"完全不会但可恢复"的样本；REG 的 KL 约束适合"已经很好、防止破坏"的样本——这与控制理论中"不同误差状态下采用不同控制律"的思想一致。
- **减少无效梯度干扰**：SKIP 分支避免了高置信错误样本的顽固梯度持续扰动参数，相当于隐式的梯度清洗（gradient cleansing）。
- **正则化效应的隐式切换**：REG 分支的高比例随着训练推进自然增加，形成一种**自动退火的正则化**，有利于收敛稳定性。

#### 10.3 关键局限的改进方向

若继续推进该工作，我认为以下方向最为重要：

1. **更大规模验证**：在 7B–32B 模型上验证路由增益的伸缩律；同时研究路由分布是否随规模发生相变（例如大模型是否更快进入 REG 主导阶段）。
2. **路由策略的轻量化与自适应**：当前路由依赖人工设计的评分函数和超参数（如 σ、成员函数），可学习一个轻量路由网络或在线估计路由策略，使框架更通用。
3. **扩展奖励来源**：将二值结果验证器替换为可学习奖励模型或 LLM-as-a-judge，检验路由框架在开放式任务中的适用性。
4. **统计严谨性补强**：补充多种子方差、消融显著性检验、以及超参数敏感性曲线。

#### 10.4 总结性评价

本文是一篇**问题意识强、方法设计精致、实验组织系统**的后训练研究。它不追求在单个算法上刷分，而是提出一种"元方法论"层面的改进——这一点在当下LLM后训练"算法竞赛"式的文献生态中显得尤为可贵。虽然模型规模、数据集广度和统计严谨性仍有提升空间，但其核心洞察（rollout 行为信号应决定样本的优化方式而非仅决定取舍）具有清晰的理论价值与工程实用潜力。论文写作结构清楚，从问题到方案再到诊断实验环环相扣，总体质量较高，值得推荐给从事LLM对齐与后训练研究的读者深入阅读。

**关键术语速查表**

| 术语 | 含义 |
|------|------|
| Rollout | 策略模型对给定问题生成的采样回答轨迹 |
| Recipe（配方） | 对样本施加的特定优化方法（GRPO/OPSD/REG/SKIP） |
| Self-Routing | 自包含的行为条件化样本-配方路由框架 |
| GRPO | 组相对策略优化，基于组内奖励相对优劣的强化学习 |
| OPSD | 基于同一模型 + 正确答案的离线自蒸馏 |
| REG | 对参考策略的 KL 正则化，用于防止漂移 |
| SKIP | 不训练，跳过低信号样本 |
| 可恢复失败（Recoverable-low） | rollout 全错且置信度低，但通过正确答案提示可以学会的样本 |
| 过度自信失败（Overconfident-failure） | rollout 全错但模型置信度很高的样本 |
| 行为状态（Behavior State） | 由 rollout 正确率与置信度共同刻画的样本学习状态 |
