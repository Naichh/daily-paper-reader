## 摘要
强化学习可以将一个语言模型转变为多个专家模型，每个专家擅长单一技能，如数学、编程或遵循指令，但用户需要一个具备所有这些技能的模型。多教师同策略蒸馏（MOPD）通过让专家模型教导一个学生模型来合并它们：学生模型回答每个提示，而该提示所属领域的专家模型对每个 token 给出反馈。这种路由决定了哪个专家模型进行教学，但不决定其反馈对共享学生模型的影响强度。在三种规模的 Qwen3.5 模型中，我们发现 MOPD 的学生模型并未超过由最佳单一专家模型教导的学生模型，并且几乎没有获得数学专家模型的优势。反馈是不平衡的：遵循指令的反馈比数学反馈的离散程度大数倍，并主导了学生模型的更新。我们提出领域归一化 MOPD（DN-MOPD），它保留路由，并根据测量到的离散程度重新缩放每个领域的反馈。在六个公开基准上，DN-MOPD 在每种规模、三个随机种子以及两种答案长度限制下均比 MOPD 提高了平均分数，并恢复了大部分丢失的数学增益。使用固定领域权重的对照实验表明，增益主要来自降低遵循指令的反馈，而不是单独提高数学反馈，并且与 DN-MOPD 测量值接近的固定权重表现相当。因此，组合专家模型不仅需要决定由哪个专家进行教学，还需要决定其反馈的权重强度。

## Abstract
Reinforcement learning can turn one language model into several specialists, each excellent at a single skill such as mathematics, coding or following instructions, but users need one model with all of these skills. Multi-teacher on-policy distillation (MOPD) merges them by letting the specialists teach one student: the student answers each prompt, and the specialist for that prompt's domain gives feedback on every token. This routing decides which specialist teaches, but not how strongly its feedback moves the shared student. In Qwen3.5 models at three sizes, we find that MOPD's student does not beat one taught by the best single specialist and gains little of the mathematics specialist's advantage. The feedback is unbalanced: instruction-following feedback is several times more spread out than mathematics feedback and dominates the student's updates. We propose Domain-Normalized MOPD (DN-MOPD), which keeps the routing and rescales each domain's feedback by its measured spread. On six public benchmarks, DN-MOPD improves the average score over MOPD at every size, across three random seeds and under two answer-length limits, and recovers most of the lost mathematics gain. Controls with fixed domain weights show that the gain comes mainly from turning down instruction-following feedback rather than turning up mathematics alone, and that fixed weights close to those DN-MOPD measures perform comparably. Combining specialists therefore requires deciding not only which one teaches, but also how strongly its feedback counts.

## 一、核心问题与研究动机

- **背景**：LLM 后训练普遍采用领域专用强化学习（RL）分别训练专家模型——数学（可验证奖励）、代码（执行反馈）、指令遵循（约束检查）。由于数据、奖励与优化流程不同，这些专家通常各自独立训练，但最终用户需要**一个同时具备所有技能的模型**。
- **主流整合方案**：多教师同策略蒸馏（MOPD）在策略空间中合并专家——学生模型自行采样回答，每个 prompt 按其领域标签路由到对应专家，该专家对学生的每个 token 给出对数概率反馈，形成稠密的蒸馏信号。
- **核心问题（论文的关键观察）**：MOPD 的**路由规则只决定"由谁来教"，却不控制"其反馈的强度"**。现有权重或按 token 占比、或按剩余教师—学生差距手工设定，均未考虑不同 RL 流程训练出的专家反馈**离散度（spread）本身不匹配**。
- **实证发现**（Qwen3.5-9B/4B/2B 三档规模）：
  - 采用标签路由的 MOPD **在任何规模上都没有超过最强单教师学生**，且几乎无法迁移数学专家的增益（8K 预算下仅保留 14–32%，16K 下甚至无增益）。
  - 反馈严重不平衡：指令遵循（IF）专家的 token 级教师—学生 log-ratio 离散度是整体池化信号的 **2.3–4.4 倍**，而数学反馈仅为约一半。
  - 由于所有领域共享同一组参数更新，即使 prompt 数量相等，初始 4B 学生下 **IF 损失贡献了 94% 的联合梯度**。

## 二、方法论：Domain-Normalized MOPD（DN-MOPD）

### 核心思想
保留 MOPD 的领域标签路由，**只增加一个操作**：在更新共享学生之前，按每个领域反馈的相对离散度重新缩放其蒸馏优势（advantage）。路由决定反馈来源，归一化决定反馈权重。

### 关键技术细节
- **反馈定义**：对每个有效响应 token，计算 rollout 阶段的对数比 $r_{i,t} = \ell_T - \ell_{roll}$，其中 $\ell_T$ 为指定教师的 token 对数概率，$\ell_{roll}$ 为学生缓存 rollout 的对数概率。
- **离散度估计**：
  - $\sigma_d$：领域 $d$ 内所有有效 token 的 $r_{i,t}$ 的**总体标准差**（除以 token 数，非样本标准差）。
  - $\sigma_{all}$：所有领域有效 token **拼接后**的池化标准差（不是各领域标准差的平均）。
- **缩放乘子**：
  $$w_d = \text{clip}\left(\frac{\sigma_{all}}{\sigma_d},\ 0.25,\ 4\right)$$
  - 对未裁剪的非退化领域，缩放后满足 $\text{Std}(w_d r_d) = \sigma_{all}$，即把各领域反馈拉到共同的池化尺度。
  - 离散度小的领域被放大，离散度大的被衰减。
  - **正乘子、不减去领域均值，保持每个 advantage 的符号**（即保留"鼓励/抑制该 token"的方向）。
  - 上下界 $[0.25, 4]$ 限制极端调整；若任一标准差为零或观测少于 2 个，则 $w_d = 1$。
- **学生更新**：actor 重新计算更新前学生对数概率 $\ell_{actor}$，形成优势 $A_{i,t} = \ell_T - \ell_{actor}$，再取 $\tilde{A}_{i,t} = \text{stopgrad}(w_{d_i} A_{i,t})$，代入基线裁剪 OPD 目标：
  $$\mathcal{L}_{i,t}(\theta) = -\min\left\{\rho_{i,t}(\theta)\tilde{A}_{i,t},\ \text{clip}(\rho_{i,t}(\theta), 1-\eta^-,\, 1+\eta^+)\tilde{A}_{i,t}\right\}$$
  其中 $\rho_{i,t}(\theta) = \pi_\theta(y_{i,t}|h_{i,t})/\pi_u(y_{i,t}|h_{i,t})$。响应掩码与损失归约方式（先在响应内平均、再跨响应平均）沿用 Label 控制组。
- **重要区分**：尺度估计是 **token 池化**，而训练损失是 **响应级平均**，二者不一致；匹配离散度并不等于固定批损失尺度或使领域梯度范数相等。
- **代价**：无需额外教师调用、额外教师模型或学习型路由器，复用 rollout 阶段已算出的对数比即可；所有 $w_d = 1$ 时即退化为原 MOPD。
- **实际取值**（Qwen3.5 运行）：数学被放大约 1.5–2.1，代码在 4B/2B 接近 1，IF 乘子多数批次触及 0.25 下界（即规则**约束而非完全均衡** IF 的尺度）。
