## 摘要
同策略蒸馏（OPD）通过在学生模型生成的轨迹上施加教师监督，在语言模型之间迁移知识。当使用不同分词器时，单个教师词元可能需要多个学生词元才能生成，从而产生事件已进入但尚未完成的中间状态。现有的跨分词器方法通过对齐词元或文本片段来构建可比较的预测目标。我们研究部分生成之后的一个互补问题：一旦学生生成了某个教师词元的前缀，多个后续词元都可能补全相同的剩余字节，但教师仅指定所需的补全，而未规定概率应如何在若干有效延续之间分配。我们提出事件集补全蒸馏（ESCD），以补全集监督来补充跨分词器的概率对齐。ESCD 聚合与前缀相关的教师事件，并监督字节兼容的单步学生补全的总概率，避免依赖分词器的、在单个词元之间的概率拆分。该方法复用学生轨迹和预测，既不需要额外的 rollout，也不需要更改学生词表。实验表明，在不同模型系列和分词器上，数学、代码和科学推理任务均获得一致提升，并扩展到从 1T 教师模型到 35B 学生模型的大规模 MoE 蒸馏。局部分析表明，保留补全集能更好地匹配参考监督，而在所研究的分词器对中，部分事件进入后，单步补全覆盖了超过 99% 的观测到的兼容教师概率质量。这些发现支持将事件进入和事件补全作为跨分词器知识迁移的互补监督目标。代码将在 GitHub 上发布。

## Abstract
On-policy distillation (OPD) transfers knowledge between language models through teacher supervision on student-generated trajectories. With different tokenizers, a single teacher token may require multiple student tokens to generate, creating intermediate states where the event is entered but not yet completed. Existing cross-tokenizer methods align tokens or text spans to construct comparable prediction targets. We study a complementary problem after partial generation: once the student produces a prefix of a teacher token, multiple next tokens may complete the same remaining bytes, but the teacher only specifies the required completion rather than how probability should be divided among these valid continuations. We introduce Event-Set Completion Distillation (ESCD), which complements cross-tokenizer probability alignment with completion-set supervision. ESCD aggregates prefix-related teacher events and supervises the total probability of byte-compatible one-step student completions, avoiding tokenizer-dependent probability splits among individual tokens. The method reuses student trajectories and predictions, requiring neither additional rollouts nor changes to the student vocabulary. Experiments demonstrate consistent gains in mathematics, code, and scientific reasoning across model families and tokenizers, extending to large-scale MoE distillation from a 1T teacher to a 35B student. Local analyses show that retaining completion sets better matches the reference supervision, while one-step completion covers over 99% of observed compatible teacher mass after partial event entry in the studied tokenizer pairs. These findings support event entry and event completion as complementary supervision targets for cross-tokenizer knowledge transfer. Code will be released on GitHub.

## 1. 核心问题与研究背景

- **研究动机**：大语言模型（LLM）在模型家族、架构、规模、训练数据和分词器（tokenizer）上存在显著差异，这为跨模型知识迁移带来了挑战。同策略蒸馏（On-Policy Distillation, OPD）通过在**学生模型自己生成的轨迹**上施加教师监督，是迁移能力的有效范式，能减少训练上下文与生成状态之间的不匹配。
- **核心矛盾**：现有 OPD 大多假设教师与学生共享分词器（即共享的下一词元预测空间）。但在跨家族蒸馏中，词汇表和词元边界都可能不同——问题不仅是"哪个词元表示一段文本"，还包括"生成它需要多少步"。
- **事件完成缺口（Event-Completion Gap）**：当教师的一个词元（如 `Bread`）需要学生用多个词元（如 `['Br', 'ead']`）生成时，学生采样 `Br` 后进入中间状态 `x′ = (x, Br)`，此时残留字节 `ead` 尚未完成。**教师事件只定义了字节层面的补全约束，并未规定概率应如何在多个有效补全（如 `ead`、`eads`）之间分配**。这种分配由学生分词器决定，而非教师监督本身。
- **研究定位**：本文将这一问题框定为**目标设计问题**——如何监督残留字节约束，同时不规定补全集内部的概率分配。这与此前通过对齐词元/文本片段来构建"可比较预测目标"的方法形成互补。
- **整体含义**：提出事件进入（event entry）与事件完成（event completion）应作为跨分词器知识迁移的两个互补监督目标。

## 2. 方法论：Event-Set Completion Distillation (ESCD)

### 2.1 核心思想

- **事件进入 → 事件完成**：学生动作可以"进入"教师字节事件但未"完成"它，在访问到的子状态留下残留字节约束。
- **关键分离**：补全应独立于"分词器相关的、在单个学生词元之间的概率分配"，从而催生**补全集监督**。
- **复用而非新增**：复用学生 rollout 轨迹和预测，**无需额外 rollout，无需修改学生词表**。

### 2.2 关键技术细节

- **字节表示**：设 $b_T$、$b_S$ 将教师/学生词元映射为精确字节串。教师事件为教师词元的字节 $y = b_T(v)$。
- **残差定义**：若学生采样的内容词元 $a$ 的字节是 $y$ 的非空严格前缀，则访问子状态 $x' = (x, a)$，残差 $r = y[|b_S(a)|:]$。
- **补全集**：$C(r) = \{u \in V_S^{cont} : r \preceq b_S(u)\}$，即所有以残差为前缀的学生内容词元（允许恰好完成或越界延伸）。

### 2.3 教师侧前缀聚合

- 候选集 $V(x)$ 为教师内容词元中**不存在精确单词元学生对应**者。
- 若两候选的字节串存在前缀关系，则合并为一个连通分量（聚合组）。
- 每组取**最短成员**作为代表前缀 $y_g$，组的教师概率质量 $M_g = \sum_{v \in V_g} q_T(v|x)$ 保留。
- 示例：`Bread` 与 `Breads` 聚合为前缀 `Bread`，保留共享约束但不要求额外的 `s`。

### 2.4 训练目标（公式以文字说明）

- **根投影损失**（复用 BPM 的字节对齐与根投影，但不保留其内部与跨位监督）：在共享坐标上构造带补集 $\perp$ 的分布，应用前向 KL：
  $$\ell_{root}(x) = \mathrm{KL}(\bar{q}_x \| \bar{p}_{\theta,x})$$
- **子损失**：对满足 $b_S(a) \prec y_g$ 且补全集非空的组，在访问子状态 $x'$ 上：
  $$\ell_{child}(x, a) = -\sum_{g \in G(x,a)} M_g \log\!\Big[\sum_{u \in C(r_g)} p_\theta(u \mid x, a)\Big]$$
  - 权重 $M_g$ 保留根处教师质量，**不在合格组间重新归一化**。
  - 学生概率使用**原生全词表分布**，不在内容词元或补全集上重新归一化。
  - 无论下一个采样词元是否属于补全集，损失均可应用。
- **总损失**：$L_{ESCD} = L_{root} + L_{child}$，两项在统一归约下求和，零贡献位置不加分。

### 2.5 为何监督"集合"而非单个词元

- 对任一 $u^* \in C(r_g)$，单完成损失可分解为：
  $$-M_g \log p_\theta(u^* \mid x') = -M_g \log P_\theta(C_g \mid x') - M_g \log \frac{p_\theta(u^* \mid x')}{P_\theta(C_g \mid x')}$$
  - 第一项鼓励补全集概率；第二项偏好集合内某一词元。
- ESCD 仅保留第一项，避免引入教师未规定的集合内偏好。当补全集大小为 1 时两者等价。

### 2.6 算法流程（Algorithm 1 摘要）

1. 从学生 rollout 对齐根行，计算根蒸馏损失；
2. 构建字节前缀索引；
3. 对每个根位置，取采样动作 $a$ 与其后继逻辑响应坐标 $c = r+1$；
4. 对合格非共享事件做前缀商运算，得到代表组 $(y_g, M_g)$；
5. 若 $b_S(a) \prec y_g$，求补全词元集合 $C_g$；
6. 若非空，在 $c$ 位置累加 $-\lambda_{ESCD} M_g \cdot \mathrm{LogSumExp}_{u \in C_g} L_S[c, u]$。
