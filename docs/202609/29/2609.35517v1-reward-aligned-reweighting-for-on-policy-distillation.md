## 摘要
同策略蒸馏（OPD）利用更强的教师模型对学生生成的轨迹提供密集反馈，来训练学生语言模型。然而，标准 OPD 对词元级蒸馏项进行均匀加权，隐含地将局部教师偏好视为纠正效用的代理。但一个决策的任务价值取决于学生如何完成后续推理。这种不匹配可能导致模仿抑制可行的学生策略，或强化学生无法可靠执行的路径。已验证的轨迹结果提供了关于续写质量的补充证据，但并不能直接识别单个决策的效用。我们提出面向同策略蒸馏的奖励对齐重加权（R$^{2}$-OPD），它利用结果一致性和师生分歧幅度来持续重新分配教师监督。该方法在保留密集反馈的同时，赋予与奖励对齐的纠正更大的相对影响，超越了均匀模仿和硬过滤。我们的分析形式化了局部教师偏好与学生续写价值之间的不匹配，并建立了重新分配相对于均匀 OPD 能提升一阶任务进展的充分条件。在七个数学推理基准上，R$^{2}$-OPD 在跨规模蒸馏和同规模蒸馏中均取得了相比训练方法中最高的平均准确率。它在所有七个基准上都优于标准 OPD，对于 1.7B 和 4B 学生模型分别平均提升 3.5 和 2.4 个百分点。将其扩展到代码生成时，相比标准 OPD 平均提升 1.6 个百分点。这些结果凸显了结果引导的监督分配是一种有效方式，可将密集教师反馈转化为跨模型规模和任务领域的更强学生性能。

## Abstract
On-policy distillation (OPD) trains a student language model with dense feedback from a stronger teacher on student-generated trajectories. Yet standard OPD weights token-level distillation terms uniformly, implicitly treating local teacher preference as a proxy for correction utility. A decision's task value, however, depends on how the student completes the subsequent reasoning. This mismatch can cause imitation to suppress viable student strategies or reinforce paths the student cannot reliably execute. Verified trajectory outcomes provide complementary evidence about continuation quality, but do not directly identify the utility of individual decisions. We introduce Reward-Aligned Reweighting for On-Policy Distillation (R$^{2}$-OPD), which uses outcome agreement and the magnitude of teacher--student disagreement to continuously reallocate teacher supervision. It gives reward-aligned corrections greater relative influence while retaining dense feedback, moving beyond uniform imitation and hard filtering. Our analysis formalizes the mismatch between local teacher preference and student continuation value and establishes sufficient conditions for reallocation to improve first-order task progress over uniform OPD. Across seven mathematical reasoning benchmarks, R$^{2}$-OPD achieves the highest average accuracy among the compared training methods in both cross-size and same-size distillation. It outperforms standard OPD on all seven benchmarks, with average gains of 3.5 and 2.4 percentage points for 1.7B and 4B students, respectively. An extension to code generation yields an average gain of 1.6 percentage points over standard OPD. These results highlight outcome-guided supervision allocation as an effective way to translate dense teacher feedback into stronger student performance across model scales and task domains.

# 论文总结：Reward-Aligned Reweighting for On-Policy Distillation（R²-OPD）

## 1. 核心问题与整体含义

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）已成为大语言模型后训练的标准环节——学生在自己生成的轨迹上接受更强教师的密集词元级反馈，从而缓解训练与推理时的上下文错配。
- **核心痛点**：标准 OPD（采样词元版本）以师生对数概率差 `A_t = log π_T(o_t|s_t) − log π̄_θ(o_t|s_t)` 作为纠正系数并**均匀使用**，隐含地把"教师局部偏好"当作"纠正效用"的代理。
- **本质错配**：一个决策的任务价值取决于**学生后续推理能否成功**（continuation value），而非教师的局部偏好。论文用两个失败模式刻画该错配：
  - *过纠正（over-correction）*：在成功轨迹上压制教师不喜欢的决策，会侵蚀学生自身有效但异于教师的策略；
  - *过信任（over-trust）*：在失败轨迹上强化教师偏好的决策，会鼓励学生无法可靠完成的推理路径。
- **理论形式化**（命题 1）：对下一个动作分布做师生插值 `π_ε ∝ π̄_θ^{1−ε} π_T^{ε}`，可得
  - 局部反 KL 导数 `D'_s(0) = −Var_s[A_t]`（恒为下降）；
  - 条件期望奖励导数 `F'_s(0) = Cov_s(A_t, Q^R_θ̄(s,o_t))`。
  - 当协方差为负时，**反 KL 下降的同时期望奖励也下降**——即"更接近教师"并不等于"更有用"。
- **动机结论**：已验证的轨迹结果 `z(q,o)=2R(q,o)−1` 提供了关于续写质量的补充证据，但不直接识别单决策效用。因此应当用结果证据来**调节纠正强度**，而非做硬性过滤或统一模仿。

## 2. 方法论

### 2.1 核心思想
用"结果对齐"（outcome agreement）与"师生分歧幅度"（disagreement magnitude）联合构造连续门控，对教师纠正进行**重新分配**：给奖励对齐的纠正更大相对影响，同时保留全部密集反馈、不改变纠正符号、不改变每条响应的绝对系数质量。

### 2.2 关键技术细节（算法流程）
1. **采样与评估**：冻结学生快照 `θ̄`，采样 prompt 与响应 `o`；对每个位置查询教师得到 `A_t`，由验证器得到响应级符号结果 `z ∈ {−1,+1}`。
2. **响应局部尺度**：`ν_o = max( median_{1≤j≤|o|} |A_j| , ε )`，用中位幅度做归一化基准，使分歧幅度具有响应内可比性。
3. **Sigmoid 门控**：`g_t = σ( β z(q,o) A_t / ν_o )`，`β ≥ 0` 控制锐度。对齐纠正 `zA_t>0` 得 `g_t > 1/2`，不一致者得 `g_t < 1/2`；`β=0` 时退化为 `g_t=1/2`（等价标准 OPD）；有限 `β` 下门控严格为正。
4. **质量保持归一化**：设 `M_o = Σ_t |A_t|`，`Z_o = M_o / Σ_j g_j |A_j|`，重加权优势为 `A^{R2}_t = Z_o g_t A_t`。`Z_o` 只恢复原系数预算，不改变各位置间的相对倍率。
5. **训练目标**：`L_R2(θ;θ̄) = −E[ Σ_t sg[A^{R2}_t] log π_θ(o_t|s_t) ]`，优势与门控全部 detach，梯度只流经 `log π_θ`；不引入额外策略梯度项或价值估计器。
6. **回退与掩码**：截断响应与零质量响应保留标准 OPD 系数；prompt/padding 位置不计入尺度、质量与损失。

### 2.3 理论性质
- **命题 2（精确分解）**：`A^{R2}_t = (Z_o/2)A_t + (Z_o/2) z|A_t| tanh(β|A_t|/2ν_o)`。前者保留教师有符号纠正，后者为结果相关调制项（成功响应上非负、失败响应上非正），衰减失败响应上的强化与成功响应上的压制，同时强化奖励对齐纠正；因 `tanh < 1`，系数符号不变。
- **命题 3（质量保持的奖励对齐分配）**：对所有有限 `β`，`Σ_t |A^{R2}_t| = M_o`，且不一致质量占比 `κ_o(β)` 单调下降（`κ'_o(β)<0`，右导数）；`β→∞` 收敛为质量归一化的硬对齐门控。注意：保留系数质量**不**等价于保留参数梯度范数（存在词元方向间的相互增强/抵消）。
- **命题 4（条件任务进展恒等式）**：以 `p_o(t)=|A_t|/M_o`、`u_t = sgn(A_t)⟨g_R, ψ_t⟩`，有
  `⟨g_R, d_R2(o) − d_V(o)⟩ = M_o · Cov_{p_o}(g,u) / E_{p_o}[g]`。
  由于 `E_{p_o}[g] > 0`，**当且仅当门控权重与任务投影效用正协变**时，重加权才改善响应级一阶任务进展。仅减少不一致质量并不保证任务进展。文中还给出充分的"奖励–效用一致性条件"（组间项 `α(1−α)(μ_{g,A}−μ_{g,C})(μ_{u,A}−μ_{u,C})` 需压过组内负贡献）。
- **附录补充**：证明了一阶梯度等价 `∇L^{sample}_OPD = ∇L_OPD`（在 rollout 参数处）；给出奖励上升的步长上界（依赖 `L_J`-Lipschitz 与 `Δ_R > −P_V`）；构造了一个两路径解析反例（学生 0.66 vs 教师 0.94 成功率，`F'_s(0) < 0`）。

## 6. 主要结论与发现

- **性能提升**：R²-OPD 在两种设置下均取得最高平均准确率，且**在全部七个数学基准上优于标准 OPD**。1.7B 学生达 46.2±0.4%（+3.5），4B 学生达 50.8%（+2.4）；分别超过最强基线 OPDVR 与 ExOPD 约 +1.2 和 +0.9。
- **难题增益更显著**：1.7B 设置下 AIME25 +4.4、AMC24 +5.2、OlympiadBench +3.0。
- **学习更快**：约第 40 步即可见 AIME25 上的平均准确率优势，约第 60 步接近峰值并持续保持。
- **跨域有效

- **跨域有效**：在代码生成（HumanEval+、LiveCodeBench）上同样取得最佳平均表现，说明结果对齐重加权不依赖数学任务的特定结构（如可验证的数值答案），对一般可验证奖励场景具有可迁移性。
- **消融验证机制归因**：
  - 反向对齐（把 `z` 取反）与结果置换均导致性能下降，说明增益来自"结果证据与纠正方向的一致性"而非单纯引入随机扰动或改变系数量级；
  - 仅符号门（只用 `sgn(A_t)`、丢弃幅度信息）与仅幅度门（只用 `|A_t|`、丢弃结果符号）都弱于完整方法，证明**符号与幅度二者缺一不可**；
  - 去掉质量归一化 `Z_o` 后性能下降，说明"不改变每条响应绝对系数预算"这一设计对稳定训练是必要的；
  - 与 GRPO 加性组合并未带来叠加收益，暗示 R²-OPD 已在密集纠正内部完成了类似"结果加权"的功能，与稀疏结果梯度存在冗余。
- **分支对照**：仅成功响应重加权 / 仅失败响应重加权均不如双向重加权，支持论文"过纠正与过信任是两种对称失败模式、需同时治理"的论断。
- **β 敏感性**：性能在 `β ∈ [10⁻⁴, 10⁻²]` 区间较平稳，`β=1e-3` 为稳健默认值；`β→0` 退化为标准 OPD，`β` 过大（如 10²）因门控过度硬化而下降。
- **训练动态**：不一致质量占比 `κ_o(β)` 随训练持续下降（与命题 3 一致）；策略熵与响应长度未见崩溃或异常膨胀，说明重加权没有以牺牲探索或输出稳定性为代价换取准确率。
- **理论—实验一致性**：Cov_{p_o}(g,u) 的经验代理（响应级任务进展）在训练早期为正并逐步增大，与命题 4 给出的"门控权重与任务效用正协变则改善进展"的判据方向一致。

## 7. 局限性、边界条件与开放问题

- **统计强度不均衡**：仅跨规模 1.7B 主实验做了 3 种子重复；4B 同规模、代码域与全部消融均为单次运行，因此除主结论外的差异（尤其 ±0.5 以内的方法间差距）不宜过度解读。
- **任务效用不可直接观测**：方法以响应级二值结果 `z` 作为续写质量的代理，属于粗粒度信号；一个响应内部不同决策的真实续写价值 `Q^R` 并不被单独识别，因此重加权只是"更好的代理"，而非最优分配。论文的命题 4 明确给出反例条件：若门控权重与任务效用负协变，重加权反而损害进展。
- **超参数依赖**：`ν_o` 采用中位数幅度、门控采用固定 `β`，其跨任务/跨模型的最优取值未做自适应研究；理论上 `β` 可随训练阶段调度，但文中未探索。
- **验证器假设**：方法要求存在可靠的结果验证器（数学可判对错、代码可跑测试）；对开放式生成、主观任务或奖励噪声较大的场景，`z` 的可靠性下降，方法有效性未验证。
- **计算等价性表述谨慎**：作者强调"模型前向次数不变 ≠ 墙钟时间等价"，但未给出实测 wall-clock 对比，也未报告总 GPU 小时，复现成本评估受限。
- **与 RL 的关系未完全厘清**：与 GRPO 加性组合无增益，但二者的互补性/替代性缺乏更系统的分析（如不同 rollout 预算、不同教师强度下的行为）。

## 8. 一句话总评

R²-OPD 用一个简洁、无需额外前向的连续门控，把"结果是否对齐"注入同策略蒸馏的逐词元纠正系数中，在理论上刻画了标准 OPD 的过纠正/过信任错配并给出质量保持与任务进展的精确条件，在实验上于两种规模、两个任务域取得一致且可归因的提升；其核心洞见——**"更接近教师"不等于"更有用"，应当用结果证据调节而非替代密集纠正**——对 OPD 及其与 RL 结合的后续研究具有直接指导意义，但结论的统计稳健性与跨任务泛化仍待更大规模、多种子与更细粒度效用信号的验证。
