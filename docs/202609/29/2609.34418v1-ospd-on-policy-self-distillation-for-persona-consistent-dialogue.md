## 摘要
在多轮对话中保持人设一致性，仍是角色扮演语言模型的核心挑战。从外部教师模型进行的离策略蒸馏会引入分布不匹配，且这种不匹配会随对话轮次累积；而强化学习则难以应对主观人设保真度所固有的奖励模糊性。我们提出 OSPD，一种同策略自蒸馏框架，其中同一模型在非对称信息下同时充当教师和学生：教师接收完整角色档案，而学生仅看到简要摘要，并且学生从自身策略生成轨迹。我们发现，教师在角色扮演对话中的置信度呈现双峰结构——在角色关键 token 上尖锐集中，而在通用话语上则较为分散——并引入角色感知的散度切换来匹配这一结构。一种渐进式特质掩蔽课程进一步促使角色知识沿语义维度分阶段内化。在 CharacterBench、CharacterEval 和 SocialBench 上的实验表明，OSPD 显著提升了人设一致性，优于监督微调和多轮强化学习基线，且无需任何外部教师模型或奖励模型。

## Abstract
Maintaining persona consistency across multi-turn dialogues remains a core challenge for role-playing language models. Off-policy distillation from external teachers incurs distribution mismatch that compounds across dialogue turns, while reinforcement learning struggles with reward ambiguity inherent in subjective persona fidelity. We propose OSPD, an on-policy self-distillation framework where the same model serves as both teacher and student under asymmetric information: the teacher receives a complete character profile while the student sees only a brief summary, and the student generates trajectories from its own policy. We find that teacher confidence in role-playing dialogue exhibits a bimodal structure---sharply peaked at character-critical tokens yet diffuse at generic utterances---and introduce role-aware divergence switching to match this structure. A progressive trait masking curriculum further forces staged internalization of character knowledge along semantic dimensions. Experiments on CharacterBench, CharacterEval, and SocialBench show that OSPD substantially improves persona consistency over supervised fine-tuning and multi-turn RL baselines, without requiring any external teacher or reward model.

## 1. 核心问题与整体含义

- **研究背景**：角色扮演语言模型（交互娱乐、教育模拟、社交陪伴）需在多轮对话中持续忠实反映角色的性格、知识与行为模式。
- **核心痛点——人设漂移（persona drift）**：随对话推进，模型逐渐抛弃设定角色、回退到通用行为；单次"出戏"回复会污染后续整个上下文。
- **理论归因**：从模仿学习视角看，这是**暴露偏差（exposure bias）**的表现——推理时按自身策略生成、训练时却依赖外部数据，误差跨轮累积（离策略蒸馏的累积误差随对话长度呈二次增长）。
- **现有方法局限**：
  - 对比学习：难以处理细粒度特质区分；
  - 强化学习：人设保真度本身是主观概念，奖励设计存在歧义；
  - 推理增强：成本高且不直接解决分布不匹配；
  - **关键空白**：此前无工作用"同策略自蒸馏"解决人设一致性，尽管其在降低暴露偏差上有理论优势。
- **核心洞察**：同一模型在完整档案 `cfull`（约 2000 tokens）与简要摘要 `cbrief`（约 100 tokens）条件下的表现存在显著差距（预实验整体差距 18.1 分），该差距天然构成自蒸馏信号，**无需任何外部教师模型**。

## 2. 方法论

### 2.1 核心思想与形式化

- 角色表示为 `C = (cfull, cbrief)`；推理时仅有 `cbrief`（模拟用户只给简短描述的实用场景）。
- 同一模型两种模式：
  - 教师 `πT(a | cfull, ht) = LM_θ̄(...)`，`θ̄` 为学生参数 `θ` 的 EMA 副本；
  - 学生 `πS(a | cbrief, ht) = LM_θ(...)`。
- **信息不对称完全落在条件上下文上**，模型参数共享，EMA 副本提供缓慢演化的稳定目标。

### 2.2 四步训练流程

1. **同策略生成**：学生从 `πS(·|cbrief, ht)` 采样回复 `ât`，训练分布即学生自身行为分布，直接消除暴露偏差。
2. **教师评估**：EMA 教师在相同对话上下文、但条件为 `cfull` 下，对 `ât` 的每个 token 位置给出分布，作为逐位置监督目标。
3. **散度计算**：按角色感知散度切换计算 `L_OSPD`。
4. **梯度更新**：梯度只流经学生 log 概率，教师 logits 视为固定目标。

> 与 SPIN 等纯自博弈方法的区别：OSPD 教师**持续通过 `cfull` 注入外部信息**，模型不是自我强化偏见，而是向"信息更丰富条件"对齐，避免策略饱和。

- **EMA 教师稳定化**：`θ̄ ← αθ̄ + (1−α)θ`，`α ∈ [0.99, 0.999]`，采用 mean-teacher 范式；避免朴素参数共享带来的移动目标振荡。

### 2.3 角色感知散度切换

- **双峰置信假设**：教师处理角色关键内容（领域知识、口头禅、价值判断）时分布尖锐集中（低熵）；处理通用话语（问候、过渡、开放式表达）时分布分散（高熵）。
- 逐位置计算教师熵 `Hk = H(πT(·|cfull, h, â<k))`，定义门控系数 `αk = σ((Hk − μH)/τ)`，其中 `μH` 为当前 batch 内教师熵的滑动均值，`τ` 为温度超参。
- 损失为前向/反向 KL 的逐位置插值：`L_OSPD = Σk [(1−αk)·D_KL(πS‖πT) + αk·D_KL(πT‖πS)]`。
  - **低 `αk`（教师高置信）→ 反向 KL**：mode-seeking，精确模仿尖锐的角色行为；
  - **高 `αk`（教师低置信）→ 前向 KL**：mode-covering，保留表达多样性。
- 与 ToDi、Entropy-Aware OPD 等通用自适应散度方法的本质差异：**切换逻辑锚定于角色扮演对话的语义结构**，教师熵直接反映特权档案在该位置的信息量，等价于"特权信息在何处重要"的隐式检测器。

### 2.4 渐进式特质掩码课程

- 将角色档案分解为五个语义维度：**Identity（身份）、Personality（性格）、Knowledge（知识）、Style（风格）、History（历史）**
