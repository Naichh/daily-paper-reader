## 摘要
在策略自蒸馏微调（SDFT）能够从演示中学习新技能，同时减少遗忘，但它始终向完整的演示条件教师蒸馏。这将教师影响固定在完整教师端点，无法控制每个预测状态下应迁移多少演示信息。我们提出信息邻近 SDFT（iSDFT），它转而将教师视为有预算的信息源。对于每个 token，iSDFT 选择最接近当前学生且满足指定教师信息约束的分布，产生具有局部确定倾斜的闭式指数目标。为控制累积漂移，我们进一步将学生锚定到其冻结的基础策略。在四个异构 LLM 主干和两个专业化任务上，iSDFT 在 8 个模型-任务设置中的 7 个上优于原始 SDFT，在剩余一个上与之持平。它还在原始 SDFT 基准套件上提供了更紧的保持性：73% 的评估保持在基础模型 0.5 分以内，而最强基线为 52%；同时在所有十个额外数学、编程和竞赛数学基准上取得最大平均提升。这些结果表明，控制教师信息引入的多少与时机，能够在保留更广泛能力的同时提升专业化。

## Abstract
On-policy self-distillation fine-tuning (SDFT) learns new skills from demonstrations while reducing forgetting, but it always distils toward the full demonstration-conditioned teacher. This fixes teacher influence at the full-teacher endpoint, providing no control over how much demonstration information should be transferred at each prediction state. We introduce Information-Proximal SDFT (iSDFT), which instead treats the teacher as a budgeted source of information. At each token, iSDFT selects the distribution closest to the current student that satisfies a prescribed teacher-information constraint, yielding a closed-form exponential target with a locally determined tilt. To control cumulative drift, we further anchor the student to its frozen base policy. Across four heterogeneous LLM backbones and two specialisation tasks, iSDFT improves vanilla SDFT in 7 of 8 model-task settings and matches it in the remaining one. It also provides tighter retention on the original SDFT benchmark suite, with 73% of evaluations remaining within 0.5 points of the base model versus 52% for the strongest baseline, while achieving the largest mean improvement on all ten additional mathematics, coding, and competition-mathematics benchmarks. These results show that controlling how much and when teacher information is introduced improves specialisation while preserving broader capability.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：持续学习关注模型能否在获得新能力的同时不擦除已有能力，即经典的稳定性–可塑性困境。对大语言模型（LLM）而言，这一矛盾在指令微调、工具使用、领域知识注入等后训练场景中尤为突出。
- **演示学习的两难**：标准监督微调（SFT）是 off-policy 的——训练用专家生成的历史，部署却在模型自身生成的历史上展开。SDFT（on-policy 自蒸馏微调）通过在学生自生成前缀上，让"演示条件化的教师"提供 token 级监督，缓解了这一训练–部署错配，且无需偏好标签或 RL 奖励。
- **核心缺陷**：SDFT 只解决了"在哪里施加信号"（学生前缀），却未控制"信号多强"。每个 token 都以**完整演示条件教师分布**为目标，等价于局部稳定性–可塑性权衡中"最大可塑性"的端点，无论演示对该状态下的预测行为改变多大。
- **另一层动机**：局部保守不等于全局保守。即使每次更新满足 KL(P⁽ⁿ⁺¹⁾‖P⁽ⁿ⁾) ≤ ε，也不能保证 KL(P⁽ᴺ⁾‖P⁽⁰⁾) 小，因此需要显式的长期锚定。
- **外部证据**：近期工作表明，完全模仿特权信息教师会压制不确定性、削弱探索性推理、加剧对既有行为的漂移，甚至损害推理能力。这促使人们寻找"控制教师影响力"的机制。
- **整体含义**：论文主张把教师重新定位为**有预算的信息源**而非模仿目标，从而在专门化与通用能力保留之间获得更细粒度的权衡。

## 2. 方法论：信息邻近自蒸馏（iSDFT）

### 2.1 核心思想
- 在每个学生生成的前缀上，不要求匹配完整教师 Tₜ，而是寻找**最接近当前学生 Pₜ、同时满足指定教师信息量约束**的目标分布 Qₜ。这被形式化为对"教师信息可行集"的 KL **I-投影**。

### 2.2 关键定义
- 局部教师信息信号：`ηₜ(v) = log(Tₜ(v)/Pₜ(v))`，刻画演示相对学生偏好的方向。
- 候选目标的信息量：`Iₜ(Q) = E_{v~Q}[ηₜ(v)]`，越大表示向演示行为越靠拢（可塑性越强）。
- 约束投影问题：`Q*ₜ = argmin_{Q∈Δ(V)} KL(Q‖Pₜ) s.t. Iₜ(Q) ≥ γₜ`，γₜ 为局部教师信息预算。

### 2.3 闭式解（Proposition 1）
- 当约束活跃时，最优目标为指数路径：
  `Q*ₜ(v) = Pₜ(v) exp(λₜηₜ(v)) / Zₜ(λₜ) = Pₜ(v)^{1−λₜ} Tₜ(v)^{λₜ} / Σᵤ Pₜ(u)^{1−λₜ} Tₜ(u)^{λₜ}`
- **关键点**：λₜ 不是人工设定或调度的插值系数，而是信息约束的 Lagrange 乘子，由约束本身**局部诱导**得到。

### 2.4 λₜ 的求解
- 定义 `Gₜ(λ) = E_{Q(·;λ)}[ηₜ(v)]`，需求解 `Gₜ(λₜ) = γₜ`。
- 单调性证明：`dGₜ/dλ = Var[ηₜ] ≥ 0`，故 Gₜ 单调非减；在可达区间内解存在，严格递增区间内唯一。
- 实现上用**一维二分法**（40 次迭代）求解，只作用于已算出的学生/教师 log-prob，无需额外前向传播。

### 2.5 相对信息预算
- 固定绝对值不合理（不同预测状态下教师信息量差异大），故采用相对预算：`γₜ = ρ·KL(Tₜ‖Pₜ)`。
- 标量 ρ 全局控制教师信息强度，γₜ 随学生–教师分歧自动局部调整。

### 2.6 基座锚定与总损失
- 由于目标是相对"当前学生"定义的移动参考，序列化的局部保守更新仍可能累积漂移，因此额外锚定冻结基座：
  `ℓₜ = KL(Q*ₜ‖Pₜ) + μ·KL(P_base‖Pₜ)`，`μ ≥ 0`
- 显式解耦**局部可塑性**（信息预算）与**长期保持**（基座锚）。

### 2.7 算法流程（Algorithm 1）
1. 用学生采样 on-policy rollout；
2. 逐 token 计算 Pₜ（学生）、Tₜ（演示条件教师）、P_base（冻结基座）及 ηₜ；
3. 选定预算 γₜ，二分求解 λₜ；
4. 构造 Q*ₜ，计算损失项；
5. 累加各 token 损失更新 θ。

### 2.8 默认超参
- 教师为学生参数的 EMA（α = 0.01）；ρ 在前 150 步从 0.25 线性升至 1；锚权重 μ = 2×10⁻³；二分 40 次。
