## 摘要
在线策略蒸馏（OPD）正成为大语言模型（LLM）后训练的重要组成部分，用于将强教师 LLM 的推理能力迁移到较弱的学生 LLM。OPD 通过由学生策略生成的 rollout 来最小化教师与学生之间的反向 KL 散度，从而训练学生。然而，在 OPD 中估计反向 KL 散度的梯度仍然是一个挑战。仅使用学生生成的 rollout 中采样得到的 token 计算成本低，但提供的分布监督有限，会降低准确率。此外，使用完整词表可提供完整的分布监督，但计算成本高昂。因此，近期工作提出 Top-$k$ OPD（TK-OPD），使用选定的 top-$k$ token，这比采样 token 估计提供更丰富的分布监督，同时计算成本远低于全词表估计。遗憾的是，仅使用选定的 top-$k$ token 会引入偏差，因为选定的 top-$k$ token 之外的概率质量被丢弃，从而导致准确率下降。为解决 TK-OPD 的偏差，我们提出尾部校正的 Top-$k$ 在线策略蒸馏（TT-OPD）。它保留了 TK-OPD 的优势，包括丰富的分布监督和低计算成本，同时提供反向 KL 散度梯度的无偏估计。TT-OPD 的关键洞见在于，不仅使用选定的 top-$k$ token，还使用学生生成的 rollout 中采样得到的 token，从而在期望意义下恢复被丢弃的概率质量，避免偏差。实验结果表明，TT-OPD 显著优于其他测试的 OPD 变体。

## Abstract
On-policy distillation (OPD) is becoming an important component of large language model (LLM) post-training for transferring the reasoning capability of a strong teacher LLM to a weaker student LLM. OPD trains the student by minimizing the reverse KL divergence between the teacher and the student via rollouts generated by the student's policy. However, estimating the gradient of the reverse KL divergence in OPD remains a challenge. Using only the sampled token from the student-generated rollout is computationally cheap but provides limited distributional supervision, which will degrade accuracy. In addition, using the full vocabulary provides complete distributional supervision but is computationally expensive. Therefore, recent works propose Top-$k$ OPD (TK-OPD) that use selected top-$k$ tokens, which provides richer distributional supervision than sampled-token estimation at substantially lower computational cost than full-vocabulary estimation. Unfortunately, using only the selected top-$k$ tokens induces bias, leading to accuracy degradation, as the probability mass outside the selected top-$k$ tokens is discarded. To address the bias of TK-OPD, we propose Tail-Corrected Top-$k$ On-Policy Distillation (TT-OPD). It preserves the advantages of TK-OPD, including rich distributional supervision and low computational cost, while providing an unbiased estimator of the gradient of the reverse KL divergence. The key insight of TT-OPD is to use not only the selected top-$k$ tokens, but also the sampled token from the student-generated rollout, thereby recovering the discarded probability mass in expectation, avoiding the bias. Experimental results demonstrate that TT-OPD significantly outperforms other tested OPD variants.

# 论文总结：面向在线策略蒸馏的无偏 Top-$k$ 估计（TT-OPD）

## 1. 核心问题与研究动机

- **背景**：在线策略蒸馏（OPD）已成为 LLM 后训练的重要环节，其做法是让学生模型在自己的策略生成的 rollout 上，最小化与教师模型之间的**反向 KL 散度**，从而把强教师的推理能力迁移给弱学生，并缓解离线蒸馏（off-policy）中因训练状态与教师轨迹不匹配造成的**暴露偏差**。
- **核心难题**：反向 KL 散度的**梯度估计**在现代大词表 LLM 上存在"监督丰富度—计算成本—无偏性"的三角权衡：
  - **ST-OPD（采样 token）**：仅用 rollout 中采样到的 token，成本 $O(1)$，梯度无偏，但分布监督极稀疏，精度受限。
  - **FV-OPD（全词表）**：覆盖全部词表，梯度无偏、监督完整，但成本 $O(|V|)$。例如 Qwen3 词表 151,646，每位置需计算 15 万多项，代价不可接受。
  - **TK-OPD（Top-$k$）**：只对选定的 top-$k$ token（学生 top-$k$、教师 top-$k$ 或二者交集）做重归一化后的 KL 计算，成本 $O(k)$，监督较丰富，但因**丢弃了 top-$k$ 之外的概率质量而引入梯度偏差**，导致精度下降。
- **整体含义**：论文试图在保留 TK-OPD 的低成本与丰富监督的同时，消除其偏差，给出一个**既无偏又廉价**的反向 KL 梯度估计器，从而提升 OPD 的蒸馏效果。

## 2. 方法论：TT-OPD（Tail-Corrected Top-$k$ OPD）

- **核心思想**：在 TK-OPD 使用的 top-$k$ 集合 $S_t^k$ 之外，**额外复用学生 rollout 中已采样到的 token $y_t$**。由于 $y_t \sim p_t$（学生完整分布），它在期望意义下能够**回收被丢弃的尾部概率质量**，从而把 TK-OPD 的偏差项补回来。top-$k$ 提供精确的头部贡献，采样 token 提供尾部校正。
- **形式化设定**：状态 $Z_t=(x,y_{<t})$，学生分布 $p_t(v)=\pi_\theta(v|Z_t)$，教师分布 $q_t(v)=\pi_{\text{tea}}(v|Z_t)$；目标是全词表反向 KL 的梯度 $g_t^\star=\nabla_\theta D_{KL}(p_t\|q_t)$。rollout 及访问状态在反向传播中被视为固定，梯度不流经采样过程。
- **逐位置损失（式 1）**：
  $$L_t^{TT}=\sum_{v\in S_t^k}\mathrm{sg}\!\left(\log\tfrac{p_t(v)}{q_t(v)}\right)p_t(v)+\mathbb{1}\{y_t\notin S_t^k\}\,\mathrm{sg}\!\left(\log\tfrac{p_t(y_t)}{q_t(y_t)}\right)\log p_t(y_t)$$
  - 第一项：精确计算 top-$k$ token 对反向 KL 梯度的贡献（stop-gradient 加在 log 比值上）。
  - 第二项：仅当采样 token 落在 $S_t^k$ 之外时启用，作为尾部 $V\setminus S_t^k$ 的单样本估计；若 $y_t\in S_t^k$，该 token 已被第一项覆盖，故省略以免重复计数。
- **理论保证（定理 4.1，证明见附录 A）**：对固定状态 $Z_t$，
  $$\mathbb{E}_{y_t\sim p_t}\left[\nabla_\theta L_t^{TT}(\theta)\,\middle|\,Z_t\right]=g_t^\star$$
  证明思路：将期望展开后，尾部项 $\sum_{v\notin S}p(v)A(v)\nabla_\theta\log p(v)=\sum_{v\notin S}A(v)\nabla_\theta p(v)$，与头部求和合并即得 $\sum_{v\in V}A(v)\nabla_\theta p(v)$，再利用 $\sum_v \nabla_\theta p(v)=\nabla_\theta 1=0$，与 FV-OPD 的梯度表达式完全一致。
- **复杂度**：每位置至多 $O(|S_t^k|+1)=O(k+1)$，与词表规模无关，仅比 TK-OPD 多一次 token 的额外计算。
- **兼容性**：TT-OPD 只替换逐位置的 OPD 损失，可与 rollout 截断/早停类改进（ESR、POPD、TOPD、KAT）及位置重加权类改进（TA-OPD、IW-OPD）叠加使用。

- **Finding 1**：TT-OPD 在两个学生规模上均取得最高平均准确率，较 ST-OPD 提升 4.39/4.72 个百分点，较 TK-OPD 提升 4.34/4.15 个百分点（4B/1.7B），且在所有 7 个基准上均优于两个基线。

- **Finding 5**：在 DeepSeek-R1-Distill-Qwen-7B / Skywork-OR1-Math-7B 组合上，TT-OPD 较 ST-OPD、TK-OPD 分别提升 4.21、2.20 点准确率，跨模型系列稳健。

## 7. 优点

- **方法层面**：
  - 思路极简而有效——只需在已有 rollout 中"顺手复用"一个采样 token，几乎零额外成本即可消除 TK-OPD 的系统性偏差，工程落地门槛低。
  - 提供了严格的期望无偏性证明（附录 A），推导清晰、依赖的假设（采样 token 来自完整学生分布、stop-gradient 处理）与 OPD 的实际训练流程一致。
  - 逐位置替换式设计使其天然与 rollout 截断、位置重加权等其他 OPD 改进正交可组合，具有良好的可扩展性。
- **实验层面**：
  - 多维度验证（学生规模、$k$ 值、top-$k 构造、模型系列、任务类型），并配套给出 pass@$k$、训练时间、消融和逐题案例，证据链较完整。
  - 明确报告了额外计算开销（≈2%），避免了"无偏但昂贵"的常见质疑。
  - 案例研究具体展示了 ST-OPD/TK-OPD 的失败模式（如单位混淆、分支枚举不全、实部计算错误）与 TT-OPD 的纠正过程，增强可解释性。

## 8. 不足与局限

- **对比缺失**：因成本原因完全未与 FV-OPD 实验对比，因此"无偏性带来的收益上限"只能通过理论论证而非实证锚定。
- **理论层面**：
  - 无偏性仅在**固定状态 $Z_t$ 下对采样 token 取期望**成立；实际训练中每 prompt 仅采样一条 rollout，单样本尾部估计的**方差**未被分析，可能出现"无偏但高方差"的风险，论文未给出方差或偏差-方差权衡的讨论。
  - 当 $y_t\in S_t^k$ 时校正项被省略，此时估计器在单步上仍是有偏的（只是期望意义上因该事件本身的分布而整体无偏），这一细节未被展开讨论。
- **实验覆盖**：
  - 模型规模仅覆盖 1.7B–8B 区间，未验证更大规模（如 32B/70B）或 MoE 架构。
  - 代码任务仅用单个学生（Qwen3-4B），且相对增益（0.72 点）远小于数学任务，跨任务泛化性的证据相对薄弱。
  - $k$ 最大只到 64，未探讨 $k$ 接近词表规模或极小（如 $k=1,2$）时的行为。
  - 仅覆盖数学推理与代码生成，未涉及通用对话、长文本、多模态等场景。
- **应用限制**：依赖 OPD 框架中必然存在的采样 token，对无法获得逐位置采样的离线蒸馏场景不适用；教师与学生分布差距过大时，尾部质量可能很大，单样本校正的方差问题可能更突出。
- **其他**：论文声称"首个同时具备三种性质的 OPD 变体"，但该表述依赖于对 ST-OPD"监督不足"、TK-OPD"有偏"的既有定位，属于相对性论断，缺乏对更广文献的系统性排查说明。
