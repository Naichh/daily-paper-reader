## 摘要
语言反馈能够识别错误并给出纠正建议，即使在可靠的程序化验证器不可用时，也能为语言模型后训练提供丰富监督。此类反馈通常由能力较强的模型生成，可用于在在线策略蒸馏中对教师进行条件化，从而训练学生匹配教师在学生生成的 rollout 上的预测。然而，这种方法可能会传递并非由反馈所激发的教师偏好，同时使反馈中的大量指导信息未被利用。我们发现，这两个问题都源于标准的在线策略蒸馏目标，具体而言，源于其所最小化的散度以及其所用作目标的分布。我们提出的方法解决了这两个局限。首先，为了将反馈所传达的信息与教师固有偏好分离，我们将语言反馈视为支持或反对“在给定前缀下下一个 token 为某个特定 token”这一假设的证据。然后，我们采用一个概率确证框架，该框架基于教师在接收反馈前后的预测，唯一地确定词汇表上的一个排序。使用与该排序一致的确证分数，我们在学生的信赖域内构造一个目标分布。其次，为了从学生 rollout 可能未利用的指导中学习，我们推导出一个简单的共享 rollout 估计器，用于估计学生分布与目标分布在 rollout 上的对称散度，并通过重要性加权在两个方向上复用学生 rollout 和经反馈条件化的教师 rollout。实证评估表明，在基于知识的基准和智能体基准上，我们的方法优于常见的在线策略蒸馏方案以及近期的一种对比式变体。

## Abstract
Verbal feedback can identify errors and prescribe corrections, providing rich supervision for language-model post-training even when reliable programmatic verifiers are unavailable. Such feedback, often generated by a capable model, can be used to condition the teacher in on-policy distillation, which trains the student to match the teacher's predictions on student-generated rollouts. However, this approach can transfer teacher preferences that the feedback did not motivate, while leaving much of the feedback's guidance unused. We find that both problems come from the standard on-policy distillation objective, specifically the divergence it minimizes and the distribution it uses as its target. Our proposed method addresses both limitations. First, to isolate the information conveyed by the feedback from the teacher's inherent preferences, we treat verbal feedback as evidence for or against the hypothesis that a particular token comes next at a given prefix. We then adopt a probabilistic confirmation framework which uniquely determines an ordering over the vocabulary based on the teacher's predictions before and after it receives feedback. Using a confirmation score consistent with this ordering, we construct a target distribution within a trust region of the student. Second, to learn from guidance that student rollouts can leave unused, we derive a simple shared-rollout estimator of a symmetric divergence between the student and target distributions over rollouts, reusing student and feedback-conditioned teacher rollouts in both directions through importance weighting. Empirical evaluations show that our method outperforms the common on-policy distillation recipe and a recent contrastive variant on knowledge-based and agentic benchmarks.

## 1. 核心问题与整体含义

- **背景**：RL 后训练语言模型的核心难点是**信用分配**。GRPO 等方法把 rollout 的标量奖励归一化为优势并"级联"到所有 token，会无差别地强化整条高分轨迹中与结果无关的步骤。
- **替代方案**：在线策略蒸馏（OPD）用教师的下一 token 预测构造 token 级优势，可提供更细粒度的监督。其特例是"教师=学生本身，但额外条件化于特权信息"（参考解、执行反馈、语言反馈）。
- **本文关注的监督源**：LLM 评判器（judge）写出的**语言反馈**。当任务缺乏可靠的程序化验证器时，judge 是实用替代；即使有结果奖励，语言反馈也能把轨迹的具体片段与所满足/违反的准则对应起来，保留奖励聚合中丢失的信息。
- **关键问题**：直接把反馈条件化的教师分布当作蒸馏目标，存在两个缺陷：
  - **迁移过多**：教师与学生在措辞、格式等与反馈和任务无关的 token 上差异很大（即使自蒸馏也会因参数平均而产生），直接匹配会把教师既有偏好/局限一并传给学生。
  - **利用不足**：OPD 只在学生实际访问的前缀上取监督；一旦学生轨迹走上不同分支，反馈的**规定性指导（prescriptive guidance）**就失效，只有少数 token 位置承载纠正信号。
- **整体含义**：本文主张这两个问题分别源于标准 OPD 的**所最小化散度**与**所使用目标分布**，并给出针对性修正，为无程序验证器场景下的反馈监督提供新范式。

## 2. 方法论

### 2.1 把反馈视为"证据"：确证分数
- 固定 prompt $x$、学生 rollout $y^s$、前缀 $y_{<t}$，只改变反馈 $F$，定义：
  - 后验 $P_{\text{post}}(v)=\pi_T(v\mid x,y^s,F,y_{<t})$
  - 先验 $P_{\text{prior}}(v)=\pi_T(v\mid x,y^s,y_{<t})$
- 将反馈视为关于假设"下一个 token 是 $v$"的证据，用 **Crupi & Tentori (2013) 部分蕴含框架**的四条公理刻画确证分数：
  - **A0** 概率依赖；**A1** 单调性（固定先验下随后验严格递增）；**A2** 反确证时的比值依赖；**A3** 互补性——token 与其补事件的排序必须反转。
- **定理 1**：满足 A0–A3 的分数当且仅当是**相对距离（relative distance）**的严格递增变换：
  - $d(v)=\dfrac{P_{\text{post}}-P_{\text{prior}}}{1-P_{\text{prior}}}$（概率上升时）
  - $d(v)=\dfrac{P_{\text{post}}-P_{\text{prior}}}{P_{\text{prior}}}$（概率下降时）
  - 取恒等变换得 $S=d\in[-1,1]$，反馈未改变预测时为 0。
- **指出已有方法的缺陷**：log 概率对比 $\log P_{\text{post}}-\log P_{\text{prior}}$ 满足 A0–A2 但**违反 A3**。例如 0.01→0.02 的 token 会被排在 0.40→0.60 的 token 之上（补事件排序相同，而 A3 要求反转）；由于严格递增变换保持排序，重新缩放无法修复。论文用合成三 token 任务（图 1）证明这种违反会导致学生**偏好错误 token**。

### 2.2 锚定学生的纠正目标
- 在学生的**信赖域**内求解 KL 正则化优化：
  $$\pi_{\text{corr}}=\arg\max_{\pi}\ \mathbb{E}_{v\sim\pi}[S(v)]-\tfrac{1}{\beta}\mathrm{KL}(\pi\|\pi_\theta)$$
- 闭式解（对学生概率做乘性重加权）：
  $$\pi_{\text{corr}}(v)=\mathrm{sg}\!\left[\frac{\pi_\theta(v)\,e^{\beta S(v)}}{Z_t}\right],\quad Z_t=\sum_v \pi_\theta(v)e^{\beta S(v)}$$
- **性质**：反馈无指导时（$P_{\text{post}}=P_{\text{prior}}$，$S\equiv0$）目标等于学生本身，该前缀无梯度；每个 token 的重加权被限制在 $[e^{-2\beta},e^{2\beta}]$；在 reverse KL 下等价于有界 token 优势 $\beta(S(v)-\mathbb{E}_{\pi_\theta}[S])$。

### 2.3 共享 rollout 的对称目标
- 用 **Jeffreys 散度**组合两个方向：reverse 项在学生访问的前缀上监督（保留 OPD），forward 项在纠正策略生成的前缀上监督（学到学生尚不能稳定生成的延续）。
- **共享 rollout 估计器**：每个 rollout 以概率 $\lambda$ 来自学生、以 $1-\lambda$ 来自 $\pi_{\text{corr}}$，混合分布 $m=\lambda\pi_\theta+(1-\lambda)\pi_{\text{corr}}$；用重要性权重回收各方向所需的前缀分布：
  - $w_{\text{rev}}(y_{<t})=\pi_\theta(y_{<t})/m(y_{<t})\le 1/\lambda$
  - $w_{\text{fwd}}(y_{<t})=\pi_{\text{corr}}(y_{<t})/m(y_{<t})\le 1/(1-\lambda)$
- **理论保证**（附录 B.3）：重要性比天然有界，避免直接比值可能出现的极大权重；给出半梯度方差上界；共享 rollout 的渐近有效样本量分数 $\rho_q\ge\lambda,\ \rho_p\ge1-\lambda$，只要学生与目标前缀分布有重叠（$\kappa>0$）就严格优于分开采样。
