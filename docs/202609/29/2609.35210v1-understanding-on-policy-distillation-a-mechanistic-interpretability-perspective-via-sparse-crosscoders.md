## 摘要
同策略蒸馏（OPD）是一种被广泛采用的、面向大语言模型推理的后训练技术。人们通常认为它从更强的教师模型中迁移知识，但 OPD 究竟向学生模型的内部表征中蒸馏了什么仍不清楚。我们使用稀疏交叉编码器（sparse crosscoders）来研究这一问题；该编码器学习一个由 OPD 前后的学生模型和教师模型共享的特征字典。然而，标准交叉编码器分析能识别模型特有的特征，却无法说明模型对其特征的使用如何变化，因为所有模型都被编码到同一组特征激活中。因此，我们提出交换读出（swap readout），它独立地读取每个学生检查点的特征激活，从而衡量训练如何改变学生对每个特征的使用，即使对于交叉编码器未见过的检查点也是如此。在三种 OPD 设置下，我们发现 OPD 既不创造特征，也不传递教师自身的特征，并且使学生频繁使用的特征中超过 98% 的发放率变化保持在 20% 以内。我们进一步考察 SFT 预热：它通常先于 OPD，在教师模型的 rollout 上进行，并使 OPD 更有效。预热并非添加特征，而是以两种方式对共享特征重新加权。首先，它已经提高和降低了许多 OPD 之后会提高和降低的特征，从而提前完成了 OPD 的部分工作。其次，它会改变仅靠 OPD 不会改变的特征，尤其是对话格式、推理风格和数学符号相关的特征，而且这些改变会贯穿 OPD 持续存在。将这种重新加权施加到直接蒸馏得到的学生模型的特征上（不改变其权重），可使其准确率接近经过预热的学生模型，而对打乱后的特征施加相同改变则不能。总之，这些发现表明，OPD 是对已有特征重新加权，而不是获得新特征：学生模型从教师模型那里学会如何使用它们已经共享的特征。

## Abstract
On-policy distillation (OPD) is a widely adopted post-training technique for LLM reasoning. It is commonly believed to transfer knowledge from a stronger teacher, yet what OPD actually distills into the student's internal representations remains unclear. We study this question with sparse crosscoders, which learn one feature dictionary shared by the student before and after OPD and the teacher. Standard crosscoder analyses, however, identify model-specific features but cannot tell how a model's use of its features changes, since all models are encoded into one set of feature activations. We therefore propose the swap readout, which reads each student checkpoint's feature activations on its own, measuring how training changes the student's use of each feature, even for checkpoints unseen by the crosscoder. Across three OPD settings, we find that OPD neither creates features nor passes on the teacher's own, and leaves the firing rates of over 98% of the student's frequently used features within 20%. We further examine the SFT warm-up on the teacher's rollouts that commonly precedes OPD and makes it more effective. Rather than adding features, the warm-up reweights the shared ones in two ways. First, it already raises and lowers many of the features that OPD later raises and lowers, doing part of OPD's work in advance. Second, it changes features that OPD alone would not, notably those for conversation format, reasoning style, and mathematical notation, and these changes persist through OPD. Imposing this reweighting on a directly distilled student's features, without changing its weights, brings its accuracy close to that of the warmed-up student, whereas the same change on shuffled features does not. Together, these findings suggest that OPD reweights existing features rather than acquiring new ones: the student learns from the teacher how to use the features they already share.

## 1. 核心问题与研究动机

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）已成为 LLM 推理模型后训练的标准范式，被 Qwen3、MiMo-V2-Flash、GLM-5、Kimi K3 等采用。其做法是让学生模型自己生成 rollout，教师模型对每个 token 打分（密集监督），以缓解固定示范带来的 exposure bias。
- **核心问题**：OPD 究竟把什么"蒸馏"进了学生的内部表征？是学生**获得了新能力/新特征**，还是只是**学会了以不同方式使用已有特征**？
- **现有研究的缺口**：
  - 已有分析（Li et al. 2026；Ding & Zhang 2026；Ge et al. 2026）只从**输出层面**（token 概率、准确率、训练信号）研究 OPD，看不到学生内部发生了什么。
  - 实证证据本身是矛盾的：OPD 有时不提升甚至损害学生；它主要改善**采样效率**而非扩展**能力边界**；只在师生"思维模式兼容"时才有效。
- **整体含义**：作者主张把 OPD 从"知识迁移"叙事改写为"**已有特征的重加权**"叙事，并由此解释上述行为学现象，同时为"为什么需要 SFT 预热"提供表征层面的机制说明。

## 2. 方法论

### 2.1 基础工具：稀疏交叉编码器（Sparse Crosscoders）
- 为多个模型（学生训练前 B、学生训练后 O、教师 T）学习**同一个特征字典**，联合编码为单一稀疏码 z，各模型用自己的解码器重建激活：
  - 编码：`z = σ(Σ_m W_m h_m + b)`，重建：`ĥ_m = D_m z`
  - 每个特征在所有模型共享一个激活值，但在每个模型有一个独立的解码方向（D_m 的对应列）。
- 使用 **BatchTopK**（而非 ℓ1）保证稀疏性，避免 ℓ1 伪影让共享特征看起来像模型专属。
- **模型归属度（MAS）**：用特征在各模型解码范数中的占比衡量归属，`MAS(m,j) = ‖d_mj‖₁/√n_m ÷ Σ_m' ‖d_m'j‖₁/√n_m'`；MAS > 0.5 视为该模型"支配"该特征。两模型无宽度修正时即 Shi et al. (2026) 的 NRN（1=专属后一模型，0=专属前一模型，1/2=共享）。

### 2.2 关键创新：Swap Readout（交换读出）
- **为什么现有读出方式不行**：
  - 联合编码给三个模型**同一个码**，无法判断是哪个模型让特征发放。
  - 解码器归属（MAS）在两个学生之间几乎无差别（两者激活方向几乎重合），而训练改变的恰恰是**何时使用**特征。
  - "自家槽位"读出（只放一个学生的激活）不可靠：两个学生的激活只差 7–12% 的范数，训练只能确定编码器之和 `S = W_B + W_O`，而差 `N = (W_B − W_O)/2` 基本停留在随机初始化水平，导致未确定项与已确定项量级相当。
- **做法**：把某个学生检查点 s 的激活（按训练前学生平均范数重新缩放）**同时放入两个学生槽位**，教师激活固定：
  - `z_s(x) = enc(h̄_s(x), h̄_s(x), h_T(x))`
  - 预激活 `a_s(x) = S h̄_s(x) + c(x)`，其中 `c(x) = W_T h_T(x) + b`
  - 两个检查点之差 `a_s′(x) − a_s(x) = S(h̄_s′ − h̄_s)`，教师项与未确定项 N 全部抵消。
- **理论保证（Proposition 1）**：交换读出对 `(W_B + E, W_O − E)` 不变；在形如 `λW_B h̄ + μW_O h̄ + c` 的读出中，它是**唯一**既具此不变性、又当两学生激活相等时与联合预激活一致的读出（要求 λ = μ、λ + μ = 2）。因此交叉编码器等效于一个"以 S 为编码器、以学生解码器为解码器、偏置由教师逐 token 设定"的稀疏自编码器。
- **可靠性**：输入与训练分布接近（两槽一致）；重建质量与联合编码相当，且对**未见过**的检查点（如 SFT 预热后的学生）同样有效。
- **特征统计**：在 300 万 held-out token 上计算发放率、log₂ 比值变化；一个特征在某检查点发放 ≥10 次而另一检查点从不发放则记为"获得/丢失"；每 token 变化用前后活跃特征集合的 Jaccard 差异度量。

### 2.3 辅助分析方法
- **决策 token 分类**：反思类（Wait / wait / actually）、犹豫类（Hmm / maybe / perhaps / Alternatively）、推进类（So / Therefore / Hence / Now / Let / Similarly）。若一个特征最强发放的 12 个位置中 ≥6 个落在决策 token 上，即判为决策 token 特征。
- **预热重加权的分解**：对每个特征构造相对基座学生的 log₂ 发放率变化向量：OPD 的 o、预热的 s、预热+OPD 的 u；用最小二乘过原点拟合 `s ≈ βo`，β 表示预热沿 OPD 方向的移动幅度；残差 `s − βo` 为正交于 OPD 方向的部分。控制实验：将预热变化旋转到随机正交方向（β ≈ −0.03）、同范数高斯噪声、以及在不相交 shard 上分别测量 s 和 o。
- **特征级干预（因果验证）**：在交叉编码器所读层（block 14），逐 token 计算 `Δh = D_O(z_S − z_B)/s_O`，加到直接蒸馏学生的残差流上（或从预热学生的残差流中减去），权重不变；打乱对照为对 `z_S − z_B` 做固定随机置换后再解码。

## 6. 主要结论与发现

- **OPD 不创造新特征，也不传递教师专属特征**：三种设置下 OPD 学生未支配任何一个特征，MAS 分布与基座学生重合；教师专属特征（Skywork 42 个、R1-7B 30 个）在 OPD 前后学生占比均为 0.19，MAS 变化不超过 0.015。
- **OPD 只做小幅重加权**：98.2% / 99.6% / 99.4% 的常用特征发放率变化在 ±20% 以内；没有特征"获得"或"丢失"；平均每 token 约 8–12% 的活跃特征发生变化。
- **最大变化集中在决策 token**：在 JustRL 下，变化最大的 50 个特征中 12% 是决策 token 特征（全体特征中仅 0.4%）；如 Wait 特征 −35%、So/Therefore 特征 −35%、maybe/perhaps 特征 +42%，且方向与教师一致（教师对应为 −34%、−36%、+52%）。这些位置也正是教师与学生分歧最大之处（KL 为平均步的 1.5–3.6 倍）。
- **SFT 预热同样不增加特征**：在教师自身 rollout 上预热，既不产生学生专属特征（NRN 仍接近 1/2），也不把教师特征变为共享（教师 NRN 均值 0.42 不变，教师专属特征数 24→25）。这与 Shi et al. (2026) 观察到的"SFT 引入新特征"不同——因为该预热在同一任务、同一教师的 rollout 上进行。
- **预热的作用是"提前 + 额外"重加权**：预热沿 OPD 方向移动约一半距离（β = 0.46），OPD 提升最多的 50 个特征中 88% 在预热后同向移动；同时 56%（含一个网络文本乱码特征时 77%）的变化位于 OPD 方向之外，且这部分在后续 OPD 中**持续存在**（Spearman 0.69），主要涉及对话格式（系统提示、答案格式指令、轮次边界）、推理风格（Wait/Alternatively/But 减少、分步列计划增加）与数学记号。
- **因果验证**：把

把 OPD 相对基座学生的特征变化 `Δh = D_O(z_S − z_B)/s_O` 逐 token 加回"直接蒸馏学生"的残差流，可在**不改变任何权重**的前提下提升其表现；反向地，从"预热学生"的残差流中减去同一变化量会使其表现下降。两个方向的效应量均约为 ±2.7 分，且带 95% bootstrap 区间；而对 `z_S − z_B` 做固定随机置换后再解码的打乱对照几乎不产生系统性变化。这说明被重加权的特征集合与 OPD 的收益之间存在**因果性**联系，而非仅相关。

- **教师信号只集中在少数位置**：教师对学生的密集监督并非均匀分布，最大的 KL 分歧集中在决策 token 上，且学生变化最大的特征恰好落在这些位置——即 OPD 的学习信号在空间上是**高度稀疏且定向**的。
- **综合结论**：OPD 与 SFT 预热都**没有扩展学生的特征字典**，也没有把教师专属特征搬运给学生；两者共同做的事情是**重新调整已有特征的使用时机与强度**，且这种调整优先作用于师生分歧最大的决策节点。因此 OPD 的行为学表现（改善采样效率、难以突破能力边界、只在思维模式兼容时有效）可以在表征层面得到统一解释。

## 7. 讨论与理论意义

- **叙事改写**：论文把 OPD 从"知识/能力迁移"重新表述为"**已有特征的重加权**"。这与"OPD 主要提升 pass@k 的采样效率、而非 pass@1 的能力上限"这一经验观察一致：如果学生的特征字典已经覆盖了解题所需的概念，那么优化"何时调用哪个特征"就能在多次采样中更容易命中正确路径，但无法产生原本不存在的推理原子。
- **对"师生兼容性"的解释**：当教师与学生的思维模式差异过大时，教师偏好的特征使用模式可能并不在学生的可用特征集合中，或需要与学生的既有模式冲突，此时重加权无法生效甚至有害；只有当两者共享足够的特征支撑时，OPD 才能通过重分配获得收益。
- **对"SFT 预热必要性"的解释**：预热的作用不是灌输新能力，而是把学生沿 OPD 将要走的方向**先移动约一半距离**（β = 0.46），使后续 OPD 的优化起点更接近教师的目标使用模式；同时预热还引入了约一半位于 OPD 方向之外的变化（对话格式、推理风格、数学记号），这部分在后续 OPD 中**持续保留**（Spearman 0.69），说明预热的贡献是"提前对齐 + 补充格式/风格先验"的双重作用，而非单纯的正则或初始化。
- **对可解释性方法论的贡献**：Swap Readout 是一个可推广的工具——当需要比较同一模型的两个极接近检查点时，联合编码 + 解码器归属都失效，而通过强制两个槽位输入一致、让编码器只依赖"和"方向 `S = W_B + W_O`，可以构造出对未确定方向 `N` 不变的读出，从而稳定地追踪训练带来的特征使用变化。

## 8. 局限性

- **单一位点与单字典**：所有特征分析都取自中间层的一个残差流位置，交叉编码器固定为 32768 特征、BatchTopK k=50；未做层间扫描或字典超参（宽度、稀疏度、是否用 JumpReLU 等）的敏感性分析，因此"无新特征"的结论在多大程度上依赖该配置尚不清楚。
- **弱信号设置难以解释**：R1-7B 设置中教师对学生的 KL 仅 0.008，OPD 几乎未改变学生，此时的"无变化"既可能是机制本身，也可能是监督信号过弱，二者无法区分。
- **规模受限**：学生仅 1.5B/1.7B、教师 1.5B–7B，结论能否外推到数十亿至数百亿参数、以及非数学推理任务（代码、agent、多轮对话）尚未验证。
- **特征语义依赖人工判读**：决策 token 分类基于关键词表与"top-12 位置中 ≥6 个命中"的启发式阈值，特征的功能标签（如"Wait 特征""数学记号特征"）带有主观性，且未做多标注者一致性检验。
- **因果干预的粒度**：干预是在 token 级一次性注入整组特征变化，无法分离单个特征各自的因果贡献，也未检验注入是否引入了分布外激活导致的副作用。
- **算力信息缺失**：如前所述，论文未报告硬件与总计算开销，削弱了成本可复现性。

## 9. 启发与可延伸方向

- **训练策略**：既然 OPD 主要做重加权，那么"先在小规模、同分布数据上预热以对齐特征使用模式，再用 OPD 精调"可能比直接 OPD 更高效；反之，若目标是扩展能力边界，则需依赖能引入新特征的信号（如多样化的 SFT 数据），而非仅靠教师打分。
- **监控指标**：特征级重加权幅度、决策 token 上的 KL 分歧、以及"预热方向与 OPD 方向的对齐系数 β"可以作为训练前的可诊断指标，用于预测 OPD 是否值得投入。
- **方法学延伸**：Swap Readout 可推广到"同一模型的不同训练阶段""不同随机种子""微调前后的对齐/安全漂移"等场景，用于追踪表征使用而非表征内容的演化。
- **开放问题**：是否存在使 OPD 真正引入新特征的条件（如教师与学生差距极大、任务分布外、或多教师混合）？重加权的幅度是否存在随模型规模变化的标度律？这些都有待进一步研究。
