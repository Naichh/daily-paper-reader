## 摘要
基于反馈的在线策略自蒸馏已成为一种有前景的方法，使基础模型（更具体地说，大语言模型，LLMs）能够在外部反馈下从自身输出中学习，并由单个模型同时充当教师和学生。然而，此类方法可能表现出不稳定的优化，容易在训练过程中导致性能崩溃。为解决这一局限，我们提出FIRE（Fisher信息引导的重校准，Fisher-Informed REcalibration），这是一个双分支框架，在微调期间重校准施加于正确和错误在线策略输出上的监督。对于正确回答，FIRE用重新加权的在线策略SFT替代自蒸馏；对于错误回答，FIRE识别出对教师诱导更新影响过大的反馈成分，并据此重校准以反馈为条件的目标。两个分支均受一个token级半径影响，该半径部分源自softmax Fisher迹。FIRE将反馈应使模型移动的方向与模型在该方向上应移动的幅度分离开来，同时保持表现良好的反馈监督不变。我们的实验表明，FIRE能够显著更稳定地进行自蒸馏，同时保持强劲的下游性能，尤其是在标准反馈条件蒸馏变得不稳定的场景中。

## Abstract
Feedback-based on-policy self-distillation has emerged as a promising approach for enabling foundation models, more specifically Large Language Models (LLMs), to learn from their own outputs under external feedback, with a single model serving as both teacher and student. However, such methods can exhibit unstable optimization, conducive to performance collapse during training. To address this limitation, we propose FIRE (Fisher-Informed REcalibration), a dual-branch framework that recalibrates the supervision applied to correct and incorrect on-policy outputs during fine-tuning. For correct responses, FIRE replaces self-distillation with re-weighted on-policy SFT, while for incorrect ones FIRE identifies feedback components that disproportionately influence the teacher-induced update and recalibrates the feedback-conditioned target accordingly. Both branches are influenced by a token-level radius derived in part from a softmax Fisher trace. FIRE separates which direction feedback should move the model from how far the model should move in that direction, while leaving well-behaved feedback supervision unchanged. Our experiments demonstrate that FIRE provides substantially more stable self-distillation while maintaining strong downstream performance, particularly in settings where standard feedback-conditioned distillation becomes unstable.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基于反馈的在线策略自蒸馏（feedback-based on-policy self-distillation）让同一个 LLM 同时充当教师和学生：学生先采样回答，再接收外部反馈（如用户交互、验证器结果），并以“反馈条件化”的模型作为教师，通过反向 KL 蒸馏更新学生。
- **核心问题**：这类方法优化不稳定，容易在训练中性能崩溃。具体表现为：
  - 对已经正确的回答继续做自蒸馏可能不必要，甚至引入发散；
  - 对错误回答盲目匹配反馈条件化教师，可能产生过大且方向不佳的更新；
  - 标准 KL 自蒸馏把整个反馈上下文当作不可置疑的监督，无法判断哪个反馈成分过度驱动了更新；
  - 教师—学生差异会因学生局部不确定性和学习率而显著影响优化。
- **整体含义**：需要区分正确与错误轨迹，并根据学生局部预测几何约束反馈诱导的更新，同时保留本来良性的反馈监督。FIRE 正是为此提出的双分支重校准框架。

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：将“反馈应把模型往哪个方向推”与“允许推多远”分离。正确回答走 Fisher 信息重加权的在线 SFT；错误回答保留反馈条件化自蒸馏，但先做反馈字段归因，再用 token 级 Fisher 半径做径向投影。两个分支共享同一学生依赖的梯度半径。
- **基础设置**：学生 π_θk 采样在线回答 y；EMA 教师 π_θ̄k 在相同 y 前缀上、以反馈 c 为条件给出教师分布 q_t^{c,k}，无需额外自回归 rollout。标准损失为反向 KL。
- **步骤 1：结果路由与教师视图**
  - 验证器 ω(y) ∈ {0,1} 判断初始回答是否正确。
  - 正确回答：不做反馈条件化蒸馏，改做 Fisher 重加权在线 SFT。
  - 错误回答：反馈表示为字段 c=(b₁,…,b_B)，构造“留一反馈字段”反事实教师 q_t^{-j}（去掉 b_j）。
- **步骤 2：正确分支训练**
  - 标准在线 SFT 梯度 g_t^+ = p_t − e_{y_t}。
  - 重加权系数 β_t = min(1, ρ_t^k / ‖g_t^+‖₂)，损失 ℓ_t^+ = −sg[β_t] log p_θ(y_t)。
  - 效果：梯度范数被限制在 min(‖g_t^+‖₂, ρ_t^k)，方向不变；当更新已在半径内时等价于普通在线 SFT。
- **步骤 3：错误分支训练**
  - 定义教师分布诱导的学生 logit 梯度 g_t(q_t)=∇_{z_t} KL(softmax(z_t)‖q_t)。
  - 计算全反馈梯度能量 E_t^c=‖g_t^c‖₂² 和字段影响能量 E_t^j=‖g_t^c−g_t^{-j}‖₂²。
  - 超额能量门 χ_t：若 E_t^c ≤ (ρ_t^k)²，χ_t=0，完全保留全反馈教师；否则 χ_t=(E_t^c−(ρ_t^k)²)/E_t^c，字段权重 w_t^j=χ_t E_t^j。
  - 归一化：Z_t=(ρ_t^k)²+Σ_j w_t^j，α_t^0=(ρ_t^k)²/Z_t，α_t^j=w_t^j/Z_t。
  - 构造归因感知教师 q_t^A 为全反馈教师与各留一视图的几何平均（指数为 α），使 log 概率线性组合，对应反向 KL logit 梯度的精确加权平均。
  - 径向收缩系数 η_t=min(1, ρ_t^k/‖g_t(q_t^A)‖₂)，再在 p_t 与 q_t^A 间做几何插值得到 q_t^{FIRE}，保证最终梯度范数为 min(‖g_t^A‖₂, ρ_t^k)。
- **Fisher 半径**：ρ_t^k = √(1−‖p_t‖₂²) / max(1, a_k/a₀)。分子为 softmax Fisher 迹的平方根，反映学生预测的分散程度；分母在学习率高于名义率 a₀ 时收缩半径。a₀ 是唯一新增超参。
- **最终损失**：按样本路由，正确样本用重加权 SFT，错误样本用 KL(p_t‖sg[q_t^{FIRE}])；两分支梯度均被同一 ρ_t^k 约束。

## 3. 实验设计：数据集、Benchmark 与对比方法

- **模型**：
  - Qwen2.5-1.5B-Instruct、Qwen2.5-3B-Instruct 为主实验；

- **数据集 / 场景**：
  - 1.5B：GSM8K、ASDiv、AQuA-RAT（数学与推理）；

  - 14B：MMLU-Pro 的六个类别（生物、化学、计算机、经济、工程、物理）。
- **Benchmark 指标**：最终准确率；训练稳定性指标包括裁剪前梯度范数、每步自回归生成 token 数、累计生成 token vs 准确率、训练墙钟时间 vs 准确率。
- **对比方法（8 个）**：

## 6. 主要结论与发现

- **准确率**：FIRE 在 1.5B、3B 和 14B 上均取得最高或最强的平均性能。例如 1.5B 平均 66.96%，3B 平均 73.03%，14B MMLU-Pro 总体 55.56%。
- **优化稳定性**：FIRE 在多数设置下裁剪前梯度范数更平稳、幅度更低；部分基线（Veto、DemoPSD、Full Context、TOP-D 等）出现剧烈振荡或量级超过 100 的梯度。
- **响应长度稳定性**：FIRE 对“生成 token 数骤降”的响应崩溃具有更强抵抗力；多个基线在训练中出现持续长度坍塌。
- **效率—准确率权衡**：FIRE 在累计生成 token 和墙钟时间两个维度上均取得最佳或接近最佳的权衡，尽管留一字段反事实带来 O(B) 开销。
- **消融结论**：移除归因、移除径向投影、或改用硬梯度切除，平均性能均下降，说明三个组件均有贡献。
- **学习率鲁棒性**：在 0.5× 到 4× 学习率范围内，FIRE 能防止崩溃并保持可接受性能；梯度范数多数低于裁剪阈值。

## 7. 优点

- **问题切入精准**：明确区分正确与错误轨迹的监督需求，避免对正确样本做不必要的蒸馏，同时只在错误样本上使用反馈。
- **方向与步长解耦**：反馈字段归因决定“往哪走”，Fisher 半径决定“走多远”，逻辑清晰且可解释。
- **理论支撑完整**：附录给出反向 KL logit 梯度、Fisher 迹与学习率标定、正确分支梯度投影、留一字段精确影响、错误分支径向投影等推导，并证明两分支共享统一上界。
- **保留良性监督**：当全反馈教师诱导的更新已在半径内时，FIRE 不做任何修改，避免过度干预。
- **超参少**：除名义率 a₀ 外无额外超参，工程友好。
- **实验维度丰富**：同时评估准确率、梯度稳定性、生成长度、时间/ token 效率，并覆盖三个模型规模，结论较有说服力。

## 8. 不足与局限

- **计算与内存开销**：错误样本需 B 次留一字段教师前向；反馈字段数很大时 O(B) 开销可能成为瓶颈。作者在结论中也将“更高效地表征留一字段反事实”列为未来工作。
- **几何平均的支持集问题**：q_t^A 采用几何平均，若任一活跃教师视图对某 token 赋零概率，log q_t^A 会发散；实际需对教师 log 概率设下限，此时理论恒等式仅近似成立。
- **约束范围有限**：Fisher 半径只约束 token 级输出 logit 梯度，不直接约束完整参数更新、下一 token KL 或全局收敛；后者还受 Jacobian、优化器预条件、动量、梯度累积和参数梯度裁剪影响。
- **实验覆盖**：仅在 Qwen2.5 系列上验证；任务以数学推理和选择题为主，缺少开放生成、长文本、多轮对话等场景；评估使用测试子集，未报告完整测试集结果。
- **对比公平性**：部分基线（TOP-D、TrOPD、Veto）面向常规教师—学生在线蒸馏，而非反馈式自蒸馏；微批次和梯度累积因资源约束不同，可能影响墙钟时间比较。
- **超参依赖**：a₀ 仍需按数据集/模型设定；学习率过高时性能仍会下降，只是避免崩溃。
