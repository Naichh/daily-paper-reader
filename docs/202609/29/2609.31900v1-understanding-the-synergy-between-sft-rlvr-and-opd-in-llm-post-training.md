## 摘要
现代 LLM 后训练将监督微调（SFT）、可验证奖励强化学习（RLVR）和同策略蒸馏（OPD）组合成多阶段流水线，然而这些阶段通常被孤立地设计和评估。我们表明，这种组合具有重要影响：一个能提升当前模型的阶段，可能会降低下一阶段的有效性。通过对 Qwen3 模型在数学与科学推理上的受控实验，我们首先在九个学生-教师模型对（参数量比从 2 倍到 53 倍不等）上刻画 OPD，并表明 OPD 的有效性取决于学生与教师的兼容性，而非仅取决于教师规模。OPD 的周边阶段以三种方式重塑这种兼容性：（1）简短的 SFT 预热能改善后续 OPD，而经过 RLVR 强化的学生在同一教师蒸馏下反而出现退化。（2）用 RLVR 对教师进行适配，会提升下游 OPD 准确率，提升幅度与其所增加的能力成正比。在上述两种干预之后，我们发现，仅将教师适配与学生预热相结合（作为额外的预备训练），在相同蒸馏步数下，就能将平均 OPD 准确率从 29.2% 提升到 43.8%（相对提升 50%）。（3）在准确率相当的情况下，OPD 为下游 RLVR 留下的初始化比 SFT 更强，且随着 RL 计算规模扩大，这一差距还会扩大。我们的结果表明，每个后训练阶段的选择不应仅依据其增加的能力，还应依据其为下一阶段创造的学习接口。

## Abstract
Modern LLM post-training composes supervised fine-tuning (SFT), reinforcement learning with verifiable rewards (RLVR), and on-policy distillation (OPD) into multi-stage pipelines, yet these stages are typically designed and evaluated in isolation. We show that this composition is consequential: a stage that improves the current model can make the next stage less effective. Through controlled experiments with Qwen3 models on math and science reasoning, we first characterize OPD across nine student-teacher pairs spanning 2x to 53x parameter ratios and show that OPD effectiveness depends on student-teacher compatibility rather than teacher scale alone. The surrounding stages of OPD reshape this compatibility in three ways: (1) A brief SFT warm-up improves subsequent OPD, while an RLVR-strengthened student regresses under distillation from the same teacher. (2) Adapting the teacher with RLVR raises downstream OPD accuracy in proportion to the capability it adds. Following these two interventions, we find that combining teacher adaptation and student warm-up alone raise average OPD accuracy from 29.2\% to 43.8\% (50\% relative improvement) after the same number of distillation steps, with additional preparatory training. (3) At comparable accuracy, OPD leaves a stronger initialization for downstream RLVR than SFT, with a gap that widens as RL compute scales. Our results suggest that each post-training stage should be chosen not only for the capability it adds, but for the learning interface it creates for the next stage.

# 论文总结：理解 LLM 后训练中 SFT、RLVR 与 OPD 的协同效应

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：当前大模型后训练（post-training）普遍把三类目标串成多阶段流水线：
  - **SFT**：在专家/固定轨迹上做稠密 token 级交叉熵监督（off-policy）；
  - **RLVR**：用可验证结果奖励在模型自生成轨迹上做稀疏结果监督（on-policy，采用 GRPO）；
  - **OPD**：在模型自生成轨迹上做稠密 token 级教师监督（on-policy，reverse-KL 蒸馏）。
- **核心问题（composition problem）**：这些阶段通常被孤立设计、孤立评估，但前一阶段会重塑后一阶段接收到的策略状态。因此**一个提升当前模型的阶段，可能同时让下一阶段变得更低效**。
- **整体含义**：论文主张后训练更新本质上是**非交换**的（示意为 U_B(U_A(π)) ≠ U_A(U_B(π))），并据此提出中心原则——**评估一个阶段不能只看它增加了什么能力，还要看它为下一阶段留下了什么样的"学习接口"（learning interface）**。
- **研究定位**：不是提出新算法，而是给出一张受控的"阶段交互地图"，并用 9 组师生对（2×–53× 参数比）刻画 OPD 在孤立条件下的动力学，再系统研究 SFT/RLVR/OPD 的组合效应。

## 2. 方法论

### 2.1 核心思想
- 采用**受控实验**：每次只改变一个部件（学生状态、教师状态、阶段顺序），其余数据、优化配置与评测协议全部固定，从而隔离单个阶段的影响。
- 先刻画 OPD 在孤立条件下的有效性问题（§3），再研究周边阶段如何重塑师生兼容性（§4），最后给出组合配方（§5）。

### 2.2 三种目标的数学形式（文字说明）
- **SFT**：最小化固定数据集上的 token 级交叉熵 L_SFT = −E[Σ_t log π_θ(y_t|x, y_<t)]，监督 off-policy。
- **RLVR**：GRPO 采样 G 条回答，组内归一化优势 Â_i = (r(x,y^(i)) − μ_group)/σ_group，同一标量优势共享给该轨迹所有 token；监督 on-policy 但稀疏。
- **OPD**：在每个前缀最小化学生 p_t 与教师 q_t 的 reverse KL，L_OPD = E[ (1/|y|) Σ_t D_KL(p_t‖q_t) ]。默认实现用**采样 token 的策略梯度估计器**：定义教师优势 A_t = sg[log π_T(y_t|h_t) − log π_S^old(y_t|h_t)]，用与 RLVR 相同的裁剪重要性比目标优化；A_t > 0 表示强化教师更偏好的 token，A_t < 0 表示抑制但**不指明替代项**。
- **鲁棒性变体**：另评估 dense top-k **forward KL** 目标 L_FKL^(k)，匹配教师 top-k 分布，用来验证结论不依赖于 reverse-KL 估计器。

### 2.3 三个关键度量（表征"迁移"）
- **蒸馏有效性 DE** = (A_S′ − A_S)/(A_T − A_S)：学生回收了多少师生能力差距，1 − DE 为未回收比例；避免不同起点学生的原始增益不可比。
- **可强化比例 ρ+0**：初始化时（未做任何参数更新）学生采样 token 中教师优势为正的比例，即教师"强化而非抑制"学生自身行为的比例；**只需一次打分、无需训练**，作为兼容性的初始化诊断量。
- **归一化 reverse KL κ_s**：在学生实际访问状态上度量师生距离，κ_s = d_rKL(s)/d_rKL(0)，用于追踪 on-policy 训练动力学。

### 2.4 三类干预（算法流程）
- **学生预热**：对比 (i) 在教师生成的正确轨迹上做 SFT（让学生靠近教师）与 (ii) 在目标域做 RLVR（独立提升学生）；并扫描 SFT 步数 K ∈ {25, 75, 150, 250, 348}。
- **教师适配**：对比 (i) 用 RLVR 提升教师（on-policy、可验证结果奖励）与 (ii) STaR 式自训练 SFT（模仿自己已验证的解），取 K ∈ {50, 100, 150, 200}（RLVR 另加 250），再用各自 checkpoint 蒸馏同一个学生。
- **阶段顺序**：比较"OPD→RLVR"与"SFT→RLVR"两条准备流水线，检验 OPD 是否比 SFT 留下更好的 RLVR 初始化。
- **组合配方**：先用 RLVR 适配教师（K=200）→ 用 SFT 简短预热学生（K=75）→ 用 OPD 蒸馏 → 交给下游 RLVR。
