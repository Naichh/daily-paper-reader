## 摘要
多教师在线策略蒸馏（MOPD）通过在学生生成的样本上蒸馏多个独立开发的领域教师的预测，将其结合到单个学生中。我们研究了一种设置：教师共享一个参考模型，但经历不同的后训练过程，并发现 MOPD 可能难以恢复某些教师能力。由于蒸馏发生在学生生成的前缀上，学生初始化会强烈影响后续恢复。然而，初始基准性能并不能可靠地预测良好的 MOPD 初始化。例如，合并初始化可能一开始低于 SFT 预热，但在 MOPD 后最终更高。我们进一步发现，有效合并既取决于教师的相对贡献，也取决于整体合并尺度，一些强配置位于凸参数平均的单纯形之外。因此，选择良好的合并初始化不仅需要评估其即时性能，还需要评估其在 MOPD 下所促成的学习，这使得一次性系数搜索变得困难。我们提出用于 MOPD 的迭代合并（IM-MOPD），它从均匀合并开始，并在蒸馏过程中逐步为恢复不足的领域添加任务向量增量。在 5 领域设置中，IM-MOPD 比采用均匀合并初始化或 SFT 预热的 MOPD 取得更高的平均归一化恢复，表明有效的教师贡献可以在训练过程中逐步确定。

## Abstract
Multi-teacher on-policy distillation (MOPD) combines independently developed domain teachers into a single student by distilling their predictions on student-generated samples. We study a setting where teachers share a reference model but undergo different post-training procedures, and find that MOPD can struggle to recover some teacher capabilities. Because distillation occurs on student-generated prefixes, the student initialization can strongly affect subsequent recovery. However, initial benchmark performance is not a reliable predictor of a good MOPD initialization. For example, merge initialization can start below SFT warm-up yet finish higher after MOPD. We further find that effective merging depends on both the relative teacher contributions and the overall merge scale, with some strong configurations lying outside the simplex of convex parameter averaging. Thus, selecting a good merge initialization requires evaluating not only its immediate performance but also the learning it enables under MOPD, making one-shot coefficient search difficult. We propose Iterative Merging for MOPD (IM-MOPD), which starts from a uniform merge and progressively adds task-vector increments for under-recovered domains during distillation. In a 5-domain setting, IM-MOPD achieves higher average normalized recovery than MOPD with either uniform merge initialization or SFT warm-up, showing that effective teacher contributions can be determined progressively during training.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：构建统一语言模型需要整合通过不同数据和训练流程获得的能力。不同领域往往受益于不同的后训练范式（SFT、RL、RLVR 等），这些专家模型可能在不同时间线独立开发，因此催生了"独立专精 + 后续整合"的模块化工作流。
- **核心问题**：多教师在线策略蒸馏（MOPD）通过在学生生成的样本上蒸馏多个领域教师的预测，将独立开发的领域教师整合到单个学生中。然而，当教师共享同一参考模型但经历不同的后训练过程时，MOPD 可能难以恢复某些教师的能力（尤其是 SFT 训练的 Tool Use 和 Medical 教师）。
- **关键洞察**：由于 MOPD 蒸馏发生在学生生成的前缀上，**学生初始化会强烈影响后续恢复**。但初始基准性能并不能可靠预测良好的 MOPD 初始化——合并初始化可能一开始低于 SFT 预热，却在 MOPD 后最终更高。
- **进一步发现**：有效合并既取决于教师的相对贡献（域间比例），也取决于整体合并尺度 λ = Σαᵢ，一些强配置位于凸参数平均的单纯形之外（λ > 1），这使得一次性系数搜索变得困难。

## 2. 方法论：IM-MOPD

### 核心思想
- 用**迭代式合并**替代一次性合并系数搜索：从均匀合并初始化出发，在 MOPD 蒸馏过程中，对恢复不足的领域逐步加入固定规模的任务向量增量，使有效教师贡献在训练中渐进确定。

### 关键技术细节
- **任务向量表示**：遵循任务算术（Task Arithmetic），将教师与参考模型的权重差表示为 τᵢ = φᵢ − θ_ref。
- **合并模型参数化**：θ_merge(α) = θ_ref + Σᵢ αᵢτᵢ，αᵢ ≥ 0；全局合并尺度 λ = Σᵢ αᵢ；标准加权平均对应 λ = 1，均匀平均对应 αᵢ = 1/K。
- **归一化评分**：定义 s̃ᵢ(θ) = (sᵢ(θ) − sᵢ(θ_ref)) / (sᵢ(φᵢ) − sᵢ(θ_ref))，参考模型为 0，领域专家为 1。

### 算法流程（IM-MOPD）
1. **初始化**：θ ← θ_ref + (1/K) Σᵢ₌₁ᴷ τᵢ（均匀合并）。
2. **迭代**（t = 1, …, n）：
   - 执行 MOPD 更新：θ ← MOPD(θ; {φᵢ})。
   - 若 t mod H = 0 且 t < n：
     - 评估各领域归一化恢复率 r̃ᵢ(θ)；
     - 选出恢复率 ≤ 阈值 γ 的领域集合 ℳ = {i | r̃ᵢ(θ) ≤ γ}；
     - 加入修正：θ ← θ + δ Σᵢ∈ℳ τᵢ（δ 为跨域共享的固定修正尺度）。
3. **返回**最终学生 θ。

### 与基线的区别
- 与 MOPD 从参考模型直接开始不同，IM-MOPD 从均匀合并开始。
- 与 SFT 预热不同，IM-MOPD 不需要额外训练阶段，也不需要访问专家训练样本。
- 与静态均匀合并不同，IM-MOPD 允许相对合并比例与总合并尺度在训练中动态演化，不约束累积系数和为 1。

## 6. 主要结论与发现

- **合并初始化有效但域间恢复不均**：从均匀合并开始 MOPD 可显著提升聚合恢复（4B：53.8% vs. 42.8%），无需额外 SFT 阶段，但 Tool Use 等域仍严重恢复不足。
- **初始性能不是良好 MOPD 初始化的可靠指标**：SFT 预热初始表现更高，但 MOPD 后低于合并初始化（4B：59.0% vs. 53.8% 的对比关系在 Tool Use 等域反转）。
- **IM-MOPD 显著提升聚合恢复**：
  - 4B：86.9%（vs. Uniform Merge 53.8%、SFT Warm-up 59.0%）；
  - 1.7B：76.0%（vs. Uniform Merge 46.3%、SFT Warm-up 46.5%），且 Tool Use 恢复到教师水平。
- **合并时机至关重要**：相同的最终累积合并系数，迭代式（86.9%）> 全部在初始化时（79.0%）> 全部在 MOPD 后（23.3%），说明每次修正后的教师引导更新对最终恢复很重要。
- **合并与 MOPD 相互增强**：合并帮助学生生成教师更容易延续的前缀，从而更有效地从教师监督中获益（教师延续诊断证据）。
- **超参数敏感性可控**：4B 在测试的修正尺度下均保持 >80% 归一化恢复；1.7B 在 γ = 0.4、δ = 0.3 时最佳，有效设置可从少量候选中识别。

## 7. 优点

- **方法简洁高效**：IM-MOPD 无需额外 SFT 阶段、无需访问专家训练样本、无需一次性连续系数搜索，仅用合并或不合的离散决策替代连续系数搜索，降低了调参复杂度。
