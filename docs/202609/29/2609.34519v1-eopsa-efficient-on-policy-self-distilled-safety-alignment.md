## 摘要
在策略自蒸馏（On-Policy Self-Distillation, OPSD）已成为安全对齐的一种有前景范式，它通过从以拒绝为导向的特权提示为条件的教师模型中进行蒸馏，提供密集的词元级监督。然而，我们揭示该范式存在严重低效问题，会同时降低训练效率和通用推理能力。具体而言，我们诊断出两个根本瓶颈：（1）长程 rollout 中的监督崩塌，即随着学生模型生成前缀变长，教师模型的纠正效果急剧下降，从而将噪声梯度注入后期词元；（2）由风格偏移导致的梯度稀释，即蒸馏目标被特权提示引发的、与安全无关的风格差异所主导，冲淡真实安全信号并损害基础推理。为解决这些问题，我们提出高效在策略自蒸馏安全对齐（EOPSA），它将计算和梯度预算专门集中于可可靠监督且对安全关键的词元。EOPSA 包含两个协同机制：（i）自适应 rollout 调度，它在一种新的教师救援率（Teacher Rescue Rate, TRR）指标引导下动态限制生成长度，以严格运行于可靠监督区间内；（ii）选择性蒸馏，它过滤掉安全中性词元，将梯度更新仅限制在安全关键的转折上。在参数规模高达 32B 的推理模型上的广泛评估表明，EOPSA 将 rollout 计算量削减约 50%，并仅对约 2% 的词元进行反向传播，在安全合规性和推理保持方面持续优于全词元蒸馏基线。

## Abstract
On-Policy Self-Distillation (OPSD) has emerged as a promising paradigm for safety alignment, delivering dense, token-level supervision by distilling from a teacher conditioned on refusal-oriented privileged prompts. However, we reveal that this paradigm suffers from critical inefficiencies that degrade both training efficiency and general reasoning capabilities. Specifically, we diagnose two fundamental bottlenecks: (1) supervisory collapse over extended rollouts, where the teacher's corrective efficacy degrades precipitously as the student's generation prefix lengthens, injecting noisy gradients into late-stage tokens; and (2) gradient dilution from stylistic shifts, where the distillation objective is dominated by safety-irrelevant stylistic discrepancies induced by privileged prompting, washing out genuine safety signals and impairing base reasoning. To resolve these issues, we propose Efficient On-Policy Self-Distilled Safety Alignment (EOPSA), which concentrates computational and gradient budgets exclusively on reliably supervised, safety-critical tokens. EOPSA incorporates two coordinated mechanisms: (i) Adaptive Rollout Scheduling, which dynamically bounds the generation horizon guided by a novel Teacher Rescue Rate (TRR) metric to operate strictly within reliable supervision regimes; and (ii) Selective Distillation, which filters out safety-neutral tokens to restrict gradient updates exclusively to safety-pivotal transitions. Extensive evaluations across reasoning models up to 32B parameters demonstrate that EOPSA slashes rollout computation by $\sim$50% and backpropagates through merely $\sim$2% of tokens, consistently outperforming full-token distillation baselines in both safety compliance and reasoning retention.

## 1. 核心问题与研究背景

- **背景**：大型推理模型（LRM）通过长链思维（CoT）在复杂推理任务上表现优异，但超长生成轨迹显著放大了有害内容生成的风险。传统对齐范式存在"安全税"（safety tax）：SFT 因离线模仿安全轨迹产生分布偏移，RL 依赖序列级粗粒度奖励，缺乏逐步（token 级）指导，二者都会损害基础推理能力。
- **既有方案**：在策略自蒸馏（OPSD）通过给学生模型配上以"拒绝导向特权提示"为条件的教师（共享基座权重），提供稠密的 token 级监督，理论上能兼顾在策略探索的分布鲁棒性与细粒度指导（代表工作：OPSA、Constitutional OPSD）。
- **本文诊断的两个瓶颈**：
  - **长程 rollout 的监督崩塌**：早期 rollout 前缀由未对齐学生生成，前缀越长，教师"救援成功率"越低，后期 token 的蒸馏梯度变成噪声。论文用两个互补指标刻画这一张力：**TRR（student→teacher，教师能否救回）随前缀变长而骤降**，而 **IDR（teacher→student，学生继承防御能力）随可靠前缀变长而提升**（图 1）。
  - **风格偏移导致的梯度稀释**：蒸馏信号的 KL 质量高度集中——仅约 **8% 的 token 贡献 80% 的 KL 散度**；而在这批高 KL 子集中，**安全无关转换（Function/Consistent/Other）占 71.0% 的 token 数和 51.7% 的 KL 质量**，真正安全信号被稀释，并扭曲基座推理分布。
- **核心研究问题**：能否把 rollout 预算与训练 token 预算同时集中到"监督可靠 + 安全相关"的 token 子集上，从而更高效地完成安全更新并更好地保留通用推理能力？

## 2. 方法论

### 2.1 核心思想
将对齐预算沿两个正交维度收窄：
- **序列级截断**：只在教师监督可靠的范围内做 rollout 与蒸馏；
- **词元级掩码**：只对安全关键转折 token 回传梯度。

### 2.2 关键技术细节

**(1) 自适应 rollout 调度（ARS）——基于 TRR**
- 定义二元安全判别器 J(x,y)∈{0,1}，定义前缀长度 t 处的教师救援率：
  TRR_t = E_x[ E_{y^S_{1:t}~P_S}[ E_{y^T_{>t}~P_T(·|x,y*_c,y^S_{1:t})}[ J(x, y^S_{1:t} ⊕ y^T_{>t}) ] ] ]
  即：给定学生已生成的未对齐前缀，教师（带特权提示 y*_c）续写后整条轨迹仍安全的期望概率。
- 为避免全程连续 profiling 的开销，只在**离散候选前缀集合 S = {128, 256, 1024}** 上、配合标准验证检查点估计 TRR；给定可靠性阈值 τ∈(0,1)，动态 rollout 边界取
  **L = max{ l ∈ S | TRR_val^l ≥ τ }**（若为空则取 min(S)）。
- 取 max 保证在可靠前提下尽量用长前缀以最大化安全继承（IDR 支持），约束条件防止摄入噪声晚期梯度。训练中 TRR 曲线右移会逐步解锁更长视野（图 4c：step 0–50 取 L=128，step 51–200 取 L=1024）。实际实现中每 K=50 步更新一次 L，默认 τ=0.75。

**(2) 语义分解与安全关键 token 识别**
- 在留出查询上取高 KL 位置的学生/教师 top-1 预测对 (v^S_t, v^T_t) 作为可解释的"生成意图"代理，人工检视后归纳出**六类语义分类**：
  - 安全关键 K = { **Pivot**（顺从→拒绝的结构转折，如 "The"→"But"）、**Intent**（从执行任务转向安全审视，如 "make"→"check"）、**Risk**（显式危害/拒绝词汇，如 illegal、refuse）}
  - 安全中性 K_neutral = { **Function**（语法胶水/标点/停用词）、**Consistent**（top-1 相同但置信度差异导致高 KL）、**Other**（任务相关但不改变安全决策的词汇替换）}
- 关键观察：安全关键转折 token **跨查询高度不变（query-independent）**，因而可用预先抽取的规则集捕获；任务特定噪声可被系统性过滤。
- **离线抽取流水线**（附录 B）：在**与训练数据不重叠**的有害留出集上，对每条轨迹取 top-16 高 KL 位置 → 用 LLM（如 GPT-4o）按"通用语义 rubric"分类 → 分桶累积为词表 L^T_pivot、L^S_intent、L^T_intent、L_risk、L_func → 二次审计清洗，得到模型家族专属词典。
- **在线运行时**为确定性 O(1) 优先级级联判定：Consistent（s=t）→ Pivot（t∈L^T_pivot 且 s∉L^T_pivot）→ Risk（s 或 t∈L_risk）→ Intent（s∈L^S_intent 且 t∈L^T_intent）→ Function（两者均在 L_func）→ Other（残差）。Pivot 故意设计为非对称（只累积教师侧）。

**(3) 选择性蒸馏目标**
- 完整目标（式 4）：在截断到 min(|y|, L) 的范围内，只对属于 K 的位置计算 KL，并用有效监督位置数 N_K(y) 归一化：
  L_EOPSA(θ) = E_{x, y~P_S} [ (1/N_K(y)) Σ_{t=1}^{min(|y|,L)} sg[ I(C(v^S_t,v^T_t) ∈ K) ] · D_KL( P_T(·|x,y*_c,y_{<t}) ‖ P_S(·|x,y_{<t}) ) ]
  其中 sg[·] 为停止梯度算子，C(·,·) 为规则查表分类器。
- **散度方向**：默认使用 **Forward KL**（教师加权、mode-covering），附录 F.3 对比 Reverse-KL、JSD(α=0.5) 与 Sampled-token 目标，Forward-KL 在安全与推理上均最优；实现上用 top-k（k=512）近似以控制显存。
- 算法流程（Algorithms 1–3）：① 初始验证确定 L → ② 采样受限的 on-policy 学生轨迹 → ③ 逐位置取学生/教师 top-1 意图并做级联分类得掩码 → ④ 计算掩码序列损失并更新 → ⑤ 每 K 步重估 TRR 并更新 L。
- 效果：梯度只回传"可靠监督 × 安全关键"的交集，优化 token 量约为全序列 OPSD 的 **~2%**。
