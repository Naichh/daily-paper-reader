## 摘要
通过群体相对策略优化（GRPO）实现的带可验证奖励的强化学习（RLVR）被广泛用于多轮 VLM 智能体训练，但它在均匀失败时会出现零梯度静默，并且仅有粗粒度的回合级信用分配。虽然在线策略蒸馏（OPD）和在线策略自蒸馏（OPSD）利用事后信息缓解稀疏奖励，但其内在机制仍未被充分理解。通过在五个多轮 VLM 智能体基准上进行受控的反事实回滚探针，我们发现 OPSD/OPD 的性能提升在很大程度上由枢轴步（pivot step）处的物理状态回滚所驱动；枢轴步被定义为在剩余步数预算为零时的首个不可恢复动作。然而，物理状态回滚在计算上代价高昂，且在实际环境中不可行。为弥合这一差距，我们提出枢轴感知内化视觉在线策略训练（PIVOT），一种将枢轴定位与状态恢复直接内化到 token 级参数更新中的强化学习框架，从而在 RL 训练期间消除环境回滚，并在测试时无需额外技能提示。PIVOT 在单一架构中统一了三种功能角色：失败分析器以非侵入方式定位枢轴步，并根据视觉轨迹拼贴图和动作日志诊断失败模式；分离的教师在此特权诊断上下文下对失败 token 重新评分；学生优化联合 GRPO 与置信度门控 OPD 目标。在测试时，教师和分析器分支均被移除。在涵盖认知网格谜题、3D 具身控制与导航以及生成式推理的五项多轮 VLM 智能体任务上评估，PIVOT 在 Qwen2.5-VL-3B 上达到 0.90 的总体准确率（较 SFT+GRPO 基线提升 8%，较此前 SOTA 提升 5%），并在 Qwen3-VL-2B 上扩展至 0.92（较 SFT+GRPO 基线提升 12%）。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) via Group-Relative Policy Optimization (GRPO) is widely used for multi-turn VLM agent training, yet it suffers from zero-gradient silence on uniform failures and coarse episode-level credit assignment. While On-Policy Distillation (OPD) and On-Policy Self-Distillation (OPSD) mitigate sparse rewards using hindsight information, their underlying mechanisms remain poorly understood. Through controlled counterfactual rollback probes across five multi-turn VLM agent benchmarks, we reveal that performance gains in OPSD/OPD are largely driven by physical state rollback at the pivot step, defined as the first unrecoverable action without remaining step budget. However, physical state rollbacks are computationally prohibitive and infeasible in real-world environments. To bridge this gap, we present Pivot-Aware Internalized Visual On-Policy Training (PIVOT), an RL framework that internalizes pivot localization and state restoration directly into token-level parameter updates, eliminating environment rollbacks during RL training and additional skill hints at test time. PIVOT unifies three functional roles within a single architecture: a failure Analyzer non-invasively localizes the pivot step and diagnoses failure modes from visual trajectory collages and action logs; a detached Teacher re-scores failed tokens under this privileged diagnostic context; and a Student optimizes joint GRPO and confidence-gated OPD objectives. At test time, both Teacher and Analyzer branches are stripped. Evaluated on five multi-turn VLM agent tasks across cognitive grid puzzles, 3D embodied control and navigation, and generative reasoning, PIVOT achieves 0.90 overall accuracy on Qwen2.5-VL-3B (+8% over SFT+GRPO baseline and +5% over previous SOTA) and scales to 0.92 on Qwen3-VL-2B (+12% over SFT+GRPO baseline).

- **背景**：带可验证奖励的强化学习（RLVR）已成为 VLM 智能体后训练的主流范式，其中 GRPO 通过组内归一化回合级回报计算相对优势。但作者在五个多轮 VLM 智能体基准上的分析表明，GRPO 存在两个关键失效模式：
  - **零梯度静默（zero-gradient silence）**：当一组 rollout 的回报完全相同（σ=0）时，GRPO 优势全部为零，策略更新失效——即使这些失败轨迹中包含了多样化的错误行为。例如在 Sokoban 上 σ=0 组占比 48.3%，PrimitiveSkill 上为 16.5%。
  - **粗粒度回合级信用分配**：GRPO 将标量优势均匀赋给轨迹中的每个动作 token，只按回合回报排序，无法定位究竟是哪一步首次使任务不可恢复。
- **已有方法的局限**：在线策略蒸馏（OPD）通过 token 级监督缓解稀疏奖励，但需要白盒教师 logits 与词表匹配；在线策略自蒸馏（OPSD）利用事后信息做自监督，但其内在机制尚不明确。
- **核心机制发现（反事实回滚探针）**：作者在五个基准上系统性地将环境回滚到枢轴步（pivot step）并重采样轨迹后缀，发现：
  - **状态回滚是主要增益来源**：在 t\* 处无提示回滚可将后缀回报提升率 ΔR 提升 3.3%–56.6%，并显著降低零方差组比例（Sokoban 48.3%→41.7%，PrimitiveSkill 16.5%→3.8%）。
  - **时间精度至关重要**：将回滚延迟一步（t\*+1）后 ΔR 急剧下降（如 Sokoban 3.3%→0.9%，PrimitiveSkill 17.7%→8.3%）。
  - **技能提示增益边际**：无论是自生成（3B-self）还是教师提供（8B-teacher）的技能提示，相比纯状态回滚仅有 ≤2.6 或 0.3–3.5 个百分点的额外增益。
- **"回滚悖论"**：OPSD/OPD 的收益主要来自枢轴步的物理状态回滚，但物理回滚在在线 RL 中计算代价高昂，在真实不可回溯环境中根本不可行；同时推理时也无法容忍额外的技能提示开销。因此需要一个能把枢轴定位与状态恢复内化到参数更新中的实用框架。

## 2. 方法论：PIVOT 框架

### 2.1 核心思想

将枢轴步定位与失败诊断内化到单一共享策略 π_θ 的参数中，用"特权上下文重打分"替代物理环境回滚，在原始失败轨迹上直接生成 token 级细粒度策略梯度；测试时剥离分析器与教师分支，仅以无特权学生部署，零额外开销。

### 2.2 关键定义

- **枢轴步 t\***：给定可行性证书 Feas(s,k)∈{0,1}（状态 s 能否在 k 步内到达目标），t\* 定义为剩余预算下首个使任务不可行的动作：t\* = min({t : Feas(s_{t+1}, T−t−1)=0} ∪ {T−1})。
- **后缀回报提升率 ΔR**：在 t\* 处回滚状态并重采样后缀 ˜τ_{t\*:} 后，成功恢复（R(˜τ) > R(τ_{t\*:})）的失败轨迹占比。

### 2.3 三阶段流程

**Stage I：视觉诊断冷启动（SFT）**
- 输入：多帧视觉拼贴图 C(τ)=Grid(o_0,…,o_{T−1})（带步索引）+ 完整动作序列 a_{0:T−1} + 任务提示 q，严格只依赖可观测轨迹历史，不需要环境状态或内部记忆。
- 监督目标：诊断三元组 z_τ=(t\*, m\*, r\*)，其中 t\* 由任务求解器钉住，m\* 为离散失败模式（如 deadlock、timeout），r\* 为冻结教师（Qwen3-VL-8B）离线生成的可选引导技能。
- 损失：长度归一化的自回归负对数似然（式 10），AdamW，学习率 2×10⁻⁶，batch size 8，最大序列长度 8192，每环境 3 个 epoch，产出 θ_sft。

**Stage II：三角色统一架构（RL）**

所有角色共享同一参数 π_θ：

- **角色 1：诊断分析器**——对每个失败 rollout 预测 (ˆt, ˆm, ˆr) = π_θ(q, C(τ), a_{0:T−1})；用预测枢轴步 ˆt 提取 3 面板视觉邻域 P_ˆt=[o_{ˆt−1}, o_ˆt, o_{ˆt+1}]（边界帧零填充）；构建特权诊断上下文 p=(P_ˆt, ˆm, ˆr)。
- **角色 2：特权教师**——在 ˜h_t=(p, h_t) 下重打分学生原始动作 token，ℓ^tea_t = sg[log π_θ(a_t | ˜h_t)]，stop-gradient 阻止教师侧参数更新。不执行额外仿真步骤、不重置环境状态。
- **角色 3：行动学生**——在标准历史 h_t 下计算 ℓ^stu_t = log π_θ(a_t | h_t)。

**联合优化目标**：
- GRPO 损失（式 6）：L_GRPO = −E[m_act min(ρ_t A^rl, clip(ρ_t,1−ε,1+ε)A^rl)]，其中 ρ_t = exp(ℓ^stu_t − ℓ^old_t)。
- 置信度门控 OPD 损失（式 7）：仅对失败轨迹（I[R(τ)<R_succ]）施加：L_OPD = E[I[R(τ)<R_succ] m_act g_t (sg[ℓ^tea_t] − ℓ^stu_t)]，其中门控权重 g_t=σ(β_opd δ_t)，δ_t=ℓ^tea_t−ℓ^stu_t 为特权对数概率差，β_opd=5 控制门控温度。
- 总损失（式 8）：L(θ) = L_GRPO(θ) + λ_opd L_OPD(θ)，λ_opd=0.01。
- **关键性质**：当一组 rollout 全部失败（σ=0）时 L_GRPO 消失，但 L_OPD 仍能提供有效策略梯度，从而解决零梯度静默问题。

**推理阶段**：分析器与教师分支被剥离，π_θ 严格以无特权学生 ∼π_θ(·|h_t) 执行，零计算与提示开销。

### 2.4 消融变体设计

- **P**：仅局部视觉面板 p=(P_ˆt)
- **M**：仅失败模式诊断 p=(ˆm)
- **M+P（默认）**：视觉面板+失败模式+预测枢轴步 p=(P_ˆt, ˆm, ˆt)
- **M+P+R**：额外追加预测引导技能 p=(P_ˆt, ˆm, ˆt, ˆr)
- **M+P-Random+R（负对照）**：用均匀随机步索引替代预测枢轴步

- SFT：每环境采样失败 on-policy rollout，经宽松事实过滤后保留约 960–1.7k 条接受轨迹（90/10 划分），每环境 3 个 epoch
- RL：250 次策略更新（Sokoban 350 次），GRPO 组大小 N=8，验证 128 episodes/环境，折扣 γ=0.95，KL 系数 0.01，无效动作惩罚 0.1
