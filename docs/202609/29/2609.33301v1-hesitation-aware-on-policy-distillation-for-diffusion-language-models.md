## 摘要
扩散大语言模型（dLLMs）通过迭代去掩码生成文本。在每个去噪步骤中，dLLM 会在每个被掩码位置提出一个 token，但解码器只提交这些提议中置信度足够高的一个子集。基于轨迹的同策略蒸馏（TOPD）建立在这一过程之上，将学生模型与更强的教师模型进行匹配，但仅在已提交的位置上。我们认为，这丢弃了大量有用信号，这些信号存在于未被提交的提议中：在这些位置，学生模型已做出预测，但尚未自信到足以提交。我们将这些提议称为“犹豫”。在我们对 SDAR-4B 学生模型的初步研究中，犹豫仅占可监督状态-位置对的 24%，却承载了 66% 的师生差异。为利用这一信号，我们提出犹豫感知同策略蒸馏（HOPD），它将教师分布匹配扩展到每个去噪步骤的每一个被掩码位置。由于不同犹豫所提供的信息量并不相同，我们进一步利用完整轨迹的事后信息来分配监督，将更大权重放在那些其提议后来与最终 token 不一致的位置，以及首步提议很少存活下来的块上。由于两个模型已经在所有被掩码位置产生分布，HOPD 相比 TOPD 不需要额外的前向传播。唯一的额外成本是在更多位置上评估损失。在从 TraDo-8B-Instruct 蒸馏得到的 SDAR-1.7B 和 SDAR-4B 学生模型上，HOPD 在五个数学与代码基准上，在静态和动态解码下、两种规模下，均取得了所评估方法中的最佳平均分。它还能加速解码。在 SDAR-4B 上，HOPD 学生模型比 TOPD 犹豫更少，每个去噪步骤多提交 11% 的 token，同时达到更高的准确率。

## Abstract
Diffusion large language models (dLLMs) generate text by iterative unmasking. At each denoising step, a dLLM proposes a token at every masked position, but the decoder commits only a confident subset of these proposals. Trace-based on-policy distillation (TOPD) builds on this process by matching the student to a stronger teacher, yet only at the committed positions. We argue that this discards much of the useful signal, which resides in the uncommitted proposals, where the student has made a prediction but is not yet confident enough to commit it. We call these proposals hesitations. In our pilot study on an SDAR-4B student, hesitations make up only 24% of supervisable state-position pairs but carry 66% of the teacher-student divergence. To exploit this signal, we propose Hesitation-Aware On-Policy Distillation (HOPD), which extends teacher distribution matching to every masked position of each denoising step. Because hesitations are not equally informative, we further allocate supervision using hindsight from the completed trajectory, placing more weight on positions whose proposal was later disagreed with the final token and on blocks where first-step proposals rarely survive. Since both models already produce distributions at all masked positions, HOPD requires no additional forward passes over TOPD. The only extra cost is evaluating the loss at more positions. With SDAR-1.7B and SDAR-4B students distilled from TraDo-8B-Instruct, HOPD achieves the best average score among the evaluated methods on five math and coding benchmarks, under both static and dynamic decoding and at both scales. It also speeds up decoding. On SDAR-4B, the HOPD student hesitates less and commits 11% more tokens per denoising step than TOPD, while reaching higher accuracy.

# 论文总结：Hesitation-Aware On-Policy Distillation for Diffusion Language Models（HOPD）

## 1. 核心问题与整体含义

- **背景**：扩散大语言模型（dLLMs）通过迭代去掩码生成文本。每个去噪步骤中，模型会在所有被掩码位置提出一个 token 提议，但解码器只提交其中置信度足够高的一个子集（由静态或动态解码规则决定）。
- **已有方法及其缺陷**：基于轨迹的同策略蒸馏（TOPD）将学生模型与更强的教师模型在**已提交位置**上匹配。但作者指出，这种做法丢弃了大量有用信号——那些学生已做出预测、但置信度不足以被提交的**未提交提议**，被命名为“**犹豫（hesitations）**”。
- **关键动机（试点研究）**：在 SDAR-4B 学生模型上，犹豫仅占可监督状态-位置对的 **24%**，却承载了 **66%** 的师生差异（KL 散度）。这说明 TOPD 的监督信号严重错配：大量分歧恰恰集中在被忽略的位置。
- **整体含义**：论文主张将教师分布匹配扩展到**每个去噪步骤的所有被掩码位置**，并利用完整轨迹的事后信息对监督进行加权，从而同时提升蒸馏精度与解码效率。

## 2. 方法论

### 核心思想
- 将同策略蒸馏（OPD）的目标集从“已提交位置”扩展为“当前块的所有掩码位置”，即 $M(s_t) = A_t \cup R_t$。
- 由于犹豫并非同等重要，进一步利用**完整轨迹的回溯信息**对位置和块赋予不同权重，将监督集中在学生预测最不稳定的地方。

### 关键技术细节

- **状态收集**：每轮 rollout 中，当前学生生成轨迹，定义访问到的 pre-action 状态 $s_t$；学生与冻结教师在同一状态下匹配，轨迹在更新期间固定。

- **事后权重**（基于试点研究的两项统计量）：
  - **位置权重**：$w_j = 1 + e_j$，其中 $e_j$ 是位置 $j$ 上与其最终 token 不一致的提议数量（retraction count），反映该位置“犹豫”程度。
  - **块权重**：$w_b = \max(1 - \rho_b, \rho_{\min})$，其中 $\rho_b$ 是块 $b$ 首步提议与最终 token 匹配的比例（first-step retention），$\rho_{\min} = 0.1$ 保证每块都有正权重。

- **训练目标**：
  $$L_{\text{HOPD}}(\theta) = \mathbb{E}_{q, \xi \sim \pi_\theta} \sum_{t: |M(s_t)|>0} w_{b(t)} \frac{1}{|M(s_t)|} \sum_{j \in M(s_t)} w_j \, \ell_{t,j}(\theta)$$
  其中 $b(t)$ 是步骤 $t$ 正在去噪的块。

- **逐位置损失**：采用**全词表反向 KL 散度**
  $$\ell_{t,j}(\theta) = D_{\mathrm{KL}}\big(\pi_\theta(\cdot | q, s_t, j) \,\|\, \pi_{\text{tea}}(\cdot | q, s_t, j)\big)$$
  直接匹配完整分布，避免单样本 token 估计带来的采样噪声；反向 KL 的 mode-seeking 特性抑制学生分配给教师不支持 token 的概率质量。

- **计算开销**：由于学生和教师本就在所有掩码位置产生分布，HOPD 相比 TOPD **无需额外前向传播**，唯一额外成本是在更多位置评估损失。
- **推理**：不改变解码规则；教师支持的预测可能更早达到置信阈值，从而每步提交更多 token。

## 3. 实验设计

### 模型与数据
- **学生模型**：SDAR-4B-Chat、SDAR-1.7B-Chat（块注意力 dLLM）。
- **教师模型**：TraDo-8B-Instruct（冻结）。
- **训练数据**：数学用 MATH 训练集 level 3–5（8,523 题）；代码用 PrimeIntellect 验证过的 stdio 问题（5,954 题）。
- **Rollout 设置**：动态解码，阈值 $\tau=0.9$，温度 1.0，每轮 64 个 prompt 各采样 1 条响应，共 30 轮，每轮 1 epoch。

### Benchmark（五个）
- 数学：**MATH500**、**AIME2024**、**GSM8K**
- 代码：**LiveCodeBench-v2**、**LiveBench**
- 评估在**静态解码**和**动态解码**（$\tau=0.9$）两种规则下进行；MATH500/GSM8K/代码报告 avg@3，AIME2024 报告 avg@20。

### 对比方法
- **SFT**：半自回归监督微调（随机块掩码 + 块级交叉熵）。
- **Off-policy**：在教师轨迹的已提交位置上做全词表反向 KL。
- **TraceRL**：轨迹感知的 RL（可验证奖励）；SDAR-4B 用发布的 TraDo-4B-Instruct，SDAR-1.7B 用公开实现训练。
- **TOPD**：基于轨迹的同策略蒸馏（采样 token 反向 KL 估计器）。
- **补充对比**：TOPD 的全词表反向 KL 变体。

### 扩展实验
- **全注意力模型**：LLaDA-8B-Instruct，以 ESPO 训练的数学/代码模型为教师，32-token 块、128-token 未来视野。
- **消融实验**：
  - 散度目标（全词表 forward KL、reverse KL、JSD、采样 token reverse KL）。
  - 事后权重（uniform、仅 $w_j$、仅 $w_b$、两者结合）。
- **解码效率**：扫 $\tau \in \{0.5, 0.7, 0.8, 0.9, 0.95, 0.99\}$，测每步提交 token 数与墙钟吞吐。
- **训练后犹豫分析**：对比 Base/TOPD/HOPD 的 committed/deferred/retracted 比例与预测熵。

## 6. 主要结论与发现

- **HOPD 在五个基准上取得所评估方法中的最佳平均分**：SDAR-1.7B 上静态/动态分别比 TOPD 高 **1.5/1.7** 个百分点；SDAR-4B 上高 **0.9/1.6** 个百分点。
- **解码更快**：在 SDAR-4B、训练阈值 $\tau=0.9$ 下，HOPD 达到 72.5% vs TOPD 71.3% 的 MATH500 准确率，同时**每步多提交 11% 的 token**；墙钟吞吐在 SDAR-4B 上高 4–18%，在 SDAR-1.7B 上高 8–23%。
- **训练后犹豫减少**：HOPD 的 committed 比例最高（77.1%），deferred/retracted 比例最低，且各类别预测熵低于 TOPD，说明学生变得更确定、更早提交。
- **犹豫确实承载主要分歧**：试点研究中犹豫占 24% 的可监督对但贡献 66% 的 KL；retraction 越多、首步保留率越低的位置/块，KL 越大。
- **全注意力模型可迁移**：LLaDA-8B-Instruct 上 HOPD 平均分高于 TOPD（静态 28.4 vs 27.9，动态 27.5 vs 27.3）。
- **反向 KL 是最佳逐位置目标**：全词表反向 KL 在散度目标消融中平均分最高；事后加权在多数设置下优于均匀加权。

## 7. 优点

- **问题识别新颖且有数据支撑**：通过试点研究量化了“犹豫”信号的占比与分歧贡献，动机清晰、有说服力。
- **方法简洁高效**：不改变解码规则、不增加前向传播，仅扩展损失评估位置并加权，工程落地成本低。
- **事后权重设计有据可依**：位置与块权重均来自完整轨迹的可观测统计量（retraction count、first-step retention），且通过消融验证其独立贡献。
- **实验覆盖较全面**：跨模型规模、跨解码规则、跨数学/代码领域、跨块注意力/全注意力架构，并系统比较多种后训练范式（SFT、Off-policy、RL、TOPD）。
- **同时提升精度与效率**：不仅提高准确率，还通过减少犹豫加速解码，具有实际部署价值。
- **公平的对照设计**：TOPD 与 HOPD 共享几乎所有训练组件，仅目标不同，能较干净地隔离方法贡献。

## 8. 不足与局限
