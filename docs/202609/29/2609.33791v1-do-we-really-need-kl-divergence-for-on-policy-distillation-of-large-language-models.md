## 摘要
自知识蒸馏诞生以来，KL散度一直是蒸馏中的标准损失。近年来，同策略蒸馏（OPD）已成为一种高效的大语言模型后训练范式。作为一种蒸馏方法，OPD自然继承了KL散度作为其标准损失。然而，在本工作中，我们发现KL散度对于OPD可能并非必要。我们表明，仅保持更新方向就足以实现有效的OPD。只要更新方向朝向教师模型，OPD就能奏效。更准确地说，起作用的并非每个token的方向，而是教师模型与学生模型强烈不一致的一小部分token的方向。我们首先表明，简单地对教师概率高于学生概率的token赋予奖励(+1)，对低于的赋予(-1)，即仅鼓励朝教师模型方向更新，就能复现与使用反向KL的OPD几乎相同的训练模式。我们进一步表明，只有教师-学生分歧较大的一小部分token的方向才是关键的；只要它们的更新方向朝向教师模型，即使其他token被拉离教师模型，训练仍然有效。作为这些发现的一个应用，我们提出共识多教师同策略蒸馏（C-MOPD）来改进多教师同策略蒸馏（MOPD）。与MOPD将每个样本路由到单个教师模型并可能导致跨领域能力冲突不同，C-MOPD让每个样本都受到所有教师模型的监督。实验表明，C-MOPD在数学和代码基准上均持续优于MOPD。我们的代码见 https://github.com/LeapLabTHU/KL-Free-OPD。

## Abstract
Since the advent of knowledge distillation, KL divergence has been the standard loss in distillation. Recently, on-policy distillation (OPD) has emerged as an efficient post-training paradigm for LLMs. As a distillation method, OPD naturally inherits KL divergence as its standard loss. However, in this work, we find that KL divergence may not be necessary for OPD. We show that simply preserving the update direction is sufficient for effective OPD. As long as the update direction is toward the teacher, OPD works. More precisely, it is not the direction of every token, but the direction of a small subset of tokens where the teacher and student disagree strongly. We first show that simply assigning a reward of (+1) to tokens where the teacher probability is higher than the student probability and (-1) where it is lower, which merely encourages updates toward the teacher, reproduces almost the same training mode as OPD with reverse KL. We further show that only the direction of a small subset of tokens with large teacher-student disagreement is critical, and training works as long as their update direction is toward the teacher, even if other tokens are pulled away from the teacher. And as an application of these findings, we introduce Consensus Multi-Teacher On-Policy Distillation (C-MOPD) to improve Multi-Teacher On-Policy Distillation (MOPD). Unlike MOPD, which routes each sample to a single teacher and may cause capability conflicts across domains, C-MOPD lets every sample be supervised by all teachers. Experiments show that C-MOPD consistently outperforms MOPD on both math and code benchmarks. Our code is available at https://github.com/LeapLabTHU/KL-Free-OPD.

# 论文总结：我们真的需要KL散度来进行大语言模型的同策略蒸馏吗？

## 一、核心问题与研究动机

- **背景**：自知识蒸馏（Hinton et al., 2015）提出以来，KL散度一直是蒸馏任务的标准损失函数，用于让学生模型匹配教师模型的软目标分布，从而捕获其中的"暗知识"。
- **同策略蒸馏（On-Policy Distillation, OPD）**：近年来成为大语言模型高效后训练范式，它在学生模型自身的 rollout 上对齐教师模型，自然地继承了反向 KL 散度作为标准损失。
- **核心问题**：本文质疑——KL 散度对于 OPD 是否真的必要？
- **核心主张**：仅保留"更新方向"（朝向教师）即可实现有效的 OPD；更精确地说，真正关键的并非所有 token 的方向，而是**教师与学生强烈分歧的一小部分 token**的方向。
- **整体含义**：挑战了"分布匹配是蒸馏本质"的普遍假设，指出 OPD 的关键可能只是对少数高分歧 token 的方向性更新。

## 二、方法论

### 1. BinaryOPD（二元方向奖励）

- **核心思想**：用简单的方向性奖励替代反向 KL 目标。
- **关键公式**：对每个 token $o_t$，比较教师概率 $\pi_T(o_t|q,o_{<t})$ 与学生概率 $\pi_\theta(o_t|q,o_{<t})$：
  - 若教师概率更高，奖励 $r_t = +1$（增加该 token 概率，拉向教师）；
  - 若教师概率更低，奖励 $r_t = -1$（降低该 token 概率，同样拉向教师）；
  - 概率相等时奖励为 0（实际中几乎不发生）。
- **优化目标**：以策略梯度形式最大化 $\mathbb{E}\left[\sum_t r_t \log \pi_\theta(o_t|q,o_{<t})\right]$，仅保留方向信息，丢弃 KL 中的幅度信息。

### 2. 高分歧 token 的关键性分析

- 用对数比 $\ell_t = \log \frac{\pi_T(o_t|q,o_{<t})}{\pi_\theta(o_t|q,o_{<t})}$ 衡量分歧，基于阈值 $\epsilon$ 将 token 分为三组：
  - **Group A**（高分歧，教师更偏好）：$\ell_t > \epsilon$
  - **Group B**（低分歧）：$-\epsilon \le \ell_t \le \epsilon$
  - **Group C**（高分歧，学生更偏好）：$\ell_t < -\epsilon$
- 通过正/负奖励实验，分别只对选定子集赋予 $+1$ 或 $-1$，检验哪些 token 对训练起决定作用。

### 3. C-MOPD（共识多教师同策略蒸馏）

- **动机**：MOPD 将每个样本路由到单一领域教师，可能引发跨域能力冲突。
- **核心设计**：每个 token 同时受所有 $K$ 个教师监督，奖励规则为：
  - 若所有教师概率都高于学生，奖励 $+1$；
  - 若所有教师概率都低于学生，奖励 $-1$；
  - 若教师间冲突，则以领域教师方向 $d = \text{sign}(\ell_{k^*})$ 为准，且仅当该方向与其他教师冲突不强烈（$\ell_k > -\epsilon$ 或 $\ell_k < \epsilon$）时采纳；
  - 否则奖励为 0。
- **效果**：每次更新要么拉向所有教师，要么拉向领域教师而不损害其他教师对应的能力。

## 六、主要结论与发现

1. **KL 散度并非 OPD 必需**：BinaryOPD 仅用 ±1 方向奖励即可复现 OPD 的训练模式，在数学与代码基准上达到相当或更优的性能（如 Qwen3-4B 数学 65.1 vs 64.1；Qwen3-1.7B 数学 22.2 vs 21.2；代码 55.2 vs 55.4）。
2. **仅高分歧 token 的方向关键**：
   - 只保留 Group A（占比不到 1.5%）并赋 +1 即可成功训练；
   - 一旦把 Group C 也赋 +1（方向背离教师），训练失败；
   - 负奖励实验呈现对称模式：只保留 Group C 赋 -1 可训练，加入 Group A 则失败。
   - 低分歧 Group B（占比超 90%）即使被错误方向更新，只要高分歧 token 处理正确，训练仍可进行。
3. **验证器信号影响甚微**：即使完全反转验证器信号（正确轨迹给非正奖励、错误轨迹给非负奖励），性能不受影响，甚至略优。
4. **重复反馈视角的解释**：OPD 状态空间高度冗余（跨 prompt 最近邻余弦相似度均值 0.893，29.5% 状态有 ≥0.95 的邻居），同一状态区域被反复访问，方向性信号通过闭环反馈即可迭代确定修正幅度，无需显式编码幅度。
5. **C-MOPD 优于 MOPD**：在数学与代码基准上几乎全面胜出（如 AIME24 61.3 vs 60.0，LiveCodeBench v6 32.9 vs 27.9）；$\epsilon=0.0$ 过于保守，零奖励比例最终超 90%，性能仅与 MOPD 持平。

- **方法极简**：BinaryOPD 将反向 KL 替换为 ±1 二元奖励，实现简单、无需调参，易于推广。
