## 摘要
对文本属性图（TAGs）进行推理需要大型语言模型（LLMs）将节点的文本与其邻域中分布的证据相结合。现有方法在生成之前固定可访问的邻居集合，迫使推理在静态上下文上运行，并阻止模型在推理过程中获取缺失的证据。我们认为邻居选择本身应该是推理过程的一部分。为此，我们提出了自行召唤邻居（CNY）框架，该框架使LLMs能够通过拓扑约束的图游走操作主动探索图邻域。CNY不预先选择邻居集合进行推理，而是暴露轻量级的邻居预览，并学习何时扩展候选邻居以获取额外证据。为了解决邻居探索的延迟信用挑战，我们引入了目的地条件在线策略自蒸馏，该方法在选定邻居的内容被揭示后对其进行回顾性评估，并将由此产生的动作偏好变化转化为动作级别的训练信号。在统一原始文本设置下的标准TAG推理基准实验表明，CNY持续优于固定上下文的后期训练基线。此外，学习到的探索策略能够迁移到未见过的图以及训练期间未遇到的图级任务。代码可在https://github.com/superallen13/CNY获取。

## Abstract
Reasoning over text-attributed graphs (TAGs) requires large language models (LLMs) to combine a node's text with evidence distributed across its neighbourhood. Existing methods fix the set of accessible neighbours before generation, forcing reasoning to operate over a static context and preventing the model from acquiring missing evidence during inference. We argue that neighbour selection should itself be part of the reasoning process. To this end, we propose Call Neighbours Yourself (CNY), a framework that enables LLMs to proactively explore graph neighbourhoods through topology-constrained graph-walk actions. Instead of reasoning over a pre-selected neighbour set, CNY exposes lightweight neighbour previews and learns when to expand candidate neighbours for additional evidence. To address the delayed-credit challenge of neighbour exploration, we introduce destination-conditioned on-policy self-distillation, which retrospectively evaluates a selected neighbour after its content is revealed and converts the resulting change in action preference into an action-level training signal. Experiments on standard TAG reasoning benchmarks under a unified raw-text setting show that CNY consistently outperforms fixed-context post-training baselines. Furthermore, the learned exploration policy transfers to unseen graphs and to a graph-level task not encountered during training. Code is available at https://github.com/superallen13/CNY.

## 1. 论文的核心问题与整体含义（研究动机和背景）

**问题背景：**
- 文本属性图（TAGs）广泛存在于现实世界，如引文网络、超链接图和商品共购网络，每个节点包含自由文本并通过边与其他文本节点相连。
- 在 TAG 上推理需要 LLM 不仅使用目标节点自身的文本，还要利用图邻域中分布的证据。
- 现有 LLM 方法通常将邻域子集在生成前选定并作为固定上下文提供给模型（如 Graph-R1、TRN-R1-Zero 的后期训练方法）——这是一种"检索后生成"的静态上下文假设。

**核心问题：**
- 在密集 TAG 上，邻域往往超过实际上下文限制（WikiCS 上有 40.3% 的目标节点的完整一跳邻域已超过 32K token 窗口），必须进行选择。
- 一旦生成前固定邻域子集，若关键证据不在其中，模型无法在推理过程中补救——邻居选择本身应该是推理过程的一部分，而非与之解耦的预处理步骤。
- 研究表明即使完整邻域能放入上下文，冻结的 LLM 在生成中主动选择邻居也优于嵌入相似度检索的 RAG 管线，且只用 6.3× 更少的 token。

**核心主张：**
- 邻居选择本身应当成为推理过程的一部分，LLM 应通过图游走动作主动探索邻域，按需获取证据。

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

**整体框架 CNY（Call Neighbours Yourself）：**

CNY 将邻域证据获取形式化为一个交互式图环境中的顺序决策过程，训练 LLM 发出 `<walk>` 动作，在生成过程中读取特定邻居的完整文本，从而将预选邻居集替换为 LLM 逐步获取的证据。

**(1) 交互式图环境**
- 初始观察包含：目标节点文本、标签描述、初始前台的每个邻居的短预览（如标题、摘要或固定长度前缀）。
- 邻居的完整文本保持隐藏，直到被显式选择。
- 执行 `<walk> X</walk>` 会揭示节点 X 的完整文本，并扩展前台（frontier）：新解锁的节点必须与已检查节点相邻——证据获取被强制遵循图连通性。

**(2) 奖励设计**

采用分层奖励，优先级从高到低为：
- 正确预测 + 有效格式 → 1.0
- 正确预测（格式无效）→ 0.6
- 错误预测但有效格式且至少一次成功探索 → 0.3
- 错误预测但有效格式（未成功探索）→ 0.2
- 错误预测且格式无效但完成回答 → 0.1
- 其他 → 0.0

目的是在正确推理出现前提供学习信号（纯稀疏奖励在初始全部错误时零优势）。

**(3) GRPO 优化**

- 采用 Dr. GRPO（非对称裁剪、无 KL 到参考模型惩罚）。

**(4) 目的地条件在线策略自蒸馏（OPSD）——核心创新**
- **信用分配问题**：轨迹级优势平均分配给所有 token，但图游走中只有少数 token（节点 ID）决定了探索方向，游走质量只有在目的地内容被揭示后才能判断。

  - 学生（student）：原始上下文中的概率
  - 教师（teacher）：在游走 span 前插入 `[Destination: ¯o]` 后的概率

## 6. 论文的主要结论与发现

**核心结论：**
- 有效的图推理不仅取决于如何解释证据，还取决于如何在推理过程中自适应地获取证据——邻居选择应融入推理过程。
- CNY 在每一个测试设置上都达到最高精度，在密集图上优势最大（WikiCS +5.2、Products +1.6、FB15K237 +1.4），在稀疏图上（Cora）优势缩小（+1.1），印证了"选择性阅读在密集图最重要"的前提。
- 学习到的探索策略零样本迁移到从未见过的图、图级任务（Expla-Graph）和多跳 KGQA（WebQSP），且能按任务需求自动调整游走深度（分类约 1.2 步/节点，KGQA 达 2.31 步/问题）。
- OPSD 的贡献在于泛化而非对训练混合的过拟合——训练奖励匹配但评估精度分离。
- OPSD 信号是结构化且双向的，随训练变得更具判别力；β=0.03 的单一系数在不同规模和骨干上稳定工作。
- 行走的增益来自对真实图结构的选择性阅读，而非预览暴露或"行走"这一动作本身——度保持重连使行走精度崩塌到无行走基线水平。

## 7. 优点

**方法设计亮点：**
- **问题定义有创新性**：明确将邻居选择定义为推理过程的一部分，而非预处理步骤，切中密集图推理的痛点。
- **OPSD 机制优雅**：利用"事后回顾"构造自蒸馏教师，无需步骤标签、外部评判者或额外 rollouts，从原理上解决了图游走的延迟信用分配问题；且只对游走 token 生效，避免了对推理轨迹的退化（相比现有自蒸馏方法）。
- **动作空间受图拓扑约束**：与开放查询空间的 agentic 检索不同，游走必须沿图连通性展开，使行为更接近真实图推理。
- **奖励设计具有原则性**：明确说明奖励值只为实现字典序偏好而非校准效用估计，并通过消融证明具体值不关键。
- **实验控制严谨**：匹配文本预算、匹配推理计算、度保持重连三重控制，系统性隔离了"选择"本身带来的增益。

**实验亮点：**
- 多层次验证：从标准基准到消融到跨任务泛化，证据链完整。
- 失败模式分析细致：三种错误的分类统计（相邻类干扰 53.5%、误导性强调 39.4%、推理漂移 6.7%），承认并解释了方法的局限。

## 8. 不足与局限

**方法层面：**
- CNY 训练的是游走选择而非骨干世界观知识，最终精度受限于基础模型已编码的知识——无法注入骨干从未见过的领域事实（论文在 Limitations 中明确承认，并通过骨干规模趋势佐证）。
- 行走可能被语义相邻的邻居"误导"（53.5% 的错误是该模式），说明选择性阅读本身并不能完全解决证据判别问题。
- OPSD 的回顾由 LLM 自己生成，如果骨干对某些主题理解偏差，回顾也可能有偏，形成自我强化的盲点。

**实验层面：**
- 评估基准沿用 GOFA 对齐的零样本设置（来自 Graph-R1/TRN-R1-Zero），未覆盖大规模异构或时间动态图。
- 跨任务泛化证据仅有一个图级任务（Expla-Graph）和一个开放式 QA 任务（WebQSP），覆盖面有限。
- 骨干研究只覆盖 Llama 和 Qwen 两个系列，最高至 14B，未测试更大规模或其他模型家族。
- 训练数据混合中 Expla-Graph 站位的概念图被包成一个全局图，这种构造虽然避免了泄漏，但与真实图级任务的差异可能需要更多验证。

**应用层面：**
- 推理时成本取决于游走暴露的局部上下文和步数预算，在需要深度探索的任务上可能显著增加 token 消耗。
- 只有 2.31 次游走/问题的 WebQSP 测试表明策略确实能加深探索，但更深层（如 5 跳以上）的泛化性能尚未验证。
