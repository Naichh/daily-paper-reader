## 摘要
现代大语言模型（LLM）依靠强化学习在单个领域构建强大能力，但将这些能力整合到单个可部署模型中仍然具有挑战性。通过将每个样本路由到其领域匹配的教师，现有方法让领域标签决定哪个教师提供监督。然而，领域专长仅平均成立：匹配的教师在给定样本上并不总是正确，而来自其他领域的教师有时却正确。因此，可靠的教师必须按样本而非按领域来识别。在本文中，我们引入了多教师自蒸馏策略优化（MT-SDPO），一种将多个冻结教师统一到一个学生模型中的在线策略蒸馏方法。MT-SDPO包含三个组件：（1）自锚点，其中一次 rollout 由其自身组中正确的 rollout 监督；（2）答案验证资格，教师仅在其自身答案通过验证器时才能监督样本；（3）特权蒸馏，将锚点和所有经过验证的反馈合并到一个上下文中，该上下文由指数移动平均自教师读取，而学生不读取，从而在部署时保持单一策略。在来自三个模型族的五个学生上，MT-SDPO将 Qwen3-8B 的最弱领域提升了14.79个百分点，并将其领域差距缩小了74.7%，比每个领域部署一个匹配教师更好的平衡。应该是经过验证的可靠性，而非领域归属，来决定谁来教导。代码可在 https://github.com/hexixiang/MT-SDPO 获取。

## Abstract
Modern large language models (LLMs) rely on reinforcement learning to build strong capabilities in individual domains, but integrating those capabilities into a single deployable model remains challenging. By routing each sample to the teacher whose domain matches it, existing approaches let a domain label decide which teacher provides supervision. However, domain expertise holds only on average: the matched teacher is not always correct on a given sample, while a teacher from another domain sometimes is. The reliable teacher therefore has to be identified per sample, not per domain. In this paper, we introduce Multi-Teacher Self-Distillation Policy Optimization (MT-SDPO), an on-policy distillation method that unifies several frozen teachers into one student model. MT-SDPO consists of three components: (1) self-anchors, where a rollout is supervised by a correct rollout from its own group; (2) answer-verified eligibility, where a teacher may supervise a sample only if its own answer passes a verifier; and (3) privileged distillation, which merges the anchor and all verified feedback into one context that an exponential moving average self-teacher reads and the student does not, thereby keeping one policy at deployment. Across five students from three model families, MT-SDPO lifts the weakest domain of Qwen3-8B by 14.79 points and narrows its domain gap by 74.7%, a better balance than serving one matched teacher per domain. Verified reliability, not domain membership, should decide who teaches. Code is available at https://github.com/hexixiang/MT-SDPO.

## 1. 核心问题与整体含义

论文针对**多领域大语言模型（LLM）后训练中的能力整合**问题——如何将多个在单独领域上强化学习训练出的教师模型融合为一个可部署的单一学生策略。

- 已有 MOPD 等方法按**领域标签**将学生 rollout 路由给“领域匹配”的教师，但领域专长只是“平均意义”上的正确。
- 论文在图 1 中用量化数据显示：被匹配教师正确的训练样本仅占 52.9%，而引入“按样本由任一正确教师”后覆盖可达 65.7%。这说明**真正的可靠教师应当逐样本决定，而非逐领域决定**。
- 总体含义：与其让领域归属决定监督来源，不如让“谁的私有答案经过验证为正确”来决定谁有资格当教师；这有助于把多个领域教师的能力集成到一个更均衡、更可部署的模型中。

## 2. 论文提出的方法论（MT-SDPO）

MT-SDPO 是**基于答案验证的多教师自蒸馏策略优化**，由三个核心概念/组件构成：

- **自锚点（Self-Anchors）**
  - 在线训练时，每个提示下学生生成 G 个 rollout，程序化验证器将 rollout 分为成功与失败。
  - 一个学生的**失败 rollout** 可以由**同组中已验证正确的另一条 rollout** 作为监督信号（截断后作为“锚”），前提是该 rollout 不是它自身，以避免“复制路径/自泄漏”。
  - 如果学生自己从未答对该问题，则没有自锚点——此时需要外部教师补充。

- **答案验证的教师准入（Answer-Verified Teacher Eligibility）**
  - 训练前，每个冻结的领域教师先私有地回答每个问题，只有答案经程序化验证器比对正确的教师才进入该样本的“合格教师集合” Vi。
  - 在线训练时，对于失败的 rollout，模型会向 Vi 中每个合格教师请求诊断性反馈（不包含参考答案、教师私有答案），反馈经过一个词法 sanitizer Γ 过滤，防止标签泄漏。
  - 该规则放弃领域标签，允许来自其他领域的教师参与监督，是一种**逐样本选择**规则。

- **特权蒸馏（Privileged Distillation）**
  - 将自锚点和所有已验证的教师反馈拼成一个“特权上下文” c，只提供给学生模型的 EMA 副本作为条件，学生自身不直接看到该上下文。
  - 学生分支和教师 EMA 分支在共享前缀上逐 token 对齐，损失为带 mask 的、用重要性加权的 Jensen–Shannon 散度（方程 7）；没有自锚点且没有通过过滤的教师反馈的 rollout 不纳入蒸馏损失。
  - 训练中只更新学生参数 θ；EMA 教师按 τ=0.05 吸收学生参数，所有领域教师冻结。部署阶段丢弃所有教师、验证器和 EMA 权重，只保留学生模型。

算法流程：先离线构建每道题的 Vi；每一步在线采样 group rollouts → 验证标出成功/失败 → 失败 rollout 向 Vi 教师取反馈并与可能存在的自锚合并 → 用特权的 EMA 教师计算蒸馏损失更新学生 → 更新 EMA。

## 3. 实验设计

- **任务与基准**
  - 使用 SciKnowEval L3 的 Science Q&A 子集，含三个领域：化学、材料科学、物理。
  - 全部是带单一参考答案的多选题，由程序化验证器抽取答案并与参考答案比对。
  - 数据集按约 9:1 划分训练/测试，三个领域平衡，每个评测域约 79 个样本。

- **模型与学生**
  - 学生模型共 5 个：Qwen3-1.7B / 4B / 8B、Llama-3.1-8B-Instruct、OLMo-3-7B-Instruct（覆盖 3 个模型族）。
  - 教师由各模型族更强的模型生成：Qwen3-32B、Llama-3.1-70B-Instruct、OLMo-3.1-32B-Instruct，再按域后训练为 3 个领域教师。
  - 每个学生都先做 multi-domain post-training（三个领域数据联合）作为所有受控在线方法的共享初始化。

- **对比方法**
  - Base（基础模型）、Matched Teachers (3)（每域部署匹配教师的参考，不是单一可部署策略）、Multi-Domain PT（共享初始化自身）、SDPO（教师无关的纯自蒸馏基线）、Domain Routing（MOPD 风格的按领域路由）以及 ablations：
    - 去掉跨领域教师（只允许验证过的领域匹配教师）
    - 去掉多教师聚合（只允许一个合格教师）
    - 去掉答案验证（允许所有三个未验证教师）
  - 额外报告 GRPO（可验证奖励 RL）作为“同一验证信号用于标量奖励而非分配规则”的目标参考。

- **评估指标**
  - avg@16 的领域准确率 → Macro（平均）、Worst-domain（最弱域）、Gap（域差，最高减最低）。

## 6. 主要结论与发现

1. **领域匹配不如逐样本验证可靠**。匹配教师在训练集上只对 52.94% 样本给出正确答案；允许任意验证正确的教师可将覆盖率提升到约 65.7%，其中跨域救援最大出现在物理（+18.7 点）。
2. **验证式分配能显著改善能力平衡**。在 Qwen3-8B 上，MT-SDPO 相对 Multi-Domain PT 提升 Macro +4.64、最弱域 +14.79，将域间差距从 20.96 缩小到 5.30，指标上优于“单教师镜像部署”的三模型参考（为其 Macro +3.79，Worst 提升 11.15）。
3. **不同模型的收益路径不同**。Qwen3-1.7B/4B 的域更平坦主要是强域回落所致；Qwen3-8B 和 OLMo-3-7B 则是最弱域上升并带动 Macro；而 Llama-3.1-8B 因为初始化已经较平衡，“头部空间”不足，在线方法几乎不再获益，这是论文中一个明显的负结果。
4. **验证器用于“分配规则”而非“奖励标量”很重要**：GRPO 参考把同一验证信号当作奖励，在 Qwen3-8B 上进一步拉宽 Gap（21.76），远不如 MT-SDPO 的分配结果。
5. **反馈数量不等于反馈质量**：使用更多未验证教师反馈的“w/o Verification”和 Domain Routing 虽然在训练时曝光更多反馈，但最终得分低于 MT-SDPO，表明选择性的逐样本验证比“喂更多反馈”更重要。

## 7. 优点

- **问题维度新颖且具有实际工程价值**：“按样本找正确教师”抓住了多域后训练中“领域匹配失真”的关键，并提供清晰量化诊断支撑。
- **训练方设计干净一致性**：锚点、外部验证反馈、EMA 特权教师三者被组合在同一目标函数中，训练流程只在学生参数上回传梯度；部署时无额外组件，符合实际场景。
- **与可用验证信息严格分离参考答案**：参考答案只进送入验证器/sanitizer 管道，学生和教师 prompt 均不暴露参考答案，可降低标签泄漏风险。
- **消融设计清晰**：固定初始化、更新预算和大部分结构，只改变“分配规则”就能同时比较验证、跨域处理和聚合收益。
- **负面结果和失败模式也被报告**：例如 Llama-3.1-8B 的情况说明方法适用受“头部空间”约束，这在论文中增加了诚信度。

## 8. 不足与局限

- **实验域面较窄**：仅评测“化学、材料、物理”的科学多选题；这些问题都依赖程序化精确比对答案，不能直接外推到开放式回答、生成式任务或奖励维度更复杂的环境。
- **验证体系依赖较强**：方法必须有可靠、可程序化执行的答案验证器；当不能获得精确/可机检的“reference answer”时，论文承认无法直接迁移。
- **存在“无法被正确教师覆盖”的采样边界**：约 34% 训练样本没有教师或学生自身能答对（无锚也无合格教师），该部分完全无法从教师蒸馏中受益，也没有被方法修复。
- **跨模型/跨尺度效果存在明显不平衡**：Qwen 系列只有 8B 有聚合收益，1.7B/4B 是在强域上“回吐”实现均衡；对 Llama-3.1 基本无效。这说明“可提升的头部空间”是收益的必要条件。
- **比较方式偏固定步长**：论文以 pre-specified step 100 作为统一比较点，且承认所有在线方法过程非单调，未用 best checkpoint 会使排名关系可能受训练过程选择影响。
- **对教师学科设置的具体解释较少**：为什么物理是跨域救授最高，或者为何化学匹配教师率如此低等深层原因没有系统分析。
- **总体算力统计不透明**：未给完整 GPU 小时数、在线训练 wall-clock、教师批量推理开销等，因此难以估计实际的相对能耗与扩展成本。
