## 摘要
基于强化学习的知识蒸馏有潜力将复杂推理从教师模型迁移到学生模型，但目前面临一个关键困境：研究者必须在稀疏的结果奖励（提供不足的逻辑指导）与昂贵的神经过程奖励模型（PRM，用于稠密信号）之间做出选择。我们通过引入SPEAR（符号过程评估与对齐奖励）解决了这一问题，这是一种无需训练且即插即用的过程奖励方法，用于序列级策略内蒸馏。SPEAR将自然语言推理轨迹投影到领域自适应的符号里程碑中，为过程级推理对齐提供了高效代理。通过利用最长公共子序列（LCS）将学生探索与教师里程碑对齐，SPEAR提供了稠密且有序的奖励信号，在不需外部神经验证器的情况下强制逻辑一致性。我们在数学、科学和常识推理任务上的实验表明，SPEAR通过高效的稠密过程奖励进行序列级蒸馏，有效弥合了学生与教师模型之间的推理差距。我们的代码和数据可在以下网址获取：https://github.com/zhuochunli/SPEAR。

## Abstract
Reinforcement learning-based knowledge distillation has the potential to transfer complex reasoning from teacher to student models, yet it currently faces a critical dilemma: researchers must choose between sparse outcome-based rewards, which provide insufficient logical guidance, or expensive neural Process Reward Models (PRMs) for dense signals. We resolve this by introducing SPEAR (Symbolic Process Evaluation and Alignment Reward), a training-free and plug-and-play process reward method for sequence-level on-policy distillation. SPEAR projects natural-language reasoning traces into domain-adaptive symbolic milestones, providing an efficient proxy for process-level reasoning alignment. By utilizing the longest common subsequence (LCS) to align student explorations with teacher milestones, SPEAR provides a dense, order-aware reward signal that enforces logical consistency without the need for an external neural verifier. Our experiments across math, science, and commonsense reasoning tasks demonstrate that SPEAR effectively bridges the reasoning gap between student and teacher models via sequence-level distillation with efficient dense process rewards. Our code and data are available at: https://github.com/zhuochunli/SPEAR.

## 一、核心问题与研究动机

- **背景**：将专有大型语言模型（LLM）的复杂推理能力蒸馏到资源高效的小语言模型（SLM）中，是实现模型实际部署的关键路径。传统的离线蒸馏（如 SFT 于教师生成的思维链数据）本质上鼓励“风格模仿”，易受“曝光偏差”影响——学生记住的是语言模式，而非逻辑转换本身，一旦推理早期出错便无法恢复。
- **核心困境**：强化学习（RL）蒸馏虽能在策略上探索自身轨迹，但奖励设计面临两难——
  - **稀疏结果奖励**（如仅验证最终答案）无法在多步逻辑上引导学生，导致“过度思考”或梯度崩溃；
  - **稠密神经过程奖励模型（PRM）** 虽能提供逐步监督，但需额外引入数十亿参数模型，训练与推理开销巨大，且多局限于数学、编程等可确定性验证的正式领域。
- **关键空白**：将过程奖励扩展到科学推理和常识推理等更广泛领域仍具挑战——自然语言推理缺乏明确的结构边界、对语言变化高度敏感。此外，现有研究常忽略教师模型推理轨迹中的丰富中间信号。
- **SPEAR 的定位**：构建一个**免训练、即插即用**的符号化过程奖励框架，在**不依赖神经 PRM**的前提下，为序列级在线策略蒸馏提供**稠密且有序**的过程级监督信号。

## 二、方法论：SPEAR 框架

### 1. 总体核心思想

SPEAR 放弃在 token 层面匹配师生输出，转而将自然语言推理过程**投影为一系列领域自适应的“符号里程碑”**（symbolic milestones），通过最长公共子序列（LCS）对学生探索的符号路径与教师的参考里程碑进行**顺序感知对齐**，从而将奖励从“表面的语言模仿”解耦为“底层逻辑结构的习得”。

### 2. 领域自适应符号锚点提取

SPEAR 定义了三种领域的投影函数 Φ，将高维自然语言推理轨迹映射为低维符号轨迹：

| 领域 | 提取方式 | 符号轨迹形式 |
|---|---|---|
| **数学/形式推理** | 基于正则表达式的投影 | LaTeX 表达式及变量赋值序列（显式排除裸数字，关注推导结构而非常量） |
| **科学推理** | 基于依存句法解析 | 以动词为中心的关系元组序列：(动词原形, 宾语) 或 (主语, 动词原形)，并去重防止循环奖励膨胀 |
| **常识/开放域推理** | 基于名词块（noun chunk）及其统制动词 | (名词短语根词, 动词原形) 状态-动作锚点，如 (ball, throw) → (window, break)，对修饰语和时态变化不敏感 |

### 3. 顺序对齐：LCS-F1

- 使用**最长公共子序列（LCS）**对齐学生轨迹 $A_s$ 与教师轨迹 $A_t$，而非无序度量（如 Jaccard）或表层度量（如 ROUGE）。
- 推理过程奖励定义为 **LCS-F1**：

$$R_{reason} = \frac{2|LCS(A_s, A_t)|}{|A_s| + |A_t|}$$

- **精确率**（|LCS|/|A_s|）惩罚冗余或重复的学生锚点；**召回率**（|LCS|/|A_t|）惩罚遗漏教师里程碑的轨迹，避免“短前缀得满分”和“冗长灌水得满分”两种退化策略。

### 4. 门控组合奖励

最终奖励为**格式合规门控**下的加权组合：

$$R_{spear} = \mathbb{I}_{fmt} \cdot (R_{acc} + \lambda \cdot R_{reason})$$

- $R_{acc}$：最终答案正确性奖励（稀疏信号）
- $R_{reason}$：LCS-F1 过程推理奖励（稠密塑造信号）
- $\lambda = 0.5$ 为主实验默认值

### 5. 算法流程（文字说明）

1. 解析学生响应中的 `<think>` 与 `<answer>` 标记，检查格式合规性；格式不符则返回 0 分；
2. 对答案做最终答案正确性验证（$R_{acc}$）；
3. 根据任务类型分别对师生思维内容提取符号轨迹 $A_s$ 和 $A_t$；
4. 若任一轨迹为空，直接返回 $R_{acc}$；
5. 计算 LCS 长度并求 LCS-F1 得到 $R_{reason}$；
6. 返回 $R_{acc} + λ·R_{reason}$。

该奖励在 RL 训练期间通过动态规划高效计算（每次提取仅需轻量 CPU 端的 spaCy 解析和 LCS 匹配）。

## 六、主要结论与发现

1. **SPEAR 一致优于结果奖励基线**：在数学、科学、常识三大类推理任务、两种学生模型、三种 RL 优化框架下，SPEAR 均带来稳定一致的提升（较基础 RL 方法平均提升约 1.94%–2.29%），且优于格式/答案部分奖励基线 Logic-RL。
2. **任务依赖性明显**：蒸馏增益在数学上最为一致；对 GPQA，SFT 蒸馏甚至优于纯结果奖励 RL，说明“探索正确答案选项”并不总能学到复杂科学推理。常识推理最难通过符号锚点分析获益。
3. **SPEAR 在性能-效率上极具竞争力**：与 7B/8B 神经 PRM 相比，SPEAR 以 ~12MB 轻量解析器的成本实现了可比较（甚至略高）的准确率；数学专用 PRM 在跨领域迁移时表现不佳。
4. **消融验证设计逻辑**：最终答案监督仍是主导学习信号；推理对齐权重 λ 需按任务调优；符号锚点抽象与顺序对齐缺一不可（移除任一都会使性能下降 2–3 个百分点）。
5. **适度的 SFT 冷启动最有利**：30% 数据的 SFT 预热后再做 SPEAR-RL 效果最佳；过高比例的 SFT 会过度约束 RL 探索空间，反而降低后续收益。

## 七、方法亮点

1. **免训练、即插即用**：无需额外神经奖励模型或训练流程，可无缝嵌入 GRPO、Dr. GRPO、DAPO 等现有 RL 管道；
2. **极高的计算效率**：符号提取 + LCS 匹配可在 CPU 上实时运行，每步训练时间仅增加约 1.87%（vs 神经 PRM 的 30.04%）；
3. **稠密且有意义的奖励信号**：利用教师思维过程中的丰富中间信号，通过有序对齐为每一步逻辑转换提供部分学分，防止早期训练梯度崩溃；
4. **逻辑习得与语言表达解耦**：允许学生用自身语言风格表达推理，仅对齐“逻辑骨架”，避免样式模仿与曝光偏差；
5. **奖励抗灌水机制**：LCS-F1 的精确率与召回率联合设计，同时惩罚冗余啰嗦与关键步骤遗漏；
6. **领域自适应性**：针对不同推理类型设计专门的符号投影函数（数学表达式、因果依赖、状态转换），并实证验证了错配提取器会导致性能下降——为提取器领域设计提供因果依据；
7. **较严谨的实验架构**：跨基座、跨 RL 框架、跨基准、含消融/迁移/鲁棒性/人工案例分析的多层次验证。

## 八、不足与局限

1. **符号匹配的语义盲区**：依赖精确符号匹配的 LCS 无法捕捉“语义等价但结构不同”的推理轨迹，可能与教师符号次序有别的正确替代路径获得较低奖励——尤其在开放域任务中此风险更高。
2. **对教师质量的高度依赖**：假设教师生成的思维链是可靠推理轨迹，但 LLM 解释可能含有冗余、噪声甚至次优步骤，这些会被当作“黄金里程碑”传递给学生。
3. **提取管道脆弱性**：当前实现依赖规则提取（正则匹配 + 依存解析），对解析错误和格式不一致较敏感，跨语言、跨文体泛化性受限。
4. **现实推理的覆盖面有限**：教师的每次推理仅为众多可行路径之一，以其单一轨迹作为对齐目标本质上存在“单参考偏差”；对高度开放式推理任务，该框架的适用性仍需更多验证。
5. **任务局限**：在常识推理上提升最微弱，说明某些依赖隐含知识和丰富语言变体的推理任务并不容易用符号里程碑刻画。
6. **探索范围有限**：仅做了序列级蒸馏，未涉及 token 级逆向 KL 蒸馏等方法——这些可能是更优的蒸馏范式。
7. **指标呈现不足**：未报告运行标准差、置信区间或显著性检验；缺少从“过程对齐分数”到“最终准确率”的剂量-反应关系分析。在 RL 超参数选择、训练步数/收敛性等方面也未详细图示说明。
