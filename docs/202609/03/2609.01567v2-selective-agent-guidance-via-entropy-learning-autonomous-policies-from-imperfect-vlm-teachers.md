## 摘要
视觉-语言模型（VLMs）为交互式决策提供了有用的先验，但直接将它们用作策略既昂贵又脆弱：必须在每一步查询它们，无法从环境交互中改进，并且可能重复系统性错误。我们研究如何从一个在线的、昂贵的、不完美但信息丰富的 VLM 教师那里学习一个廉价的自主策略。我们提出了 SAGE（基于熵的选择性智能体引导），该框架仅在学习者不确定时查询 VLM，在训练期间执行建议的动作，并将引导提炼到一个轻量级的强化学习（RL）策略中。由于 VLM 的建议并非总是可靠，SAGE 可以使用环境导出的优势来加权教师动作蒸馏，而不是将所有建议视为同等有用。在稀疏奖励的视觉推理和导航任务中，SAGE 学习到的策略在评估时无需 VLM 引导即可运行，并在多种环境中优于无引导的 RL，包括学到的策略超过其 VLM 教师的环境。结果表明，当 VLM 能帮助智能体发现高奖励轨迹时，选择性引导最为有益；而当无引导的探索已经成功或教师动作无法带来有信息量的经验时，选择性引导用处较小。SAGE 还通过在训练步骤的一部分上提示教师，并且在部署时不需要 VLM 调用，从而减少了 VLM 的使用。总的来说，我们的结果表明，VLMs 不需要被用作固定策略才能发挥作用；相反，它们可以作为临时的、不完美的引导来源，其价值通过交互得到检验并内化。

## Abstract
Vision-Language Models (VLMs) provide useful priors for interactive decision-making, but using them directly as policies is expensive and brittle: they must be queried at every step, do not improve from environment interaction, and can repeat systematic errors. We study how to learn a cheap autonomous policy from an online, expensive, and imperfect but informative VLM teacher. We propose SAGE (Selective Agent Guidance via Entropy), a framework that queries a VLM only when the learner is uncertain, executes the suggested action during training, and distills guidance into a lightweight Reinforcement Learning (RL) policy. Because VLM advice is not always reliable, SAGE can weight teacher-action distillation using environment-derived advantages rather than treating all suggestions as equally useful. Across sparse-reward visual reasoning and navigation tasks, SAGE learns policies that act without VLM guidance at evaluation time and improves over unguided RL in several environments, including settings where the learned policy exceeds its VLM teacher. The results show that selective guidance is most beneficial when the VLM can help the agent discover high-reward trajectories, and less useful when unguided exploration already succeeds or teacher actions do not lead to informative experience. SAGE also reduces VLM usage by prompting the teacher only on a fraction of training steps and requiring no VLM calls at deployment. Overall, our results suggest that VLMs don't need to be used as fixed policies to be useful; they can instead act as temporary, imperfect sources of guidance whose value is tested and internalized through interaction.

## 1. 论文的核心问题与整体含义

**研究背景与动机：**
- 强化学习（RL）智能体通常从零开始（tabula rasa）通过试错改进，在稀疏奖励环境中，随机探索很难发现成功轨迹，导致学习效率极低，尤其在需要视觉理解、符号推理或多步规划的交互式任务中。
- 视觉语言模型（VLM）通过大规模预训练具备丰富的视觉与语言先验，看似适合作为交互式决策智能体，但存在三大缺陷：
  - **成本高**：每一步决策都需要提示 VLM，部署昂贵且缓慢；
  - **无法改进**：冻结模型不随环境交互而改善；
  - **错误重复**：一旦产生系统性感知或推理错误，会持续犯同样的错。
- 因此论文提出一个问题：能否**不把 VLM 当作部署的最终策略**，而是将其当作一个**在线的、昂贵的、不完美但又具备信息量的教师**，在训练期间提供有针对性的干预，帮助轻量级 RL 策略克服稀疏奖励的探索瓶颈？

**研究问题：**
> 如何基于**不确定性**进行选择性查询，并将 VLM 教师的不完美引导与**环境奖励反馈**结合，蒸馏出一个在评估时完全自主、且无需 VLM 调用的轻量级策略？

**SAGE 的整体理念：**
- VLM 不必成为固定策略才有价值；可以充当**临时、不完美的引导源**，其价值通过环境交互被检验和内化（"VLMs don't need to be used as fixed policies to be useful"）。

## 2. 论文提出的方法论：SAGE（Selective Agent Guidance via Entropy）

### 2.1 问题设定

- 环境建模为 MDP `M = <S, A, R, T, γ, ρ₀>`，状态包含 RGB 图像和（如有）文本任务信息；
- 存在一个冻结的 VLM 教师策略 `π_T(·|s_t)`：可查询、但昂贵且不完美；
- 目标：学习一个轻量级策略 `π_θ`，在**评估时不查询 VLM**，同时**最小化训练期间对教师的查询次数**。

### 2.2 熵门控的选择性引导（Entropy-Gated Selective Guidance）

- 用策略的**归一化熵**作为不确定性的轻量级代理：

  `H_t = -Σₐ π_θ(a|s_t) log π_θ(a|s_t)`，并归一化为 `Ĥ_t = H_t / log|A| ∈ [0,1]`；

- **门控机制**：当 `Ĥ_t > ν`（ν 为固定阈值）时，查询 VLM 教师并执行其返回的动作；否则智能体按自身策略采样动作：

  ```
  a_t ~ { π_T(·|s_t) if Ĥ_t > ν
          π_θ(·|s_t) otherwise }
  ```

- 每个转移被标记为 `g_t ∈ {0,1}`，区分教师生成与学生生成的轨迹；
- 使用**缓存**（cache）存储 VLM 在相同状态下的返回，进一步减少提示开销。

### 2.3 分区损失函数（Partitioned Loss）

关键洞察：教师提供的动作并非来自智能体自身策略，直接当作 PPO 动作会出现**off-policy 不匹配**，尤其当学生对动作赋予低概率时，重要性比率会很大。因此：

- **B_π**（学生生成轨迹）：应用标准 PPO 裁剪损失 `L_PPO`；
- **B_T**（教师引导轨迹）：不使用 PPO 策略损失，而是通过行为克隆（BC）信号传递，避免重要性权重爆炸；
- **价值函数**在全部缓冲 B（B_π ∪ B_T）上训练，因为稀疏奖励下教师引导轨迹可能是训练早期唯一能观察到成功轨迹的来源。

### 2.4 优势加权行为克隆（AWBC）

- VLM 教师不完美，盲目克隆所有教师动作会让学生对错误动作变得自信，降低未来求助概率，导致策略退化；
- SAGE 采用 **Advantage-Weighted Behavioral Cloning（AWBC）**：
  - 训练目标：`L_AWBC(θ) = -E_{t∈B_T}[w_t · log π_θ(a_t|s_t)]`
  - 样本权重：`w_t = f(Â_t)`，其中 `f(Â_t) = exp(Â_t/τ)`（CRR 风格），权重截断到 20 以保证稳定性；
  - 含义：对估计能带来高回报的教师动作赋予更大蒸馏权重，对低回报动作降权；
  - 论文也坦诚地指出：训练早期 critic 可能不具信息量，因此 AWBC 在初期行为类似普通 BC，**实证上并不总比普通 BC 更优**，属于可选改进项而非核心贡献。

### 2.5 SAGE 总目标

`L_SAGE = L_PPO(θ) − c_H·Hπ(θ) + β·L_AWBC(θ) + c_v·L_value(θ)`，分别作用于 B_π 和 B_T 子集。

### 2.6 方法核心逻辑总结

| 设计维度 | SAGE 的处理方式 |
|---|---|
| 何时查询教师 | 仅当策略熵超阈值（不确定性高） |
| 如何执行教师动作 | 在训练中直接执行，产生探索轨迹 |
| 如何蒸馏教师知识 | 分区：学生轨迹走 PPO，教师轨迹走 BC/AWBC |
| 如何处理教师不可靠 | 用环境优势加权蒸馏，而非盲从 |
| 评估时 | 零 VLM 调用，仅靠轻量策略 |

## 6. 主要结论与发现

1. **SAGE 在多个稀疏奖励环境中显著超越 PPO**：CardMaze 上 PPO≈0.007 而 SAGE 达到 1.000（理论最优）；GoToDoor、Fetch、ALFWorld 也有改善。
2. **SAGE 可以超过其 VLM 教师**：CardMaze 的 VLM-as-Policy 为 0.000，而 SAGE 学到最优策略 1.000——说明 VLM 不需要本身很强，只需引导发现高奖励轨迹即可。
3. **选择性引导价值取决于环境**：教师最有用的场景是"无引导的 RL 探索无法找到稀疏奖励"（如 CardMaze、FrozenLake）；当 PPO 已经能解决（如 LavaGap）或教师动作不能产生有信息量的经验时，引导收益小，甚至有害。
4. **查询成本大幅降低**：SAGE 仅在训练步数的 ~1.2%–13.3% 调用 VLM（CardMaze 最高，EZPoints 最低），而基准方法接近 100%；且 SAGE 在部署时零 VLM 调用。
5. **蒸馏信号是核心，优势加权不是**：去掉 BC 损失后所有环境崩溃（Oracle 下也崩溃），说明“执行教师动作”本身不构成有效的学习信号；AWBC vs BC 并无稳定差异，AWBC 是可选改进。
6. **教师直接表现无法预测其教学价值**：Gemma 在 EZPoints 的直接策略比 Qwen 差很多（−3.400 vs 0.175），但 Gemma 引导的 SAGE 在该任务达到最优 10.0，而 Qwen 引导的 SAGE 为 0.0，揭示了“教学能力与政策能力之差”可能是关键变量。
7. **长程训练（5M 步）验证了引导能改变可发现性**：在 FrozenLake、EZPoints、CardMaze 上，即使训练 100 倍长的 PPO 仍基本失败，而 SAGE + Oracle 接近最优——引导不只是加速，而是让不连续/不可发现的轨迹变成可达。
8. **VLM 不应也被不能作为固定教师使用**：随机教师导致 LavaGap 从 0.945 掉到 0.000；使用 SAGE 的前提是教师保留一定任务能力，但未必需要一个能在闭环中取得高分的教师。

---

## 7. 优点

1. **方法新颖且问题设定务实**：没有假设教师是完美专家，也没有无差别信任 VLM，而是把 VLM 放在"有价值的教师+环境验证"的位置，区分了简单注入先验和基于环境反馈内化先验。
2. **系统化的不确定性处理**：归一化熵作为不确定性信号模型无关、零附加计算成本，同时门控阈值可在 0.05–0.45 范围内稳定工作，便于复现。
3. **分区损失的思路严谨**：它清楚地规避了教师动作在 PPO 中所产生的 off-policy 比率爆炸问题，是一种值得推广的模块化设计。
4. **教师质量是一个独立变量，实验设计包含该变量**：同时评估了 Qwen、Gemma、随机、Oracle，使结论不局限于单一 VLM。
5. **给出了“哪些条件下引导价值最大”的探索性结论**：引导在奖励最稀疏、探索最难的环境最有效；在引导“有用但非充分”的场景中也总结了失败机制。
6. **考虑了实际部署成本**：除了性能，还记录了 VLM 查询次数和累计曲线，并在评估时完全去掉教师，贴近真实应用中对成本的要求。
7. **实验覆盖面广且分解度高**：从视觉导航（MiniGrid）到算术推理（EZPoints）、符号匹配（CardMaze，一个新环境）到家庭交互（ALFWorld），任务难度跨越大。

---

## 8. 不足与局限

1. **熵作为不确定性代理是有局限的**：
   - 混淆了对策略动作的“真实不确定性”和“动作多模态性”（熵高不代表需要帮助）；
   - 未直接估计“该状态下教师是否会有帮助”，可能触发无效查询或在关键状态不触发。
2. **只限定在离散动作空间**：论文没有打通连续控制，也承认 VLM 在给出精确扭矩/速度等数值动作上表现不佳；扩展到 VLA（Vision-Language-Action）模型或高层次技能抽象可能是下一步。
3. **训练早期 critic 不具有区分性**：AWBC 在早期退化为普通 BC，很难有效过滤不良教师动作；论文自己也承认 AWBC 在本实验中并不总是优于普通 BC，因此其价值只在理论上成立而未得到一致实证。
4. **对“信息量低的教师”鲁棒性不足**：随机教师和 Gemma 在 MiniGrid 系列上可以导致完全负迁移；SAGE 缺乏一种在线机制来预先评估教师的有用性，可能浪费查询甚至破坏策略。
5. **种子数与统计可靠性有限**：所有实验仅用 3 个随机种子，部分表格标准差远超均值（如 FrozenLake 的 0.103±0.111、CardMaze Oracle 的 0.663±0.574），统计显著性不强。
6. **评估指标偏向“峰值”而非“稳定收敛”**：论文采用“训练过程中平均峰值的回报”，提供的是策略上限而非稳定性，使用最终回报或训练曲线会更稳健。
7. **ALFWorld 实验阶段探索有限**：训练预算偏低（40k 步），且作者就任务真实挑战给出的基线并不充分，无法得出明确结论。
8. **基准选择的局限性**：未包括一些更新的通用方法，如更现代的 VLM-微调策略（RL4VLM）、偏好蒸馏，也未对这些基准中的成本进行全面平衡分析（例如 VLM-as-Policy 在训练后仍需 VLM 调用，表中并未体现真实总成本）；报告并未完全公平地核算“训练（含查询+额外生成）+ 部署”的总 GPU 成本。
9. **没有明确分析错误导向的引导**：当 VLM 建议在完成该动作后不可避免地导致失败时，SAGE 如何避免把这种失败与引导关联，这个问题在论文中缺少一个单独的因果分析。
10. **贡献的架构与推理成本不完全透明**：模型规模是 27B 参数规模（Qwen3.5 / Gemma3），但论文没有给出实际单步推理的时间或成本估算，对“实际部署中 VLM 使用成本和节省成本”没有量化。

## 总结（续）

SAGE 提出了一种面向“昂贵且不完美的 VLM 教师”的在线选择性引导框架：通过熵门控决定何时求助教师，以分区损失规避 off-policy 失真，并用环境优势信号对教师知识进行批判性蒸馏。其核心理念——**VLM 不必成为固定策略才有价值，只需在训练早期提供“可被环境验证的线索”**——为稀疏奖励下的 RL 训练开辟了一条兼顾性能与部署成本的新路线。整体而言，SAGE 在设计上思路清晰、实验覆盖面广，在多个任务上取得了显著且可复现的提升，尤其证明了“弱于策略的教师也能教出强策略”这一反直觉结论；但其依赖 3 个种子的统计基础、熵作为不确定性代理的固有局限、以及对低质量教师鲁棒性不足等问题，也使其结论仍需在更大规模和更多样化的任务上加以验证。若未来能在连续控制、更高质量的不确定性估计、在线教师质量评估等方向上进一步拓展，该框架有望成为 VLM 辅助 RL 训练的一种通用方法论范式。

**总体评价（0–10）：8.2 / 10** —— 问题设定新颖务实，方法模块化且可复现性强，实验证据较充分；主要扣分点在于统计严谨性（种子数少、峰值指标）、教师鲁棒性缺失分析，以及缺少实际部署成本的量化对比。
