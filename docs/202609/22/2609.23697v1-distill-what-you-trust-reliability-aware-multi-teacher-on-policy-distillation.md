## 摘要
多教师同策略蒸馏允许学生模型在自身轨迹上向互补的专家模型学习。然而，领域路由方法为每个样本选择一个教师，并在整个回复过程中保持固定。这种设计既依赖于混合训练语料常常缺乏的标签，也无法在一条轨迹内所需专长发生变化时自适应地调整教师选择。我们提出 TrustMOPD，用无需标签的词元级监督分配取代样本级教师选择。在每个由学生模型生成的前缀处，TrustMOPD 使用每个专家模型相对于共享的 RL 前参考模型的 RL 诱导位移，作为局部可靠性的代理指标，跨教师校准这些得分，并构建加权的蒸馏目标。在数学、代码和指令遵循方面，TrustMOPD 优于最强的无标签基线，将 SingleCap 上的恢复率从 54.4% 提高到 91.5%，将 MultiCap 上的恢复率从 54.5% 提高到 98.0%，同时在 SingleCap 上接近基于标签的 MOPD。将词元级权重独立于学生模型生成的前缀进行随机化，其表现并不优于均匀加权，这支持了将监督条件化于不断演化的生成上下文的重要性。

## Abstract
Multi-teacher on-policy distillation allows a student to learn from complementary specialists on its own trajectories. Domain-routed approaches, however, select one teacher per example and keep it fixed throughout the response. This design both depends on labels that mixed training corpora often lack and cannot adapt teacher selection when the expertise required changes within a trajectory. We propose \textbf{TrustMOPD}, which replaces example-level teacher selection with label-free, token-level supervision allocation. At each student-generated prefix, TrustMOPD uses each specialist's RL-induced displacement from a shared pre-RL reference as a proxy for local reliability, calibrates these scores across teachers, and constructs a weighted distillation target. Across mathematics, code, and instruction following, TrustMOPD outperforms the strongest label-free baseline, increasing the recovery ratio from $54.4\%$ to $91.5\%$ on \textsc{SingleCap} and from $54.5\%$ to $98.0\%$ on \textsc{MultiCap}, while approaching label-based MOPD on \textsc{SingleCap}. Randomizing token-level weights independently of the student-generated prefix performs no better than uniform weighting, supporting the importance of conditioning supervision on the evolving generation context.

## 一、核心问题与研究动机

- **背景**：多教师同策略蒸馏（MOPD）让学生模型在自身生成的轨迹上向多个互补专家学习，从而在统一训练过程中获得数学、代码、指令遵循等多领域能力。
- **核心痛点**：现有的**领域路由式 MOPD** 存在两个根本问题：
  1. **依赖领域标签**：混合训练语料往往缺乏唯一的领域标签（如同时需要数学推理、代码验证与 JSON 格式化的提示）。
  2. **教师选择全程固定**：一条回复内不同 token 阶段所需的专长会变化（如先做数学推导、再做代码验证、最后做格式化），单一教师无法适配全轨迹。
- **更本质的洞察**：
  - **全局领域专长 ≠ 局部监督可靠性**：教师擅长某领域，不代表它在当前学生状态下的监督信号值得迁移。
  - **师生分歧不足以衡量可靠性**：大分歧可能来自有用专长，也可能来自风格偏好等无需学习的特质。
  - 因此，可靠的可靠性估计应当满足三点：**依赖当前状态、跨教师可比、无需领域标签**。

## 二、方法论：TrustMOPD

### 2.1 核心思想
用每个专家相对于**共享 RL 前参考模型**的**RL 位移**作为局部可靠性代理，并将其转化为 token 级监督权重，替代传统基于标签的样本级 one-hot 路由。

### 2.2 关键技术细节

1. **RL 位移定义（局部可靠性代理）**
   - 对每个教师 $k$ 与学生状态 $s_t$，计算中心化对数概率比：
     $$d_{k,t}(v) = \log\frac{q_{k,t}(v)}{q_{ref,t}(v)} - \frac{1}{|V|}\sum_{v'}\log\frac{q_{k,t}(v')}{q_{ref,t}(v')}$$
   - 位移幅度：$\rho_{k,t} = \|d_{k,t}\|_2$（去方向、保幅度，非负标量）
   - **直觉**：当教师专长在当前状态被激活时，其偏好显著偏离参考；未激活时则接近参考。

2. **跨教师校准（去除教师尺度差异）**
   - 在无标签校准集 $D_{cal}$ 上用蒸馏前学生 $\pi_{\theta_0}$ 估计每个教师的平均位移 $\mu_k$，并固定不变：
     $$r_{k,t} = \rho_{k,t}/\mu_k$$
   - 校准后各教师在校准分布上均值为 1，$r_{k,t}>1$ 表示该教师专长比平时表达得更强。

3. **权重归一化（幂归一化）**
   $$w_{k,t} = \frac{r_{k,t}^{\gamma}}{\sum_{j=1}^{K} r_{j,t}^{\gamma}},\quad \sum_k w_{k,t}=1$$
   - $\gamma>0$ 控制分配集中度，越大越偏向高可靠性教师。

4. **可靠性加权蒸馏目标**
   - 将标准 MOPD 的 one-hot 权重替换为 $w_{k,t}$：
     $$\mathcal{L} = \mathbb{E}\Big[\frac{1}{|y|}\sum_t \sum_k w_{k,t} D_{KL}(p_{\theta,t}\|q_{k,t})\Big]$$
   - 权重在采样的 rollout 上计算并视为常数（不通过分配过程反传梯度），每 token 权重和为 1，**不改变总监督量与更新尺度**，仅改变分配方式。

5. **理论支撑**
   - **定理 1**：在 KL 正则化序列生成的收敛最优解下，$d_{k,t}(v)$ 恰好等于动作相关效用对比 $Q^\star_k(s_t,v)-\bar{Q}^\star_{k,t}$ 除以 $\beta_k$。
   - **推论 1**：除以 $\mu_k$ 可抵消各教师 KL 系数差异，使 TrustMOPD 偏好**相对自身基线效用对比最大**的专家。

## 三、实验设计

### 3.1 模型与数据
- **骨干模型**：SmolLM3-3B（迁移实验用 DeepSeek-R1-Distill-Qwen-7B）。
- **教师构建**：从同一个混合域 SFT 检查点出发，分别做数学、代码、指令遵循三个领域 RL，得到 3 个教师；该 SFT 检查点同时作为学生初始化 $\pi_{\theta_0}$ 与共享参考 $\pi_{ref}$。
- **训练集**（各 7,458 条，排除评测数据）：
  - **SINGLECAP**：来自 OpenMOPD，每样本有唯一域标签（数学 1,540 / 代码 1,870 / 指令 4,048）。
  - **MULTICAP**：仿照 MathIF 在数学与代码题上加程序化可验证指令约束，构成双能力提示，无唯一域标签。

### 3.2 Benchmark
- 数学：AIME25 / AIME26
- 代码：LiveCodeBench v5/v6
- 指令遵循：IFEval / IFBench
- 每域得分为两项基准均值，**Overall** 为三域无权重平均；域内采样温度分别为 0.6 / 1.0 / 1.0，样本数 16 / 5 / 1；5 个随机种子取末检查点均值 ± 标准差。

### 3.3 对比方法
- **有标签 Oracle 参考（不计入排名）**：MOPD（基于 ground-truth 域标签）、Oracle-routed teachers。
- **无标签蒸馏基线**：Uniform（$w=1/K$）、Random（每个 token 从教师单纯形均匀采样）、三个单教师变体。
- **无训练参考**：初始学生、参数平均教师（Model Soup）、Oracle 路由教师。

### 3.4 消融与迁移实验
- 代理指标消融：用教师置信度 / 负熵 / 师生 KL 替换 RL 位移。
- 校准消融：去掉 $\mu_k$（设 $\mu_k=1$）。
- 粒度消融：Response-level（用 rollout 平均权重替代 token 级）。
- 敏感度：$\gamma \in \{3,5,7,9\}$。
- 迁移：换骨干（DeepSeek-R1-Distill-Qwen-7B）、换数据源（独立于 OpenMOPD 的提示）。

## 六、主要结论与发现

1. **主结果**：TrustMOPD 在两种设定下均为最强无标签方法。
   - SINGLECAP：Overall 30.04±0.47（+5.15 vs 初始学生），仅比有标签 MOPD（30.18±0.25）低 0.14。
   - MULTICAP：Overall 30.41±0.60（+5.52），超过最强无标签基线 Random 2.45 分。
   - 恢复率从 54.4% → 91.5%（SINGLECAP）、54.5% → 98.0%（MULTICAP）。
2. **分配行为验证**：
   - SINGLECAP 上呈现明显对角优势：数学/代码/IF 教师在其对应域平均权重 0.69 / 0.65 / 0.99，正确教师 margin 为正的 rollout 占比 98% / 91% / 100%。
   - MULTICAP 上相关教师联合获得 0.89 / 0.75 / 0.73 权重；单个响应内权重会随能力需求变化（数学推导阶段数学教师高，得到结果后 IF 教师主导格式化）。
3. **消融结论**：
   - RL 位移优于置信度、负熵、师生 KL 等替代代理（掉 1.63–3.06 分）。
   - 校准与 token 级分配在 MULTICAP 上贡献更大（去掉 $\mu_k$ 掉 1.28 分；response-level 掉 0.92 分），SINGLECAP 上影响较小。
4. **敏感度**：所有测试 $\gamma$ 下均优于对应 Uniform；SINGLECAP 上增益稳定（5.11–5.40），MULTICAP 上 $\gamma=7$ 最佳，$\gamma=9$ 反而下降，说明过度集中会放大 $\rho_{k,t}$ 误差并压制互补教师。
5. **迁移性**：在 DeepSeek-R1-Distill-Qwen-7B 上分别提升 7.49 / 6.30 分；在独立数据源上增益略降但仍达 4.58 / 4.30 分，且仍超过在 OpenMOPD 上训练的最强无标签基线。
6. **随机化 token 权重并不优于均匀权重**，证明性能提升来源于依据生成上下文的条件化分配，而非随机扰动。

## 七、优点与亮点

- **问题切入精准**：清晰指出“全局专长 ≠ 局部可靠性”“师生分歧 ≠ 可学信号”两大误区，动机论证扎实。
- **方法简洁且原则性强**：仅依赖教师与共享参考的 RL 位移，无需域标签、路由器或辅助模型；每 token 权重和为 1，不改变损失尺度，与现有 OPD 框架高度兼容。
- **理论支撑**：定理 1 与推论 1 从 KL 正则化最优策略出发，给出位移与隐式效用对比的等价关系，为方法提供了可解释的数学依据。
- **实验严谨**：5 种子 + 标准差；区分 Oracle 与无标签方法；随机权重、单教师、无训练参考等多重对照；消融覆盖三大组件；迁移实验覆盖骨干与数据源。
- **可解释性强**：权重可视化清晰展示了对角优势与响应内动态切换，验证了方法机理而非仅报告最终分数。
- **实用价值**：在混合语料无标签场景下接近有标签 Oracle，显著降低数据标注依赖。

## 八、不足与局限

- **强依赖“共享参考模型”假设**：方法要求所有教师均由同一 RL 前模型经领域 RL 得到；若教师来自异构基座（不同架构、不同预训练），RL 位移的语义与可比性会失效，应用范围受限。
- **未披露算力资源**：缺少 GPU 型号、数量、训练时长与总计算量，难以评估训练成本与可复现性。
- **模型规模覆盖有限**：仅在 3B（SmolLM3-3B）与 7B（Qwen-7B）规模验证，未在更大模型或更多教师数量（$K>3$）下测试可扩展性。
- **MULTICAP 缺乏有标签 Oracle 对比**：因无唯一域标签，无法与 MOPD 直接比较，仅能对 Uniform/Random/单教师；MULTICAP 上的恢复率（98.0%）是相对于无标签基线的口径，解释时需注意。
- **校准依赖无标签校准集**：$\mu_k$ 由蒸馏前学生在校准分布上的平均位移估计，若校准分布与实际训练/推理分布偏差较大，可能影响权重校准质量。
- **代理指标的可靠性边界**：位移大未必总是“更值得学”——论文以“教师已在其目标域验证过”为前提假设，该假设在教师 RL 质量不稳定时可能不成立。
- **缺少失败案例分析**：未系统分析分配错误（如代码教师 margin 更分散）的具体成因与缓解手段。
- **未报告训练稳定性/收敛曲线细节**：如损失曲线、不同 $\gamma$ 下的收敛行为等，对复现与调参参考有限。
