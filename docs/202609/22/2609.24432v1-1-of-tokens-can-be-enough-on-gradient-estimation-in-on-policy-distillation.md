## 摘要
稀疏同策略蒸馏（OPD）将教师监督分配给由学生生成的轨迹中的一小部分 token。然而，当教师的有用指导的梯度由采样的下一个 token 估计得到时，它可能产生带噪的更新。我们在信息几何中研究固定前缀下的这一估计问题，并基于信噪分解提出信息效率比（IER）。IER 刻画了在最优标量基线下的相对梯度估计误差。一种候选集近似使得能够基于 IER 及其与现有有用性评分的组合进行 token 选择，同时保留采样的反向 KL 训练目标。在数学与医学推理任务上，加入 IER 可在多种设置下改进现有选择器；在 0.1%--1% 的小 token 预算下，稀疏配置可匹配或超过不进行 token 选择的完整 OPD。这些结果支持在分配稀疏监督时同时考虑有用性和梯度估计可靠性。我们的代码见 https://github.com/BruceSheng1202/IER-OPD。

## Abstract
Sparse on-policy distillation (OPD) allocates teacher supervision to a small subset of tokens in student-generated trajectories. However, useful teacher guidance can yield a noisy update when its gradient is estimated from a sampled next token. We study this estimation problem at a fixed prefix in information geometry and propose an information-efficiency ratio (IER) based on a signal-to-noise decomposition. IER characterizes relative gradient estimation error under an optimal scalar baseline. A candidate-set approximation enables token selection based on IER and its combination with existing usefulness scores, while retaining the sampled reverse-KL training objective. On mathematical and medical reasoning tasks, adding IER improves existing selectors in multiple settings, with sparse configurations matching or exceeding full OPD without token selection at small token budgets of 0.1\%--1\%. These results support accounting for both usefulness and gradient-estimation reliability when allocating sparse supervision. Our code is available at https://github.com/BruceSheng1202/IER-OPD.

# 论文总结：《1% 的 Token 就足够：论同策略蒸馏中的梯度估计》

## 1. 核心问题与研究动机

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）让学生模型在自己的 rollout 轨迹上接受教师模型的下一 token 监督，相比序列级损失提供了密集的 token 级信号。
- **稀疏 OPD 的兴起**：由于并非所有 token 对蒸馏贡献相等，近期研究通过重要性、学生不确定性、可教性、前缀位置等启发式"有用性"分数，只对少量 token 施加监督。
- **被忽视的维度**：对于给定前缀，反向 KL 的梯度本应是对全词表的期望，但实践中通常只从**一个采样的下一 token** 来估计，导致即使教师指导本身有用，梯度估计也可能带有很大采样噪声。
- **核心矛盾**：
  - 基于"有用性"的选择可能保留梯度估计噪声极大的 token；
  - 基于"可靠性"的选择可能保留梯度实际价值很低的 token；
  - 因此**有效选择应同时考虑有用性与梯度估计可靠性两个维度**。
- **整体含义**：作者主张 token 选择需要新增"梯度估计可靠性"这一正交轴，并据此提出信息效率比（IER），在极低 token 预算（0.1%–1%）下即可匹配甚至超越全量 OPD。

## 2. 方法论

### 2.1 核心思想
- 在固定前缀下，从**信息几何（Fisher 几何）**角度分析采样反向 KL 梯度的信号与噪声，导出信噪比（即 IER），用以衡量"用有限样本估计期望梯度的可靠程度"。
- IER 是**可靠性**指标，而非**有用性**指标；因此需与现有有用性分数组合使用。

### 2.2 关键技术细节
- **设定**：给定学生前缀 $s$，学生分布 $p_a=\pi_\theta(a|s)$，教师分布 $q_a=\pi_T(a|s)$，优化 $D_{KL}(p\|q)$。
- **局部梯度**：$g = E_p[\rho(a)\phi_a]$，其中 $\rho(a)=\log(p_a/q_a)$，$\phi_a = e_a - p$（softmax 得分函数）。
- **标量基线**：引入与动作无关的基线 $b$，估计量 $\hat g_b(a)=(\rho(a)-b)\phi_a$ 保持无偏，可降低方差。
- **定理 1（信号–噪声分解）**：
  - 信号：$\|g\|^2_{F^+} = \mathrm{Var}_p[\rho(a)]$
  - 噪声：$E_p[\|\hat g_b - g\|^2_{F^+}] = E_p[(\rho(a)-b)^2 L(a)] - \mathrm{Var}_p[\rho(a)]$，其中杠杆因子 $L(a)=(1-p_a)/p_a$
  - **最优基线**：$b^\star = \frac{E_p[\rho(a)L(a)]}{E_p[L(a)]}$，是唯一全局最小化方差者。
- **IER 定义**：$\mathrm{IER} = \frac{\text{Signal}}{\text{Noise}}$；$\mathrm{IER}^{-1}$ 等于最优基线下单样本估计的相对 MSE。
- **推论 1**：若从同一前缀独立采样 $K$ 个动作求平均，则相对 MSE $= \frac{1}{K\cdot \mathrm{IER}}$；即达到相对误差 $\epsilon$ 需 $K \ge 1/(\epsilon\cdot \mathrm{IER})$。

### 2.3 候选集近似与 token 选择流程
- **计算开销问题**：全词表统计不可行，故构造候选集 $C = \mathrm{TopK}(z_\theta)\cup\mathrm{TopK}(z_T)\cup\{a\}$，实验取 $K=16$（$|C|$ 在 16–33 之间）。
- **近似步骤**：
  1. 在 $C$ 上对师生 logits 分别做 softmax 归一化，缺失 logit 赋 $-\infty$（实现中取极小值并重归一化）；
  2. 计算并裁剪对数似然比 $\hat\rho(a)=\mathrm{clip}(\log\frac{\hat p(a)}{\hat q(a)}, -30, 30)$；
  3. 按定理 1 计算近似最优基线 $\hat b^\star$ 与 $\widehat{\mathrm{IER}}$（分母加 $\epsilon=10^{-8}$ 防除零）。
- **与有用性分数融合**：
  - 先对批次内 IER 排名归一化得 $r_j\in[0,1]$，有用性分数归一化为 $u_j\in[0,1]$；
  - **IER-OR**：$s^{\mathrm{OR}}_j = 1-(1-u_j)(1-r_j)$（任一维度高即可入选）；
  - **IER-AND**：$s^{\mathrm{AND}}_j = u_j r_j$（两维度都高才入选）。
- **训练目标**：仍保留采样的反向 KL 目标，仅在选中的 token 上施加监督；批次级预算，每条约至少保留一个 token。

## 6. 主要结论与发现

1. **IER 作为独立选择器具有竞争力**：0.1% 预算下，IER 在 AIME26/HMMT26 上接近全量 OPD，且在 Qwen3 对的 4 个 benchmark 中有 3 个超越全量 OPD；医学上 0.1% 预算（约每条轨迹一个 token）HealthBench overall 达 45.25，接近全量 OPD 的 45.77。
2. **IER 与有用性分数互补**：加入 IER 后多数设置下提升现有选择器；TIP+IER-AND 在 0.1% 预算下在 Qwen3 对上持续超越全量 OPD；医学上 Prefix+IER-OR 从 38.30/8.68 提升到 44.98/19.49。
3. **IER 与有用性选择器选择的是不同 token**：除 Prefix 外各选择器整体 Spearman 排名相关性高，但 top-10% 选择的 Jaccard 相似度低，预算越小差异越明显。
4. **更高 token 预算不总是更好**：性能对预算非单调，1%–5% 常已足够，更高预算可能收益甚微甚至下降。
5. **thinking-on 与 thinking-off 均受益**：thinking-on 下 TIP 单独可能差于全量 OPD 甚至差于学生，但 TIP+IER-AND 在多数情况下改善性能。
6. **IER 分数呈重尾分布**：通常不到 0.1% 的 token IER 大于 1（噪声超过信号），且 IER 随 token 位置靠后而下降。

## 7. 优点

- **理论视角新颖**：首次从信息几何（Fisher 度量）角度对采样 OPD 梯度做信号–噪声分解，给出闭式最优基线与 IER，与策略梯度方差缩减文献自然衔接。
- **可组合性强**：IER 被设计为与任意有用性分数通过 OR/AND 软算子组合，不改变原有反向 KL 训练目标，工程上易接入。
- **计算可行**：候选集近似（Top-K 师生 logits 并集）把全词表统计降到 $K=16$，训练效率实验显示开销仅增加约 2.2%–2.5%。
- **实证覆盖较广**：跨数学/医学、强到弱/大到小、多预算、双推理模式，并附大量附录对比图与 token 选择可视化示例。
- **诚实报告失败案例**：明确指出与 Entropy 的组合有时反而降低性能，且高 IER 不保证高有用性，避免了过度宣称。

## 8. 不足与局限

- **IER 是近似量**：候选集近似、logit 裁剪、$\epsilon$ 处理等都会引入偏差，论文承认"没有更优选择的保证"。
