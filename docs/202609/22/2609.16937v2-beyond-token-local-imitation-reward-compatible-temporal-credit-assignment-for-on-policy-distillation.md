## 摘要
同策略蒸馏（OPD）已成为大语言模型后训练的一种有效方法，但现有目标在目标保真度与优化稳定性之间面临权衡。Token 级 OPD 提供稳定但局部的监督，而序列级 OPD 能够捕获未来信用，但代价是依赖于时域的方差。我们为这些形式化建立了一个统一的时序信用视角，表明实际的 Token 级 OPD 可以解释为对序列级反向 KL 梯度的一种时序近似。基于这一联系，我们提出 γOPD（GammaOPD），它使用折扣时序信用分配来平衡长时域监督与优化稳定性，同时具有与时域无关的方差上界。我们进一步为 γOPD 开发了一种奖励兼容的有界混合（RBM）机制，该机制平衡可验证的结果反馈与折扣后的 OPD 优势，从而超越纯粹依赖教师的优化。在数学与代码推理上的实验表明，在原始、规模不匹配和多教师蒸馏设置中，该方法相较于现有 OPD 方法均取得了一致的改进。

## Abstract
On-policy distillation (OPD) has emerged as an effective approach for large language model post-training, yet existing objectives face a trade-off between objective fidelity and optimization stability. Token-level OPD provides stable but local supervision, whereas sequence-level OPD captures future credit at the cost of horizon-dependent variance. We establish a unified temporal-credit view of these formulations, showing that practical token-level OPD can be interpreted as a temporal approximation to the sequence-level reverse-KL gradient. Building on this connection, we propose $γ$OPD (GammaOPD), which uses discounted temporal credit assignment to balance long-horizon supervision and optimization stability, while admitting a horizon-independent variance bound. We further develop a reward-compatible bounded mixing (RBM) mechanism for $γ$OPD that balances verifiable outcome feedback with the discounted OPD advantage to move beyond purely teacher-dependent optimization. Experiments on mathematical and code reasoning demonstrate consistent improvements over existing OPD methods across vanilla, size-mismatched, and multi-teacher distillation settings.

## 1. 核心问题与整体含义

- **研究背景**：同策略蒸馏（On-Policy Distillation, OPD）已成为大语言模型（LLM）后训练的关键技术，在数学、代码、科学推理等任务中用于将教师模型能力迁移至学生模型，并缓解曝光偏差。
- **核心矛盾**：现有 OPD 目标存在"目标保真度 vs 优化稳定性"的权衡：
  - **Token 级 OPD**（如实践中广泛使用的单样本 token 级蒙特卡洛估计）：计算高效、优化稳定，但仅提供局部监督，引入了相对于序列级目标的不可忽略偏差，实质上改变了优化问题。
  - **序列级 OPD**：更忠实地保留原始 reverse-KL 目标、能捕捉未来信用，但方差随响应长度增长，长推理轨迹下优化不稳定。
- **核心问题**：能否在 token 级与序列级之间建立统一理解，并设计一种既保留长时域信用分配、又保持优化稳定性的 OPD 目标？
- **整体含义**：论文从时序信用分配（temporal credit assignment）视角统一了两种 OPD 形式，指出 token 级 OPD 本质上是对序列级 reverse-KL 梯度的时序近似，并据此提出可插值的折扣方案 γOPD，同时引入可验证奖励以实现超越教师模仿的任务级优化。

## 2. 方法论

### 2.1 统一时序信用视角（理论基石）

- 定义 token 级与序列级 log-ratio：
  - 单 token：Δ_t = log π_θ(y_t|h_t) − log π_*(y_t|h_t)
  - 整序列：Δ(y) = Σ_{t=1}^{T} Δ_t
- 形式化两种 OPD 目标：
  - **序列级目标** J_seq^OPD：对完整响应轨迹比较学生与教师的分布（原始 reverse-KL）。
  - **Token 级目标** J_token^OPD：在采样前缀上比较下一 token 分布，前缀分布 d̄_θ(h_t|x) 采用 stop-gradient。
- **关键结论（Proposition 3.1 & 3.2）**：
  - Token 级 OPD 梯度：∇J_token = E[Σ_t Δ_t ∇log π_θ(y_t|h_t)]，即实践中的 OPD 更新。
  - 序列级 OPD 梯度：∇J_seq = E[Σ_t (Σ_{t'=t}^{T} Δ_{t'}) ∇log π_θ(y_t|h_t)]。
  - 两者在函数值层面等价（当 θ̄ = θ 时），但梯度不等价：token 级丢弃了 y_t 对未来前缀的间接影响，仅保留局部项 Δ_t。

### 2.2 γOPD：折扣时序信用分配

- **核心思想**：引入折扣因子 γ ∈ [0,1] 控制未来 OPD 信用分配给当前 token 的比例，在 token 局部与序列级之间插值。
- **折扣优势**：A_t^(γ) ≜ −Σ_{t'=t}^{T} γ^{t'−t} Δ_{t'}

  - γ = 1：恢复序列级 return-to-go（恢复公式 6）。
  - 0 < γ < 1：有偏代理，方差可由 γ 控制。
- **代理梯度**：g_γ(θ) ≜ −E[Σ_t A_t^(γ) ∇_θ log π_θ(y_t|h_t)]。
- **方差稳定性定理（Theorem 3.3）**：
  - 在 token 级优势二阶矩有界（E[(A_t^(0))²] ≤ σ²_Δ）假设下：
    - 序列级信用方差界：Var(A_t^(1)) ≤ (T−t+1)² σ²_Δ（随时域二次增长，最坏情况可达）。
    - γOPD 信用方差界：Var(A_t^(γ)) ≤ σ²_Δ/(1−γ)²，∀γ ∈ [0,1)（**与时域无关**）。

### 2.3 奖励兼容有界混合（RBM）

- **动机**：γOPD 仍源于教师分布，学生受教师策略约束，缺乏任务级优化信号；朴素混合可验证奖励会因教师优势幅度波动大而压倒有界任务奖励。

  2. 通过 softsign 变换将其压缩至 (−1, 1)；

## 6. 主要结论与发现

- **理论层面**：Token 级 OPD 可严格解释为序列级 reverse-KL 梯度的时序截断近似；γOPD 通过折扣因子在两者间插值，并具备与时域无关的方差上界。
- **Vanilla 蒸馏**：γOPD 相对最强基线在 AvgAcc 提升 2.30%、AvgPass 提升 1.80%，并**同时超越教师**（AvgAcc 69.49 vs 教师 68.10）。
- **尺寸不匹配蒸馏**：所有学生方法均低于教师，但 γOPD 相对最强基线提升 AvgAcc 4.92%、AvgPass 2.06%，显著缩小差距。
- **多教师蒸馏**：γOPD 的 TotalAvg 比最强基线 AOPD 提升 1.87%，在数学与代码两域平均均超越教师。
- **训练动态**：γOPD 始终保持最高验证奖励、绝对优势稳定、梯度范数波动最小，响应长度收敛更短且稳定。
- **消融结论**：时序折扣单独贡献 +2.04 分；朴素奖励混合仅额外 +0.05；加入有界归一化后总提升达 +3.91 分，说明折扣与有界归一化互补。
- **γ 敏感性**：γ = 1 因长时域导致梯度范数骤增、熵快速坍塌、性能下降；γ = 0.99 在长程信用与稳定性间取得最佳平衡。
- **Token 优势可视化**：A_t^(0.99) 相比 A_t^(0) 信号更平滑，能将信用重新分配到与最终结果更相关的推理步骤（正确响应强化关键推导，错误响应集中于错误公式推导而非无关 token）。

## 7. 优点

- **理论贡献扎实**：给出 token 级与序列级 OPD 梯度的严格推导与统一视角，明确指出 stop-gradient 是偏差来源，为后续方法设计提供清晰理论依据。
- **方法设计简洁且原理清晰**：仅引入一个折扣因子 γ 即可在偏差-方差间连续调节，且具有显式的时域无关方差界。
- **RBM 设计巧妙**：通过均值绝对归一化 + softsign 使教师信号有界，保证 sign(Â_t) = R(x,y)，既保留 token 级相对信用，又避免教师信号淹没任务奖励，实现"奖励兼容"。
- **计算开销极低**：额外开销仅约 0.1% 计算时间、0.00046% 内存，工程上易落地。
- **实验覆盖较全面**：同时验证数学与代码、三种蒸馏配置、多类基线，且在多个设置下均超越教师，说明方法能突破教师模仿天花板。
- **可视化分析直观**：token 级优势热力图清晰展示时序信用重分配效果，增强方法可解释性。

## 8. 不足与局限

- **模型规模受限**：实验仅限 10B 参数以下模型（最大为 Qwen3-4B），未验证更大规模模型上的可扩展性。
- **折扣因子需手动设定**：γ = 0.99 为默认值，缺乏自适应或熵感知折扣机制；不同任务/模型下最优 γ 的鲁棒性未充分讨论。
- **消融覆盖有限**：组件消融仅在 AIME24/25 上进行，未在代码任务与尺寸不匹配设置中系统验证。
- **基线对比不全**：未与 SCOPE、RWOPD、Entropy-aware OPD 等最新奖励引导/信用分配 OPD 方法直接对比，部分文献仅在相关工作提及。
- **方差界的假设较强**：Theorem 3.3 依赖 token 级优势二阶矩有界假设，实际训练中该假设是否成立未做经验验证。
- **统计严谨性**：未报告多随机种子运行的均值/标准差或显著性检验，部分提升（如多教师设置下的 MBPP+ 与教师持平）幅度较小。
- **奖励信号形式单一**：RBM 仅处理二值可验证奖励（±1），对连续奖励、过程奖励模型（PRM）或部分正确奖励的兼容性未探讨。
- **超参未公开调优细节**：γ 之外的其他混合权重、归一化细节的调参敏感性未充分说明。
