## 摘要
在策略蒸馏（OPD）中，每个新批次都要付出双重代价：学生生成轨迹，更强的教师为其评分。现有方法改进了哪些轨迹被评分以及教师信号如何构建，但通常只用一次 actor 更新来消耗该信号。我们提出 CLOOPD，一个将教师信号获取与学生侧实现分离的闭环框架。CLOOPD 在 KL 包络内选择一个自适应 $α$ 路点，冻结已评分的批次及其优势，在每次 actor 轮次后重新对学生进行前向传播，度量实现程度，并在单独的 token 预算下分配 actor 工作量。该框架包括确定性的两遍与三遍策略、按 token 计价的 CLOOPD-TPMR，以及预算匹配的对照。在 8-H20 节点上的六次 300 步运行中，每个 CLOOPD 策略都在可比的教师 token 规模下优于单遍 TOP-D 锚点：宏平均准确率从 15.41 提升至 CLOOPD-Fixed2 的 17.78，以及 CLOOPD-Fixed3 的 19.36。在第 100 步，CLOOPD-Fixed3 达到 15.35，几乎匹配第 300 步的 TOP-D，同时少用 67.2% 的教师评分 token 和 28.0% 的 GPU 小时。更早的 8-A100 消融实验表明，自适应 $α$ 消除了观察到的信任包络违规；第三遍增加了余量。这些结果将 CLOOPD 定位为一个用于对学生从教师评分 token 中学习的充分程度进行预算分配的框架。

## Abstract
On-policy distillation (OPD) pays twice for each fresh batch: the student generates trajectories and a stronger teacher scores them. Existing methods improve which trajectories are scored and how the teacher signal is constructed, but usually consume it with one actor update. We introduce CLOOPD, a closed-loop framework separating teacher-signal acquisition from student-side realization. CLOOPD selects an adaptive $α$ waypoint inside a KL envelope, freezes the scored batch and its advantages, re-forwards the student after each actor pass, measures realization, and allocates actor work under a separate token budget. The framework includes deterministic two- and three-pass policies, token-priced CLOOPD-TPMR, and a budget-matched control. Across six 300-step runs on an 8-H20 node, every CLOOPD policy improves the one-pass TOP-D anchor at comparable teacher-token scale: macro accuracy rises from 15.41 to 17.78 with CLOOPD-Fixed2 and 19.36 with CLOOPD-Fixed3. At step 100, CLOOPD-Fixed3 reaches 15.35, nearly matching TOP-D at step 300 while using 67.2% fewer teacher-scored tokens and 28.0% fewer GPU-hours. Earlier 8-A100 ablations show adaptive $α$ eliminates observed trust-envelope violations; a third pass adds headroom. These results position CLOOPD as a framework for budgeting how fully students learn from teacher-scored tokens.

## 1. 核心问题与研究动机

- **背景**：在线策略蒸馏（On-Policy Distillation, OPD）让学生在自己的当前策略上采样轨迹，并由更强的教师提供 token 级稠密监督，从而避免纯离线蒸馏的分布错配。
- **代价结构**：每个新批次构成一次"紧耦合交易"——学生生成轨迹（rollout）、教师为每个有效 token 打分、actor 执行一次更新。对推理模型而言，rollout 与教师推理都是昂贵环节，因此"被教师打分的批次"是一种昂贵的学习资产，而非普通 mini-batch。
- **已有工作的缺口**：TOP-D（构造近端教师路点）、TrOPD（将监督定位到可靠区域）、Trust-Region Behavior Blending（在信任域内混合行为策略）等方法都在优化**信号的获取侧**——即"对哪些轨迹打分、构造什么样的教师信号"。但它们普遍遵循"一遍 actor 更新即丢弃批次"的惯例，留下一个互补问题未被回答：**在付出一次安全教师打分后，学生在批次被丢弃前究竟实现了多少该信号？**
- **关键区分**：再买一个新批次 = 增加教师信号的**广度（breadth）**；复用已获取批次再做一次 actor pass = 增加**实现深度（depth）**。两者表面都表现为"更多训练"，但成本结构不同：广度需要新 rollout 与教师打分，深度只复用响应、教师 log 概率与优势，只需 actor 算力。仅看总步数、总 token 或总 GPU 小时，无法揭示学习预算到底花在哪里。
- **整体含义**：论文把"PPO 的 epoch 数"从一项未报告的实现细节，转化为显式的蒸馏设计空间，并将"学生从教师打分 token 中学习的充分程度"变成一个可预算、可度量、可分配的资源问题。

## 2. 方法论

### 2.1 核心思想
- 将每个被教师打分的批次视为一次**闭环交易（closed-loop transaction）**，包含三个阶段：**Probe（探测）→ Observe（观测）→ Allocate（分配）**。
- 教师成本只付一次；actor 成本随"实现的深度"缩放。闭环在不移动路点、不重新生成响应、不再次调用教师的前提下闭合。
- 四条不变式保证环路良定义：① rollout 策略 π₀ 锚定所有采样 token 比率；② 近端路点每批次只求解一次并冻结；③ A₀ 在 E1/E2 后不重算；④ 记账按资源所有者切分——一个有效响应 token 只在教师获取时计费一次，但在每次 actor pass 中都要计费一次。

### 2.2 自适应 α 路点构造（目标可行性层）
- 对提示 x，y 采样自行为策略 π₀；记 ℓˢₜ = log π₀(yₜ|x,y<ₜ)，ℓᵀₜ = log qᵀ(yₜ|x,y<ₜ)。
- 原始 OPD 使用采样 token 对数比 rᵗᴼᴾᴰ = ℓᵀₜ − ℓˢₜ；TOP-D 构造近端路点 qα = (1−α)π₀ + αqᵀ，其采样 token 奖励为
  **gα,t = log(1 − α + α·exp(ℓᵀₜ − ℓˢₜ))**，当 α < 1 时下界为 log(1−α)。
- CLOOPD 在一个 32 点、从 0.01 到 1 的对数间隔网格上，选择**满足约束的最大 α**：
  - K3 信任代理：⟨e^{gα} − 1 − gα⟩_m ≤ 0.02
  - 奖励下尾保护：Q₀.₀₅(gα) ≥ −0.5
- 设计意图：自适应 α 是**目标构造机制而非学习率调度**。固定混合会把同样的教师位移施加到教师–学生差距差异很大的批次上；CLOOPD 则对当前批次求解可行性——容易的交易可以向 qᵀ 移动更远，大差距交易则保持在同一外部 K3 与奖励尾部限制内。
- 随后把 gα 转为 TOP-D token 回报 Rₜ = gα,t + (Σ_{j=t+1}^{L} gα,j)/max(L−t,1)，并在提示内归一化得到 A₀；路点、响应、行为/教师 log 概率、mask 与 A₀ 全部冻结。

### 2.3 Probe：冻结信号的 actor 轮次
- 第一次 actor pass（E1）产生 π₁；策略可继续执行 E2、E3，产生 π₂、π₃，且始终复用同一 A₀。
- 每次 pass 后重新前向学生，因此每个深度增量都有"前–后"策略的实测值。E2/E3 消耗 actor 响应 token，但**不触发 rollout 生成，也不调用教师推理**。
- 与通用 PPO 多 epoch 的区别：被复用的对象包含一次昂贵的教师评估，目标是冻结的教师诱导路点，且朝目标的进展被仪器化度量。

### 2.4 Observe：路点实现度与优势实现度
- 采样 token 位移：**Δ⁽ᵏ⁾ₜ = log πₖ(yₜ|x,y<ₜ) − log π₀(yₜ|x,y<ₜ)**。
- 以 e₀,t = gα,t 为初始路点差距，残差 eₖ,t = e₀,t − Δ⁽ᵏ⁾ₜ，定义 **TSR⁽ᵏ⁾ = 1 − ⟨eₖ²⟩_w / ⟨e₀²⟩_w**。
  - TSR 为 0 表示平方路点差距未变，为 1 表示在采样路径上被完全闭合；等价于"位移与路点差距的归一化对齐度的两倍减去归一化位移能量"，从而可区分**有用移动**与**过冲/正交移动**。
- 提示均衡权重 **w_{i,t} = 1 / (|P| · |R(pᵢ)| · Lᵢ)**：让提示之间、提示内兄弟响应之间、响应内有效 token 之间各分配相等质量，避免长解与多 rollout 的提示主导统计量。
- 与 actor 目标对齐的优势空间统计量：**Mₖ = ⟨A₀, log πₖ(y) − log πₖ₋₁(y)⟩_w**，按提示计算并报告均值、标准误与 95% 下置信界（LCB）。Mₖ > 0 表示第 k 次 pass 在冻结交易上取得优势对齐的进展。
- 二者分工：**TSR 是教师路点的诊断量；Mₖ 是分配下一次 actor pass 的因果、行动前（pre-action）评分**。

### 2.5 Allocate：四种实现策略
- **CLOOPD-Fixed2**（确定性两遍）：每批次执行 E1+E2。作为稳定骨干，actor 成本可预测（约两倍教师打分 token 量），无需学习或校准的分配规则。
- **CLOOPD-Fixed3**（确定性三遍）：每批次执行 E1+E2+E3，给出优先实现深度时的可达质量上界，并提供完全观测的 E2/E3 边际工作以用于控制器设计。
- **CLOOPD-TPMR**（按 token 计价的边际实现）：每批次执行 E1+E2，E3 为在线动作。令 gₜ = max(LCB(M₂,ₜ), 0)，cₜ 为一次 actor pass 的有效响应 token 数，定义每百万 actor token 的效用 **uₜ = 10⁶·gₜ / max(cₜ,1)**，当 **uₜ ≥ λ_token 且 安全 ∧ 预算 ∧ 节奏 条件成立**时执行 E3。安全包络检查有效实现统计量、内部 K3、ESS、有限值与看门狗状态；预算仅在 E3 成功执行后按其真实活跃 token 数计费。token 价格由 CLOOPD-Fixed3 试点校准，且只使用 E3 之前可得的信息，不使用 E3 结果或留出准确率。
- **CLOOPD-Random**（预算匹配随机分配）：与 TPMR 共享 E1+E2 骨干、E3 硬 token 上限、节奏约束与安全检查，但**不读取 M₂** 而随机采样是否执行 E3。它是分配对照：与 TPMR 对比可识别在线评分本身的贡献；与 Fixed2 对比可识别"额外花掉一份 actor token 预算"本身的价值。

## 3. 实验设计

### 3.1 两层证据结构
- **主实验（长时程）**：在单节点 8×H20 上进行 6 次 300 步运行，共 6 个臂：OPD、固定 α=0.3 的 TOP-D（论文归一化）、CLOOPD-Fixed2、CLOOPD-TPMR、CLOOPD-Fixed3、CLOOPD-Random。四个 CLOOPD 策略共享自适应路点选择、保预算归一化与冻结 A₀。
- **机制实验（消融）**：在单节点 8×A100-SXM4-80GB 上进行 50–150 步的匹配消融，用于隔离：固定 vs 自适应路点、E1 vs E1+E2、E2 vs 固定/选择性 E3。两套硬件的结果**分表报告、从不合并**。
